## Related Works

Serverless computing has gained significant traction due to its ability to abstract server management, enabling automatic scaling, efficient resource utilization, and cost-effective pricing models \[[Syed Salauddin Mohammad Tariq' 2024-06-17](http://arxiv.org/abs/2406.11734v1)\]. However, the cold-start latency remains a critical challenge that negatively impacts end-to-end performance \[[Tam N. Nguyen' 2023-04-01](http://arxiv.org/abs/2304.00396v1)\]. This issue arises when new function instances are initialized, often due to inefficient library initialization and usage \[[Shiyu Wang' 2024-11-13](http://arxiv.org/abs/2411.09065v1)\]. Existing static analysis techniques can identify unreachable libraries, but they fail to address workload-dependent inefficiencies, resulting in limited performance improvements \[[Shiyu Wang' 2024-11-13](http://arxiv.org/abs/2411.09065v1)\].

Several studies have explored solutions to mitigate cold-start latency. For instance, \[[Mohak Chadha' 2022-10-09](http://arxiv.org/abs/2210.04212v1)\] introduced a pool-based approach to maintain warm containers, reducing P99 response time by 85%. Similarly, \[[Chiheng Lou' 2025-02-21](http://arxiv.org/abs/2502.15524v2)\] proposed a temporal convolutional network (TCN) to predict function instance arrivals and optimize resource provisioning, outperforming other machine learning algorithms for time series. \[[Muhammed Golec' 2023-10-12](http://arxiv.org/abs/2310.08437v2)\] introduced FaaSLight, an application-level optimization technique that reduces code loading latency by up to 78.95% by separating essential from optional code. \[[Ping-Min Lin' 2019-03-28](http://arxiv.org/abs/1903.12221v1)\] utilized SARIMA for time series forecasting to predict incoming requests and adjust container allocation, reducing resource wastage and function launching time.  presented a proactive technique called freshen, which allows developers to specify functionality to perform before a function executes, mitigating overheads at execution time.

Recent works have also focused on improving cold-start performance through dynamic optimization. \[[Xuanzhe Liu' 2022-07-17](http://arxiv.org/abs/2207.08175v2)\] developed LibProf, a Python profiler that identifies inefficient library initialization and usage in Python-based serverless applications, achieving up to a 2.26x speedup in cold-start execution time. \[[Zijun Li' 2021-08-25](http://arxiv.org/abs/2108.11240v1)\] proposed a method to reduce cold-start latency by leveraging the language model to estimate item similarities, which can be integrated into recommender systems.  investigated the performance of open-source serverless platforms, identifying design issues affecting throughput and latency.  evaluated the performance of migrating a complex IoT platform from microservices to serverless, showing that Google Cloud Run (GCR) is always cheaper than other deployment strategies.

In addition,  introduced a two-scale optimization approach for graded lattice structures, reducing the computational effort required for full-scale analyses by using asymptotic homogenization.  proposed MeSHwA, a memory-safe architecture for serverless computing, aiming to improve security and efficiency by isolating components.  developed an efficient Matlab code for three-dimensional topology optimization, improving computational efficiency and convergence rates.  introduced stochastic proximal point methods, demonstrating improved convergence and robustness guarantees under weak assumptions.

These studies collectively highlight the diverse approaches to mitigating cold-start latency in serverless computing, ranging from static analysis and dynamic optimization to machine learning and architectural improvements. The proposed SLIMSTART tool builds upon these insights, leveraging profile-guided optimization to identify and mitigate inefficient library usage patterns, thereby improving initialization and end-to-end latency while reducing memory usage.
