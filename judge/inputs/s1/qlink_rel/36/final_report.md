## Related Works

Deploying large language models (LLMs) on edge devices presents significant challenges due to the limited storage, power, and computational capabilities of such hardware \[[19](http://arxiv.org/abs/2309.17453)\]. Prior work has explored various techniques to address these limitations, including quantization, sparsity, and efficient attention mechanisms. For instance, SmoothQuant enables post-training quantization of LLMs, achieving 8-bit weight and activation quantization with minimal accuracy loss \[[2](http://arxiv.org/abs/2211.10438)\]. Similarly, AWQ introduces activation-aware weight quantization, reducing model size while preserving performance \[[3](http://arxiv.org/abs/2306.00978)\]. These methods are critical for enabling efficient deployment on resource-constrained devices.

Efficient attention mechanisms are also essential for reducing memory and computational overhead. FlashAttention and FlashAttention-2 significantly improve the efficiency of attention operations by reducing memory usage and increasing parallelism \[[14](http://arxiv.org/abs/2205.14135)\]\[[4](http://arxiv.org/abs/2307.08691)\]. These techniques are particularly important for handling long sequences, which are common in real-world applications. Additionally, DejaVu leverages contextual sparsity to accelerate inference without compromising model quality or in-context learning ability \[[12](http://arxiv.org/abs/2310.17157)\]. This approach allows for significant speedups, especially for large models like OPT-175B.

Another important direction is the use of hardware-friendly quantization techniques that account for the characteristics of modern accelerators. OliVe introduces an outlier-victim pair quantization method that is optimized for hardware efficiency, achieving substantial speedups and energy savings compared to existing methods \[[7](http://arxiv.org/abs/2304.07493)\]. Similarly, LLM.int8() enables 8-bit matrix multiplication for Transformers, reducing memory usage by half while maintaining full precision performance \[[9](http://arxiv.org/abs/2208.07339)\]. These methods are crucial for deploying large models on edge devices with limited memory.

Furthermore, specialized hardware accelerators have been proposed to improve the efficiency of LLM inference. FTRANS uses FPGA-based acceleration to reduce model size and improve energy efficiency, achieving up to 16 times model compression \[[18](http://arxiv.org/abs/2007.08563)\]. DFX, a multi-FPGA appliance, further enhances performance and energy efficiency for text generation tasks, outperforming GPU-based solutions \[[20](http://arxiv.org/abs/2209.10797)\]. These hardware solutions are essential for achieving the high throughput and low latency required for real-time applications.

[Snippet]: «Transformer-based large language models (LLMs) have achieved great success with the growing model size. LLMs' size grows by 240× every two years, which outpaces the hardware progress and makes model inference increasingly costly. Model quantization is a promising approach to mitigate the widening gap between LLM size and hardware capacity. However, the existence of outliers, values with significant magnitudes, in LLMs makes existing quantization methods less effective. Prior outlier-aware quantization schemes adopt sparsity encoding techniques to separate outliers from normal values where the process requires global coordination (e.g., a global sparsity coordination list). The key insight of OliVe is that outliers are important while the normal values next to them are not. Thus those normal values (called victims) can be sacrificed to accommodate outliers. This enables a memory-aligned OVP encoding scheme, which can be efficiently integrated to the existing hardware accelerators like systolic array and tensor core. As a result, OliVe-based accelerator surpasses the existing outlier-aware accelerator, GOBO, by 4.5× speedup and 4.0× energy reduction, respectively, with a superior model accuracy.»
