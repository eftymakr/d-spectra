## Related Works

Maximum Inner Product Search (MIPS) has been a central challenge in machine learning and information retrieval, particularly in high-dimensional data applications \[[1](http://arxiv.org/abs/1610.03317)\]. Existing approaches to MIPS typically fall into two categories: those that rely solely on inner product (IP) similarity, which can suffer from local optima and redundant computations, and those that reduce the MIPS problem to nearest neighbor search under the Euclidean metric through space projection, which may lead to topology destruction and information loss \[[1](http://arxiv.org/abs/1610.03317)\]. However, recent works have demonstrated that the two paradigms are not inherently mutually exclusive, and that integrating IP and Euclidean metrics in indexing and search algorithms can significantly enhance MIPS performance \[[1](http://arxiv.org/abs/1610.03317)\].

A greedy approach for budgeted MIPS has been proposed, which yields superior performance compared to state-of-the-art approaches \[[1](http://arxiv.org/abs/1610.03317)\]. This method, called Greedy-MIPS, is designed to handle budgeted MIPS by carefully studying the problem structure and provides a simple yet effective solution \[[1](http://arxiv.org/abs/1610.03317)\]. Additionally, asymmetric LSH (ALSH) has been introduced as a provably sublinear time algorithm for approximate MIPS, enabling efficient sublinear hashing schemes for MIPS by converting inner products into near neighbor search problems \[[2](http://arxiv.org/abs/1405.5869)\].

The problem of efficiently finding the best match for a query in a given set with respect to the inner product has also been explored using branch-and-bound algorithms and novel data structures like the cone tree \[[3](http://arxiv.org/abs/1202.6101)\]. These methods have shown significant improvements in query time over naive search techniques, with some cases exhibiting up to five orders of magnitude improvement \[[3](http://arxiv.org/abs/1202.6101)\]. Furthermore, the use of proximity graphs for MIPS has gained traction, with the inner-product navigable small world graph (ip-NSW) achieving an order of magnitude speedup over the fastest baseline \[[4](http://arxiv.org/abs/1909.13459)\].

Norm-Ranging LSH (NORM-RANGING LSH) has been proposed to address the performance issues of SIMPLE-LSH by partitioning datasets into sub-datasets and building hash indexes independently, which reduces the number of probes required for the same recall \[[5](http://arxiv.org/abs/1809.08782)\]. Similarly, quantization-based approaches have been introduced to enable fast approximate MIPS by quantizing database vectors in multiple subspaces and approximating inner products as sums of inner products with subspace quantizers \[[6](http://arxiv.org/abs/1509.01469)\].
