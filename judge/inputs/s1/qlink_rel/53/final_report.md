## Related Works

Sequential recommendation systems aim to predict the next item a user will interact with, leveraging the sequential nature of user behavior \[[10](http://arxiv.org/abs/2001.04830)\]. Traditional approaches such as Markov Chains (MCs) assume that a user's next action depends only on their last few actions, while Recurrent Neural Networks (RNNs) capture longer-term dependencies \[[1](http://arxiv.org/abs/1808.09781)\]. However, RNNs often suffer from high computational costs and difficulty in capturing long-range dependencies \[[16](http://arxiv.org/abs/2111.00396)\]. Self-attention based models, such as SASRec, have emerged as a promising alternative by allowing the model to focus on relevant items in a user's history while maintaining efficiency \[[1](http://arxiv.org/abs/1808.09781)\]. These models, however, typically treat interactions as ordered sequences without considering the actual timestamps \[[2](https://www.semanticscholar.org/paper/9c7a455b1e48d01a99e58e884a6c1acb75074ad0)\].

Recent work has sought to incorporate temporal information into sequential recommendation. TiSASRec explicitly models the time intervals between interactions, enhancing the model's ability to capture temporal dynamics \[[2](https://www.semanticscholar.org/paper/9c7a455b1e48d01a99e58e884a6c1acb75074ad0)\]. Similarly, the MEANTIME model introduces multi-temporal embeddings to better represent the sequential nature of user behavior \[[17](http://arxiv.org/abs/2008.08273)\]. These approaches highlight the importance of temporal awareness in capturing meaningful patterns in user interactions.

Efforts have also been made to improve the efficiency of attention mechanisms. LinRec introduces a linear-time attention mechanism, reducing the computational complexity of traditional attention mechanisms while preserving their effectiveness \[[18](http://arxiv.org/abs/2312.00752)\]. This is particularly important for long-term sequential recommendation, where the sequence length can be extensive \[[19](http://arxiv.org/abs/2310.02367)\]. The S4 model, based on structured state spaces, offers a more efficient approach to modeling long sequences while maintaining theoretical guarantees \[[16](http://arxiv.org/abs/2111.00396)\]. These models demonstrate that efficient sequence modeling is crucial for real-time applications.

In addition to efficiency, models have been developed to better capture diverse user preferences. BERT4Rec employs a bidirectional self-attention mechanism to model user behavior from both left and right contexts, allowing for a more comprehensive understanding of user preferences \[[5](http://arxiv.org/abs/1904.06690)\]. Similarly, the SSE-PT model introduces personalized user embeddings, enhancing the model's ability to capture individual user preferences \[[7](https://www.semanticscholar.org/paper/5aed438fecf702ead9c0cddfa9a80bd00cff0138)\]. These approaches demonstrate that personalization is essential for improving recommendation accuracy.

Furthermore, the use of graph neural networks (GNNs) has been explored to better model complex user-item interactions. The SURGE model constructs interest graphs from user behavior sequences, enabling the model to capture both core interests and dynamic preferences \[[6](http://arxiv.org/abs/2106.14226)\]. Similarly, SR-GNN models sessions as graph-structured data, allowing for the capture of complex item transitions \[[22](http://arxiv.org/abs/1811.00855)\]. These approaches highlight the potential of GNNs in sequential recommendation.

State-space modeling (SSM) has emerged as a promising approach for sequence modeling, particularly for handling long-range dependencies in sequential data \[[1](http://arxiv.org/abs/1808.09781)\]. Unlike traditional models such as RNNs, CNNs, and Transformers, which face challenges in scaling to very long sequences, SSMs simulate the system dynamics using a state matrix $ A $, enabling efficient computation of long-range dependencies \[[1](http://arxiv.org/abs/1808.09781)\]. However, early SSM implementations suffered from high computational and memory costs, limiting their practicality \[[1](http://arxiv.org/abs/1808.09781)\]. To address this, the Structured State Space (S4) model was introduced, which applies a low-rank correction to the state matrix $ A $, allowing stable diagonalization and reducing the SSM to a Cauchy kernel computation \[[1](http://arxiv.org/abs/1808.09781)\]. This improvement enables S4 to achieve strong empirical results across various benchmarks, including achieving 91% accuracy on sequential CIFAR-10 without data augmentation and outperforming Transformers on long-sequence tasks \[[1](http://arxiv.org/abs/1808.09781)\]. Additionally, recent work has focused on improving SSMs for content-based reasoning, particularly in discrete modalities like language, by making SSM parameters functions of the input \[[2](https://www.semanticscholar.org/paper/9c7a455b1e48d01a99e58e884a6c1acb75074ad0)\]. This allows models to selectively propagate or forget information along the sequence, enhancing their ability to handle diverse interaction patterns \[[2](https://www.semanticscholar.org/paper/9c7a455b1e48d01a99e58e884a6c1acb75074ad0)\]. These advancements have led to the development of models like Mamba, which integrates selective SSMs into a simplified architecture without attention or MLP blocks, achieving fast inference and linear scaling in sequence length \[[2](https://www.semanticscholar.org/paper/9c7a455b1e48d01a99e58e884a6c1acb75074ad0)\]. Such improvements highlight the growing importance of SSMs in addressing the limitations of traditional sequence modeling approaches \[[1](http://arxiv.org/abs/1808.09781)\]\[[2](https://www.semanticscholar.org/paper/9c7a455b1e48d01a99e58e884a6c1acb75074ad0)\].
