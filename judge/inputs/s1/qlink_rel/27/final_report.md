## Related Works

Recent advancements in information retrieval have focused on improving the accuracy and efficiency of document and table retrieval systems. Traditional approaches rely on a pipeline consisting of representation, indexing, and search stages, where each stage is typically handled by separate components \[[3](http://arxiv.org/abs/2206.02743)\]. This approach, while effective, suffers from error accumulation during the indexing and search phases, which can degrade overall performance \[[1](http://arxiv.org/abs/2206.10128)\]. Additionally, insufficient interaction between queries and tables hinders semantic alignment, limiting accuracy improvements \[[1](http://arxiv.org/abs/2206.10128)\]. 

To address these limitations, several works have explored differentiable search indexes (DSIs), which unify indexing and retrieval into a single model \[[2](http://arxiv.org/abs/2202.06991)\]. DSIs encode all information about the corpus directly into the model parameters, allowing queries to be answered without an explicit index \[[2](http://arxiv.org/abs/2202.06991)\]. This paradigm eliminates the need for separate indexing and retrieval components, reducing error accumulation \[[1](http://arxiv.org/abs/2206.10128)\]. However, existing DSI models face challenges in cross-lingual retrieval and dynamic indexing, where the data distribution between indexing and retrieval phases differs significantly \[[1](http://arxiv.org/abs/2206.10128)\]. 

To improve semantic alignment between queries and tables, some approaches have focused on generating synthetic queries for each table using large language models \[[16](http://arxiv.org/abs/1706.02427)\]. These synthetic queries are then used to train a model that learns the mapping between queries and table identifiers, enabling deeper query-table interactions \[[16](http://arxiv.org/abs/1706.02427)\]. This idea is closely related to the work of DSI-QG, which generates relevant queries during indexing to mitigate data distribution mismatches \[[1](http://arxiv.org/abs/2206.10128)\]. 

Another challenge in retrieval systems is the issue of catastrophic forgetting when continuously updating the index with new documents \[[6](http://arxiv.org/abs/2212.09744)\]. This problem arises because retraining the model from scratch is computationally expensive and can lead to loss of previously learned information \[[6](http://arxiv.org/abs/2212.09744)\]. To address this, DSI++ introduces an index update strategy that isolates parameters for newly indexed documents, mitigating forgetting during continual learning \[[6](http://arxiv.org/abs/2212.09744)\]. This approach is particularly relevant for dynamic table retrieval systems that need to handle evolving data \[[1](http://arxiv.org/abs/2206.10128)\].

Furthermore, the use of dense representations for retrieval has been widely explored, with models like ColBERT offering efficient and effective passage search through contextualized late interaction over BERT \[[7](http://arxiv.org/abs/2004.12832)\]. ColBERT improves retrieval speed and accuracy by leveraging vector-similarity indexes and fine-grained similarity modeling \[[7](http://arxiv.org/abs/2004.12832)\]. Similarly, Dense Passage Retrieval (DPR) has shown significant improvements over traditional sparse models like BM25 \[[11](http://arxiv.org/abs/2004.04906)\].

Differentiable Search Indexes (DSI) represent a paradigm shift in information retrieval by integrating indexing and retrieval into a single transformer model, eliminating the need for separate components \[[2](http://arxiv.org/abs/2202.06991)\]. This approach allows the model to directly map queries to document identifiers, leveraging the entire corpus encoded within its parameters \[[5](http://arxiv.org/abs/1810.04805)\]. However, existing DSI models face challenges such as data distribution mismatches between indexing and retrieval, particularly in cross-lingual settings \[[1](http://arxiv.org/abs/2206.10128)\]. To address these issues, researchers have proposed enhancements like DSI-QG, which introduces generated queries during indexing to improve alignment between queries and documents \[[1](http://arxiv.org/abs/2206.10128)\]. Similarly, the Semantic-Enhanced DSI (SE-DSI) model improves document memorization by incorporating semantic features and elaborative descriptions \[[5](http://arxiv.org/abs/1810.04805)\]. These advancements highlight ongoing efforts to refine DSI's effectiveness through better query-document interaction and more meaningful document representation \[[1](http://arxiv.org/abs/2206.10128)\]\[[5](http://arxiv.org/abs/1810.04805)\].
