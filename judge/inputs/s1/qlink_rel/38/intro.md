## Related Works

Memory bandwidth regulation and cache partitioning have been widely studied for achieving predictable timing in real-time computing systems \[[1](https://www.semanticscholar.org/paper/50d359dc737cb5c296b527f4eb1541dc55f3ed86)\]. These techniques are often combined with partitioned scheduling to ensure that task execution times depend on the allocated resources \[[2](https://www.semanticscholar.org/paper/bbebaeb1b00fdcde2aeb192543835d3ec1518f8d)\]. However, the co-allocation of tasks and resources remains a complex challenge, as task execution is highly sensitive to available resources \[[3](https://www.semanticscholar.org/paper/25ebad66dc10d7b01c22684cbb200ddeb6502475)\]. To address this, this paper introduces a 0-1 linear program for task-resource co-allocation, along with a multi-objective heuristic that minimizes resource usage while guaranteeing schedulability under a preemptive EDF scheduling policy \[[4](https://www.semanticscholar.org/paper/e02eb1430cb7aa53f20818d2b642abe10d58a459)\]. The heuristic employs a multi-layer framework, where an outer layer explores resource allocations using Pareto-pruned search, and an inner layer optimizes task allocation by solving a knapsack problem using dynamic programming \[[5](https://www.semanticscholar.org/paper/abbd6f8840092bd8e4e3684d3297e1b707abdc5d)\].

Several prior works have explored memory bandwidth regulation and cache partitioning. For instance, MemGuard is a memory bandwidth reservation system that enables efficient performance isolation in multi-core platforms \[[6](https://www.semanticscholar.org/paper/1ed3c2a13c728b4d294644db90fb278e62bece22)\]. It allows for the reservation of memory bandwidth, ensuring predictable performance for real-time tasks \[[7](https://www.semanticscholar.org/paper/dbd4eb5033815003e7f6519fd66e43e5fc297075)\]. Similarly, BRU (Bandwidth Regulation Unit) is a hardware module that enables per-core memory bandwidth regulation at fine-grained time intervals \[[8](http://arxiv.org/abs/1809.05921)\]. BRU improves time-predictability of real-time tasks while allowing best-effort tasks to better utilize memory bandwidth \[[9](https://www.semanticscholar.org/paper/0b1bc294dbd926f853a8ee41d1d8f8ecc3cfde13)\]. Additionally, the Jailhouse hypervisor has been used to enable fine-grained resource partitioning, leveraging cache set partitioning and MemGuard for memory bandwidth regulation \[[10](https://www.semanticscholar.org/paper/6e925ae85e385ac0e8810441d84be97c079f6b22)\].

Cache management and memory interference are also critical areas of research. For example, the paper "Bounding memory interference delay in COTS-based multi-core systems" presents techniques to provide a tight upper bound on the worst-case memory interference in a COTS-based multi-core system \[[11](https://www.semanticscholar.org/paper/d5336fd2234f431f554fc5d878503a04a27e366e)\]. The work explicitly models the major resources in the DRAM system, including banks, buses, and the memory controller, to analyze the worst-case memory interference delay imposed on a task by other tasks running in parallel \[[12](https://www.semanticscholar.org/paper/cf5b78d3e292fda8f6a8aa132da468f6d8e6a730)\]. Furthermore, the paper "Analysis of Dynamic Memory Bandwidth Regulation in Multi-core Real-Time Systems" focuses on dynamic allocation of main memory bandwidth and studies how to determine the worst-case response time of tasks spanning through a sequence of time intervals, each with a different bandwidth-to-core assignment \[[13](https://www.semanticscholar.org/paper/afca4afaaaa543a1da02b266e9b2ac46eb94793b)\].
