## Related Works

Efficient memory management and KV cache optimization have been central to improving the performance of large language model (LLM) serving systems. Prior work has focused on reducing memory usage and improving throughput through various techniques, including quantization, caching strategies, and dynamic memory allocation. 

Several approaches have been proposed to reduce the memory footprint of KV caches. For instance, **KIVI** introduces a tuning-free 2-bit quantization method for KV cache, achieving up to 2.6× memory reduction and enabling up to 4× larger batch sizes \[[2](http://arxiv.org/abs/2402.02750)\]. Similarly, **KVQuant** advances sub-4-bit quantization by introducing novel methods such as per-channel key quantization and non-uniform KV cache quantization, achieving less than 0.1 perplexity degradation on benchmark datasets \[[7](http://arxiv.org/abs/2401.18079)\]. These methods demonstrate the potential of quantization to reduce memory usage while maintaining model quality.

Dynamic memory management has also been explored. **PagedAttention** is inspired by virtual memory techniques and enables near-zero waste in KV cache memory by allowing flexible sharing within and across requests \[[1](http://arxiv.org/abs/2309.06180)\]. **H2O** introduces a heavy-hitter oracle to dynamically retain important tokens, reducing memory usage and improving throughput by up to 29× on certain models \[[5](http://arxiv.org/abs/2306.14048)\]. These approaches highlight the importance of intelligent eviction policies to maintain performance while minimizing memory consumption.

Efforts to optimize KV cache for streaming applications have also gained traction. **StreamingLLM** addresses the challenge of long-text generation by introducing attention sinks, which allow models to generalize to infinite sequence lengths without fine-tuning \[[4](http://arxiv.org/abs/2309.17453)\]. This is further complemented by **CacheGen**, which compresses KV caches and reduces network delays by up to 3.7× through efficient encoding and adaptive compression \[[8](http://arxiv.org/abs/2310.07240)\]. These systems demonstrate the potential of combining compression and streaming techniques to improve real-time performance.

Additionally, **Scissorhands** exploits the persistence of importance hypothesis, maintaining memory usage within a fixed budget by prioritizing pivotal tokens \[[3](http://arxiv.org/abs/2305.17118)\]. **SnapKV** further reduces memory footprint and improves decoding speed by selectively retaining important KV positions for each attention head \[[9](http://arxiv.org/abs/2404.14469)\]. These methods underscore the importance of adaptive and workload-aware strategies for KV cache management.

In summary, recent research has focused on reducing memory usage, improving throughput, and enabling efficient streaming inference through advanced caching and quantization techniques. These approaches collectively contribute to the broader goal of making LLM serving more scalable and efficient.

### <a id='category-quantization-methods'></a>Quantization Methods: 2 papers found.
Efficient KV cache quantization is a critical area of research for optimizing large language model (LLM) inference, particularly in reducing memory usage and improving throughput \[[1](http://arxiv.org/abs/2309.06180)\]. Existing studies highlight the challenges of quantizing key-value (KV) caches, which are essential for maintaining attention efficiency during inference \[[1](http://arxiv.org/abs/2309.06180)\]. For instance, the distribution of elements in KV caches has been found to vary significantly, necessitating tailored quantization strategies \[[1](http://arxiv.org/abs/2309.06180)\]. Specifically, key caches are better quantized per-channel, while value caches are more effectively quantized per-token, leading to significant memory savings without compromising model quality \[[1](http://arxiv.org/abs/2309.06180)\]. Building on these insights, recent approaches such as KIVI and KVQuant have introduced advanced techniques like per-channel key quantization, pre-RoPE key quantization, and non-uniform datatypes to enhance the accuracy of low-bit quantization \[[2](http://arxiv.org/abs/2402.02750)\]. These methods have demonstrated substantial improvements, including up to 2.6× memory reduction and 4× larger batch sizes, while maintaining model performance \[[1](http://arxiv.org/abs/2309.06180)\]. Additionally, custom CUDA kernels have been developed to further accelerate quantized KV cache operations, achieving speedups of up to 1.7× compared to baseline fp16 computations \[[2](http://arxiv.org/abs/2402.02750)\]. These advancements underscore the importance of understanding element distributions and workload patterns to design effective quantization strategies for real-world LLM serving scenarios \[[1](http://arxiv.org/abs/2309.06180)\].

[Snippet]: «Large language models(LLMs) have sparked a new wave of exciting AI applications. Hosting these models at scale requires significant memory resources. One crucial memory bottleneck for the deployment stems from the context window. It is commonly recognized that model weights are memory hungry; however, the size of key-value embedding stored during the generation process (KV cache) can easily surpass the model size. The enormous size of the KV cache puts constraints on the inference batch size, which is crucial for high throughput inference workload. Inspired by an interesting observation of the attention scores, we hypothesize the persistence of importance: only pivotal tokens, which had a substantial influence at one step, will significantly influence future generations. Based on our empirical verification and theoretical analysis around this hypothesis, we propose Scissorhands, a system that maintains the memory usage of the KV cache at a fixed budget without finetuning the model. In essence, Scissorhands manages the KV cache by storing the pivotal tokens with a higher probability. We validate that Scissorhands reduces the inference memory usage of the KV cache by up to 5X without compromising model quality. We further demonstrate that Scissorhands can be combined with 4-bit quantization, traditionally used to compress model weights, to achieve up to 20X compression.»

[Snippet]: «Deploying Large Language Models (LLMs) in streaming applications such as multi-round dialogue, where long interactions are expected, is urgently needed but poses two major challenges. Window attention, where only the most recent KVs are cached, is a natural approach -- but we show that it fails when the text length surpasses the cache size. We observe an interesting phenomenon, namely attention sink, that keeping the KV of initial tokens will largely recover the performance of window attention. We show that StreamingLLM can enable Llama-2, MPT, Falcon, and Pythia to perform stable and efficient language modeling with up to 4 million tokens and more. In addition, we discover that adding a placeholder token as a dedicated attention sink during pre-training can further improve streaming deployment. In streaming settings, StreamingLLM outperforms the sliding window recomputation baseline by up to 22.2x speedup. Code and datasets are provided at https://github.com/mit-han-lab/streaming-llm.»

[Snippet]: «Large Language Models (LLMs), despite their recent impressive accomplishments, are notably cost-prohibitive to deploy, particularly for applications involving long-content generation, such as dialogue systems and story writing. Often, a large amount of transient state information, referred to as the KV cache, is stored in GPU memory in addition to model parameters, scaling linearly with the sequence length and batch size. In this paper, we introduce a novel approach for implementing the KV cache which significantly reduces its memory footprint. Our approach is based on the noteworthy observation that a small portion of tokens contributes most of the value when computing attention scores. We call these tokens Heavy Hitters (H$_2$). Through a comprehensive investigation, we find that (i) the emergence of H$_2$ is natural and strongly correlates with the frequent co-occurrence of tokens in the text, and (ii) removing them results in significant performance degradation. Based on these insights, we propose Heavy Hitter Oracle (H$_2$O), a KV cache eviction policy that dynamically retains a balance of recent and H$_2$ tokens. We formulate the KV cache eviction as a dynamic submodular problem and prove (under mild assumptions) a theoretical guarantee for our novel eviction algorithm which could help guide future work. We validate the accuracy of our algorithm with OPT, LLaMA, and GPT-NeoX across a wide range of tasks. Our implementation of H$_2$O with 20% heavy hitters improves the throughput over three leading inference systems DeepSpeed Zero-Inference, Hugging Face Accelerate, and FlexGen by up to 29$\times$, 29$\times$, and 3$\times$ on OPT-6.7B and OPT-30B. With the same batch size, H2O can reduce the latency by up to 1.9$\times$. The code is available at https://github.com/FMInference/H2O.»
