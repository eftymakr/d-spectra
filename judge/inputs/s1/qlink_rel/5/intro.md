## Related Works

Instruction-following text embedding has emerged as a critical area in natural language processing (NLP), aiming to generate dynamic text embeddings that adapt to user instructions \[[1](http://arxiv.org/abs/1910.10683)\]. This task is particularly relevant for applications requiring real-time adaptation, such as information retrieval, semantic similarity, and document classification \[[1](http://arxiv.org/abs/1910.10683)\]. Existing approaches often suffer from significant computational overhead, as they require re-encoding the entire corpus for each new instruction \[[1](http://arxiv.org/abs/1910.10683)\]. This limitation has motivated the development of more efficient methods that can adapt pre-computed embeddings in real time \[[1](http://arxiv.org/abs/1910.10683)\].

Several studies have explored the use of pre-trained models for transfer learning, which has become a cornerstone of modern NLP \[[2](http://arxiv.org/abs/2212.09741)\]. For instance, BERT, a bidirectional transformer model, has demonstrated superior performance on a wide range of tasks by leveraging deep bidirectional representations \[[6](http://arxiv.org/abs/1810.04805)\]. Similarly, T5, a text-to-text transformer model, has been used to generate sentence embeddings that are scalable and effective for transfer learning \[[9](http://arxiv.org/abs/2108.08877)\]. However, these models typically require fine-tuning for each new task, which can be computationally expensive \[[9](http://arxiv.org/abs/2108.08877)\].

Recent work has focused on instruction-tuned models that can generalize across a variety of tasks without extensive fine-tuning \[[19](http://arxiv.org/abs/2109.01652)\]. For example, FLAN, a model instruction-tuned on over 60 NLP tasks, has shown significant improvements in zero-shot learning performance \[[19](http://arxiv.org/abs/2109.01652)\]. Similarly, InstructGPT, a model fine-tuned with human feedback, has demonstrated improved alignment with user intent and better performance on tasks such as question answering and text generation \[[10](http://arxiv.org/abs/2203.02155)\]. These models rely on human-annotated instruction data, which is often limited in quantity and diversity \[[19](http://arxiv.org/abs/2109.01652)\].

To address the limitations of human-annotated instruction data, several studies have proposed methods for generating synthetic instruction data \[[20](http://arxiv.org/abs/2304.12244)\]. For example, Self-Instruct, a framework that bootstraps instruction data from a language model's own generations, has shown promising results in improving instruction-following capabilities \[[3](http://arxiv.org/abs/2212.10560)\]. Similarly, WizardLM, a model fine-tuned on AI-evolved instructions, has demonstrated superior performance on complex tasks compared to human-created instructions \[[20](http://arxiv.org/abs/2304.12244)\]. These methods reduce the reliance on human annotations and enable the creation of large-scale instruction datasets \[[20](http://arxiv.org/abs/2304.12244)\].
