## Related Works

Federated learning (FL) has emerged as a promising paradigm for training machine learning models on decentralized data while preserving privacy \[[2](http://arxiv.org/abs/1912.04977)\]. It enables multiple clients to collaboratively train a model without sharing raw data, with a central server aggregating model updates \[[2](http://arxiv.org/abs/1912.04977)\]. However, existing FL approaches often assume homogeneous data distributions across clients, which is rarely the case in real-world scenarios \[[7](http://arxiv.org/abs/1806.00582)\]. This assumption leads to suboptimal model performance when data is non-IID (non-independent and identically distributed) \[[7](http://arxiv.org/abs/1806.00582)\]. 

Several works have addressed the issue of non-IID data in FL. For instance, \[[7](http://arxiv.org/abs/1806.00582)\] shows that federated learning accuracy can drop significantly when data is skewed, and proposes a strategy to improve performance by sharing a small subset of global data. Similarly, \[[12](http://arxiv.org/abs/1909.06335)\] investigates the impact of non-IID data on visual classification and proposes mitigation strategies such as server momentum. These studies highlight the importance of addressing data heterogeneity in FL \[[7](http://arxiv.org/abs/1806.00582)\]\[[12](http://arxiv.org/abs/1909.06335)\].

To improve communication efficiency, \[[4](http://arxiv.org/abs/1610.05492)\] introduces structured and sketched updates, reducing the communication cost by two orders of magnitude. Additionally, \[[29](http://arxiv.org/abs/2010.01264)\] proposes HeteroFL, a framework that allows for heterogeneous clients with different computation and communication capabilities, enabling efficient training of diverse local models \[[29](http://arxiv.org/abs/2010.01264)\]. 

Personalization in FL has also been explored, with methods like FedPer \[[23](http://arxiv.org/abs/1912.00818)\] and pFedMe \[[22](http://arxiv.org/abs/2006.08848)\] introducing personalization layers or regularization techniques to adapt models to individual client data. These approaches aim to improve performance on heterogeneous data by allowing for more tailored model updates \[[22](http://arxiv.org/abs/2006.08848)\]\[[23](http://arxiv.org/abs/1912.00818)\]. 

Furthermore, \[[25](http://arxiv.org/abs/2001.01523)\] introduces a method that jointly learns local and global representations, enabling communication-efficient training while maintaining performance. This approach is particularly useful in scenarios where privacy is a concern, as it minimizes the amount of data that needs to be shared \[[25](http://arxiv.org/abs/2001.01523)\].

In the context of active learning (AL), which aims to reduce annotation costs by selecting the most informative samples \[[1](http://arxiv.org/abs/1812.01097)\], federated active learning (FAL) extends this idea to distributed settings. ### <a id='category-federated-learning-(fl)-overview'></a>Federated Learning (FL) Overview: 14 papers found.
Federated learning (FL) has emerged as a critical paradigm for training machine learning models on decentralized data while preserving privacy, with significant research focusing on addressing challenges such as data heterogeneity, communication efficiency, and model convergence \[[2](http://arxiv.org/abs/1912.04977)\]. Early works highlighted the importance of FL in scenarios where clients have non-identically distributed data, leading to suboptimal performance with standard methods like FedAvg \[[6](http://arxiv.org/abs/1910.01991)\]. To mitigate these issues, researchers proposed adaptive optimization techniques such as federated versions of Adagrad, Adam, and Yogi, which showed improved convergence and performance in heterogeneous settings \[[3](http://arxiv.org/abs/2003.00295)\]. Additionally, frameworks like FedProx were introduced to handle both statistical and systems heterogeneity by allowing variable client participation and improving convergence stability \[[6](http://arxiv.org/abs/1910.01991)\]. The need for fairness in FL has also been addressed, with methods like q-FFL aiming to achieve a more uniform accuracy distribution across devices \[[7](http://arxiv.org/abs/1806.00582)\]. Furthermore, novel aggregation strategies, such as ensemble distillation, have been developed to enable flexible model fusion over heterogeneous client models without compromising privacy \[[5](http://arxiv.org/abs/1804.08333)\]. These advancements underscore the ongoing efforts to enhance the robustness, efficiency, and fairness of FL in real-world applications.

[Snippet]: «Federated Learning is a machine learning setting where the goal is to train a high-quality centralized model while training data remains distributed over a large number of clients each with unreliable and relatively slow network connections. We consider learning algorithms for this setting where on each round, each client independently computes an update to the current model based on its local data, and communicates this update to a central server, where the client-side updates are aggregated to compute a new global model. The typical clients in this setting are mobile phones, and communication efficiency is of the utmost importance. In this paper, we propose two ways to reduce the uplink communication costs: structured updates, where we directly learn an update from a restricted space parametrized using a smaller number of variables, e.g. either low-rank or a random mask; and sketched updates, where we learn a full model update and then compress it using a combination of quantization, random rotations, and subsampling before sending it to the server. Experiments on both convolutional and recurrent networks show that the proposed methods can reduce the communication cost by two orders of magnitude.»

### <a id='category-non-iid-data-challenges-in-fl'></a>Non-IID Data Challenges in FL: 6 papers found.
Non-IID data distribution is a significant challenge in federated learning (FL), as it leads to reduced model accuracy and convergence issues. Studies have shown that when local data across clients is non-IID, the accuracy of FL models can decrease by up to 55% for neural networks trained on highly skewed data \[[1](http://arxiv.org/abs/1812.01097)\]. This degradation is attributed to weight divergence, which can be measured using the earth mover's distance (EMD) between local and global data distributions \[[1](http://arxiv.org/abs/1812.01097)\]. Additionally, the heterogeneity of data across clients causes local updates to drift apart, leading to slow convergence and difficulty in tuning algorithms like FedAvg \[[4](http://arxiv.org/abs/1610.05492)\]. To mitigate these issues, researchers have proposed strategies such as creating globally shared data subsets, which can improve accuracy by up to 30% \[[1](http://arxiv.org/abs/1812.01097)\], and using server momentum to enhance performance in non-IID settings \[[2](http://arxiv.org/abs/1912.04977)\]. Furthermore, recent approaches like MOON leverage model-level contrastive learning to improve performance on image datasets \[[5](http://arxiv.org/abs/1804.08333)\], while theoretical analyses have highlighted the need for learning rate decay in non-IID scenarios to avoid suboptimal solutions \[[6](http://arxiv.org/abs/1910.01991)\]. These findings underscore the importance of addressing non-IID data challenges in FL to ensure effective and efficient collaborative learning.
