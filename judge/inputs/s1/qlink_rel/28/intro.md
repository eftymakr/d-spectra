## Related Works

Federated learning (FL) has emerged as a promising paradigm for training machine learning models on decentralized data while preserving privacy \[[2](http://arxiv.org/abs/1912.04977)\]. It enables multiple clients to collaboratively train a model without sharing raw data, with a central server aggregating model updates \[[2](http://arxiv.org/abs/1912.04977)\]. However, existing FL approaches often assume homogeneous data distributions across clients, which is rarely the case in real-world scenarios \[[7](http://arxiv.org/abs/1806.00582)\]. This assumption leads to suboptimal model performance when data is non-IID (non-independent and identically distributed) \[[7](http://arxiv.org/abs/1806.00582)\]. 

Several works have addressed the issue of non-IID data in FL. For instance, \[[7](http://arxiv.org/abs/1806.00582)\] shows that federated learning accuracy can drop significantly when data is skewed, and proposes a strategy to improve performance by sharing a small subset of global data. Similarly, \[[12](http://arxiv.org/abs/1909.06335)\] investigates the impact of non-IID data on visual classification and proposes mitigation strategies such as server momentum. These studies highlight the importance of addressing data heterogeneity in FL \[[7](http://arxiv.org/abs/1806.00582)\]\[[12](http://arxiv.org/abs/1909.06335)\].

To improve communication efficiency, \[[4](http://arxiv.org/abs/1610.05492)\] introduces structured and sketched updates, reducing the communication cost by two orders of magnitude. Additionally, \[[29](http://arxiv.org/abs/2010.01264)\] proposes HeteroFL, a framework that allows for heterogeneous clients with different computation and communication capabilities, enabling efficient training of diverse local models \[[29](http://arxiv.org/abs/2010.01264)\]. 

Personalization in FL has also been explored, with methods like FedPer \[[23](http://arxiv.org/abs/1912.00818)\] and pFedMe \[[22](http://arxiv.org/abs/2006.08848)\] introducing personalization layers or regularization techniques to adapt models to individual client data. These approaches aim to improve performance on heterogeneous data by allowing for more tailored model updates \[[22](http://arxiv.org/abs/2006.08848)\]\[[23](http://arxiv.org/abs/1912.00818)\]. 

Furthermore, \[[25](http://arxiv.org/abs/2001.01523)\] introduces a method that jointly learns local and global representations, enabling communication-efficient training while maintaining performance. This approach is particularly useful in scenarios where privacy is a concern, as it minimizes the amount of data that needs to be shared \[[25](http://arxiv.org/abs/2001.01523)\].

In the context of active learning (AL), which aims to reduce annotation costs by selecting the most informative samples \[[1](http://arxiv.org/abs/1812.01097)\], federated active learning (FAL) extends this idea to distributed settings. However, existing FAL methods fail to account for the heterogeneity of data distribution across clients and the associated fluctuations in global and local model parameters, leading to reduced accuracy \[[1](http://arxiv.org/abs/1812.01097)\].
