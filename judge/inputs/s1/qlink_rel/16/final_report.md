## Related Works

Open-vocabulary object detection (OVD) has gained significant attention in recent years due to its ability to detect objects from a vocabulary of categories not explicitly seen during training. This capability is particularly useful in scenarios where the set of target objects is not known in advance, such as in real-world applications where users may specify new or arbitrary object classes \[[1](http://arxiv.org/abs/2011.10678)\]. However, the performance of OVD models can be hampered by overly broad or mis-specified vocabularies, as these can introduce noise or irrelevant categories that degrade detection accuracy \[[1](http://arxiv.org/abs/2011.10678)\]. 

Several approaches have been proposed to address these challenges. Early methods relied on weakly supervised or zero-shot learning techniques, which often struggled with performance and scalability \[[1](http://arxiv.org/abs/2011.10678)\]. More recently, vision-language pre-training models have been leveraged to enable open-vocabulary detection by aligning visual and textual representations \[[1](http://arxiv.org/abs/2011.10678)\]. For example, ViLD \[[2](http://arxiv.org/abs/2104.13921)\] uses vision and language knowledge distillation to train a two-stage detector, achieving state-of-the-art results on benchmarks like LVIS \[[2](http://arxiv.org/abs/2104.13921)\]. Similarly, RegionCLIP \[[18](http://arxiv.org/abs/2112.09106)\] extends CLIP to learn region-level visual representations, enabling fine-grained alignment between image regions and textual concepts, and outperforms existing methods on COCO and LVIS \[[18](http://arxiv.org/abs/2112.09106)\]. 

Another line of work focuses on improving the generalization of detectors to novel categories by using large-scale image-caption pairs to generate pseudo bounding-box annotations \[[8](http://arxiv.org/abs/2111.09452)\]. This approach allows for training on a broader set of object categories without requiring extensive manual annotations \[[8](http://arxiv.org/abs/2111.09452)\]. Additionally, methods like Detic \[[12](http://arxiv.org/abs/2201.02605)\] expand the vocabulary of detectors by training on image-level supervision, enabling detection of up to 21,000 classes \[[12](http://arxiv.org/abs/2201.02605)\]. 

Recent advancements have also focused on improving the efficiency and effectiveness of open-vocabulary detection. For instance, DetPro \[[4](http://arxiv.org/abs/2203.14940)\] introduces a novel method for learning continuous prompt representations, improving performance on novel classes by up to 3.4 APbox and 3.0 APmask \[[4](http://arxiv.org/abs/2203.14940)\]. Similarly, PromptDet \[[9](http://arxiv.org/abs/2203.16513)\] proposes a two-stage open-vocabulary object detector that uses regional prompt learning to align visual and textual features, achieving superior performance with zero manual annotations \[[9](http://arxiv.org/abs/2203.16513)\].

These techniques aim to overcome the limitations of traditional object detection models, which are constrained by the small set of base categories used during training. By utilizing pre-trained vision-language models, these methods can localize and classify objects in unlabeled images, generating pseudo bounding-box labels that are then used to train object detectors \[[10](http://arxiv.org/abs/2207.08954)\]. This approach enables models to generalize to novel object categories without requiring extensive manual annotation \[[8](http://arxiv.org/abs/2111.09452)\]. Additionally, these techniques are effective in both open-vocabulary detection, where models must generalize to unseen categories, and semi-supervised detection, where unlabeled data can be leveraged to improve performance \[[10](http://arxiv.org/abs/2207.08954)\]. The generated pseudo labels have been shown to outperform competitive baselines, achieving state-of-the-art results on benchmarks such as COCO, PASCAL VOC, Objects365, and LVIS \[[8](http://arxiv.org/abs/2111.09452)\]. The use of image captions provides rich semantic information that enhances the accuracy and diversity of the generated annotations, making them a valuable resource for expanding the scope of object detection models \[[10](http://arxiv.org/abs/2207.08954)\].
