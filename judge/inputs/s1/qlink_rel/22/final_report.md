## Related Works

Unsupervised domain adaptation (UDA) for semantic segmentation has attracted significant research interest due to the high cost of obtaining pixel-level annotations in real-world scenarios \[[1](http://arxiv.org/abs/1909.13589)\]. Traditional UDA methods assume that the category settings between the source and target domains are known, which is often not the case in practical applications \[[1](http://arxiv.org/abs/1909.13589)\]. This assumption leads to performance degradation when private classes exist in the target domain, as these classes are not present in the source domain \[[1](http://arxiv.org/abs/1909.13589)\]. To address this limitation, several approaches have been proposed to handle unknown category settings in the target domain.

Early methods focused on aligning the feature distributions between the source and target domains using adversarial learning \[[2](http://arxiv.org/abs/1910.13049)\]. These methods aim to make the model invariant to domain shifts by minimizing the discrepancy between the source and target feature distributions \[[2](http://arxiv.org/abs/1910.13049)\]. However, they often fail to account for the presence of private classes, which are not present in the source domain \[[1](http://arxiv.org/abs/1909.13589)\]. To mitigate this issue, some works have introduced pseudo-labeling strategies to generate labels for the target domain \[[3](http://arxiv.org/abs/2004.07703)\]. These pseudo-labels are then used to train the model, enabling it to adapt to the target domain \[[3](http://arxiv.org/abs/2004.07703)\].

Recent approaches have explored the use of self-training and pseudo-label refinement to improve the adaptation process \[[4](http://arxiv.org/abs/2004.05498)\]. These methods leverage the model's predictions on the target domain to generate pseudo-labels, which are then used to refine the model's performance \[[4](http://arxiv.org/abs/2004.05498)\]. However, these methods often suffer from the problem of noisy pseudo-labels, which can negatively impact the adaptation process \[[4](http://arxiv.org/abs/2004.05498)\]. To address this issue, some works have introduced uncertainty estimation techniques to identify and correct noisy pseudo-labels \[[5](http://arxiv.org/abs/1904.10620)\]. These techniques help improve the quality of the pseudo-labels and, in turn, enhance the model's adaptation performance \[[5](http://arxiv.org/abs/1904.10620)\].

In addition to pseudo-labeling and self-training, some methods have focused on improving the alignment of features between the source and target domains \[[6](http://arxiv.org/abs/2007.08702)\]. These methods aim to ensure that the model learns domain-invariant features that are useful for both domains \[[6](http://arxiv.org/abs/2007.08702)\]. However, they often struggle with the challenge of aligning features across different domains, especially when the target domain contains private classes \[[1](http://arxiv.org/abs/1909.13589)\]. To address this challenge, some works have proposed the use of domain-specific prototypes to better capture the characteristics of the target domain \[[7](http://arxiv.org/abs/1809.09478)\]. These prototypes help distinguish between common and private classes, improving the model's ability to adapt to the target domain \[[7](http://arxiv.org/abs/1809.09478)\].
