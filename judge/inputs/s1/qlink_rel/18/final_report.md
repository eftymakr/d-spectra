## Related Works

Anomaly detection in industrial settings has garnered significant attention due to its critical role in quality control and defect identification. A wide range of methods have been proposed to address the challenges of unsupervised and one-class learning scenarios, where only normal data is available during training \[[3](http://arxiv.org/abs/2011.08785)\]. Early approaches relied on handcrafted features and classical computer vision techniques, but recent advances have leveraged deep learning to improve detection accuracy and localization capabilities \[[7](https://www.semanticscholar.org/paper/3aa681914a7da79f7d7293f51a058eefe61c8bb7)\].

Several methods have focused on improving the efficiency of anomaly detection models to enable deployment on resource-constrained embedded devices. For instance, PatchCore \[[3](http://arxiv.org/abs/2011.08785)\] introduced a memory bank of representative patches to enhance detection performance while maintaining competitive inference times. Similarly, CFLOW-AD \[[4](http://arxiv.org/abs/2107.12571)\] proposed a real-time model based on conditional normalizing flows, achieving a 10× reduction in computational complexity compared to prior state-of-the-art methods. These approaches highlight the importance of balancing performance with computational efficiency.

Another line of research has explored the use of generative models for anomaly detection, such as convolutional autoencoders and generative adversarial networks (GANs) \[[7](https://www.semanticscholar.org/paper/3aa681914a7da79f7d7293f51a058eefe61c8bb7)\]. However, these models often struggle with reconstructing anomalies accurately, leading to reduced detection performance. To address this, methods like RIAD \[[14](https://www.semanticscholar.org/paper/2c89b183df320c3ef698989bdc5d1d4731c4d65d)\] have been introduced, which cast anomaly detection as a self-supervised reconstruction-by-inpainting problem, improving detection capabilities by focusing on partial image reconstruction.

The MVTec AD dataset \[[7](https://www.semanticscholar.org/paper/3aa681914a7da79f7d7293f51a058eefe61c8bb7)\] has become a standard benchmark for evaluating anomaly detection algorithms, offering a comprehensive collection of real-world anomalies such as scratches, dents, and contaminations. It provides pixel-precise ground truth annotations, enabling precise evaluation of both detection and localization performance. Similarly, the MVTec 3D-AD dataset \[[2](http://arxiv.org/abs/2112.09045)\] extends this work to 3D data, addressing the challenges of geometric anomalies in industrial inspection.

Recent advances have also focused on multi-class and multi-modal anomaly detection. For example, UniAD \[[9](http://arxiv.org/abs/2206.03687)\] proposed a unified framework for detecting anomalies across multiple classes, overcoming the limitations of training separate models for each object category. The method incorporates improvements such as layer-wise query decoding and neighbor masked attention to prevent shortcut learning. Additionally, M3DM \[[10](http://arxiv.org/abs/2303.00601)\] introduced a hybrid fusion approach for multimodal anomaly detection, combining 3D point clouds and RGB images to improve detection precision.

Several works have also explored self-supervised learning for anomaly detection, such as CutPaste \[[11](http://arxiv.org/abs/2104.04015)\], which uses data augmentation strategies to learn robust representations without requiring anomalous data.

Model Architecture and Design Innovations in unsupervised anomaly detection have seen significant advancements, with recent works focusing on improving efficiency and performance for real-time applications. For instance, CFLOW-AD introduces a computationally and memory-efficient model that achieves high accuracy while being 10× faster and smaller than prior state-of-the-art methods \[[1](http://arxiv.org/abs/2106.08265)\]. Similarly, UniAD addresses the challenge of detecting anomalies across multiple classes using a unified framework, overcoming issues like the "identical shortcut" problem through layer-wise query decoders and neighbor masked attention modules \[[2](http://arxiv.org/abs/2112.09045)\]. Knowledge distillation has also been leveraged to enhance anomaly detection, with a novel teacher-student (T-S) model that introduces a "reverse distillation" paradigm and a trainable one-class bottleneck embedding (OCBE) module to preserve normal patterns while discarding anomaly perturbations \[[3](http://arxiv.org/abs/2011.08785)\]. Additionally, asymmetric student-teacher networks (AST) have been proposed to improve the distinction between normal and anomalous samples by using different architectures for the teacher and student models, leading to state-of-the-art results on industrial defect detection datasets \[[4](http://arxiv.org/abs/2107.12571)\]. These innovations highlight the ongoing efforts to develop more efficient and effective models for anomaly detection, particularly in resource-constrained environments.

### <a id='category-self-supervised-learning-techniques'></a>Self-Supervised Learning Techniques: 3 papers found.
Visual anomaly detection has seen significant advancements through self-supervised learning techniques, which aim to improve the detection of anomalies without requiring labeled anomalous data. A common approach involves training auto-encoders on normal images and detecting anomalies based on reconstruction errors, though this method often fails to distinguish anomalies effectively due to the neural network's ability to reconstruct anomalous regions \[[2](http://arxiv.org/abs/2112.09045)\]. To address this limitation, researchers have proposed self-supervised reconstruction-by-inpainting methods, such as RIAD, which randomly removes image regions and reconstructs them, thereby improving anomaly detection accuracy \[[2](http://arxiv.org/abs/2112.09045)\]. Additionally, self-supervised learning frameworks like SPot-the-difference (SPD) have been developed to enhance contrastive pre-training methods (e.g., SimSiam, MoCo, SimCLR) for anomaly detection tasks, demonstrating improved performance on datasets like VisA and MVTec-AD \[[3](http://arxiv.org/abs/2011.08785)\]. These techniques focus on learning robust representations from normal data, enabling the detection of both global and local anomalies without explicit annotations \[[3](http://arxiv.org/abs/2011.08785)\]. Furthermore, two-stage frameworks have been introduced, where self-supervised representations are first learned using data augmentation strategies like CutPaste, followed by the construction of generative one-class classifiers \[[1](http://arxiv.org/abs/2106.08265)\]. Such approaches have shown promising results, achieving state-of-the-art performance on benchmark datasets, with improvements in metrics such as AUC \[[1](http://arxiv.org/abs/2106.08265)\]. These developments highlight the growing importance of self-supervised learning in addressing the challenges of anomaly detection in industrial settings, particularly for resource-constrained environments \[[3](http://arxiv.org/abs/2011.08785)\].
