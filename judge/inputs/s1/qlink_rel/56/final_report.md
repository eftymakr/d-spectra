## Related Works

Cross-domain Sequential Recommendation (CDSR) has gained significant attention due to its ability to alleviate data sparsity and cold-start problems by leveraging information across multiple domains \[[1](http://arxiv.org/abs/2304.03891)\]. Early approaches primarily focused on transferring knowledge from a source domain to a target domain using explicit user-item interactions \[[2](http://arxiv.org/abs/2106.02768)\]. However, these methods often assumed fully overlapping users across domains, which is not always the case in real-world scenarios \[[3](http://arxiv.org/abs/1910.05189)\]. This closed-world assumption limits the generalizability of these models \[[4](https://www.semanticscholar.org/paper/f3b7672aaab5b65e1eb66aee6f3a5b95fb0c304f)\].

To address these limitations, several works have proposed more flexible frameworks. For instance, Dual Attentive Sequential Learning (DASL) introduces a dual learning mechanism that iteratively transfers information between two domains, enhancing cross-domain CTR predictions \[[5](http://arxiv.org/abs/2105.03300)\]. Similarly, Deep Dual Transfer Cross Domain Recommendation (DDTCDR) utilizes a latent orthogonal mapping to preserve relations between users across different latent spaces, improving recommendation accuracy \[[6](http://arxiv.org/abs/2103.01696)\]. These methods demonstrate the importance of modeling bidirectional latent relations between users and items \[[7](http://arxiv.org/abs/2012.00485)\].

Another challenge in CDSR is capturing complex transition patterns from mixed behavior sequences. Mixed Information Flow Network (MIFN) addresses this by considering both behavioral and knowledge flow, allowing the model to decide when and how to use cross-domain information \[[8](http://arxiv.org/abs/2311.04590)\]. Similarly, the Adaptive Multi-Interest Debiasing framework (AMID) introduces a multi-interest information module and a doubly robust estimator to handle open-world assumptions, where users may have sparse or non-overlapping interactions \[[9](http://arxiv.org/abs/1804.06769)\]. These approaches highlight the need for adaptive and robust mechanisms to handle real-world data distribution shifts \[[10](http://arxiv.org/abs/2305.19860)\].

Recent advances in representation learning have also contributed to CDSR. For example, DisenCDR disentangles domain-shared and domain-specific information, improving the efficiency of cross-domain knowledge transfer \[[11](https://www.semanticscholar.org/paper/fa36b8d483b06e0bce366970fde747761151f411)\]. Additionally, the π-Net model introduces a parallel information-sharing network to handle shared-account cross-domain sequential recommendations, effectively distinguishing between different user roles and domains \[[12](http://arxiv.org/abs/2209.10163)\]. These methods emphasize the importance of modeling both intra- and inter-domain interactions \[[13](http://arxiv.org/abs/2311.04760)\].

Furthermore, the use of graph-based models has shown promise in capturing sequential patterns. DA-GCN introduces a domain-aware graph convolution network to learn user-specific node representations, while also incorporating attention mechanisms to selectively guide message passing \[[14](http://arxiv.org/abs/1904.06690)\]. ### <a id='category-cross-domain-sequential-recommendation-(cdsr)-overview'></a>Cross-Domain Sequential Recommendation (CDSR) Overview: 5 papers found.
Cross-domain sequential recommendation (CDSR) focuses on predicting user interactions based on historical behavior across multiple domains, addressing challenges such as modeling inter-domain relationships and capturing complex transition patterns \[[1](http://arxiv.org/abs/2304.03891)\]. Existing approaches often rely on single-domain preferences and use transferring modules to infer cross-domain preferences, but these methods are limited by the bottleneck of the transferring module and neglect inter-sequence interactions \[[1](http://arxiv.org/abs/2304.03891)\]. To overcome these limitations, recent works have explored leveraging both intra- and inter-sequence item relationships, such as using graph neural networks to mine collaborative relationships and sequential attentive encoders to capture sequential patterns \[[1](http://arxiv.org/abs/2304.03891)\]. Additionally, some studies have introduced mixed information flow networks that consider both behavioral and knowledge transfer between domains, enabling more accurate cross-domain recommendations \[[7](http://arxiv.org/abs/2012.00485)\]. Another line of research addresses shared-account scenarios where multiple users share a single account, requiring methods to distinguish user behaviors and transfer knowledge across domains \[[3](http://arxiv.org/abs/1910.05189)\]. For instance, the π-Net model introduces a shared account filter unit and a cross-domain transfer unit to handle these challenges effectively \[[3](http://arxiv.org/abs/1910.05189)\]. Similarly, the PSJNet model employs a split-and-join framework to separate role-specific representations and combine them across domains \[[4](https://www.semanticscholar.org/paper/f3b7672aaab5b65e1eb66aee6f3a5b95fb0c304f)\]. These approaches highlight the importance of modeling both domain-specific and cross-domain interactions to improve recommendation performance. Furthermore, some studies have emphasized the need for better data handling, such as correcting information leak issues in existing datasets \[[1](http://arxiv.org/abs/2304.03891)\]. Overall, these works demonstrate the evolving strategies for CDSR, emphasizing the integration of multiple modeling components to enhance recommendation accuracy and adaptability.

[Snippet]: «In order to address the data sparsity problem in recommender systems, in recent years, Cross-Domain Recommendation (CDR) leverages the relatively richer information from a source domain to improve the recommendation performance on a target domain with sparser information. However, each of the two domains may be relatively richer in certain types of information (e.g., ratings, reviews, user profiles, item details, and tags), and thus, if we can leverage such information well, it is possible to improve the recommendation performance on both domains simultaneously (i.e., dual-target CDR), rather than a single target domain only. To this end, in this paper, we propose a new framework, DTCDR, for Dual-Target Cross-Domain Recommendation. In DTCDR, we first extensively utilize rating and multi-source content information to generate rating and document embeddings of users and items. Then, based on Multi-Task Learning (MTL), we design an adaptable embedding-sharing strategy to combine and share the embeddings of common users across domains, with which DTCDR can improve the recommendation performance on both richer and sparser (i.e., dual-target) domains simultaneously. Extensive experiments conducted on real-world datasets demonstrate that DTCDR can significantly improve the recommendation accuracies on both richer and sparser domains and outperform the state-of-the-art single-domain and cross-domain approaches.»
