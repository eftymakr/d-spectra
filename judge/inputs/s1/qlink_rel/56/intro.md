## Related Works

Cross-domain Sequential Recommendation (CDSR) has gained significant attention due to its ability to alleviate data sparsity and cold-start problems by leveraging information across multiple domains \[[1](http://arxiv.org/abs/2304.03891)\]. Early approaches primarily focused on transferring knowledge from a source domain to a target domain using explicit user-item interactions \[[2](http://arxiv.org/abs/2106.02768)\]. However, these methods often assumed fully overlapping users across domains, which is not always the case in real-world scenarios \[[3](http://arxiv.org/abs/1910.05189)\]. This closed-world assumption limits the generalizability of these models \[[4](https://www.semanticscholar.org/paper/f3b7672aaab5b65e1eb66aee6f3a5b95fb0c304f)\].

To address these limitations, several works have proposed more flexible frameworks. For instance, Dual Attentive Sequential Learning (DASL) introduces a dual learning mechanism that iteratively transfers information between two domains, enhancing cross-domain CTR predictions \[[5](http://arxiv.org/abs/2105.03300)\]. Similarly, Deep Dual Transfer Cross Domain Recommendation (DDTCDR) utilizes a latent orthogonal mapping to preserve relations between users across different latent spaces, improving recommendation accuracy \[[6](http://arxiv.org/abs/2103.01696)\]. These methods demonstrate the importance of modeling bidirectional latent relations between users and items \[[7](http://arxiv.org/abs/2012.00485)\].

Another challenge in CDSR is capturing complex transition patterns from mixed behavior sequences. Mixed Information Flow Network (MIFN) addresses this by considering both behavioral and knowledge flow, allowing the model to decide when and how to use cross-domain information \[[8](http://arxiv.org/abs/2311.04590)\]. Similarly, the Adaptive Multi-Interest Debiasing framework (AMID) introduces a multi-interest information module and a doubly robust estimator to handle open-world assumptions, where users may have sparse or non-overlapping interactions \[[9](http://arxiv.org/abs/1804.06769)\]. These approaches highlight the need for adaptive and robust mechanisms to handle real-world data distribution shifts \[[10](http://arxiv.org/abs/2305.19860)\].

Recent advances in representation learning have also contributed to CDSR. For example, DisenCDR disentangles domain-shared and domain-specific information, improving the efficiency of cross-domain knowledge transfer \[[11](https://www.semanticscholar.org/paper/fa36b8d483b06e0bce366970fde747761151f411)\]. Additionally, the π-Net model introduces a parallel information-sharing network to handle shared-account cross-domain sequential recommendations, effectively distinguishing between different user roles and domains \[[12](http://arxiv.org/abs/2209.10163)\]. These methods emphasize the importance of modeling both intra- and inter-domain interactions \[[13](http://arxiv.org/abs/2311.04760)\].

Furthermore, the use of graph-based models has shown promise in capturing sequential patterns. DA-GCN introduces a domain-aware graph convolution network to learn user-specific node representations, while also incorporating attention mechanisms to selectively guide message passing \[[14](http://arxiv.org/abs/1904.06690)\]. These graph-based approaches enable more accurate modeling of complex user-item relationships \[[15](https://www.semanticscholar.org/paper/fa990aee9a8f157b5d393f5f3eaa014e1e5c67aa)\].
