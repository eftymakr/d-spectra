## Related Works

Conversational Recommender Systems (CRSs) have emerged as a promising approach to address the limitations of traditional static recommendation models by enabling dynamic, multi-turn interactions with users to better capture their preferences \[[5](http://arxiv.org/abs/2101.09459)\]. Unlike conventional systems that rely solely on historical data \[[5](http://arxiv.org/abs/2101.09459)\], CRSs leverage natural language interactions to explicitly elicit user preferences, leading to more accurate and personalized recommendations \[[5](http://arxiv.org/abs/2101.09459)\]. However, the integration of conversational elements into recommendation frameworks remains a complex challenge, particularly in terms of effectively modeling user feedback and maintaining a seamless dialogue flow \[[5](http://arxiv.org/abs/2101.09459)\].

Several approaches have been proposed to address these challenges. One notable work is the Estimation-Action-Reflection (EAR) framework, which divides the conversational recommendation process into three stages: Estimation, where predictive models are used to estimate user preferences; Action, where a dialogue policy determines whether to ask for attribute information or make recommendations; and Reflection, where the model is updated based on user feedback \[[1](http://arxiv.org/abs/2002.09102)\]. This framework has been evaluated on datasets from Yelp and LastFM, showing significant improvements over state-of-the-art methods \[[1](http://arxiv.org/abs/2002.09102)\].

Another key contribution is the Conversational Path Reasoning (CPR) framework, which models conversational recommendation as an interactive path reasoning problem on a graph. By following user feedback, CPR explicitly utilizes preferred attributes to prune irrelevant candidates, leading to more accurate recommendations \[[3](http://arxiv.org/abs/2007.00194)\]. The effectiveness of CPR has been validated through empirical studies on multi-round conversational scenarios, demonstrating superior performance compared to existing methods like EAR and CRM \[[3](http://arxiv.org/abs/2007.00194)\].

The use of user simulations for evaluating CRSs has also gained traction. For instance, the work by \[[4](http://arxiv.org/abs/2006.08732)\] introduces a user simulator that generates responses based on both individual preferences and the general flow of interaction, enabling automated evaluation of conversational systems \[[4](http://arxiv.org/abs/2006.08732)\]. Similarly, \[[13](http://arxiv.org/abs/2301.05544)\] presents a user simulation toolkit that supports automatic evaluation of CRSs by simulating dialogues that mimic real conversations, requiring minimal manual annotation \[[13](http://arxiv.org/abs/2301.05544)\].

Moreover, the integration of knowledge graphs into CRSs has been explored to enhance semantic understanding and alignment between user preferences and item attributes \[[9](http://arxiv.org/abs/2007.04032)\]. This approach helps bridge the semantic gap between natural language and item-level preferences, leading to more accurate recommendations \[[9](http://arxiv.org/abs/2007.04032)\].

In addition, the development of deep reinforcement learning frameworks has enabled more sophisticated conversational recommendation strategies. For example, \[[8](http://arxiv.org/abs/2105.09710)\] proposes a unified policy learning approach using graph-based reinforcement learning to address the three key decision-making problems in CRSs: what to ask, when to recommend, and how to adapt to user feedback \[[8](http://arxiv.org/abs/2105.09710)\].

### <a id='category-graph-based-approaches-in-crss'></a>Graph-Based Approaches in CRSs: 2 papers found.
Graph-based approaches in conversational recommendation systems (CRSs) aim to enhance the modeling of user preferences through interactive conversations by leveraging the structure of attribute relationships. These methods address the limitations of traditional recommendation systems, which often fail to capture fine-grained and dynamic user preferences \[[3](http://arxiv.org/abs/2007.00194)\]. By treating conversational recommendation as an interactive path reasoning problem on a graph, recent frameworks such as Conversational Path Reasoning (CPR) enable systems to explicitly utilize user feedback to navigate through attribute vertices, thereby improving the accuracy of preference estimation \[[3](http://arxiv.org/abs/2007.00194)\]. This approach allows for the pruning of irrelevant attributes, increasing the likelihood of identifying user-preferred options \[[3](http://arxiv.org/abs/2007.00194)\]. Additionally, reinforcement learning (RL) has been employed to learn conversational recommendation policies, enabling systems to decide which attributes to ask, which items to recommend, and when to perform these actions \[[8](http://arxiv.org/abs/2105.09710)\]. However, existing methods often tackle these decision-making problems in isolation, limiting the scalability and generality of CRSs \[[8](http://arxiv.org/abs/2105.09710)\]. To overcome these challenges, researchers have proposed unified policy learning frameworks that integrate conversation and recommendation components, using dynamic weighted graphs to model the interaction process \[[8](http://arxiv.org/abs/2105.09710)\]. These advancements highlight the growing interest in graph-based methods for improving the efficiency and effectiveness of CRSs by better capturing user preferences through structured and interactive reasoning.
