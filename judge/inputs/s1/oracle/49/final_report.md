## Related Works

Neural retrieval models have shown significant promise in web search tasks, but their training typically requires large amounts of labeled query-document pairs, which are expensive to obtain \[[10](http://arxiv.org/abs/2411.00722)\]. Recent work has explored the use of synthetic queries generated by large language models (LLMs) as a scalable alternative to labeled data \[[10](http://arxiv.org/abs/2411.00722)\]. However, these synthetic queries often vary in quality, leading to suboptimal retrieval performance \[[10](http://arxiv.org/abs/2411.00722)\]. Existing methods typically filter out noisy query-document pairs using external re-rankers \[[10](http://arxiv.org/abs/2411.00722)\]. In contrast, our approach integrates ranking signals directly into the query generation process using Direct Preference Optimization (DPO), aiming to optimize the model for generating high-quality queries that maximize downstream retrieval effectiveness \[[10](http://arxiv.org/abs/2411.00722)\].

Dense retrieval methods, such as those based on BERT-Siamese models, have been shown to outperform sparse retrieval approaches, especially when combined with effective training mechanisms \[[1](http://arxiv.org/abs/2007.00808)\]. The effectiveness of dense retrieval often depends on the quality of negative training instances, which can be improved using Approximate Nearest Neighbor (ANN) indexing techniques \[[1](http://arxiv.org/abs/2007.00808)\]. Similarly, the use of dense representations for open-domain question answering has demonstrated superior performance compared to traditional sparse methods like BM25 \[[2](http://arxiv.org/abs/2004.04906)\]. These methods rely on dual-encoder frameworks to learn embeddings from questions and passages \[[2](http://arxiv.org/abs/2004.04906)\].

Recent advances in pre-training have also contributed to the development of more effective dense retrievers. For instance, the coCondenser model uses an unsupervised corpus-level contrastive loss to warm up the passage embedding space, reducing the need for heavy data engineering and large batch training \[[3](http://arxiv.org/abs/2108.05540)\]. Similarly, RetroMAE introduces an asymmetric MAE workflow with different masking ratios for encoder and decoder, leading to improved performance on dense retrieval benchmarks \[[4](http://arxiv.org/abs/2205.12035)\]. These models highlight the importance of carefully designed pre-training strategies in achieving robust dense retrieval.

Query generation for retrieval tasks has also received attention, with methods like Promptagator leveraging few-shot learning and large language models to generate task-specific queries \[[8](http://arxiv.org/abs/2209.11755)\]. This approach allows for the creation of retrievers based on a small number of examples, outperforming heavily engineered models trained on large datasets like MS MARCO \[[8](http://arxiv.org/abs/2209.11755)\]. Additionally, methods such as InPars use LLMs to generate synthetic data for information retrieval, demonstrating the potential of few-shot learning in this domain \[[7](http://arxiv.org/abs/2202.05144)\].

In summary, while synthetic query generation offers a scalable alternative to labeled data, integrating ranking signals directly into the query generation process through methods like DPO can significantly improve retrieval performance \[[10](http://arxiv.org/abs/2411.00722)\]. ### <a id='category-dense-retrieval-models-and-techniques'></a>Dense Retrieval Models and Techniques: 5 papers found.
Document 1 discusses the challenges of training dense retrieval models, highlighting that the main bottleneck lies in the training mechanisms, particularly the use of non-representative negative instances. To address this, the paper introduces Approximate Nearest Neighbor Negative Contrastive Estimation (ANCE), which constructs more realistic negative training instances by leveraging an Approximate Nearest Neighbor (ANN) index of the corpus. This approach significantly improves the performance of dense retrieval models, such as BERT-Siamese, by aligning the training and testing data distributions \[[1](http://arxiv.org/abs/2007.00808)\]. 

Document 2 presents a study showing that dense retrieval can be effectively implemented using embeddings learned from a small number of questions and passages via a dual-encoder framework. This method outperforms traditional sparse retrieval models like Lucene-BM25, achieving a notable improvement in top-20 passage retrieval accuracy across various open-domain QA datasets \[[2](http://arxiv.org/abs/2004.04906)\]. 

Document 3 identifies two key issues with dense retrievers: their fragility to training data noise and the need for large batches to learn the embedding space. To overcome these challenges, the paper proposes coCondenser, which utilizes an unsupervised contrastive loss to warm up the passage embedding space. This approach eliminates the need for extensive data engineering and large batch training, achieving performance comparable to state-of-the-art systems like RocketQA \[[3](http://arxiv.org/abs/2108.05540)\]. 

Document 4 introduces RetroMAE, a novel pre-training paradigm for dense retrieval based on the Masked Auto-Encoder (MAE) architecture. RetroMAE incorporates three critical design elements: a novel MAE workflow, an asymmetric model structure with a full-scale BERT-like encoder and a one-layer decoder, and asymmetric masking ratios. These innovations lead to significant improvements in retrieval performance on benchmarks like BEIR and MS MARCO \[[4](http://arxiv.org/abs/2205.12035)\]. 

Document 5 presents Gecko, a compact text embedding model that distills knowledge from large language models (LLMs) to enhance retrieval performance. The two-step distillation process involves generating synthetic paired data and refining it using an LLM to label positive and hard negative passages. Gecko achieves strong performance on the Massive Text Embedding Benchmark (MTEB), outperforming models with larger dimensions and higher parameter counts \[[9](http://arxiv.org/abs/2403.20327)\].
