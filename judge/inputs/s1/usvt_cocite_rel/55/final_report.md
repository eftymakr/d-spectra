## Related Works

Conversational recommendation systems (CRSs) have gained significant attention for their ability to capture user preferences through multi-turn interactions \[[15](http://arxiv.org/abs/2007.00194)\]. These systems enable users to express their preferences dynamically, allowing the system to refine recommendations iteratively \[[15](http://arxiv.org/abs/2007.00194)\]. However, accurately understanding user preferences remains a fundamental challenge due to the multifaceted and complex nature of user needs \[[1](http://arxiv.org/abs/2304.13874)\]. Traditional approaches often rely on static user feedback such as ratings or clicks, which may not fully capture the nuances of user intent \[[11](https://www.semanticscholar.org/paper/78b25ca3f02d1abe1fa5440d02dd5fa82c8dfa3c)\]. In contrast, conversational systems can ask clarifying questions and adapt to user feedback in real-time, leading to more accurate and personalized recommendations \[[15](http://arxiv.org/abs/2007.00194)\].

Several studies have explored the use of user simulation to evaluate and improve conversational systems. For instance, \[[1](http://arxiv.org/abs/2304.13874)\] proposes a user simulator that generates responses based on individual preferences and the general flow of interaction, enabling automated evaluation of conversational recommenders. Similarly, \[[6](http://arxiv.org/abs/2204.08046)\] introduces a conversational user simulator (USi) capable of answering clarifying questions throughout a search session, demonstrating that simulated responses can align with human-generated answers. These simulators are crucial for reducing the reliance on human evaluation, which is time-consuming and resource-intensive \[[3](http://arxiv.org/abs/2006.08732)\].

The integration of reinforcement learning (RL) into conversational recommendation has also been explored. \[[14](http://arxiv.org/abs/2105.09710)\] proposes a unified policy learning framework using graph-based RL to address the challenges of multi-round interactions, where the system must decide when to ask for attributes or recommend items. This approach aims to improve scalability and stability by integrating conversation and recommendation components. Additionally, \[[13](https://www.semanticscholar.org/paper/33e0fe2d4cf01b16da89ab0c180cdcbf37b3be17)\] introduces a preference estimation model (FPAN) that leverages both attribute-level and item-level feedback to refine user preferences, improving the accuracy of recommendations in multi-round settings.

Another key contribution is the development of frameworks that enable systems to ask questions to clarify user needs. \[[4](https://www.semanticscholar.org/paper/3ae5bef6b0c8317603a2deab2527383580904fd8)\] proposes the System Ask -- User Respond (SAUR) paradigm, which allows the system to proactively ask questions to understand user preferences. This approach is particularly effective in e-commerce scenarios, where the system can ask aspect-based questions to refine search results \[[4](https://www.semanticscholar.org/paper/3ae5bef6b0c8317603a2deab2527383580904fd8)\]. ### <a id='category-user-simulation-in-conversational-systems'></a>User Simulation in Conversational Systems: 5 papers found.
User simulation in conversational systems has emerged as a critical area for improving the evaluation and development of task-oriented dialogue systems \[[3](http://arxiv.org/abs/2006.08732)\]. Researchers have focused on creating user simulators that can generate realistic interactions, allowing for automated assessment of conversational search and recommendation systems without the need for extensive human involvement \[[6](http://arxiv.org/abs/2204.08046)\]. These simulators aim to mimic human behavior by incorporating both individual preferences and the natural flow of conversation \[[2](http://arxiv.org/abs/2002.09102)\]. For instance, the ConvSim framework enables multi-turn interactions by simulating user feedback and clarifying questions, which helps in evaluating the performance of passage retrieval and re-ranking models \[[1](http://arxiv.org/abs/2304.13874)\]. Similarly, the USi simulator is designed to automatically answer clarifying questions, demonstrating that generated responses can be aligned with the underlying information need and be comparable to human-generated answers \[[6](http://arxiv.org/abs/2204.08046)\]. Moreover, user satisfaction prediction has been explored as a way to enhance the realism of simulations, with datasets like USS providing annotated dialogues for training and evaluation \[[7](http://arxiv.org/abs/2105.03748)\]. These efforts highlight the importance of user simulation in addressing the challenges of scalability and cost-efficiency in evaluating conversational systems \[[3](http://arxiv.org/abs/2006.08732)\].

Conversational recommendation systems (CRSs) are designed to capture user preferences through multi-turn interactions, enabling personalized recommendations \[[2](http://arxiv.org/abs/2002.09102)\]. These systems face challenges in accurately understanding complex and multifaceted user preferences, even with access to external knowledge \[[2](http://arxiv.org/abs/2002.09102)\]. To address this, researchers have explored simulated users that provide feedback to CRSs, allowing for automatic interaction and refinement of recommendations \[[2](http://arxiv.org/abs/2002.09102)\]. One such approach involves generative reward models, where simulated users generate feedback through coarse-grained and fine-grained actions, such as item scoring and attribute-based critiques \[[2](http://arxiv.org/abs/2002.09102)\]. These feedback mechanisms are often unified into an instruction-based format, enabling the development of a versatile simulated user through instruction tuning on synthesized data \[[2](http://arxiv.org/abs/2002.09102)\]. Additionally, methods inspired by reward-guided search in complex reasoning tasks have been employed to balance effectiveness and efficiency during interactions \[[2](http://arxiv.org/abs/2002.09102)\]. These approaches highlight the evolving strategies in CRSs to enhance user experience while maintaining system efficiency \[[2](http://arxiv.org/abs/2002.09102)\].

[Snippet]: «This paper concerns user preference estimation in multi-round conversational recommender systems (CRS), which interacts with users by asking questions about attributes and recommending items multiple times in one conversation. Multi-round CRS such as EAR have been proposed in which the user's online feedback at both attribute level and item level can be utilized to estimate user preference and make recommendations. Though preliminary success has been shown, existing user preference models in CRS usually use the online feedback information as independent features or training instances, overlooking the relation between attribute-level and item-level feedback signals. The relation can be used to more precisely identify the reasons (e.g., some certain attributes) that trigger the rejection of an item, leading to more fine-grained utilization of the feedback information. To address aforementioned issue, this paper proposes a novel preference estimation model tailored for multi-round CRS, called Feedback-guided Preference Adaptation Network (FPAN). In FPAN, two gating modules are designed to respectively adapt the original user embedding and item-level feedback, both according to the online attribute-level feedback. The gating modules utilize the fine-grained attribute-level feedback to revise the user embedding and coarse-grained item-level feedback, achieving more accurate user preference estimation by considering the relation between feedback. Experimental results on two benchmarks showed that FPAN outperformed the state-of-the-art user preference models in CRS, and the multi-round CRS can also be enhanced by using FPAN as its recommender component.»
