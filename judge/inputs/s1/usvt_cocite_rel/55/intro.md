## Related Works

Conversational recommendation systems (CRSs) have gained significant attention for their ability to capture user preferences through multi-turn interactions \[[15](http://arxiv.org/abs/2007.00194)\]. These systems enable users to express their preferences dynamically, allowing the system to refine recommendations iteratively \[[15](http://arxiv.org/abs/2007.00194)\]. However, accurately understanding user preferences remains a fundamental challenge due to the multifaceted and complex nature of user needs \[[1](http://arxiv.org/abs/2304.13874)\]. Traditional approaches often rely on static user feedback such as ratings or clicks, which may not fully capture the nuances of user intent \[[11](https://www.semanticscholar.org/paper/78b25ca3f02d1abe1fa5440d02dd5fa82c8dfa3c)\]. In contrast, conversational systems can ask clarifying questions and adapt to user feedback in real-time, leading to more accurate and personalized recommendations \[[15](http://arxiv.org/abs/2007.00194)\].

Several studies have explored the use of user simulation to evaluate and improve conversational systems. For instance, \[[1](http://arxiv.org/abs/2304.13874)\] proposes a user simulator that generates responses based on individual preferences and the general flow of interaction, enabling automated evaluation of conversational recommenders. Similarly, \[[6](http://arxiv.org/abs/2204.08046)\] introduces a conversational user simulator (USi) capable of answering clarifying questions throughout a search session, demonstrating that simulated responses can align with human-generated answers. These simulators are crucial for reducing the reliance on human evaluation, which is time-consuming and resource-intensive \[[3](http://arxiv.org/abs/2006.08732)\].

The integration of reinforcement learning (RL) into conversational recommendation has also been explored. \[[14](http://arxiv.org/abs/2105.09710)\] proposes a unified policy learning framework using graph-based RL to address the challenges of multi-round interactions, where the system must decide when to ask for attributes or recommend items. This approach aims to improve scalability and stability by integrating conversation and recommendation components. Additionally, \[[13](https://www.semanticscholar.org/paper/33e0fe2d4cf01b16da89ab0c180cdcbf37b3be17)\] introduces a preference estimation model (FPAN) that leverages both attribute-level and item-level feedback to refine user preferences, improving the accuracy of recommendations in multi-round settings.

Another key contribution is the development of frameworks that enable systems to ask questions to clarify user needs. \[[4](https://www.semanticscholar.org/paper/3ae5bef6b0c8317603a2deab2527383580904fd8)\] proposes the System Ask -- User Respond (SAUR) paradigm, which allows the system to proactively ask questions to understand user preferences. This approach is particularly effective in e-commerce scenarios, where the system can ask aspect-based questions to refine search results \[[4](https://www.semanticscholar.org/paper/3ae5bef6b0c8317603a2deab2527383580904fd8)\]. Similarly, \[[10](http://arxiv.org/abs/1909.02071)\] suggests a conversational paradigm driven by non-relevant items, where negative feedback is used to collect fine-grained aspect-value pairs, improving the accuracy of recommendations \[[10](http://arxiv.org/abs/1909.02071)\].
