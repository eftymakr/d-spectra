## Related Works

The growing adoption of cloud-native applications has led to increased interest in optimizing resource usage and cost efficiency in containerized environments. Prior research has explored system-level optimization strategies for cost and resource efficiency in containerized systems \[[7](http://arxiv.org/abs/2010.10350)\]. However, the analysis of network costs in Kubernetes clusters remains underexplored \[[1](https://www.semanticscholar.org/paper/18a720c86ed6e166c26f7d39490bfd11b93ea3ec)\]. This paper addresses this gap by investigating the network usage and cost implications of containerized applications running on Kubernetes clusters. 

Several studies have examined the performance and resource management schemes for cloud-native platforms using Docker and Kubernetes \[[7](http://arxiv.org/abs/2010.10350)\]. These works highlight the importance of efficient resource allocation and scheduling to reduce overhead and improve performance. For instance, one study found that changing default settings can reduce completion time by up to 79.4% for computational-intensive applications \[[7](http://arxiv.org/abs/2010.10350)\]. Similarly, research on Kubernetes scheduling has focused on improving resource utilization and energy efficiency through QoS parameters \[[2](https://www.semanticscholar.org/paper/d11e5c5c08af88ee8abb9ebaa166b1d6fd198501)\]. These findings underscore the need for a comprehensive analysis of network costs, which is a critical but under-addressed aspect of cloud-native environments.

The use of Kubernetes in scientific workflows has also been explored, with studies demonstrating its ability to enable reproducibility and scalability in bioinformatics and metabolomics \[[10](https://www.semanticscholar.org/paper/d1b8c407ddcf31dba806e580de02cb8c873ea2a6)\]. For example, the PhenoMeNal e-infrastructure leverages Kubernetes to provide a complete, workflow-oriented, and interoperable solution for metabolomics data analysis \[[10](https://www.semanticscholar.org/paper/d1b8c407ddcf31dba806e580de02cb8c873ea2a6)\]. Similarly, Pachyderm has been adapted to support container orchestration in bioinformatics, enabling efficient and sustainable data science workflows \[[5](https://www.semanticscholar.org/paper/51e2cba5a013cbd11f2ab760a4e3906cfff44780)\]. These applications highlight the versatility of Kubernetes in managing complex, data-intensive workflows.

In the context of auto-scaling and resource management, several works have proposed strategies to dynamically adjust application instances based on load \[[14](https://www.semanticscholar.org/paper/4d4080e1a2e26fe1ead433741602ab6eccc22b72)\]. For instance, an auto-scaling system for API gateways based on Kubernetes and Prometheus has been designed to improve resource utilization and ensure high availability \[[14](https://www.semanticscholar.org/paper/4d4080e1a2e26fe1ead433741602ab6eccc22b72)\]. This aligns with the broader goal of optimizing resource usage in cloud-native environments.

Additionally, research on Kubernetes scheduling has identified challenges in resource allocation and energy consumption \[[2](https://www.semanticscholar.org/paper/d11e5c5c08af88ee8abb9ebaa166b1d6fd198501)\]. These studies emphasize the importance of efficient scheduling algorithms to meet QoS requirements while minimizing resource waste. Furthermore, the integration of Kubernetes with cloud platforms such as Google Cloud Platform has been explored to enable rapid application development and management \[[3](https://www.semanticscholar.org/paper/b5634b15badc73f3cda72b960fd51ef03ac1265d)\]. These findings support the need for a detailed analysis of network costs, which can inform more effective resource management strategies.
