## Related Works

Memory bandwidth regulation and cache partitioning have been widely studied as techniques to achieve predictable timing in real-time computing systems \[[1](https://www.semanticscholar.org/paper/1ed3c2a13c728b4d294644db90fb278e62bece22)\]. These approaches are often combined with partitioned scheduling to ensure that tasks are allocated to cores in a way that minimizes resource contention \[[2](https://www.semanticscholar.org/paper/bbebaeb1b00fdcde2aeb192543835d3ec1518f8d)\]. However, task execution times are highly sensitive to the availability of allocated resources, necessitating careful co-allocation of tasks and resources \[[3](https://www.semanticscholar.org/paper/e02eb1430cb7aa53f20818d2b642abe10d58a459)\]. This challenge has motivated the development of optimization algorithms that address task-resource co-allocation \[[4](https://www.semanticscholar.org/paper/50d359dc737cb5c296b527f4eb1541dc55f3ed86)\].

Several works have explored the use of hardware-based memory bandwidth regulation to improve predictability. The Bandwidth Regulation Unit (BRU) is a hardware module that enables fine-grained per-core memory bandwidth regulation, improving time-predictability of real-time tasks while allowing best-effort tasks to better utilize memory system bandwidth \[[5](https://www.semanticscholar.org/paper/25ebad66dc10d7b01c22684cbb200ddeb6502475)\]. Similarly, MemGuard is a memory bandwidth reservation system designed to provide performance isolation in multi-core platforms \[[6](https://www.semanticscholar.org/paper/0b1bc294dbd926f853a8ee41d1d8f8ecc3cfde13)\]. These hardware-based solutions aim to mitigate memory contention by enforcing strict bandwidth limits on memory access \[[7](http://arxiv.org/abs/1809.05921)\].

Software-based approaches have also been proposed to achieve memory isolation. One such approach is the use of cache coloring and invalidation-driven allocation (IDA) to protect cache blocks from eviction by concurrently executing tasks \[[8](https://www.semanticscholar.org/paper/dbd4eb5033815003e7f6519fd66e43e5fc297075)\]. This technique is implemented within a hypervisor to enable deterministic memory access \[[9](https://www.semanticscholar.org/paper/f71c848137ac1398f84e6ab7d896641f801ca192)\]. Additionally, the use of programmable logic in-the-middle (PLIM) has been proposed to manipulate individual memory transactions, enabling techniques like cache bleaching to improve memory predictability \[[10](https://www.semanticscholar.org/paper/6e925ae85e385ac0e8810441d84be97c079f6b22)\].

The importance of memory bandwidth management in real-time systems has also been highlighted in the context of dynamic memory regulation. A study on dynamic memory bandwidth regulation shows that response time computation can be reduced to a maximization problem over assignment of memory requests to different time intervals \[[11](https://www.semanticscholar.org/paper/d5336fd2234f431f554fc5d878503a04a27e366e)\]. This analysis has been applied to improve the schedulability of Integrated Modular Avionics systems in the presence of memory-intensive workloads \[[12](https://www.semanticscholar.org/paper/afca4afaaaa543a1da02b266e9b2ac46eb94793b)\].

Another relevant work is the E-WarP framework, which provides a system-wide approach for memory bandwidth profiling and management. E-WarP uses a profile-driven methodology to analyze memory demand and predict temporal behavior, enabling saturation-aware system consolidation \[[13](https://www.semanticscholar.org/paper/6201fb6d59a909959edfb661f52470c04799b0e7)\]. This work demonstrates the potential of workload-aware memory management in real-time systems \[[14](https://www.semanticscholar.org/paper/43cc4d0a998b9aa361264e5fc786c738a62382f1)\].
