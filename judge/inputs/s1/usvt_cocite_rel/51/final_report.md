## Related Works

Federated unlearning has emerged as a critical research area in the context of privacy-preserving machine learning, particularly in response to the "right to be forgotten" (RTBF) legislation \[[1](http://arxiv.org/abs/2203.07320)\]. This concept allows users to request the removal of their data from a trained model, a necessity in distributed learning frameworks like Federated Learning (FL) \[[2](http://arxiv.org/abs/2310.20448)\]. Early works focused on centralized unlearning, where full access to training data is available for the server to perform unlearning \[[3](https://www.semanticscholar.org/paper/eadeffdec9fac8fd7f9aea732ca410eb082b7dcf)\]. However, FL introduces unique challenges, as data remains local to clients, and the server cannot access all training data \[[4](http://arxiv.org/abs/2207.05521)\]. This necessitates the development of novel unlearning strategies tailored to FL's distributed nature \[[5](http://arxiv.org/abs/2205.12709)\].

Several approaches have been proposed to address federated unlearning. One notable method is FedEraser, which leverages historical parameter updates stored at the server to reconstruct an unlearned model without retraining from scratch \[[6](https://www.semanticscholar.org/paper/06edb1f6eadb6c141d720fcca4c854578dc5d670)\]. This approach significantly reduces the time required for unlearning while maintaining model utility \[[7](https://www.semanticscholar.org/paper/39da2d48f2132b919405e3bb6df6ece44ac6e15a)\]. Similarly, the paper \[[8](http://arxiv.org/abs/2210.10958)\] introduces a method that first performs local unlearning at the client and then uses the locally unlearned model as initialization for a few rounds of federated learning, achieving performance comparable to retraining from scratch \[[9](https://www.semanticscholar.org/paper/a52c3ec7325e81bd87fdf8d74bf9acfd1e1ffe5f)\].

Another line of research focuses on verifiable federated unlearning, ensuring that the unlearning effect can be independently verified \[[10](http://arxiv.org/abs/2209.02299)\]. The VeriFi framework introduces mechanisms for marking and checking the unlearning effect, allowing clients to verify that their data has been effectively removed from the global model \[[11](http://arxiv.org/abs/2401.11018)\]. This is crucial for ensuring compliance with privacy regulations and maintaining user trust \[[12](http://arxiv.org/abs/2401.05146)\].

Efforts have also been made to improve the efficiency and accuracy of federated unlearning. For instance, the paper \[[13](https://www.semanticscholar.org/paper/efab3b30d6f67f55c68f9dc7c65b2b54b1789030)\] proposes a method that uses momentum degradation to erase implicit knowledge from the model, ensuring smooth transitions to the retrained model's state \[[14](https://www.semanticscholar.org/paper/eff2be3b3ccfb1fc0650432b9b611ebd11ba0feb)\]. Additionally, the Exact-Fun approach introduces a quantized federated learning algorithm to enable exact and efficient unlearning, achieving high performance with minimal degradation \[[15](https://www.semanticscholar.org/paper/a5f39bcd6198b26997b77233ff81a14e6bc8a32d)\].

In the context of recommendation systems, federated unlearning has been explored to address the "right to be forgotten" while maintaining model performance \[[16](http://arxiv.org/abs/2201.09441)\]. The FRU method, inspired by transaction rollback mechanisms, enables efficient unlearning by rolling back and calibrating historical parameter updates \[[17](http://arxiv.org/abs/2302.12448)\]. This approach is particularly relevant in scenarios where clients may withdraw their data or contribute malicious updates \[[18](https://www.semanticscholar.org/paper/2f69d7e9a7428a7e31de83b993a2142d0c2cde67)\].

### <a id='category-unlearning-in-federated-learning-frameworks'></a>Unlearning in Federated Learning Frameworks: 26 papers found.
The category "Unlearning in Federated Learning Frameworks" explores the challenges and solutions related to enabling data deletion from federated learning (FL) models, driven by the "right to be forgotten" and privacy regulations. Existing unlearning methods in centralized machine learning are not directly applicable to FL due to its distributed nature and lack of global data access \[[1](http://arxiv.org/abs/2203.07320)\]. To address this, researchers have proposed various approaches such as FedEraser \[[3](https://www.semanticscholar.org/paper/eadeffdec9fac8fd7f9aea732ca410eb082b7dcf)\], which leverages historical parameter updates to reconstruct unlearned models efficiently, and FAST \[[16](http://arxiv.org/abs/2201.09441)\], which eliminates malicious clients' contributions by subtracting their updates from the global model. Additionally, methods like FATS \[[9](https://www.semanticscholar.org/paper/a52c3ec7325e81bd87fdf8d74bf9acfd1e1ffe5f)\] and SFU \[[15](https://www.semanticscholar.org/paper/a5f39bcd6198b26997b77233ff81a14e6bc8a32d)\] focus on achieving exact unlearning by ensuring the unlearned model is statistically indistinguishable from the one trained without the deleted data, while minimizing performance degradation. Other works, such as FRU \[[7](https://www.semanticscholar.org/paper/39da2d48f2132b919405e3bb6df6ece44ac6e15a)\] and Starfish \[[25](http://arxiv.org/abs/2003.10933)\], emphasize privacy-preserving techniques using secure computation and differential privacy to prevent information leakage during unlearning. These approaches highlight the need for efficient, accurate, and privacy-compliant unlearning strategies in FL, often involving local unlearning, parameter updates, and communication-efficient algorithms \[[4](http://arxiv.org/abs/2207.05521)\]\[[6](https://www.semanticscholar.org/paper/06edb1f6eadb6c141d720fcca4c854578dc5d670)\]\[[10](http://arxiv.org/abs/2209.02299)\].
