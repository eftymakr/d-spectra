## Related Works

Deploying large language models (LLMs) on edge devices presents significant challenges due to the limited storage, power, and computational capabilities of such hardware \[[1](http://arxiv.org/abs/2309.06180)\]. Several recent works have addressed these challenges by focusing on model compression, efficient inference, and hardware-software co-design. For instance, AWQ introduces an activation-aware weight quantization method that reduces model size while preserving performance, enabling efficient on-device deployment \[[2](http://arxiv.org/abs/2306.00978)\]. Similarly, SmoothQuant provides a post-training quantization solution that enables 8-bit weight and activation quantization, achieving up to 2x memory reduction and 1.56x speedup \[[3](http://arxiv.org/abs/2312.15234)\]. These methods are crucial for reducing the computational and memory footprint of LLMs, making them more suitable for edge deployment.

Efficient memory management is another critical aspect of deploying LLMs, particularly for serving large models at scale. PagedAttention, inspired by virtual memory techniques, enables near-zero waste in KV cache memory and allows flexible sharing of memory across requests, improving throughput \[[4](http://arxiv.org/abs/2211.10438)\]. Additionally, FlashAttention and FlashAttention-2 address the quadratic memory and runtime complexity of attention mechanisms by introducing IO-aware tiling and better work partitioning, achieving significant speedups and memory savings \[[5](http://arxiv.org/abs/2312.11514)\]\[[6](http://arxiv.org/abs/2307.09288)\]. These techniques are essential for optimizing the performance of LLMs on resource-constrained devices.

Hardware acceleration has also been explored to improve the efficiency of LLM inference. FTRANS proposes an efficient acceleration framework for transformer-based models using FPGAs, achieving up to 81× improvement in energy efficiency compared to GPUs \[[7](http://arxiv.org/abs/2307.08691)\]. Similarly, DFX presents a multi-FPGA appliance that accelerates text generation with low latency and high throughput, demonstrating superior performance over GPU-based solutions \[[8](http://arxiv.org/abs/2309.17453)\]. These hardware designs are important for enabling efficient inference of large models on edge devices with limited resources.

Moreover, quantization and sparsity techniques have been widely studied to reduce the computational and memory requirements of LLMs. LLM.int8() enables 8-bit matrix multiplication for transformers, reducing memory usage by half while maintaining full precision performance \[[9](http://arxiv.org/abs/2310.17157)\]. DejaVu introduces contextual sparsity, allowing for efficient inference by exploiting input-dependent sparsity patterns without compromising model quality \[[10](https://www.semanticscholar.org/paper/5af69480a7ae3b571df6782a11ec4437b386a7d9)\]. These methods are vital for deploying LLMs on edge devices with limited hardware capabilities.

In addition, efficient attention mechanisms are crucial for reducing the computational overhead of LLMs. SpAtten introduces an efficient sparse attention architecture with cascade token and head pruning, achieving significant reductions in DRAM access and energy consumption \[[11](http://arxiv.org/abs/2208.07339)\]. ### <a id='category-memory-management-optimization'></a>Memory Management Optimization: 2 papers found.
Memory management optimization is a critical area in the deployment of large language models (LLMs), particularly on resource-constrained devices. Existing approaches often struggle with the dynamic memory requirements of key-value (KV) caches, leading to significant memory fragmentation and waste, which limits the batch size and overall throughput \[[1](http://arxiv.org/abs/2309.06180)\]. To address these challenges, researchers have proposed innovative techniques inspired by virtual memory and paging systems, such as PagedAttention, which enables near-zero memory waste and flexible KV cache sharing \[[1](http://arxiv.org/abs/2309.06180)\]. Additionally, methods like "windowing" and "row-column bundling" have been introduced to optimize data transfer and chunk size from flash memory, allowing models up to twice the size of available DRAM to be executed with substantial improvements in inference speed \[[2](http://arxiv.org/abs/2306.00978)\]. These strategies highlight the importance of hardware-aware design and efficient memory utilization in enhancing the performance and scalability of LLMs on edge devices.

### <a id='category-quantization-and-sparsity-methods'></a>Quantization and Sparsity Methods: 8 papers found.
Quantization and sparsity methods have emerged as critical techniques for enabling efficient deployment of large language models (LLMs) on edge devices, addressing the challenges of memory constraints, computational costs, and energy consumption \[[1](http://arxiv.org/abs/2309.06180)\]. These methods aim to reduce model size and inference latency while preserving performance, often through post-training quantization (PTQ) or sparsity-inducing pruning strategies \[[2](http://arxiv.org/abs/2306.00978)\]. For instance, SmoothQuant enables 8-bit weight and activation quantization without accuracy loss, achieving up to 1.56x speedup and 2x memory reduction \[[4](http://arxiv.org/abs/2211.10438)\]. Similarly, LLM.int8() reduces inference memory by half by leveraging systematic emergent features in transformers, allowing even 175B parameter models to run on consumer GPUs \[[11](http://arxiv.org/abs/2208.07339)\]. Sparsity-based approaches like DejaVu exploit contextual sparsity to accelerate inference by selectively activating only necessary attention heads and MLP parameters, achieving over 2X latency reduction on OPT-175B \[[9](http://arxiv.org/abs/2310.17157)\]. Wanda introduces a novel pruning method that eliminates weights based on their magnitude multiplied by input activations, achieving competitive performance without retraining \[[7](http://arxiv.org/abs/2307.08691)\]. These methods collectively highlight the growing focus on algorithm-hardware co-design to optimize LLM inference, balancing accuracy, speed, and resource efficiency \[[1](http://arxiv.org/abs/2309.06180)\].

### <a id='category-efficient-inference-methods'></a>Efficient Inference Methods: 3 papers found.
Efficient inference methods for large language models (LLMs) have gained significant attention due to the computational and memory challenges they pose, particularly in latency-sensitive and resource-constrained environments \[[3](http://arxiv.org/abs/2312.15234)\]. Researchers have explored various strategies to address these challenges, including algorithmic modifications and system-level optimizations \[[3](http://arxiv.org/abs/2312.15234)\]. One notable approach is speculative decoding, which enables faster inference by generating multiple tokens in parallel without altering the output distribution, thereby improving throughput while maintaining accuracy \[[13](http://arxiv.org/abs/2211.17192)\]. Additionally, there is a growing focus on optimizing Transformer architectures, which underpin many modern LLMs, by analyzing bottlenecks and exploring hardware-level adaptations to reduce compute and bandwidth demands \[[3](http://arxiv.org/abs/2312.15234)\]. These efforts include both architectural changes and the development of specialized accelerators, with some studies demonstrating substantial speedups through full-stack co-design approaches \[[3](http://arxiv.org/abs/2312.15234)\]. Such methods are crucial for deploying LLMs on edge devices, where power and storage constraints are severe, and real-time performance is essential \[[3](http://arxiv.org/abs/2312.15234)\].

### <a id='category-attention-mechanism-optimization'></a>Attention Mechanism Optimization: 3 papers found.
Attention mechanism optimization has been a critical area of research to address the computational and memory bottlenecks in transformer models, particularly when scaling to longer sequences. Existing approaches such as FlashAttention \[[7](http://arxiv.org/abs/2307.08691)\] and block-sparse attention \[[3](http://arxiv.org/abs/2312.15234)\] have made significant strides by introducing IO-aware algorithms that reduce memory reads/writes between GPU memory levels, leading to improved efficiency. FlashAttention, for instance, achieves linear memory usage and runtime speedups of 2–4× compared to optimized baselines, though it still lags behind matrix-multiply operations in terms of FLOPs/s utilization \[[7](http://arxiv.org/abs/2307.08691)\]. To further enhance performance, FlashAttention-2 was proposed, incorporating better work partitioning strategies that increase occupancy and reduce communication overhead, achieving up to 73% of the theoretical maximum FLOPs/s on A100 GPUs \[[7](http://arxiv.org/abs/2307.08691)\]. Meanwhile, StreamingLLM \[[8](http://arxiv.org/abs/2309.17453)\] tackles the challenge of deploying large language models in streaming applications by addressing attention sink and enabling models to generalize to infinite sequence lengths without fine-tuning. This is achieved by caching only recent KV states and introducing placeholder tokens during pre-training to act as dedicated attention sinks. These advancements collectively highlight the importance of optimizing attention mechanisms to improve both the scalability and efficiency of transformer models in real-world applications.

### <a id='category-hardware-software-co-design'></a>Hardware-Software Co-Design: 1 papers found.
The self-attention mechanism, a cornerstone of modern neural network models like the Google Transformer and its variants, has become a critical component in natural language processing, computer vision, and recommender systems due to its ability to capture complex relationships within input data \[[1](http://arxiv.org/abs/2309.06180)\]. However, this mechanism is computationally intensive, with its cost scaling quadratically with the number of input entities, leading to significant runtime and energy consumption challenges during inference \[[1](http://arxiv.org/abs/2309.06180)\]. This has prompted research into efficient approximations of self-attention, such as ELSA (Efficient, Lightweight Self-Attention), which introduces a hardware-software co-designed solution to reduce computational overhead while maintaining model accuracy \[[1](http://arxiv.org/abs/2309.06180)\]. By filtering out less impactful relationships, ELSA achieves substantial improvements in speed and energy efficiency, with a geometric mean speedup of 58.1× and over three orders of magnitude in energy savings compared to GPU-based implementations, while keeping accuracy loss below 1% \[[1](http://arxiv.org/abs/2309.06180)\]. Such advancements are crucial for deploying large models on resource-constrained edge devices, where balancing latency, energy, and accuracy is essential \[[2](http://arxiv.org/abs/2306.00978)\].

### <a id='category-hardware-acceleration-solutions'></a>Hardware Acceleration Solutions: 4 papers found.
Hardware acceleration solutions for large language models (LLMs) have been extensively explored to address the computational and energy efficiency challenges associated with deploying these models on edge devices and in datacenters. Researchers have proposed various approaches, including FPGA-based accelerators, which leverage their high parallelism and low latency to efficiently execute transformer models \[[16](http://arxiv.org/abs/2007.08563)\]. For instance, DFX, a multi-FPGA acceleration appliance, achieves significant speedup and energy efficiency improvements over GPU-based solutions by utilizing model parallelism and optimized dataflow \[[1](http://arxiv.org/abs/2309.06180)\]. Similarly, Ftrans introduces an efficient framework for accelerating transformer-based models by reducing model size through algorithm-level optimizations, achieving up to 16 times compression with minimal accuracy loss \[[16](http://arxiv.org/abs/2007.08563)\]. Additionally, A3 focuses on accelerating attention mechanisms, which are critical for transformer models, by employing algorithmic approximations and hardware specialization, resulting in substantial improvements in energy efficiency and performance \[[23](http://arxiv.org/abs/2002.10941)\]. These solutions highlight the growing interest in custom hardware accelerators tailored for LLMs, emphasizing the need for hardware-software co-design to balance latency, energy consumption, and model accuracy \[[17](http://arxiv.org/abs/2401.09890)\].
