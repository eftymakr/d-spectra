## Related Works

Open-vocabulary object detection has emerged as a critical research direction, enabling detectors to recognize objects based on user-specified class vocabularies in natural language \[[1](http://arxiv.org/abs/2011.10678)\]. This capability is particularly valuable for applications requiring flexible and dynamic object recognition, such as content-based image retrieval and interactive vision systems \[[2](http://arxiv.org/abs/2104.13921)\]. However, the performance of such detectors can be significantly impacted by the quality and relevance of the user-defined vocabulary \[[3](http://arxiv.org/abs/2103.00020)\]. Prior work has explored various approaches to address this challenge, including weakly supervised learning, zero-shot learning, and vision-language pre-training \[[4](http://arxiv.org/abs/2205.06230)\].

Weakly supervised object detection methods aim to reduce the reliance on expensive bounding box annotations by using image-level labels or captions \[[5](http://arxiv.org/abs/2203.14940)\]. For instance, Cap2Det leverages unstructured textual descriptions to train detectors without requiring precise bounding box supervision \[[6](http://arxiv.org/abs/2207.03482)\]. Similarly, the **Learning Transferable Visual Models From Natural Language Supervision** paper demonstrates that pre-training on image-caption pairs can yield state-of-the-art performance across a wide range of vision tasks \[[7](http://arxiv.org/abs/2203.11876)\]. This approach enables zero-shot transfer to unseen categories, as the model learns to associate visual features with textual descriptions \[[8](http://arxiv.org/abs/2207.08954)\].

Zero-shot detection methods, such as those proposed in **Open-Vocabulary Object Detection Using Captions**, aim to detect novel object categories without any prior training on those classes \[[9](http://arxiv.org/abs/2201.02605)\]. These methods often rely on pre-trained vision-language models to bridge the gap between visual and textual representations \[[10](http://arxiv.org/abs/2104.12763)\]. However, they typically suffer from lower accuracy compared to fully supervised models \[[11](http://arxiv.org/abs/2004.06165)\]. To improve performance, **Open-vocabulary Object Detection via Vision and Language Knowledge Distillation** introduces ViLD, which distills knowledge from a pretrained classification model into a two-stage detector, achieving competitive results on benchmark datasets like LVIS \[[12](http://arxiv.org/abs/1908.03195)\].

Recent advances in vision-language pre-training have further enhanced open-vocabulary detection capabilities. **Learning Object-Language Alignments for Open-Vocabulary Object Detection** proposes a framework that directly learns from image-text pairs, aligning object regions with textual descriptions without requiring explicit grounding annotations \[[13](http://arxiv.org/abs/2111.09452)\]. This approach enables the model to generalize to novel classes, achieving strong performance on COCO and LVIS benchmarks \[[14](http://arxiv.org/abs/1405.0312)\].

### <a id='category-vision-language-pre-training-approaches'></a>Vision-language pre-training approaches: 8 papers found.
Vision-language pre-training approaches have been increasingly explored for improving open-vocabulary object detection, where models must generalize to unseen object categories \[[3](http://arxiv.org/abs/2103.00020)\]. These methods typically leverage large-scale image-text pairs to learn cross-modal representations, enabling zero-shot or few-shot transfer to downstream tasks \[[5](http://arxiv.org/abs/2203.14940)\]. For instance, CLIP demonstrates that pre-training on 400 million (image, text) pairs allows models to match the accuracy of ResNet-50 on ImageNet zero-shot without explicit training on the dataset \[[3](http://arxiv.org/abs/2103.00020)\]. Similarly, RegionCLIP extends CLIP to learn region-level visual representations, enabling fine-grained alignment between image regions and textual concepts, which significantly improves open-vocabulary object detection performance \[[7](http://arxiv.org/abs/2203.11876)\]. Other approaches, such as Oscar, use object tags detected in images as anchor points to align image regions with text, achieving state-of-the-art results on vision-language tasks \[[6](http://arxiv.org/abs/2207.03482)\]. Additionally, methods like MDETR introduce end-to-end modulated detectors that condition object detection on raw text queries, enhancing the model's ability to handle long-tailed visual concepts \[[5](http://arxiv.org/abs/2203.14940)\]. These pre-training strategies highlight the importance of aligning image regions with textual descriptions to improve detection accuracy, especially when dealing with open-vocabulary settings.
