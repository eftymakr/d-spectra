## Related Works

Recent advancements in information retrieval have focused on improving the accuracy and efficiency of document and table retrieval systems. Traditional approaches rely on sparse vector space models such as BM25 or TF-IDF, which are effective for exact lexical matching but limited in semantic understanding \[[19](http://arxiv.org/abs/2104.07186)\]. In contrast, deep learning-based methods have emerged as a promising alternative, leveraging dense vector representations to capture semantic similarity between queries and documents \[[14](http://arxiv.org/abs/2004.04906)\]. These methods typically follow a representation-index-search pipeline, where queries and documents are encoded into dense vectors, and similarity is computed using approximate nearest neighbor search \[[14](http://arxiv.org/abs/2004.04906)\]. However, this approach suffers from error accumulation during the representation and indexing phases, which can negatively impact search accuracy \[[1](http://arxiv.org/abs/2206.10128)\]. Additionally, insufficient interaction between queries and documents hinders effective semantic alignment, limiting performance improvements \[[1](http://arxiv.org/abs/2206.10128)\].

To address these limitations, differentiable search index (DSI) has been proposed as a new paradigm that unifies indexing and retrieval into a single model \[[4](http://arxiv.org/abs/2202.06991)\]. DSI encodes all documents into the model parameters, allowing queries to be directly mapped to relevant document identifiers without an explicit index \[[4](http://arxiv.org/abs/2202.06991)\]. This approach eliminates error accumulation and enables more direct query-document interactions. However, DSI models face challenges in handling dynamic corpora, as retraining is required when new documents are added \[[10](http://arxiv.org/abs/2212.09744)\]. To mitigate this, DSI++ was introduced, which supports continual learning by incrementally updating the model while preserving previously learned information \[[10](http://arxiv.org/abs/2212.09744)\].

Another line of research has focused on improving the effectiveness of retrieval by incorporating query generation and semantic alignment. For instance, DSI-QG generates relevant queries during indexing, which helps bridge the data distribution mismatch between indexing and retrieval \[[1](http://arxiv.org/abs/2206.10128)\]. Similarly, the Neural Corpus Indexer (NCI) uses a sequence-to-sequence network to generate document identifiers directly for a given query, improving recall performance \[[3](http://arxiv.org/abs/2206.02743)\]. Additionally, the TILDE model ranks documents based on both query and document likelihood, allowing for flexible trade-offs between efficiency and effectiveness \[[8](https://www.semanticscholar.org/paper/1a887834a7045d58e7655227dd95f7dd57f5ff4a)\]. These methods highlight the importance of semantic alignment and query-document interaction in improving retrieval accuracy.

In the context of table retrieval, the work by \[[18](http://arxiv.org/abs/1802.06159)\] introduced semantic similarity-based methods for matching queries with tables, using both sparse and dense representations to improve retrieval performance. More recently, COIL was proposed to combine the efficiency of exact lexical matching with the semantic power of deep language models by storing contextualized token representations in inverted lists \[[19](http://arxiv.org/abs/2104.07186)\]. This approach maintains the computational efficiency of traditional systems while improving semantic understanding.
