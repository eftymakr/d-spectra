## Related Works

Personalized outfit generation has gained significant attention in recent years due to its potential to enhance user experience in fashion recommendation systems. Prior works have primarily focused on two aspects: outfit compatibility and personalization. Early approaches relied on rule-based systems or simple similarity metrics to recommend compatible fashion items \[[1](http://arxiv.org/abs/1905.01866)\]. However, these methods lacked the ability to capture complex style relationships and user preferences effectively.

Recent advances in deep learning have enabled more sophisticated models for outfit generation and recommendation. For instance, \[[2](http://arxiv.org/abs/1608.03016)\] proposed a machine learning system to automatically compose fashion outfits by scoring candidates based on appearance and metadata, achieving an AUC of 85% for the scoring component. Similarly, \[[3](http://arxiv.org/abs/1807.03133)\] introduced a bidirectional LSTM and autoencoder framework to extract style information from outfits, allowing for more flexible and interpretable style-based generation. This approach outperformed baseline methods in style extraction and outfit generation tasks.

The importance of compatibility between fashion items has also been emphasized in several studies. \[[4](http://arxiv.org/abs/1712.02662)\] introduced a method to learn compatibility relationships using a bidirectional LSTM model, where each item in an outfit is treated as a time step, and the model predicts the next item based on previous ones. This approach enables the prediction of outfit compatibility and has been evaluated on the Polyvore dataset, showing strong performance compared to alternative methods. \[[5](http://arxiv.org/abs/1803.09196)\] further extended this idea by proposing a compatibility family learning framework that embeds items into a latent space and projects queries into compatible prototypes, achieving state-of-the-art results on multiple datasets.

Personalization in outfit recommendation has also been a key focus. \[[6](http://arxiv.org/abs/1711.02231)\] introduced a model that learns type-aware embeddings for fashion compatibility, capturing both item similarity and compatibility across different types. This model was evaluated on a large dataset of 68,306 outfits, achieving improvements over existing methods. \[[7](http://arxiv.org/abs/1904.00741)\] proposed a system that uses visual and textual features to learn embeddings in a latent style space, enabling the recommendation of compatible items of different types. This approach was validated on the ASOS dataset, showing strong performance in outfit compatibility prediction.

Several studies have also explored the use of generative models for outfit generation. \[[8](http://arxiv.org/abs/1707.05691)\] introduced a framework that uses a transformer architecture to generate personalized outfits by connecting user preferences with the model. This method was deployed on a platform named Dida in Alibaba, demonstrating its effectiveness in generating personalized outfits. \[[9](http://arxiv.org/abs/1712.01262)\] further extended this idea by proposing a model that uses text and image embeddings to represent fashion items, allowing for the generation of outfits that match a specified theme. ### <a id='category-compatibility-relationship-learning'></a>Compatibility Relationship Learning: 10 papers found.
The category of Compatibility Relationship Learning focuses on modeling the relationships between fashion items to improve outfit compatibility and recommendation systems. This involves learning compatibility metrics from large-scale datasets, often using deep learning techniques such as neural networks and attention mechanisms. For instance, researchers have developed methods to embed items into a latent space where compatibility can be measured through distance functions \[[3](http://arxiv.org/abs/1807.03133)\]. These approaches often consider the visual and semantic attributes of items, as well as their interactions within an outfit \[[8](http://arxiv.org/abs/1707.05691)\]. Some studies have proposed end-to-end trainable systems that learn compatibility relationships by jointly modeling visual-semantic embeddings and compatibility scores \[[9](http://arxiv.org/abs/1712.01262)\]. Additionally, graph-based methods have been introduced to represent outfits as graphs, where nodes correspond to categories and edges capture interactions between items \[[18](http://arxiv.org/abs/1902.08009)\]. These models use graph neural networks to better capture complex interactions and improve compatibility prediction \[[18](http://arxiv.org/abs/1902.08009)\]. Furthermore, some works have focused on learning compatibility from "in the wild" images, translating visual compatibility metrics to cleaner catalog photos and improving over existing methods \[[1](http://arxiv.org/abs/1905.01866)\]. The use of attention mechanisms and self-attention in transformer-based models has also been explored to capture the relationships between items in an outfit \[[16](http://arxiv.org/abs/1912.08967)\]. Overall, the field emphasizes the development of scalable and effective methods for learning compatibility relationships, which are essential for personalized fashion recommendation and outfit generation \[[10](http://arxiv.org/abs/1509.07473)\].
