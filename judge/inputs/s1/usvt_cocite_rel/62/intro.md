## Related Works

Generative retrieval has emerged as a promising paradigm in information retrieval, shifting from traditional index-based methods to end-to-end neural network models that directly generate document identifiers \[[1](http://arxiv.org/abs/2204.10628)\]. This approach leverages large language models to perform both indexing and retrieval in a unified framework, offering potential improvements in efficiency and integration with generative models \[[1](http://arxiv.org/abs/2204.10628)\]. Prior work has explored various aspects of this paradigm, including the design of retrieval models, the optimization of decoding strategies, and the generalization of models to unseen data.

Several studies have investigated the use of autoregressive models for document retrieval. For instance, SEAL \[[1](http://arxiv.org/abs/2204.10628)\] proposes using ngrams as document identifiers, allowing autoregressive models to generate and score distinctive ngrams, which are then mapped to full passages. This method outperforms prior autoregressive approaches and establishes new state-of-the-art results on the KILT benchmark \[[1](http://arxiv.org/abs/2204.10628)\]. Similarly, CorpusBrain \[[2](http://arxiv.org/abs/2208.07652)\] introduces a pre-trained generative retrieval model that replaces traditional index-retrieve pipelines with a single-step generative model, achieving significant improvements in retrieval performance \[[2](http://arxiv.org/abs/2208.07652)\]. The model is trained on a set of pre-defined tasks and can be fine-tuned for various downstream tasks \[[2](http://arxiv.org/abs/2208.07652)\].

Another line of research focuses on the challenges of generating document identifiers in a constrained manner. For example, GENRE \[[3](http://arxiv.org/abs/2010.00904)\] introduces an autoregressive system for entity retrieval, generating entity names token-by-token while conditioning on the context. This approach mitigates issues related to dense vector representations and memory footprint, enabling efficient and accurate entity retrieval \[[3](http://arxiv.org/abs/2010.00904)\]. Similarly, the Differentiable Search Index (DSI) \[[9](http://arxiv.org/abs/2202.06991)\] represents documents as sequences of document ID tokens, allowing a single transformer model to perform both indexing and retrieval. This paradigm simplifies the retrieval process and enables end-to-end optimization \[[9](http://arxiv.org/abs/2202.06991)\].

The effectiveness of beam search in generative retrieval has also been a topic of investigation. For example, DSI-QG \[[6](http://arxiv.org/abs/2206.10128)\] addresses the issue of data distribution mismatch between indexing and retrieval by generating relevant queries during indexing. These queries help align the document identifiers with the query distribution, improving retrieval performance in both mono-lingual and cross-lingual settings \[[6](http://arxiv.org/abs/2206.10128)\]. Additionally, PAG \[[7](http://arxiv.org/abs/2404.14600)\] introduces a novel decoding approach that guides autoregressive generation through simultaneous decoding, achieving significant improvements in MRR and query latency \[[7](http://arxiv.org/abs/2404.14600)\].
