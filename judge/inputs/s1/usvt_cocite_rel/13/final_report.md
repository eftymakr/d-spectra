## Related Works

Long-tailed recognition remains a challenging problem in computer vision due to the skewed class distribution in real-world datasets, where a few classes dominate the data while most classes have very few samples \[[1](http://arxiv.org/abs/2207.09052)\]. This imbalance leads to biased models that perform poorly on tail classes \[[2](http://arxiv.org/abs/1910.09217)\]. Several approaches have been proposed to address this issue, including class-balancing strategies, loss re-weighting, and data re-sampling \[[3](http://arxiv.org/abs/2107.12028)\]. However, these methods often suffer from overfitting to tail classes or fail to capture meaningful representations \[[4](http://arxiv.org/abs/2111.13998)\].

Recent work has focused on contrastive learning as a promising approach to improve representation learning for long-tailed data \[[5](http://arxiv.org/abs/1904.05160)\]. Supervised contrastive learning (SCL) has shown significant performance gains by pulling positive samples together and pushing negative samples apart in the embedding space \[[6](http://arxiv.org/abs/2002.05709)\]. However, SCL suffers from gradient conflicts and imbalanced attraction and repulsion gradients between positive and negative pairs, which hinder its effectiveness in long-tailed scenarios \[[7](http://arxiv.org/abs/2103.14267)\]. This issue is exacerbated as the number of views increases, leading to inconsistent generalization \[[8](http://arxiv.org/abs/2010.01809)\].

To address these limitations, several methods have been proposed. For instance, Balanced Contrastive Learning (BCL) introduces class-averaging and class-complement strategies to balance the gradient contributions of negative classes and ensure uniform class distribution \[[9](http://arxiv.org/abs/2103.16370)\]. Similarly, Parametric Contrastive Learning (PaCo) introduces class-wise learnable centers to rebalance the optimization process and improve hard example learning \[[10](http://arxiv.org/abs/2104.00466)\]. Targeted Supervised Contrastive Learning (TSC) further improves feature uniformity by generating uniformly distributed targets on a hypersphere and aligning features to these targets \[[11](http://arxiv.org/abs/1912.02413)\].

Decoupling representation and classifier learning has also been explored as a way to improve long-tailed recognition \[[12](http://arxiv.org/abs/2101.10633)\]. For example, Decoupling Representation and Classifier for Long-Tailed Recognition (DRCLR) shows that high-quality representations can be learned with simple instance-balanced sampling, and strong recognition performance can be achieved by adjusting only the classifier \[[13](http://arxiv.org/abs/2007.07314)\]. This approach has led to new state-of-the-art results on benchmarks such as ImageNet-LT and iNaturalist \[[14](http://arxiv.org/abs/2007.10740)\].

In addition to contrastive learning, other methods have been proposed to improve long-tailed recognition. For example, BBN introduces a bilateral-branch network that simultaneously learns representations and classifiers, with a cumulative learning strategy to gradually focus on tail data \[[15](http://arxiv.org/abs/2203.14197)\]. ResLT proposes a residual learning framework that preserves specific capacity for low-frequency classes and improves performance through residual fusion \[[16](http://arxiv.org/abs/2003.05176)\]. ### <a id='category-long-tailed-recognition-challenges'></a>Long-Tailed Recognition Challenges: 13 papers found.
The long-tailed recognition problem, where a few classes dominate the dataset while most are underrepresented, has been extensively studied, with various approaches addressing class imbalance through re-weighting, re-sampling, or transfer learning \[[1](http://arxiv.org/abs/2207.09052)\]. Recent work has emphasized the importance of decoupling representation learning from classifier training to improve performance \[[2](http://arxiv.org/abs/1910.09217)\]. For instance, some studies suggest that data imbalance may not hinder high-quality representation learning, and that a simple instance-balanced sampling can lead to strong long-tailed recognition when combined with an appropriately designed classifier \[[1](http://arxiv.org/abs/2207.09052)\]. Others have focused on reducing classifier variance and bias by introducing multiple experts or dynamic routing mechanisms to handle both head and tail classes \[[3](http://arxiv.org/abs/2107.12028)\]. Additionally, methods like dynamic meta-embedding have been proposed to enhance open-set recognition by mapping images to a feature space that respects closed-world assumptions while acknowledging novel classes \[[4](http://arxiv.org/abs/2111.13998)\]. Theoretical insights into gradient conflicts and imbalanced attraction/repulsion gradients in contrastive learning have also been explored to improve generalization \[[5](http://arxiv.org/abs/1904.05160)\]. These approaches highlight the ongoing efforts to balance performance across class distributions while maintaining model robustness and adaptability to real-world scenarios.

### <a id='category-supervised-contrastive-learning-(scl)'></a>Supervised Contrastive Learning (SCL): 3 papers found.
The category "Supervised Contrastive Learning (SCL)" encompasses research that explores the use of contrastive learning frameworks in supervised settings, aiming to improve representation learning by leveraging label information. This body of work builds upon earlier contrastive learning methods, such as SimCLR, which demonstrated the effectiveness of data augmentation and large batch sizes in self-supervised learning \[[6](http://arxiv.org/abs/2002.05709)\]. SCL extends these ideas by incorporating label information into the contrastive loss, enabling more effective clustering of embeddings for the same class while pushing apart embeddings from different classes \[[19](http://arxiv.org/abs/2004.11362)\]. This approach has been shown to outperform traditional cross-entropy loss, particularly when combined with techniques like large batch sizes and normalized embeddings, leading to improved accuracy and robustness \[[19](http://arxiv.org/abs/2004.11362)\]. Additionally, methods like Momentum Contrast (MoCo) have further advanced the field by introducing dynamic dictionaries and moving-averaged encoders, which enhance the consistency and quality of learned representations in both supervised and unsupervised settings \[[21](http://arxiv.org/abs/1911.05722)\]. These contributions highlight the potential of SCL to bridge the gap between self-supervised and supervised learning, offering new insights into how contrastive learning can be adapted for labeled data.
