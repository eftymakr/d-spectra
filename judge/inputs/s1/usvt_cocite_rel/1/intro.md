## Related Works

KV cache mechanisms are essential for improving the efficiency of large language model (LLM) inference by reducing redundant computations \[[1](http://arxiv.org/abs/2402.02750)\]. Prior work has focused on optimizing memory usage and computational efficiency through various techniques such as quantization, sparsity, and compression \[[2](http://arxiv.org/abs/2305.17118)\]. For instance, KIVI introduces a tuning-free 2bit quantization method that reduces the memory footprint of the KV cache by up to 2.6×, enabling larger batch sizes and improved throughput \[[1](http://arxiv.org/abs/2402.02750)\]. Similarly, MiniCache compresses the KV cache across layers by exploiting the high similarity between adjacent layers, achieving up to 5.02× compression ratios and reducing memory usage by 41% \[[5](http://arxiv.org/abs/2405.14366)\]. These methods highlight the importance of understanding the distribution and structure of KV cache elements to develop effective compression strategies \[[1](http://arxiv.org/abs/2402.02750)\]\[[5](http://arxiv.org/abs/2405.14366)\].

The persistence of importance hypothesis has also been explored to reduce the memory usage of the KV cache during inference. Scissorhands leverages this hypothesis to prioritize the storage of pivotal tokens, reducing memory usage by up to 5× without compromising model quality \[[2](http://arxiv.org/abs/2305.17118)\]. Furthermore, Scissorhands can be combined with 4-bit quantization to achieve up to 20× compression, demonstrating the potential of hybrid approaches \[[2](http://arxiv.org/abs/2305.17118)\]. This aligns with the findings of H2O, which identifies "Heavy Hitters" as tokens that significantly contribute to attention scores, leading to a 29× improvement in throughput when these tokens are prioritized \[[6](http://arxiv.org/abs/2306.14048)\].

Attention sink phenomena have also been studied, where retaining the KV states of initial tokens helps recover performance lost by window attention \[[3](http://arxiv.org/abs/2309.17453)\]. StreamingLLM addresses this by enabling LLMs to generalize to infinite sequence lengths without fine-tuning, demonstrating up to 22.2× speedup in streaming settings \[[3](http://arxiv.org/abs/2309.17453)\]. This highlights the importance of managing KV cache states effectively to maintain performance while reducing memory overhead \[[3](http://arxiv.org/abs/2309.17453)\].

In addition, PagedAttention, inspired by virtual memory techniques, manages the dynamic nature of KV cache memory more efficiently, reducing fragmentation and enabling flexible sharing across requests \[[4](http://arxiv.org/abs/2309.06180)\]. This approach improves throughput by 2–4× compared to state-of-the-art systems \[[4](http://arxiv.org/abs/2309.06180)\]. These methods collectively emphasize the need for adaptive and workload-aware strategies to optimize KV cache usage in LLM serving \[[1](http://arxiv.org/abs/2402.02750)\]\[[2](http://arxiv.org/abs/2305.17118)\]\[[3](http://arxiv.org/abs/2309.17453)\]\[[4](http://arxiv.org/abs/2309.06180)\]\[[5](http://arxiv.org/abs/2405.14366)\].
