## Related Works

Representation learning has become a cornerstone in modern recommender systems, enabling efficient and effective user-item matching \[[1](http://arxiv.org/abs/1706.02216)\]. Early approaches relied on matrix factorization to learn latent representations of users and items \[[17](http://arxiv.org/abs/1602.01585)\]. However, these methods struggled with scalability and capturing complex interactions between users and items. To address these limitations, recent work has explored deep learning techniques, such as Neural Collaborative Filtering (NCF), which uses neural networks to model user-item interactions more flexibly \[[6](http://arxiv.org/abs/1708.05031)\]. NCF replaces the inner product used in traditional matrix factorization with a neural architecture, allowing for non-linear modeling of interactions \[[6](http://arxiv.org/abs/1708.05031)\].

Graph-based methods have also gained traction in recommendation systems. Graph Convolutional Neural Networks (GCNs) leverage the structure of user-item graphs to generate embeddings that encode both local graph structure and node features \[[2](http://arxiv.org/abs/1609.02907)\]. These models have been successfully applied to large-scale recommendation tasks, such as those at Pinterest, where they outperform traditional methods \[[3](http://arxiv.org/abs/1806.01973)\]. Similarly, GraphSAGE extends this idea by generating embeddings for unseen nodes through sampling and aggregating features from a node's neighborhood \[[1](http://arxiv.org/abs/1706.02216)\]. This inductive approach enables the generalization of embeddings to new data, which is crucial for evolving recommendation systems.

In addition to graph-based models, collaborative filtering has been enhanced by incorporating auxiliary information. Collaborative Deep Learning (CDL) integrates content information with collaborative filtering by jointly learning deep representations for both \[[7](http://arxiv.org/abs/1409.2944)\]. This approach addresses the sparsity problem in traditional collaborative filtering and improves recommendation accuracy. Similarly, Neural Graph Collaborative Filtering (NGCF) explicitly models user-item interactions by propagating embeddings on the bipartite graph structure \[[5](http://arxiv.org/abs/1905.08108)\]. This method captures high-order connectivity in the user-item graph, effectively injecting collaborative signals into the embedding process.

Recent work has also focused on incorporating knowledge graphs (KGs) into recommendation systems to improve accuracy and explainability. Knowledge Graph Attention Network (KGAT) explicitly models high-order relations in KGs by recursively propagating embeddings and using attention mechanisms to weigh the importance of neighbors \[[9](http://arxiv.org/abs/1905.07854)\]. This approach outperforms existing KG-based methods by better capturing complex interactions between items and their attributes.

Furthermore, Bayesian Personalized Ranking (BPR) has been proposed to optimize recommendation models for personalized ranking tasks \[[10](http://arxiv.org/abs/1205.2618)\]. BPR is derived from a Bayesian analysis of the problem and provides a learning algorithm based on stochastic gradient descent with bootstrap sampling. This method has been shown to outperform standard learning techniques for matrix factorization and adaptive kNN.

Graph Convolutional Neural Networks (GCNs) have emerged as a powerful tool for learning representations on graph-structured data, enabling effective node and graph-level predictions. These models extend traditional convolutional neural networks (CNNs) to irregular domains such as social networks, brain connectomes, and recommendation systems by leveraging spectral graph theory to design localized convolutional filters \[[4](http://arxiv.org/abs/1802.05814)\]. GCNs operate by aggregating features from a node's neighborhood, allowing them to capture both local structure and node-specific attributes \[[2](http://arxiv.org/abs/1609.02907)\]. This capability has been crucial in improving performance on tasks like node classification, where models must generalize to unseen nodes, as seen in the development of inductive frameworks like GraphSAGE \[[1](http://arxiv.org/abs/1706.02216)\]. Furthermore, GCNs have been adapted for large-scale applications, such as web-scale recommendation systems, where they combine efficient random walks with graph convolutions to generate embeddings that incorporate both structural and feature information \[[3](http://arxiv.org/abs/1806.01973)\]. These advancements have enabled GCNs to outperform traditional methods on benchmark datasets, demonstrating their scalability and effectiveness in real-world scenarios \[[2](http://arxiv.org/abs/1609.02907)\]\[[3](http://arxiv.org/abs/1806.01973)\].

### <a id='category-graph-based-recommendation-systems'></a>Graph-Based Recommendation Systems: 3 papers found.

### <a id='category-collaborative-deep-learning-approaches'></a>Collaborative Deep Learning Approaches: 3 papers found.
Collaborative deep learning approaches aim to integrate collaborative filtering with deep learning techniques to enhance recommendation systems by leveraging both user-item interactions and auxiliary information. Traditional collaborative filtering methods suffer from sparsity issues, as they rely solely on user ratings, which are often sparse in real-world scenarios \[[1](http://arxiv.org/abs/1706.02216)\]. To address this, methods like Collaborative Topic Regression (CTR) have been introduced, which combine content-based information with collaborative filtering by jointly learning latent representations from multiple sources \[[7](http://arxiv.org/abs/1409.2944)\]. However, the effectiveness of these models can be limited when auxiliary information is sparse, prompting the development of more sophisticated models such as Collaborative Deep Learning (CDL), which extends deep learning to non-i.i.d. inputs and jointly learns representations from content and ratings \[[7](http://arxiv.org/abs/1409.2944)\]. Similarly, DeepWalk has been proposed to learn latent representations of network nodes by treating random walks as sentences, enabling the encoding of social relations in a continuous vector space \[[14](http://arxiv.org/abs/1403.6652)\]. This approach has shown superior performance in network classification tasks, especially when labeled data is sparse \[[14](http://arxiv.org/abs/1403.6652)\]. In the context of fashion recommendation, models have been developed to capture both the visual characteristics of products and evolving user preferences, combining deep convolutional neural networks with collaborative filtering to handle the complexity of dynamic and sparse data \[[17](http://arxiv.org/abs/1602.01585)\]. These approaches collectively highlight the importance of integrating deep learning with collaborative filtering to improve recommendation accuracy and adaptability to sparse and evolving data environments.
