## Related Works

Natural language (NL)-driven table discovery has gained significant attention in recent years due to the increasing availability of tabular data and the need for efficient retrieval mechanisms. Traditional approaches rely on dense vector search pipelines, which involve representation, indexing, and search stages \[[1](http://arxiv.org/abs/2305.02073)\]. However, these methods face limitations, including error accumulation during representation and indexing, and insufficient query-table interaction that hinders semantic alignment \[[1](http://arxiv.org/abs/2305.02073)\]. 

Several works have explored the use of neural networks for table discovery. Neural Enquirer \[[6](http://arxiv.org/abs/1512.00965)\] proposes a neural network architecture to execute natural language queries on knowledge-base tables, enabling the retrieval of answers by leveraging distributed representations and differentiable operations. This work focuses on query execution rather than retrieval, but it highlights the importance of semantic alignment between queries and tables. 

The nlcTables dataset \[[2](http://arxiv.org/abs/2504.15849)\] was introduced to address the challenge of NL-conditional table discovery, where users combine a query table with natural language requirements to refine search results. This dataset includes diverse queries and annotations, providing a benchmark for evaluating table discovery methods. However, existing methods still struggle with semantic alignment and query-table interaction \[[2](http://arxiv.org/abs/2504.15849)\].

Differentiable Search Index (DSI) \[[13](http://arxiv.org/abs/2202.06991)\] represents a novel paradigm for information retrieval, using a single transformer model to perform both indexing and retrieval. This approach eliminates the need for separate indexing and retrieval components, but early versions of DSI faced issues with data distribution mismatch between indexing and retrieval phases \[[3](http://arxiv.org/abs/2206.10128)\]. Subsequent works, such as DSI-QG \[[3](http://arxiv.org/abs/2206.10128)\], proposed indexing strategies that generate synthetic queries to improve alignment between queries and tables. This approach enhances semantic interactions during indexing, which is crucial for accurate retrieval.

The concept of using query generation to improve retrieval has also been explored in cross-lingual dense retrieval \[[11](http://arxiv.org/abs/2305.03950)\]. By generating queries in different languages, models can better align with target languages, improving retrieval effectiveness without requiring additional training data. This technique aligns with the approach used in Birdie, where synthetic queries are generated for each table to enhance query-table interactions.

In addition to query generation, the use of semantic representations has been extensively studied. Semantic table retrieval \[[10](http://arxiv.org/abs/2105.06365)\] investigates the use of multiple semantic spaces and similarity measures to match queries and tables. This work demonstrates the importance of semantic alignment in improving retrieval accuracy, a key challenge in NL-driven table discovery.

### <a id='category-differentiable-search-index-frameworks'></a>Differentiable Search Index Frameworks: 5 papers found.
Differentiable Search Index (DSI) frameworks have emerged as a novel approach in information retrieval, aiming to simplify the retrieval process by integrating indexing and search into a single differentiable model \[[5](http://arxiv.org/abs/2502.02788)\]. These frameworks leverage neural architectures, such as transformers, to directly map queries to document identifiers, bypassing traditional retrieval pipelines \[[5](http://arxiv.org/abs/2502.02788)\]. However, early implementations of DSI faced challenges in distinguishing relevant documents from random ones, which impacted retrieval effectiveness \[[1](http://arxiv.org/abs/2305.02073)\]. To address this, researchers proposed multi-task distillation approaches to enhance retrieval quality without altering the model structure \[[1](http://arxiv.org/abs/2305.02073)\]. Additionally, the integration of large language models (LLMs) into DSI frameworks, such as De-DSI, has enabled decentralized and scalable information retrieval by utilizing query-docid pairs and ensemble models for improved accuracy and efficiency \[[4](http://arxiv.org/abs/2404.12237)\]. Furthermore, studies have explored balancing relevance and diversity in DSI training, inspired by Maximal Marginal Relevance (MMR), to achieve both high relevance and diverse results without post-processing \[[3](http://arxiv.org/abs/2206.10128)\]. These advancements highlight the evolving landscape of DSI, focusing on improving retrieval effectiveness, scalability, and the integration of advanced language models \[[1](http://arxiv.org/abs/2305.02073)\]\[[3](http://arxiv.org/abs/2206.10128)\]\[[4](http://arxiv.org/abs/2404.12237)\]\[[5](http://arxiv.org/abs/2502.02788)\].

[Snippet]: «The Differentiable Search Index (DSI) is an emerging paradigm for information retrieval. Unlike traditional retrieval architectures where index and retrieval are two different and separate components, DSI uses a single transformer model to perform both indexing and retrieval. In this paper, we identify and tackle an important issue of current DSI models: the data distribution mismatch that occurs between the DSI indexing and retrieval processes. Specifically, we argue that, at indexing, current DSI methods learn to build connections between the text of long documents and the identifier of the documents, but then retrieval of document identifiers is based on queries that are commonly much shorter than the indexed documents. This problem is further exacerbated when using DSI for cross-lingual retrieval, where document text and query text are in different languages. To address this fundamental problem of current DSI models, we propose a simple yet effective indexing framework for DSI, called DSI-QG. When indexing, DSI-QG represents documents with a number of potentially relevant queries generated by a query generation model and re-ranked and filtered by a cross-encoder ranker. The presence of these queries at indexing allows the DSI models to connect a document identifier to a set of queries, hence mitigating data distribution mismatches present between the indexing and the retrieval phases. Empirical results on popular mono-lingual and cross-lingual passage retrieval datasets show that DSI-QG significantly outperforms the original DSI model.»

The category "Query-Table Semantic Alignment" explores the challenges and advancements in connecting natural language queries with structured table data. This includes efforts to improve semantic understanding between unstructured text and semi-structured tables, such as content-based table retrieval, where the goal is to find the most relevant table from a collection based on a query \[[3](http://arxiv.org/abs/2206.10128)\].
