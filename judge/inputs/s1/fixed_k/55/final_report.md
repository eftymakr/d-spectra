## Related Works

Conversational Recommender Systems (CRSs) have gained significant attention for their ability to engage users in multi-turn dialogues to elicit preferences and provide personalized recommendations \[[1](http://arxiv.org/abs/2401.05783)\]. However, effectively capturing user preferences remains a fundamental challenge due to the multifaceted and complex nature of user intent \[[1](http://arxiv.org/abs/2401.05783)\]. Traditional approaches often rely on handcrafted reward functions, which may not align with user intent, limiting the adaptability of reinforcement learning-based CRS solutions \[[3](http://arxiv.org/abs/2310.20109)\]. To address this, recent research has explored intrinsic reward learning from user interactions, formulating it as a multi-objective bi-level optimization problem to maximize success rate while minimizing the number of turns needed for successful recommendations \[[3](http://arxiv.org/abs/2310.20109)\].

User simulators have been widely used to evaluate CRSs by generating realistic user feedback in simulated interactions \[[5](http://arxiv.org/abs/2006.08732)\]. Early work focused on single-target evaluations, which may underestimate the effectiveness of CRSs by not considering alternative items or the exploratory nature of recommendation systems \[[1](http://arxiv.org/abs/2401.05783)\]. More recent approaches have introduced user simulators that allow simulated users to express preferences over alternative items, change their minds, and exhibit varying levels of patience, leading to more accurate evaluations \[[1](http://arxiv.org/abs/2401.05783)\]. These simulators are often initialized with information needs and generate feedback based on the system's responses, enabling multi-turn interactions \[[2](http://arxiv.org/abs/2304.13874)\].

The use of Large Language Models (LLMs) has further advanced the development of user simulators, enabling more realistic and controllable simulations \[[6](http://arxiv.org/abs/2405.08035)\]. However, existing LLM-based simulators face limitations such as data leakage, difficulty in controlling outputs through prompts, and overreliance on conversational history \[[9](http://arxiv.org/abs/2403.16416)\]. To mitigate these issues, researchers have proposed frameworks that incorporate controllable and scalable simulation strategies, such as the CSHI framework, which manages user simulator behavior through a plugin manager \[[6](http://arxiv.org/abs/2405.08035)\]. These frameworks aim to generate feedback that closely mirrors real users, facilitating reliable evaluation of CRSs \[[6](http://arxiv.org/abs/2405.08035)\].

In addition to user simulators, methods for preference elicitation have been explored, such as generating usage-related questions to implicitly uncover user preferences \[[10](http://arxiv.org/abs/2111.13463)\]. These approaches leverage natural language to ask questions about item usage, which can be more effective than direct item-based queries, especially for users unfamiliar with the domain \[[10](http://arxiv.org/abs/2111.13463)\]. Furthermore, the integration of multi-aspect user modeling has been proposed to capture a broader range of user preferences, including historical dialogues and look-alike users, leading to more accurate recommendations \[[7](http://arxiv.org/abs/2204.09263)\].

### <a id='category-user-simulator-evaluation-methods'></a>User Simulator Evaluation Methods: 5 papers found.
User simulators play a crucial role in evaluating conversational recommendation systems (CRSs), as they enable automated interaction and feedback mechanisms that mimic real user behavior \[[1](http://arxiv.org/abs/2401.05783)\]. These simulators are designed to provide feedback on recommended items, either through natural language or clarifying questions, and can be enhanced to consider alternative items and adjust user patience levels \[[1](http://arxiv.org/abs/2401.05783)\]. This flexibility allows for more accurate evaluation of CRS models, as it addresses the limitations of single-target evaluations that often underestimate system effectiveness \[[1](http://arxiv.org/abs/2401.05783)\]. Research has also focused on developing user simulators that can generate realistic feedback based on user preferences and interaction flow, improving the alignment between automated evaluations and human judgments \[[3](http://arxiv.org/abs/2310.20109)\]. Additionally, reinforcement learning frameworks have been proposed to simulate user behavior by learning reward functions and environment dynamics, leading to more effective recommendation policies \[[8](http://arxiv.org/abs/1812.10613)\]. These approaches highlight the importance of incorporating diverse feedback mechanisms and adaptive user behavior in user simulators to better assess CRS performance.

### <a id='category-llm-based-user-simulators-and-limitations'></a>LLM-Based User Simulators and Limitations: 2 papers found.
The development of user simulators for Conversational Recommender Systems (CRSs) has gained significant attention, particularly with the advent of Large Language Models (LLMs) that offer capabilities approaching human-level intelligence \[[6](http://arxiv.org/abs/2405.08035)\]. These simulators aim to replicate realistic user behavior to evaluate and improve CRS performance \[[9](http://arxiv.org/abs/2403.16416)\]. However, existing approaches face several limitations, such as data leakage in conversational history and simulated replies, which can inflate evaluation results \[[9](http://arxiv.org/abs/2403.16416)\]. Additionally, controlling the output of user simulators through single prompt templates remains challenging \[[9](http://arxiv.org/abs/2403.16416)\]. To address these issues, researchers have proposed frameworks like the Controllable, Scalable, and Human-Involved (CSHI) simulator, which employs a plugin manager to manage user behavior across different stages \[[6](http://arxiv.org/abs/2405.08035)\]. This framework enhances the authenticity of user-system interactions by tailoring behavioral simulations and interaction patterns \[[6](http://arxiv.org/abs/2405.08035)\]. Another effort, SimpleUserSim, introduces a straightforward strategy to guide the conversation toward target items, improving the reliability of evaluation methods \[[9](http://arxiv.org/abs/2403.16416)\]. These advancements highlight the ongoing efforts to create more realistic and effective user simulators for CRSs, which are crucial for improving personalized recommendations and user experience \[[6](http://arxiv.org/abs/2405.08035)\]\[[9](http://arxiv.org/abs/2403.16416)\].
