## Related Works

Table detection and discovery have garnered significant attention in recent years due to the increasing availability of tabular data in various domains. Early approaches to table detection relied on classical computer vision techniques, which often struggled with complex layouts and diverse structures \[[1](http://arxiv.org/abs/2209.09207)\]. These methods typically focused on identifying table boundaries and cell structures but lacked the ability to generalize across different document formats and table designs. The introduction of deep learning models, particularly convolutional neural networks, has significantly improved the accuracy and robustness of table detection \[[1](http://arxiv.org/abs/2209.09207)\]. These models can effectively capture spatial relationships and handle variations in table structures, leading to better performance on benchmark datasets \[[1](http://arxiv.org/abs/2209.09207)\].

In parallel, the development of large-scale table detection datasets has been crucial for advancing research in this area. One such dataset, the STDW dataset, contains over 7,000 diverse table samples collected from various sources, enabling researchers to train and evaluate models on a more representative set of data \[[1](http://arxiv.org/abs/2209.09207)\]. This dataset has been instrumental in demonstrating the superiority of deep learning methods over traditional computer vision approaches \[[1](http://arxiv.org/abs/2209.09207)\]. However, the focus of these datasets has primarily been on detecting table structures within documents rather than addressing the broader challenge of discovering relevant tables based on natural language queries.

Recent work has also explored the use of large language models (LLMs) in table question-answering tasks, highlighting the limitations of existing models in handling complex queries and aligning natural language with programmatic commands \[[2](http://arxiv.org/abs/2406.10803)\]. The "HiddenTables" cooperative game and the associated "PyQTax" dataset have been introduced to address these challenges by providing a secure and scalable framework for evaluating LLMs on a large set of table-related tasks \[[2](http://arxiv.org/abs/2406.10803)\]. This dataset includes over 116,671 question-table-answer triplets, offering a rich resource for studying the capabilities and limitations of LLMs in TableQA scenarios \[[2](http://arxiv.org/abs/2406.10803)\].

Additionally, the development of datasets for linked business tables has been an emerging area of research. The SALT dataset, derived from an Enterprise Resource Planning (ERP) system, provides a comprehensive set of linked tables for studying table representation learning in enterprise settings \[[4](http://arxiv.org/abs/2501.03413)\]. This dataset is particularly valuable for understanding how models can be adapted to handle structured data with complex relationships \[[4](http://arxiv.org/abs/2501.03413)\].
