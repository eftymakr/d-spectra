## Related Works

Zero-Knowledge Proofs (ZKPs) have emerged as a critical tool in privacy-preserving and verifiable computing, enabling a prover to demonstrate the validity of a statement without revealing additional information \[[12](http://arxiv.org/abs/2401.03118)\]. Recent advancements have focused on accelerating the computational bottlenecks in ZKP generation, particularly for key primitives such as Number Theoretic Transform (NTT) and Multi-scalar Multiplication (MSM) \[[1](http://arxiv.org/abs/2408.05890)\]. Prior works have explored GPU and ASIC implementations, but these often face limitations such as requiring trusted setups or producing larger proof sizes with higher verification costs \[[1](http://arxiv.org/abs/2408.05890)\]. 

The need for efficient and scalable ZKP acceleration has led to the development of specialized hardware and software solutions. For instance, SZKP presents an ASIC-based accelerator that achieves significant speedups over CPU, ASIC, and GPU implementations by leveraging structured dataflows for NTT and MSM operations \[[1](http://arxiv.org/abs/2408.05890)\]. Similarly, if-ZKP introduces an FPGA-based architecture optimized for the MSM operation in zk-SNARKs, achieving 110x–150x speedups over software for elliptic curves like BLS12-381 and BN128 \[[2](http://arxiv.org/abs/2412.12481)\]. These approaches highlight the importance of parallelism and modular arithmetic optimization in improving ZKP performance.

In addition to hardware acceleration, there has been growing interest in ZKP applications across various domains. For example, zkFi proposes a middleware solution that enables privacy-preserving transactions in multi-chain protocols, including DeFi and gaming, while ensuring regulatory compliance \[[4](http://arxiv.org/abs/2307.00521)\]. The zksk library provides a Python-based framework for constructing and composing sigma protocols, simplifying the implementation of ZKPs for developers \[[5](http://arxiv.org/abs/1911.02459)\]. These tools demonstrate the increasing demand for accessible and composable ZKP solutions.

Prior works have explored GPU implementations and custom RTL designs, but these approaches often struggle with the irregular memory access patterns inherent in NTT butterfly computations and the data-dependent memory accesses in MSMs using Pippenger's algorithm \[[1](http://arxiv.org/abs/2408.05890)\]. Additionally, the need for efficient cryptographic hashing in ZKP protocols has led to the development of ZK-friendly hash functions like MiMC, which are optimized for ZKP applications due to their simple algebraic structure and low complexity \[[3](http://arxiv.org/abs/2206.13350)\]. Hardware accelerators such as AMAZE have been designed to integrate these ZK-friendly hashes, achieving performance improvements of over 13× compared to standard CPU implementations \[[3](http://arxiv.org/abs/2206.13350)\]. These efforts highlight the growing importance of hardware acceleration in overcoming the computational bottlenecks of ZKP systems, enabling more practical and scalable applications.
