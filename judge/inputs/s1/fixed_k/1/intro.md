## Related Works

KV cache management has emerged as a critical technique for accelerating large language model (LLM) inference and improving serving efficiency. Prior work has primarily focused on optimizing KV cache reuse, compression, and eviction policies to reduce redundant computations and improve memory utilization. For instance, \[[3](http://arxiv.org/abs/2503.14647)\] highlights the importance of KV cache reuse in reducing prefill delays, particularly for repeated input texts. This aligns with \[[6](http://arxiv.org/abs/2310.07240)\], which investigates the economic benefits of storing and reusing precomputed KV caches in cloud environments, showing that it can save both delay and cloud costs across various workloads. Similarly, \[[4](http://arxiv.org/abs/2502.16002)\] introduces KVLink, which enables efficient KV cache reuse by precomputing and concatenating KV caches of retrieved documents, significantly reducing time-to-first-token (TTFT) by up to 96%. 

Several studies have also explored KV cache compression to reduce memory footprint and improve inference throughput. \[[8](http://arxiv.org/abs/2405.14366)\] presents MiniCache, a depth-aware approach that compresses KV caches by exploiting high similarity between adjacent layers, achieving up to 5.02x compression ratios and improving inference throughput by approximately 5x. \[[6](http://arxiv.org/abs/2310.07240)\] further enhances this by introducing CacheGen, which uses a custom tensor encoder to compress KV caches into compact bitstream representations, reducing the cache size by 3.5–4.3x and total delay by 3.2–3.7x. 

In addition to compression, KV cache eviction policies have been studied to manage memory constraints while maintaining model performance. \[[5](http://arxiv.org/abs/2503.12491)\] introduces CAKE, which frames cache eviction as a "cake-slicing problem" and allocates cache sizes based on layer-specific attention patterns, achieving over 10x speedup in decoding latency. \[[7](http://arxiv.org/abs/2501.06709)\] proposes Mell, a multi-GPU KV cache management system that reduces the number of GPUs needed by 31% and increases GPU utilization by 43% through adaptive request migration and scheduling. 

Recent work has also addressed the challenges of KV cache reuse in vision-language models (VLMs), where traditional LLM-based methods yield suboptimal results. \[[9](http://arxiv.org/abs/2410.23317)\] proposes VL-Cache, a sparsity and modality-aware compression method tailored for VLMs, achieving up to 90% reduction in memory footprint while maintaining high accuracy. 

These studies collectively demonstrate that KV cache management is a key enabler for efficient LLM serving, with significant improvements in latency, throughput, and memory usage.
