## Related Works

KV cache management has emerged as a critical technique for accelerating large language model (LLM) inference and improving serving efficiency. Prior work has primarily focused on optimizing KV cache reuse, compression, and eviction policies to reduce redundant computations and improve memory utilization. For instance, \[[3](http://arxiv.org/abs/2503.14647)\] highlights the importance of KV cache reuse in reducing prefill delays, particularly for repeated input texts. This aligns with \[[6](http://arxiv.org/abs/2310.07240)\], which investigates the economic benefits of storing and reusing precomputed KV caches in cloud environments, showing that it can save both delay and cloud costs across various workloads. Similarly, \[[4](http://arxiv.org/abs/2502.16002)\] introduces KVLink, which enables efficient KV cache reuse by precomputing and concatenating KV caches of retrieved documents, significantly reducing time-to-first-token (TTFT) by up to 96%. 

Several studies have also explored KV cache compression to reduce memory footprint and improve inference throughput. \[[8](http://arxiv.org/abs/2405.14366)\] presents MiniCache, a depth-aware approach that compresses KV caches by exploiting high similarity between adjacent layers, achieving up to 5.02x compression ratios and improving inference throughput by approximately 5x. \[[6](http://arxiv.org/abs/2310.07240)\] further enhances this by introducing CacheGen, which uses a custom tensor encoder to compress KV caches into compact bitstream representations, reducing the cache size by 3.5–4.3x and total delay by 3.2–3.7x. 

In addition to compression, KV cache eviction policies have been studied to manage memory constraints while maintaining model performance. \[[5](http://arxiv.org/abs/2503.12491)\] introduces CAKE, which frames cache eviction as a "cake-slicing problem" and allocates cache sizes based on layer-specific attention patterns, achieving over 10x speedup in decoding latency. \[[7](http://arxiv.org/abs/2501.06709)\] proposes Mell, a multi-GPU KV cache management system that reduces the number of GPUs needed by 31% and increases GPU utilization by 43% through adaptive request migration and scheduling. 

Recent work has also addressed the challenges of KV cache reuse in vision-language models (VLMs), where traditional LLM-based methods yield suboptimal results. \[[9](http://arxiv.org/abs/2410.23317)\] proposes VL-Cache, a sparsity and modality-aware compression method tailored for VLMs, achieving up to 90% reduction in memory footprint while maintaining high accuracy. 

These studies collectively demonstrate that KV cache management is a key enabler for efficient LLM serving, with significant improvements in latency, throughput, and memory usage. [Snippet]: «A critical approach for efficiently deploying computationally demanding large language models (LLMs) is Key-Value (KV) caching. The KV cache stores key-value states of previously generated tokens, significantly reducing the need for repetitive computations and thereby lowering latency in autoregressive generation. However, the size of the KV cache grows linearly with sequence length, posing challenges for applications requiring long context input and extensive sequence generation. In this paper, we present a simple yet effective approach, called MiniCache, to compress the KV cache across layers from a novel depth perspective, significantly reducing the memory footprint for LLM inference. Our approach is based on the observation that KV cache states exhibit high similarity between the adjacent layers in the middle-to-deep portion of LLMs. To facilitate merging, we propose disentangling the states into the magnitude and direction components, interpolating the directions of the state vectors while preserving their lengths unchanged. Furthermore, we introduce a token retention strategy to keep highly distinct state pairs unmerged, thus preserving the information with minimal additional storage overhead. Our MiniCache is training-free and general, complementing existing KV cache compression strategies, such as quantization and sparsity. We conduct a comprehensive evaluation of MiniCache utilizing various models including LLaMA-2, LLaMA-3, Phi-3, Mistral, and Mixtral across multiple benchmarks, demonstrating its exceptional performance in achieving superior compression ratios and high throughput. On the ShareGPT dataset, LLaMA-2-7B with 4-bit MiniCache achieves a remarkable compression ratio of up to 5.02x, enhances inference throughput by approximately 5x, and reduces the memory footprint by 41% compared to the FP16 full cache baseline, all while maintaining near-lossless performance.»

The category "Vision-Language Model Cache Strategies" focuses on optimizing the performance of Vision-Language Models (VLMs) by addressing the challenges of storing and accessing large Key-Value (KV) caches that encode long visual contexts. Unlike traditional Large Language Models (LLMs), VLMs face unique challenges due to the sparsity patterns of their attention mechanisms, which involve both visual and textual tokens \[[1](http://arxiv.org/abs/2503.16525)\]. Existing KV cache compression methods, while effective for LLMs, often lead to suboptimal accuracy and speed when directly applied to VLMs \[[1](http://arxiv.org/abs/2503.16525)\]. To overcome this, the proposed VL-Cache approach introduces a layer-adaptive sparsity-aware cache budget allocation method, which effectively distributes the limited cache budget across different layers of the model, enabling significant reductions in KV cache size without compromising accuracy \[[1](http://arxiv.org/abs/2503.16525)\]. Additionally, a modality-aware token scoring policy is developed to better evaluate the importance of tokens, further enhancing the efficiency of the cache \[[1](http://arxiv.org/abs/2503.16525)\]. Empirical results show that retaining only 10% of the KV cache can achieve accuracy comparable to using the full cache, while significantly improving inference speed and reducing memory footprint \[[1](http://arxiv.org/abs/2503.16525)\]. These advancements are crucial for deploying VLMs in real-world applications where resource efficiency and performance are critical.
