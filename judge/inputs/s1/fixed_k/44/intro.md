## Related Works

Representation learning is a cornerstone of modern recommender systems, enabling efficient user-item matching through vectorized embeddings \[[10](http://arxiv.org/abs/1502.04163)\]. However, the computational and memory costs of these embeddings can be prohibitive for real-time applications. To address this, binarization techniques have emerged as a promising approach, converting dense embeddings into compact binary representations \[[3](http://arxiv.org/abs/1803.09065)\]. This strategy not only reduces memory usage but also accelerates inference, making it suitable for resource-constrained environments \[[15](http://arxiv.org/abs/1611.01600)\]. 

Existing binarization methods primarily focus on numerical quantization, often at the expense of information retention \[[15](http://arxiv.org/abs/1611.01600)\]. This leads to performance degradation, as the loss of precision can negatively impact recommendation accuracy \[[3](http://arxiv.org/abs/1803.09065)\]. To mitigate this, recent work has explored the integration of graph-based models to enhance the binarization process \[[1](http://arxiv.org/abs/1906.01829)\]. For instance, Binarized Collaborative Filtering with Distilling Graph Convolutional Networks (BGCN) introduces a framework that distills ranking information from GCNs into binarized collaborative filtering, using stochastic penalties to convert binary optimization into continuous optimization \[[1](http://arxiv.org/abs/1906.01829)\]. This approach allows for efficient optimization using standard solvers like SGD and Adam \[[1](http://arxiv.org/abs/1906.01829)\].

Another line of research focuses on learning vector representations of users and items through graph structures, capturing collaborative signals more effectively \[[2](http://arxiv.org/abs/1905.08108)\]. Neural Graph Collaborative Filtering (NGCF) explicitly integrates user-item interactions into the embedding process by propagating embeddings on the bipartite graph, enabling high-order connectivity modeling \[[2](http://arxiv.org/abs/1905.08108)\]. Similarly, Multi-Graph Convolution Collaborative Filtering (Multi-GCCF) extends this idea by incorporating multiple graphs—user-user, item-item, and user-item—to better capture proximal information \[[4](http://arxiv.org/abs/2001.00267)\]. These models demonstrate that leveraging graph structures can significantly improve the quality of learned embeddings \[[4](http://arxiv.org/abs/2001.00267)\].

In addition to graph-based methods, some studies have explored the use of autoencoders for binarizing word embeddings while preserving semantic information \[[3](http://arxiv.org/abs/1803.09065)\]. This approach, known as Near-lossless Binarization of Word Embeddings, reduces vector size by 97% while maintaining 92% of original accuracy \[[3](http://arxiv.org/abs/1803.09065)\]. This principle has also been applied to collaborative filtering, where binarized embeddings can be used to reduce computational overhead without sacrificing performance \[[15](http://arxiv.org/abs/1611.01600)\].

Furthermore, recent work has investigated the use of graph signal processing (GSP) to improve item representations in collaborative filtering \[[18](http://arxiv.org/abs/2505.11552)\].
