## Related Works

Representation learning is a cornerstone of modern recommender systems, enabling efficient user-item matching through vectorized embeddings \[[10](http://arxiv.org/abs/1502.04163)\]. However, the computational and memory costs of these embeddings can be prohibitive for real-time applications. To address this, binarization techniques have emerged as a promising approach, converting dense embeddings into compact binary representations \[[3](http://arxiv.org/abs/1803.09065)\]. This strategy not only reduces memory usage but also accelerates inference, making it suitable for resource-constrained environments \[[15](http://arxiv.org/abs/1611.01600)\]. 

Existing binarization methods primarily focus on numerical quantization, often at the expense of information retention \[[15](http://arxiv.org/abs/1611.01600)\]. This leads to performance degradation, as the loss of precision can negatively impact recommendation accuracy \[[3](http://arxiv.org/abs/1803.09065)\]. To mitigate this, recent work has explored the integration of graph-based models to enhance the binarization process \[[1](http://arxiv.org/abs/1906.01829)\]. For instance, Binarized Collaborative Filtering with Distilling Graph Convolutional Networks (BGCN) introduces a framework that distills ranking information from GCNs into binarized collaborative filtering, using stochastic penalties to convert binary optimization into continuous optimization \[[1](http://arxiv.org/abs/1906.01829)\]. This approach allows for efficient optimization using standard solvers like SGD and Adam \[[1](http://arxiv.org/abs/1906.01829)\].

Another line of research focuses on learning vector representations of users and items through graph structures, capturing collaborative signals more effectively \[[2](http://arxiv.org/abs/1905.08108)\]. Neural Graph Collaborative Filtering (NGCF) explicitly integrates user-item interactions into the embedding process by propagating embeddings on the bipartite graph, enabling high-order connectivity modeling \[[2](http://arxiv.org/abs/1905.08108)\]. Similarly, Multi-Graph Convolution Collaborative Filtering (Multi-GCCF) extends this idea by incorporating multiple graphs—user-user, item-item, and user-item—to better capture proximal information \[[4](http://arxiv.org/abs/2001.00267)\]. These models demonstrate that leveraging graph structures can significantly improve the quality of learned embeddings \[[4](http://arxiv.org/abs/2001.00267)\].

In addition to graph-based methods, some studies have explored the use of autoencoders for binarizing word embeddings while preserving semantic information \[[3](http://arxiv.org/abs/1803.09065)\]. This approach, known as Near-lossless Binarization of Word Embeddings, reduces vector size by 97% while maintaining 92% of original accuracy \[[3](http://arxiv.org/abs/1803.09065)\]. This principle has also been applied to collaborative filtering, where binarized embeddings can be used to reduce computational overhead without sacrificing performance \[[15](http://arxiv.org/abs/1611.01600)\].

Furthermore, recent work has investigated the use of graph signal processing (GSP) to improve item representations in collaborative filtering \[[18](http://arxiv.org/abs/2505.11552)\]. GSPRec, for example, incorporates item-item proximity derived from user interaction ordering, enhancing the spectral representation of items and improving recommendation accuracy \[[18](http://arxiv.org/abs/2505.11552)\]. ### <a id='category-binarization-techniques-for-efficiency'></a>Binarization Techniques for Efficiency: 3 papers found.
The category "Binarization Techniques for Efficiency" explores methods to convert high-dimensional, continuous representations into binary formats to enhance computational efficiency and reduce memory usage, particularly in recommendation systems and neural network models \[[1](http://arxiv.org/abs/1906.01829)\]. This approach is motivated by the challenges of handling large-scale data and the computational costs of floating-point operations \[[1](http://arxiv.org/abs/1906.01829)\]. One key technique involves using autoencoder architectures to transform real-valued embeddings into binary representations while preserving semantic information, resulting in a significant reduction in memory footprint and faster vector operations \[[2](http://arxiv.org/abs/1905.08108)\]. Additionally, binarization of network weights and activations has been proposed to reduce computational overhead by replacing multiplications with bit-wise operations, although early methods often neglected the impact of binarization on model loss \[[3](http://arxiv.org/abs/1803.09065)\]. To address these limitations, recent work has focused on developing loss-aware binarization algorithms that directly minimize the loss function during training, improving model performance while maintaining efficiency \[[3](http://arxiv.org/abs/1803.09065)\]. These techniques are particularly relevant to the paper's focus on graph representation binarization for collaborative filtering, where mitigating information loss during binarization is crucial for maintaining performance \[[1](http://arxiv.org/abs/1906.01829)\].

### <a id='category-graph-based-collaborative-filtering-models'></a>Graph-Based Collaborative Filtering Models: 12 papers found.
Graph-based collaborative filtering models have emerged as a powerful approach for recommendation systems, leveraging the structure of user-item interaction graphs to enhance the modeling of collaborative signals. These models typically integrate graph neural networks (GNNs) to propagate embeddings through the bipartite graph, capturing high-order connectivity and implicit user-item relationships \[[1](http://arxiv.org/abs/1906.01829)\]. For instance, Neural Graph Collaborative Filtering (NGCF) explicitly incorporates user-item graphs to refine embeddings by propagating information across the graph, leading to more accurate recommendations \[[2](http://arxiv.org/abs/1905.08108)\]. Similarly, Multi-GCCF extends this idea by integrating multiple graphs—user-user, item-item, and user-item—to better capture proximal and high-order interactions \[[3](http://arxiv.org/abs/1803.09065)\]. The importance of graph structure in representation learning is further emphasized by models like SimRec, which addresses over-smoothing and scalability issues through knowledge distillation and contrastive learning \[[4](http://arxiv.org/abs/2001.00267)\]. Additionally, models such as GCF and W-GCF generalize implicit feedback to both user and item sides, while A-GCF introduces attention mechanisms to weigh implicit feedback more effectively \[[5](http://arxiv.org/abs/2304.13195)\]. Spectral methods, such as the spectral graph wavelet collaborative filtering framework, also contribute by representing users and items in the spectral domain to capture both local and global structures \[[6](http://arxiv.org/abs/1809.06120)\]. Furthermore, the challenge of data sparsity is tackled by methods like Neighborhood-enriched Contrastive Learning (NCL), which leverages structural and semantic neighbors to improve contrastive learning \[[7](http://arxiv.org/abs/1910.03081)\]. The issue of over-correlation in GNN-based models is addressed by AFDGCF, which introduces adaptive feature de-correlation to mitigate both over-smoothing and over-correlation \[[8](http://arxiv.org/abs/2303.08537)\]. Overall, these works highlight the growing interest in graph-based collaborative filtering, emphasizing the need for more effective graph structures, better embedding propagation, and robust handling of sparsity and fairness concerns \[[9](http://arxiv.org/abs/1803.03502)\].
