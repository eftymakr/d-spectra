## Related Works

Memory bandwidth regulation and cache partitioning have been extensively studied for achieving predictable timing in real-time computing systems \[[1](http://arxiv.org/abs/2310.02959)\]. These techniques are often combined with partitioned scheduling to manage task execution times, which are highly dependent on allocated resources \[[2](http://arxiv.org/abs/1809.05921)\]. Prior work has focused on optimizing resource allocation and task scheduling to improve schedulability and reduce resource usage \[[3](http://arxiv.org/abs/2410.14003)\].

Several approaches have been proposed to co-optimize cache partitioning and task scheduling. For example, \[[4](http://arxiv.org/abs/2302.11236)\] introduces a hybrid multi-layer design space exploration technique that interleaves cache partitioning, task allocation, and schedulability analysis. This approach uses a breadth-first search with proactive pruning for cache partitioning, a first-fit heuristic for task allocation, and a recurrence relation for schedulability analysis. The results show that this method improves real-time schedulability by up to 233.6% for highly cache-sensitive tasks \[[4](http://arxiv.org/abs/2302.11236)\]. Similarly, \[[5](http://arxiv.org/abs/2502.02437)\] explores dynamic memory bandwidth regulation, focusing on how to determine worst-case response times for tasks spanning different time intervals with varying bandwidth-to-core assignments. The work highlights the importance of considering memory bandwidth in real-time scheduling \[[5](http://arxiv.org/abs/2502.02437)\].

Cache partitioning has also been studied in the context of improving performance and reducing contention. \[[6](http://arxiv.org/abs/2501.08484)\] proposes a per-bank bandwidth regulation approach for multi-banked shared LLCs, aiming to prevent unnecessary throttling of non-contended banks. This method improves performance by up to 3.66× compared to prior bank-oblivious approaches \[[6](http://arxiv.org/abs/2501.08484)\]. Additionally, \[[7](http://arxiv.org/abs/2102.11528)\] presents a coordinated management mechanism for cache partitioning, bandwidth partitioning, and prefetch throttling, which dynamically manages these resources to reduce average memory access time and improve performance. The results show that this coordinated approach outperforms state-of-the-art techniques by up to 50% \[[7](http://arxiv.org/abs/2102.11528)\].

In the area of cache-aware scheduling, \[[8](http://arxiv.org/abs/1312.4509)\] proposes a static scheduling method for hard real-time multicore systems based on communication affinities. This approach minimizes L1 data cache misses by leveraging communication patterns between tasks \[[8](http://arxiv.org/abs/1312.4509)\]. Furthermore, \[[9](http://arxiv.org/abs/1809.02892)\] introduces a dependency-graph approach for multiprocessor real-time synchronization, which helps manage resource sharing and task prioritization. This method is particularly useful for frame-based real-time tasks with periodic execution \[[9](http://arxiv.org/abs/1809.02892)\].
