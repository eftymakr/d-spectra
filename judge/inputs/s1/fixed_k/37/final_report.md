## Related Works

Vision Transformers (ViTs) have emerged as a powerful alternative to convolutional neural networks (CNNs) in computer vision tasks, leveraging the transformer architecture to effectively capture global context \[[2](http://arxiv.org/abs/2405.00314)\]. However, the deployment of ViTs on hardware platforms, particularly FPGAs, remains challenging due to the high computational and memory demands of their non-linear operations, such as Softmax and LayerNorm, which are sensitive to model accuracy \[[1](http://arxiv.org/abs/2211.08110)\]. Existing methods often only exploit parallelism in matrix multiplication operations, leaving complex operations to the CPU, resulting in suboptimal performance due to communication overhead \[[1](http://arxiv.org/abs/2211.08110)\]. 

Several studies have explored hardware-efficient methods for ViT acceleration. HeatViT proposes a hardware-efficient image-adaptive token pruning framework that dynamically identifies and consolidates non-informative tokens, achieving up to 65.3% computation reduction while maintaining high accuracy \[[1](http://arxiv.org/abs/2211.08110)\]. Similarly, ME-ViT introduces a single-load policy to minimize memory traffic, significantly improving memory bandwidth and throughput \[[3](http://arxiv.org/abs/2402.09709)\]. Trio-ViT focuses on post-training quantization and acceleration for efficient ViTs, eliminating the problematic Softmax and integrating linear attention, achieving up to 7.3× DSP efficiency improvements \[[4](http://arxiv.org/abs/2405.03882)\]. 

ViTA is a configurable hardware accelerator designed for resource-constrained edge devices, reducing off-chip memory accesses and achieving nearly 90% hardware utilization efficiency \[[6](http://arxiv.org/abs/2302.09108)\]. ViTCoD introduces a dedicated algorithm and accelerator co-design framework, pruning and polarizing attention maps to reduce attention computations and data movement costs, achieving up to 235.3× speedups over general computing platforms \[[7](http://arxiv.org/abs/2210.09573)\]. SuperViT reduces computational costs by training a single model capable of handling various computational budgets, achieving performance improvements while maintaining hardware efficiency \[[8](http://arxiv.org/abs/2205.11397)\]. 

The VITALITY framework unifies low-rank and sparse approximations for ViT acceleration, using linear Taylor attention to reduce the quadratic cost of attention matrices and improve hardware efficiency \[[10](http://arxiv.org/abs/2211.05109)\]. Evo-ViT introduces a slow-fast token evolution approach, maintaining spatial structure and information flow to accelerate ViTs from the beginning of training \[[11](http://arxiv.org/abs/2108.01390)\].

Microscaling (MX) data formats combine per-block scaling factors with narrow floating-point and integer types, achieving both high memory density and dynamic range \[[13](http://arxiv.org/abs/2307.15517)\]. PEANO-ViT introduces power-efficient approximations for non-linearities like LayerNorm, Softmax, and GELU, reducing resource usage and improving power efficiency \[[15](http://arxiv.org/abs/2406.14854)\].

### <a id='category-recent-advances-in-data-format-optimization'></a>Recent Advances in Data Format Optimization: 3 papers found.
Recent advances in data format optimization have focused on developing efficient representations that balance hardware efficiency, model accuracy, and user convenience. Microscaling (MX) formats, which combine per-block scaling factors with narrow floating-point and integer types, have emerged as a promising solution for reducing computational and storage costs in deep learning applications \[[14](http://arxiv.org/abs/2310.10537)\]. These formats enable high memory density while maintaining large dynamic ranges, making them suitable for complex operations in models like large language models (LLMs) \[[1](http://arxiv.org/abs/2211.08110)\]. Hardware converters for MX-format have been proposed, supporting various types such as E5M2 and INT8, with experimental results demonstrating their feasibility on FPGA platforms \[[17](http://arxiv.org/abs/2411.03149)\]. Additionally, MX formats have been explored for training generative language models at sub-8-bit precision with minimal accuracy loss, highlighting their potential for both inference and training \[[14](http://arxiv.org/abs/2310.10537)\]. The integration of MX formats into hardware accelerators, such as through a compiler named MASE, has shown significant improvements in energy efficiency and accuracy, achieving an average 24% improvement in Δ accuracy with only a 3% overhead compared to 8-bit fixed-point designs \[[1](http://arxiv.org/abs/2211.08110)\]. These developments underscore the growing interest in MX formats as a viable alternative to traditional floating-point representations, particularly for applications requiring high performance and low precision \[[14](http://arxiv.org/abs/2310.10537)\].
