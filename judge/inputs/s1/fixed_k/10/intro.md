## Related Works

Multi-token prediction (MTP) has emerged as a promising pre-training objective for language models, offering potential improvements in downstream performance, inference speed, and training efficiency \[[4](http://arxiv.org/abs/2404.19737)\]. Unlike traditional next-token prediction (NTP), which predicts one token at a time, MTP extends the prediction horizon by forecasting multiple future tokens simultaneously using multiple prediction heads \[[4](http://arxiv.org/abs/2404.19737)\]. This approach has been explored in various works, each proposing different strategies to enhance the effectiveness of MTP. For instance, L-MTP introduces a leap-based mechanism that allows the model to predict non-sequential tokens in a single forward pass, enhancing long-range dependency capture and inference efficiency \[[1](http://arxiv.org/abs/2505.17505)\]. Similarly, Future Token Prediction (FTP) generates embedding vectors for each token position that better capture the overall meaning of longer sequences, leading to improved topic coherence in generated text \[[7](http://arxiv.org/abs/2410.18160)\]. 

However, the application of MTP has not been without challenges. Research has shown that smaller language models (SLMs) struggle with the MTP objective, which limits its general applicability \[[4](http://arxiv.org/abs/2404.19737)\]. To address this, several studies have explored curriculum learning strategies for MTP training. For example, one study proposes a curriculum learning approach that gradually increases the complexity of the pre-training objective from NTP to MTP, enabling SLMs to better leverage the MTP objective during pre-training \[[6](http://arxiv.org/abs/2407.10194)\]. Another study investigates the use of curriculum learning for code language models, demonstrating that a well-designed curriculum can significantly improve the accuracy of small decoder-only code language models on code execution tasks \[[6](http://arxiv.org/abs/2407.10194)\]. 

Additionally, multi-token prediction has been explored in the context of vision-language pre-training, where it has been extended to a novel Next Patch Prediction (NPP) paradigm for autoregressive image generation. This approach groups image tokens into patch tokens, reducing computational costs while maintaining image generation quality \[[12](http://arxiv.org/abs/2412.15321)\]. Furthermore, the use of multi-token prediction in the context of self-speculative decoding has been explored, with one study showing that models trained with 4-token prediction are up to 3 times faster at inference, even with large batch sizes \[[4](http://arxiv.org/abs/2404.19737)\].
