## Related Works

Differential privacy (DP) has emerged as a de facto standard for privacy-preserving data analysis \[[19](http://arxiv.org/abs/2006.05609)\]. However, its implementation is vulnerable to malicious behavior by servers, particularly in distributed settings \[[20](http://arxiv.org/abs/2209.14086)\]. Servers may sample noise from incorrect distributions or generate correlated noise while appearing to follow established protocols \[[20](http://arxiv.org/abs/2209.14086)\]. This issue has been studied in various contexts, including the use of discrete distributions for noise generation \[[4](http://arxiv.org/abs/2112.05307)\], and the susceptibility of DP mechanisms to timing and floating-point representation attacks \[[4](http://arxiv.org/abs/2112.05307)\]. These attacks can reveal sensitive information by exploiting side channels, such as the time taken to generate noise \[[4](http://arxiv.org/abs/2112.05307)\].

Several works have addressed the verification of DP mechanisms. Interactive proofs for differential privacy have been introduced to ensure that the output is both differentially private and reliable \[[2](http://arxiv.org/abs/2208.09011)\]. This approach requires a zero-knowledge proof that convinces an efficient verifier that the output is both differentially private and reliable \[[2](http://arxiv.org/abs/2208.09011)\]. This is achieved by carefully mixing private and public randomness to compute verifiable DP counting queries with theoretical guarantees \[[2](http://arxiv.org/abs/2208.09011)\]. However, the computational assumptions required for such proofs are necessary, as shown by a separation between information-theoretic DP and computational DP under the definition of verifiability \[[2](http://arxiv.org/abs/2208.09011)\].

In the context of verifiable differential privacy, recent work has focused on improving efficiency and practicality. For instance, efficient verifiable LDP (VLDP) schemes have been proposed that prevent both input and output manipulation attacks, requiring only one-time interaction between client and server \[[1](http://arxiv.org/abs/2406.18940)\]. These schemes are particularly relevant in the shuffle model, where the link between clients and the aggregator is disconnected \[[1](http://arxiv.org/abs/2406.18940)\]. Additionally, verifiable decentralized machine learning using zero-knowledge proofs (ZKP) has been explored to ensure the integrity and validity of computation results shared by other participants \[[7](http://arxiv.org/abs/2310.14848)\]. ZKP-based verifiable machine learning (ZKP-VML) has been reviewed comprehensively, highlighting the role of ZKP in ensuring verifiability \[[7](http://arxiv.org/abs/2310.14848)\].

In the realm of distributed differential privacy, the challenge of efficiently sampling noise with secure multi-party computation (MPC) has been addressed. Several secure sampling methods have been proposed, each with different security assumptions and theoretical analyses \[[3](http://arxiv.org/abs/2409.10667)\]. The performance of these protocols has been benchmarked, showing that malicious protocols based on bitwise sampling are more efficient than other methods \[[3](http://arxiv.org/abs/2409.10667)\]. Furthermore, the utility loss caused by sampling noise in MPC is small, which mitigates concerns about the practicality of distributed differential privacy \[[3](http://arxiv.org/abs/2409.10667)\].
