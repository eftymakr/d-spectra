## Related Works

Generative retrieval has emerged as a promising paradigm that replaces traditional search index data structures with a single large-scale neural network, enabling improved efficiency and seamless integration with generative large language models \[[1](http://arxiv.org/abs/2407.19829)\]. This approach directly generates document identifiers through corpus-specific constrained decoding, forming an end-to-end retrieval framework \[[1](http://arxiv.org/abs/2407.19829)\]. The generalization capabilities of generative retrieval on out-of-distribution corpora have attracted significant attention \[[1](http://arxiv.org/abs/2407.19829)\].

Several works have explored the challenges and limitations of generative retrieval. For instance, \[[2](http://arxiv.org/abs/2408.02152)\] highlights the difficulties in generating detailed item titles from brief queries in e-commerce search, including noise in item titles and interpretability issues. To address these, they propose a framework that uses multi-span identifiers and constraint-based beam search to enhance result interpretability \[[2](http://arxiv.org/abs/2408.02152)\]. Similarly, \[[3](http://arxiv.org/abs/2104.05336)\] discusses the limitations of training-based indexing in generative retrieval, which requires heavy training and underutilizes pre-trained knowledge in large language models (LLMs). To mitigate this, they introduce a few-shot indexing-based framework that generates document identifiers without training, improving adaptability to dynamic document corpora \[[3](http://arxiv.org/abs/2104.05336)\].

The role of beam search in generative retrieval has also been scrutinized. \[[4](http://arxiv.org/abs/2210.02068)\] presents a study on machine translation decoding beyond beam search, showing that beam search, while effective for BLEU improvements, is agnostic to end metrics. They explore alternative decoding algorithms, including Monte-Carlo Tree Search (MCTS), which can be more metric-driven \[[4](http://arxiv.org/abs/2210.02068)\]. This aligns with \[[5](http://arxiv.org/abs/2411.00744)\], which introduces a cost-constrained retrieval optimization framework for RAG, using MCTS to find optimal chunk combinations while considering chunk correlations and non-monotonic utility \[[5](http://arxiv.org/abs/2411.00744)\].

In the context of document retrieval, \[[6](http://arxiv.org/abs/2404.14600)\] proposes Nonparametric Decoding (Np Decoding), which enhances generative retrieval models by using nonparametric contextualized vocab embeddings as decoder embeddings. This allows the model to utilize both parametric and nonparametric spaces, improving performance across multiple datasets \[[6](http://arxiv.org/abs/2404.14600)\]. Additionally, \[[7](http://arxiv.org/abs/2404.07220)\] introduces PAG, a novel optimization approach that guides autoregressive generation through simultaneous decoding, achieving significant improvements in MRR and a substantial reduction in query latency \[[7](http://arxiv.org/abs/2404.07220)\].

The use of multiple query rewrites for conversational passage retrieval is explored in \[[8](http://arxiv.org/abs/2401.06761)\], where a neural query rewriter generates multiple queries and integrates them efficiently in the retrieval pipeline. This approach leverages beam search to produce multiple query rewrites at no additional cost, improving retrieval performance without sacrificing efficiency \[[8](http://arxiv.org/abs/2401.06761)\].
