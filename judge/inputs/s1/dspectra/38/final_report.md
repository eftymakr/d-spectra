## Related Works

Memory bandwidth regulation and cache partitioning have been extensively studied for achieving predictable timing in real-time computing systems \[[1](http://arxiv.org/abs/1809.05921)\]. These techniques are often combined with partitioned scheduling to manage resource allocation effectively \[[2](http://arxiv.org/abs/1607.07763)\]. Task execution times are heavily influenced by the availability of allocated resources, necessitating careful co-allocation of tasks and resources to cores \[[3](https://www.semanticscholar.org/paper/abbd6f8840092bd8e4e3684d3297e1b707abdc5d)\]. 

Several studies have explored the challenges of memory contention in multi-core systems. For instance, \[[4](https://www.semanticscholar.org/paper/e02eb1430cb7aa53f20818d2b642abe10d58a459)\] highlights that contention over shared memory resources, such as caches, interconnects, and DRAM, is a primary source of unpredictability in modern multi-core embedded systems. This has led to the development of frameworks like BRU, which enables per-core memory bandwidth regulation at fine-grained time intervals \[[5](https://www.semanticscholar.org/paper/1ed3c2a13c728b4d294644db90fb278e62bece22)\]. Similarly, MemGuard has been proposed as a memory bandwidth reservation system to improve performance isolation in multi-core platforms \[[8](https://www.semanticscholar.org/paper/bbebaeb1b00fdcde2aeb192543835d3ec1518f8d)\].

The integration of security tasks into real-time systems without compromising timing constraints has also been addressed. Contego, for example, introduces an adaptive framework that allows security tasks to operate in different modes while maintaining compatibility with legacy systems \[[6](http://arxiv.org/abs/1705.00138)\]. This is particularly relevant in environments where security and real-time performance must coexist \[[7](http://arxiv.org/abs/1810.07059)\].

Memory interference delay in COTS-based multi-core systems has been another area of focus. Techniques have been proposed to provide tight upper bounds on worst-case memory interference, considering the timing characteristics of DRAM resources such as banks, buses, and memory controllers \[[14](https://www.semanticscholar.org/paper/afca4afaaaa543a1da02b266e9b2ac46eb94793b)\]. These approaches help quantify how memory interference can be reduced through DRAM bank partitioning \[[14](https://www.semanticscholar.org/paper/afca4afaaaa543a1da02b266e9b2ac46eb94793b)\].

The multiframe model has been used to improve schedulability analysis by eliminating pessimism in systems with tasks whose worst-case execution times vary \[[10](https://www.semanticscholar.org/paper/e8d15aa827be70bebf15e217ac9295276ddebda7)\]. However, this model is optimistic and unsafe for multi-core systems with shared memory controllers, as it ignores memory contention \[[10](https://www.semanticscholar.org/paper/e8d15aa827be70bebf15e217ac9295276ddebda7)\]. Recent work has adapted existing stall analyses for memory-regulated systems to the multiframe model, leading to improved scheduling success ratios \[[10](https://www.semanticscholar.org/paper/e8d15aa827be70bebf15e217ac9295276ddebda7)\].

Cache partitioning techniques have been successfully adopted to mitigate interference among real-time tasks on multi-core processors \[[12](http://arxiv.org/abs/2310.02959)\]. A hybrid multi-layer design space exploration technique has been proposed to solve this multi-resource management problem \[[12](http://arxiv.org/abs/2310.02959)\].

### <a id='category-memory-contention-analysis-in-multi-core-systems'></a>Memory Contention Analysis in Multi-Core Systems: 6 papers found.
Memory contention in multi-core systems is a critical challenge for achieving predictable timing in real-time applications, as shared memory resources like caches, interconnects, and DRAM are prone to contention \[[1](http://arxiv.org/abs/1809.05921)\]. This issue is exacerbated by unpredictable access patterns and cache eviction policies that prioritize average performance over timing determinism \[[2](http://arxiv.org/abs/1607.07763)\]. Existing approaches often rely on partitioning and software-driven memory allocation to mitigate contention \[[4](https://www.semanticscholar.org/paper/e02eb1430cb7aa53f20818d2b642abe10d58a459)\], but these strategies can have unintended side effects on high-performance platforms \[[2](http://arxiv.org/abs/1607.07763)\]. DDR DRAMs, for instance, suffer from inherent limitations such as variable access latencies and overly pessimistic latency bounds, making them unsuitable for systems requiring strict timing guarantees \[[7](http://arxiv.org/abs/1810.07059)\]. To address these limitations, alternative memory solutions like RLDRAM have been proposed, offering reduced timing variability and lower worst-case latency \[[7](http://arxiv.org/abs/1810.07059)\]. Additionally, techniques such as cache coloring and invalidation-driven allocation (IDA) have been introduced to restore memory access determinism by protecting critical cache blocks from both internal and external eviction \[[2](http://arxiv.org/abs/1607.07763)\]. In commercial-off-the-shelf (COTS) systems, memory interference due to shared DRAM can lead to significant and variable delays, necessitating methods to bound worst-case memory interference \[[4](https://www.semanticscholar.org/paper/e02eb1430cb7aa53f20818d2b642abe10d58a459)\]. Recent work has also focused on cache bank contention, particularly in multi-banked shared LLCs, where uneven request distribution can lead to performance degradation and even malicious denial-of-service attacks \[[5](https://www.semanticscholar.org/paper/1ed3c2a13c728b4d294644db90fb278e62bece22)\]. To counteract these issues, per-bank bandwidth regulation has been proposed to improve performance while maintaining isolation benefits \[[5](https://www.semanticscholar.org/paper/1ed3c2a13c728b4d294644db90fb278e62bece22)\]. These efforts highlight the ongoing research into memory contention analysis and mitigation strategies in multi-core systems.
