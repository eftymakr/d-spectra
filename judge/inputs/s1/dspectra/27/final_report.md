## Related Works

Recent advancements in information retrieval have seen the rise of differentiable search index (DSI) frameworks, which unify indexing and retrieval into a single model \[[4](http://arxiv.org/abs/2202.06991)\]. Traditional retrieval systems often rely on separate indexing and retrieval stages, which can introduce error accumulation during the indexing phase and hinder effective query-document alignment \[[1](http://arxiv.org/abs/2206.10128)\]. In contrast, DSI models directly map queries to document identifiers using a single neural network, simplifying the retrieval pipeline \[[4](http://arxiv.org/abs/2202.06991)\]. However, DSI models face challenges such as data distribution mismatches between indexing and retrieval \[[1](http://arxiv.org/abs/2206.10128)\], and difficulties in cross-lingual retrieval \[[1](http://arxiv.org/abs/2206.10128)\]. To address these issues, several works have proposed enhancements to the DSI paradigm.

One such approach is DSI-QG, which generates potentially relevant queries during indexing and uses a cross-encoder ranker to filter and re-rank them \[[1](http://arxiv.org/abs/2206.10128)\]. This allows the model to better align with retrieval queries, which are typically shorter than the indexed documents \[[1](http://arxiv.org/abs/2206.10128)\]. Similarly, the Semantic-Enhanced DSI (SE-DSI) model introduces elaborative descriptions for documents and leverages rehearsal strategies to improve memorization \[[2](http://arxiv.org/abs/2305.15115)\]. These strategies enhance the model's ability to connect queries to relevant documents, improving retrieval effectiveness.

Another challenge in DSI models is the inability to handle dynamic updates to the corpus without retraining \[[9](http://arxiv.org/abs/2212.09744)\]. To address this, DSI++ introduces a continual learning framework that allows incremental indexing of new documents while maintaining retrieval performance \[[9](http://arxiv.org/abs/2212.09744)\]. This is achieved by optimizing for flatter loss basins and introducing a generative memory to prevent catastrophic forgetting \[[9](http://arxiv.org/abs/2212.09744)\]. Similarly, IncDSI enables real-time addition of new documents without retraining the entire model, making it suitable for dynamic environments \[[18](http://arxiv.org/abs/2307.10323)\].

In addition to DSI-based approaches, other models have explored the use of contextual language models for improved retrieval. For example, ColBERT introduces a late interaction architecture that independently encodes queries and documents using BERT, then computes their fine-grained similarity \[[20](http://arxiv.org/abs/2004.12832)\]. This approach allows for efficient retrieval while maintaining high accuracy. Similarly, SPLADE leverages sparse representations and explicit sparsity regularization to achieve competitive results with dense models, while maintaining efficiency \[[19](http://arxiv.org/abs/2107.05720)\].

The use of query generation to enhance retrieval has also been explored. For instance, the Document Expansion by Query Prediction method predicts queries that a document can answer and expands the document with those queries, improving retrieval effectiveness \[[16](http://arxiv.org/abs/1904.08375)\]. This approach is complementary to DSI-based methods, as it enhances the relevance of indexed documents during the indexing phase.

### <a id='category-differentiable-search-index-frameworks'></a>Differentiable Search Index Frameworks: 4 papers found.
Differentiable Search Index (DSI) frameworks represent a paradigm shift in information retrieval by integrating indexing and retrieval into a unified neural model, eliminating the need for separate indexing stages \[[3](http://arxiv.org/abs/2305.02073)\]. These frameworks encode all documents into model parameters, allowing queries to be directly mapped to relevant document identifiers through a sequence-to-sequence architecture \[[12](http://arxiv.org/abs/2206.02743)\]. This approach addresses traditional limitations of error accumulation during representation and indexing phases, as well as insufficient query-document interaction \[[3](http://arxiv.org/abs/2305.02073)\]. For instance, the Semantic-Enhanced DSI (SE-DSI) model improves document identifiers by incorporating elaborative descriptions inspired by cognitive psychology, while rehearsal strategies are used to enhance semantic feature memorization \[[2](http://arxiv.org/abs/2305.15115)\]. Similarly, the Neural Corpus Indexer (NCI) introduces a prefix-aware decoder and semantic document identifiers to improve recall performance, achieving significant gains over baselines \[[4](http://arxiv.org/abs/2202.06991)\]. These advancements highlight the potential of DSI to enhance retrieval accuracy and generalization, particularly in zero-shot scenarios \[[3](http://arxiv.org/abs/2305.02073)\]. However, challenges remain, such as ensuring exclusivity, completeness, and relevance ordering in retrieval results \[[2](http://arxiv.org/abs/2305.15115)\]. Overall, DSI frameworks offer a promising direction for end-to-end optimization in document retrieval.

[Snippet]: «Differentiable Search Indices (DSIs) encode a corpus of documents in model parameters and use the same model to answer user queries directly. Despite the strong performance of DSI models, deploying them in situations where the corpus changes over time is computationally expensive because reindexing the corpus requires re-training the model.
