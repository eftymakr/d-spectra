## Related Works

Vision Transformers (ViTs) have gained significant attention for their ability to capture global context in image recognition tasks, surpassing traditional convolutional neural networks (CNNs) in many scenarios \[[17](http://arxiv.org/abs/2105.15075)\]. However, the deployment of ViTs on resource-constrained hardware remains challenging due to their high computational and memory demands \[[1](http://arxiv.org/abs/2211.08110)\]. A major limitation in existing ViT accelerators is the reliance on CPU for complex operations such as Softmax and LayerNorm, which are sensitive to precision and hinder efficient hardware mapping \[[1](http://arxiv.org/abs/2211.08110)\]. This communication bottleneck between CPU and accelerator results in suboptimal performance \[[1](http://arxiv.org/abs/2211.08110)\].

Several works have addressed the efficiency of ViTs through various techniques. HeatViT proposes a hardware-efficient token pruning framework that dynamically identifies and consolidates non-informative tokens, reducing computation by up to 65.3% while maintaining high accuracy \[[1](http://arxiv.org/abs/2211.08110)\]. Similarly, EViT reorganizes image tokens during inference to reduce redundant computations, achieving a 50% speedup with minimal accuracy loss \[[4](http://arxiv.org/abs/2202.07800)\]. CrossViT introduces a dual-branch transformer that combines small and large patches for stronger feature representation, improving performance over existing models \[[2](http://arxiv.org/abs/2103.14899)\]. 

Token pruning methods such as Evo-ViT and Patch Slimming have also been explored to reduce computational costs. Evo-ViT employs a slow-fast token evolution strategy to maintain spatial structure while reducing computation, achieving over 60% throughput improvement \[[14](http://arxiv.org/abs/2108.01390)\]. Patch Slimming discards useless patches in a top-down manner, reducing FLOPs by over 45% with only a minor accuracy drop \[[12](http://arxiv.org/abs/2106.02852)\]. 

Quantization techniques have been widely studied to reduce the computational burden of ViTs. Auto-ViT-Acc introduces an FPGA-aware quantization framework that improves Top-1 accuracy by 0.47%–1.36% compared to 32-bit floating-point baselines \[[3](http://arxiv.org/abs/2208.05163)\]. Trio-ViT focuses on quantization and acceleration for efficient ViTs, eliminating the problematic Softmax and integrating linear attention, achieving up to 7.3× speedup \[[16](http://arxiv.org/abs/2405.03882)\]. 

Moreover, hardware-specific optimizations have been proposed to improve ViT acceleration. ME-ViT introduces a single-load policy to minimize memory traffic, achieving up to 17.89× improvement in memory bandwidth \[[9](http://arxiv.org/abs/2402.09709)\]. ViTA is a configurable accelerator targeting edge devices, achieving nearly 90% hardware utilization efficiency \[[10](http://arxiv.org/abs/2302.09108)\].

FPGA-based ViT acceleration has seen significant advancements aimed at overcoming the computational and memory bottlenecks inherent in ViT models. Researchers have focused on optimizing hardware efficiency through techniques such as token pruning, quantization, and memory-efficient architectures. For instance, HeatViT introduces an image-adaptive token pruning framework that dynamically identifies and consolidates non-informative tokens, achieving up to 65.3% computation reduction while maintaining high accuracy \[[1](http://arxiv.org/abs/2211.08110)\]. Similarly, ME-ViT minimizes memory traffic by employing a single-load policy and a memory-efficient processing element (ME-PE), resulting in up to 17.89x improvement in memory bandwidth and 2.16x improvement in throughput per DSP \[[3](http://arxiv.org/abs/2208.05163)\]. Another approach, ViTA, targets resource-constrained edge devices by avoiding repeated off-chip memory accesses and achieving nearly 90% hardware utilization efficiency \[[10](http://arxiv.org/abs/2302.09108)\]. Additionally, FPGA-aware quantization methods, such as those proposed in \[[3](http://arxiv.org/abs/2208.05163)\], have shown improvements in frame rate with minimal accuracy loss. These approaches collectively highlight the importance of hardware-aware design in enabling efficient ViT inference on FPGAs.

### <a id='category-token-pruning-techniques-for-vit-efficiency'></a>Token Pruning Techniques for ViT Efficiency: 6 papers found.
The category "Token Pruning Techniques for ViT Efficiency" focuses on reducing computational overhead in Vision Transformers (ViTs) through token pruning and reorganization strategies. These techniques aim to eliminate redundant or less informative tokens during the forward pass, thereby improving inference speed and resource utilization without significant accuracy loss. For instance, EViT reorganizes image tokens by preserving attentive tokens and fusing inattentive ones, achieving a 50% speedup in inference while maintaining 99.7% accuracy \[[4](http://arxiv.org/abs/2202.07800)\]. Similarly, ViTCoD introduces an algorithm and accelerator co-design framework that prunes attention maps by up to 90% without severe accuracy degradation, achieving speedups of up to 235.3× over general computing platforms \[[6](http://arxiv.org/abs/2210.09573)\]. The computation-aware soft pruning framework proposed in another work dynamically selects tokens based on attention mechanisms, integrating less informative tokens into a package for subsequent calculations, which reduces computation costs while maintaining performance \[[11](http://arxiv.org/abs/2112.13890)\]. Additionally, Evo-ViT employs a slow-fast token evolution approach, updating informative and uninformative tokens separately to maintain spatial structure and information flow, achieving over 60% throughput improvement with minimal accuracy loss \[[15](http://arxiv.org/abs/2103.15358)\]. Lastly, the Dynamic Transformer automatically adjusts the number of tokens per input image, reducing redundant computations by reusing features and relationships across components \[[17](http://arxiv.org/abs/2105.15075)\]. These approaches collectively highlight the importance of token pruning in enhancing ViT efficiency for real-world deployment.
