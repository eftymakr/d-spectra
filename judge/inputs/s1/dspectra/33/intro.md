## Related Works

Rehearsal-based methods have been widely studied in continual learning (CL) to mitigate catastrophic forgetting, where models forget previously learned knowledge when adapting to new tasks \[[1](http://arxiv.org/abs/2203.17269)\]. These methods typically store a subset of past data in a replay buffer and train the model on both new and past data simultaneously \[[2](http://arxiv.org/abs/2111.11210)\]. While concurrent rehearsal has shown effectiveness, recent work suggests that sequential rehearsal—where new data is trained first, followed by revisiting past data—may offer additional benefits, particularly when tasks are less similar \[[3](http://arxiv.org/abs/1805.12369)\]. This idea is inspired by human learning, where revisiting tasks sequentially helps reinforce memory \[[4](http://arxiv.org/abs/2104.07446)\].

Several studies have explored the role of rehearsal in CL. For instance, \[[5](http://arxiv.org/abs/2302.05836)\] highlights the limitations of rehearsal, noting that it may lead to overfitting on stored samples and hinder generalization. In contrast, \[[6](http://arxiv.org/abs/2103.07492)\] proposes a gradient coreset-based replay buffer selection strategy that improves performance over existing methods by maintaining a representative subset of past data. Similarly, \[[7](http://arxiv.org/abs/1812.02464)\] introduces a memory-efficient approach that uses a dual memory system and pseudo-rehearsal to avoid catastrophic forgetting in reinforcement learning. These methods emphasize the importance of carefully selecting which data to store and when to revisit it.

Theoretical analysis of rehearsal strategies has also gained traction. \[[8](http://arxiv.org/abs/1902.10486)\] provides a theoretical framework for understanding forgetting and generalization in overparameterized linear models, showing that sequential rehearsal outperforms concurrent rehearsal when tasks are less similar. This aligns with empirical findings from \[[9](http://arxiv.org/abs/2307.02251)\], which demonstrates that sequential rehearsal can improve performance on tasks with varying similarity. Building on these insights, \[[10](http://arxiv.org/abs/2205.07390)\] proposes a hybrid rehearsal strategy that combines concurrent and sequential approaches, training similar tasks together and revisiting dissimilar tasks sequentially. This hybrid method has been shown to outperform standard concurrent rehearsal in both theoretical and experimental settings \[[11](http://arxiv.org/abs/2308.13646)\].

In addition to rehearsal, other techniques such as knowledge distillation and parameter regularization have been explored to address catastrophic forgetting \[[12](http://arxiv.org/abs/2303.11165)\]. For example, \[[13](http://arxiv.org/abs/2305.00316)\] shows that vanilla L2 regularization outperforms EWC and feature distillation in rehearsal-free settings. However, these methods often require additional computational resources or assumptions about task boundaries \[[14](http://arxiv.org/abs/1811.11682)\]. In contrast, \[[15](http://arxiv.org/abs/2112.08654)\] proposes a method that learns to dynamically prompt a pre-trained model without relying on task identities, offering a more efficient alternative.
