## Related Works

Deploying large language models (LLMs) on edge devices presents significant challenges due to the limited storage, memory, and power available on such platforms \[[24](http://arxiv.org/abs/2211.10438)\]. Prior work has explored various techniques to address these limitations, including model compression, quantization, and efficient inference strategies. For instance, **Quantization and Training of Neural Networks for Efficient Integer-Arithmetic-Only Inference** \[[7](http://arxiv.org/abs/1712.05877)\] proposes a quantization scheme that allows inference to be carried out using integer-only arithmetic, improving the tradeoff between accuracy and on-device latency. This work is foundational to many subsequent efforts in reducing the computational footprint of LLMs for edge deployment.

Similarly, **LLM.int8(): 8-bit Matrix Multiplication for Transformers at Scale** \[[12](http://arxiv.org/abs/2208.07339)\] introduces a method for performing inference with 8-bit matrix multiplication, significantly reducing memory usage while maintaining performance. This technique has been widely adopted in practical deployments of large models on edge devices. **AWQ: Activation-aware Weight Quantization for On-Device LLM Compression and Acceleration** \[[16](http://arxiv.org/abs/2306.00978)\] further advances this field by proposing an activation-aware quantization method that preserves model performance while reducing size and improving inference speed. These methods are critical for enabling efficient LLM inference on resource-constrained devices.

Efficient inference is also a focus of **LLM in a flash: Efficient Large Language Model Inference with Limited Memory** \[[6](http://arxiv.org/abs/2312.11514)\], which stores model parameters in flash memory and brings them on demand to DRAM, enabling the execution of models up to twice the size of available DRAM. This approach is particularly relevant for edge devices with limited memory capacity. Additionally, **Efficient Memory Management for Large Language Model Serving with PagedAttention** \[[3](http://arxiv.org/abs/2309.06180)\] introduces a novel attention mechanism inspired by virtual memory techniques, enabling near-zero waste in KV cache memory and flexible sharing across requests, which is essential for high-throughput serving on edge devices.
