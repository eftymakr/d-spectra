## Related Works

Deploying large language models (LLMs) on edge devices presents significant challenges due to the limited storage, memory, and power available on such platforms \[[24](http://arxiv.org/abs/2211.10438)\]. For instance, **Quantization and Training of Neural Networks for Efficient Integer-Arithmetic-Only Inference** \[[7](http://arxiv.org/abs/1712.05877)\] proposes a quantization scheme that allows inference to be carried out using integer-only arithmetic, improving the tradeoff between accuracy and on-device latency. This work is foundational to many subsequent efforts in reducing the computational footprint of LLMs for edge deployment.

Similarly, **LLM.int8(): 8-bit Matrix Multiplication for Transformers at Scale** \[[12](http://arxiv.org/abs/2208.07339)\] introduces a method for performing inference with 8-bit matrix multiplication, significantly reducing memory usage while maintaining performance. ### <a id='category-model-compression-techniques'></a>Model Compression Techniques: 1 papers found.
Model compression techniques are critical for deploying neural network models on resource-constrained devices such as mobile phones and edge devices, where computation resources and power budgets are limited \[[1](http://arxiv.org/abs/1804.07461)\]. Traditional methods rely on hand-crafted features and require domain expertise to navigate the trade-offs between model size, speed, and accuracy, often leading to sub-optimal results and significant manual effort \[[1](http://arxiv.org/abs/1804.07461)\]. To address these limitations, automated approaches like AutoML for Model Compression (AMC) have been proposed, leveraging reinforcement learning to efficiently explore the design space and achieve state-of-the-art results without human intervention \[[1](http://arxiv.org/abs/1804.07461)\]. For instance, under a 4× FLOPs reduction, AMC improved accuracy by 2.7% compared to hand-crafted methods for VGG-16 on ImageNet \[[1](http://arxiv.org/abs/1804.07461)\]. Additionally, AMC has been successfully applied to MobileNet-V1, achieving a speedup of 1.53× on a GPU and 1.95× on an Android phone with minimal accuracy loss \[[1](http://arxiv.org/abs/1804.07461)\]. These advancements highlight the growing importance of automated, efficient model compression techniques in enabling practical deployment of complex models on edge devices.

### <a id='category-memory-management-in-llm-inference'></a>Memory Management in LLM Inference: 2 papers found.
Memory management in large language model (LLM) inference remains a critical challenge, particularly due to the dynamic and often substantial memory requirements of key-value (KV) caches \[[3](http://arxiv.org/abs/2309.06180)\]. Traditional approaches struggle with memory fragmentation and redundant duplication, which limit batch sizes and overall throughput \[[3](http://arxiv.org/abs/2309.06180)\]. To address these issues, PagedAttention was introduced, drawing inspiration from virtual memory and paging techniques, enabling near-zero memory waste and flexible KV cache sharing \[[3](http://arxiv.org/abs/2309.06180)\]. Additionally, methods such as "windowing" and "row-column bundling" have been proposed to optimize data transfer and access patterns, allowing models up to twice the size of available DRAM to be run efficiently \[[6](http://arxiv.org/abs/2312.11514)\]. These techniques are hardware-informed, leveraging the characteristics of flash memory to enhance inference speed and reduce energy consumption \[[6](http://arxiv.org/abs/2312.11514)\]. Together, these approaches represent significant advancements in managing memory constraints during LLM inference.
