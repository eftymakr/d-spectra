## Related Works

Human pose estimation has been a focal point in computer vision, particularly for 3D reconstruction from 2D inputs. Early methods relied on graphical models and hand-crafted features, but recent advances have shifted toward deep learning approaches that leverage convolutional networks and attention mechanisms \[[1](http://arxiv.org/abs/1708.01101)\]. For instance, Convolutional Pose Machines (CPM) introduced a sequential prediction framework that implicitly models long-range dependencies in structured prediction tasks like articulated pose estimation \[[21](http://arxiv.org/abs/1602.00134)\]. This approach avoids explicit graphical model inference by using convolutional networks to refine part locations iteratively.

The challenge of modeling long-range dependencies between body joints has been addressed by various architectures. For example, the Joint Training of a Convolutional Network and a Graphical Model for Human Pose Estimation proposed a hybrid architecture that combines deep convolutional networks with Markov Random Fields to exploit structural domain constraints \[[2](http://arxiv.org/abs/1406.2984)\]. Similarly, the work on Learning Feature Pyramids for Human Pose Estimation introduced Pyramid Residual Modules (PRMs) to enhance scale invariance in deep convolutional neural networks \[[1](http://arxiv.org/abs/1708.01101)\]. These modules learn convolutional filters on various scales of input features, improving the model's ability to handle scale variations.

Another approach, DeepPose, proposed a cascade of deep neural network regressors to achieve high precision in pose estimation \[[8](http://arxiv.org/abs/1312.4659)\]. This method capitalizes on the holistic reasoning capability of deep learning, leading to state-of-the-art performance on multiple benchmarks. The work on Efficient object localization using Convolutional Networks also introduced a position refinement model to improve joint location estimation \[[3](http://arxiv.org/abs/1411.4280)\]. This refinement model is trained in cascade with a state-of-the-art ConvNet to achieve higher accuracy.

In the realm of 3D human pose estimation, several methods have been proposed to address the depth ambiguity and self-occlusion issues. For example, the paper on Reconstructing 3D Human Pose from 2D Image Landmarks proposed an activity-independent method that leverages a large motion capture corpus as a proxy for visual memory \[[4](https://www.semanticscholar.org/paper/ec3eddefc3c658ed8de35ed18bfa7e6ce675019a)\]. [Snippet]: «Regression based methods are not performing as well as detection based methods for human pose estimation. A central problem is that the structural information in the pose is not well exploited in the previous regression methods. In this work, we propose a structure-aware regression approach. It adopts a reparameterized pose representation using bones instead of joints. It exploits the joint connection structure to define a compositional loss function that encodes the long range interactions in the pose. It is simple, effective, and general for both 2D and 3D pose estimation in a unified setting. Comprehensive evaluation validates the effectiveness of our approach. It significantly advances the state-of-the-art on Human3.6M \[[20](http://arxiv.org/abs/2109.02303)\] and is competitive with state-of-the-art results on MPII \[[3](http://arxiv.org/abs/1411.4280)\].»
