## Related Works

Open-vocabulary object detection (OVD) has gained significant attention in recent years due to its ability to detect objects beyond the pre-defined set of categories in training data. This capability is crucial for real-world applications where the set of object categories may be unknown or dynamically changing \[[1](http://arxiv.org/abs/2211.14843)\]. Early approaches to OVD relied on zero-shot learning and weakly supervised methods, which often suffered from poor performance due to the lack of fine-grained object-language alignments and the reliance on costly annotations \[[2](http://arxiv.org/abs/2011.10678)\]. These methods typically used pre-trained vision-language models (VLMs) to generate class embeddings for novel categories, but they struggled with localization accuracy and generalization \[[3](http://arxiv.org/abs/2203.14940)\].

More recent work has focused on leveraging large-scale image-text pairs to train detectors that can generalize to novel categories without requiring additional bounding box annotations \[[4](http://arxiv.org/abs/2306.05493)\]. For instance, VLDet \[[1](http://arxiv.org/abs/2211.14843)\] proposes a framework that directly learns from image-text pairs by formulating object-language alignment as a set matching problem between image region features and word embeddings. This approach enables the model to detect novel categories with high accuracy, achieving 32.0% mAP on COCO and 21.7% mask mAP on LVIS \[[1](http://arxiv.org/abs/2211.14843)\]. Similarly, the work in \[[5](http://arxiv.org/abs/1411.4952)\] introduces a method that uses pseudo bounding-box labels generated from image-caption pairs to train detectors on a broader set of categories, outperforming existing methods by 8% AP on COCO novel categories \[[5](http://arxiv.org/abs/1411.4952)\].

Another line of research explores the use of vision-language pre-training to enable open-vocabulary detection. For example, \[[6](http://arxiv.org/abs/2111.09452)\] introduces a method that uses CLIP to generate pseudo labels for object detection, allowing the model to generalize to unseen categories without requiring additional annotations \[[6](http://arxiv.org/abs/2111.09452)\]. The work in \[[7](http://arxiv.org/abs/2211.12914)\] further improves upon this by introducing a two-stage open-vocabulary object detector that uses a pre-trained vision-language model to classify object proposals \[[7](http://arxiv.org/abs/2211.12914)\]. This approach achieves superior performance, with PromptDet showing significant improvements over existing methods with fewer additional training images and zero manual annotations \[[7](http://arxiv.org/abs/2211.12914)\].

Additionally, the use of contrastive learning and region prompting has been explored to bridge the gap between object and image-level representations \[[8](http://arxiv.org/abs/2207.08954)\]. The CORA framework, for instance, adapts CLIP for open-vocabulary detection by using region prompting and anchor pre-matching to improve localization accuracy \[[8](http://arxiv.org/abs/2207.08954)\]. This approach achieves 41.7 AP50 on novel classes on the COCO benchmark, outperforming previous state-of-the-art methods \[[8](http://arxiv.org/abs/2207.08954)\].
