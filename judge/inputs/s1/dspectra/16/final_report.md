## Related Works

Open-vocabulary object detection (OVD) has gained significant attention in recent years due to its ability to detect objects beyond the pre-defined set of categories in training data. This capability is crucial for real-world applications where the set of object categories may be unknown or dynamically changing \[[1](http://arxiv.org/abs/2211.14843)\]. Early approaches to OVD relied on zero-shot learning and weakly supervised methods, which often suffered from poor performance due to the lack of fine-grained object-language alignments and the reliance on costly annotations \[[2](http://arxiv.org/abs/2011.10678)\]. These methods typically used pre-trained vision-language models (VLMs) to generate class embeddings for novel categories, but they struggled with localization accuracy and generalization \[[3](http://arxiv.org/abs/2203.14940)\].

More recent work has focused on leveraging large-scale image-text pairs to train detectors that can generalize to novel categories without requiring additional bounding box annotations \[[4](http://arxiv.org/abs/2306.05493)\]. For instance, VLDet \[[1](http://arxiv.org/abs/2211.14843)\] proposes a framework that directly learns from image-text pairs by formulating object-language alignment as a set matching problem between image region features and word embeddings. This approach enables the model to detect novel categories with high accuracy, achieving 32.0% mAP on COCO and 21.7% mask mAP on LVIS \[[1](http://arxiv.org/abs/2211.14843)\]. Similarly, the work in \[[5](http://arxiv.org/abs/1411.4952)\] introduces a method that uses pseudo bounding-box labels generated from image-caption pairs to train detectors on a broader set of categories, outperforming existing methods by 8% AP on COCO novel categories \[[5](http://arxiv.org/abs/1411.4952)\].

Another line of research explores the use of vision-language pre-training to enable open-vocabulary detection. For example, \[[6](http://arxiv.org/abs/2111.09452)\] introduces a method that uses CLIP to generate pseudo labels for object detection, allowing the model to generalize to unseen categories without requiring additional annotations \[[6](http://arxiv.org/abs/2111.09452)\]. The work in \[[7](http://arxiv.org/abs/2211.12914)\] further improves upon this by introducing a two-stage open-vocabulary object detector that uses a pre-trained vision-language model to classify object proposals \[[7](http://arxiv.org/abs/2211.12914)\]. This approach achieves superior performance, with PromptDet showing significant improvements over existing methods with fewer additional training images and zero manual annotations \[[7](http://arxiv.org/abs/2211.12914)\].

Additionally, the use of contrastive learning and region prompting has been explored to bridge the gap between object and image-level representations \[[8](http://arxiv.org/abs/2207.08954)\]. The CORA framework, for instance, adapts CLIP for open-vocabulary detection by using region prompting and anchor pre-matching to improve localization accuracy \[[8](http://arxiv.org/abs/2207.08954)\]. This approach achieves 41.7 AP50 on novel classes on the COCO benchmark, outperforming previous state-of-the-art methods \[[8](http://arxiv.org/abs/2207.08954)\].

### <a id='category-open-vocabulary-object-detection-frameworks'></a>Open-vocabulary object detection frameworks: 9 papers found.
Open-vocabulary object detection (OVD) has emerged as a critical research direction, enabling detectors to recognize and localize objects from novel categories without requiring extensive labeled data \[[1](http://arxiv.org/abs/2211.14843)\]. Traditional methods are constrained by fixed vocabularies and rely on costly bounding box annotations for new categories \[[2](http://arxiv.org/abs/2011.10678)\]. To address these limitations, recent works have explored leveraging natural language supervision, such as image-text pairs, to expand the detection vocabulary \[[1](http://arxiv.org/abs/2211.14843)\]. For instance, VLDet directly learns from image-text pairs by formulating object-language alignment as a set matching problem, achieving competitive performance on COCO and LVIS benchmarks \[[1](http://arxiv.org/abs/2211.14843)\]. Similarly, OV-DETR extends DETR to support open-vocabulary detection by conditioning the Transformer decoder on pre-trained vision-language models like CLIP, allowing detection based on natural language or exemplar images \[[8](http://arxiv.org/abs/2207.08954)\]. Other approaches, such as PromptDet, use regional prompt learning to align visual and textual embeddings, enabling zero manual annotations for training \[[4](http://arxiv.org/abs/2306.05493)\]. Additionally, CORA introduces region prompting and anchor pre-matching to bridge the gap between image-level and region-level representations, achieving state-of-the-art results on COVD benchmarks \[[5](http://arxiv.org/abs/1411.4952)\]. These methods highlight the growing trend of integrating vision-language models with detection frameworks to enhance generalization and reduce reliance on manual annotations \[[1](http://arxiv.org/abs/2211.14843)\]\[[4](http://arxiv.org/abs/2306.05493)\]\[[5](http://arxiv.org/abs/1411.4952)\].

### <a id='category-vision-language-model-utilization-in-detection'></a>Vision-language model utilization in detection: 5 papers found.
The category "Vision-language model utilization in detection" explores how vision-language pre-trained models are leveraged to enhance open-vocabulary object detection, enabling models to detect objects based on arbitrary text inputs without requiring explicit training on those classes \[[3](http://arxiv.org/abs/2203.14940)\]. This is achieved by generating class text embeddings through prompts fed into the text encoder of a pre-trained vision-language model, which are then used as region classifiers to supervise detector training \[[3](http://arxiv.org/abs/2203.14940)\]. Several approaches have been proposed to improve this process, such as DetPro, which introduces continuous prompt representations and incorporates background interpretation and context grading schemes to refine detection performance \[[3](http://arxiv.org/abs/2203.14940)\]. Additionally, methods like ViLD utilize vision-language knowledge distillation, where a pre-trained open-vocabulary image classification model (teacher) is used to align region embeddings of detected boxes with text and image embeddings, improving detection accuracy on benchmarks like LVIS and enabling transfer learning across datasets \[[4](http://arxiv.org/abs/2306.05493)\]. Other works, such as the OVAD benchmark, focus on attribute-level detection, creating annotated datasets to evaluate vision-language models' ability to infer object attributes from text prompts \[[2](http://arxiv.org/abs/2011.10678)\]. Furthermore, pseudo-label generation methods leverage vision-language models to localize and classify objects in unlabeled images, effectively creating training data for open-vocabulary and semi-supervised detection tasks \[[3](http://arxiv.org/abs/2203.14940)\]. These approaches highlight the growing importance of vision-language models in enabling flexible, zero-shot, and open-world object detection scenarios, with ongoing efforts to improve robustness, scalability, and generalization across diverse datasets and tasks \[[3](http://arxiv.org/abs/2203.14940)\]\[[4](http://arxiv.org/abs/2306.05493)\]\[[2](http://arxiv.org/abs/2011.10678)\].
