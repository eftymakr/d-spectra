## Related Works

Semi-supervised learning (SSL) has emerged as a powerful paradigm for improving model performance by leveraging unlabeled data when labeled data is scarce \[[1](http://arxiv.org/abs/2308.13168)\]. However, conventional SSL methods typically assume that labeled and unlabeled data share the same class distribution, an assumption that is often violated in practice \[[2](http://arxiv.org/abs/2205.07246)\]. Unlabeled data may contain out-of-distribution (OOD) samples, referred to as outliers, which can significantly degrade SSL performance \[[3](http://arxiv.org/abs/2109.00650)\]. These outliers are typically treated as noise, leading to suboptimal results \[[4](http://arxiv.org/abs/2203.02261)\]. 

To address this issue, several works have explored open-set semi-supervised learning (open-set SSL), where the goal is to classify inliers while detecting outliers \[[5](http://arxiv.org/abs/2007.11330)\]. For example, IOMatch proposes a framework that jointly utilizes inliers and outliers by treating all outliers as a single new class and optimizing an open-set classifier with all unlabeled samples \[[6](http://arxiv.org/abs/2311.10572)\]. Similarly, OpenMatch unifies FixMatch with novelty detection using one-vs-all (OVA) classifiers to detect outliers \[[7](http://arxiv.org/abs/2105.14148)\]. The OVA classifier outputs confidence scores, which are used to threshold outlier detection \[[8](http://arxiv.org/abs/2007.08844)\]. 

Another approach, FreeMatch, introduces a self-adaptive thresholding mechanism for pseudo-labeling, which adjusts the confidence threshold based on the model's learning status \[[9](http://arxiv.org/abs/2107.08943)\]. This helps in effectively utilizing unlabeled data even when labeled data is extremely scarce \[[10](http://arxiv.org/abs/2102.09559)\]. In contrast, Dash dynamically adjusts the threshold for unlabeled data selection during training, ensuring only relevant samples are used for training \[[11](https://www.semanticscholar.org/paper/f3df804a7eef204b0c4fc4b81166dec9b4abc073)\]. 

Additionally, methods like CCSSL have been proposed to improve pseudo-label quality and enhance robustness in real-world settings by separately handling in-distribution and out-of-distribution data \[[12](http://arxiv.org/abs/2101.06329)\]. This is particularly important in scenarios with extensive out-of-distribution data, where pseudo-label-based methods suffer from confirmation bias \[[13](http://arxiv.org/abs/2303.11066)\]. 

Furthermore, the problem of class imbalance in SSL has also been addressed. For instance, CReST introduces a class-rebalancing self-training framework that iteratively expands the labeled set with pseudo-labeled samples from the unlabeled set, prioritizing minority classes \[[14](http://arxiv.org/abs/2001.07685)\]. Similarly, DARP refines pseudo-labels by aligning the distribution of pseudo-labels with the true distribution, improving generalization on imbalanced datasets \[[15](http://arxiv.org/abs/2108.05617)\].
