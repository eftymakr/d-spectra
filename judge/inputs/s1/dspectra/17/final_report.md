## Related Works

Semi-supervised learning (SSL) has emerged as a powerful paradigm for improving model performance by leveraging unlabeled data when labeled data is scarce \[[1](http://arxiv.org/abs/2308.13168)\]. However, conventional SSL methods typically assume that labeled and unlabeled data share the same class distribution, an assumption that is often violated in practice \[[2](http://arxiv.org/abs/2205.07246)\]. Unlabeled data may contain out-of-distribution (OOD) samples, referred to as outliers, which can significantly degrade SSL performance \[[3](http://arxiv.org/abs/2109.00650)\]. These outliers are typically treated as noise, leading to suboptimal results \[[4](http://arxiv.org/abs/2203.02261)\]. 

To address this issue, several works have explored open-set semi-supervised learning (open-set SSL), where the goal is to classify inliers while detecting outliers \[[5](http://arxiv.org/abs/2007.11330)\]. For example, IOMatch proposes a framework that jointly utilizes inliers and outliers by treating all outliers as a single new class and optimizing an open-set classifier with all unlabeled samples \[[6](http://arxiv.org/abs/2311.10572)\]. Similarly, OpenMatch unifies FixMatch with novelty detection using one-vs-all (OVA) classifiers to detect outliers \[[7](http://arxiv.org/abs/2105.14148)\]. The OVA classifier outputs confidence scores, which are used to threshold outlier detection \[[8](http://arxiv.org/abs/2007.08844)\]. 

Another approach, FreeMatch, introduces a self-adaptive thresholding mechanism for pseudo-labeling, which adjusts the confidence threshold based on the model's learning status \[[9](http://arxiv.org/abs/2107.08943)\]. This helps in effectively utilizing unlabeled data even when labeled data is extremely scarce \[[10](http://arxiv.org/abs/2102.09559)\]. In contrast, Dash dynamically adjusts the threshold for unlabeled data selection during training, ensuring only relevant samples are used for training \[[11](https://www.semanticscholar.org/paper/f3df804a7eef204b0c4fc4b81166dec9b4abc073)\]. 

Additionally, methods like CCSSL have been proposed to improve pseudo-label quality and enhance robustness in real-world settings by separately handling in-distribution and out-of-distribution data \[[12](http://arxiv.org/abs/2101.06329)\]. This is particularly important in scenarios with extensive out-of-distribution data, where pseudo-label-based methods suffer from confirmation bias \[[13](http://arxiv.org/abs/2303.11066)\]. 

Furthermore, the problem of class imbalance in SSL has also been addressed. For instance, CReST introduces a class-rebalancing self-training framework that iteratively expands the labeled set with pseudo-labeled samples from the unlabeled set, prioritizing minority classes \[[14](http://arxiv.org/abs/2001.07685)\]. Similarly, DARP refines pseudo-labels by aligning the distribution of pseudo-labels with the true distribution, improving generalization on imbalanced datasets \[[15](http://arxiv.org/abs/2108.05617)\].

### <a id='category-open-set-ssl-frameworks'></a>Open-Set SSL Frameworks: 8 papers found.
Open-set semi-supervised learning (Open-set SSL) addresses the challenge where unlabeled data may contain outliers from unseen classes, which traditional SSL methods assume to be absent \[[1](http://arxiv.org/abs/2308.13168)\]. Existing approaches typically focus on outlier detection before training, but this can lead to performance degradation when labeled data is scarce, as unreliable detectors may exclude valuable inliers \[[1](http://arxiv.org/abs/2308.13168)\]. To mitigate this, several frameworks have been proposed. For instance, IOMatch jointly utilizes inliers and outliers by introducing a multi-binary classifier alongside a closed-set classifier, treating all outliers as a single class, and optimizing an open-set classifier with both types of samples \[[1](http://arxiv.org/abs/2308.13168)\]. Similarly, OpenMatch integrates novelty detection with FixMatch, using one-vs-all classifiers to estimate inlier confidence scores and detect outliers, while introducing a soft-consistency regularization loss to enhance outlier detection \[[4](http://arxiv.org/abs/2203.02261)\]. Another approach, SSB, leverages high-confidence pseudo-labeled data, regardless of whether they are inliers or outliers, and employs non-linear transformations to separate inlier and outlier features in a multi-task learning framework, improving both classification and detection performance \[[3](http://arxiv.org/abs/2109.00650)\]. OpenCoS utilizes self-supervised contrastive learning to identify out-of-class samples in open-set unlabeled data and applies one-hot pseudo-labels and soft-labels for inlier and outlier data, respectively, to improve SSL robustness \[[5](http://arxiv.org/abs/2007.11330)\]. SAFE-R-STUDENT introduces a teacher-student framework with a discrepancy-based scoring method and calibration losses to handle unseen-class data, enhancing seen-class classification performance \[[6](http://arxiv.org/abs/2311.10572)\]. ANEDL employs evidential deep learning to quantify uncertainty and introduces an adaptive negative optimization strategy to better distinguish between inliers and outliers \[[7](http://arxiv.org/abs/2105.14148)\]. These methods collectively highlight the importance of robust outlier detection and the integration of uncertainty quantification in open-set SSL frameworks \[[1](http://arxiv.org/abs/2308.13168)\]\[[3](http://arxiv.org/abs/2109.00650)\]\[[4](http://arxiv.org/abs/2203.02261)\]\[[5](http://arxiv.org/abs/2007.11330)\]\[[6](http://arxiv.org/abs/2311.10572)\]\[[7](http://arxiv.org/abs/2105.14148)\].

### <a id='category-robustness-to-class-imbalance'></a>Robustness to Class Imbalance: 3 papers found.
The category "Robustness to Class Imbalance" highlights the challenges and solutions in semi-supervised learning (SSL) when class distributions are imbalanced. Existing SSL algorithms often assume balanced class distributions, leading to biased pseudo-labels that favor majority classes and degrade performance on minority classes \[[8](http://arxiv.org/abs/2007.08844)\]. To address this, DARP proposes a convex optimization approach to refine pseudo-labels and improve generalization under imbalanced conditions \[[8](http://arxiv.org/abs/2007.08844)\]. Similarly, CReST introduces a framework that iteratively expands the labeled set with pseudolabeled samples, prioritizing minority classes to enhance model performance \[[10](http://arxiv.org/abs/2102.09559)\]. Additionally, CoSSL introduces a co-learning framework that decouples representation and classifier learning, incorporating Tail-class Feature Enhancement (TFE) to better handle class imbalance \[[19](http://arxiv.org/abs/2112.04564)\]. These approaches collectively demonstrate the importance of addressing class imbalance in SSL, with varying strategies to improve robustness and performance on minority classes. The evaluation of these methods often focuses on shifted test distributions, reflecting real-world scenarios where class distributions may differ between training and testing \[[19](http://arxiv.org/abs/2112.04564)\]. These studies underscore the need for more robust SSL methods that can effectively handle class imbalance, a critical yet underexplored area in the field \[[8](http://arxiv.org/abs/2007.08844)\]\[[10](http://arxiv.org/abs/2102.09559)\]\[[19](http://arxiv.org/abs/2112.04564)\].

Whilst demonstrating impressive performance boost, existing SSL methods artificially assume that small labelled data and large unlabelled data are drawn from the same class distribution. In a more realistic scenario with class distribution mismatch between the two sets, they often suffer severe performance degradation due to error propagation introduced by irrelevant unlabelled samples. Our work addresses this under-studied and realistic SSL problem by a novel algorithm named Uncertainty-Aware Self-Distillation (UASD). Specifically, UASD produces soft targets that avoid catastrophic error propagation, and empower learning effectively from unconstrained unlabelled data with out-of-distribution (OOD) samples. This is based on joint Self-Distillation and OOD filtering in a unified formulation. Without bells and whistles, UASD significantly outperforms six state-of-the-art methods in more realistic SSL under class distribution mismatch on three popular image classification datasets: CIFAR10, CIFAR100, and TinyImageNet.»
