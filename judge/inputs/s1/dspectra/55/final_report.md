## Related Works

Conversational Recommender Systems (CRSs) have emerged as a promising approach to address the limitations of traditional static recommendation models by enabling dynamic, multi-turn interactions with users to better capture their preferences \[[1](http://arxiv.org/abs/2101.09459)\]. Unlike static systems that rely solely on historical data, CRSs leverage natural language interactions to explicitly elicit user preferences, leading to more accurate and personalized recommendations \[[1](http://arxiv.org/abs/2101.09459)\]. However, developing effective CRSs remains challenging due to the need for sophisticated dialogue understanding, efficient exploration-exploitation strategies, and robust evaluation methods \[[1](http://arxiv.org/abs/2101.09459)\].

Several studies have explored the use of simulated users to evaluate and improve CRSs. For instance, \[[6](http://arxiv.org/abs/2006.08732)\] proposes a user simulator, ConvSim, that generates feedback for system responses and clarifying questions, enabling multi-turn interactions with mixed-initiative conversational search systems. The results show that incorporating user feedback significantly improves retrieval performance, with a 16% increase in nDCG@3 \[[6](http://arxiv.org/abs/2006.08732)\]. Similarly, \[[9](http://arxiv.org/abs/2204.08046)\] introduces a conversational user simulator, USi, that automatically answers clarifying questions based on an information need description, demonstrating that simulated user responses are comparable to human-generated ones \[[9](http://arxiv.org/abs/2204.08046)\]. These works highlight the importance of user feedback in improving the performance of CRSs.

To facilitate the development of CRSs, several frameworks have been proposed to integrate dialogue and recommendation modules. \[[3](http://arxiv.org/abs/2002.09102)\] introduces the Estimation-Action-Reflection (EAR) framework, which consists of three stages: Estimation (predicting user preferences), Action (deciding whether to ask for attributes or recommend items), and Reflection (updating the model based on user feedback). This approach reduces the number of conversation turns and improves recommendation accuracy \[[3](http://arxiv.org/abs/2002.09102)\]. \[[11](http://arxiv.org/abs/2007.00194)\] proposes Conversational Path Reasoning (CPR), which models conversational recommendation as an interactive path reasoning problem on a graph, allowing the system to explicitly use user feedback to prune irrelevant attributes and improve recommendation accuracy \[[11](http://arxiv.org/abs/2007.00194)\].

The integration of knowledge graphs (KGs) has also been explored to enhance the semantic understanding of user preferences in CRSs. \[[4](http://arxiv.org/abs/2007.04032)\] incorporates both word-oriented and entity-oriented KGs to align semantic spaces and improve the accuracy of recommendations and dialogues. The results show that KG-enhanced models outperform baseline approaches in both tasks \[[4](http://arxiv.org/abs/2007.04032)\]. \[[5](http://arxiv.org/abs/2206.09363)\] further proposes a unified CRS model, UniCRS, based on knowledge-enhanced prompt learning, which integrates recommendation and conversation modules using a fixed pre-trained language model (PLM) \[[5](http://arxiv.org/abs/2206.09363)\].

[Snippet]: «This research aims to explore various methods for assessing user feedback in mixed-initiative conversational search (CS ) systems. While CS systems enjoy profuse advancements across multiple aspects, recent research fails to successfully incorporate feedback from the users. One of the main reasons for that is the lack of system-user conversational interaction data. To this end, we propose a user simulator-based framework for multi-turn interactions with a variety of mixed-initiative CS systems. Specifically, we develop a user simulator, dubbed ConvSim, that, once initialized with an information need description, is capable of providing feedback to system's responses, as well as answering potential clarifying questions. Moreover, we observe consistent improvements as the number of feedback rounds increases (35% relative improvement in terms of nDCG@3 after three rounds). This points to a research gap in the development of specific feedback processing modules and opens a potential for significant advancements in CS. To support further research in the topic, we release over 30 000 transcripts of system-simulator interactions based on well-established CS datasets.»

### <a id='category-dialogue-and-recommendation-integration-frameworks'></a>Dialogue and Recommendation Integration Frameworks: 5 papers found.
Conversational recommender systems (CRSs) have been extensively studied, focusing on integrating dialogue and recommendation modules to better capture user preferences through multi-turn interactions \[[3](http://arxiv.org/abs/2002.09102)\]. Early approaches primarily addressed individual decision-making problems, such as when to recommend items or what attributes to ask, often using reinforcement learning (RL) to learn conversational policies \[[8](http://arxiv.org/abs/2105.09710)\]. However, these methods typically treated recommendation and dialogue components separately, limiting scalability and integration \[[3](http://arxiv.org/abs/2002.09102)\]. Recent works have aimed to unify these components, such as the UniCRS model, which leverages knowledge-enhanced prompt learning to simultaneously handle recommendation and conversation tasks \[[2](http://arxiv.org/abs/2304.13874)\]. Additionally, the Estimation-Action-Reflection (EAR) framework proposes a structured approach with three stages—estimating user preferences, deciding dialogue actions, and reflecting on user feedback—to improve conversational interaction \[[3](http://arxiv.org/abs/2002.09102)\]. Another line of research, such as the User-Centric Conversational Recommendation (UCCR) model, emphasizes the importance of historical user data and look-alike users to enrich preference modeling beyond current session interactions \[[4](http://arxiv.org/abs/2007.04032)\]. Furthermore, the System Ask--User Respond (SAUR) paradigm introduces a formalized framework for conversational search and recommendation, enabling systems to actively clarify user needs through question-asking \[[5](http://arxiv.org/abs/2206.09363)\]. These approaches highlight the ongoing efforts to enhance the integration of dialogue and recommendation, ensuring more accurate and efficient user preference modeling in CRSs.

The category "Simulated User Approaches for CRS Evaluation" focuses on the development and evaluation of simulated users to assess conversational recommender systems (CRSs) without requiring extensive human involvement. These approaches aim to generate realistic user responses that reflect both individual preferences and the natural flow of conversation, thereby enabling more efficient and scalable evaluation of CRSs \[[3](http://arxiv.org/abs/2002.09102)\]. A key challenge in CRSs is accurately capturing user preferences through multi-turn interactions, which simulated users can help address by providing structured feedback such as generative item scoring and attribute-based item critique \[[1](http://arxiv.org/abs/2101.09459)\]. These feedback mechanisms allow CRSs to refine recommendations iteratively, mimicking real user behavior \[[1](http://arxiv.org/abs/2101.09459)\]. Several studies have explored the use of user simulators, such as USi, which can automatically answer clarifying questions and engage in multi-turn dialogues, making them valuable tools for evaluating conversational search systems \[[9](http://arxiv.org/abs/2204.08046)\]. Additionally, tools like the extensible user simulation toolkit have been introduced to enhance the realism of simulated interactions by incorporating elements such as user satisfaction prediction, persona modeling, and conditional natural language generation \[[3](http://arxiv.org/abs/2002.09102)\]. These simulators are often trained on limited manually annotated dialogues, demonstrating their potential for practical application \[[3](http://arxiv.org/abs/2002.09102)\]. Overall, simulated user approaches represent a promising direction for improving the efficiency and effectiveness of CRS evaluation, as they reduce reliance on manual assessments while maintaining alignment with human-like behavior \[[3](http://arxiv.org/abs/2002.09102)\]\[[9](http://arxiv.org/abs/2204.08046)\].
