## Related Works

Conversational Recommender Systems (CRSs) have emerged as a promising approach to address the limitations of traditional static recommendation models by enabling dynamic, multi-turn interactions with users to better capture their preferences \[[1](http://arxiv.org/abs/2101.09459)\]. Unlike static systems that rely solely on historical data, CRSs leverage natural language interactions to explicitly elicit user preferences, leading to more accurate and personalized recommendations \[[1](http://arxiv.org/abs/2101.09459)\]. However, developing effective CRSs remains challenging due to the need for sophisticated dialogue understanding, efficient exploration-exploitation strategies, and robust evaluation methods \[[1](http://arxiv.org/abs/2101.09459)\].

Several studies have explored the use of simulated users to evaluate and improve CRSs. For instance, \[[6](http://arxiv.org/abs/2006.08732)\] proposes a user simulator, ConvSim, that generates feedback for system responses and clarifying questions, enabling multi-turn interactions with mixed-initiative conversational search systems. The results show that incorporating user feedback significantly improves retrieval performance, with a 16% increase in nDCG@3 \[[6](http://arxiv.org/abs/2006.08732)\]. Similarly, \[[9](http://arxiv.org/abs/2204.08046)\] introduces a conversational user simulator, USi, that automatically answers clarifying questions based on an information need description, demonstrating that simulated user responses are comparable to human-generated ones \[[9](http://arxiv.org/abs/2204.08046)\]. These works highlight the importance of user feedback in improving the performance of CRSs.

To facilitate the development of CRSs, several frameworks have been proposed to integrate dialogue and recommendation modules. \[[3](http://arxiv.org/abs/2002.09102)\] introduces the Estimation-Action-Reflection (EAR) framework, which consists of three stages: Estimation (predicting user preferences), Action (deciding whether to ask for attributes or recommend items), and Reflection (updating the model based on user feedback). This approach reduces the number of conversation turns and improves recommendation accuracy \[[3](http://arxiv.org/abs/2002.09102)\]. \[[11](http://arxiv.org/abs/2007.00194)\] proposes Conversational Path Reasoning (CPR), which models conversational recommendation as an interactive path reasoning problem on a graph, allowing the system to explicitly use user feedback to prune irrelevant attributes and improve recommendation accuracy \[[11](http://arxiv.org/abs/2007.00194)\].

The integration of knowledge graphs (KGs) has also been explored to enhance the semantic understanding of user preferences in CRSs. \[[4](http://arxiv.org/abs/2007.04032)\] incorporates both word-oriented and entity-oriented KGs to align semantic spaces and improve the accuracy of recommendations and dialogues. The results show that KG-enhanced models outperform baseline approaches in both tasks \[[4](http://arxiv.org/abs/2007.04032)\]. \[[5](http://arxiv.org/abs/2206.09363)\] further proposes a unified CRS model, UniCRS, based on knowledge-enhanced prompt learning, which integrates recommendation and conversation modules using a fixed pre-trained language model (PLM) \[[5](http://arxiv.org/abs/2206.09363)\].
