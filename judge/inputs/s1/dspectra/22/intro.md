## Related Works

Unsupervised domain adaptation (UDA) for semantic segmentation has attracted significant attention due to the high cost of acquiring pixel-level annotations in target domains \[[1](http://arxiv.org/abs/2007.08702)\]. Traditional UDA methods assume that the category settings between source and target domains are known, which is often not the case in real-world applications \[[1](http://arxiv.org/abs/2007.08702)\]. This assumption can lead to performance degradation when private classes exist in the target domain \[[1](http://arxiv.org/abs/2007.08702)\]. Several approaches have been proposed to address this limitation.

One line of work focuses on improving the alignment of features between domains. For instance, DACS proposes a method that mixes images from the source and target domains along with their labels and pseudo-labels, leading to state-of-the-art results on the GTA5 to Cityscapes benchmark \[[2](https://www.semanticscholar.org/paper/5f9ce93f82dcd9b0f9ffe4274b81682f40d86253)\]. Similarly, DSP introduces a dual soft-paste strategy to align features between domains, improving convergence and performance \[[3](http://arxiv.org/abs/2107.09600)\]. These methods aim to reduce domain gaps by leveraging both feature and output-level alignment.

Another approach involves using pseudo-labels and consistency regularization. For example, \[[4](http://arxiv.org/abs/2012.12545)\] introduces a zero-style loss to address the class imbalance problem, while \[[5](http://arxiv.org/abs/2103.16372)\] proposes an uncertainty-aware consistency regularization to improve the reliability of pseudo-labels. These methods enhance the robustness of the model by ensuring consistency between predictions from different models or under different perturbations.

Domain separation networks \[[6](http://arxiv.org/abs/2004.08878)\] aim to explicitly model what is unique to each domain, enabling the extraction of domain-invariant features. This approach partitions image representations into private and shared subspaces, improving generalization across domains. Similarly, \[[7](http://arxiv.org/abs/2009.12559)\] proposes a method that uses adversarial perturbations to train a domain-invariant classifier, which is particularly effective for small objects and tail classes.

In addition to feature alignment, some works focus on leveraging auxiliary tasks for domain adaptation. For example, \[[8](http://arxiv.org/abs/2110.11062)\] uses depth estimation as a supervisory signal to bridge the domain gap, while \[[9](http://arxiv.org/abs/2308.05493)\] introduces a multi-source domain adaptation framework that leverages collaborative learning across multiple source domains. These methods demonstrate the potential of using additional information to improve adaptation performance.

Recent advances also focus on improving the efficiency and scalability of domain adaptation methods. For instance, \[[10](http://arxiv.org/abs/1904.01886)\] proposes a lightweight self-supervised framework that ensures consistency of semantic predictions across different image transformations, making it practical for real-world applications. Similarly, \[[11](http://arxiv.org/abs/2104.13613)\] introduces a curriculum learning approach that first solves easy tasks to infer properties about the target domain, gradually improving the model's performance.
