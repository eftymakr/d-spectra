## Related Works

Open-vocabulary object detection has emerged as a critical research direction, enabling detectors to recognize objects based on user-specified text queries rather than a fixed set of predefined categories. This capability is particularly valuable in real-world applications where the target objects may not be present in the training data \[[1](http://arxiv.org/abs/2011.10678)\]. However, prior approaches have faced challenges in effectively leveraging textual supervision, especially when the vocabulary is overly broad or mis-specified \[[1](http://arxiv.org/abs/2011.10678)\]. 

Several methods have explored the use of vision-language models to enhance open-vocabulary detection. For instance, ViLD \[[2](http://arxiv.org/abs/2104.13921)\] introduces a training method that distills knowledge from a pretrained open-vocabulary image classification model into a two-stage detector. This approach enables the model to detect objects described by arbitrary text inputs, achieving competitive performance on benchmarks like LVIS and COCO \[[2](http://arxiv.org/abs/2104.13921)\]. Similarly, RegionCLIP \[[17](http://arxiv.org/abs/2112.09106)\] extends CLIP to learn region-level visual representations, enabling fine-grained alignment between image regions and textual concepts. This method significantly improves performance on open-vocabulary detection tasks \[[17](http://arxiv.org/abs/2112.09106)\].

The use of pseudo labels has also been explored to expand the vocabulary of detectors. For example, PB-OVD \[[7](http://arxiv.org/abs/2111.09452)\] generates pseudo bounding-box annotations from large-scale image-caption pairs, allowing detectors to be trained on a broader set of categories without requiring extensive manual annotation. This approach outperforms existing open-vocabulary detectors on several benchmarks, including COCO and LVIS \[[7](http://arxiv.org/abs/2111.09452)\]. Similarly, Detic \[[8](http://arxiv.org/abs/2201.02605)\] trains detectors on image classification data, expanding the vocabulary of detectors to tens of thousands of concepts without requiring complex assignment schemes. This method achieves significant improvements on open-vocabulary and long-tail detection benchmarks \[[8](http://arxiv.org/abs/2201.02605)\].

Another line of research focuses on improving the efficiency and effectiveness of open-vocabulary detection through knowledge distillation. For example, HierKD \[[15](http://arxiv.org/abs/2203.10593)\] proposes a hierarchical visual-language knowledge distillation method for open-vocabulary one-stage detection. This approach combines global-level and instance-level knowledge distillation to learn both seen and unseen categories simultaneously, significantly improving performance on MS-COCO \[[15](http://arxiv.org/abs/2203.10593)\]. Similarly, DetPro \[[4](http://arxiv.org/abs/2203.14940)\] introduces a novel method to learn continuous prompt representations for open-vocabulary object detection based on pre-trained vision-language models. This method outperforms the baseline ViLD \[[2](http://arxiv.org/abs/2104.13921)\] in all settings, demonstrating the importance of prompt engineering in open-vocabulary detection \[[4](http://arxiv.org/abs/2203.14940)\].

### <a id='category-weakly-supervised-learning-strategies'></a>Weakly supervised learning strategies: 3 papers found.
Weakly supervised learning strategies have been extensively explored to address the limitations of traditional object detection methods that rely on expensive bounding box annotations. These strategies aim to leverage cheaper or more accessible forms of supervision, such as image-level labels or textual descriptions, to train detectors without explicit object localization \[[5](http://arxiv.org/abs/2207.03482)\]. For instance, some approaches utilize pretrained models like CLIP, which provide language-visual alignment but lack precise object localization capabilities \[[5](http://arxiv.org/abs/2207.03482)\]. Others focus on pseudo-labeling techniques that generate high-quality object proposals using only image-level supervision, enabling the expansion of detection vocabularies during training \[[5](http://arxiv.org/abs/2207.03482)\]. Additionally, there are methods that incorporate unstructured textual descriptions provided by users, which can be used to train detection models by extracting relevant nouns and refining the detection vocabulary \[[9](http://arxiv.org/abs/1907.10164)\]. These approaches highlight the potential of weakly supervised learning to improve detection performance while reducing annotation costs. Furthermore, some works propose architectures that modify deep convolutional networks to operate at the level of image regions, enabling simultaneous region selection and classification without explicit bounding box supervision \[[20](http://arxiv.org/abs/1511.02853)\]. Overall, these strategies demonstrate the feasibility of training effective object detectors using weakly supervised signals, paving the way for more scalable and flexible detection systems.

Another method introduces a cross-modal pseudo-labeling framework, aligning word semantics from captions with visual features of object masks to generate pseudo masks for instance segmentation \[[13](http://arxiv.org/abs/2111.12698)\]. Additionally, some methods focus on improving the quality of pseudo labels by incorporating noise estimation mechanisms to mitigate the adverse effects of noisy annotations \[[13](http://arxiv.org/abs/2111.12698)\]. These approaches collectively highlight the potential of pseudo label generation in expanding the scope of object detection and segmentation to larger, more diverse label spaces while reducing the need for manual annotation \[[7](http://arxiv.org/abs/2111.09452)\]\[[10](http://arxiv.org/abs/2207.08954)\].
