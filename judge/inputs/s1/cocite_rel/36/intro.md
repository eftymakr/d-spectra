## Related Works

Deploying large language models (LLMs) on edge devices presents significant challenges due to the limited storage, power, and computational capabilities of such hardware \[[1](http://arxiv.org/abs/2309.06180)\]. Several recent works have addressed these challenges by focusing on efficient inference, memory management, and hardware acceleration. For instance, **vLLM** introduces PagedAttention to manage the key-value (KV) cache more efficiently, reducing memory waste and enabling flexible sharing of cache across requests \[[1](http://arxiv.org/abs/2309.06180)\]. This approach significantly improves throughput by up to 2–4× compared to state-of-the-art systems like FasterTransformer and Orca \[[1](http://arxiv.org/abs/2309.06180)\]. Similarly, **FlashAttention** improves the efficiency of attention mechanisms by reducing memory reads/writes and optimizing for GPU memory hierarchy, achieving up to 2× speedup over previous methods \[[18](http://arxiv.org/abs/2205.14135)\]. 

Quantization techniques have also been widely explored to reduce memory and computational demands. **SmoothQuant** enables 8-bit weight and activation quantization (W8A8) for LLMs without significant accuracy loss, achieving up to 1.56× speedup and 2× memory reduction \[[2](http://arxiv.org/abs/2211.10438)\]. **AWQ** introduces activation-aware weight quantization, which reduces model size while preserving performance, enabling 4× model size reduction and 3–4× acceleration across various edge platforms \[[4](http://arxiv.org/abs/2306.00978)\]. **OmniQuant** further advances quantization by introducing learnable weight clipping and equivalent transformation, allowing efficient optimization of quantization parameters for diverse settings such as W4A4, W6A6, and W2A16 \[[22](http://arxiv.org/abs/2308.13137)\].

Hardware accelerators play a crucial role in enabling efficient LLM deployment. **MECLA** proposes a memory-compute-efficient accelerator with sub-matrix partitioning, reducing memory access and computation by 83.6% and 72.2%, respectively \[[12](https://www.semanticscholar.org/paper/06046794314216dbdb53aeb0263ee41026e78574)\]. **DFX** presents a multi-FPGA appliance that accelerates GPT-2 inference with low latency and high throughput, achieving 5.58× speedup and 3.99× energy efficiency over NVIDIA V100 GPUs \[[14](http://arxiv.org/abs/2209.10797)\]. **LlamaF** focuses on FPGA-based acceleration for LLM inference, achieving up to 15.8× speedup and 6.1× power efficiency improvement on embedded FPGAs \[[15](http://arxiv.org/abs/2409.11424)\].
