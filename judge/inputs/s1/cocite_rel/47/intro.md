## Related Works

Multi-Domain Recommendation (MDR) has emerged as a promising approach to improve recommendation performance by leveraging knowledge transfer across different domains \[[1](http://arxiv.org/abs/2103.01696)\]. Traditional MDR methods often assume a uniform structure for knowledge transfer, which may not be suitable for all scenarios due to varying domain characteristics and potential conflicts \[[1](http://arxiv.org/abs/2103.01696)\]. This limitation has led to the Negative Transfer Problem (NTP), where unselective knowledge transfer can degrade performance \[[1](http://arxiv.org/abs/2103.01696)\]. 

Several approaches have been proposed to address the challenges of MDR. For instance, CoNet \[[3](http://arxiv.org/abs/1804.06769)\] introduces a deep transfer learning method that enables dual knowledge transfer across domains by connecting hidden layers of neural networks. This approach improves recommendation performance by capturing complex user-item interactions \[[3](http://arxiv.org/abs/1804.06769)\]. Similarly, DDTCDR \[[4](http://arxiv.org/abs/1910.05189)\] proposes a model that iteratively transfers information between domains using dual learning, enhancing the representation of user preferences while preserving cross-domain relations \[[4](http://arxiv.org/abs/1910.05189)\]. 

BiTGCF \[[5](https://www.semanticscholar.org/paper/d5630291a4ba3f6266c77e6d00920502f986afa6)\] further advances the field by using a graph collaborative filtering network to enable bi-directional knowledge transfer. It exploits high-order connectivity in user-item graphs and fuses common and domain-specific user features during transfer \[[5](https://www.semanticscholar.org/paper/d5630291a4ba3f6266c77e6d00920502f986afa6)\]. Another approach, PPGN \[[6](https://www.semanticscholar.org/paper/24a473700894dbfab0bfd9dc3d542acfeef66bca)\], constructs a Cross-Domain Preference Matrix (CDPM) to model interactions across domains and uses a preference propagation layer to capture how user preferences propagate in the graph \[[6](https://www.semanticscholar.org/paper/24a473700894dbfab0bfd9dc3d542acfeef66bca)\]. 

In addition to these methods, the Variational Information Bottleneck (VIB) approach \[[7](http://arxiv.org/abs/2203.16863)\] has been applied to CDR to capture domain-shared information for cold-start users. This method introduces regularizers to model cross-domain and in-domain interactions, enabling the learning of unbiased representations \[[7](http://arxiv.org/abs/2203.16863)\]. The ETL model \[[9](https://www.semanticscholar.org/paper/3ec388df2f38ebeeb4d184ec3e305a5aecd0d080)\] also addresses the challenge of shared-user representation by proposing an equivalent transformation learner that preserves both domain-specific and overlapping features \[[9](https://www.semanticscholar.org/paper/3ec388df2f38ebeeb4d184ec3e305a5aecd0d080)\]. 

The Adversarial Feature Translation (AFT) model \[[10](https://www.semanticscholar.org/paper/7807d924fa46caec7b706b98156962caf8458d59)\] leverages a generative adversarial network (GAN) framework to learn feature translations between domains. It uses a domain-specific masked encoder and a domain-specific attention mechanism to highlight inter-domain feature interactions \[[10](https://www.semanticscholar.org/paper/7807d924fa46caec7b706b98156962caf8458d59)\]. 

The STAR model \[[14](http://arxiv.org/abs/2101.11427)\] proposes a star topology adaptive recommender that trains a single model to serve multiple domains by combining a shared network with domain-specific networks. This approach enables the model to capture domain characteristics while maintaining generalizability \[[14](http://arxiv.org/abs/2101.11427)\].
