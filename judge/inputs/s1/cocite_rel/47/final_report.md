## Related Works

Multi-Domain Recommendation (MDR) has emerged as a promising approach to improve recommendation performance by leveraging knowledge transfer across different domains \[[1](http://arxiv.org/abs/2103.01696)\]. Traditional MDR methods often assume a uniform structure for knowledge transfer, which may not be suitable for all scenarios due to varying domain characteristics and potential conflicts \[[1](http://arxiv.org/abs/2103.01696)\]. This limitation has led to the Negative Transfer Problem (NTP), where unselective knowledge transfer can degrade performance \[[1](http://arxiv.org/abs/2103.01696)\]. 

Several approaches have been proposed to address the challenges of MDR. For instance, CoNet \[[3](http://arxiv.org/abs/1804.06769)\] introduces a deep transfer learning method that enables dual knowledge transfer across domains by connecting hidden layers of neural networks. This approach improves recommendation performance by capturing complex user-item interactions \[[3](http://arxiv.org/abs/1804.06769)\]. Similarly, DDTCDR \[[4](http://arxiv.org/abs/1910.05189)\] proposes a model that iteratively transfers information between domains using dual learning, enhancing the representation of user preferences while preserving cross-domain relations \[[4](http://arxiv.org/abs/1910.05189)\]. 

BiTGCF \[[5](https://www.semanticscholar.org/paper/d5630291a4ba3f6266c77e6d00920502f986afa6)\] further advances the field by using a graph collaborative filtering network to enable bi-directional knowledge transfer. It exploits high-order connectivity in user-item graphs and fuses common and domain-specific user features during transfer \[[5](https://www.semanticscholar.org/paper/d5630291a4ba3f6266c77e6d00920502f986afa6)\]. Another approach, PPGN \[[6](https://www.semanticscholar.org/paper/24a473700894dbfab0bfd9dc3d542acfeef66bca)\], constructs a Cross-Domain Preference Matrix (CDPM) to model interactions across domains and uses a preference propagation layer to capture how user preferences propagate in the graph \[[6](https://www.semanticscholar.org/paper/24a473700894dbfab0bfd9dc3d542acfeef66bca)\]. 

In addition to these methods, the Variational Information Bottleneck (VIB) approach \[[7](http://arxiv.org/abs/2203.16863)\] has been applied to CDR to capture domain-shared information for cold-start users. This method introduces regularizers to model cross-domain and in-domain interactions, enabling the learning of unbiased representations \[[7](http://arxiv.org/abs/2203.16863)\]. The ETL model \[[9](https://www.semanticscholar.org/paper/3ec388df2f38ebeeb4d184ec3e305a5aecd0d080)\] also addresses the challenge of shared-user representation by proposing an equivalent transformation learner that preserves both domain-specific and overlapping features \[[9](https://www.semanticscholar.org/paper/3ec388df2f38ebeeb4d184ec3e305a5aecd0d080)\]. 

The Adversarial Feature Translation (AFT) model \[[10](https://www.semanticscholar.org/paper/7807d924fa46caec7b706b98156962caf8458d59)\] leverages a generative adversarial network (GAN) framework to learn feature translations between domains. It uses a domain-specific masked encoder and a domain-specific attention mechanism to highlight inter-domain feature interactions \[[10](https://www.semanticscholar.org/paper/7807d924fa46caec7b706b98156962caf8458d59)\].

### <a id='category-cross-domain-preference-modeling'></a>Cross-Domain Preference Modeling: 5 papers found.
Cross-Domain Preference Modeling has been a focal point in improving recommendation systems by leveraging information from multiple domains to mitigate data sparsity \[[1](http://arxiv.org/abs/2103.01696)\]. Existing approaches have primarily focused on transferring knowledge between domains, either through shared user representations \[[4](http://arxiv.org/abs/1910.05189)\] or by capturing domain-specific features \[[9](https://www.semanticscholar.org/paper/3ec388df2f38ebeeb4d184ec3e305a5aecd0d080)\]. However, many methods lack a systematic understanding of how to effectively model cross-domain relationships, often resulting in the Negative Transfer Problem (NTP) when conflicting or low-quality domain information is involved \[[15](http://arxiv.org/abs/2211.11191)\]. To address these limitations, recent works have proposed more sophisticated frameworks, such as the Preference Propagation GraphNet (PPGN), which integrates cross-domain graph structures and high-order information propagation to enhance recommendation accuracy \[[6](https://www.semanticscholar.org/paper/24a473700894dbfab0bfd9dc3d542acfeef66bca)\]. Similarly, the Equivalent Transformation Learner (ETL) aims to model joint user behavior across domains by preserving both domain-specific and shared features through an equivalent transformation mechanism \[[9](https://www.semanticscholar.org/paper/3ec388df2f38ebeeb4d184ec3e305a5aecd0d080)\]. Additionally, the introduction of hierarchical hypergraph networks has enabled more nuanced modeling of multi-domain interactions by capturing both item-level and user-level correlations \[[15](http://arxiv.org/abs/2211.11191)\]. These advancements highlight the ongoing efforts to refine cross-domain recommendation strategies, emphasizing the need for dynamic and adaptive approaches that can effectively handle domain-specific challenges while maintaining overall performance \[[1](http://arxiv.org/abs/2103.01696)\]\[[4](http://arxiv.org/abs/1910.05189)\]\[[6](https://www.semanticscholar.org/paper/24a473700894dbfab0bfd9dc3d542acfeef66bca)\]\[[9](https://www.semanticscholar.org/paper/3ec388df2f38ebeeb4d184ec3e305a5aecd0d080)\]\[[15](http://arxiv.org/abs/2211.11191)\].

### <a id='category-domain-specific-and-cross-domain-interaction-models'></a>Domain-Specific and Cross-Domain Interaction Models: 6 papers found.
Cross-Domain Recommendation (CDR) has emerged as a promising approach to alleviate data sparsity by leveraging knowledge from multiple domains \[[1](http://arxiv.org/abs/2103.01696)\]. Traditional methods often focus on transferring information from a source domain to a target domain, but recent advancements have explored dual-target CDR, where both domains benefit simultaneously \[[2](https://www.semanticscholar.org/paper/2b031c7170c9dccbe506f3d3a1d6104f65e835ae)\]. For instance, DTCDR utilizes rating and multi-source content information to generate embeddings and employs Multi-Task Learning (MTL) to share embeddings across domains, improving performance on both richer and sparser domains \[[2](https://www.semanticscholar.org/paper/2b031c7170c9dccbe506f3d3a1d6104f65e835ae)\]. Similarly, CoNet introduces cross connections between base networks to enable dual knowledge transfer, achieving significant improvements in NDCG \[[3](http://arxiv.org/abs/1804.06769)\]. Another approach, CDRIB, addresses the cold-start problem by using the information bottleneck principle to derive unbiased representations that capture domain-shared information, leading to better performance on cross-domain datasets \[[7](http://arxiv.org/abs/2203.16863)\]. Additionally, multi-domain collaborative filtering (MCF) tackles the data sparsity issue by considering multiple domains simultaneously and learning domain correlations through probabilistic matrix factorization \[[8](http://arxiv.org/abs/1203.3535)\]. In more complex settings, such as shared-account cross-domain sequential recommendation, π-Net is designed to handle both shared accounts and cross-domain interactions by using a parallel information-sharing architecture \[[12](https://www.semanticscholar.org/paper/fa990aee9a8f157b5d393f5f3eaa014e1e5c67aa)\]. These methods highlight the ongoing efforts to improve cross-domain recommendation by addressing domain interactions, transfer efficiency, and cold-start challenges.

[Snippet]: «Large-scale e-commercial platforms in the real-world usually contain various recommendation scenarios (domains) to meet demands of diverse customer groups. Multi-Domain Recommendation (MDR), which aims to jointly improve recommendations on all domains and easily scales to thousands of domains, has attracted increasing attention from practitioners and researchers. Existing MDR methods usually employ a shared structure and several specific components to respectively leverage reusable features and domain-specific information. However, data distribution differs across domains, making it challenging to develop a general model that can be applied to all circumstances. To address the problems of MDR methods, we propose a novel model agnostic learning framework, namely MAMDR, for the multi-domain recommendation. Specifically, we first propose a Domain Negotiation (DN) strategy to alleviate the conflict between domains. Then, we develop a Domain Regularization (DR) to improve the generalizability of specific parameters by learning from other domains. We integrate these components into a unified framework and present MAMDR, which can be applied to any model structure to perform multi-domain recommendation. Finally, we present a large-scale implementation of MAMDR in the Taobao application and construct various public MDR benchmark datasets which can be used for following studies. Extensive experiments on both benchmark datasets and industry datasets demonstrate the effectiveness and generalizability of MAMDR.»
