## Related Works

Conversational Recommender Systems (CRSs) have emerged as a promising approach to dynamically capture user preferences through multi-turn interactions. Unlike traditional recommender systems that rely on static models and historical data, CRSs engage users in dialogues to elicit preferences in a more interactive and personalized manner \[[9](http://arxiv.org/abs/2101.09459)\]. This shift has been driven by advancements in natural language processing and the increasing demand for more adaptive and user-centric recommendation mechanisms \[[14](http://arxiv.org/abs/2004.00646)\]. However, effectively understanding user preferences from conversational data remains a fundamental challenge, as user preferences can be complex and multifaceted \[[1](http://arxiv.org/abs/2002.09102)\].

Several approaches have been proposed to address these challenges. One line of research focuses on the integration of conversation and recommendation components through unified frameworks. For instance, the Estimation-Action-Reflection (EAR) framework \[[1](http://arxiv.org/abs/2002.09102)\] divides the CRS process into three stages: Estimation, which builds predictive models to estimate user preferences; Action, which determines whether to ask about item attributes or recommend items; and Reflection, which updates the model based on user feedback. Similarly, the Conversational Path Reasoning (CPR) framework \[[2](http://arxiv.org/abs/2007.00194)\] models conversational recommendation as an interactive path reasoning problem on a graph, leveraging user feedback to navigate through attribute vertices and improve recommendation accuracy. These methods emphasize the importance of dynamic interaction and feedback in refining user preferences.

Another key area of research involves the use of reinforcement learning to learn conversational recommendation policies. The Unified Conversational Recommendation Policy Learning via Graph-based Reinforcement Learning \[[8](http://arxiv.org/abs/2105.09710)\] proposes a dynamic weighted graph-based RL method to learn a policy for selecting actions, either asking for attributes or recommending items, while ensuring stable training and scalability. This approach addresses the limitations of existing methods that often separate conversation and recommendation components, leading to suboptimal performance.

User simulation has also been widely explored as a means to evaluate CRSs without relying on human evaluation, which is time-consuming and resource-intensive \[[6](http://arxiv.org/abs/2006.08732)\]. The UserSimCRS toolkit \[[10](http://arxiv.org/abs/2301.05544)\] provides an extensible user simulation framework that generates realistic user responses based on individual preferences and interaction flow. This enables automated evaluation of CRSs, making it feasible to test and compare different models at scale. Additionally, the Simulating User Satisfaction for the Evaluation of Task-oriented Dialogue Systems \[[11](http://arxiv.org/abs/2105.03748)\] introduces a user satisfaction annotation dataset and baseline methods for predicting user satisfaction, enhancing the realism and effectiveness of user simulations.
