## Related Works

Unsupervised domain adaptation (UDA) for semantic segmentation has attracted significant research interest due to its practical importance in real-world applications where labeled data in the target domain is scarce or unavailable \[[1](http://arxiv.org/abs/1909.13589)\]. Traditional UDA methods typically assume that the category settings between the source and target domains are known, which is often not the case in real-world scenarios \[[1](http://arxiv.org/abs/1909.13589)\]. This assumption leads to performance degradation when private classes exist in the target domain, as these classes are not represented in the source domain \[[1](http://arxiv.org/abs/1909.13589)\].

To address this limitation, several works have explored methods that do not require prior knowledge of category settings. For instance, \[[2](http://arxiv.org/abs/1910.13049)\] introduces a method that aligns the marginal distributions between domains using adversarial learning, but it fails to account for category-level feature alignment, leading to incorrect predictions on the target domain. A more recent approach, \[[3](http://arxiv.org/abs/2007.08702)\], proposes a category anchor-guided (CAG) model that explicitly enforces category-aware feature alignment to learn shared discriminative features and classifiers simultaneously. This method improves performance by leveraging category-wise centroids as anchors for feature alignment \[[3](http://arxiv.org/abs/2007.08702)\].

Another line of research focuses on pseudo-label generation and refinement. For example, \[[4](http://arxiv.org/abs/2004.07703)\] proposes a method that uses entropy minimization to generate pseudo-labels, but this approach is biased towards easy-to-transfer samples. To mitigate this issue, \[[5](http://arxiv.org/abs/2107.09600)\] introduces the maximum squares loss to balance the gradient of well-classified target samples and prevent the training process from being dominated by easy-to-transfer samples \[[5](http://arxiv.org/abs/2107.09600)\]. Similarly, \[[6](http://arxiv.org/abs/1904.10620)\] employs a self-supervised learning algorithm to improve the segmentation adaptation model, which in turn enhances the image translation model \[[6](http://arxiv.org/abs/1904.10620)\].

In addition to pseudo-label refinement, some works focus on domain shift mitigation through feature alignment. \[[7](http://arxiv.org/abs/2101.10979)\] introduces a dual soft-paste (DSP) method that soft-pastes image patches from the source domain onto both the source and target training images, using a fusion weight to align features across domains \[[7](http://arxiv.org/abs/2101.10979)\]. This approach is combined with a mean teacher framework to align probability maps and feature maps, leading to faster convergence and better performance \[[7](http://arxiv.org/abs/2101.10979)\].

Recent methods have also explored the use of auxiliary tasks, such as depth estimation, to bridge the domain gap. \[[8](https://www.semanticscholar.org/paper/3f9f801aec1f87ae81524f1928407673805927cb)\] leverages self-supervised depth estimation to guide the adaptation process, using depth prediction discrepancy to approximate pixel-wise adaptation difficulty and refine pseudo-labels \[[8](https://www.semanticscholar.org/paper/3f9f801aec1f87ae81524f1928407673805927cb)\]. This approach is particularly effective in synthetic-to-real domain adaptation tasks \[[8](https://www.semanticscholar.org/paper/3f9f801aec1f87ae81524f1928407673805927cb)\].

Unsupervised domain adaptation (UDA) for semantic segmentation aims to transfer knowledge from a labeled source domain to an unlabeled target domain, addressing the challenge of domain shift \[[1](http://arxiv.org/abs/1909.13589)\]. Traditional methods often assume known category settings between domains, which is impractical in real-world scenarios where private classes may exist, leading to performance degradation \[[1](http://arxiv.org/abs/1909.13589)\]. Recent works have focused on mitigating domain shift through feature alignment, such as category-aware alignment to learn shared discriminative features \[[2](http://arxiv.org/abs/1910.13049)\], or dual soft-paste methods that facilitate domain-invariant feature learning \[[5](http://arxiv.org/abs/2107.09600)\]. Others have introduced category-level adversarial networks to enforce local semantic consistency during global alignment \[[9](http://arxiv.org/abs/1809.09478)\], or multi-level adversarial networks to perform output space domain adaptation \[[11](http://arxiv.org/abs/1802.10349)\]. Additionally, methods like entropy-based losses and adversarial losses have been proposed to improve generalization across domains \[[12](http://arxiv.org/abs/1811.12833)\]. Some approaches leverage adversarial learning in the output space, considering spatial similarities between domains \[[14](http://arxiv.org/abs/1612.02649)\], while others focus on channel-wise feature alignment to preserve spatial structures and semantic information \[[20](http://arxiv.org/abs/1804.05827)\]. A few studies have also explored collaborative learning for multi-source domain adaptation, leveraging multiple source domains to improve adaptation performance \[[24](http://arxiv.org/abs/2103.04717)\]. These methods highlight the ongoing efforts to address domain shift through various alignment strategies, including feature, output, and class-level adaptations.

[Snippet]: «Domain adaptation aims to transfer knowledge in the presence of the domain gap. Existing domain adaptation methods rely on rich prior knowledge about the relationship between the label sets of source and target domains, which greatly limits their application in the wild. This paper introduces Universal Domain Adaptation (UDA) that requires no prior knowledge on the label sets. For a given source label set and a target label set, they may contain a common label set and hold a private label set respectively, bringing up an additional category gap. UDA requires a model to either (1) classify the target sample correctly if it is associated with a label in the common label set, or (2) mark it as ``unknown'' otherwise. To solve the universal domain adaptation problem, we propose Universal Adaptation Network (UAN). It quantifies sample-level transferability to discover the common label set and the label sets private to each domain, thereby promoting the adaptation in the automatically discovered common label set and recognizing the ``unknown'' samples successfully. A thorough evaluation shows that UAN outperforms the state of the art closed set, partial and open set domain adaptation methods in the novel UDA setting.»
