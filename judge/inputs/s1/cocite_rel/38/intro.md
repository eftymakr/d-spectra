## Related Works

Memory bandwidth regulation and cache partitioning have been widely explored as techniques to achieve predictable timing in real-time computing systems \[[1](https://www.semanticscholar.org/paper/50d359dc737cb5c296b527f4eb1541dc55f3ed86)\]. These approaches are often combined with partitioned scheduling to ensure that tasks are co-allocated with appropriate resources \[[2](https://www.semanticscholar.org/paper/bbebaeb1b00fdcde2aeb192543835d3ec1518f8d)\]. Task execution times are strongly dependent on the availability of allocated resources, which necessitates careful co-allocation strategies \[[3](https://www.semanticscholar.org/paper/25ebad66dc10d7b01c22684cbb200ddeb6502475)\]. 

Several studies have investigated memory bandwidth regulation, such as the Bandwidth Regulation Unit (BRU), which enables fine-grained per-core memory bandwidth regulation \[[4](https://www.semanticscholar.org/paper/e02eb1430cb7aa53f20818d2b642abe10d58a459)\]. BRU also allows collective regulation of memory access bandwidth across multiple cores, improving utilization while maintaining time-predictability \[[4](https://www.semanticscholar.org/paper/e02eb1430cb7aa53f20818d2b642abe10d58a459)\]. Similarly, MemGuard is a memory bandwidth reservation system designed to provide performance isolation in multi-core platforms \[[5](https://www.semanticscholar.org/paper/1ed3c2a13c728b4d294644db90fb278e62bece22)\]. These systems aim to mitigate contention in shared memory resources, a major source of unpredictability in multi-core embedded systems \[[6](https://www.semanticscholar.org/paper/dbd4eb5033815003e7f6519fd66e43e5fc297075)\].

Cache partitioning has also been proposed as a method to improve predictability. The paper on Cache Bleaching introduces Programmable Logic In-the-Middle (PLIM) to manipulate individual memory transactions, enabling cache coloring and reducing cache contention \[[7](https://www.semanticscholar.org/paper/0b1bc294dbd926f853a8ee41d1d8f8ecc3cfde13)\]. Another study presents a real-time cache management framework that leverages OS-transparent and DMA-friendly cache coloring, along with invalidation-driven allocation (IDA) to protect important cache blocks from eviction \[[8](https://www.semanticscholar.org/paper/abbd6f8840092bd8e4e3684d3297e1b707abdc5d)\]. These techniques aim to restore memory access determinism by preventing both internal and external cache evictions \[[8](https://www.semanticscholar.org/paper/abbd6f8840092bd8e4e3684d3297e1b707abdc5d)\].

Dynamic memory bandwidth regulation has also been studied, particularly in the context of worst-case response time analysis. A paper on dynamic allocation of main memory bandwidth proposes a framework to determine worst-case response times of tasks across varying bandwidth-to-core assignments \[[9](https://www.semanticscholar.org/paper/6e925ae85e385ac0e8810441d84be97c079f6b22)\]. This work highlights the need for theoretical frameworks to reason about worst-case behavior in multi-core systems, especially when both processors and memory resources are subject to scheduling decisions \[[9](https://www.semanticscholar.org/paper/6e925ae85e385ac0e8810441d84be97c079f6b22)\].

In addition, the paper on RT-Gang introduces a real-time gang scheduling framework that enforces a one-gang-at-a-time policy to reduce pessimism in worst-case execution time (WCET) analysis \[[10](https://www.semanticscholar.org/paper/cf5b78d3e292fda8f6a8aa132da468f6d8e6a730)\]. This approach integrates memory bandwidth throttling to allow safe execution of best-effort tasks while minimizing interference with real-time gang tasks \[[10](https://www.semanticscholar.org/paper/cf5b78d3e292fda8f6a8aa132da468f6d8e6a730)\]. These techniques demonstrate the importance of combining scheduling and resource allocation strategies to improve predictability in multi-core environments \[[10](https://www.semanticscholar.org/paper/cf5b78d3e292fda8f6a8aa132da468f6d8e6a730)\].

Finally, the paper on bounding memory interference delay in COTS-based multi-core systems presents techniques to provide tight upper bounds on worst-case memory interference \[[11](https://www.semanticscholar.org/paper/d5336fd2234f431f554fc5d878503a04a27e366e)\].
