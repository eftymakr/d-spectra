## Related Works

Semi-supervised learning (SSL) has emerged as a powerful paradigm for improving model performance when labeled data is scarce, leveraging the abundance of unlabeled data \[[3](http://arxiv.org/abs/2001.07685)\]. However, conventional SSL methods assume that labeled and unlabeled data share the same class distribution, an assumption that is often violated in practice due to the presence of out-of-distribution (OOD) or outlier samples \[[3](http://arxiv.org/abs/2001.07685)\]. These outliers, which are typically treated as noise, can significantly degrade model performance \[[3](http://arxiv.org/abs/2001.07685)\]. To address this issue, several works have explored open-set SSL, where the unlabeled data may contain unseen classes \[[1](https://www.semanticscholar.org/paper/f3df804a7eef204b0c4fc4b81166dec9b4abc073)\]\[[2](http://arxiv.org/abs/2007.11330)\]\[[4](http://arxiv.org/abs/2108.05617)\].

Early approaches to open-set SSL focused on filtering out OOD samples before applying SSL techniques \[[1](https://www.semanticscholar.org/paper/f3df804a7eef204b0c4fc4b81166dec9b4abc073)\]. For instance, \[[1](https://www.semanticscholar.org/paper/f3df804a7eef204b0c4fc4b81166dec9b4abc073)\] proposed a multi-task curriculum learning framework that jointly optimizes OOD detection and SSL. This method estimates the probability of a sample being OOD and uses a joint optimization framework to update network parameters and OOD scores alternately \[[1](https://www.semanticscholar.org/paper/f3df804a7eef204b0c4fc4b81166dec9b4abc073)\]. Similarly, \[[2](http://arxiv.org/abs/2007.11330)\] introduced a method that leverages OOD detection to improve classification performance on in-distribution (ID) data by selecting ID samples with small OOD scores for training \[[2](http://arxiv.org/abs/2007.11330)\].

More recently, methods have sought to exploit OOD data rather than simply filtering it out. For example, \[[4](http://arxiv.org/abs/2108.05617)\] proposed a training mechanism that uses OOD data for enhanced feature learning while mitigating their adverse impact on SSL. This is achieved through a warm-up training phase that leverages all unlabeled data, including OOD samples, and a cross-modal matching strategy to detect OOD samples \[[4](http://arxiv.org/abs/2108.05617)\]. The cross-modal matching approach is designed to generate a compatible feature space that aligns with the core classification task, improving performance over binary classification methods \[[4](http://arxiv.org/abs/2108.05617)\].

Another line of work focuses on improving the robustness of SSL in the presence of OOD data by adjusting confidence thresholds and pseudo-labeling strategies \[[9](http://arxiv.org/abs/2205.07246)\]\[[12](http://arxiv.org/abs/2110.08263)\]. For example, \[[9](http://arxiv.org/abs/2205.07246)\] proposed FreeMatch, which dynamically adjusts the confidence threshold during training based on the model's learning status, leading to improved performance when labeled data is extremely rare \[[9](http://arxiv.org/abs/2205.07246)\]. ### <a id='category-open-set-ssl-frameworks'></a>Open-Set SSL Frameworks: 6 papers found.
Open-set semi-supervised learning (OSSL) addresses the challenge where unlabeled data may contain out-of-distribution (OOD) samples, which traditional SSL methods fail to handle effectively \[[1](https://www.semanticscholar.org/paper/f3df804a7eef204b0c4fc4b81166dec9b4abc073)\]. Recent works have proposed frameworks that integrate OOD detection with SSL training to improve robustness. For instance, a multi-task curriculum learning framework was introduced to jointly optimize OOD detection and classification tasks, achieving state-of-the-art results by eliminating the negative impact of OOD samples \[[2](http://arxiv.org/abs/2007.11330)\]. Another approach, SAFE-R-STUDENT, employs a teacher-student paradigm with a novel scoring framework and calibration losses to enhance the identification of seen and unseen classes, leading to improved performance on both seen and unseen data \[[6](https://www.semanticscholar.org/paper/9e4376e0572de32236e408469ffb2173d89eaab5)\]. OpenMatch combines FixMatch with novelty detection using one-vs-all classifiers, enabling effective outlier rejection and achieving state-of-the-art results on multiple datasets \[[7](http://arxiv.org/abs/2105.14148)\]. Similarly, OpenCoS leverages self-supervised contrastive learning to identify OOD samples and uses pseudo-labels to improve SSL performance in open-set scenarios \[[8](http://arxiv.org/abs/2107.08943)\]. ORCA introduces an uncertainty adaptive margin mechanism to address class distribution mismatches, achieving significant improvements on both seen and novel classes \[[16](http://arxiv.org/abs/2102.03526)\]. These methods highlight the growing interest in developing robust OSSL frameworks that can handle real-world data with unknown classes, emphasizing the need for integrated approaches that combine OOD detection with semi-supervised learning \[[1](https://www.semanticscholar.org/paper/f3df804a7eef204b0c4fc4b81166dec9b4abc073)\].

Methods such as FixMatch \[[3](http://arxiv.org/abs/2001.07685)\] and MixMatch \[[5](http://arxiv.org/abs/1905.02249)\] have demonstrated significant improvements by generating pseudo-labels and leveraging data augmentation. FixMatch retains pseudo-labels only when the model's predictions are confident, while MixMatch further enhances performance by combining labeled and unlabeled data through techniques like MixUp. Additionally, Dash \[[10](http://arxiv.org/abs/2109.00650)\] introduces a dynamic thresholding mechanism to select high-quality pseudo-labels, ensuring that only relevant examples are used for training. Self-ensembling \[[11](http://arxiv.org/abs/1610.02242)\] has also been employed to improve robustness by using consensus predictions across different training epochs and augmentations. Furthermore, FlexMatch \[[12](http://arxiv.org/abs/2110.08263)\] builds upon FixMatch by introducing a curriculum learning approach that adapts thresholds for different classes, improving performance especially with limited labeled data. The importance of data augmentation quality has also been highlighted, with methods like those in \[[14](http://arxiv.org/abs/1904.12848)\] showing that advanced augmentation techniques significantly enhance SSL performance. These strategies collectively emphasize the critical role of pseudo-labeling in improving SSL models, particularly in scenarios with scarce labeled data.
