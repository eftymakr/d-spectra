## Related Works

Sequential recommendation systems aim to predict the next item a user will interact with based on their historical behavior \[[1](http://arxiv.org/abs/1808.09781)\]. These systems have evolved from simple Markov Chain models, which assume that the next action depends only on the last few actions, to more sophisticated models like Recurrent Neural Networks (RNNs) and Transformers, which capture longer-term dependencies \[[1](http://arxiv.org/abs/1808.09781)\]. However, these models often face challenges in handling long sequences and capturing diverse user behaviors \[[1](http://arxiv.org/abs/1808.09781)\].

Early approaches, such as Markov Chains, are efficient but limited in their ability to model complex sequential patterns \[[1](http://arxiv.org/abs/1808.09781)\]. RNNs, while more expressive, suffer from high computational complexity and difficulty in capturing long-term dependencies \[[1](http://arxiv.org/abs/1808.09781)\]. To address these limitations, attention-based models like SASRec and Caser have been proposed \[[1](http://arxiv.org/abs/1808.09781)\]\[[2](http://arxiv.org/abs/1809.07426)\]. SASRec uses self-attention to identify relevant items in a user's history, while Caser employs convolutional filters to extract local features from sequences \[[1](http://arxiv.org/abs/1808.09781)\]\[[2](http://arxiv.org/abs/1809.07426)\]. These models improve performance but often at the cost of increased computational requirements \[[1](http://arxiv.org/abs/1808.09781)\]\[[2](http://arxiv.org/abs/1809.07426)\].

The Transformer architecture, which underpins many modern sequential recommendation models, has also been adapted for this task \[[4](http://arxiv.org/abs/1904.06690)\]. BERT4Rec, for instance, uses bidirectional self-attention to model user behavior sequences, allowing for more comprehensive representation of user preferences \[[4](http://arxiv.org/abs/1904.06690)\]. However, the quadratic complexity of attention mechanisms limits their scalability to long sequences \[[4](http://arxiv.org/abs/1904.06690)\]. To mitigate this, LinRec introduces a linear attention mechanism that maintains the expressive power of dot-product attention while reducing computational overhead \[[3](http://arxiv.org/abs/2411.01537)\].

Temporal information has also been recognized as a critical factor in sequential recommendation \[[14](https://www.semanticscholar.org/paper/5574d6123deea94eba2cb35b2486851e826c16ce)\]. Models like TiSASRec explicitly model time intervals between interactions, improving the accuracy of next-item predictions \[[5](https://www.semanticscholar.org/paper/9c7a455b1e48d01a99e58e884a6c1acb75074ad0)\]. Similarly, the Temporal Graph Collaborative Transformer (TGSRec) integrates both sequential patterns and temporal collaborative signals, enhancing the modeling of user preferences over time \[[22](http://arxiv.org/abs/2108.06625)\].

Efficient modeling of long sequences remains a challenge, particularly for industrial applications where user interactions are frequent and extensive \[[10](http://arxiv.org/abs/2409.01192)\]. Mamba, a state space model with linear complexity, has shown promise in this regard \[[7](http://arxiv.org/abs/2312.00752)\]. Inspired by Mamba, SSD4Rec and Mamba4Rec further explore the potential of selective state space models for sequential recommendation, achieving state-of-the-art performance while maintaining efficiency \[[10](http://arxiv.org/abs/2409.01192)\]\[[13](http://arxiv.org/abs/2403.03900)\]. These models demonstrate that it is possible to balance effectiveness and efficiency in sequential recommendation tasks.

### <a id='category-sequential-recommendation-models'></a>Sequential Recommendation Models: 16 papers found.
Sequential recommendation models aim to predict users' next interactions based on their historical behavior, leveraging sequential patterns and dynamic preferences \[[1](http://arxiv.org/abs/1808.09781)\]. Traditional approaches such as Markov Chains (MCs) assume that predictions depend only on the last few actions, while Recurrent Neural Networks (RNNs) capture longer-term dependencies \[[1](http://arxiv.org/abs/1808.09781)\]. However, these models often struggle with sparse data or dense datasets, prompting the development of more sophisticated architectures \[[1](http://arxiv.org/abs/1808.09781)\]. For instance, SASRec introduces a self-attention mechanism to balance the efficiency of MCs with the expressiveness of RNNs, allowing the model to focus on relevant items in a user's history \[[1](http://arxiv.org/abs/1808.09781)\]. Similarly, Caser uses convolutional filters to extract local features from sequences, enabling flexible modeling of both general preferences and sequential patterns \[[2](http://arxiv.org/abs/1809.07426)\]. BERT4Rec extends this idea by employing bidirectional self-attention, allowing the model to consider both left and right contexts in a sequence, thus improving the representation of user behavior \[[3](http://arxiv.org/abs/2411.01537)\]. TiSASRec further refines this by incorporating time intervals between interactions, providing a more nuanced understanding of temporal dynamics \[[4](http://arxiv.org/abs/1904.06690)\]. Additionally, models like SURGE integrate graph neural networks to capture complex interactions and cluster user preferences, enhancing the ability to distinguish core interests from noisy data \[[7](http://arxiv.org/abs/2312.00752)\]. The recent trend also includes contrastive learning frameworks, such as DCRec, which address popularity bias and disentangle user conformity from real interest by aligning representations across different views \[[8](http://arxiv.org/abs/2303.11780)\]. These advancements highlight the ongoing efforts to improve the accuracy and adaptability of sequential recommendation systems, particularly in handling diverse user behaviors and varying sequence lengths \[[1](http://arxiv.org/abs/1808.09781)\].

### <a id='category-attention-mechanisms-in-recommendations'></a>Attention Mechanisms in Recommendations: 1 papers found.
Attention mechanisms have become a cornerstone in sequential recommender systems (SRSs), with Transformer models demonstrating significant success in capturing complex user behavior patterns \[[3](http://arxiv.org/abs/2411.01537)\]. However, traditional attention mechanisms, such as dot-product attention, suffer from quadratic computational complexity due to the need to compute an attention matrix, which becomes prohibitive for long sequences \[[3](http://arxiv.org/abs/2411.01537)\]. To address this challenge, researchers have proposed efficient attention mechanisms that maintain the expressive power of traditional methods while reducing computational overhead. One such approach is the L2-Normalized Linear Attention (LinRec), which achieves linear complexity by leveraging the equivalence conditions of efficient attention mechanisms \[[3](http://arxiv.org/abs/2411.01537)\]. This method not only improves time and memory efficiency but also preserves the learning capabilities of traditional attention mechanisms, making it particularly suitable for long-term sequential recommendation tasks \[[3](http://arxiv.org/abs/2411.01537)\]. The theoretical and empirical validation of LinRec highlights its potential to enhance the scalability of Transformer-based SRSs, especially in scenarios involving large and variable-length user interaction sequences.

### <a id='category-state-space-modeling-for-sequences'></a>State-Space Modeling for Sequences: 5 papers found.
State-space modeling for sequences has emerged as a promising approach to address the limitations of traditional architectures like RNNs, CNNs, and Transformers in handling long-range dependencies and variable-length sequences \[[11](http://arxiv.org/abs/2111.00396)\]. These models, such as the Structured State Space (S4) model, leverage the fundamental state space model (SSM) to simulate sequences with efficient computation, enabling linear scaling in sequence length \[[11](http://arxiv.org/abs/2111.00396)\]. This is particularly important for applications like sequential recommendation, where user behavior sequences can be extremely long \[[19](http://arxiv.org/abs/2403.16371)\]. Recent advancements, such as the Mamba architecture, have further improved upon SSMs by introducing selective mechanisms that allow models to dynamically propagate or forget information based on the input, enhancing performance on discrete modalities like language \[[7](http://arxiv.org/abs/2312.00752)\]. Mamba's hardware-aware design enables fast inference and efficient processing, making it suitable for real-world applications with long sequences \[[7](http://arxiv.org/abs/2312.00752)\]. Similarly, frameworks like SSD4Rec and Mamba4Rec have adapted these state-space models for sequential recommendation, integrating them with specialized blocks to handle variable-length sequences and long-range dependencies \[[10](http://arxiv.org/abs/2409.01192)\]\[[13](http://arxiv.org/abs/2403.03900)\]. These models demonstrate significant improvements in both efficiency and effectiveness, achieving state-of-the-art results on benchmark datasets while maintaining linear scalability \[[10](http://arxiv.org/abs/2409.01192)\]\[[13](http://arxiv.org/abs/2403.03900)\]. The integration of state-space models with attention mechanisms, as seen in STAR-Rec, further highlights their potential to unify temporal dynamics with diverse item relationships, offering a robust solution for deep sequential recommendation \[[1](http://arxiv.org/abs/1808.09781)\].
