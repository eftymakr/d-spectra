## Related Works

Sequential recommendation systems aim to predict the next item a user will interact with based on their historical behavior \[[1](http://arxiv.org/abs/1808.09781)\]. These systems have evolved from simple Markov Chain models, which assume that the next action depends only on the last few actions, to more sophisticated models like Recurrent Neural Networks (RNNs) and Transformers, which capture longer-term dependencies \[[1](http://arxiv.org/abs/1808.09781)\]. However, these models often face challenges in handling long sequences and capturing diverse user behaviors \[[1](http://arxiv.org/abs/1808.09781)\].

Early approaches, such as Markov Chains, are efficient but limited in their ability to model complex sequential patterns \[[1](http://arxiv.org/abs/1808.09781)\]. RNNs, while more expressive, suffer from high computational complexity and difficulty in capturing long-term dependencies \[[1](http://arxiv.org/abs/1808.09781)\]. To address these limitations, attention-based models like SASRec and Caser have been proposed \[[1](http://arxiv.org/abs/1808.09781)\]\[[2](http://arxiv.org/abs/1809.07426)\]. SASRec uses self-attention to identify relevant items in a user's history, while Caser employs convolutional filters to extract local features from sequences \[[1](http://arxiv.org/abs/1808.09781)\]\[[2](http://arxiv.org/abs/1809.07426)\]. These models improve performance but often at the cost of increased computational requirements \[[1](http://arxiv.org/abs/1808.09781)\]\[[2](http://arxiv.org/abs/1809.07426)\].

The Transformer architecture, which underpins many modern sequential recommendation models, has also been adapted for this task \[[4](http://arxiv.org/abs/1904.06690)\]. BERT4Rec, for instance, uses bidirectional self-attention to model user behavior sequences, allowing for more comprehensive representation of user preferences \[[4](http://arxiv.org/abs/1904.06690)\]. However, the quadratic complexity of attention mechanisms limits their scalability to long sequences \[[4](http://arxiv.org/abs/1904.06690)\]. To mitigate this, LinRec introduces a linear attention mechanism that maintains the expressive power of dot-product attention while reducing computational overhead \[[3](http://arxiv.org/abs/2411.01537)\].

Temporal information has also been recognized as a critical factor in sequential recommendation \[[14](https://www.semanticscholar.org/paper/5574d6123deea94eba2cb35b2486851e826c16ce)\]. Models like TiSASRec explicitly model time intervals between interactions, improving the accuracy of next-item predictions \[[5](https://www.semanticscholar.org/paper/9c7a455b1e48d01a99e58e884a6c1acb75074ad0)\]. Similarly, the Temporal Graph Collaborative Transformer (TGSRec) integrates both sequential patterns and temporal collaborative signals, enhancing the modeling of user preferences over time \[[22](http://arxiv.org/abs/2108.06625)\].

Efficient modeling of long sequences remains a challenge, particularly for industrial applications where user interactions are frequent and extensive \[[10](http://arxiv.org/abs/2409.01192)\]. Mamba, a state space model with linear complexity, has shown promise in this regard \[[7](http://arxiv.org/abs/2312.00752)\]. Inspired by Mamba, SSD4Rec and Mamba4Rec further explore the potential of selective state space models for sequential recommendation, achieving state-of-the-art performance while maintaining efficiency \[[10](http://arxiv.org/abs/2409.01192)\]\[[13](http://arxiv.org/abs/2403.03900)\]. These models demonstrate that it is possible to balance effectiveness and efficiency in sequential recommendation tasks.
