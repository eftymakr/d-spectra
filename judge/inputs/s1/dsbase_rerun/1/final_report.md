## Related Works

Efficient inference for large language models (LLMs) has been a focal point of recent research, particularly in the context of key-value (KV) cache management. KV caches are essential for accelerating decoding by storing intermediate activations, but their memory footprint grows with sequence length, posing challenges for deployment \[[1' 2025-04-21](http://arxiv.org/abs/2504.15364v4)\]. Prior work has focused on reducing KV cache size while preserving generation quality, often through token eviction strategies that rely on attention scores or statistical patterns \[[2' 2025-05-24](http://arxiv.org/abs/2505.20334v2)\]. However, these methods typically allocate budgets uniformly across attention heads, ignoring the unique patterns of each head, which can lead to suboptimal performance \[[3' 2024-07-16](http://arxiv.org/abs/2407.11550v5)\].

Several approaches have been proposed to address this issue. KeyDiff \[[1' 2025-04-21](http://arxiv.org/abs/2504.15364v4)\] introduces a training-free KV cache eviction method based on key similarity, allowing for efficient processing of long prompts without relying on attention scores. This enables the use of optimized attention mechanisms like FlashAttention. Similarly, Lookahead Q-Cache \[[2' 2025-05-24](http://arxiv.org/abs/2505.20334v2)\] generates pseudo lookahead queries to better approximate real decoding queries, improving the consistency of cache eviction with actual inference scenarios. Ada-KV \[[3' 2024-07-16](http://arxiv.org/abs/2407.11550v5)\] builds on this by proposing an adaptive budget allocation strategy that operates at the head level, offering plug-and-play benefits and substantial quality improvements over existing methods.

The importance of accurate attention score estimation for cache eviction has also been emphasized. NACL \[[4' 2024-08-07](http://arxiv.org/abs/2408.03675v2)\] introduces a general framework that combines accurate attention score statistics with diversified random eviction strategies, significantly improving performance on both short- and long-text tasks. This approach reduces KV cache size by up to 50% while maintaining over 95% performance. InfiniGen \[[5' 2024-11-26](http://arxiv.org/abs/2411.17089v2)\] further enhances efficiency by leveraging dynamic KV cache management, allowing for speculative computation of essential KV cache entries without fetching all of them, thereby reducing fetch overhead in offloading-based systems.

Recent work has also explored the interplay between KV cache eviction and inference latency. ### <a id='category-kv-cache-management-techniques'></a>KV Cache Management Techniques: 4 papers found.
Key themes in KV cache management techniques revolve around optimizing memory usage and computational efficiency during LLM inference. Researchers have explored various strategies to mitigate the memory and performance bottlenecks caused by the rapid growth of KV caches. For instance, KVPR introduces an I/O-aware method that overlaps GPU recomputation with KV cache transfer, reducing idle GPU time and improving inference performance \[[5' 2024-11-26](http://arxiv.org/abs/2411.17089v2)\]. Similarly, InfiniGen leverages the insight that only essential tokens are needed for subsequent attention layers, allowing for selective prefetching of KV cache entries and reducing fetch overhead \[[6' 2024-06-28](http://arxiv.org/abs/2406.19707v1)\]. SAGE-KV further enhances efficiency by compressing the KV cache through top-k selection at both token and head levels, maintaining accuracy while significantly improving memory efficiency \[[7' 2025-03-11](http://arxiv.org/abs/2503.08879v1)\]. Additionally, R-KV focuses on reasoning models, proposing a redundancy-aware compression method that preserves nearly 100% of full KV cache performance using only 10% of the cache size, leading to substantial memory savings and throughput improvements \[[8' 2025-05-30](http://arxiv.org/abs/2505.24133v4)\]. These approaches collectively highlight the importance of workload-aware strategies and intelligent cache management in enhancing the scalability and performance of LLM inference systems.

### <a id='category-workload-aware-optimization'></a>Workload-Aware Optimization: 1 papers found.
Context: 
	Document 1: [Snippet]: «Efficiently serving large language models (LLMs) under dynamic and bursty workloads remains a key challenge for real-world deployment. Existing serving frameworks and static model compression techniques fail to adapt to workload fluctuations, leading to either service-level objective (SLO) violations under full-precision serving or persistent accuracy degradation with static quantization. We present MorphServe, a dynamic, workload-aware LLM serving framework based on morphological adaptation. MorphServe introduces two asynchronous, token-level runtime mechanisms: quantized layer swapping, which selectively replaces less impactful layers with quantized alternatives during high-load periods, and pressure-aware KV cache resizing, which dynamically adjusts KV cache capacity in response to memory pressure. These mechanisms enable state-preserving transitions with minimum runtime overhead and are fully compatible with modern scheduling and attention techniques. Extensive experiments on Vicuna and Llama family models with real-world workloads demonstrate that MorphServe reduces average SLO violations by 92.45 percent and improves the P95 TTFT latency by 2.2x-3.9x compared to full-precision serving, without compromising generation quality. These results establish MorphServe as a practical and elastic solution for LLM deployment in dynamic environments.»
