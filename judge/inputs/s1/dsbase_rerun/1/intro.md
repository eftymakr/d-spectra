## Related Works

Efficient inference for large language models (LLMs) has been a focal point of recent research, particularly in the context of key-value (KV) cache management. KV caches are essential for accelerating decoding by storing intermediate activations, but their memory footprint grows with sequence length, posing challenges for deployment \[[1' 2025-04-21](http://arxiv.org/abs/2504.15364v4)\]. Prior work has focused on reducing KV cache size while preserving generation quality, often through token eviction strategies that rely on attention scores or statistical patterns \[[2' 2025-05-24](http://arxiv.org/abs/2505.20334v2)\]. However, these methods typically allocate budgets uniformly across attention heads, ignoring the unique patterns of each head, which can lead to suboptimal performance \[[3' 2024-07-16](http://arxiv.org/abs/2407.11550v5)\].

Several approaches have been proposed to address this issue. KeyDiff \[[1' 2025-04-21](http://arxiv.org/abs/2504.15364v4)\] introduces a training-free KV cache eviction method based on key similarity, allowing for efficient processing of long prompts without relying on attention scores. This enables the use of optimized attention mechanisms like FlashAttention. Similarly, Lookahead Q-Cache \[[2' 2025-05-24](http://arxiv.org/abs/2505.20334v2)\] generates pseudo lookahead queries to better approximate real decoding queries, improving the consistency of cache eviction with actual inference scenarios. Ada-KV \[[3' 2024-07-16](http://arxiv.org/abs/2407.11550v5)\] builds on this by proposing an adaptive budget allocation strategy that operates at the head level, offering plug-and-play benefits and substantial quality improvements over existing methods.

The importance of accurate attention score estimation for cache eviction has also been emphasized. NACL \[[4' 2024-08-07](http://arxiv.org/abs/2408.03675v2)\] introduces a general framework that combines accurate attention score statistics with diversified random eviction strategies, significantly improving performance on both short- and long-text tasks. This approach reduces KV cache size by up to 50% while maintaining over 95% performance. InfiniGen \[[5' 2024-11-26](http://arxiv.org/abs/2411.17089v2)\] further enhances efficiency by leveraging dynamic KV cache management, allowing for speculative computation of essential KV cache entries without fetching all of them, thereby reducing fetch overhead in offloading-based systems.

Recent work has also explored the interplay between KV cache eviction and inference latency. KVPR \[[6' 2024-06-28](http://arxiv.org/abs/2406.19707v1)\] introduces an I/O-aware method that overlaps GPU recomputation with KV cache transfer, minimizing idle GPU time and improving throughput. This approach reduces latency by up to 35.8% and increases throughput by 46.2% compared to state-of-the-art methods. Additionally, SAGE-KV \[[7' 2025-03-11](http://arxiv.org/abs/2503.08879v1)\] leverages self-attention to guide cache eviction, achieving 4x higher memory efficiency with improved accuracy over static selection methods.
