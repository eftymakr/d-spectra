## Related Works

Neural retrieval models have shown significant promise in improving Web search performance by leveraging deep learning techniques to better understand the semantic relationships between queries and documents \[[6' 2021-02-23](http://arxiv.org/abs/2102.11903v2)\]. However, these models typically require extensive labeled query-document pairs for training, which are expensive and time-consuming to obtain \[[1' 2024-03-20](http://arxiv.org/abs/2403.13468v1)\]. To address this challenge, researchers have explored the use of synthetic queries generated by large language models (LLMs) as a scalable alternative \[[16' 2024-02-19](http://arxiv.org/abs/2402.12317v2)\]. These synthetic queries can be used to train retrieval models without the need for extensive human annotation \[[16' 2024-02-19](http://arxiv.org/abs/2402.12317v2)\]. However, the quality of these synthetic queries can vary, leading to suboptimal retrieval performance \[[16' 2024-02-19](http://arxiv.org/abs/2402.12317v2)\]. 

Existing methods often filter out noisy query-document pairs based on signals from an external re-ranker \[[16' 2024-02-19](http://arxiv.org/abs/2402.12317v2)\]. This approach, while effective, can be computationally intensive and may not fully capture the nuances of query-document relevance \[[16' 2024-02-19](http://arxiv.org/abs/2402.12317v2)\]. In contrast, our work proposes a framework that integrates ranking signals directly into the query generation process using Direct Preference Optimization (DPO) \[[17' 2024-11-01](http://arxiv.org/abs/2411.00744v2)\]. This approach aims to optimize the generation of high-quality synthetic queries that maximize downstream retrieval effectiveness \[[17' 2024-11-01](http://arxiv.org/abs/2411.00744v2)\]. 

DPO has been successfully applied in other domains, such as improving the accuracy of counter-speech generation by aligning LLM outputs with human preferences \[[7' 2024-12-19](http://arxiv.org/abs/2412.15453v1)\]. This method leverages preference-based alignment techniques to ensure that generated content is both contextually appropriate and linguistically accurate \[[7' 2024-12-19](http://arxiv.org/abs/2412.15453v1)\]. Similarly, in the field of information retrieval, DPO has been used to optimize query recommendations by generating more relevant and specific queries \[[14' 2024-05-30](http://arxiv.org/abs/2405.19749v2)\]. This approach has shown promising results in improving the performance of query recommendation systems, particularly in cold start scenarios where query logs are not available \[[14' 2024-05-30](http://arxiv.org/abs/2405.19749v2)\].
