## Related Works

Event cameras, which capture scene changes asynchronously on a per-pixel basis, offer significant advantages in temporal resolution over traditional frame-based cameras \[[12' 2020-03-02](http://arxiv.org/abs/2003.00847v2)\]. However, this high temporal resolution comes with challenges such as high bandwidth, memory, and computational demands \[[12' 2020-03-02](http://arxiv.org/abs/2003.00847v2)\]. Prior work has addressed these issues by exploring event downsampling techniques. Most existing approaches rely on fixed heuristics or threshold-based strategies, which limit their adaptability to different applications \[[12' 2020-03-02](http://arxiv.org/abs/2003.00847v2)\]. These methods often fail to account for scene-specific variations and can lead to suboptimal performance when applied to diverse tasks \[[12' 2020-03-02](http://arxiv.org/abs/2003.00847v2)\].

To overcome these limitations, recent research has proposed adaptive and context-aware event sampling strategies. For example, \[[6' 2024-05-28](http://arxiv.org/abs/2405.17769v1)\] introduced a system that uses event cameras to achieve fast localization and data streaming, mitigating issues related to screen refresh rates and camera motion. Similarly, \[[10' 2025-04-25](http://arxiv.org/abs/2504.18235v2)\] presented a benchmark for tuning the biases of event cameras, emphasizing the importance of optimal parameter settings for performance. These works highlight the need for dynamic and scene-adaptive sampling strategies.

In the field of probabilistic modeling, \[[3' 2012-12-03](http://arxiv.org/abs/1212.0582v1)\] proposed an implicit adaptive importance sampling method that iteratively matches moments of Monte Carlo draws to weighted moments based on importance weights. This approach is particularly useful for complex distributions that are not available in closed form. The method has been applied to Bayesian leave-one-out cross-validation, demonstrating better performance than existing parametric methods while being computationally inexpensive \[[3' 2012-12-03](http://arxiv.org/abs/1212.0582v1)\]. This work aligns with the idea of using probabilistic frameworks to model event importance, which is central to our proposed POLED framework.

Additionally, \[[11' 2012-12-05](http://arxiv.org/abs/1212.0967v1)\] explored the use of relational database schemata to automatically construct Bayesian graphical models, demonstrating the potential of probabilistic modeling in capturing complex dependencies. While not directly related to event cameras, this work supports the broader application of probabilistic models in adaptive sampling and scene understanding.

In the context of event-based vision, \[[8' 2018-07-25](http://arxiv.org/abs/1807.09480v2)\] proposed attention mechanisms for object recognition, emphasizing the importance of focusing on regions of interest. These attention-based methods have been applied to various datasets, improving translation and scale invariance in event-based vision tasks. Similarly, \[[12' 2020-03-02](http://arxiv.org/abs/2003.00847v2)\] explored the use of event cameras for deblurring and generating high frame rate video, demonstrating the potential of event-based data in high-speed applications.

Adaptive importance sampling techniques aim to improve the efficiency of Monte Carlo methods by dynamically adjusting proposal distributions to better match target distributions, particularly in complex scenarios where closed-form solutions are unavailable \[[1' 2019-06-20](http://arxiv.org/abs/1906.08850v2)\]. This approach iteratively refines the proposal distribution using weighted moments derived from Monte Carlo samples, leading to more accurate and computationally efficient inference \[[1' 2019-06-20](http://arxiv.org/abs/1906.08850v2)\]. In parallel, probabilistic programming has emerged as a powerful framework for stochastic modeling, enabling the systematic derivation of algorithms for simulation, inference, and model reduction through compositional approaches that handle continuous-time dynamics and parallel processes \[[3' 2012-12-03](http://arxiv.org/abs/1212.0582v1)\]. Additionally, automated Bayesian graphical model construction from relational database schemas has been explored, allowing for the creation of models that incorporate customized distributions, latent variables, and factors representing foreign key links, thereby enhancing scalability and accuracy in data modeling \[[11' 2012-12-05](http://arxiv.org/abs/1212.0967v1)\]. These methods collectively highlight the growing interest in adaptive and automated approaches for probabilistic modeling, emphasizing the need for flexible and efficient techniques to handle uncertainty and complexity in diverse applications.

### <a id='category-event-based-vision-applications'></a>Event-Based Vision Applications: 6 papers found.
Event cameras, which capture scene changes asynchronously on a per-pixel basis, offer high temporal resolution but face challenges in managing bandwidth, memory, and computational demands \[[12' 2020-03-02](http://arxiv.org/abs/2003.00847v2)\]. Prior approaches to address these issues have relied on fixed heuristics or threshold-based event downsampling strategies, which limit adaptability to varying scenarios \[[12' 2020-03-02](http://arxiv.org/abs/2003.00847v2)\]. In contrast, recent work proposes a probabilistic framework, POLED, that models event importance using an event-importance probability density function (ePDF), allowing for scene-specific adaptation and online estimation of event importance \[[12' 2020-03-02](http://arxiv.org/abs/2003.00847v2)\]. This approach enables more intelligent sampling, crucial for maintaining performance under event-budget constraints \[[12' 2020-03-02](http://arxiv.org/abs/2003.00847v2)\]. Additionally, the concept of zero-shot event downsampling has been introduced, where downsampled events must remain usable for models trained on the original event stream without task-specific adaptation \[[12' 2020-03-02](http://arxiv.org/abs/2003.00847v2)\]. This aligns with broader efforts in event-based vision, such as the use of event cameras for high-speed robotic perception \[[4' 2025-05-16](http://arxiv.org/abs/2505.11282v2)\], dynamic visual marker tracking \[[1' 2019-06-20](http://arxiv.org/abs/1906.08850v2)\], and overcoming motion blur and texture instability \[[6' 2024-05-28](http://arxiv.org/abs/2405.17769v1)\]. These studies highlight the growing interest in leveraging event cameras for applications requiring high temporal resolution and robustness to dynamic conditions.
