## Related Works

Deep sequential recommendation models have seen significant advancements, driven by the need to effectively model user behavior patterns and handle variable-length sequences. Traditional approaches, such as RNNs and attention-based models, have been widely used but face challenges in computational efficiency and capturing diverse interaction patterns \[[16' 2023-10-03](http://arxiv.org/abs/2310.02367v2)\]. For instance, self-attention mechanisms, while powerful in modeling long-range dependencies, suffer from quadratic computational complexity, which becomes prohibitive for long sequences \[[1' 2025-01-02](http://arxiv.org/abs/2501.01242v1)\]. This limitation has motivated the exploration of alternative architectures, such as state space models (SSMs), which offer linear complexity and efficient processing of variable-length sequences \[[6' 2024-03-06](http://arxiv.org/abs/2403.03900v2)\].

Several works have attempted to address these challenges by introducing novel attention mechanisms or integrating SSMs into sequential recommendation frameworks. For example, HydraRec proposes a linear attention mechanism that reduces the complexity of attention computation while preserving temporal context \[[1' 2025-01-02](http://arxiv.org/abs/2501.01242v1)\]. Similarly, MLSA4Rec combines Mamba with low-rank decomposed self-attention to achieve linear complexity and structural bias, enhancing the model's ability to capture both local and global patterns \[[2' 2024-07-18](http://arxiv.org/abs/2407.13135v1)\]. These models demonstrate that hybrid approaches can offer a balance between efficiency and effectiveness.

State space models, particularly Mamba, have also gained traction for their ability to handle long sequences with linear complexity \[[6' 2024-03-06](http://arxiv.org/abs/2403.03900v2)\]. Mamba4Rec is the first work to explore the potential of selective SSMs for efficient sequential recommendation, leveraging the Mamba block's hardware-aware parallel algorithm to improve inference efficiency \[[6' 2024-03-06](http://arxiv.org/abs/2403.03900v2)\]. Similarly, EchoMamba4Rec integrates bi-directional processing with frequency-domain filtering to capture complex patterns in user interaction data, further enhancing the model's expressiveness \[[7' 2024-06-04](http://arxiv.org/abs/2406.02638v2)\]. These models highlight the growing interest in SSMs for sequential recommendation tasks.

In addition to SSMs, some works have focused on improving attention mechanisms to better capture diverse user preferences. For example, FEARec introduces a frequency-enhanced hybrid attention network that explicitly learns both low- and high-frequency information, enabling the model to capture periodic patterns in user behavior \[[4' 2023-04-18](http://arxiv.org/abs/2304.09184v3)\]. Similarly, AWRSR refines attention distributions by paying attention to attention weights, allowing for more accurate modeling of high-order dependencies \[[12' 2024-10-28](http://arxiv.org/abs/2410.21048v1)\]. These approaches demonstrate the potential of attention mechanisms to improve recommendation accuracy when augmented with additional modeling components.

Finally, recent studies have explored the integration of knowledge graphs and counterfactual reasoning to enhance the robustness of sequential recommendation models.
