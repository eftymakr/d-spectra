## Related Works

Maximum Inner Product Search (MIPS) has been extensively studied in the context of high-dimensional data retrieval and machine learning. Traditional approaches to MIPS often rely solely on inner product (IP) similarity, which can lead to issues such as local optima and redundant computations \[[1' 2019-11-12](http://arxiv.org/abs/1911.04654v2)\]. Alternatively, some methods reduce the MIPS problem to nearest neighbor search under the Euclidean metric through space projection, but this often results in topology destruction and information loss \[[2' 2018-12-15](http://arxiv.org/abs/1812.06360v1)\]. Despite these divergent paradigms, recent work has argued that there is no inherent binary opposition between IP and Euclidean metrics \[[3' 2014-05-22](http://arxiv.org/abs/1405.5869v1)\]. Instead, by integrating both metrics into indexing and search algorithms, significant performance improvements can be achieved \[[4' 2023-09-16](http://arxiv.org/abs/2309.09013v1)\].

Several studies have explored approximate methods for MIPS, particularly in the context of large-scale datasets. For instance, Norm-Explicit Quantization (NEQ) improves existing vector quantization techniques by explicitly quantizing the norms of items, which is crucial for MIPS \[[5' 2014-06-19](http://arxiv.org/abs/1406.4966v2)\]. Similarly, Asymmetric LSH (ALSH) was introduced as the first provably sublinear time algorithm for approximate MIPS, leveraging asymmetric transformations to convert the problem into near neighbor search \[[6' 2023-01-25](http://arxiv.org/abs/2301.10622v1)\]. Norm-Ranging LSH further enhances this by partitioning datasets into sub-datasets to address long-tail distributions \[[7' 2019-08-23](http://arxiv.org/abs/1908.08656v2)\].

Another line of research focuses on the use of tree-based data structures for efficient MIPS. The paper by \[[8' 2021-10-14](http://arxiv.org/abs/2110.07131v1)\] presents a general branch-and-bound algorithm using a tree data structure, which significantly improves query time over naive search techniques. Similarly, the paper by \[[9' 2019-09-30](http://arxiv.org/abs/1909.13459v2)\] introduces a dual-tree algorithm for multiple queries, further enhancing efficiency. These tree-based approaches have been further refined with the introduction of the ip-NSW graph, which achieves an order of magnitude speedup over previous methods \[[10' 2018-09-24](http://arxiv.org/abs/1809.08782v2)\].

In addition to tree-based and hashing-based methods, there has been work on clustering-based approaches for MIPS. For example, the paper by \[[11' 2014-10-20](http://arxiv.org/abs/1410.5410v2)\] explores clustering-based nearest neighbor search, where points are partitioned into geometric shards to form an index, and only a few shards are searched during queries. ### <a id='category-reverse-mips-algorithms'></a>Reverse MIPS Algorithms: 2 papers found.
The category "Reverse MIPS Algorithms" focuses on solving the Reverse Maximum Inner Product Search (Reverse MIPS) problem, which involves identifying user vectors with the highest inner product with a query vector, given sets of user and item vectors. This problem is critical in recommendation systems, especially for e-commerce companies aiming to promote new or discounted items by targeting interested users \[[8' 2021-10-14](http://arxiv.org/abs/2110.07131v1)\]. Existing approaches, such as Simpfer, introduce efficient indexing strategies that maintain lower bounds of maximum inner products, enabling fast filtering of user vectors during search \[[8' 2021-10-14](http://arxiv.org/abs/2110.07131v1)\]. Similarly, the R$k$MIPS problem extends this by seeking the top $k$ user vectors with the highest inner products, and the Shifting-aware Asymmetric Hashing (SAH) algorithm provides a subquadratic-time solution with theoretical guarantees \[[19' 2022-11-23](http://arxiv.org/abs/2211.12751v1)\]. These methods leverage asymmetric transformations and hashing schemes to enhance search efficiency while preserving accuracy. Both Simpfer and SAH demonstrate significant performance improvements over traditional MIPS techniques, with Simpfer achieving at least two orders of magnitude speedup in experiments \[[8' 2021-10-14](http://arxiv.org/abs/2110.07131v1)\], and SAH delivering up to 8x faster results with high F1-scores \[[19' 2022-11-23](http://arxiv.org/abs/2211.12751v1)\]. These advancements highlight the growing importance of reverse MIPS algorithms in efficiently addressing recommendation challenges in high-dimensional data scenarios.
