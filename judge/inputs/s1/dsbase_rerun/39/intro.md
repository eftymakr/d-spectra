## Related Works

De novo genome assembly remains a computationally intensive task, with significant challenges related to memory usage, algorithmic complexity, and scalability \[[1' 2011-06-14](http://arxiv.org/abs/1106.2603v1)\]. Early approaches, such as those based on de Bruijn graphs, have been widely used but suffer from high memory requirements, which scale with the k-mer length and diversity of the genome \[[1' 2011-06-14](http://arxiv.org/abs/1106.2603v1)\]. This limitation becomes particularly pronounced when handling large-scale genomic data or multiple genomes simultaneously \[[1' 2011-06-14](http://arxiv.org/abs/1106.2603v1)\]. To address this, SparseAssembler was introduced, employing a sparse de Bruijn graph structure that significantly reduces memory usage while maintaining comparable assembly quality \[[1' 2011-06-14](http://arxiv.org/abs/1106.2603v1)\]. This approach also includes a denoising algorithm to remove substitution errors, which is crucial given the error rates of current sequencing technologies \[[1' 2011-06-14](http://arxiv.org/abs/1106.2603v1)\].

Distributed-memory parallel algorithms have also been developed to improve the efficiency of de novo assembly, particularly for large genomes \[[2' 2020-10-20](http://arxiv.org/abs/2010.10055v1)\]. These algorithms leverage linear-algebra operations over semirings using 2D distributed sparse matrices to accelerate overlap detection and layout simplification \[[2' 2020-10-20](http://arxiv.org/abs/2010.10055v1)\]. The implementation, diBELLA 2D, demonstrates near-linear scaling with high parallel efficiency, significantly reducing runtime for both human and *C. elegans* genomes \[[2' 2020-10-20](http://arxiv.org/abs/2010.10055v1)\]. Similarly, the HipMER assembler is designed for extreme-scale analysis, utilizing efficient parallelization of the Meraculous code to handle large genomes like the hexaploid wheat genome \[[3' 2017-05-31](http://arxiv.org/abs/1705.11147v1)\].

Transcriptome assembly, a related but distinct task, has also seen advancements. SOAPdenovo-Trans was developed specifically for RNA-Seq data, offering improved contiguity and faster execution compared to other assemblers \[[4' 2013-05-29](http://arxiv.org/abs/1305.6760v2)\]. It was evaluated on transcriptome datasets from rice and mouse, using known transcripts as benchmarks \[[4' 2013-05-29](http://arxiv.org/abs/1305.6760v2)\]. Additionally, the Assemblathon 2 competition highlighted the variability in performance across different assemblers and underscored the need for more robust evaluation metrics \[[5' 2013-01-23](http://arxiv.org/abs/1301.5406v3)\].

Recent work has also explored the use of reinforcement learning for genome assembly, aiming to automate and improve the accuracy of the process \[[7' 2021-02-02](http://arxiv.org/abs/2102.02649v4)\]. While promising, these approaches face challenges due to the high dimensionality of state and action spaces \[[7' 2021-02-02](http://arxiv.org/abs/2102.02649v4)\]. Another notable contribution is the development of a linear-time algorithm for identifying superbubbles in de Bruijn graphs, which aids in filtering out sequencing errors and repetitive structures \[[8' 2015-05-15](http://arxiv.org/abs/1505.04019v6)\].

In the context of theoretical advancements, a linear-time algorithm for identifying maximal omnitigs in genome assembly graphs has been proposed, offering a safe and complete solution to the problem \[[9' 2020-02-24](http://arxiv.org/abs/2002.10498v3)\].
