## Related Works

Conversational recommendation systems (CRSs) leverage multi-turn interactions to capture user preferences and deliver personalized recommendations. However, accurately understanding user preferences remains a significant challenge, particularly due to the complexity and multifaceted nature of user preferences \[[1' 2023-04-26](http://arxiv.org/abs/2304.13874v3)\]. This challenge is exacerbated by the need for frequent user involvement, which can degrade the user experience \[[1' 2023-04-26](http://arxiv.org/abs/2304.13874v3)\]. To address these issues, this paper introduces a generative reward model-based simulated user, named GRSU, for automatic interaction with CRSs \[[1' 2023-04-26](http://arxiv.org/abs/2304.13874v3)\]. This approach is inspired by existing work on user simulation and feedback processing in conversational systems \[[3' 2023-09-19](http://arxiv.org/abs/2309.10691v3)\].

User simulation has been widely explored in conversational search systems to address the lack of real user interaction data \[[3' 2023-09-19](http://arxiv.org/abs/2309.10691v3)\]. For instance, ConvSim, a user simulator, enables multi-turn interactions with mixed-initiative conversational search systems by providing feedback and answering clarifying questions \[[3' 2023-09-19](http://arxiv.org/abs/2309.10691v3)\]. Similarly, the use of simulated users in recommendation systems has been explored to reduce the reliance on human feedback and improve the efficiency of multi-turn interactions \[[10' 2024-09-04](http://arxiv.org/abs/2409.02392v2)\]. The GRSU model builds on these ideas by incorporating generative feedback mechanisms to better capture user preferences through multi-turn interaction \[[1' 2023-04-26](http://arxiv.org/abs/2304.13874v3)\].

Feedback processing in conversational systems has also been studied in the context of reinforcement learning and reward modeling. For example, the Follow-up Likelihood as Reward (FLR) mechanism uses the likelihood of follow-up utterances as a reward signal to differentiate preferred responses from less favored ones \[[2' 2024-09-20](http://arxiv.org/abs/2409.13948v3)\]. This approach aligns with the idea of using simulated feedback to guide the learning process in conversational systems. Additionally, the use of natural language feedback in multi-turn interactions has been shown to improve the performance of large language models (LLMs) in complex tasks \[[10' 2024-09-04](http://arxiv.org/abs/2409.02392v2)\]. The GRSU model extends this by introducing two types of feedback actions: generative item scoring for coarse-grained feedback and attribute-based item critique for fine-grained feedback \[[1' 2023-04-26](http://arxiv.org/abs/2304.13874v3)\].

To ensure seamless integration of these feedback mechanisms, the GRSU model employs an instruction-based format, allowing for the development of a unified simulated user through instruction tuning on synthesized data \[[1' 2023-04-26](http://arxiv.org/abs/2304.13874v3)\]. This approach is similar to the use of instruction tuning in conversational recommendation systems, where models are trained to generate responses based on user instructions \[[5' 2020-02-12](http://arxiv.org/abs/2002.05063v1)\]. Additionally, the GRSU model draws inspiration from reward-guided search paradigms in complex reasoning tasks, employing beam search to balance effectiveness and efficiency during the interaction process \[[1' 2023-04-26](http://arxiv.org/abs/2304.13874v3)\].
