## Related Works

Unsupervised domain adaptation (UDA) for semantic segmentation has been a focal point in recent years, aiming to transfer knowledge from a labeled source domain to an unlabeled target domain without requiring explicit alignment of class labels \[[1' 2022-08-12](http://arxiv.org/abs/2208.06507v1)\]. Traditional approaches often assume that the category settings between the source and target domains are known, which is not always the case in real-world applications \[[1' 2022-08-12](http://arxiv.org/abs/2208.06507v1)\]. This assumption can lead to performance degradation when private classes exist in the target domain \[[1' 2022-08-12](http://arxiv.org/abs/2208.06507v1)\]. 

Several works have addressed domain adaptation in semantic segmentation by focusing on feature alignment and distribution matching. For instance, \[[2' 2020-12-15](http://arxiv.org/abs/2012.08226v2)\] introduced a learnable clustering module and a novel domain adaptation framework called cross-domain grouping and alignment, which improves adaptation performance by encouraging semantic consistency and orthogonality among clusters \[[2' 2020-12-15](http://arxiv.org/abs/2012.08226v2)\]. Similarly, \[[3' 2022-06-07](http://arxiv.org/abs/2206.03600v2)\] proposed a method that leverages a class-conditional multi-scale discriminator and a class-conditional loss to equalize loss over classes and improve domain adaptation \[[3' 2022-06-07](http://arxiv.org/abs/2206.03600v2)\]. 

In the context of open-set domain adaptation, \[[4' 2021-08-13](http://arxiv.org/abs/2108.06383v1)\] introduced a method that allows the model to identify unknown classes in the target domain by using a contrastive loss to discern boundaries between known and unknown classes \[[4' 2021-08-13](http://arxiv.org/abs/2108.06383v1)\]. This is particularly relevant to the problem of handling private classes in the target domain, as it enables the model to distinguish between known and unknown categories \[[4' 2021-08-13](http://arxiv.org/abs/2108.06383v1)\]. 

Another approach to domain adaptation involves the use of pseudo-labels and self-training. For example, \[[5' 2022-04-05](http://arxiv.org/abs/2204.02111v1)\] proposed a framework that uses pseudo-labels generated from the target domain to refine the model's predictions iteratively \[[5' 2022-04-05](http://arxiv.org/abs/2204.02111v1)\]. This technique has been further enhanced by methods such as \[[6' 2024-05-30](http://arxiv.org/abs/2405.19899v1)\], which introduces a threshold-adaptive unsupervised focal loss to regularize predictions in the target domain and mitigate the problem of hard samples being barely optimized \[[6' 2024-05-30](http://arxiv.org/abs/2405.19899v1)\]. 

The use of adversarial learning has also been explored in domain adaptation for semantic segmentation. \[[7' 2019-11-27](http://arxiv.org/abs/1911.11981v2)\] introduced a method that uses adversarial learning to align latent feature distributions across domains during the latent diffusion process, achieving state-of-the-art results on benchmark datasets \[[7' 2019-11-27](http://arxiv.org/abs/1911.11981v2)\]. Additionally, \[[8' 2023-02-13](http://arxiv.org/abs/2302.06378v1)\] proposed a framework that incorporates contrastive losses into a student-teacher learning paradigm, making use of pseudo-labels generated from the target domain by the teacher network \[[8' 2023-02-13](http://arxiv.org/abs/2302.06378v1)\]. 

In the context of multi-source and semi-supervised domain adaptation, \[[9' 2021-10-21](http://arxiv.org/abs/2110.11062v1)\] investigated both pixel-level and feature-level adaptation, as well as the fusion of features from different backbones to facilitate the learning of domain-invariant classifiers \[[9' 2021-10-21](http://arxiv.org/abs/2110.11062v1)\].
