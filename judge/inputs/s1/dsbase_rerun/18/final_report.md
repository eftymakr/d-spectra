## Related Works

Anomaly detection has become a critical component in intelligent manufacturing, enabling quality control on modern production lines \[[1' 2023-06-25](http://arxiv.org/abs/2306.14289v2)\]. While numerous models have demonstrated promising performance, many are too large and computationally intensive for deployment on resource-constrained embedded devices, especially in Small and Medium Enterprises (SMEs) \[[1' 2023-06-25](http://arxiv.org/abs/2306.14289v2)\]. This challenge has motivated the development of lightweight and efficient models that can be deployed on edge devices. One such effort is MobileSAM, a lightweight variant of the Segment Anything Model (SAM) that is designed for mobile applications \[[2' 2024-11-03](http://arxiv.org/abs/2411.01431v2)\]. MobileSAM reduces the model size by more than 60 times while maintaining performance comparable to the original SAM, and it achieves an inference speed of around 10ms per image on a single GPU \[[2' 2024-11-03](http://arxiv.org/abs/2411.01431v2)\]. This makes it a strong candidate for deployment on embedded systems.

Several other works have focused on improving the efficiency of anomaly detection models for embedded computing systems. For example, the paper by Zhang et al. \[[3' 2024-08-27](http://arxiv.org/abs/2408.15113v2)\] provides a comprehensive survey of efficient deep learning infrastructures for embedded systems, covering topics such as network compression, automated design, and hardware-software co-design. This survey highlights the growing need for efficient models that can run on resource-constrained devices \[[3' 2024-08-27](http://arxiv.org/abs/2408.15113v2)\]. Similarly, the work by Zhang et al. \[[4' 2024-03-07](http://arxiv.org/abs/2403.04932v2)\] introduces a tiled ensemble approach for high-resolution industrial anomaly detection, which reduces memory consumption by dividing images into tiles and training a dedicated model for each tile location. This method is compatible with existing anomaly detection models and can be used with a variety of architectures, including Padim, PatchCore, and FastFlow \[[4' 2024-03-07](http://arxiv.org/abs/2403.04932v2)\].

Another approach to improving the efficiency of anomaly detection is the use of lightweight architectures and memory-efficient techniques. For instance, TinyAD \[[5' 2025-04-10](http://arxiv.org/abs/2504.08115v1)\] proposes a framework for deploying CNNs on memory-constrained Industrial Internet of Things (IIoT) devices by using depthwise separable convolutions and memory rescheduling strategies. This reduces the peak memory consumption of CNNs by 2–5 times with negligible computation overhead \[[5' 2025-04-10](http://arxiv.org/abs/2504.08115v1)\]. Similarly, the Prior Normality Prompt Transformer (PNPT) \[[6' 2024-04-10](http://arxiv.org/abs/2404.06832v1)\] introduces a dual-stream architecture for multi-class industrial image anomaly detection, combining normal prior semantics with abnormal samples to improve discrimination between normal and abnormal instances \[[6' 2024-04-10](http://arxiv.org/abs/2404.06832v1)\].

In addition to model efficiency, the use of synthetic data and weakly-supervised learning has also been explored to reduce the dependency on large labeled datasets. The paper by Zhang et al. \[[7' 2023-03-07](http://arxiv.org/abs/2303.03611v1)\] introduces a weakly-supervised approach using Digital Twin systems to generate synthetic datasets for anomaly detection

	Document 1: [Snippet]: «Segment Anything Model (SAM) has attracted significant attention due to its impressive zero-shot transfer performance and high versatility for numerous vision applications (like image editing with fine-grained control). Many of such applications need to be run on resource-constraint edge devices, like mobile phones. In this work, we aim to make SAM mobile-friendly by replacing the heavyweight image encoder with a lightweight one. A naive way to train such a new SAM as in the original SAM paper leads to unsatisfactory performance, especially when limited training sources are available. We find that this is mainly caused by the coupled optimization of the image encoder and mask decoder, motivated by which we propose decoupled distillation. Concretly, we distill the knowledge from the heavy image encoder (ViT-H in the original SAM) to a lightweight image encoder, which can be automatically compatible with the mask decoder in the original SAM. The training can be completed on a single GPU within less than one day, and the resulting lightweight SAM is termed MobileSAM which is more than 60 times smaller yet performs on par with the original SAM. For inference speed, With a single GPU, MobileSAM runs around 10ms per image: 8ms on the image encoder and 4ms on the mask decoder. With superior performance, our MobileSAM is around 5 times faster than the concurrent FastSAM and 7 times smaller, making it more suitable for mobile applications. Moreover, we show that MobileSAM can run relatively smoothly on CPU. The code for our project is provided at \href(https://github.com/ChaoningZhang/MobileSAM)(\textcolor(red)(MobileSAM))), with a demo showing that MobileSAM can run relatively smoothly on CPU.»

	Document 1: [Snippet]: «Industrial anomaly detection is an important task within computer vision with a wide range of practical use cases. The small size of anomalous regions in many real-world datasets necessitates processing the images at a high resolution. This frequently poses significant challenges concerning memory consumption during the model training and inference stages, leaving some existing methods impractical for widespread adoption. To overcome this challenge, we present the tiled ensemble approach, which reduces memory consumption by dividing the input images into a grid of tiles and training a dedicated model for each tile location. The tiled ensemble is compatible with any existing anomaly detection model without the need for any modification of the underlying architecture. By introducing overlapping tiles, we utilize the benefits of traditional stacking ensembles, leading to further improvements in anomaly detection capabilities beyond high resolution alone. We perform a comprehensive analysis using diverse underlying architectures, including Padim, PatchCore, FastFlow, and Reverse Distillation, on two standard anomaly detection datasets: MVTec and VisA. Our method demonstrates a notable improvement across setups while remaining within GPU memory constraints, consuming only as much GPU memory as a single model needs to process a single tile.»

In this paper, we present novel weakly-supervised approaches to anomaly detection for industrial settings.
