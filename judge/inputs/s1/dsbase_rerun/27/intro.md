## Related Works

Natural language (NL)-driven table discovery has gained significant attention in recent years due to the increasing availability of large table repositories and the need for efficient and accurate retrieval mechanisms. Early approaches primarily relied on traditional dense vector search pipelines, which involve representation, indexing, and search stages \[[5' 2017-06-08](http://arxiv.org/abs/1706.02427v1)\]. These methods, while achieving notable accuracy, suffer from error accumulation during the representation and indexing phases, which degrades search accuracy \[[1' 2022-02-14](http://arxiv.org/abs/2202.06991v3)\]. Additionally, insufficient interaction between queries and tables limits semantic alignment and hinders accuracy improvements \[[1' 2022-02-14](http://arxiv.org/abs/2202.06991v3)\].

Several works have attempted to address these limitations by introducing more sophisticated indexing and retrieval frameworks. The Differentiable Search Index (DSI) \[[1' 2022-02-14](http://arxiv.org/abs/2202.06991v3)\] is a notable paradigm that simplifies the retrieval process by encoding all information about the corpus directly into the model's parameters. This approach allows for direct query-to-docid mapping without the need for separate indexing steps. However, DSI has been found to struggle with distinguishing relevant documents from random ones, which impacts retrieval effectiveness \[[2' 2023-05-03](http://arxiv.org/abs/2305.02073v2)\]. To address this, a multi-task distillation approach was proposed to enhance retrieval quality without altering the model structure \[[2' 2023-05-03](http://arxiv.org/abs/2305.02073v2)\].

In the context of table discovery, the NLCTables dataset \[[3' 2025-04-22](http://arxiv.org/abs/2504.15849v1)\] was introduced to evaluate the performance of table discovery methods under various conditions, including NL-only, union, join, and fuzzy conditions. This dataset includes 627 diverse queries and 22,020 candidate tables, providing a comprehensive benchmark for evaluating new methods. The results of this study highlighted the need for advanced techniques to improve performance in NL-conditional table discovery \[[3' 2025-04-22](http://arxiv.org/abs/2504.15849v1)\].

Recent work has also explored the use of large language models (LLMs) to generate synthetic queries for improving the accuracy of table retrieval systems \[[19' 2024-06-10](http://arxiv.org/abs/2406.06729v1)\]. These synthetic queries are designed to be similar to real user queries, allowing for more effective semantic alignment between queries and tables. This approach complements template-based methods and has shown promising results in improving retrieval accuracy \[[19' 2024-06-10](http://arxiv.org/abs/2406.06729v1)\].

The De-DSI framework \[[6' 2024-04-18](http://arxiv.org/abs/2404.12237v2)\] further extends the DSI concept by introducing a decentralized architecture that enables efficient retrieval without direct document access. This framework uses an ensemble of DSI models trained on smaller shards of data, which improves scalability and allows for distributed computation. The results demonstrate that De-DSI achieves retrieval success comparable to centralized methods while enabling fast updates to the index \[[6' 2024-04-18](http://arxiv.org/abs/2404.12237v2)\].
