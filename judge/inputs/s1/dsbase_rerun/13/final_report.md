## Related Works

Long-tailed recognition remains a challenging problem in computer vision due to the skewed class distribution in real-world datasets \[[1' 2021-11-27](http://arxiv.org/abs/2111.13998v2)\]. Many prior works have explored various strategies to address this issue, including data reweighing, resampling, and supervised contrastive learning \[[3' 2023-06-28](http://arxiv.org/abs/2306.15925v2)\]. For instance, \[[1' 2021-11-27](http://arxiv.org/abs/2111.13998v2)\] highlights that imbalanced data leads to poor separability of minority class samples in the feature space, which hinders model generalization. To mitigate this, \[[3' 2023-06-28](http://arxiv.org/abs/2306.15925v2)\] proposes targeted supervised contrastive learning (TSC), which ensures uniform distribution of features on the hypersphere by aligning class representations with uniformly distributed targets. This approach improves class boundaries and generalization, especially for long-tailed data.

Contrastive learning has also been extensively studied for long-tailed recognition. \[[6' 2024-03-10](http://arxiv.org/abs/2403.06151v1)\] discusses how contrastive learning methods struggle with long-tailed tasks because they maximize mutual information between latent features and input data, ignoring the ground-truth labels. To address this, \[[6' 2024-03-10](http://arxiv.org/abs/2403.06151v1)\] introduces a method that integrates contrastive learning with logit adjustment, leading to state-of-the-art performance on long-tailed benchmarks. Similarly, \[[7' 2023-09-28](http://arxiv.org/abs/2309.16135v1)\] proposes subclass-balancing contrastive learning (SBCL), which clusters head classes into subclasses to enforce a two-layer class hierarchy. This approach preserves semantic substructures while maintaining balance between head and tail classes, achieving competitive results on multiple datasets.

Another line of research focuses on improving contrastive learning by addressing gradient imbalances and conflicts. \[[8' 2022-11-22](http://arxiv.org/abs/2211.11938v1)\] identifies that supervised contrastive learning (SCL) fails to form a regular simplex in long-tailed data, which is crucial for effective representation learning. To correct this, \[[8' 2022-11-22](http://arxiv.org/abs/2211.11938v1)\] introduces balanced contrastive learning (BCL), which includes class-averaging and class-complement techniques to balance negative class contributions and ensure all classes appear in every mini-batch. This leads to better feature representation and improved performance on benchmarks such as CIFAR-10-LT and ImageNet-LT.

Additionally, \[[9' 2024-07-06](http://arxiv.org/abs/2407.04911v1)\] explores the use of latent categories to enhance feature representation in long-tailed recognition. By learning class-agnostic latent features shared among head and tail classes, \[[9' 2024-07-06](http://arxiv.org/abs/2407.04911v1)\] improves the diversity of training samples and achieves state-of-the-art results. Similarly, \[[10' 2024-10-08](http://arxiv.org/abs/2410.06109v1)\] introduces a method that leverages semantic data augmentation to enrich tail class representations, leading to significant improvements in accuracy.

### <a id='category-supervised-contrastive-learning-(scl)-approaches'></a>Supervised Contrastive Learning (SCL) Approaches: 6 papers found.
Supervised Contrastive Learning (SCL) has emerged as a promising approach for improving long-tailed recognition tasks by leveraging contrastive learning to enhance feature representation \[[1' 2021-11-27](http://arxiv.org/abs/2111.13998v2)\]. However, existing methods face challenges due to class imbalance, which leads to poor uniformity and separability of minority class samples in the feature space \[[1' 2021-11-27](http://arxiv.org/abs/2111.13998v2)\]. For instance, SCL typically treats two types of positive samples—augmented versions and other same-class images—equally, which can bias intra-category distance optimization and overlook meaningful semantic cues from negative samples \[[6' 2024-03-10](http://arxiv.org/abs/2403.06151v1)\]. To address these issues, researchers have proposed modifications such as decoupling positive samples and optimizing them toward distinct objectives, thereby alleviating the impact of imbalanced datasets \[[6' 2024-03-10](http://arxiv.org/abs/2403.06151v1)\]. Additionally, methods like MixUp-based data augmentation and class-mixture-based loss have been introduced to balance the latent feature space and improve generalization \[[8' 2022-11-22](http://arxiv.org/abs/2211.11938v1)\]. Furthermore, probabilistic contrastive learning (ProCo) has been proposed to estimate class distributions in the feature space and sample contrastive pairs efficiently, even with small batches \[[11' 2024-03-11](http://arxiv.org/abs/2403.06726v2)\]. These advancements highlight the ongoing efforts to refine SCL for long-tailed recognition by addressing uniformity, bias, and data efficiency \[[1' 2021-11-27](http://arxiv.org/abs/2111.13998v2)\]\[[6' 2024-03-10](http://arxiv.org/abs/2403.06151v1)\]\[[8' 2022-11-22](http://arxiv.org/abs/2211.11938v1)\]\[[11' 2024-03-11](http://arxiv.org/abs/2403.06726v2)\].
