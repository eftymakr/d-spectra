## Related Works

Memory bandwidth regulation and cache partitioning have been widely studied for achieving predictable timing in real-time computing systems \[[1' 2023-10-04](http://arxiv.org/abs/2310.02959v1)\]. These techniques are often combined with partitioned scheduling to ensure that task execution times remain within acceptable bounds \[[2' 2019-07-04](http://arxiv.org/abs/1907.02184v1)\]. Task execution times are strongly influenced by the resources allocated to them, such as cache and memory bandwidth, which necessitates careful co-allocation of tasks and resources to cores \[[3' 2021-02-23](http://arxiv.org/abs/2102.11528v1)\]. 

Several approaches have been proposed to address this challenge. For instance, \[[4' 2017-04-29](http://arxiv.org/abs/1705.00138v3)\] introduces a hybrid multi-layer design space exploration technique that interleaves cache partitioning and task allocation to improve schedulability. This work explores the interplay between cache partitioning and schedulability using a breadth-first search combined with proactive pruning in the outer layer, and a first-fit heuristic for task allocation in the middle layer \[[5' 2016-02-14](http://arxiv.org/abs/1602.04415v1)\]. The inner layer uses a recurrence relation for schedulability analysis under non-preemptive fixed-priority (NP-FP) scheduling \[[6' 2025-02-04](http://arxiv.org/abs/2502.02437v1)\]. While focused on NP-FP, the framework is flexible enough to support other scheduling policies like NP-EDF and P-EDF \[[7' 2016-10-26](http://arxiv.org/abs/1610.08129v1)\].

Another approach, \[[8' 2011-12-22](http://arxiv.org/abs/1112.5472v3)\], investigates bandwidth-efficient DRAM caching for hybrid memory systems, particularly for 3D-XPoint memories. It proposes a novel organization, TicToc, that combines the benefits of Tag-Inside-Cacheline (TIC) and Tag-Outside-Cacheline (TOC) designs to reduce bandwidth overhead. This work also introduces architectural techniques like DRAM Cache Dirtiness Bit and Preemptive Dirty Marking to reduce the bandwidth required for maintaining metadata \[[9' 2013-09-26](http://arxiv.org/abs/1309.7082v1)\]. 

The work in \[[10' 2022-04-19](http://arxiv.org/abs/2204.08846v1)\] presents a coordinated management approach for cache partitioning, bandwidth partitioning, and prefetch throttling, aiming to reduce average memory access time. CBP dynamically manages these resources to improve performance during workload consolidation, showing a 11% improvement over state-of-the-art techniques and a 50% improvement over baselines \[[11' 2013-09-22](http://arxiv.org/abs/1309.5647v1)\]. 

In the realm of security and real-time systems, \[[12' 2020-09-01](http://arxiv.org/abs/2009.00466v1)\] introduces Contego, an adaptive framework for integrating security tasks without affecting temporal requirements. It uses opportunistic execution and hierarchical scheduling to maintain compatibility with legacy systems \[[13' 2012-05-09](http://arxiv.org/abs/1205.1871v1)\]. 

For cache tuning in embedded systems, \[[14' 2014-02-01](http://arxiv.org/abs/1402.0087v1)\] proposes phase distance mapping, a phase-based methodology that determines the best configuration for each phase without requiring extensive design space exploration. This approach yields energy delay product savings of 27% on average \[[15' 2015-07-06](http://arxiv.org/abs/1507.01451v2)\].

	Document 1: [Snippet]: «Cache partitioning techniques have been successfully adopted to mitigate interference among concurrently executing real-time tasks on multi-core processors. Considering that the execution time of a cache-sensitive task strongly depends on the cache available for it to use, co-optimizing cache partitioning and task allocation improves the system's schedulability. In this paper, we propose a hybrid multi-layer design space exploration technique to solve this multi-resource management problem. We explore the interplay between cache partitioning and schedulability by systematically interleaving three optimization layers, viz., (i) in the outer layer, we perform a breadth-first search combined with proactive pruning for cache partitioning; (ii) in the middle layer, we exploit a first-fit heuristic for allocating tasks to cores; and (iii) in the inner layer, we use the well-known recurrence relation for the schedulability analysis of non-preemptive fixed-priority (NP-FP) tasks in a uniprocessor setting. Although our focus is on NP-FP scheduling, we evaluate the flexibility of our framework in supporting different scheduling policies (NP-EDF, P-EDF) by plugging in appropriate analysis methods in the inner layer. Experiments show that, compared to the state-of-the-art techniques, the proposed framework can improve the real-time schedulability of NP-FP task sets by an average of 15.2% with a maximum improvement of 233.6% (when tasks are highly cache-sensitive) and a minimum of 1.6% (when cache sensitivity is low). For such task sets, we found that clustering similar-period (or mutually compatible) tasks often leads to higher schedulability (on average 7.6%) than clustering by cache sensitivity. In our evaluation, the framework also achieves good results for preemptive and dynamic-priority scheduling policies.»
