However, the computational and memory demands of LLMs pose substantial challenges for deployment on resource-constrained edge hardware \[[2' 2025-02-19](http://arxiv.org/abs/2502.15816v1)\]. Prior research has explored various strategies to address these challenges, including model compression, quantization, and hardware acceleration \[[3' 2024-02-22](http://arxiv.org/abs/2402.14800v2)\].

Model compression techniques such as pruning and quantization have been widely studied to reduce the size and computational cost of LLMs \[[4' 2024-06-03](http://arxiv.org/abs/2406.01698v3)\]. For instance, activation sparsity methods have been proposed to achieve up to 50% memory and computing reductions with minimal accuracy degradation \[[1' 2024-12-13](http://arxiv.org/abs/2412.12178v2)\]. These methods are orthogonal to existing compression techniques and can be combined to maximize compression while maintaining performance \[[1' 2024-12-13](http://arxiv.org/abs/2412.12178v2)\]. Similarly, low-rank pruning and factorization approaches have been used to reduce the parameter count of large models while preserving their effectiveness \[[24' 2023-06-25](http://arxiv.org/abs/2306.14152v1)\].

Quantization is another critical technique for deploying LLMs on edge devices, as it reduces both memory usage and computational load \[[6' 2022-05-30](http://arxiv.org/abs/2205.15437v2)\]. ### <a id='category-model-compression-techniques-for-llms'></a>Model Compression Techniques for LLMs: 5 papers found.
Model compression techniques for large language models (LLMs) have been extensively explored to address the challenges of deploying LLMs on edge devices, where memory, computational power, and energy constraints are critical \[[1' 2024-12-13](http://arxiv.org/abs/2412.12178v2)\]. Activation sparsity has emerged as a promising approach, allowing for significant reductions in memory and computation while maintaining model accuracy \[[1' 2024-12-13](http://arxiv.org/abs/2412.12178v2)\]. This method is orthogonal to existing compression techniques and can be combined with them to achieve higher compression rates \[[1' 2024-12-13](http://arxiv.org/abs/2412.12178v2)\]. The focus on Feed-Forward Network (FFN) components, which constitute a large portion of LLM parameters, has shown that enforcing activation sparsity can lead to up to 50% reductions in memory and computation with minimal accuracy degradation \[[1' 2024-12-13](http://arxiv.org/abs/2412.12178v2)\]. Additionally, activation sparsity can be tuned by injecting zero-enforcing thresholds, enabling further optimization \[[1' 2024-12-13](http://arxiv.org/abs/2412.12178v2)\]. In parallel, other methods such as expert-level sparsification have been introduced to improve the deployment efficiency of Mixture-of-Experts (MoE) LLMs \[[3' 2024-02-22](http://arxiv.org/abs/2402.14800v2)\]. These techniques allow for task-agnostic and task-specific pruning, enhancing inference speed and reducing model size without compromising performance \[[3' 2024-02-22](http://arxiv.org/abs/2402.14800v2)\]. Quantization is another widely used method, converting model parameters and activations into low-bit integers to reduce memory consumption \[[13' 2024-02-19](http://arxiv.org/abs/2402.12065v2)\]. Recent approaches like WKVQuant have been developed to specifically target the quantization of weights and key/value (KV) cache, improving attention computation and achieving memory savings comparable to weight-activation quantization \[[13' 2024-02-19](http://arxiv.org/abs/2402.12065v2)\]. These techniques collectively highlight the diverse strategies being pursued to enable efficient deployment of LLMs on resource-constrained devices.
