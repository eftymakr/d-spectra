## Related Works

Federated Learning (FL) has emerged as a promising paradigm for collaborative machine learning while preserving data privacy \[[1' 2023-07-31](http://arxiv.org/abs/2308.00155v1)\]. It enables multiple clients to train a shared model without sharing raw data, making it particularly suitable for sensitive applications such as healthcare and IoT \[[23' 2020-04-24](http://arxiv.org/abs/2004.11794v2)\]. However, FL faces significant challenges due to data heterogeneity, where clients have non-IID (non-independent and identically distributed) data distributions \[[2' 2022-06-11](http://arxiv.org/abs/2206.05507v1)\]. This heterogeneity can lead to performance degradation and slow convergence of the global model \[[3' 2022-06-20](http://arxiv.org/abs/2206.10032v4)\].

Active Learning (AL) is another important technique that reduces annotation costs by selecting the most informative samples for labeling \[[28' 2021-10-14](http://arxiv.org/abs/2110.07661v2)\]. However, performing AL independently may not be sufficient due to limited data diversity and annotation budgets \[[29' 2021-10-13](http://arxiv.org/abs/2110.06978v2)\]. Federated Active Learning (FAL) extends AL to FL settings, enabling collaborative data selection and model training while maintaining data confidentiality \[[29' 2021-10-13](http://arxiv.org/abs/2110.06978v2)\]. Despite this, existing FAL methods often fail to account for the heterogeneity of data distribution across clients and the associated fluctuations in global and local model parameters, which can negatively impact model accuracy \[[29' 2021-10-13](http://arxiv.org/abs/2110.06978v2)\].

To address these limitations, several approaches have been proposed. For instance, \[[4' 2023-11-22](http://arxiv.org/abs/2311.13267v1)\] introduces a framework that uses synthetic data to mitigate non-IID challenges by generating differentially private synthetic data for each client. This helps align data distributions across clients and improves model consistency. Similarly, \[[5' 2025-04-15](http://arxiv.org/abs/2504.11216v2)\] proposes a method that leverages feature normalization to alleviate data heterogeneity by reducing feature representation discrepancies between local and global models. These approaches focus on data alignment and normalization to improve model performance in heterogeneous settings.

Client selection strategies have also been explored to enhance FL performance. \[[6' 2025-04-02](http://arxiv.org/abs/2504.01921v1)\] proposes a novel client selection algorithm that promotes collaboration between clients with complementary data distributions, improving model generalization. Additionally, \[[7' 2019-12-13](http://arxiv.org/abs/1912.06733v1)\] introduces a correlation-based client selection strategy that improves convergence rates by selecting clients with higher loss correlation. These methods highlight the importance of client selection in addressing data heterogeneity and improving FL efficiency.

Furthermore, \[[8' 2022-07-17](http://arxiv.org/abs/2207.08187v1)\] introduces a framework for self-supervised learning in heterogeneous settings, enabling collaborative representation learning across clients without requiring labeled data. This approach allows for more flexible and scalable FL applications. In addition, \[[9' 2024-09-19](http://arxiv.org/abs/2409.13004v1)\] proposes a method for feature-based federated transfer learning, reducing communication overhead by uploading features instead of full model updates. This approach is particularly useful in scenarios with limited bandwidth.
