## Related Works

Table discovery has emerged as a critical task in the analysis of large-scale tabular data repositories, where the goal is to efficiently retrieve relevant tables based on user queries \[[1' 2017-04-18](http://arxiv.org/abs/1704.05295v1)\]. Traditional approaches rely on either a query table or a set of vague keywords, often leading to a large number of candidate tables that require manual filtering by users \[[1' 2017-04-18](http://arxiv.org/abs/1704.05295v1)\]. This limitation has motivated the development of more sophisticated methods that incorporate natural language (NL) conditions to refine search results, leading to the introduction of the NL-conditional table discovery (nlcTD) task \[[1' 2017-04-18](http://arxiv.org/abs/1704.05295v1)\].

Several works have explored the use of semantic similarity in natural language processing (NLP) to improve the understanding of query intent and table relevance. For instance, semantic similarity measures have been extensively studied to compare the meaning of words, sentences, and concepts, often leveraging either corpus-based NLP techniques or knowledge-based approaches such as ontologies and thesauruses \[[2' 2024-03-09](http://arxiv.org/abs/2403.05839v3)\]. These methods aim to capture the semantic relationships between query terms and table content, thereby improving the accuracy of retrieval systems \[[2' 2024-03-09](http://arxiv.org/abs/2403.05839v3)\]. However, these approaches typically focus on text-based similarity and may not directly address the structured nature of tabular data \[[1' 2017-04-18](http://arxiv.org/abs/1704.05295v1)\].

In the field of visual object tracking, researchers have developed benchmarks and datasets to evaluate the performance of tracking algorithms under various conditions \[[3' 2022-11-01](http://arxiv.org/abs/2211.00727v1)\]. For example, the FELT dataset was introduced to address the challenges of long-term visual object tracking using event cameras, incorporating a large-scale collection of videos and diverse target objects \[[3' 2022-11-01](http://arxiv.org/abs/2211.00727v1)\]. Similarly, the BSCV dataset was created to evaluate video recovery techniques in the presence of bitstream corruption, providing a realistic benchmark for multimedia forensics and communication applications \[[4' 2019-06-27](http://arxiv.org/abs/1906.11561v1)\]. These datasets highlight the importance of benchmarking in advancing the state-of-the-art in specific domains \[[3' 2022-11-01](http://arxiv.org/abs/2211.00727v1)\]\[[4' 2019-06-27](http://arxiv.org/abs/1906.11561v1)\].

In the context of texture image analysis and surface defect detection, the STI dataset was proposed to support research in image processing and computer vision \[[5' 2023-09-25](http://arxiv.org/abs/2309.13890v2)\]. This dataset includes a variety of stone textures and is designed to reflect real-world applications, offering a rich set of features for evaluating texture descriptors and defect detection algorithms \[[5' 2023-09-25](http://arxiv.org/abs/2309.13890v2)\]. Such datasets are crucial for validating the effectiveness of new methods in practical scenarios \[[5' 2023-09-25](http://arxiv.org/abs/2309.13890v2)\].

The proposed nlcTables dataset represents a significant contribution to the field by providing a comprehensive benchmark for NL-conditional table discovery, encompassing diverse query types and conditions \[[1' 2017-04-18](http://arxiv.org/abs/1704.05295v1)\].
