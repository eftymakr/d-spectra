## Related Works

The growing adoption of cloud-native applications has led to increased interest in optimizing both resource usage and financial expenditures. Several studies have explored strategies for improving cost efficiency in cloud environments, particularly focusing on Kubernetes and container orchestration. For instance, cloud cost optimization has been widely discussed in the context of resource allocation, workload distribution, and the use of cloud management tools \[[1](https://www.semanticscholar.org/paper/8335555ae08140dc2fe0da4807040fc88b0cace1)\]. These strategies aim to reduce waste and improve the cost-effectiveness of cloud infrastructure by ensuring that resources are used in a manner that aligns with organizational goals.

FinOps, an emerging discipline that merges financial management with cloud operations, has also gained traction as a way to optimize cloud costs \[[2](http://arxiv.org/abs/2501.14753)\]. ABACUS, a FinOps solution, demonstrates how automated budget analysis and cloud usage surveillance can help enforce cost controls by setting budgets, blocking new deployments when thresholds are exceeded, and alerting teams before resources are deployed \[[2](http://arxiv.org/abs/2501.14753)\]. This approach aligns with the broader goal of achieving visibility into cloud spend and ensuring that costs are managed effectively.

In the context of Kubernetes, several studies have highlighted the challenges of cost optimization, particularly in relation to network usage and resource allocation. For example, native Kubernetes autoscaling mechanisms such as Horizontal Pod Autoscaler (HPA), Vertical Pod Autoscaler (VPA), and Cluster Autoscaler (CA) often fail to strike an optimal balance between resource utilization and application performance \[[3](https://www.semanticscholar.org/paper/2ce38cfb0bf3be6e875f5feb8c4b5e140587bb10)\]. To address these limitations, recent research has focused on leveraging AI and machine learning techniques to enhance Kubernetes’ resource allocation efficiency \[[3](https://www.semanticscholar.org/paper/2ce38cfb0bf3be6e875f5feb8c4b5e140587bb10)\]. These AI-driven approaches have shown promise in improving resource utilization and reducing operational expenses by enabling proactive and dynamic scaling decisions \[[3](https://www.semanticscholar.org/paper/2ce38cfb0bf3be6e875f5feb8c4b5e140587bb10)\].

Additionally, the performance and cost implications of Kubernetes in cloud-native environments have been investigated. For instance, the use of Docker and Kubernetes for cloud-native applications has been shown to significantly reduce completion times for computationally intensive tasks, such as big data and deep learning applications \[[12](http://arxiv.org/abs/2010.10350)\]. However, resource management schemes can have a substantial impact on performance, with some configurations leading to delays in resource release \[[12](http://arxiv.org/abs/2010.10350)\]. These findings underscore the importance of selecting appropriate resource management strategies to achieve optimal performance and cost efficiency.

Furthermore, the security of Kubernetes clusters has been a focus of several studies, particularly in multi-cloud and hybrid environments \[[5](https://www.semanticscholar.org/paper/c60cd2fe9e05152ae366a070ba5d8798f7e64151)\]. These studies emphasize the need for robust security practices, including the use of CNAPP platforms that integrate cloud security management (CSPM) and Kubernetes security management (KSPM) \[[5](https://www.semanticscholar.org/paper/c60cd2fe9e05152ae366a070ba5d8798f7e64151)\]. ### <a id='category-finops-frameworks-and-tools'></a>FinOps Frameworks and Tools: 1 papers found.

### <a id='category-security-practices-in-kubernetes-clusters'></a>Security Practices in Kubernetes Clusters: 6 papers found.
The security practices in Kubernetes clusters are a critical area of research, particularly as Kubernetes becomes more prevalent in modern cloud-native environments \[[5](https://www.semanticscholar.org/paper/c60cd2fe9e05152ae366a070ba5d8798f7e64151)\]. Key challenges include configuration management, network security, access control, and compliance with regulatory requirements \[[5](https://www.semanticscholar.org/paper/c60cd2fe9e05152ae366a070ba5d8798f7e64151)\]. To address these issues, CNAPP platforms that integrate Cloud Security Posture Management (CSPM) and Kubernetes Security Posture Management (KSPM) are recommended, along with automation of monitoring and authentication processes \[[5](https://www.semanticscholar.org/paper/c60cd2fe9e05152ae366a070ba5d8798f7e64151)\]. Real-time tracking of container activities is also essential to detect and prevent potential security breaches \[[6](https://www.semanticscholar.org/paper/2a7396b670ac72d37afbf5da2925116d35a4030a)\]. Additionally, the use of encryption technologies, software-defined networks (SDN), and regular audits can significantly reduce risks \[[5](https://www.semanticscholar.org/paper/c60cd2fe9e05152ae366a070ba5d8798f7e64151)\]. Recent studies have highlighted the need for advanced security strategies that adapt to evolving threats, ensuring the sustainability of multi-cloud deployments and data integrity \[[5](https://www.semanticscholar.org/paper/c60cd2fe9e05152ae366a070ba5d8798f7e64151)\]. Furthermore, the adoption of container technologies has introduced new security concerns, such as the potential for attackers to exploit containers to gain access to internal infrastructure \[[6](https://www.semanticscholar.org/paper/2a7396b670ac72d37afbf5da2925116d35a4030a)\]. As Kubernetes continues to evolve, so do the methods used by attackers, necessitating robust security practices that address both existing and emerging threats \[[7](https://www.semanticscholar.org/paper/8e1ccea4a7235a295ddf13ba43061889e39bcb13)\]. Comparative analyses of different Kubernetes cluster configurations have revealed variations in security postures, emphasizing the importance of tailored security approaches \[[8](https://www.semanticscholar.org/paper/00f68d85141a6981a05bb57b9e84610b2ef61941)\]. Overall, the security of Kubernetes clusters requires a multifaceted approach that includes both technical and operational measures \[[5](https://www.semanticscholar.org/paper/c60cd2fe9e05152ae366a070ba5d8798f7e64151)\].
