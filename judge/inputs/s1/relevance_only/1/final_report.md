## Related Works

Efficient Large Language Model (LLM) serving has attracted significant research interest, particularly in optimizing Key-Value (KV) cache management to reduce computational costs and improve inference performance. Prior work has focused on KV cache compression, reuse, and scheduling strategies to enhance LLM serving efficiency. For instance, \[[2](http://arxiv.org/abs/2404.18057)\] introduces KCache, a technique that reduces memory overhead by eliminating unnecessary KV cache during inference, achieving a 40% throughput improvement without compromising accuracy. Similarly, \[[8](http://arxiv.org/abs/2503.08461)\] presents FastCache, a framework that optimizes multimodal LLM serving through lightweight KV-cache compression, achieving up to 19.3× reduction in Time-To-First-Token (TTFT) and 12.1× improvement in throughput compared to state-of-the-art baselines. These approaches highlight the importance of memory optimization and efficient KV cache management for real-world LLM deployment.

KV cache reuse has also been explored as a way to reduce redundant computations. \[[6](http://arxiv.org/abs/2502.16002)\] proposes KVLink, which precomputes KV caches for documents and reuses them during inference, reducing TTFT by up to 96% and improving question answering accuracy by 4%. \[[1](http://arxiv.org/abs/2503.16525)\] investigates the use of stored KV caches in cloud environments, showing that reusing precomputed caches can save both delay and cloud costs, especially for workloads with long context. These studies emphasize the potential of KV cache reuse to improve efficiency in LLM serving.

However, existing methods often overlook the complexities of cache management in multi-tenant and real-time scenarios. \[[1](http://arxiv.org/abs/2503.16525)\] and \[[6](http://arxiv.org/abs/2502.16002)\] highlight the need for adaptive strategies to handle varying reuse patterns and workload characteristics. \[[9](http://arxiv.org/abs/2407.08454)\] introduces KVMerger, an adaptive KV cache merging approach that maintains performance under constrained memory budgets by leveraging token-level similarity in key states. This work addresses the limitations of traditional eviction policies that may degrade performance in long-context tasks. \[[7](http://arxiv.org/abs/2505.21919)\] further explores the challenges of efficient KVC management in inference workloads like Retrieval-Augmented Generation (RAG), emphasizing the need for tailored storage solutions and optimized metadata management for LLMs with extended context windows.

### <a id='category-kv-cache-compression-techniques'></a>KV Cache Compression Techniques: 2 papers found.
Key-value (KV) cache compression techniques have gained attention as a means to optimize memory usage and computational efficiency in large language model (LLM) serving systems \[[1](http://arxiv.org/abs/2503.16525)\]. These techniques aim to reduce the memory footprint of KV caches, which are critical for maintaining context across sequential requests, thereby improving throughput and reducing latency \[[1](http://arxiv.org/abs/2503.16525)\]. However, existing compression algorithms often lack practical implementation, leading to suboptimal performance in production environments \[[1](http://arxiv.org/abs/2503.16525)\]. For instance, methods like FlashAttention and PagedAttention, while effective in reducing memory consumption, do not fully optimize for the demands of real-time LLM serving, resulting in lower throughput and increased end-to-end latency \[[1](http://arxiv.org/abs/2503.16525)\]. Additionally, compression can introduce variability in output length, further complicating latency predictions \[[1](http://arxiv.org/abs/2503.16525)\]. To address these challenges, recent work has introduced frameworks such as FastCache, which employs dynamic batching and an efficient memory pool mechanism to mitigate processing overhead and queuing delays, achieving significant improvements in throughput and time-to-first-token (TTFT) \[[2](http://arxiv.org/abs/2404.18057)\]. These advancements highlight the ongoing evolution of KV cache compression strategies, emphasizing the need for both algorithmic innovation and system-level optimizations to support scalable and efficient LLM serving.

### <a id='category-metadata-management-for-kv-caches'></a>Metadata Management for KV Caches: 1 papers found.
The category "Metadata Management for KV Caches" focuses on the challenges and opportunities in managing key-value caches for large language models (LLMs) with extended context windows. As LLMs become more prevalent in inference workloads such as Retrieval-Augmented Generation (RAG) and agents, the need for efficient caching mechanisms becomes critical to reduce redundancy and improve speed \[[7](http://arxiv.org/abs/2505.21919)\]. Current systems, including commercial key-value stores like Redis and state-of-the-art RDMA-based systems like CHIME and Sherman, have limitations in handling the specific prefilling requirements of KVCs \[[7](http://arxiv.org/abs/2505.21919)\]. This highlights a gap in the existing storage solutions, emphasizing the need for a tailored distributed caching system optimized for LLM workloads \[[7](http://arxiv.org/abs/2505.21919)\]. The analysis of real-world KVC access patterns reveals that efficient metadata management is essential for achieving low-latency and scalable inference \[[7](http://arxiv.org/abs/2505.21919)\]. Thus, this category underscores the importance of developing improved KVC management systems that can adapt to the dynamic and workload-dependent nature of LLM serving.
