## Related Works

Neural rendering has emerged as a powerful paradigm for reconstructing 3D scenes from 2D images, leveraging deep learning to model complex geometry and appearance \[[1](https://www.semanticscholar.org/paper/d909acffb3f83eb140ac77b3b9f76c03cd995ee9)\]. The core idea involves using multiple input views to optimize the reconstructed scene by minimizing uncertainty in both geometry and appearance \[[1](https://www.semanticscholar.org/paper/d909acffb3f83eb140ac77b3b9f76c03cd995ee9)\]. However, the quality of reconstruction is often constrained by the number of input views, particularly in complex and dynamic scenes where certain angles of objects are not captured \[[1](https://www.semanticscholar.org/paper/d909acffb3f83eb140ac77b3b9f76c03cd995ee9)\]. To address this limitation, several approaches have been proposed to enhance the training data for neural rendering by generating additional views through video frame interpolation \[[1](https://www.semanticscholar.org/paper/d909acffb3f83eb140ac77b3b9f76c03cd995ee9)\].

Video frame interpolation techniques have been extensively studied, with a focus on generating high-quality intermediate frames between existing ones \[[2](http://arxiv.org/abs/2503.18897)\]. Early methods relied on optical flow estimation and image synthesis, but recent advances have integrated deep learning to improve both accuracy and efficiency \[[3](https://www.semanticscholar.org/paper/23c9b2b3d315dd81563f57bbec8fda28d53700a6)\]. For example, Super SloMo \[[4](http://arxiv.org/abs/2211.14005)\] introduced an end-to-end convolutional neural network for multi-frame interpolation, jointly modeling motion interpretation and occlusion reasoning. This approach uses bi-directional optical flow and visibility maps to avoid artifacts in interpolated frames \[[4](http://arxiv.org/abs/2211.14005)\]. Similarly, Video Frame Interpolation via Adaptive Convolution \[[5](http://arxiv.org/abs/2204.09900)\] combined motion estimation and pixel synthesis into a single convolutional process, allowing for robust handling of occlusion, blur, and brightness changes \[[5](http://arxiv.org/abs/2204.09900)\].

The use of auxiliary features, such as depth and normals, has also been explored to improve the quality of frame interpolation, particularly for rendered content \[[6](http://arxiv.org/abs/2309.07021)\]. Neural frame interpolation methods have leveraged these features to obtain better motion estimates and handle occlusions more accurately \[[6](http://arxiv.org/abs/2309.07021)\]. Additionally, methods like Video Frame Interpolation Via Residue Refinement \[[7](http://arxiv.org/abs/1712.00080)\] introduced residue refinement and adaptive weight maps to reduce artifacts and improve visual appearance \[[7](http://arxiv.org/abs/1712.00080)\]. These techniques have been further extended to handle high-resolution videos, where memory and computational constraints are significant challenges \[[8](http://arxiv.org/abs/1708.01692)\].

Recent approaches have also focused on improving the efficiency of feature extraction for high-resolution frame interpolation \[[8](http://arxiv.org/abs/1708.01692)\]. For instance, Efficient Feature Extraction for High-resolution Video Frame Interpolation \[[9](https://www.semanticscholar.org/paper/43e2e7359854f0deb48f8e9ac4b0277c28b229e6)\] proposed dimensionality reduction techniques combined with lightweight optimization to compress input representations while maintaining accuracy \[[9](https://www.semanticscholar.org/paper/43e2e7359854f0deb48f8e9ac4b0277c28b229e6)\]. This approach eliminates the need for pretrained flow or synthesis networks, reducing both the number of trainable parameters and memory usage \[[9](https://www.semanticscholar.org/paper/43e2e7359854f0deb48f8e9ac4b0277c28b229e6)\].
