## Related Works

Event cameras have emerged as a promising alternative to traditional frame-based cameras due to their high temporal resolution and ability to capture dynamic scenes efficiently \[[15](http://arxiv.org/abs/1906.07165)\]. However, the asynchronous nature of event data introduces challenges in processing and analysis. Prior work has primarily focused on event downsampling to reduce bandwidth and computational load, often relying on fixed heuristics or threshold-based strategies \[[15](http://arxiv.org/abs/1906.07165)\]. These approaches, while effective in some scenarios, lack adaptability to varying scene dynamics and application-specific requirements \[[15](http://arxiv.org/abs/1906.07165)\].

Several studies have explored the use of deep learning for event-based tasks. For instance, EV-FlowNet introduced a self-supervised pipeline for optical flow estimation from event data, leveraging grayscale images captured at the same time as events as supervisory signals \[[2](http://arxiv.org/abs/1802.06898)\]. Similarly, E-RAFT proposed a dense optical flow estimation method for event cameras by incorporating feature correlation and sequential processing, significantly improving performance over previous methods \[[1](http://arxiv.org/abs/2108.10552)\]. The work in \[[6](http://arxiv.org/abs/1812.08156)\] further advanced unsupervised learning for event cameras, enabling the estimation of optical flow, depth, and egomotion from raw event streams without supervision.

Event-based semantic segmentation has also been a focus of recent research. OpenESS introduced a framework that synergizes image, text, and event data to enable scalable semantic scene understanding, achieving competitive performance without relying on labeled data \[[4](http://arxiv.org/abs/2405.05259)\]. Additionally, Masked Event Modeling (MEM) was proposed to reduce dependency on labeled event data by pretraining neural networks on unlabeled events, leading to significant improvements in downstream tasks such as classification and segmentation \[[3](http://arxiv.org/abs/2212.10368)\].

The challenge of reconstructing intensity images from event streams has been addressed by several methods. Events-To-Video proposed a recurrent neural network to reconstruct videos from event data, demonstrating superior performance compared to state-of-the-art reconstruction methods \[[10](http://arxiv.org/abs/1904.08298)\]. Similarly, the EDI model was introduced to reconstruct high frame-rate, sharp videos from a single blurry frame and its event data, achieving better results than existing methods \[[11](http://arxiv.org/abs/1811.10180)\].

In the realm of zero-shot recognition, EZSR explored the use of event data for zero-shot object recognition by developing an event encoder that does not rely on additional reconstruction networks, leading to improved performance over previous approaches \[[13](http://arxiv.org/abs/2407.21616)\]. Similarly, Improving Event Definition Following for Zero-Shot Event Detection introduced a dataset with diverse event definitions to enhance the performance of zero-shot event detection models \[[14](http://arxiv.org/abs/2403.02586)\].
