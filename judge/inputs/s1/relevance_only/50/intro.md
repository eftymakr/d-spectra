## Related Works

The rapid growth of open-source machine learning (ML) resources has significantly impacted information retrieval (IR) research, prompting the need for more sophisticated tools to manage and analyze these resources \[[1](http://arxiv.org/abs/2005.00687)\]. Existing platforms, such as Hugging Face, provide access to a vast array of ML models and datasets but lack structured representations that enable advanced queries and analyses \[[1](http://arxiv.org/abs/2005.00687)\]. This limitation hinders tasks such as tracing model evolution and recommending relevant datasets \[[1](http://arxiv.org/abs/2005.00687)\]. To address these challenges, recent work has explored the use of knowledge graphs (KGs) to organize and enhance the management of ML resources \[[1](http://arxiv.org/abs/2005.00687)\].

Knowledge graphs have been widely used in various domains, including social networks, biological networks, and knowledge graphs, to represent complex relationships between entities \[[2](http://arxiv.org/abs/2408.08921)\]. These KGs often include rich textual attributes and domain-specific relations, which are essential for advanced querying and analysis \[[1](http://arxiv.org/abs/2005.00687)\]. For example, the Open Graph Benchmark (OGB) provides a set of large-scale datasets for graph machine learning, emphasizing scalability and out-of-distribution generalization \[[2](http://arxiv.org/abs/2408.08921)\]. The OGB datasets are designed to challenge existing models and encourage the development of more robust and scalable graph ML techniques \[[2](http://arxiv.org/abs/2408.08921)\].

In the context of knowledge graph reasoning, several studies have explored the use of graph-based methods to enhance the accuracy and efficiency of knowledge graph completion tasks \[[3](http://arxiv.org/abs/1808.09040)\]. For instance, relational graph convolutional networks (R-GCNs) have been introduced to handle the highly multi-relational data characteristic of knowledge bases \[[8](http://arxiv.org/abs/1703.06103)\]. These models have shown significant improvements in tasks such as link prediction and entity classification \[[8](http://arxiv.org/abs/1703.06103)\]. Additionally, one-shot relational learning frameworks have been proposed to address the challenge of predicting new facts with limited training data \[[3](http://arxiv.org/abs/1808.09040)\]. These frameworks utilize embedding models and graph structures to achieve better performance without requiring extensive training \[[3](http://arxiv.org/abs/1808.09040)\].

The use of knowledge graphs in information retrieval has also been explored in the context of user intent capture and recommendation systems \[[9](http://arxiv.org/abs/2411.01023)\]. Knowledge graphs can be used to store not only workflow components and datasets but also user intents and feedback, enabling more personalized and context-aware recommendations \[[9](http://arxiv.org/abs/2411.01023)\]. This approach has been applied in intelligent discovery assistants (IDAs) and automated machine learning (AutoML) systems to enhance user interaction with data \[[9](http://arxiv.org/abs/2411.01023)\].

In summary, the construction of HuggingKG and the development of HuggingBench are informed by existing research on knowledge graphs and their applications in information retrieval and machine learning resource management \[[1](http://arxiv.org/abs/2005.00687)\].
