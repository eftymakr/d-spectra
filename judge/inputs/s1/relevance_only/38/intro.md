## Related Works

Memory bandwidth regulation and cache partitioning have been extensively studied for achieving predictable timing in real-time computing systems \[[1](https://www.semanticscholar.org/paper/b022c4ce1e5c99ccdddcd753164b91943e50dca8)\]. These techniques are often combined with partitioned scheduling to manage task execution times, which are highly dependent on allocated resources \[[2](http://arxiv.org/abs/2310.02959)\]. Prior work has focused on optimizing cache partitioning to reduce interference among tasks running on shared caches \[[3](http://arxiv.org/abs/1809.05921)\]. For example, cache partitioning schemes have been developed to guarantee schedulability while minimizing cache usage \[[4](https://www.semanticscholar.org/paper/70e84ea65caaab72e87ee13fa2e61f7d7d9a54c2)\]. These approaches typically allocate cache segments to tasks that benefit the most from having their data stored in the cache, thereby reducing execution time \[[5](http://arxiv.org/abs/2410.14003)\].

In multi-core systems, co-optimizing cache partitioning and task scheduling has been proposed to improve schedulability by exploiting the cache sensitivity of tasks \[[6](https://www.semanticscholar.org/paper/e8d15aa827be70bebf15e217ac9295276ddebda7)\]. A hybrid multi-layer design space exploration technique has been introduced to systematically interleave cache partitioning and task allocation, leading to improved real-time schedulability \[[7](https://www.semanticscholar.org/paper/1ed3c2a13c728b4d294644db90fb278e62bece22)\]. This approach has been evaluated for both non-preemptive and preemptive scheduling policies, showing significant improvements in schedulability \[[8](http://arxiv.org/abs/2302.11236)\]. Furthermore, the importance of considering cache bank contention in shared last-level caches has been highlighted, with per-bank bandwidth regulation proposed to mitigate such issues and improve performance \[[9](http://arxiv.org/abs/2502.02437)\].

Dynamic memory bandwidth regulation has also been explored to address memory contention in multi-core real-time systems \[[10](http://arxiv.org/abs/2501.08484)\]. This includes the development of a framework for determining worst-case response times based on dynamic allocation of main memory bandwidth, which has been applied to improve the schedulability of Integrated Modular Avionics systems \[[11](https://www.semanticscholar.org/paper/e02eb1430cb7aa53f20818d2b642abe10d58a459)\]. Additionally, hardware-based solutions such as the Bandwidth Regulation Unit (BRU) have been proposed to enable fine-grained memory bandwidth regulation at the core level, improving time-predictability for real-time tasks \[[12](http://arxiv.org/abs/2102.11528)\].

The multiframe model has been adapted to address the limitations of traditional schedulability analysis in multi-core systems by incorporating memory regulation and stall analysis \[[13](https://www.semanticscholar.org/paper/6ca5ab717934109c6424d996c4d7d914373ab8d0)\]. This approach has shown significant improvements in scheduling success ratios, enabling higher platform utilization without compromising safety \[[14](http://arxiv.org/abs/1312.4509)\]. Moreover, the use of generative profiling techniques has been proposed to accurately model the time-varying resource use characteristics of tasks under different shared resource budgets, enabling more precise scheduling decisions \[[15](http://arxiv.org/abs/1809.02892)\].

In the context of energy-efficient scheduling, multi-objective optimization methods have been introduced to minimize both execution time and energy consumption in cache memory designs \[[16](https://www.semanticscholar.org/paper/d72ab05ae01c058f89eb026eb9678af389c44eff)\].
