## Related Works

Table detection and understanding have seen significant advancements in recent years, driven by the increasing availability of tabular data in digital documents and the need for automated analysis. Early approaches relied on classical computer vision techniques, which struggled with the complexity and variability of table structures in natural documents \[[1](http://arxiv.org/abs/2209.09207)\]. This limitation has led to the development of deep learning methods that leverage convolutional neural networks (CNNs) to improve the accuracy and robustness of table detection \[[1](http://arxiv.org/abs/2209.09207)\]. A notable contribution in this area is the introduction of the STDW dataset, which contains over 7,000 diverse table samples collected from various sources, enabling more comprehensive training and evaluation of table detection models \[[1](http://arxiv.org/abs/2209.09207)\]. This dataset has been instrumental in demonstrating the superiority of deep learning methods over traditional approaches \[[1](http://arxiv.org/abs/2209.09207)\].

The challenge of understanding and querying tabular data has also been addressed through the development of specialized models. For instance, TaBERT was introduced as a pretrained language model that jointly learns representations for both natural language sentences and structured tables, enabling better semantic parsing over tabular data \[[4](http://arxiv.org/abs/2005.08314)\]. This model has shown promising results on tasks such as semantic parsing and text-to-SQL, outperforming existing methods \[[4](http://arxiv.org/abs/2005.08314)\]. Similarly, the TableBank dataset provides a large-scale benchmark for image-based table detection and recognition, containing 417K high-quality labeled tables. This dataset has been used to train and evaluate state-of-the-art models, contributing to the advancement of table recognition techniques \[[3](http://arxiv.org/abs/1903.01949)\].

In addition to detection, there has been growing interest in interactive table manipulation and question-answering over tabular data. The iTBLS dataset introduces a new paradigm for interacting with tabular information, focusing on tasks such as interpretation, modification, and generation of tabular data \[[5](http://arxiv.org/abs/2404.12580)\]. This dataset has been used to develop novel frameworks that reformulate tabular operations as question-answering tasks, leading to significant improvements in performance across various benchmarks \[[5](http://arxiv.org/abs/2404.12580)\]. These advancements highlight the evolving landscape of table understanding, where models are increasingly capable of handling complex interactions with tabular data.

Recent work has also focused on addressing the limitations of existing table discovery methods, which often rely on query tables or vague keywords, resulting in large result sets that require manual filtering . To overcome this, the nlcTables dataset was introduced as a comprehensive benchmark for natural language conditional table discovery (nlcTD).
