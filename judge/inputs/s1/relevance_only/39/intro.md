## Related Works

De novo genome assembly is a fundamental challenge in bioinformatics, enabling the reconstruction of genomes from short, overlapping DNA sequences without a reference. This process is computationally intensive, requiring efficient algorithms and scalable architectures to handle the exponential growth of genomic data \[[1](http://arxiv.org/abs/1705.11147)\]. Traditional assemblers often struggle with memory constraints, irregular data patterns, and poor scalability, especially when dealing with large genomes \[[18](https://www.semanticscholar.org/paper/7279acd9c61a8de019ea2d55d23124dfbb6b5269)\]. 

Several studies have explored distributed and parallel approaches to address these challenges. For instance, HipMER leverages efficient parallelization of the Meraculous code to assemble large genomes on supercomputers with tens of thousands of cores \[[1](http://arxiv.org/abs/1705.11147)\]. Similarly, PPA-assembler utilizes the Pregel framework to enable distributed de novo assembly, demonstrating superior performance compared to existing assemblers \[[2](http://arxiv.org/abs/1801.04453)\]. The work on distributed-memory parallel contig generation further advances the field by introducing a novel algorithm that reduces computational overhead and improves assembly quality \[[3](http://arxiv.org/abs/2207.04350)\]. 

The use of de Bruijn graphs has been a cornerstone in de novo assembly due to their ability to represent overlaps efficiently. However, memory usage remains a critical issue. SparseAssembler and SparseAssembler2 introduce sparse k-mer graphs to significantly reduce memory consumption while maintaining assembly accuracy \[[11](http://arxiv.org/abs/1106.2603)\]\[[12](http://arxiv.org/abs/1108.3556)\]. These approaches are particularly beneficial for large-scale genome analysis, where memory efficiency is crucial \[[14](http://arxiv.org/abs/1008.2555)\]. 

Recent developments in long-read sequencing have also influenced genome assembly methodologies. Tools like ntLink leverage long-read data to improve scaffolding and mapping, offering resource-efficient solutions for generating high-quality assemblies \[[10](http://arxiv.org/abs/2301.08785)\]. Additionally, the integration of genetic linkage maps with de novo assemblies has shown promise in resolving misassemblies and anchoring chromosome-scale sequences \[[8](https://www.semanticscholar.org/paper/d200128ff098fc7da12747f7ce732d6f414ebe53)\]. 

Despite these advancements, the computational complexity of de novo assembly remains a significant barrier. Theoretical studies have explored the parametric complexity of sequence assembly, highlighting the impact of repeat complexity, read lengths, and coverage on assembly difficulty \[[17](https://www.semanticscholar.org/paper/d04b3cc774151260a59a5e6768b6cfae7fc3e512)\]. These insights are essential for designing more robust and efficient assemblers. 

In the context of hardware-software co-design, recent efforts have focused on optimizing memory usage and computational efficiency. For example, the work on succinct data structures has demonstrated the potential for reducing storage requirements and improving scalability in de Bruijn graph-based assemblers \[[14](http://arxiv.org/abs/1008.2555)\]. These approaches align with the need for more efficient and scalable solutions, especially as sequencing technologies continue to evolve \[[15](http://arxiv.org/abs/2111.01916)\].
