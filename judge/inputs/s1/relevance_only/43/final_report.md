## Related Works

Performance modeling for large language models (LLMs) has gained significant attention due to the complexity of training and inference in distributed environments. Early work focused on traditional performance modeling techniques for general-purpose computing on GPUs (GPGPU), where manually crafted models were used to estimate execution times \[[1](http://arxiv.org/abs/2503.11244)\]. However, these models were limited by program and hardware constraints, making them unsuitable for the intricate and dynamic nature of LLMs \[[1](http://arxiv.org/abs/2503.11244)\]. Recent studies have explored the use of machine learning (ML) techniques to improve the accuracy of performance prediction. For instance, LLMs have been employed to estimate performance for OpenCL device source programs, achieving a mean absolute percentage error (MAPE) of 24.25% on a large-scale validation set \[[1](http://arxiv.org/abs/2503.11244)\]. This approach, however, still faces challenges in handling the variability and complexity of LLM workloads \[[1](http://arxiv.org/abs/2503.11244)\].

In the context of multi-GPU platforms, several works have addressed the challenges of performance prediction. A notable effort is the development of data-distribution-aware performance models for embedding table lookups and data movement prediction for communication collectives \[[2](http://arxiv.org/abs/2404.12674)\]. These models enable accurate prediction of per-iteration training time for deep learning recommendation models (DLRM), achieving a geometric mean error (GME) of 5.21% on multi-GPU platforms \[[2](http://arxiv.org/abs/2404.12674)\]. Furthermore, these models generalize well to other ML workloads, such as Transformer-based natural language processing (NLP) models, with a GME of 3.00% \[[2](http://arxiv.org/abs/2404.12674)\]. This demonstrates the potential of ML-based performance modeling in handling diverse and complex workloads.

The need for accurate performance prediction has also driven the development of specialized tools and frameworks. LLM-Pilot is a system designed to characterize and optimize LLM inference services by benchmarking across various GPUs and learning predictive models to recommend cost-effective hardware \[[3](http://arxiv.org/abs/2410.02425)\]. This system improves performance requirements fulfillment by 33% while reducing costs by 60% \[[3](http://arxiv.org/abs/2410.02425)\]. Similarly, Vidur is a high-fidelity simulation framework for LLM inference that models performance using experimental profiling and predictive modeling, achieving less than 9% error in latency estimation \[[10](http://arxiv.org/abs/2405.05465)\]. [Snippet]: «The ability to model, analyze, and predict execution time of computations is an important building block that supports numerous efforts, such as load balancing, benchmarking, job scheduling, developer-guided performance optimization, and the automation of performance tuning for high performance, parallel applications. In today’s increasingly heterogeneous computing environment, this task must be accomplished efficiently across multiple architectures, including massively parallel coprocessors like GPUs, which are increasingly prevalent in the world’s fastest supercomputers. To address this challenge, we present an approach for constructing customizable, cross-machine performance models for GPU kernels, including a mechanism to automatically and symbolically gather performance-relevant kernel operation counts, a tool for formulating mathematical models using these counts, and a customizable parameterized collection of benchmark kernels used to calibrate models to GPUs in a black-box fashion. With this approach, we empower the user to manage trade-offs between model accuracy, evaluation speed, and generalizability. A user can define their own model and customize the calibration process, making it as simple or complex as desired, and as application-targeted or general as desired. As application examples of our approach, we demonstrate both linear and nonlinear models; these examples are designed to predict execution times for multiple variants of a particular computation: two matrix-matrix multiplication variants, four discontinuous Galerkin differentiation operation variants, and two 2D five-point finite difference stencil variants. For each variant, we present accuracy results on GPUs from multiple vendors and hardware generations. We view this highly user-customizable approach as a response to a central question arising in GPU performance modeling: how can we model GPU performance in a cost-explanatory fashion while maintaining accuracy, evaluation speed, portability, and ease of use, an attribute we believe precludes approaches requiring manual collection of kernel or hardware statistics.»
