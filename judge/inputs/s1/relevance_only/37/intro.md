## Related Works

Vision Transformers (ViTs) have emerged as a powerful alternative to convolutional neural networks (CNNs) in computer vision tasks, leveraging self-attention mechanisms to capture global context \[[4](http://arxiv.org/abs/2405.00314)\]. However, the deployment of ViTs on hardware platforms, especially FPGAs, remains challenging due to their high computational and memory demands \[[1](https://www.semanticscholar.org/paper/0ade4d722e48379761d17cf1efc05200315c27d9)\]. Existing accelerators often rely on floating-point arithmetic, which is inefficient for hardware implementation \[[16](https://www.semanticscholar.org/paper/b2e51759f910101691039846bec4401a85b53309)\]. Additionally, complex operations such as Softmax and LayerNorm are difficult to map onto low-precision hardware without significant accuracy loss \[[1](https://www.semanticscholar.org/paper/0ade4d722e48379761d17cf1efc05200315c27d9)\].

Several works have explored hardware acceleration for ViTs. HDViT introduces a heterogeneous FPGA accelerator with adaptive dataflow mapping to improve performance \[[1](https://www.semanticscholar.org/paper/0ade4d722e48379761d17cf1efc05200315c27d9)\]. Auto-ViT-Acc proposes an FPGA-aware framework with mixed-scheme quantization, achieving up to 5.6x speedup on frame rate with minimal accuracy loss \[[2](http://arxiv.org/abs/2208.05163)\]. HeatViT employs adaptive token pruning and 8-bit quantization to reduce computation and memory usage while maintaining accuracy \[[3](http://arxiv.org/abs/2211.08110)\]. ME-ViT focuses on minimizing memory traffic by implementing a single-load policy, achieving significant improvements in memory bandwidth and throughput \[[5](http://arxiv.org/abs/2402.09709)\]. ReViT leverages visual semantics to optimize attention mechanisms, achieving speedups of up to 2.3x and energy efficiency improvements of 3.6x \[[6](https://www.semanticscholar.org/paper/f47b726ad00e1a93adc5b3e266c71d75bb05e1ff)\].

Quantization has also been extensively studied for ViTs. Q-ViT introduces an information rectification module and distribution-guided distillation to maintain accuracy during full quantization, achieving up to 6.14x speedup \[[9](http://arxiv.org/abs/2210.06707)\]. Trio-ViT eliminates the Softmax operation and integrates linear attention, achieving up to 7.3x speedup in FPS \[[8](http://arxiv.org/abs/2405.03882)\]. GhostViT reduces parameters and FLOPs by generating diverse features through cheap operations, achieving up to 17% FLOP reduction without accuracy loss \[[10](https://www.semanticscholar.org/paper/37c4b720e1468ca18efb79aa383ffd72a761757b)\]. CHOSEN introduces a software-hardware co-design framework with approximate non-linear functions and efficient use of FPGA resources, achieving up to 1.5x throughput improvement \[[11](http://arxiv.org/abs/2407.12736)\]. ViTA is a configurable accelerator for edge devices, achieving nearly 90% hardware utilization and low power consumption \[[12](http://arxiv.org/abs/2302.09108)\].

The 13th paper proposes a comprehensive codesign approach combining static and dynamic pruning to reduce computation complexity by up to 3.4x with minimal accuracy drop \[[13](http://arxiv.org/abs/2403.14047)\].
