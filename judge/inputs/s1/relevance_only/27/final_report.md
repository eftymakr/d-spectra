## Related Works

Natural language (NL)-driven table discovery has gained significant attention in recent years due to the increasing availability of tabular data repositories. Traditional approaches typically rely on dense vector search pipelines, which involve representation, indexing, and search stages \[[18](http://arxiv.org/abs/1802.06159)\]. These methods often face limitations such as error accumulation during representation and indexing, which negatively impacts search accuracy \[[18](http://arxiv.org/abs/1802.06159)\]. Additionally, insufficient interaction between queries and tables hinders effective semantic alignment, limiting performance improvements \[[18](http://arxiv.org/abs/1802.06159)\].

Several studies have explored deep learning-based methods for table retrieval. For instance, \[[1](http://arxiv.org/abs/2005.09207)\] investigates the use of BERT for ad hoc table retrieval, proposing approaches that incorporate features from prior literature and jointly train them with BERT. While this work demonstrates improvements over BERT baselines, it does not address the issue of error accumulation during indexing and search. Similarly, \[[15](http://arxiv.org/abs/2105.06365)\] introduces a semantic table retrieval framework that matches queries and tables using multiple semantic spaces and similarity measures, achieving significant improvements over state-of-the-art baselines. However, it does not explicitly address the problem of error propagation or query-table interaction limitations.

Recent work on differentiable search indices (DSI) has shown promise in unifying indexing and retrieval into a single model \[[5](http://arxiv.org/abs/2206.10128)\]. DSI models encode all documents in the corpus into model parameters and directly map queries to relevant document identifiers. However, they face challenges such as data distribution mismatch between indexing and retrieval phases \[[5](http://arxiv.org/abs/2206.10128)\]. To address this, \[[5](http://arxiv.org/abs/2206.10128)\] proposes DSI-QG, which generates synthetic queries during indexing to align with the shorter query lengths typically used in retrieval. This approach improves retrieval performance, but it does not explicitly tackle the issue of error accumulation or dynamic indexing.

### <a id='category-differentiable-search-index-frameworks'></a>Differentiable Search Index Frameworks: 7 papers found.
Differentiable Search Index (DSI) frameworks have emerged as a novel paradigm in information retrieval, aiming to unify indexing and retrieval into a single differentiable model \[[2](http://arxiv.org/abs/2305.02073)\]. Unlike traditional systems that require separate indexing and retrieval stages, DSI models encode document identifiers and their associations directly into the model parameters, enabling end-to-end optimization \[[5](http://arxiv.org/abs/2206.10128)\]. However, early DSI approaches faced challenges such as data distribution mismatches between indexing (which often uses long documents) and retrieval (which typically involves shorter queries) \[[3](http://arxiv.org/abs/2504.15849)\]. This issue was exacerbated in cross-lingual retrieval scenarios where query and document languages differ \[[5](http://arxiv.org/abs/2206.10128)\]. To address these limitations, researchers proposed various enhancements, including the Semantic-Enhanced DSI (SE-DSI) model, which improves document memorization through semantic features and elaborative descriptions \[[2](http://arxiv.org/abs/2305.02073)\]. Additionally, DSI-QG was introduced to mitigate data distribution mismatches by generating relevant queries during indexing, allowing the model to better align with retrieval queries \[[5](http://arxiv.org/abs/2206.10128)\]. Furthermore, methods like IncDSI have been developed to enable real-time addition of new documents without retraining the entire model, supporting dynamic updates \[[7](http://arxiv.org/abs/2307.10323)\]. Another approach, ConSI, leverages contrastive learning to improve semantic alignment between queries and documents, enhancing retrieval performance \[[20](https://www.semanticscholar.org/paper/fb80512348a0372a16c826b2af93f56b0cb6bdd3)\]. These advancements highlight the ongoing efforts to refine DSI frameworks, focusing on improving relevance, diversity, and scalability while addressing the challenges of dynamic and cross-lingual retrieval \[[6](http://arxiv.org/abs/2404.12237)\]\[[8](http://arxiv.org/abs/2502.02788)\].
