## Related Works

Deploying large language models (LLMs) on edge devices has been a focal point of recent research due to the increasing demand for privacy-preserving and low-latency inference \[[1](http://arxiv.org/abs/2505.03745)\]. However, the computational and memory demands of LLMs pose significant challenges for resource-constrained edge hardware \[[2](http://arxiv.org/abs/2312.11514)\]. Several approaches have been proposed to address these challenges, primarily focusing on algorithmic optimizations, hardware acceleration, and efficient memory management.

Algorithmic optimizations such as pruning, quantization, and attention mechanism improvements have been widely explored to reduce the computational footprint of LLMs \[[3](http://arxiv.org/abs/2408.00462)\]. For example, $\Lambda$-shaped attention and W2A8KV4 quantization have been introduced to minimize memory and bandwidth usage during inference \[[1](http://arxiv.org/abs/2505.03745)\]. These techniques are critical for enabling efficient inference on edge devices with limited resources \[[4](http://arxiv.org/abs/2410.00531)\]. Additionally, activation sparsity has emerged as a promising method to further compress models while maintaining high accuracy \[[17](http://arxiv.org/abs/2412.12178)\].

Hardware acceleration has also been a key area of research, with FPGA and ASIC-based accelerators being proposed to enhance the performance of LLM inference \[[5](http://arxiv.org/abs/2409.15654)\]. FPGA-based accelerators, in particular, offer reconfigurability and flexibility, allowing for tailored optimizations that match the specific requirements of LLMs \[[6](http://arxiv.org/abs/2406.01698)\]. The design of dedicated hardware accelerators, such as the SECDA-LLM platform, has enabled significant improvements in inference speed and energy efficiency \[[7](http://arxiv.org/abs/2410.04466)\]. Moreover, the integration of hardware-aware techniques, such as in-flash computing and on-die ECC, has further improved the efficiency of LLM deployment on edge devices \[[8](http://arxiv.org/abs/1806.07840)\].

Memory management remains a critical challenge in LLM deployment, especially for long-context generation \[[9](http://arxiv.org/abs/2404.14294)\]. Techniques such as PagedAttention and KV cache management have been introduced to optimize memory usage by reducing fragmentation and enabling efficient sharing of cache across requests \[[10](http://arxiv.org/abs/2502.15816)\]. These methods are essential for supporting real-time and long-context inference on edge devices \[[11](http://arxiv.org/abs/2009.00278)\]. Additionally, sub-matrix partitioning and scaling strategies have been proposed to reduce memory access and computation, significantly improving the efficiency of LLM inference \[[12](http://arxiv.org/abs/2302.00282)\].

Collaborative inference across multiple edge devices has also been explored to address the limitations of individual devices \[[13](http://arxiv.org/abs/2012.03257)\]. Techniques such as distributed CNN inference and cooperative DNN inference have been developed to leverage the combined resources of multiple edge devices, improving both performance and energy efficiency \[[14](https://www.semanticscholar.org/paper/5855287706e30aab1ba0478543027cc2abc7b6c0)\]. These approaches are particularly relevant for deploying large-scale LLMs on resource-constrained edge platforms \[[15](http://arxiv.org/abs/2410.06270)\].

### <a id='category-memory-management-strategies'></a>Memory Management Strategies: 3 papers found.
Memory management strategies for large language models (LLMs) have been a focal point in recent research, particularly in addressing the challenges posed by limited DRAM capacity and high computational demands. Techniques such as "windowing" and "row-column bundling" have been introduced to reduce data transfer from flash memory and optimize sequential data access, enabling models up to twice the size of available DRAM to be run efficiently \[[2](http://arxiv.org/abs/2312.11514)\]. Additionally, PagedAttention has been proposed as an attention algorithm inspired by virtual memory and paging techniques, which significantly reduces KV cache memory waste and allows flexible sharing of cache across requests, leading to improved throughput \[[21](http://arxiv.org/abs/2309.06180)\]. These approaches, along with broader strategies like token-level, model-level, and system-level optimizations, highlight the importance of efficient memory utilization in accelerating LLM inference and improving scalability \[[22](http://arxiv.org/abs/2412.19442)\]. Such strategies are crucial for deploying LLMs on edge devices, where memory and computational resources are constrained, and for achieving real-time performance while maintaining model accuracy \[[2](http://arxiv.org/abs/2312.11514)\].

For instance, Edgent introduces a collaborative and on-demand DNN co-inference framework that partitions computation between the device and edge to leverage hybrid resources for real-time inference, while also employing early-exit techniques to reduce latency \[[8](http://arxiv.org/abs/1806.07840)\]. The integration of hardware accelerators, such as the 28nm scalable system presented in CLONE, further demonstrates the potential of co-design approaches to enhance inference efficiency while maintaining model accuracy \[[1](http://arxiv.org/abs/2505.03745)\].
