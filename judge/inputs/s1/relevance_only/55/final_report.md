## Related Works

Conversational Recommender Systems (CRSs) have emerged as a promising approach to address the limitations of traditional static recommendation models by enabling dynamic, multi-turn interactions with users to better capture their preferences \[[1](http://arxiv.org/abs/2004.00646)\]. Unlike conventional systems that rely solely on historical data \[[1](http://arxiv.org/abs/2004.00646)\], CRSs leverage natural language interactions to explicitly elicit user preferences, leading to more accurate and personalized recommendations \[[3](http://arxiv.org/abs/2101.09459)\]. However, the effectiveness of CRSs is often constrained by the need for frequent user involvement, which can degrade the user experience \[[1](http://arxiv.org/abs/2004.00646)\]. To mitigate this, researchers have proposed simulated users to enable automatic and efficient interaction with CRSs \[[1](http://arxiv.org/abs/2004.00646)\].

Several studies have explored the use of user simulators to evaluate and train CRSs. For instance, \[[2](http://arxiv.org/abs/2401.05783)\] introduced a user simulator that allows simulated users to express preferences about alternative items, improving the evaluation of existing CRS models by considering a broader range of user behavior. Similarly, \[[4](http://arxiv.org/abs/2304.13874)\] proposed a user simulator called ConvSim, which enables multi-turn interactions and provides feedback to system responses, leading to significant improvements in retrieval performance when user feedback is effectively utilized. These simulators are essential for evaluating CRSs in offline settings, as they reduce the reliance on real users and allow for controlled experimentation \[[4](http://arxiv.org/abs/2304.13874)\].

To enhance the realism of simulated users, \[[10](https://www.semanticscholar.org/paper/ecf6d500b491fd4ac35dd7800cd8f171f3e2c08f)\] introduced an approach that leverages user historical data and similar user profiles to capture linguistic style and evolving interests, leading to more natural and context-aware interactions. This is particularly important for generating responses that are not only relevant but also aligned with the user's communication style \[[10](https://www.semanticscholar.org/paper/ecf6d500b491fd4ac35dd7800cd8f171f3e2c08f)\]. Additionally, \[[13](http://arxiv.org/abs/2303.00311)\] proposed a method to model multiple user interests using hierarchical knowledge, allowing for more diverse and accurate recommendations by considering different categories or genres of interest \[[13](http://arxiv.org/abs/2303.00311)\].

Another key challenge in CRSs is the integration of feedback into the recommendation process. \[[11](http://arxiv.org/abs/2002.09102)\] proposed the Estimation-Action-Reflection (EAR) framework, which systematically addresses three core problems: what questions to ask, when to recommend, and how to adapt to user feedback. This framework improves the efficiency of CRSs by reducing the number of conversation turns while maintaining a high level of recommendation accuracy \[[11](http://arxiv.org/abs/2002.09102)\]. Similarly, \[[14](http://arxiv.org/abs/2007.00194)\] introduced a graph-based approach called Conversational Path Reasoning (CPR), which models conversational recommendation as an interactive path reasoning problem, allowing for more precise and efficient attribute selection \[[14](http://arxiv.org/abs/2007.00194)\].
