## Related Works

Semi-supervised learning (SSL) has been widely studied for its ability to leverage unlabeled data when labeled data is scarce. However, conventional SSL methods assume that labeled and unlabeled data share the same class distribution, which is often violated in practice. Unlabeled data may contain out-of-distribution (OOD) samples, i.e., outliers, which can significantly degrade model performance \[[1](http://arxiv.org/abs/2311.10572)\]. Several works have addressed this challenge by focusing on open-set semi-supervised learning (OSSL), where the goal is to classify inliers while detecting outliers \[[2](http://arxiv.org/abs/2303.12091)\].

Early approaches to OSSL primarily relied on outlier detection via binary classifiers, which suffer from scalability issues and inability to distinguish different types of uncertainty \[[3](http://arxiv.org/abs/2308.13168)\]. More recent methods, such as Adaptive Negative Evidential Deep Learning (ANEDL), introduce evidential deep learning (EDL) to quantify uncertainty and design adaptive negative optimization strategies for better performance \[[4](http://arxiv.org/abs/2412.18256)\]. Similarly, IOMatch proposes a framework that jointly utilizes inliers and outliers, improving performance even when distinguishing between them is difficult \[[5](http://arxiv.org/abs/2105.14148)\].

Another line of research focuses on robust SSL in open environments, where unlabeled data may contain inconsistent or noisy samples. These methods aim to improve model performance by studying techniques for label, feature, and data distribution inconsistency \[[6](http://arxiv.org/abs/2109.00650)\]. The work by OpenMatch introduces an open-set soft-consistency regularization loss to enhance the smoothness of the OVA-classifier and improve outlier detection \[[7](http://arxiv.org/abs/2107.08943)\]. Additionally, methods like OpenCoS utilize self-supervised contrastive learning to identify out-of-class samples and improve SSL performance \[[8](http://arxiv.org/abs/2007.08844)\].

The problem of class distribution mismatch between labeled and unlabeled data has also been explored. For example, the work by Distribution Aligning Refinery of Pseudo-label (DARP) addresses this issue by refining pseudo-labels to reduce bias toward majority classes \[[9](http://arxiv.org/abs/2007.11330)\]. Similarly, the Uncertainty-Aware Self-Distillation (UASD) method produces soft targets to avoid catastrophic error propagation and improve generalization under class distribution mismatch \[[10](https://www.semanticscholar.org/paper/f3df804a7eef204b0c4fc4b81166dec9b4abc073)\].

In addition, methods like Class-Aware Contrastive Semi-Supervised Learning (CCSSL) aim to improve pseudo-label quality and model robustness by separately handling in-distribution and out-of-distribution data \[[11](http://arxiv.org/abs/2203.02261)\]. Weight-Aware Distillation (WAD) selectively transfers knowledge from unsupervised contrastive representation to the target classifier, improving performance under class distribution mismatch \[[12](http://arxiv.org/abs/2308.11874)\].

### <a id='category-open-set-semi-supervised-learning-(ossl)-approaches'></a>Open-Set Semi-Supervised Learning (OSSL) Approaches: 11 papers found.
Open-set semi-supervised learning (OSSL) addresses the challenge where unlabeled data may contain out-of-distribution (OOD) samples, which can degrade the performance of conventional semi-supervised learning (SSL) methods \[[1](http://arxiv.org/abs/2311.10572)\]. Existing approaches often rely on detecting outliers through a single model trained on labeled data, which can fail when labeled data is insufficient, leading to worse performance than naive SSL that ignores outliers \[[1](http://arxiv.org/abs/2311.10572)\]. To mitigate this, several studies have proposed frameworks that incorporate multi-task learning, such as Simple but Strong Baseline (SSB), which uses non-linear transformations to separate inlier classification and outlier detection \[[1](http://arxiv.org/abs/2311.10572)\]. Similarly, Adaptive Negative Evidential Deep Learning (ANEDL) introduces uncertainty metrics and an adaptive negative optimization strategy to improve scalability and uncertainty distinction \[[2](http://arxiv.org/abs/2303.12091)\]. Other methods, like IOMatch, jointly utilize inliers and outliers by employing a multi-binary classifier and treating all outliers as a single class, leading to improved performance with minimal complexity \[[3](http://arxiv.org/abs/2308.13168)\]. OpenMatch, another OSSL approach, integrates novelty detection with FixMatch, using one-vs-all classifiers to estimate inlier confidence scores and detect outliers \[[5](http://arxiv.org/abs/2105.14148)\]. Additionally, methods such as WiseOpen propose data selection strategies to filter out harmful OOD samples, enhancing ID classification performance \[[17](http://arxiv.org/abs/2405.06979)\]. The Diversify and Conquer (DAC) framework, which is the focus of this paper, builds upon these ideas by leveraging prediction disagreements among multiple differently biased models trained on unlabeled data, enabling robust outlier detection even with underspecified labeled data \[[1](http://arxiv.org/abs/2311.10572)\].

### <a id='category-open-set-soft-consistency-regularization'></a>Open-Set Soft-Consistency Regularization: 1 papers found.

	Document 1: [Category]: «Open-Set Soft-Consistency Regularization»
[Snippet]: «Semi-Supervised Learning (SSL) has been an effective way to leverage abundant unlabeled data with extremely scarce labeled data. However, most SSL methods are commonly based on instance-wise consistency between different data transformations. Therefore, the label guidance on labeled data is hard to be propagated to unlabeled data. Consequently, the learning process on labeled data is much faster than on unlabeled data which is likely to fall into a local minima that does not favor unlabeled data, leading to sub-optimal generalization performance. In this paper, we propose FlatMatch which minimizes a cross-sharpness measure to ensure consistent learning performance between the two datasets. Specifically, we increase the empirical risk on labeled data to obtain a worst-case model which is a failure case that needs to be enhanced. Then, by leveraging the richness of unlabeled data, we penalize the prediction difference (i.e., cross-sharpness) between the worst-case model and the original model so that the learning direction is beneficial to generalization on unlabeled data. Therefore, we can calibrate the learning process without being limited to insufficient label information. As a result, the mismatched learning performance can be mitigated, further enabling the effective exploitation of unlabeled data and improving SSL performance. Through comprehensive validation, we show FlatMatch achieves state-of-the-art results in many SSL settings.»
