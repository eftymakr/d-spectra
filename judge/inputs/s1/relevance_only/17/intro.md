## Related Works

Semi-supervised learning (SSL) has been widely studied for its ability to leverage unlabeled data when labeled data is scarce. However, conventional SSL methods assume that labeled and unlabeled data share the same class distribution, which is often violated in practice. Unlabeled data may contain out-of-distribution (OOD) samples, i.e., outliers, which can significantly degrade model performance \[[1](http://arxiv.org/abs/2311.10572)\]. Several works have addressed this challenge by focusing on open-set semi-supervised learning (OSSL), where the goal is to classify inliers while detecting outliers \[[2](http://arxiv.org/abs/2303.12091)\].

Early approaches to OSSL primarily relied on outlier detection via binary classifiers, which suffer from scalability issues and inability to distinguish different types of uncertainty \[[3](http://arxiv.org/abs/2308.13168)\]. More recent methods, such as Adaptive Negative Evidential Deep Learning (ANEDL), introduce evidential deep learning (EDL) to quantify uncertainty and design adaptive negative optimization strategies for better performance \[[4](http://arxiv.org/abs/2412.18256)\]. Similarly, IOMatch proposes a framework that jointly utilizes inliers and outliers, improving performance even when distinguishing between them is difficult \[[5](http://arxiv.org/abs/2105.14148)\].

Another line of research focuses on robust SSL in open environments, where unlabeled data may contain inconsistent or noisy samples. These methods aim to improve model performance by studying techniques for label, feature, and data distribution inconsistency \[[6](http://arxiv.org/abs/2109.00650)\]. The work by OpenMatch introduces an open-set soft-consistency regularization loss to enhance the smoothness of the OVA-classifier and improve outlier detection \[[7](http://arxiv.org/abs/2107.08943)\]. Additionally, methods like OpenCoS utilize self-supervised contrastive learning to identify out-of-class samples and improve SSL performance \[[8](http://arxiv.org/abs/2007.08844)\].

The problem of class distribution mismatch between labeled and unlabeled data has also been explored. For example, the work by Distribution Aligning Refinery of Pseudo-label (DARP) addresses this issue by refining pseudo-labels to reduce bias toward majority classes \[[9](http://arxiv.org/abs/2007.11330)\]. Similarly, the Uncertainty-Aware Self-Distillation (UASD) method produces soft targets to avoid catastrophic error propagation and improve generalization under class distribution mismatch \[[10](https://www.semanticscholar.org/paper/f3df804a7eef204b0c4fc4b81166dec9b4abc073)\].

In addition, methods like Class-Aware Contrastive Semi-Supervised Learning (CCSSL) aim to improve pseudo-label quality and model robustness by separately handling in-distribution and out-of-distribution data \[[11](http://arxiv.org/abs/2203.02261)\]. Weight-Aware Distillation (WAD) selectively transfers knowledge from unsupervised contrastive representation to the target classifier, improving performance under class distribution mismatch \[[12](http://arxiv.org/abs/2308.11874)\].
