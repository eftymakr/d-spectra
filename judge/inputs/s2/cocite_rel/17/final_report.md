## Related Works

Semi-supervised learning (SSL) has emerged as a powerful paradigm for improving model performance when labeled data is scarce, leveraging the abundance of unlabeled data \[[1](https://www.semanticscholar.org/paper/f3df804a7eef204b0c4fc4b81166dec9b4abc073)\]. However, conventional SSL methods assume that labeled and unlabeled data share the same class distribution, an assumption that is often violated in practice, as unlabeled data may contain out-of-distribution (OOD) samples or outliers \[[2](http://arxiv.org/abs/2007.11330)\]. These outliers, if not properly handled, can significantly degrade model performance \[[3](http://arxiv.org/abs/2001.07685)\]. To address this limitation, several works have explored open-set SSL, where the presence of OOD samples is explicitly considered \[[4](http://arxiv.org/abs/2108.05617)\].

One approach to open-set SSL is the use of OOD detection techniques to filter out or handle these samples during training. For instance, the work by \[[5](http://arxiv.org/abs/1905.02249)\] introduces a multi-task curriculum learning framework that jointly optimizes OOD detection and SSL, achieving state-of-the-art results by effectively eliminating the impact of OOD samples \[[6](https://www.semanticscholar.org/paper/9e4376e0572de32236e408469ffb2173d89eaab5)\]. Similarly, \[[7](http://arxiv.org/abs/2105.14148)\] proposes a method that leverages cross-modal matching to detect OOD samples, enabling the model to learn more discriminative features while avoiding the adverse effects of OOD data \[[8](http://arxiv.org/abs/2205.07246)\]. Another notable approach is the use of consistency regularization, as seen in FixMatch \[[9](http://arxiv.org/abs/2107.08943)\], which generates pseudo-labels for unlabeled data based on high-confidence predictions \[[10](http://arxiv.org/abs/2109.00650)\].

To further enhance robustness against OOD samples, methods like OpenMatch \[[11](http://arxiv.org/abs/1610.02242)\] and OpenCoS \[[12](http://arxiv.org/abs/2110.08263)\] have been proposed. OpenMatch unifies FixMatch with novelty detection, using one-vs-all (OVA) classifiers to identify inliers and outliers \[[13](http://arxiv.org/abs/1606.04586)\]. OpenCoS, on the other hand, leverages self-supervised contrastive learning to identify OOD samples in unlabeled data, then uses both one-hot and soft labels to improve SSL performance \[[14](http://arxiv.org/abs/1904.12848)\]. These methods demonstrate that handling OOD data is crucial for robust SSL, especially in open-world scenarios where new classes may appear during testing \[[15](http://arxiv.org/abs/1906.12340)\].

Another line of research focuses on improving the thresholding mechanisms for pseudo-labeling, as fixed or manually set thresholds can lead to suboptimal performance \[[16](http://arxiv.org/abs/2203.06915)\]. FreeMatch \[[17](http://arxiv.org/abs/2102.03526)\] introduces a self-adaptive thresholding mechanism that adjusts the confidence threshold based on the model's learning progress, leading to better performance, especially when labeled data is scarce \[[18](https://www.semanticscholar.org/paper/67f8f7fd1b8fea0214b032f94209650a73afece6)\]. Similarly, FlexMatch \[[19](http://arxiv.org/abs/2011.13529)\] employs curriculum pseudo labeling to dynamically adjust thresholds for different classes, improving convergence speed and performance \[[20](http://arxiv.org/abs/1610.02136)\].

### <a id='category-thresholding-mechanisms-for-pseudo-labeling'></a>Thresholding Mechanisms for Pseudo-Labeling: 5 papers found.
In the context of thresholding mechanisms for pseudo-labeling, several recent works have focused on improving the selection of pseudo-labeled data to enhance semi-supervised learning (SSL) performance. FixMatch, for instance, employs a simple yet effective approach by generating pseudo-labels for weakly-augmented images and retaining them only if the model's prediction is confident \[[3](http://arxiv.org/abs/2001.07685)\]. However, this method uses a fixed threshold across all classes, which may not account for varying learning dynamics \[[12](http://arxiv.org/abs/2110.08263)\]. To address this, FreeMatch introduces a self-adaptive thresholding mechanism that adjusts the confidence threshold based on the model's learning progress, leading to better performance, especially when labeled data is scarce \[[8](http://arxiv.org/abs/2205.07246)\]. Similarly, Dash dynamically adjusts the threshold during training by considering the loss of each example, ensuring that only informative pseudo-labels are used \[[10](http://arxiv.org/abs/2109.00650)\]. Another approach, Curriculum Pseudo Labeling (CPL), further refines this idea by allowing different thresholds for different classes, enabling more flexible and efficient use of unlabeled data \[[12](http://arxiv.org/abs/2110.08263)\]. These methods collectively highlight the importance of adaptive thresholding in pseudo-labeling to improve SSL robustness and performance.

### <a id='category-consistency-regularization-methods'></a>Consistency Regularization Methods: 9 papers found.
Consistency regularization methods have been widely explored in semi-supervised learning (SSL) to improve model performance when labeled data is scarce. These methods typically enforce consistency between predictions on labeled and unlabeled data, often through techniques like data augmentation, self-ensembling, or virtual adversarial training \[[11](http://arxiv.org/abs/1610.02242)\]. For instance, self-ensembling leverages predictions from different epochs and augmented views to form a consensus, which serves as a target for training, leading to improved accuracy on benchmarks like CIFAR-10 and SVHN \[[11](http://arxiv.org/abs/1610.02242)\]. Similarly, virtual adversarial training (VAT) introduces a loss function that measures the smoothness of the model's predictions around input data points, enhancing robustness without requiring labeled data \[[21](http://arxiv.org/abs/1704.03976)\]. Advanced data augmentation techniques, such as RandAugment, have also been shown to significantly improve performance by generating high-quality noisy examples that better align with real-world data distributions \[[14](http://arxiv.org/abs/1904.12848)\]. Furthermore, methods like MixMatch combine consistency regularization with data augmentation and label guessing to achieve state-of-the-art results across multiple datasets \[[5](http://arxiv.org/abs/1905.02249)\]. The key idea is that enforcing consistency across different views of the same data point helps the model generalize better, even in the presence of outliers or distribution mismatches \[[24](http://arxiv.org/abs/1912.08766)\]. These approaches highlight the importance of leveraging unlabeled data effectively through consistency-based regularization to enhance SSL performance.

### <a id='category-ood-detection-techniques'></a>OOD Detection Techniques: 5 papers found.
Out-of-distribution (OOD) detection is a critical component in building robust machine learning systems, as it enables the identification of inputs that deviate from the training distribution, which can include adversarial examples, label corruption, and novel, unseen classes \[[15](http://arxiv.org/abs/1906.12340)\]. Several approaches have been proposed to address this challenge, including leveraging self-supervised learning to improve robustness and uncertainty estimation \[[15](http://arxiv.org/abs/1906.12340)\]. For instance, self-supervision has been shown to enhance OOD detection, particularly in identifying difficult, near-distribution outliers, often outperforming fully supervised methods \[[15](http://arxiv.org/abs/1906.12340)\]. Additionally, methods such as using softmax probabilities to distinguish between correctly classified and OOD examples have been explored, demonstrating effectiveness across various domains like computer vision and natural language processing \[[20](http://arxiv.org/abs/1610.02136)\]. Another approach, Outlier Exposure (OE), involves training anomaly detectors against an auxiliary dataset of outliers, which improves generalization and detection performance, especially in tasks like natural language processing and vision \[[22](http://arxiv.org/abs/1812.04606)\]. Furthermore, contrasting shifted instances (CSI) has been introduced as a method inspired by contrastive learning, where models are trained to contrast samples with distributionally-shifted augmentations, leading to improved novelty detection across different settings \[[27](http://arxiv.org/abs/2007.08176)\]. Additionally, methods based on Gaussian discriminant analysis have been proposed to detect abnormal samples by computing confidence scores based on Mahalanobis distance, achieving state-of-the-art performance in both OOD and adversarial sample detection \[[30](http://arxiv.org/abs/1807.03888)\]. These techniques highlight the ongoing research and advancements in OOD detection, emphasizing the need for robust and adaptable methods to ensure reliable machine learning deployment.
