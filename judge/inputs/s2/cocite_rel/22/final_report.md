## Related Works

Unsupervised domain adaptation (UDA) for semantic segmentation has attracted significant research interest due to the high cost of obtaining pixel-level annotations in real-world scenarios \[[1](http://arxiv.org/abs/1909.13589)\]. Traditional UDA methods assume that the category settings between the source and target domains are known, which is often not the case in practical applications \[[1](http://arxiv.org/abs/1909.13589)\]. This assumption leads to performance degradation when private classes exist in the target domain, as the model cannot distinguish between common and private classes \[[1](http://arxiv.org/abs/1909.13589)\].

To address this limitation, several approaches have been proposed. For instance, \[[2](http://arxiv.org/abs/2004.07703)\] introduces a two-step self-supervised domain adaptation approach that minimizes both inter-domain and intra-domain gaps. The method first conducts inter-domain adaptation and then uses an entropy-based ranking function to separate the target domain into easy and hard splits. This allows for more effective adaptation within the target domain \[[2](http://arxiv.org/abs/2004.07703)\]. Similarly, \[[3](http://arxiv.org/abs/1904.01886)\] proposes a depth-aware UDA framework that leverages dense depth information from the source domain to improve the performance of semantic segmentation on the target domain \[[3](http://arxiv.org/abs/1904.01886)\].

Another line of research focuses on improving the robustness of domain adaptation by incorporating self-supervised learning techniques. For example, \[[4](http://arxiv.org/abs/1910.13049)\] introduces a category anchor-guided UDA model that explicitly enforces category-aware feature alignment to learn shared discriminative features and classifiers simultaneously. This approach uses category-wise centroids of the source domain features as guided anchors to identify active features in the target domain and assign pseudo-labels \[[4](http://arxiv.org/abs/1910.13049)\]. The model also employs an anchor-based pixel-level distance loss and a discriminative loss to drive intra-category features closer and inter-category features further apart \[[4](http://arxiv.org/abs/1910.13049)\].

In addition, \[[5](http://arxiv.org/abs/1904.10620)\] proposes a bidirectional learning framework that alternates between learning the image translation model and the segmentation adaptation model. This framework promotes mutual improvement between the two components and introduces a self-supervised learning algorithm to enhance the segmentation adaptation model, which in turn improves the image translation model \[[5](http://arxiv.org/abs/1904.10620)\]. The method achieves superior performance compared to existing state-of-the-art methods \[[5](http://arxiv.org/abs/1904.10620)\].

Furthermore, \[[6](https://www.semanticscholar.org/paper/3f9f801aec1f87ae81524f1928407673805927cb)\] introduces a Separated Semantic Feature based domain adaptation network (SSF-DAN) that addresses the inconsistent adaptation issue in class-wise adversarial learning. The method uses a Semantic-wise Separable Discriminator (SS-D) to independently adapt semantic features across the target and source domains. A progressive confidence strategy is included to achieve a more reliable separation of features \[[6](https://www.semanticscholar.org/paper/3f9f801aec1f87ae81524f1928407673805927cb)\].

### <a id='category-self-supervised-learning-in-domain-adaptation'></a>Self-Supervised Learning in Domain Adaptation: 17 papers found.
The category "Self-Supervised Learning in Domain Adaptation" encompasses a range of approaches aimed at improving the generalization of semantic segmentation models across different domains without requiring labeled target data. These methods often rely on pseudo-labels generated from the source domain to train on the target domain, but they face challenges such as noisy pseudo-labels and domain shift \[[7](http://arxiv.org/abs/2007.08702)\]. To address these issues, various techniques have been proposed, including entropy minimization \[[1](http://arxiv.org/abs/1909.13589)\], adversarial learning \[[12](http://arxiv.org/abs/1802.10349)\], and prototype-based distinction \[[16](https://www.semanticscholar.org/paper/a2e433da83c6e1eb4f4486c900fdfbf1951c4d30)\]. For instance, entropy minimization helps reduce the bias towards easy-to-transfer samples by balancing the gradient during training \[[1](http://arxiv.org/abs/1909.13589)\]. Adversarial learning, on the other hand, has been used to align feature representations between domains by enforcing domain-invariant features \[[13](http://arxiv.org/abs/1811.12833)\]. Additionally, methods like DACS introduce cross-domain mixed sampling to improve the quality of pseudo-labels by combining labeled source data with unlabeled target data \[[7](http://arxiv.org/abs/2007.08702)\]. Furthermore, approaches such as SFDA and SHOT focus on scenarios where source data is not available, relying instead on pre-trained source models to transfer knowledge to the target domain \[[11](http://arxiv.org/abs/2103.16372)\]\[[19](http://arxiv.org/abs/2002.08546)\]. These techniques highlight the importance of leveraging both domain-invariant and domain-specific features to achieve robust adaptation \[[16](https://www.semanticscholar.org/paper/a2e433da83c6e1eb4f4486c900fdfbf1951c4d30)\]. The use of prototype-based distinction, as seen in methods like UniMAP, further enhances the separation of common and private classes by dividing each class into domain-specific prototypes \[[16](https://www.semanticscholar.org/paper/a2e433da83c6e1eb4f4486c900fdfbf1951c4d30)\]. Overall, these approaches demonstrate the evolving strategies in self-supervised learning for domain adaptation, emphasizing the need for robust pseudo-labeling, domain alignment, and handling of class imbalance \[[1](http://arxiv.org/abs/1909.13589)\]\[[7](http://arxiv.org/abs/2007.08702)\]\[[11](http://arxiv.org/abs/2103.16372)\].
