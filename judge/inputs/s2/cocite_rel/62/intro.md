## Related Works

Generative retrieval has emerged as a promising paradigm in information retrieval, shifting from traditional index-based methods to end-to-end neural network models that directly generate document identifiers for a given query \[[12](http://arxiv.org/abs/2202.06991)\]. This approach leverages the power of large language models to bypass the need for explicit index structures, enabling seamless integration with generative models \[[12](http://arxiv.org/abs/2202.06991)\]. Several recent works have explored different aspects of this paradigm, focusing on scalability, efficiency, and effectiveness.

Early efforts in generative retrieval focused on using transformer networks as differentiable search indexes, where each document is represented as a sequence of document ID tokens \[[12](http://arxiv.org/abs/2202.06991)\]. This allows the retrieval process to be cast as a document ID generation problem, enabling a more flexible and end-to-end approach \[[12](http://arxiv.org/abs/2202.06991)\]. However, these models often struggled with performance on large-scale benchmarks due to limitations in training and inference \[[12](http://arxiv.org/abs/2202.06991)\]. Subsequent works, such as RIPOR, introduced optimization frameworks designed to address these issues by improving the accuracy of relevance scoring during sequential document ID generation and constructing document IDs based on relevance associations between queries and documents \[[2](http://arxiv.org/abs/2311.09134)\].

Another key contribution to the field is the development of methods for learning document identifiers in a fully end-to-end manner. GenRet, for instance, proposes a discrete auto-encoding approach to tokenize documents into short discrete representations (docids) while also enabling the reconstruction of the original document from the docid \[[3](http://arxiv.org/abs/2304.04171)\]. This method not only improves the semantic richness of the identifiers but also enables more effective retrieval \[[3](http://arxiv.org/abs/2304.04171)\]. Similarly, CorpusBrain demonstrates that a strong generative retrieval model can be pre-trained on a set of carefully designed tasks and then fine-tuned for various downstream KILT tasks \[[4](http://arxiv.org/abs/2208.07652)\].

The issue of data distribution mismatch between indexing and retrieval phases in differentiable search indexes has also been addressed. DSI-QG introduces a novel indexing framework that generates potentially relevant queries for each document during indexing, allowing the retrieval process to better align with the query distribution \[[5](http://arxiv.org/abs/2206.10128)\]. This approach significantly improves performance on both mono-lingual and cross-lingual retrieval tasks \[[5](http://arxiv.org/abs/2206.10128)\].

Moreover, the challenge of learning to rank in generative retrieval has been tackled by LTRGR, which introduces a learning-to-rank framework that optimizes the autoregressive model toward the final passage ranking target via a rank loss \[[9](http://arxiv.org/abs/2306.15222)\]. This approach enhances the performance of existing generative retrieval systems without adding overhead during inference \[[9](http://arxiv.org/abs/2306.15222)\].
