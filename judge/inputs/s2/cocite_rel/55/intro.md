## Related Works

Conversational Recommender Systems (CRSs) have emerged as a promising approach to dynamically capture user preferences through multi-turn interactions \[[1](http://arxiv.org/abs/2002.09102)\]. Traditional recommendation systems rely on static models that estimate user preferences based on historical interactions, often leading to suboptimal recommendations due to their inability to adapt to dynamic user behavior \[[4](http://arxiv.org/abs/2101.09459)\]. In contrast, CRSs enable systems to actively engage with users, ask clarifying questions about item attributes, and refine recommendations in real-time \[[3](http://arxiv.org/abs/2004.00646)\]. This interaction-based approach has been shown to improve recommendation accuracy and user satisfaction \[[10](https://www.semanticscholar.org/paper/be0edbe07823c69a4e6fc1e194a35910655885e4)\].

Several studies have explored the challenges of modeling user preferences in conversational settings. For instance, the Estimation-Action-Reflection (EAR) framework proposes a three-stage process to manage the interaction between conversation and recommendation: estimating user preferences, determining whether to ask for attribute information or recommend items, and updating the model based on user feedback \[[1](http://arxiv.org/abs/2002.09102)\]. Similarly, the Conversational Path Reasoning (CPR) framework models the recommendation process as an interactive path reasoning problem on a graph, allowing for more efficient exploration of user preferences \[[2](http://arxiv.org/abs/2007.00194)\]. These approaches highlight the importance of integrating dialogue understanding with recommendation algorithms to improve the accuracy of preference elicitation.

The ability to generate and respond to clarifying questions is a key component of effective conversational recommendation \[[17](http://arxiv.org/abs/1812.07617)\]. Recent work has focused on generating questions that help clarify user intent, particularly in scenarios where user preferences are ambiguous or multifaceted \[[20](https://www.semanticscholar.org/paper/223884ef08f38fd0765e4c0e467a223aef573236)\]. For example, the Q&R framework proposes a two-stage approach to interactive recommendation: first, generating relevant questions based on user input, and then using the feedback to refine recommendations \[[13](https://www.semanticscholar.org/paper/2610b45131f31a7c58b0cd6a8fce21c02ba014be)\]. This approach has been successfully applied in YouTube's user onboarding and homepage recommendation systems, demonstrating improvements in recommendation accuracy and user engagement \[[13](https://www.semanticscholar.org/paper/2610b45131f31a7c58b0cd6a8fce21c02ba014be)\].

Another critical challenge in CRSs is the integration of dialogue and recommendation components. The Unified Conversational Recommender Systems (UniCRS) model addresses this by leveraging knowledge-enhanced prompt learning to unify the recommendation and conversation subtasks within a single framework \[[16](http://arxiv.org/abs/2206.09363)\]. This approach allows for more seamless integration of dialogue generation and recommendation, improving both the quality of interactions and the accuracy of recommendations.

Simulated users have also been proposed as a means to evaluate and improve CRSs without requiring extensive human interaction. The UserSimCRS toolkit enables automated evaluation by simulating user behavior, including preference modeling and interaction flow \[[9](http://arxiv.org/abs/2301.05544)\]. This approach has been shown to produce results that correlate well with human evaluations, making it a valuable tool for benchmarking CRS
