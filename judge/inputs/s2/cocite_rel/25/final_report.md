## Related Works

The integration of knowledge graphs (KGs) with large language models (LLMs) to enhance reasoning capabilities has gained significant attention in recent years. While LLMs have demonstrated strong reasoning abilities, they often struggle with structured knowledge retrieval and multi-step reasoning tasks \[[1](http://arxiv.org/abs/2104.06378)\]. KGs, on the other hand, provide rich, structured representations that are well-suited for logical inference and reasoning \[[2](http://arxiv.org/abs/2308.09729)\]. However, most existing verification methods rely on unstructured text corpora, limiting their ability to effectively leverage KGs \[[1](http://arxiv.org/abs/2104.06378)\]. 

Several works have explored the use of KGs to improve LLM performance. QA-GNN \[[1](http://arxiv.org/abs/2104.06378)\] introduces a model that combines LMs with KGs by using relevance scoring and joint reasoning over the QA context and KG. This approach enables the model to handle negation and perform structured reasoning. Similarly, MindMap \[[2](http://arxiv.org/abs/2308.09729)\] proposes a prompting pipeline that leverages KGs to enhance LLMs' inference and transparency, enabling them to understand KG inputs and infer with a combination of implicit and external knowledge. 

Query2box \[[3](http://arxiv.org/abs/2002.05969)\] presents an embedding-based framework for reasoning over arbitrary logical queries in KGs, supporting conjunctions, disjunctions, and existential quantifiers. This work addresses the challenge of representing complex queries in vector space by using boxes (hyper-rectangles) to capture sets of answer entities. The framework demonstrates effectiveness on large KGs and achieves up to 25% relative improvement over the state of the art. 

Retrieval-Augmented Generation (RAG) \[[4](http://arxiv.org/abs/2005.11401)\] combines pre-trained parametric and non-parametric memory for language generation, enabling models to access external knowledge. This approach has been successfully applied to knowledge-intensive NLP tasks, achieving state-of-the-art results on open-domain QA tasks. The use of non-parametric memory, such as dense vector indexes of Wikipedia, allows models to access up-to-date and diverse knowledge. 

KEPLER \[[5](http://arxiv.org/abs/2011.00235)\] proposes a unified model for knowledge embedding and pre-trained language representation, integrating textual information with KGs to produce effective text-enhanced knowledge embeddings. This model has shown state-of-the-art performance on various NLP tasks and works well as an inductive KG link prediction model. 

Recent works have also focused on the integration of LLMs with KGs for reasoning. LARK \[[12](http://arxiv.org/abs/2305.01157)\] introduces a decoupled approach that combines contextual KG search with logical query reasoning, leveraging the strengths of graph extraction algorithms and LLMs. This approach outperforms state-of-the-art KG reasoning

	Document 1: [Snippet]: «Answering complex logical queries on large-scale incomplete knowledge graphs (KGs) is a fundamental yet challenging task. Recently, a promising approach to this problem has been to embed KG entities as well as the query into a vector space such that entities that answer the query are embedded close to the query. However, prior work models queries as single points in the vector space, which is problematic because a complex query represents a potentially large set of its answer entities, but it is unclear how such a set can be represented as a single point. Furthermore, prior work can only handle queries that use conjunctions ($\wedge$) and existential quantifiers ($\exists$). Handling queries with logical disjunctions ($\vee$) remains an open problem. Here we propose query2box, an embedding-based framework for reasoning over arbitrary queries with $\wedge$, $\vee$, and $\exists$ operators in massive and incomplete KGs. Our main insight is that queries can be embedded as boxes (i.e., hyper-rectangles), where a set of points inside the box corresponds to a set of answer entities of the query. We show that conjunctions can be naturally represented as intersections of boxes and also prove a negative result that handling disjunctions would require embedding with dimension proportional to the number of KG entities. However, we show that by transforming queries into a Disjunctive Normal Form, query2box is capable of handling arbitrary logical queries with $\wedge$, $\vee$, $\exists$ in a scalable manner. We demonstrate the effectiveness of query2box on two large KGs and show that query2box achieves up to 25% relative improvement over the state of the art.»
