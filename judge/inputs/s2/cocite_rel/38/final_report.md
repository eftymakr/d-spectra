## Related Works

Memory bandwidth regulation and cache partitioning have been widely studied as techniques to achieve predictable timing in real-time computing systems \[[1](https://www.semanticscholar.org/paper/bbebaeb1b00fdcde2aeb192543835d3ec1518f8d)\]. These approaches are often combined with partitioned scheduling to ensure that tasks execute within their guaranteed time bounds \[[2](https://www.semanticscholar.org/paper/50d359dc737cb5c296b527f4eb1541dc55f3ed86)\]. However, the co-allocation of tasks and resources to cores remains a critical challenge, as task execution times are strongly influenced by the allocated resources \[[3](https://www.semanticscholar.org/paper/25ebad66dc10d7b01c22684cbb200ddeb6502475)\]. To address this, this paper introduces a 0-1 linear program for task-resource co-allocation, along with a multi-objective heuristic that minimizes resource usage while guaranteeing schedulability under a preemptive EDF scheduling policy \[[4](https://www.semanticscholar.org/paper/dbd4eb5033815003e7f6519fd66e43e5fc297075)\].

Several prior works have explored memory bandwidth management and cache partitioning to improve predictability in multi-core systems. For instance, MemGuard \[[5](https://www.semanticscholar.org/paper/abbd6f8840092bd8e4e3684d3297e1b707abdc5d)\] introduces a memory bandwidth reservation system to isolate performance across cores, while PALLOC \[[6](https://www.semanticscholar.org/paper/0b1bc294dbd926f853a8ee41d1d8f8ecc3cfde13)\] proposes a DRAM bank-aware memory allocator to enhance performance isolation. These approaches aim to reduce interference and improve predictability by controlling memory access patterns \[[7](https://www.semanticscholar.org/paper/afca4afaaaa543a1da02b266e9b2ac46eb94793b)\]. Similarly, E-WarP \[[8](https://www.semanticscholar.org/paper/6e925ae85e385ac0e8810441d84be97c079f6b22)\] presents a system-wide framework for memory bandwidth profiling and management, enabling more accurate predictions of workload behavior on multi-core platforms. The framework uses a profile-driven approach to analyze memory demands and supports saturation-aware system consolidation \[[9](https://www.semanticscholar.org/paper/d5336fd2234f431f554fc5d878503a04a27e366e)\].

Cache management is another key area of research, particularly in real-time systems. The paper "A Coordinated Approach for Practical OS-Level Cache Management in Multi-core Real-Time Systems" \[[10](https://www.semanticscholar.org/paper/f71c848137ac1398f84e6ab7d896641f801ca192)\] discusses techniques to manage cache effectively in multi-core environments, addressing the challenges of cache interference and unpredictability \[[11](https://www.semanticscholar.org/paper/31e4e1bb57bd04bc02d7f7110e66122a215d7bfa)\]. Additionally, the "Real-time cache management framework for multi-core architectures" \[[12](http://arxiv.org/abs/1903.00999)\] proposes a framework that enables efficient cache utilization, which is crucial for predictable timing in real-time applications \[[13](https://www.semanticscholar.org/paper/7cfc8086dda3ff7017af905d6ca3a5d6a6690f89)\].

The concept of cache coloring and cache bleaching has also been explored to mitigate cache interference. This technique is particularly relevant in consolidating hard real-time systems onto modern multi-core SoCs .

### <a id='category-memory-bandwidth-regulation-techniques'></a>Memory Bandwidth Regulation Techniques: 7 papers found.
Memory Bandwidth Regulation Techniques have been extensively studied to address the challenges of predictable timing in real-time computing systems, particularly in multi-core and accelerator-enabled environments \[[3](https://www.semanticscholar.org/paper/25ebad66dc10d7b01c22684cbb200ddeb6502475)\]. These techniques aim to mitigate memory interference and ensure bounded execution times by controlling access to shared memory resources. For instance, in COTS multi-core systems, memory interference can lead to significant and variable delays, making it difficult to design predictable real-time systems \[[7](https://www.semanticscholar.org/paper/afca4afaaaa543a1da02b266e9b2ac46eb94793b)\]. To tackle this, researchers have proposed methods to model and bound worst-case memory interference by considering the timing characteristics of DRAM resources such as banks, buses, and memory controllers \[[7](https://www.semanticscholar.org/paper/afca4afaaaa543a1da02b266e9b2ac46eb94793b)\]. Additionally, memory bandwidth regulation is often combined with cache partitioning and scheduling strategies to improve predictability \[[3](https://www.semanticscholar.org/paper/25ebad66dc10d7b01c22684cbb200ddeb6502475)\]. A notable approach is the RT-Gang framework, which enforces a one-gang-at-a-time policy to minimize contention and improve system predictability by integrating memory bandwidth throttling for best-effort tasks \[[12](http://arxiv.org/abs/1903.00999)\]. Furthermore, predictive models like E-WarP have been introduced to analyze memory demands and predict temporal behavior, enabling more efficient system consolidation and resource allocation \[[10](https://www.semanticscholar.org/paper/f71c848137ac1398f84e6ab7d896641f801ca192)\]. These techniques collectively highlight the importance of memory bandwidth regulation in achieving reliable performance in complex, real-time embedded systems.

The extensive sharing of hardware resources at the memory hierarchy raises important unpredictability concerns. The problem is exacerbated as more computationally demanding workload is expected to be handled with real-time guarantees in next-generation Cyber-Physical Systems (CPS). A large body of works has approached the problem by proposing novel hardware redesigns, and by proposing software-only solutions to mitigate performance interference.Strong from the observation that unpredictability arises from a lack of fine-grained control over the behavior of shared hardware components, we outline a promising new resource management approach. We demonstrate that it is possible to introduce Programmable Logic In-the-Middle (PLIM) between a traditional multi-core processor and main memory. This provides the unique capability of manipulating individual memory transactions. We propose a proof-of-concept system implementation of PLIM modules on a commercial multi-core SoC. The PLIM approach is then leveraged to solve long-standing issues with cache coloring. Thanks to PLIM, colored sparse addresses can be re-compacted in main memory. This is the base principle behind the technique we call Cache Bleaching. We evaluate our design on real applications and propose hypervisor-level adaptations to showcase the potential of the PLIM approach.»
