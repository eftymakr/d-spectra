## Related Works

Multi-Domain Recommendation (MDR) has emerged as a promising approach to improve recommendation performance by leveraging knowledge transfer across different domains \[[12](http://arxiv.org/abs/2202.12524)\]. Traditional MDR methods often rely on a shared structure to transfer domain-shared knowledge, but this approach can lead to the Negative Transfer Problem (NTP) when there is knowledge conflict or poor quality in certain domains \[[12](http://arxiv.org/abs/2202.12524)\]. This issue is particularly problematic because the beneficial transfer information can vary significantly across domains \[[12](http://arxiv.org/abs/2202.12524)\]. 

Several studies have attempted to address these challenges. For instance, CoNet \[[2](http://arxiv.org/abs/1804.06769)\] introduces a deep transfer learning approach using neural networks to enable dual knowledge transfer across domains. It utilizes cross connections between base networks to facilitate collaborative learning and has shown improvements in recommendation accuracy. Similarly, DTCDR \[[3](https://www.semanticscholar.org/paper/2b031c7170c9dccbe506f3d3a1d6104f65e835ae)\] proposes a framework that leverages multi-source content information and multi-task learning to improve performance on both richer and sparser domains simultaneously. 

The BiTGCF model \[[4](https://www.semanticscholar.org/paper/d5630291a4ba3f6266c77e6d00920502f986afa6)\] extends cross-domain recommendation by using a bi-directional transfer learning method with a graph collaborative filtering network, enabling two-way knowledge transfer through common users. This model effectively captures high-order information propagation and has been validated on multiple benchmark datasets. 

DDTCDR \[[5](http://arxiv.org/abs/1910.05189)\] further advances cross-domain recommendation by introducing a dual learning mechanism that iteratively transfers information between domains until the learning process stabilizes. This approach preserves latent relations between users across different domains and has been tested on a large dataset with three domains, showing significant improvements over existing methods. 

Preference Propagation GraphNet (PPGN) \[[6](https://www.semanticscholar.org/paper/24a473700894dbfab0bfd9dc3d542acfeef66bca)\] addresses the sparsity issue by constructing a Cross-Domain Preference Matrix (CDPM) and using a propagation layer to model how user preferences propagate in the graph. This method simplifies cross-domain recommendation into a unified multi-task model and has been validated on real-world datasets. 

Multi-Domain Collaborative Filtering (MCF) \[[7](http://arxiv.org/abs/1203.3535)\] tackles the data sparsity problem by considering multiple collaborative filtering tasks in different domains and allowing knowledge transfer across domains. This probabilistic framework enables adaptive learning of domain correlations and has been tested on several real-world applications. 

Adversarial Feature Translation (AFT) \[[8](https://www.semanticscholar.org/paper/7807d924fa46caec7b706b98156962caf8458d59)\] is another approach that learns feature translations between domains using a generative adversarial network framework. This model explicitly models relationships between items, domains, and user representations, achieving significant improvements on both public and industrial datasets. 

The work in \[[9](http://arxiv.org/abs/2211.11964)\] proposes CAT-ART, a multi-target CDR method that improves recommendations in all participating domains through representation learning and embedding transfer.

### <a id='category-cross-domain-knowledge-transfer'></a>Cross-Domain Knowledge Transfer: 9 papers found.
Cross-domain recommendation (CDR) has emerged as a critical approach to address data sparsity in recommender systems by leveraging knowledge from multiple domains \[[1](http://arxiv.org/abs/2103.01696)\]. Various methods have been proposed to facilitate knowledge transfer between domains, including deep transfer learning models like CoNet \[[2](http://arxiv.org/abs/1804.06769)\], which introduces cross connections between base networks to enable dual knowledge transfer. Similarly, BiTGCF \[[4](https://www.semanticscholar.org/paper/d5630291a4ba3f6266c77e6d00920502f986afa6)\] employs a bidirectional transfer learning approach using graph collaborative filtering networks to enable two-way knowledge transfer across domains. These methods aim to improve recommendation performance by effectively utilizing shared user features and domain-specific information. Additionally, the DDTCDR model \[[5](http://arxiv.org/abs/1910.05189)\] introduces a dual learning mechanism that iteratively transfers information between domains to enhance recommendation accuracy. The challenge of negative transfer, where knowledge from a source domain may hinder performance in a target domain, has also been addressed through methods like CAT-ART \[[9](http://arxiv.org/abs/2211.11964)\], which employs a multi-target approach to improve recommendations across multiple domains by learning global user embeddings and transferring domain-specific knowledge. Furthermore, the SCSR task \[[10](https://www.semanticscholar.org/paper/fa990aee9a8f157b5d393f5f3eaa014e1e5c67aa)\] extends cross-domain recommendation to sequential settings, where user behaviors across domains are considered to improve recommendations in real-time. These approaches highlight the ongoing efforts to develop more effective and scalable cross-domain recommendation systems that can handle the complexities of multi-domain data and avoid negative transfer.

### <a id='category-multi-task-learning-approaches'></a>Multi-Task Learning Approaches: 1 papers found.
Context: 
	Document 1: [Snippet]: «In order to address the data sparsity problem in recommender systems, in recent years, Cross-Domain Recommendation (CDR) leverages the relatively richer information from a source domain to improve the recommendation performance on a target domain with sparser information. However, each of the two domains may be relatively richer in certain types of information (e.g., ratings, reviews, user profiles, item details, and tags), and thus, if we can leverage such information well, it is possible to improve the recommendation performance on both domains simultaneously (i.e., dual-target CDR), rather than a single target domain only. To this end, in this paper, we propose a new framework, DTCDR, for Dual-Target Cross-Domain Recommendation. In DTCDR, we first extensively utilize rating and multi-source content information to generate rating and document embeddings of users and items. Then, based on Multi-Task Learning (MTL), we design an adaptable embedding-sharing strategy to combine and share the embeddings of common users across domains, with which DTCDR can improve the recommendation performance on both richer and sparser (i.e., dual-target) domains simultaneously. Extensive experiments conducted on real-world datasets demonstrate that DTCDR can significantly improve the recommendation accuracies on both richer and sparser domains and outperform the state-of-the-art single-domain and cross-domain approaches.»

### <a id='category-graph-based-recommendation-models'></a>Graph-Based Recommendation Models: 1 papers found.
Context: 
	Document 1: [Snippet]: «Recommendation can be framed as a graph link prediction task naturally. The user-item interaction graph built within a single domain often suffers from high sparsity. Thus, there has been a surge of approaches to alleviate the sparsity issue via cross-domain mutual augmentation. The SOTA cross-domain recommendation algorithms all try to bridge the gap via knowledge transfer in the latent space. We find there are mainly three problems in their formulations: 1) their knowledge transfer is unaware of the cross-domain graph structure. 2) their framework cannot capture high-order information propagation on the graph. 3) their cross-domain transfer formulations are generally more complicated to be optimized than the unified methods. In this paper, we propose the Preference Propagation GraphNet (PPGN) to address the above problems. Specifically, we construct a Cross-Domain Preference Matrix (CDPM) to model the interactions of different domains as a whole. Through the propagation layer of PPGN, we try to capture how user preferences propagate in the graph. Consequently, a joint objective for different domains is defined, and we simplify the cross-domain recommendation into a unified multi-task model. Extensive experiments on two pairs of real-world datasets show PPGN outperforms the SOTA algorithms significantly.»

### <a id='category-collaborative-filtering-frameworks'></a>Collaborative Filtering Frameworks: 1 papers found.
Context: 
	Document 1: [Snippet]: «Collaborative filtering is an effective recommendation approach in which the preference of a user on an item is predicted based on the preferences of other users with similar interests. A big challenge in using collaborative filtering methods is the data sparsity problem which often arises because each user typically only rates very few items and hence the rating matrix is extremely sparse. In this paper, we address this problem by considering multiple collaborative filtering tasks in different domains simultaneously and exploiting the relationships between domains. We refer to it as a multi-domain collaborative filtering (MCF) problem. To solve the MCF problem, we propose a probabilistic framework which uses probabilistic matrix factorization to model the rating problem in each domain and allows the knowledge to be adaptively transferred across different domains by automatically learning the correlation between domains. We also introduce the link function for different domains to correct their biases. Experiments conducted on several real-world applications demonstrate the effectiveness of our methods when compared with some representative methods.»

### <a id='category-adversarial-learning-in-recommendation-systems'></a>Adversarial Learning in Recommendation Systems: 1 papers found.
Context: 
	Document 1: [Snippet]: «Real-world super platforms such as Google and WeChat usually have different recommendation scenarios to provide heterogeneous items for users' diverse demands. Multi-domain recommendation (MDR) is proposed to improve all recommendation domains simultaneously, where the key point is to capture informative domain-specific features from all domains. To address this problem, we propose a novel Adversarial feature translation (AFT) model for MDR, which learns the feature translations between different domains under a generative adversarial network framework. Precisely, in the multi-domain generator, we propose a domain-specific masked encoder to highlight inter-domain feature interactions, and then aggregate these features via a transformer and a domain-specific attention. In the multi-domain discriminator, we explicitly model the relationships between item, domain and users' general/domain-specific representations with a two-step feature translation inspired by the knowledge representation learning. In experiments, we evaluate AFT on a public and an industrial MDR datasets and achieve significant improvements. We also conduct an online evaluation on a real-world MDR system. We further give detailed ablation tests and model analyses to verify the effectiveness of different components. Currently, we have deployed AFT on WeChat Top Stories. The source code is in https://github.com/xiaobocser/AFT.»
