## Related Works

Recent advancements in information retrieval have seen a shift from traditional sparse indexing methods to dense retrieval models that leverage deep learning for improved accuracy. Early work on dense retrieval focused on using pre-trained language models to generate embeddings for both queries and documents, enabling more semantically meaningful comparisons \[[14](http://arxiv.org/abs/2004.04906)\]. This approach has been widely adopted in open-domain question answering, where dense retrievers have demonstrated significant improvements over traditional methods like BM25 \[[14](http://arxiv.org/abs/2004.04906)\]. However, these methods often suffer from error accumulation during the representation and indexing phases, which can degrade search accuracy \[[1](http://arxiv.org/abs/2204.10628)\].

To address these limitations, several works have explored differentiable search indices (DSIs), which unify indexing and retrieval into a single model. The DSI framework encodes the entire corpus into model parameters and directly maps queries to document identifiers, eliminating the need for separate indexing and retrieval stages \[[3](http://arxiv.org/abs/2202.06991)\]. This approach has shown strong generalization capabilities, outperforming BM25 in zero-shot settings \[[3](http://arxiv.org/abs/2202.06991)\]. However, DSIs face challenges in handling dynamic corpora, as retraining is required when new documents are added, leading to catastrophic forgetting \[[7](http://arxiv.org/abs/2212.09744)\].

To mitigate this, DSI++ was introduced, which enables continual learning by incrementally updating the model with new documents while preserving previously learned information. This is achieved through techniques such as flatter loss basins and generative memory to simulate pseudo-queries during indexing \[[7](http://arxiv.org/abs/2212.09744)\]. These improvements have led to significant gains in retrieval accuracy, with DSI++ achieving a $+21.1\%$ improvement in Hits@10 over competitive baselines \[[7](http://arxiv.org/abs/2212.09744)\].

Another line of work focuses on improving query-table interaction for semantic table retrieval. The GTR framework addresses the limitations of treating tables as plain text by representing them as multi-granular graphs, capturing both content and layout structures. This allows for more accurate semantic alignment between queries and tables, especially in complex layouts \[[15](http://arxiv.org/abs/2105.01736)\]. Similarly, the MTR model introduces a multimodal ranking approach using Gated Multimodal Units (GMUs) to jointly represent queries and table modalities, enhancing semantic similarity computation \[[10](https://www.semanticscholar.org/paper/373588873bef360e3ecad2e091ac17895eb863af)\].

### <a id='category-differentiable-search-index-(dsi)-frameworks'></a>Differentiable Search Index (DSI) Frameworks: 5 papers found.
Differentiable Search Index (DSI) frameworks represent a paradigm shift in information retrieval by integrating indexing and retrieval into a unified model, eliminating the need for separate components \[[3](http://arxiv.org/abs/2202.06991)\]. These frameworks leverage autoregressive models to generate document identifiers directly from queries, enabling end-to-end optimization \[[2](http://arxiv.org/abs/2206.02743)\]. For instance, the DSI approach encodes all corpus information into a single Transformer, allowing direct query-to-docid mapping without explicit indexing \[[3](http://arxiv.org/abs/2202.06991)\]. This contrasts with traditional index-retrieve pipelines, which suffer from data distribution mismatches between indexing and retrieval stages \[[4](http://arxiv.org/abs/2206.10128)\]. To address this, DSI-QG introduces a query generation module during indexing, aligning document representations with query characteristics \[[4](http://arxiv.org/abs/2206.10128)\]. Additionally, methods like SEAL use ngrams as identifiers, allowing autoregressive models to score passages efficiently \[[1](http://arxiv.org/abs/2204.10628)\]. These approaches demonstrate that DSI models can achieve superior performance over established retrieval systems, often with reduced memory footprints \[[1](http://arxiv.org/abs/2204.10628)\]\[[3](http://arxiv.org/abs/2202.06991)\]. Furthermore, they enable zero-shot generalization, as seen in BM25 comparisons \[[3](http://arxiv.org/abs/2202.06991)\]. The integration of query generation and semantic alignment further enhances retrieval accuracy, as demonstrated by models like NCI, which improve Recall@1 and R-Precision through prefix-aware decoding and consistency-based regularization \[[2](http://arxiv.org/abs/2206.02743)\]. These developments highlight the growing importance of DSI in advancing retrieval systems through unified, differentiable architectures.
