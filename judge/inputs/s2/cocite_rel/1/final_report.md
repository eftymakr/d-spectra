## Related Works

Efficient memory management and KV cache optimization have been extensively studied to improve the performance and scalability of large language model (LLM) serving systems. Early approaches focused on reducing memory usage through quantization and compression techniques. For instance, KIVI \[[2](http://arxiv.org/abs/2402.02750)\] introduced a tuning-free 2-bit quantization method for the KV cache, significantly reducing peak memory usage and enabling larger batch sizes. Similarly, GEAR \[[10](http://arxiv.org/abs/2403.05527)\] proposed a near-lossless compression framework that combines quantization and low-rank approximation to achieve up to 2.38x throughput improvements while reducing memory usage by 2.29x. These methods highlight the importance of reducing the memory footprint of the KV cache to enable efficient inference.

Recent research has also explored adaptive and workload-aware strategies for managing the KV cache. For example, H2O \[[5](http://arxiv.org/abs/2306.14048)\] introduced a dynamic eviction policy based on the Heavy Hitter Oracle, which identifies and retains tokens that contribute most to attention scores. This approach improves throughput by up to 29x on certain models. Similarly, Scissorhands \[[3](http://arxiv.org/abs/2305.17118)\] leverages the persistence of importance hypothesis, maintaining only pivotal tokens in the KV cache to reduce memory usage by up to 5X without compromising model quality. These methods demonstrate the effectiveness of prioritizing important tokens to maintain generation quality while minimizing memory consumption.

Another line of work focuses on the structural properties of attention mechanisms and how they can be exploited for efficient KV cache management. For example, PyramidKV \[[13](http://arxiv.org/abs/2406.02069)\] dynamically adjusts the KV cache size across different layers of the model, allocating more cache in lower layers and less in higher ones. This approach reduces memory usage significantly while maintaining performance. Similarly, PyramidInfer \[[15](http://arxiv.org/abs/2405.12532)\] compresses the KV cache by retaining only the most crucial context layer by layer, achieving over 54% GPU memory reduction and improving throughput by 2.2x compared to existing methods. These techniques highlight the importance of understanding the hierarchical nature of attention in LLMs to optimize cache usage.

Moreover, methods such as Keyformer \[[14](http://arxiv.org/abs/2403.09054)\] focus on reducing the memory bandwidth and KV cache size by retaining only the key tokens that contribute most to attention. This approach reduces inference latency by 2.1x and improves token generation throughput by 2.4x without compromising model accuracy. These methods underscore the importance of identifying and retaining only the most relevant tokens to optimize both memory and computational efficiency.

### <a id='category-memory-management-techniques-for-kv-cache'></a>Memory Management Techniques for KV Cache: 10 papers found.
Memory management techniques for KV cache have been extensively explored to optimize the performance and efficiency of large language models (LLMs) during inference. Several approaches have been proposed to address the memory bottlenecks caused by the dynamic and often large size of the KV cache. For instance, PagedAttention \[[1](http://arxiv.org/abs/2309.06180)\] introduces an attention algorithm inspired by virtual memory paging, enabling near-zero memory waste and flexible sharing of KV cache across requests. Similarly, Scissorhands \[[3](http://arxiv.org/abs/2305.17118)\] reduces memory usage by prioritizing the storage of pivotal tokens, achieving up to 5X compression without compromising model quality. Heavy Hitter Oracle (H$_2$O) \[[5](http://arxiv.org/abs/2306.14048)\] further improves memory efficiency by retaining a balance of recent and high-impact tokens, reducing latency by up to 1.9X. SnapKV \[[6](http://arxiv.org/abs/2404.14469)\] compresses KV caches by focusing on important attention features, achieving significant memory savings and improved generation speed. InfiniGen \[[9](http://arxiv.org/abs/2406.19707)\] leverages the insight that only essential tokens are needed for future attention layers, enabling efficient prefetching and reducing fetch overhead. PyramidKV \[[13](http://arxiv.org/abs/2406.02069)\] dynamically adjusts cache size across layers, retaining more cache in lower layers and less in higher ones, which significantly reduces memory usage while maintaining performance. These methods collectively highlight the importance of intelligent KV cache management in improving both memory efficiency and inference throughput for LLMs.

### <a id='category-quantization-and-compression-methods'></a>Quantization and Compression Methods: 3 papers found.
Efficient KV cache management is a critical area of research in LLM inference, with multiple approaches focusing on reducing memory usage and improving throughput \[[2](http://arxiv.org/abs/2402.02750)\]. Quantization has emerged as a straightforward method to decrease the memory footprint of the KV cache, with studies showing that per-channel quantization of key caches and per-token quantization of value caches can significantly reduce memory consumption \[[2](http://arxiv.org/abs/2402.02750)\]. However, the challenge lies in maintaining generation quality while compressing the cache, as uniform quantization often introduces approximation errors that compound during autoregressive decoding \[[10](http://arxiv.org/abs/2403.05527)\]. Recent work has explored mixed-precision approaches, where evicted KV pairs are stored at lower precision while critical entries are retained at higher precision to preserve generation quality \[[7](http://arxiv.org/abs/2402.18096)\]. Additionally, advanced techniques like GEAR combine quantization with low-rank and sparse matrix approximations to achieve near-lossless compression, enabling substantial throughput improvements \[[10](http://arxiv.org/abs/2403.05527)\]. These methods highlight the ongoing efforts to balance memory efficiency with performance in KV cache management.

### <a id='category-attention-mechanism-optimization'></a>Attention Mechanism Optimization: 2 papers found.
Attention mechanism optimization has been a focal point in improving the efficiency and performance of large language models (LLMs) in streaming and inference settings. Researchers have identified key challenges such as memory consumption during decoding due to caching of Key and Value (KV) states and the inability of LLMs to generalize to longer sequences than their training data \[[4](http://arxiv.org/abs/2309.17453)\]. To address these issues, window attention was proposed, where only recent KV states are cached; however, this approach fails when the text length exceeds the cache size, leading to the phenomenon of attention sink, where initial tokens with strong attention scores hinder performance \[[4](http://arxiv.org/abs/2309.17453)\]. To mitigate this, StreamingLLM was introduced, enabling LLMs to generalize to infinite sequence lengths without fine-tuning by leveraging attention sink \[[4](http://arxiv.org/abs/2309.17453)\]. Additionally, Prompt Cache was developed to accelerate inference by reusing attention states across prompts with overlapping text segments, significantly reducing latency for longer prompts \[[11](http://arxiv.org/abs/2311.04934)\]. These approaches highlight the importance of optimizing attention mechanisms to enhance both the efficiency and effectiveness of LLM deployment in real-world applications.
