## Related Works

Deploying large language models (LLMs) on edge devices has been a focal point of recent research due to the increasing demand for privacy-preserving, low-latency AI services \[[1](https://www.semanticscholar.org/paper/007e7d6cb64a7dfcdcad9fc6f4f0ba69fdc88203)\]. Traditional cloud-based deployments suffer from high latency, bandwidth costs, and privacy concerns \[[1](https://www.semanticscholar.org/paper/007e7d6cb64a7dfcdcad9fc6f4f0ba69fdc88203)\]. To address these challenges, several approaches have been proposed, including model compression, collaborative edge computing, and efficient inference techniques.

Model quantization has emerged as a key technique for reducing memory footprint and computational overhead, enabling efficient LLM inference on resource-constrained devices \[[20](http://arxiv.org/abs/2211.10438)\]. SmoothQuant, for instance, enables 8-bit weight and 8-bit activation quantization without significant accuracy loss, achieving up to 1.56x speedup and 2x memory reduction \[[20](http://arxiv.org/abs/2211.10438)\]. Similarly, AWQ (Activation-aware Weight Quantization) identifies and protects salient weights based on activation distribution, reducing model size while preserving performance \[[3](http://arxiv.org/abs/2306.00978)\]. These methods, however, often rely on dequantization processes that can be computationally intensive \[[8](http://arxiv.org/abs/2206.09557)\].

Collaborative edge computing has also been explored to distribute LLM inference across edge devices and cloud servers, improving efficiency without accuracy loss \[[1](https://www.semanticscholar.org/paper/007e7d6cb64a7dfcdcad9fc6f4f0ba69fdc88203)\]. EdgeShard partitions computation-intensive LLMs into shards and distributes them across heterogeneous devices, achieving up to 50% latency reduction and 2× throughput improvement \[[1](https://www.semanticscholar.org/paper/007e7d6cb64a7dfcdcad9fc6f4f0ba69fdc88203)\]. Galaxy, another collaborative edge AI system, introduces hybrid model parallelism and tile-based communication-computation overlapping to reduce inference latency \[[6](http://arxiv.org/abs/2405.17245)\]. These approaches demonstrate the potential of distributed inference but often require complex coordination and resource management.

Efficient memory management is another critical area for LLM deployment on edge devices. PagedAttention, inspired by virtual memory techniques, enables near-zero waste in KV cache memory and flexible sharing across requests \[[2](http://arxiv.org/abs/2309.06180)\]. TPI-LLM further optimizes memory usage by introducing a sliding window memory scheduler and overlapping disk I/O latency with computation \[[11](http://arxiv.org/abs/2410.00531)\]. These techniques are essential for managing the dynamic and large memory requirements of LLM inference on edge platforms.

Hardware-software co-design has also played a crucial role in accelerating LLM inference.
