## Related Works

Representation learning has become a cornerstone in modern recommender systems, enabling efficient and effective user-item matching \[[1](http://arxiv.org/abs/1905.08108)\]. Early methods relied on matrix factorization to learn low-dimensional embeddings, but recent advances have shifted toward deep learning-based approaches that better capture complex interactions \[[2](http://arxiv.org/abs/2002.02126)\]. Among these, graph neural networks (GNNs) have emerged as a powerful tool for modeling user-item interactions through graph structures \[[3](http://arxiv.org/abs/1706.02216)\]. However, GNNs often suffer from over-smoothing and scalability issues due to recursive message propagation \[[10](http://arxiv.org/abs/2303.08537)\]. To address these limitations, researchers have proposed simpler variants such as LightGCN, which focuses on linear neighborhood aggregation and avoids unnecessary nonlinear operations \[[2](http://arxiv.org/abs/2002.02126)\]. This simplification leads to better performance and easier training \[[2](http://arxiv.org/abs/2002.02126)\].

In addition to GNNs, contrastive learning has been explored to enhance representation quality by leveraging self-supervised tasks \[[13](http://arxiv.org/abs/2202.06200)\]. For instance, Neighborhood-enriched Contrastive Learning (NCL) incorporates structural and semantic neighbors into contrastive pairs, improving performance on sparse data \[[13](http://arxiv.org/abs/2202.06200)\]. Similarly, LightGCL introduces a novel contrastive learning paradigm using singular value decomposition for structural refinement, achieving robustness against data sparsity \[[20](http://arxiv.org/abs/2302.08191)\]. These methods highlight the importance of preserving semantic relationships while mitigating noise in the graph structure \[[13](http://arxiv.org/abs/2202.06200)\]\[[20](http://arxiv.org/abs/2302.08191)\].

Another key area of research is the use of binary representations for efficient inference in recommendation systems \[[15](http://arxiv.org/abs/1906.01829)\]. Binarized collaborative filtering aims to reduce memory and computational overhead by converting embeddings into compact binary codes. However, this process often leads to information loss, which degrades performance \[[15](http://arxiv.org/abs/1906.01829)\]. To address this, the paper introduces BiGeaR++, which explicitly mitigates information loss during binarization through fine-grained inference distillation and effective embedding sample synthesis \[[1](http://arxiv.org/abs/1905.08108)\]. This approach improves performance by up to 10% compared to its predecessor BiGeaR \[[1](http://arxiv.org/abs/1905.08108)\].

Furthermore, graph embedding methods such as LINE and GraphSAGE have been widely used for learning node representations in large-scale networks \[[4](http://arxiv.org/abs/1503.03578)\]\[[3](http://arxiv.org/abs/1706.02216)\]. LINE preserves both local and global structures by optimizing an objective function that captures edge relationships \[[4](http://arxiv.org/abs/1503.03578)\]. GraphSAGE, on the other hand, generates embeddings for unseen nodes by sampling and aggregating features from local neighborhoods \[[3](http://arxiv.org/abs/1706.02216)\]. These methods provide a foundation for learning robust and scalable representations in recommendation systems \[[3](http://arxiv.org/abs/1706.02216)\]\[[4](http://arxiv.org/abs/1503.03578)\].
