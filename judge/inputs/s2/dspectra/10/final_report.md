## Related Works

Multi-token prediction (MTP) has emerged as an alternative to the traditional next-token prediction (NTP) objective in training large language models (LLMs). While NTP focuses on predicting one token at a time, MTP extends this by predicting multiple future tokens simultaneously, often using multiple independent output heads that share a common model trunk \[[1](http://arxiv.org/abs/2404.19737)\]. This approach has been shown to improve downstream performance, inference speed, and training efficiency, particularly for large models \[[1](http://arxiv.org/abs/2404.19737)\]. However, smaller language models (SLMs) face challenges in effectively leveraging the MTP objective \[[1](http://arxiv.org/abs/2404.19737)\]. To address this, we propose a curriculum learning strategy for MTP training, exploring two variants: a forward curriculum, which gradually increases the complexity of the pre-training objective from NTP to MTP, and a reverse curriculum, which does the opposite \[[1](http://arxiv.org/abs/2404.19737)\].

Curriculum learning has been widely explored in the context of neural networks, where it aims to improve learning efficiency by structuring the training data in an order that aligns with the model's learning capacity \[[12](http://arxiv.org/abs/1704.03003)\]. This concept has been applied to various tasks, including natural language understanding \[[7](https://www.semanticscholar.org/paper/2d315208dd88eed245dc4ae1ae398af75aa291f8)\] and neural machine translation \[[9](http://arxiv.org/abs/1903.09848)\]. For example, in the case of neural machine translation, curriculum learning has been shown to reduce training time and improve performance by gradually increasing the difficulty of the training examples \[[9](http://arxiv.org/abs/1903.09848)\]. Similarly, in the context of language models, curriculum learning has been used to improve the performance of smaller models by introducing tasks in an order that matches their capacity \[[1](http://arxiv.org/abs/2404.19737)\].

In the context of MTP, the forward curriculum has been shown to enable SLMs to better leverage the MTP objective during pre-training, improving downstream NTP performance and generative output quality while retaining the benefits of self-speculative decoding \[[1](http://arxiv.org/abs/2404.19737)\]. In contrast, the reverse curriculum, which starts with MTP and gradually reduces the number of tokens predicted, achieves stronger NTP performance and output quality but fails to provide any self-speculative decoding benefits \[[1](http://arxiv.org/abs/2404.19737)\]. This suggests that the order in which the model is trained can significantly impact its ability to generalize and perform well on downstream tasks.

### <a id='category-multi-token-prediction-(mtp)-frameworks'></a>Multi-token Prediction (MTP) Frameworks: 3 papers found.

Unlike NTP, which focuses on predicting one token at a time, MTP trains models to predict multiple future tokens simultaneously using independent output heads atop a shared model trunk \[[1](http://arxiv.org/abs/2404.19737)\]. This approach has demonstrated significant gains, particularly in generative tasks like coding, where models trained with MTP outperform NTP baselines by several percentage points \[[1](http://arxiv.org/abs/2404.19737)\]. To address this, curriculum learning strategies have been proposed, including forward and reverse curricula that gradually adjust the complexity of the pre-training objective \[[1](http://arxiv.org/abs/2404.19737)\]. These strategies aim to balance the benefits of MTP with the limitations of SLMs, offering a path toward more effective and efficient pre-training methods \[[1](http://arxiv.org/abs/2404.19737)\].

### <a id='category-curriculum-learning-strategies'></a>Curriculum Learning Strategies: 4 papers found.
Curriculum learning strategies have gained significant attention in natural language understanding (NLU) and neural machine translation (NMT) tasks, as they aim to improve model performance by structuring training data in a way that aligns with the learning process of human learners \[[7](https://www.semanticscholar.org/paper/2d315208dd88eed245dc4ae1ae398af75aa291f8)\]. These strategies typically involve organizing training examples from easy to difficult, allowing models to gradually build up their capabilities \[[9](http://arxiv.org/abs/1903.09848)\]. For instance, in NLU tasks, curriculum learning has been shown to enhance performance without requiring manual architecture design or external data \[[7](https://www.semanticscholar.org/paper/2d315208dd88eed245dc4ae1ae398af75aa291f8)\]. Similarly, in NMT, curriculum learning frameworks have been proposed to reduce training time and improve performance by filtering training samples based on estimated difficulty and model competence \[[9](http://arxiv.org/abs/1903.09848)\]. This approach helps avoid local optima and accelerates convergence \[[9](http://arxiv.org/abs/1903.09848)\]. Furthermore, curriculum learning has also been applied to complex reasoning tasks, where it enables models to learn from correct demonstrations and establish a step-wise curriculum that provides precise error signals \[[10](http://arxiv.org/abs/2402.05808)\]. These methods demonstrate the versatility of curriculum learning in enhancing both efficiency and effectiveness across different NLP tasks.

The current approach to training them consists of maximizing the likelihood of each token in the sequence given the current (recurrent) state and the previous token.
