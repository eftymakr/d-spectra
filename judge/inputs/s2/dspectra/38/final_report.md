## Related Works

Memory bandwidth regulation and cache partitioning have been extensively studied in the context of real-time systems to ensure predictable timing behavior \[[1](http://arxiv.org/abs/1809.05921)\]. These techniques are particularly important in multi-core environments where shared memory resources such as caches, interconnects, and DRAM can introduce significant contention and variability in execution times \[[1](http://arxiv.org/abs/1809.05921)\]. Early work focused on analyzing the worst-case response times of tasks under varying memory bandwidth allocations, highlighting the need for theoretical frameworks to reason about the worst-case behavior of real-time workloads \[[1](http://arxiv.org/abs/1809.05921)\]. This has led to the development of methods that reduce response time computation to a maximization problem over memory request assignments \[[1](http://arxiv.org/abs/1809.05921)\].

Cache partitioning has also been explored as a way to mitigate interference among real-time tasks \[[12](http://arxiv.org/abs/2310.02959)\]. Techniques such as cache set partitioning and memory bandwidth regulation are used to isolate resources and improve predictability \[[12](http://arxiv.org/abs/2310.02959)\]. For example, MemGuard provides a memory bandwidth reservation system that enables efficient performance isolation in multi-core platforms \[[5](https://www.semanticscholar.org/paper/bbebaeb1b00fdcde2aeb192543835d3ec1518f8d)\]. Similarly, the paper on per-bank bandwidth regulation for shared last-level caches demonstrates how regulating bandwidth on a per-bank basis can prevent unnecessary throttling and improve performance \[[7](http://arxiv.org/abs/2410.14003)\]. These approaches are essential for ensuring that real-time tasks are not impacted by cache bank contention or memory interference.

In addition to cache partitioning, memory bandwidth management has been studied in the context of real-time scheduling for heterogeneous multiprocessors \[[2](http://arxiv.org/abs/1607.07763)\]. 	Document 1: [Snippet]: «We propose three novel mathematical optimization formulations that solve the same two-type heterogeneous multiprocessor scheduling problem for a real-time taskset with hard constraints. Our formulations are based on a global scheduling scheme and a fluid model. The first formulation is a mixed-integer nonlinear program, since the scheduling problem is intuitively considered as an assignment problem. However, by changing the scheduling problem to first determine a task workload partition and then to find the execution order of all tasks, the computation time can be significantly reduced. Specifically, the workload partitioning problem can be formulated as a continuous nonlinear program for a system with continuous operating frequency, and as a continuous linear program for a practical system with a discrete speed level set. The latter problem can therefore be solved by an interior point method to any accuracy in polynomial time. The task ordering problem can be solved by an algorithm with a complexity that is linear in the total number of tasks. The work is evaluated against existing global energy/feasibility optimal workload allocation formulations. The results illustrate that our algorithms are both feasibility optimal and energy optimal for both implicit and constrained deadline tasksets. Specifically, our algorithm can achieve up to 40% energy saving for some simulated tasksets with constrained deadlines. The benefit of our formulation compared with existing work is that our algorithms can solve a more general class of scheduling problems due to incorporating a scheduling dynamic model in the formulations and allowing for a time-varying speed profile.»
