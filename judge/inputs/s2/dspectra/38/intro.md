## Related Works

Memory bandwidth regulation and cache partitioning have been extensively studied in the context of real-time systems to ensure predictable timing behavior \[[1](http://arxiv.org/abs/1809.05921)\]. These techniques are particularly important in multi-core environments where shared memory resources such as caches, interconnects, and DRAM can introduce significant contention and variability in execution times \[[1](http://arxiv.org/abs/1809.05921)\]. Early work focused on analyzing the worst-case response times of tasks under varying memory bandwidth allocations, highlighting the need for theoretical frameworks to reason about the worst-case behavior of real-time workloads \[[1](http://arxiv.org/abs/1809.05921)\]. This has led to the development of methods that reduce response time computation to a maximization problem over memory request assignments \[[1](http://arxiv.org/abs/1809.05921)\].

Cache partitioning has also been explored as a way to mitigate interference among real-time tasks \[[12](http://arxiv.org/abs/2310.02959)\]. Techniques such as cache set partitioning and memory bandwidth regulation are used to isolate resources and improve predictability \[[12](http://arxiv.org/abs/2310.02959)\]. For example, MemGuard provides a memory bandwidth reservation system that enables efficient performance isolation in multi-core platforms \[[5](https://www.semanticscholar.org/paper/bbebaeb1b00fdcde2aeb192543835d3ec1518f8d)\]. Similarly, the paper on per-bank bandwidth regulation for shared last-level caches demonstrates how regulating bandwidth on a per-bank basis can prevent unnecessary throttling and improve performance \[[7](http://arxiv.org/abs/2410.14003)\]. These approaches are essential for ensuring that real-time tasks are not impacted by cache bank contention or memory interference.

In addition to cache partitioning, memory bandwidth management has been studied in the context of real-time scheduling for heterogeneous multiprocessors \[[2](http://arxiv.org/abs/1607.07763)\]. The work proposes three novel mathematical optimization formulations to solve the scheduling problem, incorporating a global scheduling scheme and a fluid model. The formulations allow for time-varying speed profiles and enable energy-efficient scheduling \[[2](http://arxiv.org/abs/1607.07763)\]. This aligns with the goal of the current paper, which also emphasizes the importance of co-allocating tasks and resources to cores to ensure predictable execution times \[[1](http://arxiv.org/abs/1809.05921)\].

Another important aspect of memory interference is the analysis of worst-case memory latency in COTS-based multi-core systems \[[9](https://www.semanticscholar.org/paper/afca4afaaaa543a1da02b266e9b2ac46eb94793b)\]. This work models the major resources in the DRAM system, including banks, buses, and the memory controller, to provide tight upper bounds on memory interference delay \[[9](https://www.semanticscholar.org/paper/afca4afaaaa543a1da02b266e9b2ac46eb94793b)\]. The results show that partitioning DRAM banks can significantly reduce memory interference, which is a critical consideration for real-time systems \[[9](https://www.semanticscholar.org/paper/afca4afaaaa543a1da02b266e9b2ac46eb94793b)\]. This is particularly relevant for the current paper, which evaluates its proposed method on a commercial platform with fine-grained resource partitioning \[[1](http://arxiv.org/abs/1809.05921)\].
