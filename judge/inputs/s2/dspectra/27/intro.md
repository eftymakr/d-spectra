## Related Works

Recent advancements in information retrieval have focused on improving the efficiency and effectiveness of document and table retrieval systems. Traditional approaches rely on a pipeline consisting of representation, indexing, and search stages, where each stage is typically handled by separate components \[[3](http://arxiv.org/abs/2305.15115)\]. This approach, while effective, suffers from error accumulation during the indexing and search phases, which can degrade overall performance \[[1](http://arxiv.org/abs/2206.10128)\]. Additionally, insufficient interaction between queries and indexed documents or tables hinders semantic alignment and limits accuracy improvements \[[1](http://arxiv.org/abs/2206.10128)\].

Several works have explored alternative paradigms for retrieval. The Differentiable Search Index (DSI) framework \[[2](http://arxiv.org/abs/2202.06991)\] proposes a unified approach by encoding all information about the corpus into a single neural model, allowing direct mapping from queries to document identifiers. This eliminates the need for separate indexing and retrieval stages, thereby reducing error propagation. However, DSI models face challenges in handling dynamic updates and catastrophic forgetting when new documents are added \[[11](http://arxiv.org/abs/2212.09744)\]. To address this, IncDSI \[[16](http://arxiv.org/abs/2307.10323)\] introduces an incremental indexing strategy that enables real-time updates without retraining the entire model, significantly improving efficiency and reducing forgetting.

In the context of table retrieval, prior methods often use dense vector search pipelines, which involve representing tables and queries as vectors and performing similarity-based retrieval \[[14](http://arxiv.org/abs/1802.06159)\]. While these methods achieve good accuracy, they are limited by the lack of deep query-table interaction and error accumulation during the indexing phase \[[1](http://arxiv.org/abs/2206.10128)\]. The proposed Birdie framework addresses these limitations by leveraging a differentiable search index, which integrates indexing and search into a single encoder-decoder model \[[1](http://arxiv.org/abs/2206.10128)\]. This approach allows for direct generation of table identifiers from queries, eliminating the need for intermediate indexing steps.

To enhance the semantic alignment between queries and tables, Birdie introduces a prefix-aware identifier assignment and uses a large language model to generate synthetic queries for each table \[[1](http://arxiv.org/abs/2206.10128)\]. These synthetic queries are then encoded into the model parameters, enabling deep interactions between queries and tables. This method significantly improves accuracy and reduces error propagation compared to traditional dense retrieval approaches.

In addition to improving accuracy, Birdie also addresses the challenge of continual indexing for dynamic table repositories. The framework introduces an index update strategy based on parameter isolation, which mitigates catastrophic forgetting by isolating the parameters associated with newly indexed tables \[[1](http://arxiv.org/abs/2206.10128)\]. This approach enables real-time updates without retraining the entire model, making it suitable for large-scale and evolving datasets.
