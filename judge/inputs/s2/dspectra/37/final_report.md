## Related Works

Vision Transformers (ViTs) have gained significant traction in computer vision due to their ability to capture global context effectively \[[1](http://arxiv.org/abs/2211.08110)\]. However, deploying ViTs on resource-constrained hardware remains challenging due to their high computational and memory demands \[[1](http://arxiv.org/abs/2211.08110)\]. Prior work has focused on optimizing ViT performance through various techniques, including quantization, pruning, and architectural modifications \[[2](http://arxiv.org/abs/2208.05163)\]\[[3](http://arxiv.org/abs/2210.09573)\]\[[4](http://arxiv.org/abs/2302.09108)\].

Several studies have explored quantization strategies to reduce the computational overhead of ViTs. For example, Auto-ViT-Acc introduces a mixed-scheme quantization approach that improves accuracy while maintaining high inference speeds on FPGAs \[[2](http://arxiv.org/abs/2208.05163)\]. Similarly, VAQF proposes a fully automatic framework for low-bit ViT acceleration, enabling real-time execution on FPGAs by optimizing quantization precision and accelerator settings \[[10](http://arxiv.org/abs/2201.06618)\]. These approaches demonstrate the potential of quantization in reducing the computational burden of ViT models.

Token pruning has also been widely investigated as a means to improve hardware efficiency. HeatViT introduces an adaptive token pruning framework that dynamically identifies and consolidates non-informative tokens, achieving significant computation reduction without sacrificing accuracy \[[1](http://arxiv.org/abs/2211.08110)\]. Similarly, EViT reorganizes image tokens during inference to reduce redundant computations, improving both speed and accuracy \[[11](http://arxiv.org/abs/2202.07800)\]. These methods highlight the importance of efficient token management in accelerating ViT inference.

Hardware-specific optimizations have been another key focus in ViT acceleration. ViTA proposes a configurable FPGA accelerator that minimizes off-chip memory accesses, achieving high hardware utilization efficiency and reasonable frame rates for edge applications \[[4](http://arxiv.org/abs/2302.09108)\]. ViTCoD further advances this by integrating algorithm and accelerator co-design, achieving speedups of up to 235.3× over general computing platforms \[[3](http://arxiv.org/abs/2210.09573)\]. These accelerators demonstrate the potential of custom hardware solutions in improving ViT performance.

Recent work has also explored hybrid architectures to enhance both accuracy and efficiency. EfficientViT combines convolutional and transformer layers, improving hardware efficiency while maintaining high accuracy \[[9](http://arxiv.org/abs/2403.20230)\]. The proposed FPGA-based accelerator for EfficientViT further exploits its hybrid architecture to achieve high throughput and energy efficiency \[[9](http://arxiv.org/abs/2403.20230)\]. These hybrid models represent a promising direction for future ViT designs.

Moreover, dynamic token configuration has been introduced to adaptively adjust the number of tokens based on input characteristics. Dynamic Transformers automatically configure the number of tokens for each input image, reducing computational costs while maintaining accuracy \[[13](http://arxiv.org/abs/2105.15075)\]. This approach aligns with the goal of achieving a better trade-off between accuracy and speed.

### <a id='category-fpga-based-accelerators-for-vit'></a>FPGA-Based Accelerators for ViT: 4 papers found.
FPGA-based accelerators for Vision Transformers (ViTs) have emerged as a critical area of research to address the computational and memory challenges of deploying ViTs on edge devices \[[9](http://arxiv.org/abs/2403.20230)\]. Existing accelerators often struggle with the unique architecture of ViTs, particularly due to their reliance on complex operations like Softmax and LayerNorm, which are sensitive to precision and difficult to map efficiently onto hardware \[[14](http://arxiv.org/abs/2402.09709)\]. To overcome these limitations, recent works have focused on optimizing hardware designs to support both lightweight convolutions and attention mechanisms, enhancing hardware utilization and reducing off-chip memory access \[[2](http://arxiv.org/abs/2208.05163)\]. For instance, EfficientViT, a state-of-the-art hybrid Convolution-Transformer model, has been targeted by FPGA accelerators that employ reconfigurable architectures and time-multiplexed dataflows to improve throughput and energy efficiency \[[9](http://arxiv.org/abs/2403.20230)\]. Additionally, quantization techniques have been integrated into FPGA-based ViT acceleration frameworks to balance accuracy and performance, with approaches like VAQF enabling automatic quantization strategies that meet target frame rates while maintaining model accuracy \[[10](http://arxiv.org/abs/2201.06618)\]. Furthermore, innovations such as the ME-ViT accelerator have introduced memory-efficient designs that minimize off-chip traffic by implementing a single-load policy and custom hardware for complex operations, significantly improving throughput and power efficiency \[[14](http://arxiv.org/abs/2402.09709)\]. These advancements highlight the growing trend of leveraging FPGA platforms to achieve real-time ViT inference with high accuracy and efficiency \[[2](http://arxiv.org/abs/2208.05163)\]\[[9](http://arxiv.org/abs/2403.20230)\]\[[10](http://arxiv.org/abs/2201.06618)\]\[[14](http://arxiv.org/abs/2402.09709)\].

### <a id='category-dynamic-token-configuration-methods'></a>Dynamic Token Configuration Methods: 2 papers found.
Dynamic Token Configuration Methods have emerged as a critical area of research in Vision Transformers (ViT), aiming to balance computational efficiency with model accuracy. Traditional ViTs use a fixed number of patches (e.g., 16x16 or 14x14) to represent images, which can lead to unnecessary computational overhead for "easy" images that can be accurately predicted with fewer tokens \[[13](http://arxiv.org/abs/2105.15075)\]. To address this, researchers have proposed dynamic token configuration approaches that adaptively adjust the number of tokens based on the complexity of the input. For instance, the Dynamic Transformer introduces a cascading structure of Transformers with increasing token counts, allowing the model to terminate inference early when a sufficiently confident prediction is achieved \[[13](http://arxiv.org/abs/2105.15075)\]. Similarly, the Coarse-to-Fine Vision Transformer (CF-ViT) employs a two-stage inference process, starting with coarse-grained patches and refining the representation if initial predictions are insufficient \[[16](http://arxiv.org/abs/2203.03821)\]. These methods leverage the observation that most images can be effectively recognized with a small number of tokens, while only a subset requires finer-grained representations \[[13](http://arxiv.org/abs/2105.15075)\]. To reduce redundant computations, both approaches incorporate mechanisms such as feature reuse and relationship reuse across different components \[[13](http://arxiv.org/abs/2105.15075)\]. These strategies not only improve computational efficiency but also maintain or enhance model performance, as demonstrated through extensive empirical evaluations on datasets like ImageNet and CIFAR \[[13](http://arxiv.org/abs/2105.15075)\]\[[16](http://arxiv.org/abs/2203.03821)\].
