## Related Works

Deploying large language models (LLMs) on edge devices presents significant challenges due to the limited storage, computational power, and energy resources available on such platforms \[[22](https://www.semanticscholar.org/paper/ec93fc7ec82c65a7bf7213488327d391014539ed)\]. Prior work has explored various strategies to address these challenges, including model compression, efficient inference techniques, and hardware-software co-design. For instance, EIE \[[3](http://arxiv.org/abs/1602.01528)\] introduces an energy-efficient inference engine that operates on compressed deep neural networks, achieving up to 189x speedup compared to CPU implementations. Similarly, Deep Compression \[[24](http://arxiv.org/abs/1510.00149)\] employs pruning, trained quantization, and Huffman coding to reduce model size by 35x to 49x without accuracy loss, enabling deployment on resource-constrained devices. These methods focus on reducing model size and computational demand, which is critical for edge deployment \[[24](http://arxiv.org/abs/1510.00149)\].

Efficient inference on edge devices has also been addressed through quantization techniques. For example, SmoothQuant \[[26](http://arxiv.org/abs/2211.10438)\] enables 8-bit weight and activation quantization for LLMs without accuracy loss, achieving up to 1.56x speedup and 2x memory reduction. This is particularly relevant for edge deployment, where memory and computational resources are limited \[[26](http://arxiv.org/abs/2211.10438)\]. Additionally, AWQ \[[21](http://arxiv.org/abs/2306.00978)\] introduces activation-aware weight quantization, reducing model size by 4x while maintaining performance. These quantization methods are essential for enabling efficient LLM inference on edge devices with limited hardware capabilities \[[21](http://arxiv.org/abs/2306.00978)\].

Edge computing has also been explored in the context of deep learning and neural networks. For example, Eyeriss \[[19](https://www.semanticscholar.org/paper/5ec594e9f5ca4b629be28625cd78c882514ea3be)\] presents a spatial architecture for energy-efficient dataflow in convolutional neural networks, reducing energy consumption in both convolutional and fully-connected layers. This work highlights the importance of optimizing data movement and computation for energy efficiency on edge devices \[[19](https://www.semanticscholar.org/paper/5ec594e9f5ca4b629be28625cd78c882514ea3be)\]. Similarly, DNNBuilder \[[14](https://www.semanticscholar.org/paper/a821a00c54749a69a9d9fe0a7411de590d247715)\] automates the design of high-performance DNN hardware accelerators for FPGAs, achieving up to 5.15x faster inference compared to existing solutions. These approaches demonstrate the potential of specialized hardware for accelerating deep learning inference on edge devices \[[14](https://www.semanticscholar.org/paper/a821a00c54749a69a9d9fe0a7411de590d247715)\].

Collaborative edge computing has also been proposed to enhance the efficiency of LLM deployment. EdgeShard \[[4](https://www.semanticscholar.org/paper/007e7d6cb64a7dfcdcad9fc6f4f0ba69fdc88203)\] partitions LLM computations across edge devices and cloud servers, achieving up to 50% latency reduction and 2× throughput improvement. This approach leverages distributed computing to overcome the limitations of individual edge devices \[[4](https://www.semanticscholar.org/paper/007e7d6cb64a7dfcdcad9fc6f4f0ba69fdc88203)\].
