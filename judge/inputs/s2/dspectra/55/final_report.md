## Related Works

Conversational Recommender Systems (CRSs) have emerged as a promising approach to address the limitations of traditional recommendation systems by enabling multi-turn interactions to better capture user preferences \[[1](http://arxiv.org/abs/2004.00646)\]. Unlike static recommendation models that rely solely on historical data, CRSs engage users in dialogues to elicit preferences dynamically \[[2](http://arxiv.org/abs/1806.03277)\]. This interactive approach allows for more accurate and personalized recommendations, but it also introduces challenges such as maintaining a natural conversation flow and efficiently managing user feedback \[[3](https://www.semanticscholar.org/paper/3ae5bef6b0c8317603a2deab2527383580904fd8)\].

Several studies have explored the integration of dialog systems and recommendation systems. For instance, \[[4](http://arxiv.org/abs/2101.09459)\] proposed a deep reinforcement learning framework that combines both to build a personalized conversational recommendation agent. This agent uses a belief tracker to analyze user utterances and update the user query representation, which is then used to make recommendations \[[4](http://arxiv.org/abs/2101.09459)\]. Similarly, \[[5](http://arxiv.org/abs/2002.09102)\] introduced a framework named Estimation-Action-Reflection (EAR) that divides the interaction into three stages: estimation of user preferences, action selection based on conversation history, and reflection to update the model when recommendations are rejected \[[5](http://arxiv.org/abs/2002.09102)\]. These approaches highlight the importance of dynamic interaction in CRSs.

To improve the effectiveness of conversational recommendation, \[[6](http://arxiv.org/abs/2007.04032)\] proposed a system that uses knowledge graphs to enhance both the recommendation and dialog components. By aligning semantic representations from word-level and entity-level knowledge graphs, the system improves the accuracy of recommendations and the informativeness of dialog responses \[[6](http://arxiv.org/abs/2007.04032)\]. Additionally, \[[7](http://arxiv.org/abs/1107.0029)\] introduced a unified conversational recommendation framework that integrates recommendation and dialog modules through knowledge-enhanced prompt learning, allowing for a more seamless interaction experience \[[7](http://arxiv.org/abs/1107.0029)\].

User simulation has also been widely studied as a means to evaluate CRSs without requiring real user participation. \[[8](http://arxiv.org/abs/2304.13874)\] developed a user simulator named ConvSim that generates realistic user feedback, enabling the evaluation of multi-turn conversational search systems \[[8](http://arxiv.org/abs/2304.13874)\]. Similarly, \[[9](http://arxiv.org/abs/2206.09363)\] proposed a user simulation toolkit called UserSimCRS, which allows for the automatic evaluation of CRSs by simulating dialogues based on a small set of manually annotated examples \[[9](http://arxiv.org/abs/2206.09363)\]. These tools are essential for benchmarking CRSs in controlled environments.

Moreover, \[[10](http://arxiv.org/abs/2006.08732)\] explored the use of simulated users to provide feedback during the recommendation process, which helps the system better understand user preferences through iterative interactions \[[10](http://arxiv.org/abs/2006.08732)\]. This aligns with the proposed GRSU model, which uses a simulated user to provide both coarse-grained and fine-grained feedback during multi-turn interactions \[[1](http://arxiv.org/abs/2004.00646)\].

### <a id='category-conversational-recommender-systems-overview'></a>Conversational Recommender Systems Overview: 2 papers found.
Conversational recommender systems (CRSs) have gained significant attention due to their ability to support dynamic, multi-turn interactions between users and the recommendation system, enabling more accurate preference elicitation compared to traditional one-shot approaches \[[1](http://arxiv.org/abs/2004.00646)\]. Unlike static models that rely solely on historical data and struggle to explain why a user prefers an item \[[4](http://arxiv.org/abs/2101.09459)\], CRSs leverage natural language interactions to explicitly capture user preferences, allowing for richer feedback mechanisms such as generative item scoring and attribute-based critiques \[[4](http://arxiv.org/abs/2101.09459)\]. This aligns with broader efforts in the field to improve the understanding of user intent and the generation of more personalized recommendations \[[1](http://arxiv.org/abs/2004.00646)\]. Additionally, the integration of dialogue understanding and generation, along with strategies for managing the exploitation-exploration trade-off, has been identified as critical for the development of effective CRSs \[[4](http://arxiv.org/abs/2101.09459)\]. These advancements are supported by progress in natural language processing and the increasing use of chatbots and voice assistants, which have created new opportunities for conversational interactions \[[1](http://arxiv.org/abs/2004.00646)\]. The evaluation of CRSs remains an active area of research, with challenges related to user simulation and the creation of realistic interaction scenarios \[[4](http://arxiv.org/abs/2101.09459)\]. Overall, the evolution of CRSs reflects a shift toward more interactive, explainable, and user-centric recommendation systems \[[1](http://arxiv.org/abs/2004.00646)\].

### <a id='category-integration-of-dialog-and-recommendation-systems'></a>Integration of Dialog and Recommendation Systems: 7 papers found.
The integration of dialog systems and recommender systems has been a focal point in recent research, aiming to enhance user experience by combining the strengths of both paradigms. Existing approaches often rely on either single-round adhoc search engines or traditional multi-round dialog systems, which typically ignore long-term user preferences \[[2](http://arxiv.org/abs/1806.03277)\]. To address these limitations, several studies propose unified frameworks that integrate dialog and recommendation components, such as the deep reinforcement learning framework that optimizes a per-session utility function by leveraging both past ratings and current conversational data \[[1](http://arxiv.org/abs/2004.00646)\]. Additionally, the SAUR paradigm enables systems to actively clarify user needs through targeted questioning, supported by architectures like the Multi-Memory Network (MMN) \[[3](https://www.semanticscholar.org/paper/3ae5bef6b0c8317603a2deab2527383580904fd8)\]. The EAR framework further advances this integration by addressing three key problems: question selection, recommendation timing, and adaptation to user feedback, using a three-stage process of estimation, action, and reflection \[[5](http://arxiv.org/abs/2002.09102)\]. Similarly, the ADAPTIVE PLACE ADVISOR demonstrates how conversational systems can unobtrusively gather long-term preferences during interactions, improving efficiency in item selection \[[7](http://arxiv.org/abs/1107.0029)\]. More recently, the UniCRS model introduces a knowledge-enhanced prompt learning approach to unify recommendation and conversation tasks, leveraging pre-trained language models and contextual information \[[9](http://arxiv.org/abs/2206.09363)\]. Meanwhile, the dynamic weighted graph-based RL method proposed in \[[14](http://arxiv.org/abs/2105.09710)\] systematically integrates conversation and recommendation components, enabling scalable and stable policy learning for conversational recommendation. These efforts collectively highlight the growing interest in developing unified, adaptive, and efficient conversational recommendation systems that balance user engagement with recommendation accuracy.
