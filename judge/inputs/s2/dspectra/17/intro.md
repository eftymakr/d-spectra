## Related Works

Semi-supervised learning (SSL) has emerged as a powerful paradigm for improving model performance by leveraging unlabeled data when labeled data is scarce \[[1](http://arxiv.org/abs/2109.00650)\]. Traditional SSL methods assume that both labeled and unlabeled data share the same class distribution \[[2](http://arxiv.org/abs/2007.08844)\], but this assumption is often violated in practice, as unlabeled data may contain out-of-distribution (OOD) samples, or outliers, which are not present in the labeled set \[[3](http://arxiv.org/abs/2205.07246)\]. These outliers are typically treated as noise, leading to significant performance degradation \[[4](http://arxiv.org/abs/2001.07685)\]. Several recent works have addressed this challenge by focusing on open-set SSL, where the goal is to classify inliers and detect outliers simultaneously \[[5](http://arxiv.org/abs/2007.11330)\].

FixMatch \[[6](http://arxiv.org/abs/2107.08943)\] is one of the most influential SSL methods, which combines pseudo-labeling with consistency regularization. It generates pseudo-labels for unlabeled data based on high-confidence predictions and trains the model to maintain consistency between strongly and weakly augmented versions of the same image. However, FixMatch assumes that all unlabeled data is from the same distribution as the labeled data, which is not always the case in open-set scenarios \[[7](http://arxiv.org/abs/2105.14148)\].

To address the limitations of FixMatch and other SSL methods in open-set settings, several approaches have been proposed. For instance, FlexMatch \[[8](http://arxiv.org/abs/2102.09559)\] introduces curriculum pseudo-labeling to adaptively adjust thresholds for different classes during training, improving performance when labeled data is scarce. Similarly, FreeMatch \[[9](http://arxiv.org/abs/2308.13168)\] proposes a self-adaptive thresholding mechanism to dynamically adjust confidence thresholds based on the model's learning progress. These methods, however, still struggle with handling OOD samples effectively, as they often filter out outliers during training \[[10](http://arxiv.org/abs/2201.06247)\].

OpenMatch \[[11](https://www.semanticscholar.org/paper/f3df804a7eef204b0c4fc4b81166dec9b4abc073)\] extends SSL to handle open-set scenarios by integrating novelty detection with consistency regularization. It uses one-vs-all (OVA) classifiers to detect outliers and applies soft-consistency regularization to improve outlier detection. Despite these advances, existing methods often rely on binary classification for outlier detection, which can be limited in scalability and uncertainty quantification \[[12](http://arxiv.org/abs/1606.04586)\].

To better handle OOD samples, contrastive regularization has been introduced to improve the efficiency and accuracy of SSL methods \[[13](http://arxiv.org/abs/2303.11066)\]. Contrastive regularization encourages features of confident pseudo-labels to cluster together while pushing apart features from different clusters, enabling more effective propagation of labeling information \[[14](http://arxiv.org/abs/2101.06329)\]. This approach has shown promising results in open-set SSL, particularly when unlabeled data contains OOD samples \[[15](http://arxiv.org/abs/2311.10572)\].
