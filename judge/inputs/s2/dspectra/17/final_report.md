## Related Works

Semi-supervised learning (SSL) has emerged as a powerful paradigm for improving model performance by leveraging unlabeled data when labeled data is scarce \[[1](http://arxiv.org/abs/2109.00650)\]. Traditional SSL methods assume that both labeled and unlabeled data share the same class distribution \[[2](http://arxiv.org/abs/2007.08844)\], but this assumption is often violated in practice, as unlabeled data may contain out-of-distribution (OOD) samples, or outliers, which are not present in the labeled set \[[3](http://arxiv.org/abs/2205.07246)\]. These outliers are typically treated as noise, leading to significant performance degradation \[[4](http://arxiv.org/abs/2001.07685)\]. Several recent works have addressed this challenge by focusing on open-set SSL, where the goal is to classify inliers and detect outliers simultaneously \[[5](http://arxiv.org/abs/2007.11330)\].

FixMatch \[[6](http://arxiv.org/abs/2107.08943)\] is one of the most influential SSL methods, which combines pseudo-labeling with consistency regularization. It generates pseudo-labels for unlabeled data based on high-confidence predictions and trains the model to maintain consistency between strongly and weakly augmented versions of the same image. However, FixMatch assumes that all unlabeled data is from the same distribution as the labeled data, which is not always the case in open-set scenarios \[[7](http://arxiv.org/abs/2105.14148)\].

To address the limitations of FixMatch and other SSL methods in open-set settings, several approaches have been proposed. For instance, FlexMatch \[[8](http://arxiv.org/abs/2102.09559)\] introduces curriculum pseudo-labeling to adaptively adjust thresholds for different classes during training, improving performance when labeled data is scarce. Similarly, FreeMatch \[[9](http://arxiv.org/abs/2308.13168)\] proposes a self-adaptive thresholding mechanism to dynamically adjust confidence thresholds based on the model's learning progress. These methods, however, still struggle with handling OOD samples effectively, as they often filter out outliers during training \[[10](http://arxiv.org/abs/2201.06247)\].

OpenMatch \[[11](https://www.semanticscholar.org/paper/f3df804a7eef204b0c4fc4b81166dec9b4abc073)\] extends SSL to handle open-set scenarios by integrating novelty detection with consistency regularization. It uses one-vs-all (OVA) classifiers to detect outliers and applies soft-consistency regularization to improve outlier detection. Despite these advances, existing methods often rely on binary classification for outlier detection, which can be limited in scalability and uncertainty quantification \[[12](http://arxiv.org/abs/1606.04586)\].

To better handle OOD samples, contrastive regularization has been introduced to improve the efficiency and accuracy of SSL methods \[[13](http://arxiv.org/abs/2303.11066)\]. Contrastive regularization encourages features of confident pseudo-labels to cluster together while pushing apart features from different clusters, enabling more effective propagation of labeling information \[[14](http://arxiv.org/abs/2101.06329)\]. This approach has shown promising results in open-set SSL, particularly when unlabeled data contains OOD samples \[[15](http://arxiv.org/abs/2311.10572)\].

### <a id='category-open-set-ssl-frameworks'></a>Open-Set SSL Frameworks: 10 papers found.
Open-set semi-supervised learning (Open-set SSL) addresses the challenge where unlabeled data may contain out-of-distribution (OOD) samples not present in the labeled set, which can severely degrade model performance \[[1](http://arxiv.org/abs/2109.00650)\]. Existing methods often rely on detecting OOD samples through binary classifiers or separate OOD detection modules, but these approaches struggle with scalability and uncertainty distinction \[[2](http://arxiv.org/abs/2007.08844)\]. For instance, some methods assume that labeled and unlabeled data share the same class distribution, which is often violated in real-world scenarios \[[3](http://arxiv.org/abs/2205.07246)\]. To mitigate this, recent frameworks like OpenCoS utilize self-supervised contrastive learning to identify OOD samples and apply one-hot pseudo-labels for inlier data \[[4](http://arxiv.org/abs/2001.07685)\]. Similarly, OpenMatch integrates novelty detection with FixMatch to reject outliers while improving inlier classification \[[5](http://arxiv.org/abs/2007.11330)\]. Other approaches, such as IOMatch, propose joint utilization of inliers and outliers by employing multi-binary classifiers and treating outliers as a single class \[[6](http://arxiv.org/abs/2107.08943)\]. These methods highlight the need for robust frameworks that can handle OOD samples effectively while maintaining performance on in-distribution data \[[7](http://arxiv.org/abs/2105.14148)\]. Additionally, frameworks like ANEDL introduce evidential deep learning to quantify uncertainty and adapt to unlabeled data containing both inliers and outliers \[[8](http://arxiv.org/abs/2102.09559)\]. Overall, these works emphasize the importance of addressing OOD samples in SSL to improve generalization and robustness in open-world settings \[[9](http://arxiv.org/abs/2308.13168)\].

### <a id='category-contrastive-regularization-in-ssl'></a>Contrastive Regularization in SSL: 3 papers found.
Contrastive regularization has emerged as a powerful technique to enhance semi-supervised learning (SSL) by improving the efficiency and accuracy of label propagation. Unlike traditional consistency regularization, which often struggles with the propagation of confident pseudo-labels due to the exclusion of uncertain samples, contrastive regularization leverages well-clustered features of unlabeled data to better aggregate and separate representations \[[10](http://arxiv.org/abs/2201.06247)\]. This approach ensures that features with confident pseudo-labels are pulled closer within their cluster while being pushed away from features in other clusters, thereby enabling more effective information propagation \[[10](http://arxiv.org/abs/2201.06247)\]. This idea is further supported by works such as SimCLR, which demonstrates the importance of data augmentation and contrastive learning in capturing meaningful visual representations \[[24](http://arxiv.org/abs/2002.05709)\]. SimCLR shows that by using a combination of data augmentations and a learnable nonlinear transformation, contrastive learning can significantly improve the quality of representations, achieving performance comparable to supervised learning \[[24](http://arxiv.org/abs/2002.05709)\]. Similarly, CoMatch integrates contrastive learning with graph-based methods to refine pseudo-labels and improve model robustness, achieving state-of-the-art results on benchmark datasets \[[29](http://arxiv.org/abs/2011.11183)\]. These studies collectively highlight the potential of contrastive regularization in SSL, particularly in scenarios where unlabeled data may contain out-of-distribution samples, as seen in open-set SSL settings \[[10](http://arxiv.org/abs/2201.06247)\].
