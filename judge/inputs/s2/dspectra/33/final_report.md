## Related Works

Rehearsal-based methods have been widely studied in continual learning (CL) to mitigate catastrophic forgetting. These methods store a subset of past data in a buffer and use it during training alongside new data, enabling the model to retain knowledge from previous tasks \[[1](http://arxiv.org/abs/2302.05836)\]. Early works such as \[[2](http://arxiv.org/abs/1812.02464)\] introduced pseudo-rehearsal systems that "recall" representative samples of past tasks using deep generative networks, allowing models to learn sequentially without explicitly storing raw data. Similarly, \[[3](http://arxiv.org/abs/2104.07446)\] proposed a dual memory system that separates continual learning from reinforcement learning, further improving the ability to retain past knowledge. However, most of these approaches assume that concurrent rehearsal—where past and new data are trained together—is optimal \[[4](http://arxiv.org/abs/2305.00316)\].

Recent studies have questioned this assumption, suggesting that sequential rehearsal—where new data is trained first, followed by revisiting past data—may offer greater benefits in certain scenarios \[[5](http://arxiv.org/abs/1908.01091)\]. For example, \[[6](http://arxiv.org/abs/2207.04543)\] showed that models trained with sequential rehearsal can achieve better performance on tasks with low similarity, as the model is given the opportunity to reinforce previously learned knowledge without interference from new data. This aligns with findings in \[[7](http://arxiv.org/abs/1807.09536)\], which demonstrated that rehearsal strategies that allow for sequential revisiting of tasks can lead to improved generalization and reduced forgetting, particularly when tasks are dissimilar. These insights were further supported by \[[8](http://arxiv.org/abs/1805.12369)\], which showed that sequential rehearsal can be more effective in scenarios where the model needs to adapt to rapidly changing data distributions.

Theoretical analyses have also contributed to understanding the effectiveness of different rehearsal strategies. \[[9](http://arxiv.org/abs/1809.10635)\] provided a formal analysis of rehearsal-based CL under overparameterized linear models, showing that sequential rehearsal can outperform concurrent rehearsal when tasks are less similar. This was further validated by \[[10](http://arxiv.org/abs/2203.17269)\], which demonstrated that sequential rehearsal can lead to better generalization and lower forgetting errors in both linear and non-linear models. These results were corroborated by \[[11](http://arxiv.org/abs/2403.01244)\], which showed that sequential rehearsal can be particularly beneficial in scenarios where the model needs to learn from non-stationary data streams.

In addition to theoretical work, several practical approaches have been proposed to implement sequential rehearsal. \[[12](http://arxiv.org/abs/2103.07492)\] introduced a hybrid rehearsal strategy that combines concurrent and sequential rehearsal, training similar tasks together while revisiting dissimilar tasks sequentially. This approach was shown to outperform standard concurrent rehearsal in both linear and deep learning settings.
