## Related Works

KV cache management has been a focal point in optimizing the inference efficiency of large language models (LLMs). Early approaches primarily focused on reducing the memory footprint of the KV cache through quantization techniques \[[2](http://arxiv.org/abs/2402.02750)\]. For instance, KIVI introduced a tuning-free 2bit quantization method, which significantly reduced peak memory usage while maintaining generation quality \[[2](http://arxiv.org/abs/2402.02750)\]. Similarly, Coupled Quantization (CQ) leveraged the interdependencies between channels in key/value activations to achieve efficient compression down to 1-bit precision \[[8](http://arxiv.org/abs/2405.03917)\]. These methods aim to reduce the memory footprint of the KV cache, which is critical for handling large batch sizes and long context lengths \[[2](http://arxiv.org/abs/2402.02750)\].

Several studies have also explored compression techniques that go beyond simple quantization. MiniCache, for example, compresses the KV cache across layers by exploiting the high similarity between adjacent layers in the middle-to-deep portion of LLMs \[[5](http://arxiv.org/abs/2405.14366)\]. This approach, which is training-free and general, complements existing strategies like quantization and sparsity \[[5](http://arxiv.org/abs/2405.14366)\]. Similarly, PQCache utilized Product Quantization (PQ) to manage the KV cache, maintaining model quality while ensuring low serving latency \[[9](http://arxiv.org/abs/2407.12820)\]. These methods demonstrate the potential of advanced compression techniques to reduce the memory and computational overhead of KV caching.

Efforts have also been made to improve the efficiency of KV cache reuse. KVLink precomputed KV caches for documents and concatenated them during inference, allowing the model to reuse cached representations instead of recomputing them \[[11](http://arxiv.org/abs/2502.16002)\]. This approach significantly reduced the time-to-first-token and improved question answering accuracy \[[11](http://arxiv.org/abs/2502.16002)\]. Additionally, LESS integrated a constant-sized cache with eviction-based methods to retain information throughout decoding, enabling efficient inference while maintaining performance \[[12](http://arxiv.org/abs/2402.09398)\]. These strategies highlight the importance of adaptive and context-aware approaches in managing the KV cache effectively.

Moreover, recent work has focused on the impact of cache eviction on model performance. The No Token Left Behind paper examined the detrimental effects of cache eviction and proposed a mixed-precision quantization approach to preserve critical information while reducing memory usage \[[10](http://arxiv.org/abs/2402.18096)\]. This method, called MiKV, ensures that important KV pairs are retained at higher precision to safeguard generation quality \[[10](http://arxiv.org/abs/2402.18096)\]. Similarly, CAKE introduced a cascading and adaptive eviction strategy that allocates cache size based on layer-specific attention patterns \[[13](http://arxiv.org/abs/2503.12491)\]. These approaches demonstrate the need for intelligent eviction policies that balance memory constraints with model performance.
