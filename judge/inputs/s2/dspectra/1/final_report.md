Similarly, Coupled Quantization (CQ) leveraged the interdependencies between channels in key/value activations to achieve efficient compression down to 1-bit precision \[[8](http://arxiv.org/abs/2405.03917)\]. These methods aim to reduce the memory footprint of the KV cache, which is critical for handling large batch sizes and long context lengths \[[2](http://arxiv.org/abs/2402.02750)\].

Several studies have also explored compression techniques that go beyond simple quantization.
