## Related Works

Table discovery and retrieval have garnered significant attention in recent years due to the increasing availability of tabular data in various domains. Traditional methods often rely on keyword-based retrieval or query table matching, which can lead to large result sets requiring manual filtering \[[5](http://arxiv.org/abs/1802.06159)\]. This limitation highlights the need for more sophisticated approaches that can incorporate natural language (NL) requirements to refine search results. The proposed task of NL-conditional table discovery (nlcTD) addresses this gap by enabling users to combine a query table with NL conditions to obtain more precise and relevant results \[[1](http://arxiv.org/abs/1804.07461)\].

Several works have explored the use of semantic similarity for table retrieval. For instance, \[[5](http://arxiv.org/abs/1802.06159)\] introduced a method for semantic matching between queries and tables by representing both in multiple semantic spaces and using various similarity measures. This approach significantly improves retrieval performance over existing baselines. Similarly, \[[6](http://arxiv.org/abs/2209.09207)\] presents a diverse table detection dataset with over 7,000 samples, emphasizing the importance of diverse and high-quality training data for improving generalization in real-world applications. The dataset includes a wide variety of table structures, which is crucial for developing robust models.

Pretrained language models have also been leveraged to enhance table understanding. \[[2](http://arxiv.org/abs/2005.08314)\] introduces TaBERT, a pretrained model that jointly learns representations for natural language sentences and structured tables, achieving state-of-the-art results on semantic parsing tasks. This work demonstrates the potential of pretrained models in bridging the gap between textual and tabular data. Additionally, \[[3](http://arxiv.org/abs/1903.01949)\] presents GLUE, a benchmark for natural language understanding tasks, which emphasizes the importance of transfer learning and model generalization across different domains. While GLUE focuses on text-based tasks, its insights on model robustness and transfer learning are relevant to table discovery.

In the realm of table detection, \[[6](http://arxiv.org/abs/2209.09207)\] introduces a large-scale dataset with diverse table structures, highlighting the need for more representative training data. This work also presents baseline results using convolutional neural networks, showing the superiority of deep learning methods over classical computer vision approaches. Furthermore, \[[4](http://arxiv.org/abs/1208.4016)\] discusses the challenges of semantic table discovery, emphasizing the need for semantic connections between unrelated tables to provide meaningful and customized information to users.

The proposed nlcTables dataset \[[1](http://arxiv.org/abs/1804.07461)\] builds on these advancements by providing a comprehensive benchmark with diverse queries, candidate tables, and relevance annotations. This dataset enables the evaluation of state-of-the-art methods and highlights the performance gaps that exist in current approaches. The availability of this dataset and its construction framework fosters further research into advanced techniques for NL-conditional table discovery.
