## Related Works

Federated Learning (FL) has emerged as a promising paradigm for collaborative model training while preserving data privacy by keeping raw data on client devices \[[1](http://arxiv.org/abs/1804.08333)\]. However, existing FL approaches often assume homogeneous data distributions across clients, which is not the case in real-world scenarios \[[19](http://arxiv.org/abs/2210.04505)\]. This heterogeneity, both in data distribution and client resources, poses significant challenges to model convergence and accuracy \[[12](http://arxiv.org/abs/2010.01243)\]. 

Several works have addressed these challenges by introducing techniques for client selection and communication efficiency. For example, FedCS \[[1](http://arxiv.org/abs/1804.08333)\] focuses on selecting clients based on their resource conditions to improve training efficiency, while Power-of-Choice \[[12](http://arxiv.org/abs/2010.01243)\] proposes a biased selection strategy that accelerates convergence by favoring clients with lower local loss. Similarly, HeteroFL \[[5](http://arxiv.org/abs/2010.01264)\] introduces a framework that allows for heterogeneous local models and global inference models, challenging the assumption that local models must share the same architecture as the global model. These approaches highlight the need for adaptive strategies that account for client heterogeneity \[[5](http://arxiv.org/abs/2010.01264)\]\[[12](http://arxiv.org/abs/2010.01243)\].

Personalization in FL has also been a focal point of recent research. Federated Averaging (FedAvg), a popular FL algorithm, has been interpreted as a meta-learning algorithm \[[2](http://arxiv.org/abs/1909.12488)\]. This insight has led to the development of personalized FL approaches that allow users to adapt a global model to their local data with minimal computation \[[4](http://arxiv.org/abs/2002.07948)\]. For instance, the work in \[[4](http://arxiv.org/abs/2002.07948)\] introduces a meta-learning approach that enables users to fine-tune the global model with just a few gradient steps, leading to improved personalization. Similarly, FedMeta \[[11](http://arxiv.org/abs/1802.07876)\] proposes a federated meta-learning framework that reduces communication costs and improves convergence speed compared to FedAvg. These methods demonstrate that personalization is not only possible but also beneficial in FL settings \[[4](http://arxiv.org/abs/2002.07948)\]\[[11](http://arxiv.org/abs/1802.07876)\].

Another important aspect of FL is the handling of non-IID data, which is common in real-world applications. To address this, SDA-FL \[[8](http://arxiv.org/abs/2206.05507)\] introduces a framework that generates synthetic data for clients to improve data distribution consistency across the network. This approach uses GANs to create differentially private synthetic data and an iterative pseudo labeling mechanism to enhance model performance. Additionally, FedMatch \[[6](http://arxiv.org/abs/2006.12097)\] tackles the problem of semi-supervised learning in FL by introducing an inter-client consistency loss and parameter decomposition, leading to better performance than naive approaches. These methods underscore the importance of addressing data heterogeneity in FL \[[6](http://arxiv.org/abs/2006.12097)\]\[[8](http://arxiv.org/abs/2206.05507)\].

### <a id='category-client-heterogeneity-in-fl'></a>Client Heterogeneity in FL: 7 papers found.
Client heterogeneity in Federated Learning (FL) has been a focal point in recent research, addressing challenges posed by diverse data distributions, computational capabilities, and communication conditions across clients. Existing FL frameworks, such as the original FL protocol \[[1](http://arxiv.org/abs/1804.08333)\], assume uniform client behavior, leading to inefficiencies when clients have limited resources or poor network conditions. To mitigate this, novel approaches like FedCS \[[1](http://arxiv.org/abs/1804.08333)\] have been introduced, which actively manage client participation based on their resource constraints, enabling more efficient model training. Similarly, HeteroFL \[[5](http://arxiv.org/abs/2010.01264)\] challenges the assumption that local models must share the same architecture as the global model, proposing a framework that allows for heterogeneous local models while still producing a unified global inference model. Furthermore, the problem of noisy and heterogeneous clients has been tackled by RHFL \[[13](https://www.semanticscholar.org/paper/1ace65d958cd27ae9ad857c49d8caa9aa5740526)\], which integrates robustness against label noise and develops a client confidence re-weighting scheme to improve model performance. These approaches collectively highlight the need for adaptive and robust FL frameworks that can handle the complexities of heterogeneous client environments \[[1](http://arxiv.org/abs/1804.08333)\]\[[5](http://arxiv.org/abs/2010.01264)\]\[[13](https://www.semanticscholar.org/paper/1ace65d958cd27ae9ad857c49d8caa9aa5740526)\].

### <a id='category-federated-learning-(fl)-foundations'></a>Federated Learning (FL) Foundations: 3 papers found.
Federated Learning (FL) has emerged as a critical paradigm for distributed optimization in machine learning, particularly in scenarios where data is distributed across a large number of clients while maintaining data privacy \[[7](http://arxiv.org/abs/1511.03575)\]. In this setting, the goal is to train a centralized model without transferring raw data, making communication efficiency a key concern \[[7](http://arxiv.org/abs/1511.03575)\]. Traditional approaches, such as Federated Averaging (FedAvg), face challenges when client data is heterogeneous, as local updates can drift apart, leading to slow convergence and difficulty in tuning \[[10](http://arxiv.org/abs/1910.06378)\]. To address these limitations, new algorithms like SCAFFOLD have been proposed, which use control variates to reduce drift and offer favorable convergence guarantees with fewer communication rounds \[[10](http://arxiv.org/abs/1910.06378)\]. Additionally, recent work has focused on biased client selection strategies, revealing that selecting clients with higher local loss can accelerate convergence \[[12](http://arxiv.org/abs/2010.01243)\]. These advancements highlight the evolving landscape of FL, emphasizing the need for robust algorithms that account for data heterogeneity, communication constraints, and efficient client participation \[[7](http://arxiv.org/abs/1511.03575)\]\[[10](http://arxiv.org/abs/1910.06378)\]\[[12](http://arxiv.org/abs/2010.01243)\].

	Document 1: [Snippet]: «Federated learning (FL) has recently emerged as a popular privacy-preserving collaborative learning paradigm. However, it suffers from the non-independent and identically distributed (non-IID) data among clients. In this paper, we propose a novel framework, named Synthetic Data Aided Federated Learning (SDA-FL), to resolve this non-IID challenge by sharing synthetic data. Specifically, each client pretrains a local generative adversarial network (GAN) to generate differentially private synthetic data, which are uploaded to the parameter server (PS) to construct a global shared synthetic dataset. To generate confident pseudo labels for the synthetic dataset, we also propose an iterative pseudo labeling mechanism performed by the PS. A combination of the local private dataset and synthetic dataset with confident pseudo labels leads to nearly identical data distributions among clients, which improves the consistency among local models and benefits the global aggregation. Extensive experiments evidence that the proposed framework outperforms the baseline methods by a large margin in several benchmark datasets under both the supervised and semi-supervised settings.»
