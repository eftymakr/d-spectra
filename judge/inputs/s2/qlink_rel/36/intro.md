## Related Works

Deploying large language models (LLMs) on edge devices has garnered significant attention due to its potential to enable real-time, privacy-preserving AI services \[[1](https://www.semanticscholar.org/paper/007e7d6cb64a7dfcdcad9fc6f4f0ba69fdc88203)\]. However, the computational and memory demands of LLMs pose substantial challenges for resource-constrained edge hardware \[[16](https://www.semanticscholar.org/paper/ec93fc7ec82c65a7bf7213488327d391014539ed)\]. Prior work has explored various strategies to mitigate these challenges, including model compression, efficient inference techniques, and collaborative edge computing \[[1](https://www.semanticscholar.org/paper/007e7d6cb64a7dfcdcad9fc6f4f0ba69fdc88203)\]\[[3](http://arxiv.org/abs/2410.11845)\]\[[16](https://www.semanticscholar.org/paper/ec93fc7ec82c65a7bf7213488327d391014539ed)\].

Model compression techniques, such as quantization and pruning, have been widely studied to reduce the memory footprint and computational requirements of LLMs \[[11](http://arxiv.org/abs/2211.10438)\]\[[25](http://arxiv.org/abs/2402.14800)\]. For instance, SmoothQuant enables 8-bit weight and 8-bit activation quantization for LLMs, achieving up to 1.56x speedup and 2x memory reduction with negligible accuracy loss \[[11](http://arxiv.org/abs/2211.10438)\]. Similarly, AWQ (Activation-aware Weight Quantization) identifies and protects salient weights based on activation distribution, significantly reducing model size while preserving performance \[[6](http://arxiv.org/abs/2306.00978)\]. These methods are crucial for deploying LLMs on edge devices with limited resources.

Efficient inference techniques have also been proposed to optimize the performance of LLMs on edge hardware. FlashAttention-2 improves attention computation by better work partitioning and parallelism, achieving up to 50-73% of the theoretical maximum FLOPs/s on A100 GPUs \[[18](http://arxiv.org/abs/2307.08691)\]. Additionally, PagedAttention, inspired by virtual memory and paging techniques, enables near-zero waste in KV cache memory and flexible sharing within and across requests, improving throughput by 2-4× compared to state-of-the-art systems \[[2](http://arxiv.org/abs/2309.06180)\]. These techniques are essential for reducing the computational overhead of LLM inference on edge devices.

Collaborative edge computing has emerged as a promising approach to address the resource limitations of individual edge devices \[[1](https://www.semanticscholar.org/paper/007e7d6cb64a7dfcdcad9fc6f4f0ba69fdc88203)\]\[[3](http://arxiv.org/abs/2410.11845)\]. EdgeShard partitions computation-intensive LLMs into shards and distributes them across edge devices and cloud servers, achieving up to 50% latency reduction and 2× throughput improvement \[[1](https://www.semanticscholar.org/paper/007e7d6cb64a7dfcdcad9fc6f4f0ba69fdc88203)\]. Similarly, Galaxy introduces a hybrid model parallelism and heterogeneity-aware parallelism planning to break the resource walls across heterogeneous edge devices, achieving up to 2.5× end-to-end latency reduction \[[7](http://arxiv.org/abs/2405.17245)\]. These collaborative approaches are vital for enabling efficient LLM inference on edge networks.
