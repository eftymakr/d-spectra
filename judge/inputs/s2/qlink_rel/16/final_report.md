## Related Works

Open-vocabulary object detection has emerged as a critical research direction, enabling detectors to recognize objects from arbitrary text inputs at inference time \[[1](http://arxiv.org/abs/2011.10678)\]. This capability significantly expands the practicality of object detection systems by allowing users to specify classes of interest without requiring extensive training data \[[2](http://arxiv.org/abs/2104.13921)\]. However, early approaches faced challenges in generalization, particularly when dealing with novel or mis-specified vocabularies \[[3](http://arxiv.org/abs/2205.06230)\]. Several methods have since been proposed to address these limitations, leveraging vision-language models and weakly supervised learning strategies.

Weakly supervised object detection methods, such as those based on image-level annotations, have been explored to reduce the reliance on expensive bounding box annotations \[[4](http://arxiv.org/abs/2103.00020)\]. These methods often use image captions or other forms of weak supervision to guide the detection process \[[5](http://arxiv.org/abs/2203.14940)\]. However, they typically struggle with precision and generalization, especially when dealing with novel or rare categories \[[6](http://arxiv.org/abs/2207.03482)\]. In contrast, zero-shot detection approaches aim to detect objects without any training on those classes, relying instead on semantic embeddings from pre-trained models \[[7](http://arxiv.org/abs/2111.09452)\]. While these methods show promise, they often suffer from performance degradation on novel categories due to the lack of fine-grained alignment between text and visual features \[[8](http://arxiv.org/abs/2203.11876)\].

Recent advances in vision-language pre-training have enabled more effective open-vocabulary detection by aligning visual and textual representations \[[9](http://arxiv.org/abs/2207.08954)\]. For instance, models like CLIP and ALIGN have demonstrated strong zero-shot transfer capabilities, allowing detectors to generalize to unseen classes based on semantic descriptions \[[10](http://arxiv.org/abs/2201.02605)\]. However, these models often require careful prompt engineering or additional training to achieve optimal performance \[[11](http://arxiv.org/abs/2203.16513)\]. To address this, methods such as ViLD and RegionCLIP have been proposed, which distill knowledge from vision-language models into object detectors, improving alignment between text and visual features \[[12](http://arxiv.org/abs/2104.12763)\].

Another line of research focuses on leveraging large-scale image-text pairs to generate pseudo labels for training object detectors \[[13](https://www.semanticscholar.org/paper/c5ff974a69fd0c760b4855b819e61e89f31cfffe)\]. These methods aim to reduce the need for manual annotations by using vision-language models to generate bounding box proposals and class labels from captions \[[14](http://arxiv.org/abs/1405.0312)\]. This approach has shown promising results, particularly in improving performance on novel categories and reducing the dependency on labeled data \[[15](http://arxiv.org/abs/1908.03195)\]. However, the quality of pseudo labels can vary, and robust methods are needed to ensure accurate detection \[[16](http://arxiv.org/abs/2112.09106)\].

Additionally, methods such as Detic and PromptDet have been developed to expand the vocabulary of object detectors by training on image-level supervision and uncurated data \[[17](http://arxiv.org/abs/2205.06160)\]. ### <a id='category-weakly-supervised-detection-methods-[4]'></a>Weakly supervised detection methods [4]: 4 papers found.
Weakly supervised detection methods aim to reduce the reliance on expensive bounding box annotations by utilizing alternative forms of supervision, such as image-level labels or textual descriptions \[[4](http://arxiv.org/abs/2103.00020)\]. These approaches have gained traction in open-vocabulary object detection (OVD), where models must detect objects from a dynamically specified vocabulary \[[6](http://arxiv.org/abs/2207.03482)\]. For instance, some methods leverage pretrained models like CLIP, which provide language-visual alignment but lack precise localization \[[6](http://arxiv.org/abs/2207.03482)\]. Others use image-level supervision with pseudo-labeling to generate high-quality object proposals \[[6](http://arxiv.org/abs/2207.03482)\]. Additionally, methods based on image-caption pairs have been proposed to learn class labels for both known and novel objects in a weakly supervised manner \[[17](http://arxiv.org/abs/2205.06160)\]. These techniques often incorporate consistency-regularization to better utilize caption data \[[17](http://arxiv.org/abs/2205.06160)\]. Another approach focuses on training text-only classifiers to generalize beyond dataset boundaries, enabling detection from noisy caption data \[[21](http://arxiv.org/abs/1907.10164)\]. Furthermore, weakly supervised architectures have been developed to operate at the level of image regions, performing simultaneous region selection and classification \[[26](http://arxiv.org/abs/1511.02853)\]. These methods collectively highlight the ongoing efforts to improve detection accuracy while minimizing annotation costs, with a focus on aligning language and visual representations for better performance in OVD settings.
