## Related Works

Event cameras, which capture asynchronous per-pixel brightness changes, have gained significant attention for their high temporal resolution and robustness in challenging environments \[[1](http://arxiv.org/abs/1804.01310)\]. However, the asynchronous nature of event data introduces challenges in processing and analysis, particularly in terms of computational efficiency and memory usage \[[1](http://arxiv.org/abs/1804.01310)\]. Prior work has addressed these challenges by exploring event downsampling techniques, which aim to reduce the volume of data while preserving essential information \[[1](http://arxiv.org/abs/1804.01310)\]. Most existing approaches rely on fixed heuristics or threshold-based strategies, which limit their adaptability to different scenarios \[[1](http://arxiv.org/abs/1804.01310)\]. For instance, some methods use static thresholds to filter out less significant events \[[2](http://arxiv.org/abs/1802.06898)\], while others apply uniform downsampling across the entire event stream \[[3](http://arxiv.org/abs/1904.08405)\]. These approaches, however, do not account for the varying importance of events in different contexts, leading to suboptimal performance in tasks such as object classification and visual odometry \[[4](http://arxiv.org/abs/1812.08156)\].

To overcome these limitations, recent research has proposed adaptive and context-aware event sampling strategies. For example, \[[5](http://arxiv.org/abs/1904.08298)\] introduced a method that dynamically adjusts the sampling rate based on the motion of the scene, which can improve performance in high-speed scenarios. Similarly, \[[6](http://arxiv.org/abs/1906.07165)\] proposed a probabilistic framework that models the importance of events using a probability density function (PDF), allowing for more flexible and scene-specific adaptation. This approach is similar to the proposed POLED framework, which uses an event-importance probability density function (ePDF) to guide downsampling decisions \[[1](http://arxiv.org/abs/1804.01310)\]. Unlike previous methods, POLED operates in an online setting, estimating event importance on-the-fly from raw event streams \[[1](http://arxiv.org/abs/1804.01310)\]. This enables real-time adaptation to changing scene dynamics, which is crucial for applications such as autonomous driving and robotics \[[7](http://arxiv.org/abs/1803.07913)\].

Another line of research has focused on preserving structural information during event downsampling. For instance, \[[8](http://arxiv.org/abs/1904.08245)\] proposed a contour-preserving method that prioritizes events contributing to the edges and contours of objects, ensuring that important visual features are retained. ### <a id='category-event-camera-fundamentals'></a>Event Camera Fundamentals: 12 papers found.
Event cameras, also known as neuromorphic or dynamic vision sensors, are bio-inspired devices that capture asynchronous, per-pixel intensity changes, referred to as "events," rather than traditional frame-based images \[[1](http://arxiv.org/abs/1804.01310)\]. This asynchronous nature allows for high temporal resolution (up to μs), high dynamic range (140 dB), and low power consumption, making them suitable for high-speed and challenging visual tasks \[[3](http://arxiv.org/abs/1904.08405)\]. However, their unconventional output, consisting of sparse events and lacking standard intensity information, requires novel processing techniques \[[17](http://arxiv.org/abs/1607.06283)\]. Several studies have explored methods to process event streams, including learning-based approaches and specialized processors such as spiking neural networks \[[1](http://arxiv.org/abs/1804.01310)\]. Additionally, hybrid sensors like the DAVIS combine event-based and global-shutter cameras, offering both asynchronous events and synchronous frames, which can be used for tasks such as ego-motion estimation and pose tracking \[[10](http://arxiv.org/abs/1610.08336)\]. Recent advancements have also introduced color event cameras, such as the Color-DAVIS346, along with datasets like the Color Event Camera Dataset (CED), which provide color frames and events for research \[[9](http://arxiv.org/abs/1709.06310)\]. Furthermore, algorithms have been developed to fuse event data with inertial measurements for accurate 6DoF pose estimation \[[25](https://www.semanticscholar.org/paper/1d5201ed10c9e401abc833b2b209ad675c391abb)\]. These developments highlight the growing interest in event-based vision and the need for adaptive, efficient processing methods to fully leverage the capabilities of event cameras \[[12](http://arxiv.org/abs/1801.10202)\].
