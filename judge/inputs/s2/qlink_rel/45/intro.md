## Related Works

Opinion mining has garnered significant attention for its ability to extract insights from textual data, particularly in the context of user feedback \[[17](https://www.semanticscholar.org/paper/96761dc3d8adaeff44eb9c07501eb3109802ee4b)\]. While much of the research focuses on sentiment polarity—such as classifying text as positive, negative, or neutral—fine-grained emotion classification remains underexplored, especially in app reviews \[[1](http://arxiv.org/abs/2005.00547)\]. This gap is addressed by several recent works that have attempted to develop more nuanced emotion detection systems.

The GoEmotions dataset \[[1](http://arxiv.org/abs/2005.00547)\] represents a significant contribution to the field, offering a large-scale, manually annotated corpus of Reddit comments with fine-grained emotion labels. This dataset includes 58k English comments labeled for 27 emotion categories or neutral, and it demonstrates high annotation quality through Principal Component Analysis. However, this dataset is not tailored specifically for app reviews, which present unique challenges in terms of language and context \[[18](https://www.semanticscholar.org/paper/3fb416be9e59b35c7cc91cd11b5b3f3f5491f13a)\].

Similarly, the EmoBank dataset \[[5](http://arxiv.org/abs/2205.01996)\] focuses on dimensional emotion analysis using the Valence-Arousal-Dominance (VAD) framework. It distinguishes between writer’s and reader’s emotions, which is an important distinction for understanding how emotions are perceived rather than expressed. While this work is valuable, it does not address the specific challenges of app review analysis, such as the need for domain-specific annotations \[[12](https://www.semanticscholar.org/paper/7d0531aaaa4dbf4033da964289843e7812262702)\].

The SemEval-2018 Task 1: Affect in Tweets \[[10](https://www.semanticscholar.org/paper/66c8ab0b3b7698cf5333c3f7350a6eaa5302294b)\] explores the classification of affect in social media content, including emotion intensity, valence, and emotion classification. This work highlights the importance of multi-lingual and multi-task approaches, but again, it is not focused on app reviews. Nevertheless, the techniques developed for this task could be adapted for app review analysis.

In the context of app reviews, the work by \[[18](https://www.semanticscholar.org/paper/3fb416be9e59b35c7cc91cd11b5b3f3f5491f13a)\] explores the classification of app reviews into bug reports, feature requests, or praise. This task is closely related to sentiment analysis, as it involves identifying the intent behind user feedback. However, it does not focus on fine-grained emotion classification, which is the core of this study.

The CROWDSOURCING A WORD–EMOTION ASSOCIATION LEXICON \[[13](http://arxiv.org/abs/1308.6297)\] presents a method for generating a large, high-quality word-emotion lexicon using crowdsourcing. This work is relevant to the development of lexicons for emotion analysis, which can be used to improve the performance of sentiment and emotion classification models.
