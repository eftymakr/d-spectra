## Related Works

Anomaly detection in industrial settings has garnered significant attention due to its critical role in quality control and defect identification. Early approaches relied on handcrafted features and classical machine learning models, which often struggled with scalability and adaptability to diverse defect types \[[3](http://arxiv.org/abs/2011.08785)\]. More recently, deep learning-based methods have emerged as a promising alternative, offering improved performance in both detection and localization tasks \[[6](https://www.semanticscholar.org/paper/3aa681914a7da79f7d7293f51a058eefe61c8bb7)\]. These methods typically leverage pre-trained convolutional neural networks (CNNs) to extract meaningful features from images and employ outlier detection techniques to identify anomalies \[[3](http://arxiv.org/abs/2011.08785)\].

Several notable works have contributed to the field. PatchCore, for instance, introduces a memory bank of representative patch features to enhance detection accuracy and reduce computational overhead \[[3](http://arxiv.org/abs/2011.08785)\]. This approach achieves state-of-the-art performance on the MVTec AD benchmark, achieving an AUROC score of up to 99.6% \[[3](http://arxiv.org/abs/2011.08785)\]. Similarly, PaDiM proposes a framework that uses multivariate Gaussian distributions to model the normal class and exploits semantic correlations within CNN features to improve localization \[[3](http://arxiv.org/abs/2011.08785)\]. PaDiM outperforms existing methods on both MVTec AD and STC datasets, demonstrating its effectiveness in real-world scenarios \[[3](http://arxiv.org/abs/2011.08785)\].

CFLOW-AD is another recent advancement that focuses on real-time anomaly detection with localization. It employs a conditional normalizing flow framework, resulting in a model that is 10× faster and smaller than prior state-of-the-art methods while maintaining high accuracy \[[5](http://arxiv.org/abs/2107.12571)\]. The MVTec AD dataset has been instrumental in benchmarking these models, providing a comprehensive set of normal and anomalous images with precise ground truth annotations \[[6](https://www.semanticscholar.org/paper/3aa681914a7da79f7d7293f51a058eefe61c8bb7)\]. This dataset includes over 70 types of defects, such as scratches and dents, making it a valuable resource for evaluating the robustness of anomaly detection algorithms \[[6](https://www.semanticscholar.org/paper/3aa681914a7da79f7d7293f51a058eefe61c8bb7)\].

The development of multi-modal and hybrid fusion approaches has also gained traction. For example, M3DM integrates 3D point clouds and RGB images using a hybrid fusion scheme, achieving superior performance on the MVTec-3D AD dataset \[[9](http://arxiv.org/abs/2303.00601)\]. This work highlights the importance of aligning features from different modalities to improve detection and segmentation accuracy \[[9](http://arxiv.org/abs/2303.00601)\]. Similarly, UniAD presents a unified framework for multi-class anomaly detection, overcoming the limitations of training separate models for each class \[[10](http://arxiv.org/abs/2206.03687)\]. This approach improves detection and localization performance on MVTec-AD, surpassing existing methods by a significant margin \[[10](http://arxiv.org/abs/2206.03687)\].

### <a id='category-deep-learning-based-anomaly-detection-methods'></a>Deep Learning-Based Anomaly Detection Methods: 7 papers found.
In the realm of deep learning-based anomaly detection, recent approaches have focused on improving both detection accuracy and computational efficiency, particularly for industrial applications \[[1](http://arxiv.org/abs/2106.08265)\]. Methods like PatchCore leverage maximally representative memory banks of nominal patch-features to achieve state-of-the-art performance on benchmarks such as MVTec-AD, with an AUROC score of 99.6% \[[1](http://arxiv.org/abs/2106.08265)\]. Similarly, PaDiM uses pretrained CNNs and multivariate Gaussian distributions to model normal patterns, offering competitive results in both detection and localization \[[3](http://arxiv.org/abs/2011.08785)\]. The challenge of one-class learning, where only normal data is available, has also been addressed by models like CFLOW-AD, which introduces a conditional normalizing flow framework for real-time processing, achieving a 10× reduction in computational complexity compared to prior methods \[[5](http://arxiv.org/abs/2107.12571)\]. Additionally, DRÆM proposes a discriminative approach that directly learns a decision boundary between normal and anomalous examples, enabling efficient anomaly localization without post-processing \[[5](http://arxiv.org/abs/2107.12571)\]. The need for models that can generalize across multiple classes has led to the development of UniAD, which uses a unified framework to detect anomalies across 15 categories, surpassing state-of-the-art results in both detection and localization \[[6](https://www.semanticscholar.org/paper/3aa681914a7da79f7d7293f51a058eefe61c8bb7)\]. Knowledge distillation has also been explored to enhance anomaly detection, with methods like the proposed T-S model achieving better performance by introducing a “reverse distillation” paradigm and a trainable one-class bottleneck embedding \[[11](http://arxiv.org/abs/2201.10703)\]. These advancements highlight the ongoing efforts to develop efficient, accurate, and versatile anomaly detection systems suitable for real-world industrial deployment.

[Snippet]: «In recent years, a number of process-based anomaly detection schemes for Industrial Control Systems were proposed. In this work, we provide the first systematic analysis of such schemes, and introduce a taxonomy of properties that are verified by those detection systems. We then present a novel general framework to generate adversarial spoofing signals that violate physical properties of the system, and use the framework to analyze four anomaly detectors published at top security conferences. We find that three of those detectors are susceptible to a number of adversarial manipulations (e.g., spoofing with precomputed patterns), which we call Synthetic Sensor Spoofing and one is resilient against our attacks. We investigate the root of its resilience and demonstrate that it comes from the properties that we introduced. Our attacks reduce the Recall (True Positive Rate) of the attacked schemes making them not able to correctly detect anomalies. Thus, the vulnerabilities we discovered in the anomaly detectors show that (despite an original good detection performance), those detectors are not able to reliably learn physical properties of the system. Even attacks that prior work was expected to be resilient against (based on verified properties) were found to be successful. We argue that our findings demonstrate the need for both more complete attacks in datasets, and more critical analysis of process-based anomaly detectors. We plan to release our implementation as open-source, together with an extension of two public datasets with a set of Synthetic Sensor Spoofing attacks as generated by our framework.»

[Snippet]: «2D-based Industrial Anomaly Detection has been widely discussed, however, multimodal industrial anomaly detection based on 3D point clouds and RGB images still has many untouched fields. Existing multimodal industrial anomaly detection methods directly concatenate the multimodal features, which leads to a strong disturbance between features and harms the detection performance. In this paper, we propose Multi-3D-Memory (M3DM), a novel multimodal anomaly detection method with hybrid fusion scheme: firstly, we design an unsupervised feature fusion with patch-wise contrastive learning to encourage the interaction of different modal features; secondly, we use a decision layer fusion with multiple memory banks to avoid loss of information and additional novelty classifiers to make the final decision. We further propose a point feature alignment operation to better align the point cloud and RGB features. Extensive experiments show that our multi-modal industrial anomaly detection model outperforms the state-of-the-art (SOTA) methods on both detection and segmentation precision on MVTec-3D AD dataset.
