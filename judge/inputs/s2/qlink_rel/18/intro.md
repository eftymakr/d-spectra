## Related Works

Anomaly detection in industrial settings has garnered significant attention due to its critical role in quality control and defect identification. Early approaches relied on handcrafted features and classical machine learning models, which often struggled with scalability and adaptability to diverse defect types \[[3](http://arxiv.org/abs/2011.08785)\]. More recently, deep learning-based methods have emerged as a promising alternative, offering improved performance in both detection and localization tasks \[[6](https://www.semanticscholar.org/paper/3aa681914a7da79f7d7293f51a058eefe61c8bb7)\]. These methods typically leverage pre-trained convolutional neural networks (CNNs) to extract meaningful features from images and employ outlier detection techniques to identify anomalies \[[3](http://arxiv.org/abs/2011.08785)\].

Several notable works have contributed to the field. PatchCore, for instance, introduces a memory bank of representative patch features to enhance detection accuracy and reduce computational overhead \[[3](http://arxiv.org/abs/2011.08785)\]. This approach achieves state-of-the-art performance on the MVTec AD benchmark, achieving an AUROC score of up to 99.6% \[[3](http://arxiv.org/abs/2011.08785)\]. Similarly, PaDiM proposes a framework that uses multivariate Gaussian distributions to model the normal class and exploits semantic correlations within CNN features to improve localization \[[3](http://arxiv.org/abs/2011.08785)\]. PaDiM outperforms existing methods on both MVTec AD and STC datasets, demonstrating its effectiveness in real-world scenarios \[[3](http://arxiv.org/abs/2011.08785)\].

CFLOW-AD is another recent advancement that focuses on real-time anomaly detection with localization. It employs a conditional normalizing flow framework, resulting in a model that is 10× faster and smaller than prior state-of-the-art methods while maintaining high accuracy \[[5](http://arxiv.org/abs/2107.12571)\]. The MVTec AD dataset has been instrumental in benchmarking these models, providing a comprehensive set of normal and anomalous images with precise ground truth annotations \[[6](https://www.semanticscholar.org/paper/3aa681914a7da79f7d7293f51a058eefe61c8bb7)\]. This dataset includes over 70 types of defects, such as scratches and dents, making it a valuable resource for evaluating the robustness of anomaly detection algorithms \[[6](https://www.semanticscholar.org/paper/3aa681914a7da79f7d7293f51a058eefe61c8bb7)\].

The development of multi-modal and hybrid fusion approaches has also gained traction. For example, M3DM integrates 3D point clouds and RGB images using a hybrid fusion scheme, achieving superior performance on the MVTec-3D AD dataset \[[9](http://arxiv.org/abs/2303.00601)\]. This work highlights the importance of aligning features from different modalities to improve detection and segmentation accuracy \[[9](http://arxiv.org/abs/2303.00601)\]. Similarly, UniAD presents a unified framework for multi-class anomaly detection, overcoming the limitations of training separate models for each class \[[10](http://arxiv.org/abs/2206.03687)\]. This approach improves detection and localization performance on MVTec-AD, surpassing existing methods by a significant margin \[[10](http://arxiv.org/abs/2206.03687)\].
