## Related Works

Efficient memory management and KV cache optimization have been extensively studied in the context of large language model (LLM) serving systems. Early work focused on the challenges of managing the key-value (KV) cache, which stores attention keys and values to avoid recomputation during inference \[[1](http://arxiv.org/abs/2309.06180)\]. The primary issue lies in the dynamic and often large memory footprint of the KV cache, which can significantly limit batch sizes and throughput \[[1](http://arxiv.org/abs/2309.06180)\]. Traditional systems often suffer from memory fragmentation and redundant duplication, leading to suboptimal utilization of available resources \[[1](http://arxiv.org/abs/2309.06180)\].

Several approaches have been proposed to address these limitations. PagedAttention, inspired by virtual memory and paging techniques, enables near-zero waste in KV cache memory and allows flexible sharing within and across requests \[[1](http://arxiv.org/abs/2309.06180)\]. This approach is foundational to the vLLM system, which achieves significant throughput improvements over state-of-the-art systems like FasterTransformer and Orca \[[1](http://arxiv.org/abs/2309.06180)\]. Similarly, KIVI introduces a tuning-free 2-bit quantization method for the KV cache, reducing peak memory usage by up to 2.6× while maintaining model quality \[[2](http://arxiv.org/abs/2402.02750)\]. This approach is particularly effective for models like Llama, Falcon, and Mistral \[[2](http://arxiv.org/abs/2402.02750)\].

The importance of KV cache compression and efficient management has also been explored in the context of streaming applications and long-context generation. Scissorhands leverages the persistence of importance hypothesis, retaining only pivotal tokens in the KV cache to reduce memory usage by up to 5× without compromising model quality \[[3](http://arxiv.org/abs/2305.17118)\]. This method can be combined with 4-bit quantization to achieve up to 20× compression \[[3](http://arxiv.org/abs/2305.17118)\]. Similarly, H2O introduces a Heavy Hitter Oracle (H$_2$O) that dynamically retains recent and important tokens, reducing latency by up to 1.9× and improving throughput over existing systems \[[5](http://arxiv.org/abs/2306.14048)\].

Quantization techniques have also been applied to KV cache activations to reduce memory consumption. KVQuant enables 3-bit quantization with less than 0.1 perplexity degradation, allowing models like LLaMA-7B to handle up to 10 million context tokens on an 8-GPU system \[[6](http://arxiv.org/abs/2401.18079)\]. This method incorporates several innovations, including per-channel key quantization and non-uniform datatypes, to better represent the distribution of activations \[[6](http://arxiv.org/abs/2401.18079)\].

Existing studies highlight the challenges of accurately representing KV cache activations at sub-4-bit precision, with approaches like per-channel key quantization and pre-RoPE key quantization being proposed to better match activation distributions \[[6](http://arxiv.org/abs/2401.18079)\]. Additionally, the importance of quantization strategies varies between key and value caches, with key caches often requiring per-channel quantization while value caches benefit from per-token approaches \[[2](http://arxiv.org/abs/2402.02750)\]. Furthermore, mixed-precision KV cache methods have been introduced to balance compression and generation quality by retaining important KV pairs at higher precision while quantizing less critical ones to lower precision \[[11](http://arxiv.org/abs/2402.18096)\]. These techniques aim to address the growing memory demands of KV caches, especially as context lengths and batch sizes increase, thereby enabling larger models and more efficient serving.

### <a id='category-kv-cache-management-techniques'></a>KV Cache Management Techniques: 6 papers found.
The category "KV Cache Management Techniques" explores various strategies to optimize memory usage and performance in large language models (LLMs) during inference. These techniques address the significant memory footprint of the key-value (KV) cache, which scales with sequence length and batch size, often surpassing the model size itself \[[1](http://arxiv.org/abs/2309.06180)\]. One approach, Scissorhands, leverages the persistence of importance by prioritizing the storage of pivotal tokens that have a substantial influence on future generations, reducing memory usage by up to 5X without compromising model quality \[[3](http://arxiv.org/abs/2305.17118)\]. Similarly, StreamingLLM introduces a framework that enables LLMs to generalize to infinite sequence lengths by addressing the attention sink phenomenon, where initial tokens play a critical role in maintaining performance \[[4](http://arxiv.org/abs/2309.17453)\]. The Heavy Hitter Oracle (H$_2$O) identifies and retains "Heavy Hitters" — tokens that contribute most to attention scores — ensuring a balance between recent and important tokens, leading to a 29$\times$ improvement in throughput over existing systems \[[5](http://arxiv.org/abs/2306.14048)\]. Adaptive KV cache compression, as implemented in FastGen, further optimizes memory by selectively evicting non-essential tokens based on attention head specialization, enabling efficient deployment without retraining \[[7](http://arxiv.org/abs/2310.01801)\]. InfiniGen introduces a method to speculate on essential KV cache entries during inference, reducing fetch overhead and improving performance by up to 3.00x \[[9](http://arxiv.org/abs/2406.19707)\]. Lastly, Quest proposes a query-aware selection of KV cache pages, prioritizing critical tokens based on query vectors, achieving a 2.23x speedup in self-attention and reducing latency by 7.03x \[[14](http://arxiv.org/abs/2406.10774)\]. These techniques collectively highlight the importance of workload-aware and adaptive strategies in managing the KV cache for efficient and scalable LLM inference.
