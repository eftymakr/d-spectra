## Related Works

Conversational Recommender Systems (CRSs) have emerged as a promising approach to dynamically capture user preferences through multi-turn interactions \[[1](http://arxiv.org/abs/2002.09102)\]. Unlike traditional recommender systems that rely on static user profiles and historical data, CRSs enable real-time preference elicitation by engaging users in natural language dialogues \[[2](http://arxiv.org/abs/2004.00646)\]. This interactive nature allows for more accurate and personalized recommendations, but it also introduces challenges in managing the complexity of user preferences and maintaining a seamless user experience \[[3](http://arxiv.org/abs/2101.09459)\].

Several approaches have been proposed to address these challenges. One line of work focuses on developing frameworks that integrate conversation and recommendation modules, such as the Estimation-Action-Reflection (EAR) framework \[[1](http://arxiv.org/abs/2002.09102)\]. This framework consists of three stages: Estimation, which builds predictive models to estimate user preference; Action, which determines whether to ask for attribute information or recommend items; and Reflection, which updates the recommender model based on user feedback \[[1](http://arxiv.org/abs/2002.09102)\]. Another approach, the Conversational Path Reasoning (CPR) framework, models conversational recommendation as an interactive path reasoning problem on a graph, allowing for more efficient exploration of user preferences \[[5](http://arxiv.org/abs/2007.00194)\].

To improve the effectiveness of conversational recommendation, researchers have also explored the use of user simulation for automated evaluation. The work in \[[4](http://arxiv.org/abs/2006.08732)\] proposes a user simulator that generates realistic user responses based on individual preferences and interaction flow, enabling the evaluation of CRSs without requiring extensive human input. Similarly, the ConvSim framework \[[10](http://arxiv.org/abs/2304.13874)\] is designed to simulate user feedback in multi-turn conversational search systems, demonstrating that incorporating user feedback can significantly improve retrieval performance.

In addition to user simulation, recent work has focused on improving the dialogue understanding and generation capabilities of CRSs. For example, the KBRD framework \[[16](http://arxiv.org/abs/1908.05391)\] integrates a knowledge-based recommender system with a dialog generation system, allowing for more informed and context-aware recommendations. The UniCRS model \[[17](http://arxiv.org/abs/2206.09363)\] further unifies the recommendation and conversation subtasks through knowledge-enhanced prompt learning, enabling a more seamless integration of both modules.

Another important aspect of CRS development is the ability to handle multi-round interactions and adapt to user feedback. The Feedback-guided Preference Adaptation Network (FPAN) \[[11](https://www.semanticscholar.org/paper/33e0fe2d4cf01b16da89ab0c180cdcbf37b3be17)\] is designed to refine user preference estimation by leveraging the relationship between attribute-level and item-level feedback, leading to more accurate recommendations. Additionally, the Q&R system \[[13](https://www.semanticscholar.org/paper/2610b45131f31a7c58b0cd6a8fce21c02ba014be)\] introduces a two-stage approach for interactive recommendation, where the system first asks questions to elicit user preferences and then uses this information to generate more accurate recommendations
