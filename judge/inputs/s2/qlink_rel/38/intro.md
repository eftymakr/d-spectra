## Related Works

Memory bandwidth regulation and cache partitioning have been widely studied as techniques to achieve predictable timing in real-time computing systems \[[1](https://www.semanticscholar.org/paper/bbebaeb1b00fdcde2aeb192543835d3ec1518f8d)\]. These methods are often combined with partitioned scheduling to ensure that task execution times are tightly bounded \[[2](https://www.semanticscholar.org/paper/50d359dc737cb5c296b527f4eb1541dc55f3ed86)\]. However, the co-allocation of tasks and resources to cores remains a significant challenge, as task execution times are strongly influenced by the availability of allocated resources \[[3](https://www.semanticscholar.org/paper/25ebad66dc10d7b01c22684cbb200ddeb6502475)\]. 

Several approaches have been proposed to manage memory bandwidth in multi-core systems. MemGuard \[[4](https://www.semanticscholar.org/paper/abbd6f8840092bd8e4e3684d3297e1b707abdc5d)\] introduces a memory bandwidth reservation system to enable efficient performance isolation. Similarly, PALLOC \[[5](https://www.semanticscholar.org/paper/6e925ae85e385ac0e8810441d84be97c079f6b22)\] presents a DRAM bank-aware memory allocator designed to improve performance isolation on multicore platforms. These systems aim to reduce contention and provide predictable memory access patterns, which is critical for real-time applications. 

Cache partitioning has also been explored as a means to improve predictability. The work in \[[6](https://www.semanticscholar.org/paper/dbd4eb5033815003e7f6519fd66e43e5fc297075)\] proposes a real-time cache management framework for multi-core architectures, emphasizing the importance of managing shared cache resources to meet timing constraints. Additionally, \[[7](https://www.semanticscholar.org/paper/31e4e1bb57bd04bc02d7f7110e66122a215d7bfa)\] discusses utility-based cache partitioning, which offers a low-overhead, high-performance runtime mechanism to partition shared caches. This approach allows for dynamic adjustments based on workload characteristics, enhancing flexibility and performance. 

Memory interference in COTS-based multi-core systems has been a major concern, as tasks running on one core can be delayed by others due to shared DRAM access \[[8](https://www.semanticscholar.org/paper/afca4afaaaa543a1da02b266e9b2ac46eb94793b)\]. To address this, \[[9](http://arxiv.org/abs/1809.05921)\] presents techniques to bound memory interference delay, explicitly modeling key resources such as memory banks, buses, and controllers. This work provides a tight upper bound on worst-case memory interference, which is essential for predictable real-time systems. 

Dynamic memory bandwidth regulation has also been studied, with \[[10](https://www.semanticscholar.org/paper/d5336fd2234f431f554fc5d878503a04a27e366e)\] focusing on the worst-case response time of tasks under varying bandwidth-to-core assignments. The paper shows that response time computation can be reduced to a maximization problem over memory request assignments, enabling more accurate scheduling decisions. This approach is particularly relevant for systems with memory-intensive workloads, such as integrated modular avionics. 

In addition to memory management, scheduling algorithms play a critical role in real-time systems. \[[11](https://www.semanticscholar.org/paper/333da42f4369dff8ca905ad21ea6ee2f5dc99d55)\] presents a survey of hard real-time scheduling for multiprocessor systems, highlighting the challenges of scheduling parallel real-time tasks on multi-core processors. The paper discusses various scheduling policies and their effectiveness in meeting timing constraints. 

The integration of hardware and software solutions is also a key theme in recent work. \[[12](https://www.semanticscholar.org/paper/0b1bc294dbd926f853a8ee41d1d8f8ecc3cfde13)\] discusses a coordinated approach for practical OS-level cache management
