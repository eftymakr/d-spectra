## Related Works

Semi-supervised learning (SSL) has emerged as a powerful paradigm for improving model performance when labeled data is scarce. Traditional SSL methods assume that labeled and unlabeled data share the same class distribution \[[1](https://www.semanticscholar.org/paper/f3df804a7eef204b0c4fc4b81166dec9b4abc073)\]. However, this assumption is often violated in practice, as unlabeled data may contain out-of-distribution (OOD) samples, i.e., outliers \[[2](http://arxiv.org/abs/2001.07685)\]. These outliers are typically treated as noise, leading to significant performance degradation \[[3](http://arxiv.org/abs/2007.11330)\]. To address this limitation, numerous approaches have been proposed to handle open-set SSL, where the unlabeled data may contain unseen classes \[[4](http://arxiv.org/abs/2105.14148)\].

One early approach, FixMatch, leverages consistency regularization and pseudo-labeling to improve performance on SSL benchmarks \[[5](http://arxiv.org/abs/1905.02249)\]. It generates pseudo-labels for unlabeled data based on high-confidence predictions and trains the model to maintain consistency between different augmented views of the same input \[[6](http://arxiv.org/abs/2108.05617)\]. While FixMatch achieves strong results, it assumes that the labeled and unlabeled data share the same label space, which is not always the case in open-set scenarios \[[7](http://arxiv.org/abs/2109.00650)\].

To address the issue of OOD samples, OpenMatch extends FixMatch by incorporating novelty detection based on one-vs-all (OVA) classifiers. This allows the model to distinguish between inliers and outliers and apply an open-set soft-consistency regularization loss to improve outlier detection \[[8](http://arxiv.org/abs/1610.02242)\]. Similarly, the Multi-Task Curriculum Framework for Open-Set SSL proposes a joint optimization framework that detects OOD samples and trains the model on in-distribution (ID) data simultaneously \[[9](http://arxiv.org/abs/2205.07246)\].

Another approach, Temporal Ensembling, introduces self-ensembling by forming a consensus prediction of unknown labels using outputs from different training epochs \[[10](http://arxiv.org/abs/2102.03526)\]. This method improves performance on benchmarks such as CIFAR-10 and SVHN \[[11](http://arxiv.org/abs/1904.12848)\]. However, it does not explicitly address the presence of OOD samples in the unlabeled data.

Recent work has also focused on improving the robustness of SSL in the presence of OOD samples. For example, the UASD algorithm addresses class distribution mismatch by producing soft targets that avoid error propagation and enables learning from unconstrained unlabelled data \[[12](http://arxiv.org/abs/1606.04586)\]. Similarly, the Trash to Treasure paper proposes a cross-modal matching strategy to detect OOD samples while leveraging their presence for feature learning \[[13](http://arxiv.org/abs/2110.08263)\].

In addition, methods such as MixMatch and ReMixMatch have been proposed to improve SSL performance by combining consistency regularization with data augmentation \[[14](http://arxiv.org/abs/2107.08943)\]. ### <a id='category-consistency-regularization-techniques'></a>Consistency Regularization Techniques: 5 papers found.
Consistency regularization techniques have emerged as a cornerstone in semi-supervised learning (SSL), aiming to improve model performance by leveraging unlabeled data. These methods enforce consistency in model predictions across different data augmentations or models, thereby reducing overfitting to noisy or outlier data \[[1](https://www.semanticscholar.org/paper/f3df804a7eef204b0c4fc4b81166dec9b4abc073)\]. For instance, FixMatch employs pseudo-labeling and strong augmentation to ensure consistency, achieving state-of-the-art results on benchmarks like CIFAR-10 with minimal labeled data \[[2](http://arxiv.org/abs/2001.07685)\]. Similarly, advanced data augmentation strategies such as RandAugment have been shown to significantly enhance consistency training by improving the quality of noised examples, leading to better performance on tasks like text classification and image recognition \[[3](http://arxiv.org/abs/2007.11330)\]. The stochastic nature of techniques like dropout and random max-pooling also plays a role, as they introduce variability in predictions, which can be exploited through unsupervised loss functions that minimize prediction differences across multiple passes of the same sample \[[4](http://arxiv.org/abs/2105.14148)\]. Virtual adversarial training (VAT) further extends this idea by using a virtual adversarial loss to measure local smoothness of the model's predictions, enabling robust semi-supervised learning with low computational cost \[[5](http://arxiv.org/abs/1905.02249)\]. Additionally, frameworks like SimMatch integrate both semantic and instance-level consistency, enhancing performance by leveraging both labeled and unlabeled data more effectively \[[6](http://arxiv.org/abs/2108.05617)\]. These approaches collectively highlight the importance of consistency regularization in improving SSL robustness, particularly in scenarios where labeled data is scarce or contaminated by outliers.

Additionally, SSB proposes a multi-task learning framework that separates features for inlier classification and outlier detection, along with pseudo-negative mining to further improve performance \[[16](https://www.semanticscholar.org/paper/9e4376e0572de32236e408469ffb2173d89eaab5)\]. ### <a id='category-pseudo-labeling-methods'></a>Pseudo-Labeling Methods: 7 papers found.
In the realm of pseudo-labeling methods for semi-supervised learning, several approaches have been proposed to enhance model performance by effectively utilizing unlabeled data. Early methods like MixMatch \[[7](http://arxiv.org/abs/2109.00650)\] combined data augmentation with pseudo-labeling and consistency regularization, achieving state-of-the-art results by generating low-entropy labels for unlabeled data and mixing labeled and unlabeled examples \[[1](https://www.semanticscholar.org/paper/f3df804a7eef204b0c4fc4b81166dec9b4abc073)\]. However, these methods often relied on fixed thresholds for pseudo-label selection, which could lead to suboptimal performance due to inconsistent handling of class distributions \[[9](http://arxiv.org/abs/2205.07246)\]. To address this, methods like Dash \[[2](http://arxiv.org/abs/2001.07685)\] introduced dynamic threshold adjustment during training, selecting only those unlabeled examples with losses below a threshold that evolves with model learning progress. Similarly, FreeMatch \[[9](http://arxiv.org/abs/2205.07246)\] further refined this by introducing self-adaptive thresholding based on the model's learning status, improving convergence and performance, especially when labeled data is scarce. Building on these ideas, FlexMatch \[[4](http://arxiv.org/abs/2105.14148)\] proposed class-specific threshold adjustments, allowing for more nuanced pseudo-label selection and significantly improving performance on datasets with limited labels. More recently, CoMatch \[[5](http://arxiv.org/abs/1905.02249)\] unified multiple approaches by jointly learning class probabilities and embeddings, leveraging smoothness constraints and graph-based contrastive learning to enhance pseudo-label quality. Additionally, ReMixMatch \[[7](http://arxiv.org/abs/2109.00650)\] introduced distribution alignment and augmentation anchoring to improve data efficiency and accuracy, demonstrating superior performance on benchmark datasets with minimal labeled data. These methods collectively highlight the ongoing evolution of pseudo-labeling techniques, emphasizing adaptability, robustness, and efficiency in semi-supervised learning.
