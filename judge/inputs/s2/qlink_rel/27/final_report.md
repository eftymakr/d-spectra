## Related Works

Recent advancements in information retrieval have seen a shift from traditional index-retrieve paradigms to differentiable search indices (DSIs), which unify indexing and retrieval into a single model \[[2](http://arxiv.org/abs/2202.06991)\]. This paradigm eliminates the need for separate indexing and retrieval stages, thereby reducing error accumulation during the retrieval process \[[1](http://arxiv.org/abs/2206.10128)\]. The traditional dense vector search pipeline, which includes representation, indexing, and search stages, has been widely used in deep learning-based methods for table retrieval \[[12](http://arxiv.org/abs/2004.04906)\]. However, it suffers from error accumulation during the representation and indexing phases, which negatively affects search accuracy \[[1](http://arxiv.org/abs/2206.10128)\]. Additionally, insufficient query-table interaction limits semantic alignment and hinders performance improvements \[[1](http://arxiv.org/abs/2206.10128)\].

To address these limitations, several works have explored alternative approaches. For instance, the DSI framework \[[2](http://arxiv.org/abs/2202.06991)\] uses a single transformer model to map queries directly to document identifiers, simplifying the retrieval process. This approach has been further refined with DSI-QG \[[1](http://arxiv.org/abs/2206.10128)\], which generates synthetic queries during indexing to improve semantic alignment. Similarly, the Neural Corpus Indexer (NCI) \[[3](http://arxiv.org/abs/2206.02743)\] proposes an end-to-end deep neural network that generates document identifiers directly for a given query, improving recall performance through techniques like prefix-aware decoding and semantic document identifiers.

Another line of research focuses on autoregressive models for document retrieval. The Autoregressive Search Engines (ASE) \[[5](http://arxiv.org/abs/2204.10628)\] propose generating document identifiers from n-grams, enabling efficient retrieval through a data structure. This approach has shown significant improvements over traditional methods, particularly in passage-level retrieval. Additionally, the ColBERT model \[[6](http://arxiv.org/abs/2004.12832)\] introduces a late interaction architecture that independently encodes queries and documents using BERT, followed by a cheap yet powerful interaction step that models fine-grained similarity. This approach improves both efficiency and effectiveness in document retrieval.

In the context of table retrieval, several works have explored semantic similarity and query-table interaction. The Ad Hoc Table Retrieval \[[11](http://arxiv.org/abs/1802.06159)\] method introduces semantic matching between queries and tables, using multiple semantic spaces and similarity measures to improve retrieval accuracy. The Table2Vec \[[9](http://arxiv.org/abs/1906.00041)\] model employs neural language modeling to embed tabular data into vector spaces, enhancing row and column population tasks. Furthermore, the Dense Passage Retrieval \[[12](http://arxiv.org/abs/2004.04906)\] model demonstrates that dense representations alone can be used for passage retrieval, outperforming traditional sparse models like BM25.

The Differentiable Search Index (DSI) represents a paradigm shift in information retrieval by integrating indexing and retrieval into a single transformer model, eliminating the need for separate components \[[2](http://arxiv.org/abs/2202.06991)\]. This approach allows the model to directly map queries to document identifiers, leveraging the entire corpus representation within its parameters \[[2](http://arxiv.org/abs/2202.06991)\]. However, existing DSI models face challenges such as data distribution mismatches between indexing and retrieval, particularly when handling cross-lingual queries \[[1](http://arxiv.org/abs/2206.10128)\]. To address these issues, researchers have proposed enhancements like DSI-QG, which introduces generated queries during indexing to better align with retrieval-phase queries \[[1](http://arxiv.org/abs/2206.10128)\]. Additionally, the Semantic-Enhanced DSI (SE-DSI) improves document identifier assignment and association learning by incorporating cognitive psychology-inspired strategies, such as elaborative descriptions and rehearsal contents \[[15](http://arxiv.org/abs/2305.15115)\]. These advancements highlight ongoing efforts to refine DSI frameworks, ensuring robust performance across diverse retrieval tasks.
