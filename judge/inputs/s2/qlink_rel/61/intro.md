## Related Works

Personalized outfit generation has been a focal point in recent research, driven by the increasing demand for fashion recommendation systems that can generate compatible and personalized outfits. Early works focused on outfit compatibility and item-level similarity, often using rule-based or heuristic approaches \[[1](http://arxiv.org/abs/1905.01866)\]. However, these methods lacked scalability and personalization. More recent approaches have leveraged deep learning to model compatibility and personalization more effectively.

Several studies have explored the use of deep learning for outfit generation and recommendation. For example, \[[2](http://arxiv.org/abs/1608.03016)\] introduced a machine learning system to compose fashion outfits automatically, using a multimodal multiinstance deep learning approach to score outfit candidates based on appearance and metadata. This work achieved an AUC of 85% for the scoring component. Similarly, \[[3](http://arxiv.org/abs/1807.03133)\] proposed a model that incorporated an unsupervised style extraction module to generate more flexible and interpretable outfits. The model was evaluated on human-generated datasets and showed improved performance in style extraction and outfit generation tasks.

Outfit compatibility modeling has also been a key area of research. \[[4](http://arxiv.org/abs/1803.09196)\] presented an approach to learn type-aware embeddings that respect item type and jointly model item similarity and compatibility. This method was evaluated on a large dataset of 68,306 outfits and showed improvements over state-of-the-art methods. Additionally, \[[5](http://arxiv.org/abs/1712.02662)\] introduced a framework for learning compatibility between items, leveraging user behavior data to improve the accuracy of compatibility predictions.

The integration of user preferences into outfit recommendation has also been explored. \[[6](http://arxiv.org/abs/2005.12566)\] proposed a system that automatically creates capsule wardrobes by selecting a minimal set of items that provide maximal mix-and-match outfits. This work used submodular objective functions to capture visual compatibility, versatility, and user-specific preferences. \[[7](http://arxiv.org/abs/1711.02231)\] further extended this idea by proposing a hierarchical fashion graph network (HFGN) that models relationships among users, items, and outfits simultaneously, achieving significant improvements over existing methods.

In addition to compatibility and personalization, explainability has become an important aspect of outfit recommendation. \[[8](http://arxiv.org/abs/1806.08977)\] introduced a neural outfit recommendation (NOR) framework that simultaneously provides outfit recommendations and generates abstractive comments. This system used a multi-task learning framework to improve both recommendation accuracy and explainability. The generated comments achieved impressive ROUGE and BLEU scores, demonstrating the effectiveness of this approach.
