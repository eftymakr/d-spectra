## Related Works

Maximum Inner Product Search (MIPS) has been a focal point in machine learning and information retrieval, particularly in high-dimensional data applications \[[1](http://arxiv.org/abs/1405.5869)\]. Traditional approaches to MIPS often rely solely on inner product (IP) similarity, which can lead to issues such as local optima and redundant computations \[[1](http://arxiv.org/abs/1405.5869)\]. Alternatively, some methods reduce MIPS to Euclidean metric-based nearest neighbor search through space projection, which can cause topology distortion and information loss \[[1](http://arxiv.org/abs/1405.5869)\]. Despite these divergent paradigms, recent research suggests that there is no inherent binary opposition between IP and Euclidean metrics. Instead, integrating both metrics in indexing and search algorithm design can significantly enhance MIPS performance \[[1](http://arxiv.org/abs/1405.5869)\].

Several studies have explored sub-linear time algorithms for approximate MIPS. Asymmetric LSH (ALSH) was introduced to address this challenge by transforming the problem into approximate near neighbor search, leveraging asymmetric hashing schemes \[[2](http://arxiv.org/abs/1610.03317)\]. This approach allows for efficient sub-linear time hashing for MIPS, which is particularly useful in large-scale applications \[[2](http://arxiv.org/abs/1610.03317)\]. Another work proposed a greedy approach for budgeted MIPS, enabling control over the trade-off between search efficiency and quality \[[3](http://arxiv.org/abs/1202.6101)\]. This method, Greedy-MIPS, demonstrated superior performance compared to state-of-the-art approaches on large datasets \[[3](http://arxiv.org/abs/1202.6101)\].

Graph-based methods have also gained traction in MIPS. The inner-product navigable small world graph (ip-NSW) represents a state-of-the-art method for approximate MIPS, achieving an order of magnitude speedup over baseline methods \[[4](http://arxiv.org/abs/1509.01469)\]. However, its performance is influenced by norm bias, where large norm items are more likely to be the result of MIPS \[[4](http://arxiv.org/abs/1509.01469)\]. To address this, the ip-NSW+ algorithm was proposed, combining angular and inner-product proximity graphs to improve search accuracy and robustness \[[4](http://arxiv.org/abs/1509.01469)\].

Quantization-based approaches, such as those proposed in \[[5](http://arxiv.org/abs/1809.08782)\], offer another avenue for fast approximate MIPS. By quantizing database vectors into multiple subspaces, these methods approximate inner products efficiently without requiring high-dimensional feature space augmentation \[[5](http://arxiv.org/abs/1809.08782)\]. Theoretical analysis supports the effectiveness of these approaches, and experimental results show significant improvements over existing methods \[[5](http://arxiv.org/abs/1809.08782)\].

Norm-Ranging LSH (NORM-RANGING LSH) was introduced to address the limitations of SIMPLE-LSH by partitioning datasets into sub-datasets and building hash indexes independently \[[6](http://arxiv.org/abs/1909.13459)\]. This approach reduces query time complexity and improves search efficiency, particularly in real-world datasets with long-tailed norm distributions \[[6](http://arxiv.org/abs/1909.13459)\].
