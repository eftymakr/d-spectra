## Related Works

Sequential recommendation systems aim to predict the next item a user will interact with, leveraging the sequential nature of user behavior \[[10](http://arxiv.org/abs/2001.04830)\]. Traditional approaches such as Markov Chains (MCs) assume that a user's next action depends only on their last few actions, while Recurrent Neural Networks (RNNs) are capable of capturing longer-term dependencies \[[1](http://arxiv.org/abs/1808.09781)\]. However, RNNs often suffer from computational inefficiency and difficulty in modeling long-range dependencies \[[16](http://arxiv.org/abs/2111.00396)\]. To address these limitations, self-attention based models such as SASRec \[[1](http://arxiv.org/abs/1808.09781)\] and BERT4Rec \[[5](http://arxiv.org/abs/1904.06690)\] have been proposed. These models utilize attention mechanisms to capture both similar and diverse item relationships, enabling more accurate recommendations. However, they often face challenges in handling long sequences due to quadratic computational complexity \[[18](http://arxiv.org/abs/2312.00752)\].

To improve efficiency, models like LinRec \[[18](http://arxiv.org/abs/2312.00752)\] and Mamba \[[16](http://arxiv.org/abs/2111.00396)\] have been introduced. LinRec employs a linear attention mechanism to reduce computational complexity while preserving the learning capabilities of traditional attention mechanisms. Mamba, on the other hand, is a state space model that allows for linear-time sequence modeling by leveraging a selective state space mechanism. This enables efficient processing of long sequences while maintaining model expressiveness \[[16](http://arxiv.org/abs/2111.00396)\]. These models have shown significant improvements in both efficiency and performance compared to traditional attention-based approaches \[[18](http://arxiv.org/abs/2312.00752)\].

Another line of research focuses on incorporating temporal information into sequential recommendation. TiSASRec \[[2](https://www.semanticscholar.org/paper/9c7a455b1e48d01a99e58e884a6c1acb75074ad0)\] explicitly models the time intervals between interactions, allowing for more accurate predictions by considering the actual timestamps of user actions. Similarly, MEANTIME \[[17](http://arxiv.org/abs/2008.08273)\] introduces multi-temporal embeddings to capture diverse temporal patterns in user behavior. These models demonstrate the importance of temporal information in improving recommendation accuracy \[[17](http://arxiv.org/abs/2008.08273)\].

Additionally, graph neural networks have been applied to sequential recommendation to better capture complex item transitions and user preferences \[[22](http://arxiv.org/abs/1811.00855)\]. SR-GNN \[[22](http://arxiv.org/abs/1811.00855)\] models sessions as graph-structured data, enabling the capture of intricate item transitions that are difficult to model with traditional sequential methods. This approach has shown promising results in improving recommendation accuracy \[[22](http://arxiv.org/abs/1811.00855)\].

Moreover, contrastive learning has been utilized to address representation degeneration in sequential recommendation. DuoRec \[[13](http://arxiv.org/abs/2110.05730)\] introduces a contrastive regularization to improve the distribution of item embeddings, leading to more meaningful user representations. This approach has been effective in enhancing recommendation performance, particularly in scenarios with limited training data \[[13](http://arxiv.org/abs/2110.05730)\].
