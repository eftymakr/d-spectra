## Related Works

KV cache management has been a focal point in optimizing large language model (LLM) serving systems, particularly in reducing memory overhead and improving inference efficiency. Early work focused on the fundamental challenges of KV cache, such as its linear growth with sequence length and the resulting memory constraints \[[14](http://arxiv.org/abs/2407.18003)\]. To mitigate these issues, several studies proposed KV cache compression techniques, including quantization, merging, and eviction strategies, to reduce memory footprint while maintaining model accuracy \[[1](http://arxiv.org/abs/2503.16525)\]\[[5](http://arxiv.org/abs/2503.24000)\]\[[13](http://arxiv.org/abs/2407.01527)\]. For instance, KCache \[[1](http://arxiv.org/abs/2503.16525)\] introduced a novel approach to reduce memory usage without requiring any training, achieving a 40% improvement in throughput while preserving accuracy. Similarly, KVMerger \[[9](http://arxiv.org/abs/2407.08454)\] proposed an adaptive KV cache merging method that leverages token-level similarity to reduce memory consumption without significant performance degradation, achieving superior results under constrained budgets.

The importance of workload-aware strategies has also been emphasized in recent studies. For example, PagedAttention \[[12](http://arxiv.org/abs/2309.06180)\] was introduced to address memory fragmentation and enable efficient KV cache sharing across requests, significantly improving throughput and reducing memory waste. This approach inspired the development of vLLM, which demonstrated up to 4× improvement in throughput compared to existing systems. Similarly, the work by \[[15](http://arxiv.org/abs/2503.12491)\] introduced CAKE, a cascading and adaptive KV cache eviction policy that considers layer-specific attention patterns and temporal dynamics, leading to a 10x speedup in decoding latency for long contexts.

Efforts to improve the efficiency of KV cache reuse have also gained traction. KVLink \[[6](http://arxiv.org/abs/2502.16002)\] proposed a method to precompute and concatenate KV caches for shared documents, reducing time-to-first-token (TTFT) by up to 96%. Additionally, SpeCache \[[11](http://arxiv.org/abs/2503.16163)\] leveraged CPU memory to offload KV caches and dynamically fetch them during decoding, enabling high compression ratios without information loss. These approaches highlight the growing interest in optimizing KV cache usage for both memory and computational efficiency.

Recent studies have also explored the economic benefits of KV cache reuse, particularly in cloud environments. For example, \[[4](http://arxiv.org/abs/2503.14647)\] investigated the cost-effectiveness of storing and reusing precomputed KV caches, showing that it can reduce both delay and cloud costs across a range of workloads. This work underscores the importance of considering not only performance but also economic factors when designing KV cache systems.

In summary, while many approaches have been proposed to optimize KV cache usage, there remains a gap in systematically characterizing workload patterns and developing workload-aware policies that can adapt to real-world scenarios. This paper addresses this gap
