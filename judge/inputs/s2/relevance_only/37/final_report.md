## Related Works

Vision Transformers (ViTs) have emerged as a powerful alternative to convolutional neural networks (CNNs) in computer vision tasks, leveraging self-attention mechanisms to capture global context \[[8](http://arxiv.org/abs/2309.02031)\]. However, the deployment of ViTs on hardware platforms, especially FPGAs, remains challenging due to their high computational and memory demands \[[8](http://arxiv.org/abs/2309.02031)\]. Several recent works have focused on optimizing ViT inference through hardware acceleration, algorithmic improvements, and efficient quantization techniques \[[1](https://www.semanticscholar.org/paper/0ade4d722e48379761d17cf1efc05200315c27d9)\]\[[3](http://arxiv.org/abs/2211.08110)\]\[[5](http://arxiv.org/abs/2402.09709)\]\[[7](http://arxiv.org/abs/2403.20230)\]\[[10](http://arxiv.org/abs/2210.06707)\].

Existing hardware accelerators for ViTs often rely on floating-point arithmetic, which is computationally intensive and not well-suited for resource-constrained devices \[[1](https://www.semanticscholar.org/paper/0ade4d722e48379761d17cf1efc05200315c27d9)\]. For instance, Auto-ViT-Acc introduces an FPGA-aware framework that explores mixed-scheme quantization to reduce computational demands while maintaining accuracy \[[2](http://arxiv.org/abs/2208.05163)\]. Similarly, ME-ViT proposes a memory-efficient FPGA accelerator that minimizes off-chip memory access by loading model parameters only once and storing intermediate results on-chip \[[5](http://arxiv.org/abs/2402.09709)\]. This approach significantly improves throughput and power efficiency compared to state-of-the-art accelerators.

Another line of research focuses on reducing the computational complexity of ViTs through pruning and quantization. HeatViT introduces an adaptive token pruning framework that dynamically identifies and removes non-informative tokens, reducing computation by up to 65.3% while maintaining high accuracy \[[3](http://arxiv.org/abs/2211.08110)\]. Similarly, Trio-ViT eliminates the computationally expensive Softmax operation and integrates linear attention with low computational complexity, enabling post-training quantization and acceleration \[[9](http://arxiv.org/abs/2405.03882)\]. These methods demonstrate that reducing the complexity of ViT operations can lead to significant performance gains.

Moreover, several works have explored the use of hardware-friendly quantization schemes to improve the efficiency of ViT inference. Q-ViT introduces a fully quantized ViT model that uses an information rectification module (IRM) and distribution-guided distillation (DGD) to mitigate performance degradation caused by low-bit quantization \[[10](http://arxiv.org/abs/2210.06707)\]. This approach achieves up to 6.14x speedup and maintains high accuracy on the ImageNet dataset. Similarly, BSViT employs dynamic patch and weight bit-group quantization to balance workload across processing elements (PEs) and improve energy efficiency \[[16](https://www.semanticscholar.org/paper/b2e51759f910101691039846bec4401a85b53309)\].

In addition to algorithmic improvements, recent works have focused on optimizing the hardware architecture for ViT inference. HDViT proposes a heterogeneous FPGA accelerator that combines multiple processing engines (PEs) and employs a hybrid dataflow mapping strategy to reduce data transmission granularity and improve hardware utilization \[[1](https://www.semanticscholar.org/paper/0ade4d722e48379761d17cf1efc05200315c27d9)\]. ### <a id='category-token-pruning-and-complexity-reduction'></a>Token Pruning and Complexity Reduction: 6 papers found.
Vision Transformers (ViTs) have demonstrated strong performance in computer vision tasks by effectively capturing global context, but their complex arithmetic operations, such as Softmax and LayerNorm, pose challenges for hardware acceleration due to their sensitivity to model accuracy \[[15](http://arxiv.org/abs/2205.11397)\]. Existing methods often rely on parallelism in matrix multiplication while keeping these operations on the CPU, leading to suboptimal performance due to communication overhead \[[15](http://arxiv.org/abs/2205.11397)\]. To address this, recent works have focused on reducing computational complexity through token pruning and complexity reduction techniques \[[3](http://arxiv.org/abs/2211.08110)\]. For example, HeatViT introduces a hardware-efficient token pruning framework that dynamically identifies and consolidates non-informative tokens, achieving significant computation reduction while maintaining high accuracy \[[3](http://arxiv.org/abs/2211.08110)\]. Similarly, ReViT leverages hierarchical visual semantics to accelerate ViTs, improving both speed and energy efficiency by exploiting semantic-aware attention mechanisms \[[6](https://www.semanticscholar.org/paper/f47b726ad00e1a93adc5b3e266c71d75bb05e1ff)\]. The work in \[[13](http://arxiv.org/abs/2403.14047)\] proposes a comprehensive algorithm-hardware codesign that combines static weight pruning with dynamic token pruning, reducing computation complexity by up to 3.4× with minimal accuracy drop. Additionally, ViTCoD introduces a dedicated algorithm and accelerator co-design framework, enabling efficient attention computation through fixed sparse patterns and reducing dominant data movement costs \[[14](http://arxiv.org/abs/2210.09573)\]. SuperViT further reduces computational costs by training a single model capable of handling varying input sizes and preserving informative tokens, achieving performance improvements with reduced FLOPs \[[15](http://arxiv.org/abs/2205.11397)\]. These approaches collectively highlight the importance of reducing computational complexity and improving hardware efficiency in ViT accelerators.

### <a id='category-memory-efficiency-in-fpga-accelerators'></a>Memory Efficiency in FPGA Accelerators: 4 papers found.
Vision Transformers (ViTs) have gained significant traction in computer vision due to their ability to capture global context, yet their deployment on hardware platforms like FPGAs remains challenging due to high computational demands and memory usage \[[1](https://www.semanticscholar.org/paper/0ade4d722e48379761d17cf1efc05200315c27d9)\]. Existing accelerators often suffer from frequent off-chip memory access, which limits throughput and introduces bottlenecks, especially in edge devices with limited bandwidth \[[1](https://www.semanticscholar.org/paper/0ade4d722e48379761d17cf1efc05200315c27d9)\]. To address these issues, several works have focused on improving memory efficiency and hardware utilization. For instance, ME-ViT introduces a single-load policy and a memory-efficient processing element (ME-PE) to minimize memory traffic and improve throughput and power efficiency \[[1](https://www.semanticscholar.org/paper/0ade4d722e48379761d17cf1efc05200315c27d9)\]. Similarly, EfficientViT, a Convolution-Transformer hybrid architecture, has been targeted by FPGA accelerators that aim to enhance hardware efficiency through reconfigurable architectures and time-multiplexed dataflows \[[2](http://arxiv.org/abs/2208.05163)\]. Additionally, CHOSEN proposes a software-hardware co-design framework that includes multi-kernel design, approximate non-linear functions, and efficient logic block utilization to maximize performance and memory efficiency \[[3](http://arxiv.org/abs/2211.08110)\]. ViTA, another accelerator, targets resource-constrained edge devices by reducing off-chip memory accesses through head-level pipelining and inter-layer optimizations, achieving high hardware utilization and low power consumption \[[4](http://arxiv.org/abs/2405.00314)\]. These approaches collectively highlight the ongoing efforts to optimize ViT inference on FPGAs by addressing memory bandwidth limitations and improving hardware efficiency through innovative architectural and algorithmic designs.
