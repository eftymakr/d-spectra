## Related Works

De novo genome assembly has been a focal point of computational biology for decades, driven by the need to reconstruct genomes from short, overlapping DNA sequences without a reference. Early approaches relied on overlap-layout-consensus (OLC) methods, which involve comparing all reads pairwise, leading to quadratic computational complexity \[[18](https://www.semanticscholar.org/paper/7279acd9c61a8de019ea2d55d23124dfbb6b5269)\]. This limitation has spurred the development of de Bruijn graph-based algorithms, which offer more efficient handling of short reads by reducing the problem to graph traversal \[[11](http://arxiv.org/abs/1106.2603)\]. However, these methods still face challenges in terms of memory usage and scalability, particularly for large genomes \[[14](http://arxiv.org/abs/1008.2555)\].

Several studies have addressed the computational and memory bottlenecks in de novo assembly. For instance, SparseAssembler and its successor, SparseAssembler2, introduced sparse k-mer graphs to reduce memory consumption by up to 90% compared to traditional de Bruijn graph-based assemblers \[[11](http://arxiv.org/abs/1106.2603)\]\[[12](http://arxiv.org/abs/1108.3556)\]. These methods skip intermediate k-mers, thereby significantly lowering memory requirements while maintaining assembly quality. Additionally, they incorporate denoising algorithms to mitigate the impact of sequencing errors \[[11](http://arxiv.org/abs/1106.2603)\]. Similarly, SOAPdenovo2 improved upon earlier versions by optimizing memory usage and increasing contig and scaffold lengths, achieving better performance in terms of accuracy and coverage \[[9](https://www.semanticscholar.org/paper/f8d1052e2c9d1cdd63093427ccc9169e848d777d)\].

Distributed computing frameworks have also played a crucial role in enabling the assembly of large genomes. PPA-assembler, for example, leverages the Pregel framework to perform distributed de Bruijn graph-based assembly, demonstrating superior performance compared to existing assemblers \[[2](http://arxiv.org/abs/1801.04453)\]. Similarly, HipMER utilizes efficient parallelization of the Meraculous code to handle extreme-scale genome assembly on supercomputers with thousands of cores \[[1](http://arxiv.org/abs/1705.11147)\]. These approaches highlight the importance of parallelism and distributed memory systems in overcoming the computational demands of de novo assembly.

Recent advancements in hardware-software co-design have further enhanced the efficiency of genome assembly. For example, the diBELLA 2D pipeline introduced distributed-memory algorithms for overlap detection and layout simplification, achieving near-linear scaling with over 80% parallel efficiency \[[6](http://arxiv.org/abs/2010.10055)\]. Similarly, the development of FPGA-based accelerators for genome analysis has shown promise in reducing data movement bottlenecks and improving energy efficiency \[[25](http://arxiv.org/abs/2106.06433)\]. These innovations underscore the growing trend of integrating hardware and software optimizations to address the challenges of de novo assembly.
