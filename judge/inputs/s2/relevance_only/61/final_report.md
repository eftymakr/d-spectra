## Related Works

Personalized outfit generation has been a focal point in recent fashion recommendation research, with a growing emphasis on generating visually compatible and personalized outfits. Early approaches primarily relied on pre-defined outfit recommendations or personalized outfit composition, which were constrained by existing fashion products, limiting their ability to address diverse user needs \[[3](http://arxiv.org/abs/2402.17279)\]. This limitation has spurred the development of generative models that can create novel fashion items tailored to individual preferences \[[11](https://www.semanticscholar.org/paper/61c15a1723d210ac75824bf185b547cee37c70af)\]. 

Several studies have explored the use of generative adversarial networks (GANs) for outfit generation, aiming to improve compatibility and personalization. For instance, OutfitGAN introduces a compatibility network to ensure reasonable compatibility among generated items, while also using a GAN to generate new fashion items \[[11](https://www.semanticscholar.org/paper/61c15a1723d210ac75824bf185b547cee37c70af)\]. Similarly, POG leverages a Transformer architecture to connect user preferences with outfit generation, demonstrating strong performance on both compatibility and personalization metrics \[[2](http://arxiv.org/abs/1905.01866)\]. These models, however, often rely on supervised learning paradigms, which may limit their adaptability to diverse user preferences \[[21](http://arxiv.org/abs/2008.01780)\].

Recent advances have shifted towards diffusion models, which offer higher fidelity and greater control over the generation process. DiFashion, for example, employs diffusion models to generate multiple fashion images in parallel, ensuring compatibility and personalization through carefully designed conditions and Classifier-Free-Guidance \[[3](http://arxiv.org/abs/2402.17279)\]. This approach aligns with the broader trend of using diffusion models for generative tasks, as they have shown superior performance in image generation compared to traditional GANs \[[3](http://arxiv.org/abs/2402.17279)\].

To address the challenge of aligning generated content with human preferences, DreamDPO introduces a direct preference optimization framework that integrates human feedback into the generation process. By using pairwise comparisons and a preference-driven loss function, DreamDPO reduces reliance on precise pointwise evaluations and enables fine-grained controllability \[[5](http://arxiv.org/abs/2502.04370)\]. This approach is particularly relevant to the current work, as it provides a method for refining generative models using automatically generated feedback without the need for task-specific reward functions \[[1](https://www.semanticscholar.org/paper/ca3ad34ff2652cd922c3476514a758674bc7e76b)\].

In addition to generative models, several studies have focused on improving the compatibility and personalization of generated outfits. For example, the work by \[[19](https://www.semanticscholar.org/paper/c16dbfb1303c5dce657e29a84a12ee8a43caedcd)\] introduces a graph-based approach to model the visual relationships between items in an outfit, capturing the overall compatibility of the set. This method uses a dot-attention graph neural network to generate a final outfit embedding, which is then compared with user embeddings to assess compatibility \[[19](https://www.semanticscholar.org/paper/c16dbfb1303c5dce657e29a84a12ee8a43caedcd)\]. Similarly, the OutfitTransformer framework models outfits as unordered sets of items and uses self-attention mechanisms to learn compatibility \[[17](https://www.semanticscholar.org/paper/4d431b88f7dfe1e75b0e23bb21fc9dd378b15cf2)\].

[Snippet]: «Recent advances in multi-modal vision and language tasks enable a new set of applications. In this paper, we consider the task of generating natural language fashion feedback on outfit images. We collect a unique dataset, which contains outfit images and corresponding positive and constructive fashion feedback. We treat each feedback type separately, and train deep generative encoder-decoder models with visual attention, similar to the standard image captioning pipeline. Following this approach, the generated sentences tend to be too general and non-informative. We propose an alternative decoding technique based on the Maximum Mutual Information objective function, which leads to more diverse and detailed responses. We evaluate our model with common language metrics, and also show human evaluation results. This technology is applied within the ``Alexa, how do I look?'' feature, publicly available in Echo Look devices.»
