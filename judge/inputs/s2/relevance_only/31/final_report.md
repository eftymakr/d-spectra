## Related Works

Recent advances in pre-training methods have inspired researchers to apply these techniques to DNA sequence analysis. However, pure sequence-based pre-training often lacks sufficient information to capture the complex regulatory mechanisms that govern DNA function \[[1](http://arxiv.org/abs/2307.05628)\]. This limitation has motivated the exploration of alternative approaches that incorporate additional genomic data modalities, such as chromatin accessibility, to enhance model performance \[[1](http://arxiv.org/abs/2307.05628)\]. 

Several studies have investigated self-supervised pre-training for sequential data, demonstrating that pre-training on large amounts of unlabeled data can improve downstream task performance \[[2](http://arxiv.org/abs/2007.00800)\]. For example, contrastive predictive coding has been used to learn useful representations from high-dimensional data, achieving strong performance across multiple domains including speech, images, and text \[[5](http://arxiv.org/abs/1807.03748)\]. Similarly, self-supervised learning has been applied to remote sensing image change detection, where semantic information is incorporated during pre-training to improve spatial sensitivity and generalization \[[8](http://arxiv.org/abs/2205.13769)\]. These methods highlight the potential of leveraging unlabeled data to learn robust representations, especially when labeled data is scarce.

In the context of DNA analysis, DNAGPT was proposed as a generalized pre-trained model trained on over 200 billion base pairs from mammals. It incorporates tasks such as binary classification and numerical regression to better handle diverse DNA analysis tasks \[[1](http://arxiv.org/abs/2307.05628)\]. Additionally, Markov models have been used to describe complete genomes, with multiple competing models of different orders achieving performance comparable to state-of-the-art DNA compression methods \[[4](https://www.semanticscholar.org/paper/db85f5cf0d7b04fef5bb8cb38df9aeb94f78e95a)\]. These approaches emphasize the importance of modeling local and non-local dependencies in genomic sequences.

Similarly, graph-based pre-training methods, such as GCC, have been developed to learn transferable structural representations across multiple graphs \[[17](http://arxiv.org/abs/2006.09963)\].
