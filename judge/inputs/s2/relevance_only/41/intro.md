## Related Works

Cold start latency remains a critical challenge in serverless computing, impacting end-to-end performance and resource utilization \[[1](http://arxiv.org/abs/2406.11734)\]. Several studies have explored mitigation strategies, focusing on container warming, prediction-based resource allocation, and optimization of function initialization. For instance, LibProf introduces a Python profiler that identifies inefficient library initializations through dynamic program analysis and statistical sampling, leading to up to 2.26x speedup in cold-start execution time \[[1](http://arxiv.org/abs/2406.11734)\]. Similarly, the LCS approach employs an LRU-based warm container selection strategy to reduce cold start occurrences by keeping containers alive for longer periods, achieving a 48% improvement over MRU-based methods \[[15](https://www.semanticscholar.org/paper/d45518ce5741587c4c37ccbc5e74b3fcfd6f80f1)\]. 

A reinforcement learning-based approach, as proposed in \[[3](https://www.semanticscholar.org/paper/27cd21426fe51167dd6ac79d1c83db55a07a2046)\], aims to adaptively manage container warm-up and pre-warm strategies by learning function invocation patterns over time. This method leverages a two-layer adaptive system, combining reinforcement learning for optimal warm-up timing and LSTM for future invocation prediction, resulting in a 22.65% improvement in execution invocations on prewarmed containers \[[3](https://www.semanticscholar.org/paper/27cd21426fe51167dd6ac79d1c83db55a07a2046)\]. Additionally, the ATOM framework utilizes deep reinforcement learning to predict cold start events and optimize resource management in edge computing environments, demonstrating superior prediction accuracy compared to traditional warm-start approaches \[[8](https://www.semanticscholar.org/paper/891a89fad669dc7d107ad2d5a047b288b5cc9832)\]. 

Time series forecasting has also been applied to mitigate cold start latency. The SARIMA model, as implemented in \[[17](https://www.semanticscholar.org/paper/7412ca941221b24fe57ae995a3ce5db100cf068b)\], predicts function call volumes based on historical data, enabling dynamic resource allocation and reducing cold start times compared to static threshold-based methods. Similarly, the PBA approach, which uses SARIMA for prediction-based autoscaling, outperforms the default HPA in Kubernetes by minimizing resource wastage and improving response times \[[12](http://arxiv.org/abs/2206.15176)\]. 

Recent work on cold start prediction and provisioning optimization, such as the ABiGRU model \[[16](https://www.semanticscholar.org/paper/69cb9bb1154a606a16bdcebb22feb8a05003913a)\], leverages deep learning to forecast cold start occurrences using real-time features like invocation frequency, cold start indicators, and historical data. This model achieves high accuracy, with an F1 score of 90.28% and an MCC of 82.28%, demonstrating its effectiveness in reducing cold start latency in AWS Lambda environments \[[16](https://www.semanticscholar.org/paper/69cb9bb1154a606a16bdcebb22feb8a05003913a)\]. 

Furthermore, the SPES scheduler optimizes serverless function provision by leveraging invocation prediction and categorizing functions based on their invocation patterns, reducing cold start rates by 49.77% and memory waste by 56.43% \[[9](http://arxiv.org/abs/2403.17574)\].
