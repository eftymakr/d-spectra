## Related Works

Unsupervised domain adaptation (UDA) for semantic segmentation has been extensively studied to address the challenge of transferring knowledge from a labeled source domain to an unlabeled target domain \[[1](http://arxiv.org/abs/2405.19899)\]. Traditional UDA methods typically assume that the label sets of the source and target domains are known and share a common set of classes, which limits their applicability in real-world scenarios where novel or private classes may exist in the target domain \[[2](http://arxiv.org/abs/2110.10639)\]. This assumption leads to performance degradation when private classes are present, as these classes are not accounted for during the adaptation process \[[3](https://www.semanticscholar.org/paper/5f9ce93f82dcd9b0f9ffe4274b81682f40d86253)\].

To mitigate this limitation, several approaches have been proposed. For instance, \[[4](https://www.semanticscholar.org/paper/6518b0e6334c6ffb9b94c551c57ad79c7008cbb5)\] introduces a method that leverages adversarial learning to bridge the domain gap while preserving class-specific information. This approach focuses on aligning the feature distributions between the source and target domains, but it does not explicitly address the issue of private classes. Similarly, \[[5](http://arxiv.org/abs/2012.12545)\] proposes a framework that uses pseudo-labels to improve adaptation, but it assumes that the target domain contains only known classes. These methods are limited in their ability to handle unknown or private classes in the target domain \[[6](http://arxiv.org/abs/2103.15467)\].

In contrast, \[[7](http://arxiv.org/abs/1904.01886)\] introduces a novel approach called Universal Domain Adaptation (UDA), which does not require prior knowledge of the label sets. This method is designed to handle both common and private classes by classifying target samples as either belonging to the common label set or being marked as unknown. This aligns with the problem formulation of the proposed UniDA-SS approach, which aims to handle the presence of private classes in the target domain \[[8](http://arxiv.org/abs/2407.17101)\]. The work in \[[9](http://arxiv.org/abs/2211.07609)\] further explores the use of uncertainty-aware consistency regularization to improve the reliability of pseudo-labels, which is crucial for robust domain adaptation in the presence of unknown classes.

Additionally, \[[10](https://www.semanticscholar.org/paper/a0ee98646f8244028a1a85f23bc100ec5b3a3815)\] proposes a framework that leverages domain-specific prototypes to enhance the separation of common and private classes. This is similar to the Domain-Specific Prototype-based Distinction (DSPD) component in UniMAP, which aims to improve the identification of common classes across domains \[[11](http://arxiv.org/abs/2005.10876)\]. The work in \[[12](http://arxiv.org/abs/2004.08878)\] also addresses the issue of class imbalance and uncertainty in pseudo-labels, which is a critical challenge in UDA for semantic segmentation \[[13](https://www.semanticscholar.org/paper/2b21347a62ecfaa30e0e6a371a6b335b3159b0df)\].

### <a id='category-domain-adaptation-for-semantic-segmentation'></a>Domain Adaptation for Semantic Segmentation: 22 papers found.
Unsupervised domain adaptation for semantic segmentation (UDA-SS) has been extensively studied, with a focus on transferring knowledge from labeled source data to unlabeled target data while addressing domain discrepancies \[[1](http://arxiv.org/abs/2405.19899)\]. Traditional methods assume a shared label space between domains, which limits their applicability in real-world scenarios where novel categories may emerge \[[1](http://arxiv.org/abs/2405.19899)\]. To overcome this limitation, recent works have explored open-set domain adaptation (OSDA-SS), where the target domain includes unknown classes \[[1](http://arxiv.org/abs/2405.19899)\]. For instance, BUS \[[1](http://arxiv.org/abs/2405.19899)\] introduces a boundary and unknown shape-aware approach to accurately discern boundaries between known and unknown classes using a novel dilation-erosion-based contrastive loss. Similarly, OpenReMix \[[1](http://arxiv.org/abs/2405.19899)\] proposes a domain mixing augmentation method to improve shape detection of both known and unknown classes. Other approaches, such as SSDDA \[[2](http://arxiv.org/abs/2110.10639)\], focus on semi-supervised domain adaptation (SSDA), leveraging a small amount of labeled target data to bridge the domain gap. Additionally, methods like CDEA \[[10](https://www.semanticscholar.org/paper/a0ee98646f8244028a1a85f23bc100ec5b3a3815)\] and PiPa++ \[[8](http://arxiv.org/abs/2407.17101)\] emphasize context and detail enhancement to improve performance on real-world data. Furthermore, source-free domain adaptation frameworks, such as SFDA \[[14](http://arxiv.org/abs/2103.16372)\], have been proposed to address privacy concerns by not requiring access to the source domain data during adaptation. These methods often employ adversarial learning, self-training, and pseudo-label refinement to align feature distributions and improve generalization \[[6](http://arxiv.org/abs/2103.15467)\]\[[12](http://arxiv.org/abs/2004.08878)\]. The proposed UniMAP framework builds upon these advancements by introducing domain-specific prototype-based distinction and target-based image matching to enhance common class identification and reduce confusion with private classes \[[1](http://arxiv.org/abs/2405.19899)\].

[Snippet]: «Multi-target unsupervised domain adaptation (UDA) aims to learn a unified model to address the domain shift between multiple target domains. Due to the difficulty of obtaining annotations for dense predictions, it has recently been introduced into cross-domain semantic segmentation. Collectively, we refer to this data as"external". To address these challenges, we introduce a new strategy called"multi-target UDA without external data"for semantic segmentation. Specifically, the segmentation model is initially trained on the external data. Then, it is adapted to a new unseen target domain without accessing any external data. This approach is thus more scalable than existing solutions and remains applicable when external data is inaccessible. We demonstrate this strategy using a simple method that incorporates self-distillation and adversarial learning, where knowledge acquired from the external data is preserved during adaptation through"one-way"adversarial learning. Extensive experiments in several synthetic-to-real and real-to-real adaptation settings on four benchmark urban driving datasets show that our method significantly outperforms current state-of-the-art solutions, even in the absence of external data. [Snippet]: «Domain adaptation aims to transfer knowledge in the presence of the domain gap. Existing domain adaptation methods rely on rich prior knowledge about the relationship between the label sets of source and target domains, which greatly limits their application in the wild. This paper introduces Universal Domain Adaptation (UDA) that requires no prior knowledge on the label sets. For a given source label set and a target label set, they may contain a common label set and hold a private label set respectively, bringing up an additional category gap. UDA requires a model to either (1) classify the target sample correctly if it is associated with a label in the common label set, or (2) mark it as ``unknown'' otherwise. More importantly, a UDA model should work stably against a wide spectrum of commonness (the proportion of the common label set over the complete label set) so that it can handle real-world problems with unknown target label sets. To solve the universal domain adaptation problem, we propose Universal Adaptation Network (UAN). It quantifies sample-level transferability to discover the common label set and the label sets private to each domain, thereby promoting the adaptation in the automatically discovered common label set and recognizing the ``unknown'' samples successfully. A thorough evaluation shows that UAN outperforms the state of the art closed set, partial and open set domain adaptation methods in the novel UDA setting.»
