## Related Works

KV cache management has emerged as a critical technique for accelerating large language model (LLM) inference by reducing redundant computations and improving memory utilization \[[2](http://arxiv.org/abs/2412.19442)\]. Prior work has primarily focused on token-level, model-level, and system-level optimizations to enhance KV reuse \[[2](http://arxiv.org/abs/2412.19442)\]. Token-level strategies include KV cache selection, budget allocation, merging, quantization, and low-rank decomposition \[[2](http://arxiv.org/abs/2412.19442)\]. Model-level optimizations focus on architectural innovations and attention mechanisms to enhance KV reuse \[[2](http://arxiv.org/abs/2412.19442)\]. System-level approaches address memory management, scheduling, and hardware-aware designs to improve efficiency across diverse computing environments \[[2](http://arxiv.org/abs/2412.19442)\].

Several studies have explored KV cache compression to reduce memory footprint and improve inference speed. MiniCache proposes a method to compress the KV cache across layers by leveraging the high similarity between adjacent layers in the middle-to-deep portion of LLMs \[[8](http://arxiv.org/abs/2405.14366)\]. This approach reduces the memory footprint by up to 41% while maintaining near-lossless performance \[[8](http://arxiv.org/abs/2405.14366)\]. Similarly, VL-Cache introduces a sparsity and modality-aware compression method tailored for vision-language models (VLMs), achieving a 90% reduction in memory footprint while preserving accuracy \[[9](http://arxiv.org/abs/2410.23317)\]. These methods demonstrate the effectiveness of compression techniques in enabling efficient LLM inference.

KV cache eviction strategies have also been extensively studied to manage memory constraints. CAKE introduces a cascading and adaptive eviction approach that considers layer-specific preferences and temporal dynamics, achieving a 3.2% cache usage while maintaining model performance \[[5](http://arxiv.org/abs/2503.12491)\]. NACL proposes a general framework for long-context KV cache eviction, combining accurate attention score statistics with diversified random eviction strategies to improve performance on both short- and long-text tasks \[[12](http://arxiv.org/abs/2408.03675)\]. These methods highlight the importance of workload-aware eviction policies in balancing memory usage and model accuracy.

Recent work has also explored the use of public cloud services to store and reuse precomputed KV caches, offering potential cost savings and performance improvements \[[3](http://arxiv.org/abs/2503.14647)\]. CacheGen introduces a custom tensor encoder to compress KV caches into compact bitstream representations, reducing the size by 3.5–4.3x and the total delay by 3.2–3.7x \[[6](http://arxiv.org/abs/2310.07240)\]. These findings underscore the potential of cloud-based KV cache reuse in reducing both delay and cost for LLM serving.

The effectiveness of KV cache reuse has been further validated by studies such as KVLink, which precomputes KV caches for documents and concatenates them during inference, reducing time-to-first-token by up to 96% \[[4](http://arxiv.org/abs/2502.16002)\].
