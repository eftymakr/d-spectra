## Related Works

Long-tailed recognition remains a challenging problem in computer vision due to the imbalance in class distribution, where a few head classes dominate the dataset while most tail classes contain very few samples \[[1](http://arxiv.org/abs/2403.06151)\]. Existing methods have primarily focused on data reweighing, resampling, or supervised contrastive learning (SCL) to address this issue \[[2](http://arxiv.org/abs/2306.15925)\]. However, these approaches often fail to effectively capture the complex relationships between classes and suffer from poor generalization on tail classes \[[3](http://arxiv.org/abs/2309.11177)\].

SCL has been widely adopted for visual representation learning due to its ability to pull positive samples and push away negative ones \[[4](http://arxiv.org/abs/2305.01160)\]. However, in the context of long-tailed recognition, treating all positive samples equally leads to biased optimization for intra-category distances \[[5](http://arxiv.org/abs/2207.09052)\]. This issue is further exacerbated by the lack of consideration for the semantic relationships among negative samples, which are ignored by SCL \[[6](http://arxiv.org/abs/2406.02223)\]. To address these limitations, several works have proposed modifications to SCL, such as decoupling the training objective to optimize the relations of different types of positives separately \[[7](http://arxiv.org/abs/2211.11938)\].

One approach, decoupled contrastive learning, introduces a patch-based self-distillation strategy to transfer knowledge from head to tail classes \[[8](http://arxiv.org/abs/2111.13998)\]. This method aims to alleviate the under-representation of tail classes by leveraging shared visual patterns among instances \[[9](http://arxiv.org/abs/2410.06109)\]. Another work, subclass-balancing contrastive learning (SBCL), clusters head classes into multiple subclasses to enforce a two-layer class hierarchy, which helps maintain semantic substructures while avoiding overemphasis on tail classes \[[10](http://arxiv.org/abs/2306.13275)\].

Additionally, contrastive learning has been extended to graph-based models to address long-tailed recognition in recommendation systems \[[11](http://arxiv.org/abs/2411.09453)\]. This method introduces a long-tail augmentation approach to enhance tail nodes and generates contrastive views based on the resulting augmented graph \[[12](http://arxiv.org/abs/2309.07186)\]. Similarly, probabilistic contrastive learning (ProCo) estimates the distribution of samples from each class in the feature space and samples contrastive pairs accordingly, which is particularly useful in class-imbalanced scenarios \[[13](http://arxiv.org/abs/2407.12568)\].

In contrast to these methods, some works have focused on the theoretical foundations of contrastive learning in long-tailed settings. For instance, one study showed that the fundamental issue with contrastive learning in long-tailed tasks is that it maximizes mutual information between latent features and input data, without considering ground-truth labels \[[14](http://arxiv.org/abs/2309.16135)\]. This led to the development of a new loss function that integrates contrastive learning with logit adjustment to achieve state-of-the-art performance \[[15](http://arxiv.org/abs/2408.00483)\].

### <a id='category-long-tailed-recognition-challenges'></a>Long-tailed Recognition Challenges: 13 papers found.
The long-tailed recognition problem, where a few dominant classes have abundant samples while most classes are severely underrepresented, poses significant challenges for deep learning models \[[1](http://arxiv.org/abs/2403.06151)\]. This imbalance leads to biased predictions towards majority classes and poor generalization for minority classes \[[2](http://arxiv.org/abs/2306.15925)\]. Previous approaches have focused on data augmentation, re-balancing strategies, or class-wise re-weighting to address this issue \[[3](http://arxiv.org/abs/2309.11177)\]. However, these methods often fail to improve feature representations due to limited training data for tail classes \[[4](http://arxiv.org/abs/2305.01160)\]. To mitigate this, researchers have proposed contrastive learning frameworks, which aim to improve feature distribution and class separability \[[5](http://arxiv.org/abs/2207.09052)\]. For example, supervised contrastive learning (SCL) has shown performance gains but suffers from poor uniformity due to imbalanced data distribution, leading to poor separability of minority class samples in the feature space \[[6](http://arxiv.org/abs/2406.02223)\]. To address this, targeted supervised contrastive learning (TSC) was introduced, which generates uniformly distributed targets on a hypersphere and forces features to converge towards these targets, improving class boundaries and generalization \[[7](http://arxiv.org/abs/2211.11938)\]. Additionally, methods like saliency masked contrastive learning and latent categories-based recognition have been proposed to enhance feature representation by leveraging shared latent features or masked image processing \[[8](http://arxiv.org/abs/2111.13998)\]. Furthermore, continual learning strategies have been explored to sequentially learn head and tail classes without forgetting prior knowledge, offering a principled approach to long-tailed recognition \[[9](http://arxiv.org/abs/2410.06109)\]. These approaches highlight the ongoing efforts to improve generalization and performance in long-tailed recognition by addressing both class-wise and attribute-wise imbalances \[[10](http://arxiv.org/abs/2306.13275)\].

### <a id='category-theoretical-foundations-of-contrastive-learning'></a>Theoretical Foundations of Contrastive Learning: 1 papers found.
Contrastive learning (CL) methods have gained significant attention for their ability to learn robust data representations through self-supervised learning, where an encoder contrasts positive samples against multiple negative ones using a one-vs-many softmax cross-entropy loss \[[19](http://arxiv.org/abs/2105.03746)\]. While these methods have achieved promising results, especially on large-scale datasets like ImageNet, they often assume that augmented views from the same instance are positive pairs, while views from other instances are negative \[[19](http://arxiv.org/abs/2105.03746)\]. This binary partitioning of samples may limit the model's ability to generalize, particularly on real-world datasets where data distribution is less curated \[[19](http://arxiv.org/abs/2105.03746)\]. To address these limitations, recent work has proposed strategies that consider the intra-contrastive relationships within positive and negative pairs, aiming to improve generalization and robustness \[[19](http://arxiv.org/abs/2105.03746)\]. For instance, the doubly CL strategy introduces contrastive attraction and contrastive repulsion (CACR), which not only attracts distant positive samples but also repels closer negative ones, thereby narrowing the gap between the sampled and true distribution \[[19](http://arxiv.org/abs/2105.03746)\]. This approach has shown better performance on imbalanced datasets, highlighting the importance of refining the contrastive learning framework to handle real-world data more effectively.
