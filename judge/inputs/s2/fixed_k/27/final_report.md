## Related Works

Natural language (NL)-driven table discovery has gained significant attention in recent years due to the increasing availability of tabular data and the need for efficient retrieval mechanisms. Traditional approaches rely on dense vector search pipelines, which involve representation, indexing, and search stages \[[12](http://arxiv.org/abs/1706.02427)\]. However, these methods face limitations such as error accumulation during representation and indexing, and insufficient query-table interaction that hinders semantic alignment \[[1](http://arxiv.org/abs/2305.02073)\]. To address these challenges, recent works have explored alternative paradigms, including differentiable search indexes and neural architectures that unify indexing and retrieval \[[13](http://arxiv.org/abs/2202.06991)\].

The Differentiable Search Index (DSI) is a novel framework that integrates indexing and retrieval into a single model, enabling direct query-to-docid mapping without the need for separate indexing and retrieval components \[[13](http://arxiv.org/abs/2202.06991)\]. This approach simplifies the retrieval process and avoids error propagation that occurs in traditional pipelines. However, early implementations of DSI faced challenges in distinguishing relevant documents from random ones, impacting retrieval effectiveness \[[1](http://arxiv.org/abs/2305.02073)\]. Subsequent work has focused on improving DSI by addressing data distribution mismatches between indexing and retrieval, particularly in cross-lingual settings \[[3](http://arxiv.org/abs/2206.10128)\]. For example, DSI-QG introduces a query generation mechanism during indexing, allowing the model to learn connections between queries and document identifiers, thereby improving retrieval performance \[[3](http://arxiv.org/abs/2206.10128)\].

In the context of table discovery, several approaches have been proposed to enhance semantic alignment between queries and tables. Neural Enquirer, for instance, uses a neural network architecture to execute natural language queries on knowledge bases, enabling the retrieval of answers from structured data \[[6](http://arxiv.org/abs/1512.00965)\]. Similarly, Table2Vec employs neural language modeling techniques to embed tabular data into vector spaces, which are then used to improve table retrieval performance \[[14](http://arxiv.org/abs/1906.00041)\]. These methods, however, often rely on separate representation and search stages, which can lead to error accumulation \[[12](http://arxiv.org/abs/1706.02427)\].

To further improve semantic alignment, recent work has explored the use of semantic table retrieval frameworks that consider multiple semantic spaces and similarity measures for matching queries and tables \[[10](http://arxiv.org/abs/2105.06365)\]. These approaches aim to capture richer semantic representations and improve the accuracy of table retrieval. Additionally, the nlcTables dataset has been introduced to benchmark NL-conditional table discovery, providing a comprehensive set of queries and relevance annotations for evaluating different methods \[[2](http://arxiv.org/abs/2504.15849)\].

In the realm of continual learning, the issue of catastrophic forgetting has been addressed through parameter isolation strategies, which allow models to update their parameters without degrading performance on previously learned tasks \[[16](http://arxiv.org/abs/2410.12164)\]. ### <a id='category-differentiable-search-index-frameworks'></a>Differentiable Search Index Frameworks: 5 papers found.
Differentiable Search Index (DSI) frameworks have emerged as a novel approach in information retrieval, aiming to simplify the retrieval process by integrating indexing and search into a single differentiable model \[[5](http://arxiv.org/abs/2502.02788)\]. These frameworks leverage neural architectures, such as transformers, to directly map queries to document identifiers, bypassing traditional retrieval pipelines \[[5](http://arxiv.org/abs/2502.02788)\]. However, early implementations of DSI faced challenges in distinguishing relevant documents from random ones, which impacted retrieval effectiveness \[[1](http://arxiv.org/abs/2305.02073)\]. To address this, researchers proposed multi-task distillation approaches to enhance retrieval quality without altering the model structure \[[1](http://arxiv.org/abs/2305.02073)\]. Additionally, the integration of large language models (LLMs) into DSI frameworks, such as De-DSI, has enabled decentralized and scalable information retrieval by utilizing query-docid pairs and ensemble models for improved accuracy and efficiency \[[4](http://arxiv.org/abs/2404.12237)\]. Furthermore, studies have explored balancing relevance and diversity in DSI training, inspired by Maximal Marginal Relevance (MMR), to achieve both high relevance and diverse results without post-processing \[[3](http://arxiv.org/abs/2206.10128)\]. These advancements highlight the evolving landscape of DSI, focusing on improving retrieval effectiveness, scalability, and the integration of advanced language models \[[1](http://arxiv.org/abs/2305.02073)\]\[[3](http://arxiv.org/abs/2206.10128)\]\[[4](http://arxiv.org/abs/2404.12237)\]\[[5](http://arxiv.org/abs/2502.02788)\].

[Snippet]: «The Differentiable Search Index (DSI) is an emerging paradigm for information retrieval. Unlike traditional retrieval architectures where index and retrieval are two different and separate components, DSI uses a single transformer model to perform both indexing and retrieval. In this paper, we identify and tackle an important issue of current DSI models: the data distribution mismatch that occurs between the DSI indexing and retrieval processes. Specifically, we argue that, at indexing, current DSI methods learn to build connections between the text of long documents and the identifier of the documents, but then retrieval of document identifiers is based on queries that are commonly much shorter than the indexed documents. This problem is further exacerbated when using DSI for cross-lingual retrieval, where document text and query text are in different languages. To address this fundamental problem of current DSI models, we propose a simple yet effective indexing framework for DSI, called DSI-QG. When indexing, DSI-QG represents documents with a number of potentially relevant queries generated by a query generation model and re-ranked and filtered by a cross-encoder ranker. The presence of these queries at indexing allows the DSI models to connect a document identifier to a set of queries, hence mitigating data distribution mismatches present between the indexing and the retrieval phases. Empirical results on popular mono-lingual and cross-lingual passage retrieval datasets show that DSI-QG significantly outperforms the original DSI model.»

### <a id='category-neural-approaches-for-table-retrieval'></a>Neural Approaches for Table Retrieval: 4 papers found.
Neural approaches for table retrieval have seen significant advancements, focusing on improving semantic matching between natural language queries and structured tabular data. Recent works emphasize the use of neural architectures to better capture the relationships between unstructured text and semi-structured tables. For instance, Neural Enquirer introduces a fully neuralized framework that executes natural language queries on knowledge-base tables by learning distributed representations and performing differentiable operations \[[6](http://arxiv.org/abs/1512.00965)\]. Similarly, a ranking-based approach has been proposed to enhance content-based table retrieval, incorporating both carefully designed features and neural network models to measure query-table relevance \[[12](http://arxiv.org/abs/1706.02427)\]. Additionally, neural language modeling techniques have been applied to embed tabular data into vector spaces, leveraging elements such as captions, column headings, and cells to improve tasks like row population, column population, and table retrieval \[[14](http://arxiv.org/abs/1906.00041)\]. These methods highlight the potential of neural models in capturing semantic alignments and improving retrieval accuracy. Furthermore, recent efforts have focused on fine-tuning large language models for table-specific tasks, such as data cleaning and NL-to-Code, through self-trained paradigms that reduce dependency on manually labeled data \[[16](http://arxiv.org/abs/2410.12164)\]. These developments underscore the growing interest in leveraging neural networks to bridge the gap between natural language and structured data representation.
