## Related Works

Differential privacy (DP) has been widely studied as a formal framework for protecting individual privacy in data analysis. While DP is often considered the de facto standard for privacy-preserving data release \[[20](http://arxiv.org/abs/2006.05609)\], its implementation in distributed settings is vulnerable to malicious behavior by servers, such as incorrect noise sampling or correlated noise generation \[[1](http://arxiv.org/abs/2406.18940)\]. These issues have motivated the development of verifiable DP mechanisms that ensure the correctness of DP execution \[[3](http://arxiv.org/abs/2409.10667)\]. 

Verifiable differential privacy (VLDP) has been explored in the local model, where clients add noise to their data before sending it to a server \[[1](http://arxiv.org/abs/2406.18940)\]. However, these approaches typically require multiple rounds of interaction between the client and server, which can be inefficient \[[3](http://arxiv.org/abs/2409.10667)\]. In contrast, our proposed Verifiable Distributed Differential Privacy (VDDP) framework introduces a novel definition that incorporates verification mechanisms to ensure the correctness of DP execution in a distributed setting \[[1](http://arxiv.org/abs/2406.18940)\]. This is a significant advancement over previous work that assumes trust in the server's execution of DP mechanisms \[[3](http://arxiv.org/abs/2409.10667)\].

Zero-knowledge proofs (ZKPs) have been used to verify the correctness of DP mechanisms, ensuring that the output is both differentially private and reliable \[[2](http://arxiv.org/abs/2208.09011)\]. While ZKPs are sufficient for achieving DP under verifiability requirements, they are not necessary, as demonstrated by our analysis \[[1](http://arxiv.org/abs/2406.18940)\]. This insight is crucial for designing efficient verification mechanisms that do not rely on ZKPs.

In the context of verifiable DP mechanisms, several approaches have been proposed. For instance, \[[3](http://arxiv.org/abs/2409.10667)\] introduces a scheme that prevents both input and output manipulation attacks against generic LDP mechanisms, requiring only one-time interaction between client and server. Similarly, \[[1](http://arxiv.org/abs/2406.18940)\] proposes a scheme for verifiable LDP in the shuffle model, which is more efficient than existing alternatives. Our VDDP framework builds on these ideas, offering significant improvements in efficiency and verification capabilities.

In addition to verification, the efficiency of DP mechanisms is a critical consideration. For example, \[[1](http://arxiv.org/abs/2406.18940)\] describes a scheme for verifiable LDP in the local model, with client run times of less than 2 seconds and server run times of 5-7 milliseconds per client. Our VDDP framework further improves upon these results by achieving up to a $4 \times 10^5$x improvement in proof generation efficiency with only 0.1-0.2x error compared to the previous state-of-the-art verifiable differentially private mechanism \[[1](http://arxiv.org/abs/2406.18940)\].
