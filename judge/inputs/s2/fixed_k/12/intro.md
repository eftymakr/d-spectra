## Related Works

Event cameras, which capture scene changes asynchronously on a per-pixel basis, have gained significant attention for their high temporal resolution and ability to handle dynamic scenes \[[6](http://arxiv.org/abs/1904.08405)\]. However, this advantage comes with challenges such as high bandwidth, memory, and computational demands \[[6](http://arxiv.org/abs/1904.08405)\]. Prior work has explored event downsampling as a means to mitigate these issues, but most approaches rely on fixed heuristics or threshold-based strategies, which limit their adaptability to different applications \[[6](http://arxiv.org/abs/1904.08405)\]. For instance, some studies have used simple thresholding to filter out less significant events \[[10](http://arxiv.org/abs/1207.3270)\], while others have applied fixed sampling rates to reduce the number of events processed \[[2](http://arxiv.org/abs/1804.01310)\]. These methods, however, often fail to account for the varying importance of events across different tasks and environments \[[6](http://arxiv.org/abs/1904.08405)\].

To address these limitations, researchers have proposed more adaptive and context-aware approaches. One notable work introduces a probabilistic framework that models event importance through an event-importance probability density function (ePDF), which can be arbitrarily defined and adapted to different applications \[[6](http://arxiv.org/abs/1904.08405)\]. This approach is inspired by earlier efforts that attempted to model event significance using statistical methods \[[10](http://arxiv.org/abs/1207.3270)\]. Another study explores the use of temporal and spatial features to prioritize events, aiming to preserve critical information while reducing the event stream size \[[24](http://arxiv.org/abs/2310.02642)\]. These methods, however, often require offline processing or are limited to specific tasks, making them less suitable for real-time applications \[[6](http://arxiv.org/abs/1904.08405)\].

In addition to event downsampling, several works have focused on improving the usability of downsampled events for downstream tasks. For example, some studies have proposed zero-shot event downsampling, where downsampled events must remain usable for models trained on the original event stream without task-specific adaptation \[[6](http://arxiv.org/abs/1904.08405)\]. This concept has been explored in the context of object classification and detection, where maintaining structural information is crucial \[[24](http://arxiv.org/abs/2310.02642)\]. Other approaches have focused on preserving contours and edges in downsampled events to ensure that key visual features are retained \[[24](http://arxiv.org/abs/2310.02642)\].

The importance of intelligent sampling for maintaining performance under event-budget constraints has also been emphasized in recent work \[[6](http://arxiv.org/abs/1904.08405)\]. Several studies have evaluated the effectiveness of different downsampling strategies across multiple tasks, including object classification, image interpolation, surface normal estimation, and object detection \[[6](http://arxiv.org/abs/1904.08405)\]. These evaluations highlight the need for adaptive and task-aware methods that can dynamically adjust to the requirements of different applications \[[6](http://arxiv.org/abs/1904.08405)\].
