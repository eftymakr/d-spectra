## Related Works

Unsupervised domain adaptation (UDA) for semantic segmentation has been extensively studied to address the challenge of transferring knowledge from a labeled source domain to an unlabeled target domain \[[1](http://arxiv.org/abs/2405.19899)\]. Traditional UDA methods typically assume that the category sets of the source and target domains are known and aligned \[[2](http://arxiv.org/abs/2110.10639)\], which is often not the case in real-world applications. This assumption leads to performance degradation when private classes—classes present in the target domain but absent in the source—exist \[[3](http://arxiv.org/abs/2012.12545)\]. To address this limitation, several works have explored open-set domain adaptation, where the target domain may contain unknown classes \[[4](http://arxiv.org/abs/2103.15467)\]. For instance, \[[5](http://arxiv.org/abs/2103.16372)\] introduces a method that detects unknown classes by learning to distinguish between known and unknown categories during adaptation. Similarly, \[[6](http://arxiv.org/abs/2405.06502)\] proposes a framework that explicitly handles unknown classes by identifying their boundaries and shapes, improving the detection of novel categories.

Another line of research focuses on semi-supervised domain adaptation (SSDA), where a small amount of labeled target data is available \[[7](http://arxiv.org/abs/1910.13049)\]. This approach leverages both labeled source and partially labeled target data to improve adaptation performance \[[8](http://arxiv.org/abs/2205.11419)\]. For example, \[[9](http://arxiv.org/abs/2007.15176)\] proposes a two-step adaptation framework that first aligns domain distributions and then refines predictions using a student-teacher network. This method effectively addresses both cross- and intra-domain gaps in semantic segmentation \[[10](http://arxiv.org/abs/2011.08502)\]. Additionally, \[[11](http://arxiv.org/abs/1911.11981)\] introduces a class-conditional domain adaptation method that equalizes loss over classes, improving performance for lower probability categories \[[12](http://arxiv.org/abs/2204.02111)\].

To further enhance adaptation, some works focus on domain alignment and pseudo-labeling strategies. For instance, \[[13](http://arxiv.org/abs/2106.01656)\] proposes a method that aligns the distribution of semantic classes between the source and target domains, reducing domain shift \[[14](http://arxiv.org/abs/2004.01130)\]. Similarly, \[[15](http://arxiv.org/abs/2103.13041)\] introduces a photometric alignment module that aligns images across domains, improving feature consistency \[[16](http://arxiv.org/abs/2110.02833)\]. Moreover, \[[17](http://arxiv.org/abs/2110.06484)\] explores the use of self-training techniques to improve pseudo-label quality, particularly at class boundaries \[[18](http://arxiv.org/abs/2106.06237)\].

In addition to these approaches, recent works have explored the use of domain-invariant prototypes and contrastive learning to improve adaptation. For example, \[[19](http://arxiv.org/abs/2010.12239)\] proposes a framework that learns domain-invariant prototypes, enabling robust adaptation even with limited labeled target data \[[20](http://arxiv.org/abs/2406.19225)\]. Another work, \[[21](http://arxiv.org/abs/2208.06087)\], introduces a semantic prototype-based contrastive learning framework that improves fine-grained class alignment by leveraging per-pixel discriminative representation learning \[[22](http://arxiv.org/abs/2111.12358)\].
