## Related Works

Semi-supervised learning (SSL) has emerged as a powerful paradigm for improving model performance by leveraging unlabeled data alongside a limited set of labeled samples \[[1](http://arxiv.org/abs/2311.10572)\]. However, traditional SSL methods assume that both labeled and unlabeled data originate from the same distribution, which is often violated in real-world scenarios where unlabeled data may contain out-of-distribution (OOD) instances, commonly referred to as outliers \[[2](http://arxiv.org/abs/2303.12091)\]. These outliers, if not properly handled, can significantly degrade model performance by introducing noise into the training process \[[3](http://arxiv.org/abs/2308.13168)\].

Several recent works have addressed the challenge of open-set semi-supervised learning (OSSL), where the goal is to not only classify inliers but also detect outliers \[[4](http://arxiv.org/abs/2105.14148)\]. For instance, SSB proposes a framework that incorporates high-confidence pseudo-labeled data and utilizes non-linear transformations to separate inlier classification and outlier detection tasks \[[1](http://arxiv.org/abs/2311.10572)\]. Similarly, ANEDL introduces an adaptive negative optimization strategy to enhance outlier detection by quantifying different types of uncertainty \[[2](http://arxiv.org/abs/2303.12091)\]. IOMatch, on the other hand, jointly utilizes inliers and outliers by employing a multi-binary classifier and treating all outliers as a single class \[[3](http://arxiv.org/abs/2308.13168)\]. This approach mitigates the performance degradation caused by unreliable outlier detectors when labeled data is scarce \[[4](http://arxiv.org/abs/2105.14148)\].

OpenMatch extends the idea of outlier detection by integrating novelty detection with consistency regularization, which improves the smoothness of the classifier with respect to input transformations \[[5](http://arxiv.org/abs/2107.08943)\]. OpenCoS, another OSSL method, leverages self-supervised contrastive learning to identify out-of-class samples and uses them to improve the performance of semi-supervised learning \[[6](http://arxiv.org/abs/2405.06979)\]. These methods highlight the importance of effectively distinguishing between inliers and outliers to maintain model accuracy \[[7](http://arxiv.org/abs/2301.10127)\].

In contrast to these methods, which often rely on a single model or a fixed threshold for outlier detection, our proposed framework, Diversify and Conquer (DAC), leverages prediction disagreements among multiple models with different biases toward the unlabeled distribution \[[8](http://arxiv.org/abs/2505.13317)\]. This approach is inspired by the observation that existing open-set SSL methods can fail when labeled data is insufficient, leading to worse performance than naive SSL methods that ignore outliers \[[9](http://arxiv.org/abs/2403.10658)\]. By constructing a collection of differently biased models through a single training process, DAC enables robust outlier detection even with underspecified labeled data \[[10](http://arxiv.org/abs/2201.09196)\].

The effectiveness of using multiple models for outlier detection has also been explored in other domains, such as semi-supervised object detection \[[11](http://arxiv.org/abs/2401.14387)\] and medical image segmentation \[[12](http://arxiv.org/abs/2201.06247)\]. These studies demonstrate that leveraging model disagreement can improve the robustness of learning algorithms

### <a id='category-open-set-semi-supervised-learning-(ossl)-challenges'></a>Open-Set Semi-Supervised Learning (OSSL) Challenges: 11 papers found.
Open-set semi-supervised learning (OSSL) addresses the challenge where unlabeled data may contain outliers from novel categories not present in the labeled set, which can degrade model performance \[[1](http://arxiv.org/abs/2311.10572)\]. Existing methods often rely on outlier detection via binary classifiers, but these suffer from scalability issues and inability to distinguish different types of uncertainty \[[2](http://arxiv.org/abs/2303.12091)\]. Some approaches, like IOMatch, propose joint utilization of inliers and outliers by introducing multi-binary classifiers and unified open-set classification targets \[[3](http://arxiv.org/abs/2308.13168)\]. Others, such as OpenMatch, integrate novelty detection with existing SSL frameworks like FixMatch, using one-vs-all classifiers to detect inliers and generate pseudo-labels \[[4](http://arxiv.org/abs/2105.14148)\]. Additionally, methods like OpenCoS leverage self-supervised contrastive learning to identify out-of-class samples, enabling the use of both inlier and outlier data for training \[[5](http://arxiv.org/abs/2107.08943)\]. To improve robustness, WiseOpen introduces a selective data usage strategy based on gradient variance, filtering out harmful open-set data during training \[[6](http://arxiv.org/abs/2405.06979)\]. Furthermore, frameworks like SSB incorporate pseudo-negative mining and non-linear feature transformations to enhance both inlier classification and outlier detection \[[1](http://arxiv.org/abs/2311.10572)\]. These approaches collectively highlight the importance of handling open-set scenarios by improving outlier detection, leveraging pseudo-labels, and designing robust training strategies \[[1](http://arxiv.org/abs/2311.10572)\]\[[2](http://arxiv.org/abs/2303.12091)\]\[[3](http://arxiv.org/abs/2308.13168)\]\[[4](http://arxiv.org/abs/2105.14148)\]\[[5](http://arxiv.org/abs/2107.08943)\]\[[6](http://arxiv.org/abs/2405.06979)\].

### <a id='category-semi-supervised-learning-foundations'></a>Semi-Supervised Learning Foundations: 9 papers found.
Recent advances in semi-supervised learning (SSL) have focused on leveraging unlabeled data to improve model performance, particularly in scenarios with limited labeled data \[[1](http://arxiv.org/abs/2311.10572)\]. However, traditional SSL methods often assume that unlabeled data follows the same class distribution as labeled data, which is not always the case in real-world applications where unlabeled data may contain outliers or unknown classes \[[1](http://arxiv.org/abs/2311.10572)\]. This assumption can lead to significant performance degradation, as outliers are typically treated as noise \[[1](http://arxiv.org/abs/2311.10572)\]. To address this limitation, several studies have explored methods that account for the presence of outliers in unlabeled data, such as contrastive regularization, which clusters features of unlabeled data to improve consistency regularization \[[4](http://arxiv.org/abs/2105.14148)\]. Additionally, methods like FreeMatch have been proposed to adaptively adjust confidence thresholds for pseudo-labels, enhancing performance when labeled data is scarce \[[5](http://arxiv.org/abs/2107.08943)\]. Another approach, InterLUDE, introduces a new loss function based on consistency regularization to minimize prediction discrepancies between labeled and unlabeled inputs, achieving significant improvements on benchmarks like STL-10 \[[2](http://arxiv.org/abs/2303.12091)\]. Furthermore, research has extended SSL to structured output prediction tasks, where feature rankings are learned using semi-supervised techniques, showing superior performance compared to supervised methods \[[6](http://arxiv.org/abs/2405.06979)\]. These developments highlight the ongoing efforts to enhance SSL robustness, particularly in open-set settings where unlabeled data may include out-of-distribution samples \[[1](http://arxiv.org/abs/2311.10572)\]. The integration of pre-trained models and SSL techniques has also been explored, with studies showing that pre-trained models can achieve strong performance on SSL benchmarks, suggesting a potential synergy between the two approaches \[[1](http://arxiv.org/abs/2311.10572)\]. Overall, these works emphasize the importance of addressing the challenges posed by unlabeled data, including outliers and distribution shifts, to improve the generalizability and robustness of SSL methods.

### <a id='category-multi-model-ossl-approaches'></a>Multi-Model OSSL Approaches: 2 papers found.
In the realm of multi-model semi-supervised learning (OSSL) approaches, recent research has focused on mitigating the challenges posed by noisy pseudo-labels and outlier data. A primary issue in SSL for segmentation is confirmation bias, where noisy pseudo-labels destabilize training and degrade performance \[[11](http://arxiv.org/abs/2401.14387)\]. To address this, the Inconsistency Masks (IM) framework reframes model disagreement as a valuable signal for identifying uncertainty, using an ensemble of teacher models to generate masks that delineate regions of prediction divergence \[[11](http://arxiv.org/abs/2401.14387)\]. This approach effectively filters inconsistent areas from input-pseudo-label pairs, mitigating error propagation in self-training paradigms. Additionally, in the context of open-set SSL, the Diversify and Conquer (DAC) framework enhances robustness by leveraging prediction disagreements among multiple models with differing biases toward the unlabeled distribution \[[14](http://arxiv.org/abs/2503.17057)\]. This enables robust outlier detection even with underspecified labeled data. Both methods emphasize the importance of model diversity and disagreement as a means to improve training stability and performance in semi-supervised settings.

### <a id='category-outlier-detection-mechanisms'></a>Outlier Detection Mechanisms: 5 papers found.
Outlier detection mechanisms have been a focal point in machine learning, particularly in scenarios where data quality and distribution assumptions are not met. Traditional clustering methods, such as k-means, often struggle with non-convex cluster shapes and are sensitive to outliers, leading to suboptimal performance \[[15](http://arxiv.org/abs/2208.05561)\]. To address these limitations, researchers have explored semi-supervised density-based algorithms like SSDBCODI, which integrate outlier detection within the clustering process using reachability, local-density, and similarity scores to generate instance weights for improved clustering and outlier detection \[[15](http://arxiv.org/abs/2208.05561)\]. Similarly, in the context of deep learning, challenges such as domain shift and lack of labels in private datasets have prompted the development of methods like Tabular Data Adapters (TDA), which generate soft labels for unlabeled tabular data by aligning private data with public datasets through autoencoders \[[20](http://arxiv.org/abs/2504.20862)\]. In cybersecurity, the increasing complexity of intrusion attacks has driven the use of hybrid frameworks combining unsupervised, semi-supervised, and supervised learning techniques, such as the three-stage deep learning framework that integrates K-means, GANomaly, and CNN for enhanced intrusion detection \[[24](http://arxiv.org/abs/2212.00966)\]. For time series data, convolutional ensembles have been proposed to improve accuracy and efficiency by leveraging diversity-driven training and parallelism, enabling better outlier detection in high-dimensional temporal data \[[28](http://arxiv.org/abs/2111.11108)\]. Additionally, in deep anomaly detection, approaches like Outlier Exposure (OE) have been introduced to improve generalization by training models on auxiliary outlier datasets, allowing them to detect unseen anomalies more effectively \[[29](http://arxiv.org/abs/1812.04606)\]. These methods collectively highlight the evolving landscape of outlier detection, emphasizing the need for robust, adaptive, and scalable solutions that can handle the complexities of real-world data.
