## Related Works

Semi-supervised learning (SSL) has emerged as a powerful paradigm for improving model performance by leveraging unlabeled data alongside a limited set of labeled samples \[[1](http://arxiv.org/abs/2311.10572)\]. However, traditional SSL methods assume that both labeled and unlabeled data originate from the same distribution, which is often violated in real-world scenarios where unlabeled data may contain out-of-distribution (OOD) instances, commonly referred to as outliers \[[2](http://arxiv.org/abs/2303.12091)\]. These outliers, if not properly handled, can significantly degrade model performance by introducing noise into the training process \[[3](http://arxiv.org/abs/2308.13168)\].

Several recent works have addressed the challenge of open-set semi-supervised learning (OSSL), where the goal is to not only classify inliers but also detect outliers \[[4](http://arxiv.org/abs/2105.14148)\]. For instance, SSB proposes a framework that incorporates high-confidence pseudo-labeled data and utilizes non-linear transformations to separate inlier classification and outlier detection tasks \[[1](http://arxiv.org/abs/2311.10572)\]. Similarly, ANEDL introduces an adaptive negative optimization strategy to enhance outlier detection by quantifying different types of uncertainty \[[2](http://arxiv.org/abs/2303.12091)\]. IOMatch, on the other hand, jointly utilizes inliers and outliers by employing a multi-binary classifier and treating all outliers as a single class \[[3](http://arxiv.org/abs/2308.13168)\]. This approach mitigates the performance degradation caused by unreliable outlier detectors when labeled data is scarce \[[4](http://arxiv.org/abs/2105.14148)\].

OpenMatch extends the idea of outlier detection by integrating novelty detection with consistency regularization, which improves the smoothness of the classifier with respect to input transformations \[[5](http://arxiv.org/abs/2107.08943)\]. OpenCoS, another OSSL method, leverages self-supervised contrastive learning to identify out-of-class samples and uses them to improve the performance of semi-supervised learning \[[6](http://arxiv.org/abs/2405.06979)\]. These methods highlight the importance of effectively distinguishing between inliers and outliers to maintain model accuracy \[[7](http://arxiv.org/abs/2301.10127)\].

In contrast to these methods, which often rely on a single model or a fixed threshold for outlier detection, our proposed framework, Diversify and Conquer (DAC), leverages prediction disagreements among multiple models with different biases toward the unlabeled distribution \[[8](http://arxiv.org/abs/2505.13317)\]. This approach is inspired by the observation that existing open-set SSL methods can fail when labeled data is insufficient, leading to worse performance than naive SSL methods that ignore outliers \[[9](http://arxiv.org/abs/2403.10658)\]. By constructing a collection of differently biased models through a single training process, DAC enables robust outlier detection even with underspecified labeled data \[[10](http://arxiv.org/abs/2201.09196)\].

The effectiveness of using multiple models for outlier detection has also been explored in other domains, such as semi-supervised object detection \[[11](http://arxiv.org/abs/2401.14387)\] and medical image segmentation \[[12](http://arxiv.org/abs/2201.06247)\]. These studies demonstrate that leveraging model disagreement can improve the robustness of learning algorithms
