## Related Works

Table discovery has emerged as a critical challenge in the era of abundant tabular data repositories. Traditional approaches often rely on query tables or vague keywords to retrieve relevant tables, requiring users to manually filter large result sets \[[6](http://arxiv.org/abs/2411.03356)\]. This limitation highlights the need for more sophisticated methods that can integrate natural language (NL) requirements into the search process. The proposed task, NL-conditional table discovery (nlcTD), addresses this by enabling users to refine search results using both a query table and NL conditions \[[6](http://arxiv.org/abs/2411.03356)\]. 

Several studies have explored the semantic connections between tables, aiming to improve the semantic capabilities of database systems \[[1](http://arxiv.org/abs/1208.4016)\]. For instance, the concept-driven framework for latent table discovery focuses on semantically connecting unrelated tables that are not syntactically related by design \[[1](http://arxiv.org/abs/1208.4016)\]. This work laid the groundwork for understanding how semantic relationships can enhance table discovery. However, these methods often lack the ability to handle complex NL conditions, which are essential for more nuanced queries.

Recent advancements in deep learning have shown promise in table detection, particularly with the introduction of diverse datasets like the STDW dataset, which contains over 7,000 samples with varied table structures \[[2](http://arxiv.org/abs/2209.09207)\]. This dataset has enabled the development of high-throughput deep learning methods for understanding document layout and tabular data processing. While these methods improve the detection of table structures, they do not directly address the integration of NL conditions into the discovery process.

The challenge of handling large tables and ensuring data privacy has also been addressed in recent works. The "HiddenTables" cooperative game and dataset "PyQTax" demonstrate how LLMs can interact with massive datasets while ensuring data security and minimizing generation costs \[[3](http://arxiv.org/abs/2406.10803)\]. This work highlights the limitations of current LLMs in handling complex queries and compositional dependencies, which is a key consideration for the nlcTD task. The proposed framework in "HiddenTables" allows for more efficient handling of large tables by not being constrained by the number of rows, which is a significant advantage for the nlcTD task.

In addition, the use of synthetic data generation to enhance table representations has been explored. The paper "Enhancing Table Representations with LLM-powered Synthetic Data Generation" proposes a novel pipeline that leverages LLMs to create synthetic datasets tailored for table-level representation learning \[[6](http://arxiv.org/abs/2411.03356)\]. This work addresses the lack of high-quality training data in existing approaches, which is a critical factor in improving the performance of table discovery methods.
