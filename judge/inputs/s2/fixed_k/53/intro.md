## Related Works

Deep sequential recommendation models have seen significant advancements, driven by the need to effectively model user behavior sequences. Traditional approaches, such as RNNs and Transformers, have been widely used to capture sequential dependencies \[[1](http://arxiv.org/abs/2502.08132)\]. However, these models often struggle with computational efficiency and the ability to handle variable-length sequences \[[2](http://arxiv.org/abs/2409.01192)\]. For instance, Transformer-based models suffer from quadratic complexity due to self-attention mechanisms, which limits their scalability for long sequences \[[3](http://arxiv.org/abs/2403.03900)\]. This challenge has motivated the exploration of alternative architectures, such as state space models (SSMs), which offer linear complexity and efficient processing of variable-length sequences \[[4](http://arxiv.org/abs/2105.14060)\].

Several works have attempted to address the limitations of attention-based models. Mamba, a selective SSM, has shown promise in efficient sequence modeling due to its hardware-aware design and linear complexity \[[5](http://arxiv.org/abs/2406.02638)\]. Similarly, the SS4Rec model integrates time-aware and relation-aware SSMs to better handle irregular time intervals and contextual dependencies \[[6](http://arxiv.org/abs/2504.05323)\]. These models demonstrate that SSMs can effectively capture temporal dynamics and user preferences while maintaining computational efficiency \[[7](http://arxiv.org/abs/2409.05022)\].

Efforts to improve attention mechanisms have also been made. For example, the Mamba4Rec model introduces selective SSMs to enhance inference efficiency while maintaining model effectiveness \[[8](http://arxiv.org/abs/2411.01537)\]. Additionally, the EchoMamba4Rec model combines bidirectional processing with spectral filtering to capture complex patterns in user interactions \[[9](http://arxiv.org/abs/2012.03323)\]. These approaches highlight the potential of combining SSMs with attention mechanisms to achieve both efficiency and accuracy in sequential recommendation \[[10](http://arxiv.org/abs/2501.01242)\].

Another line of research focuses on multi-head attention and mixture-of-experts (MoE) structures to better capture diverse user preferences. The FAME model introduces a facet-aware MoE structure that disentangles user preferences within different item facets, such as genres or actors \[[11](http://arxiv.org/abs/2311.08272)\]. Similarly, the MAN model employs local and global attention modules to extract both domain-specific and cross-domain information, improving performance in data-scarce scenarios \[[12](http://arxiv.org/abs/2109.05261)\]. These models demonstrate the value of incorporating multiple attention mechanisms to better model complex user behaviors \[[13](http://arxiv.org/abs/2008.08273)\].

Moreover, the use of multi-modal data has been explored to enhance recommendation accuracy. The attention-based sequential recommendation system using multimodal data integrates image, text, and category features to provide more comprehensive item representations \[[14](http://arxiv.org/abs/2209.07997)\]. This approach highlights the importance of leveraging diverse data sources to improve recommendation quality \[[15](http://arxiv.org/abs/2405.17959)\].
