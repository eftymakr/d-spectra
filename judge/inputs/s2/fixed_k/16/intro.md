## Related Works

Open-vocabulary object detection (OVD) has gained significant attention in recent years due to its ability to detect objects from an unrestricted set of categories, including those unseen during training \[[1](http://arxiv.org/abs/2211.14843)\]. Early approaches relied on pre-trained vision-language models (VLMs) to align image regions with textual descriptions, but they often suffered from poor performance due to the lack of fine-grained object-language alignments \[[1](http://arxiv.org/abs/2211.14843)\]. This limitation was addressed by several works that proposed novel frameworks for OVD, such as VLDet \[[1](http://arxiv.org/abs/2211.14843)\], which directly learns from image-text pairs without requiring expensive grounding annotations \[[1](http://arxiv.org/abs/2211.14843)\]. Another approach, Locov \[[2](http://arxiv.org/abs/2205.06160)\], introduced a two-stage training method that first uses location-guided image-caption matching to learn class labels and then specializes the model for object detection \[[2](http://arxiv.org/abs/2205.06160)\]. These methods demonstrated the potential of using weakly supervised learning to detect novel object classes \[[2](http://arxiv.org/abs/2205.06160)\].

The challenge of aligning image regions with textual descriptions has also been tackled through vision transformer-based approaches. For instance, Prompt-OVD \[[25](http://arxiv.org/abs/2303.14386)\] utilizes class embeddings from CLIP as prompts to guide the Transformer decoder, enabling efficient and effective open-vocabulary object detection \[[25](http://arxiv.org/abs/2303.14386)\]. This approach was further enhanced by the introduction of RoI-based masked attention and RoI pruning techniques, which improved detection performance at minimal computational cost \[[25](http://arxiv.org/abs/2303.14386)\]. Similarly, DVDet \[[26](http://arxiv.org/abs/2402.04630)\] introduced conditional context prompts and hierarchical textual descriptors to enable precise region-text alignment, leading to significant improvements in open-vocabulary detection \[[26](http://arxiv.org/abs/2402.04630)\].

To address the issue of limited training data, several works proposed methods for generating pseudo labels from image-text pairs. For example, PB-OVD \[[4](http://arxiv.org/abs/2111.09452)\] leverages the localization ability of pre-trained vision-language models to generate pseudo bounding-box labels, which are then used for training object detectors \[[4](http://arxiv.org/abs/2111.09452)\]. This approach significantly improved performance on COCO novel categories, achieving an 8% AP improvement over the state-of-the-art \[[4](http://arxiv.org/abs/2111.09452)\]. Similarly, the OWLv2 model and OWL-ST self-training recipe \[[24](http://arxiv.org/abs/2306.09683)\] scaled detection data using self-training, enabling the model to achieve a 43% relative improvement on LVIS rare classes \[[24](http://arxiv.org/abs/2306.09683)\].
