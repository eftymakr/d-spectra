## Related Works

Long-tailed recognition remains a challenging problem in computer vision due to the imbalance in class distribution, where a few classes (head classes) dominate the dataset while others (tail classes) have very few samples \[[1' 2024-03-10](http://arxiv.org/abs/2403.06151v1)\]. This imbalance leads to biased feature spaces and poor generalization for tail classes \[[2' 2022-03-22](http://arxiv.org/abs/2203.11506v2)\]. Several approaches have been proposed to address this issue, primarily focusing on contrastive learning, data augmentation, and loss function design.

Contrastive learning has shown promising results in representation learning by pulling positive samples closer and pushing negative samples apart \[[3' 2023-05-02](http://arxiv.org/abs/2305.01160v3)\]. However, in long-tailed scenarios, the standard supervised contrastive loss (SCL) fails to account for the imbalanced attraction and repulsion gradients between positive and negative pairs \[[4' 2022-07-19](http://arxiv.org/abs/2207.09052v3)\]. This leads to gradient conflicts that hinder the learning of discriminative features for tail classes \[[5' 2022-12-21](http://arxiv.org/abs/2212.11187v1)\]. To address this, several works have introduced modifications to SCL, such as decoupling positive samples \[[6' 2022-11-22](http://arxiv.org/abs/2211.11938v1)\], introducing class-balanced losses \[[7' 2021-02-17](http://arxiv.org/abs/2102.08817v4)\], and leveraging self-distillation to transfer knowledge from head to tail classes \[[8' 2024-06-04](http://arxiv.org/abs/2406.02223v1)\].

For instance, Decoupled Contrastive Learning for Long-Tailed Recognition \[[9' 2023-09-28](http://arxiv.org/abs/2309.16135v1)\] decouples the training objective to optimize the relationships between different types of positive samples, which helps alleviate the impact of imbalanced data. Similarly, Rebalanced Siamese Contrastive Mining \[[10' 2020-04-07](http://arxiv.org/abs/2004.03706v2)\] introduces a class-balanced queue to maintain equal representation of all classes in the Siamese batch level. These methods aim to improve the performance of contrastive learning in long-tailed settings by addressing the dual class-imbalance problem.

Another line of work focuses on the theoretical foundations of contrastive learning. Dissecting Supervised Contrastive Learning \[[11' 2023-06-23](http://arxiv.org/abs/2306.13275v2)\] provides insights into the geometric properties of the learned representations, showing that both SCL and cross-entropy losses converge to a regular simplex configuration. However, SCL exhibits different optimization behavior, particularly under class imbalance, which can lead to suboptimal feature learning \[[12' 2024-07-17](http://arxiv.org/abs/2407.12568v2)\]. This motivates the development of new contrastive learning methods that explicitly account for the imbalanced nature of long-tailed data.

In addition to contrastive learning, other approaches have explored the use of self-supervised learning and meta-learning for long-tailed recognition. For example, SelfMatch \[[13' 2024-08-01](http://arxiv.org/abs/2408.00483v1)\] combines contrastive self-supervision with consistency regularization to achieve state-of-the-art results on benchmark datasets. Similarly, Balanced Meta-Softmax \[[14' 2021-01-16](http://arxiv.org/abs/2101.06480v1)\] introduces a novel loss function that mitigates the bias in gradient estimation caused by class imbalance

To mitigate this, some works reinterpret the problem as maximizing mutual information between latent features and ground-truth labels, leading to a unified loss function that achieves state-of-the-art results \[[3' 2023-05-02](http://arxiv.org/abs/2305.01160v3)\]. Additionally, dual-branch frameworks have been proposed, combining imbalanced learning with contrastive learning branches to enhance decision boundaries and feature representation for tail classes \[[5' 2022-12-21](http://arxiv.org/abs/2212.11187v1)\]. These approaches collectively highlight the ongoing efforts to refine contrastive learning for long-tailed scenarios, emphasizing the need for theoretical insights and novel loss functions to address class imbalance effectively.

### <a id='category-theoretical-foundations-of-contrastive-learning'></a>Theoretical Foundations of Contrastive Learning: 3 papers found.
The theoretical foundations of contrastive learning are explored in several recent works, which examine both the optimization behavior and the geometric properties of learned representations. One study demonstrates that minimizing cross-entropy and supervised contrastive losses can lead to similar optimal configurations where class representations collapse to the vertices of a regular simplex inscribed in a hypersphere, under mild assumptions \[[7' 2021-02-17](http://arxiv.org/abs/2102.08817v4)\]. This configuration is associated with good generalization performance, though the two losses exhibit different optimization dynamics, with the contrastive loss showing superlinear scaling with label noise \[[7' 2021-02-17](http://arxiv.org/abs/2102.08817v4)\]. Another work introduces Joint Contrastive Learning (JCL), which implicitly learns an infinite number of query-key pairs and derives an upper bound for end-to-end training, revealing mechanisms that favor intra-class similarity and enable discriminative feature learning \[[21' 2020-09-30](http://arxiv.org/abs/2009.14776v2)\]. Additionally, research on contrastive learning's feature learning process highlights how proper data augmentations can help neural networks learn sparse, semantically aligned features by reducing correlations between dense features in positive samples, a principle termed feature decoupling \[[27' 2021-05-31](http://arxiv.org/abs/2105.15134v3)\]. These findings collectively underscore the importance of both theoretical analysis and practical design in advancing contrastive learning methods.
