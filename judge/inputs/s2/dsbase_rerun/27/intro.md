## Related Works

Recent advancements in information retrieval have focused on improving the accuracy and efficiency of query-to-document mapping through differentiable search index (DSI) frameworks \[[1' 2022-02-14](http://arxiv.org/abs/2202.06991v3)\]. Traditional dense retrieval methods, such as those based on vector similarity, often suffer from error accumulation during the representation and indexing phases, which degrades search accuracy \[[1' 2022-02-14](http://arxiv.org/abs/2202.06991v3)\]. Additionally, insufficient interaction between queries and documents limits semantic alignment, hindering performance improvements \[[1' 2022-02-14](http://arxiv.org/abs/2202.06991v3)\]. To address these limitations, several works have explored alternative approaches to enhance retrieval effectiveness.

The DSI framework, introduced in \[[1' 2022-02-14](http://arxiv.org/abs/2202.06991v3)\], represents a paradigm shift by encoding all corpus information directly into the model parameters, allowing queries to be mapped directly to document identifiers without requiring external indexes \[[1' 2022-02-14](http://arxiv.org/abs/2202.06991v3)\]. This approach simplifies the retrieval process and enables zero-shot performance, outperforming BM25 baselines \[[1' 2022-02-14](http://arxiv.org/abs/2202.06991v3)\]. However, early DSI implementations faced challenges in distinguishing relevant documents from random ones, indicating a need for further refinement \[[4' 2023-05-03](http://arxiv.org/abs/2305.02073v2)\]. To address this, \[[4' 2023-05-03](http://arxiv.org/abs/2305.02073v2)\] proposed a multi-task distillation approach that improves indexing abilities without altering the model structure, leading to better retrieval quality.

Decentralized DSI implementations, such as De-DSI \[[2' 2024-04-18](http://arxiv.org/abs/2404.12237v2)\], extend the DSI concept to distributed settings, enabling efficient retrieval using query-docid pairs without direct access to documents \[[2' 2024-04-18](http://arxiv.org/abs/2404.12237v2)\]. By partitioning datasets into shards and using an ensemble of DSI models, De-DSI maintains accuracy while improving scalability through beam search and softmax-based score normalization \[[2' 2024-04-18](http://arxiv.org/abs/2404.12237v2)\]. This approach also allows for the retrieval of multimedia items via magnet links, reducing reliance on intermediaries \[[2' 2024-04-18](http://arxiv.org/abs/2404.12237v2)\].

In the context of table retrieval, \[[7' 2019-05-31](http://arxiv.org/abs/1906.00041v1)\] introduced Table2Vec, which uses neural embeddings to enhance table population and retrieval tasks by incorporating semantic similarity signals into existing retrieval models \[[7' 2019-05-31](http://arxiv.org/abs/1906.00041v1)\]. Similarly, \[[12' 2024-11-04](http://arxiv.org/abs/2411.03356v1)\] proposed a synthetic data generation pipeline leveraging LLMs to improve table-level representations and recommendation performance \[[12' 2024-11-04](http://arxiv.org/abs/2411.03356v1)\]. These methods highlight the importance of high-quality training data and semantic alignment in table retrieval systems.

For cross-modal retrieval, \[[16' 2024-07-17](http://arxiv.org/abs/2407.12346v2)\] introduced an object-aware query perturbation method that improves small object recognition by aligning queries with detected objects in images \[[16' 2024-07-17](http://arxiv.org/abs/2407.12346v2)\]. This approach enhances semantic alignment without requiring additional fine-tuning, demonstrating the potential of query-aware methods in cross-modal settings \[[16' 2024-07-17](http://arxiv.org/abs/2407.12346v2)\].
