## Related Works

Rehearsal-based methods have been widely studied in continual learning (CL) to mitigate catastrophic forgetting, where models lose knowledge from previous tasks when learning new ones \[[1' 2022-03-28](http://arxiv.org/abs/2203.14544v1)\]. These methods typically store a subset of past data in a memory buffer and train the model on both new and old data simultaneously \[[2' 2020-10-07](http://arxiv.org/abs/2010.04003v2)\]. While concurrent rehearsal has been shown to be effective, recent work has questioned whether this approach is always optimal \[[3' 2017-08-07](http://arxiv.org/abs/1708.02072v4)\]. Inspired by human learning, where revisiting tasks sequentially helps retain knowledge, researchers have explored whether sequential rehearsal could offer greater benefits compared to standard concurrent rehearsal \[[4' 2020-07-14](http://arxiv.org/abs/2007.07400v1)\].

Several studies have investigated the effectiveness of rehearsal strategies in CL. For instance, \[[5' 2023-06-16](http://arxiv.org/abs/2306.10181v1)\] proposed a coreset selection method for rehearsal-based CL, aiming to maintain a small, informative subset of data that closely matches the gradients induced by the full dataset. This approach reduces memory usage while preserving model performance \[[6' 2022-03-31](http://arxiv.org/abs/2203.17269v2)\]. Similarly, \[[7' 2021-05-16](http://arxiv.org/abs/2105.07385v1)\] introduced a method to measure catastrophic forgetting by analyzing how performance on earlier tasks degrades after learning new ones. This work highlighted the importance of evaluating forgetting in addition to accuracy \[[8' 2025-05-28](http://arxiv.org/abs/2505.21942v1)\].

The idea of sequential rehearsal has also been explored in the context of deep reinforcement learning. \[[9' 2024-02-12](http://arxiv.org/abs/2402.08096v3)\] introduced a dual memory system that separates continual learning from reinforcement learning and uses a pseudo-rehearsal mechanism to "recall" past tasks via a deep generative network. This approach enables models to learn sequentially without catastrophic forgetting, avoiding the need to store raw data or revisit past tasks \[[10' 2020-04-29](http://arxiv.org/abs/2004.14046v1)\]. Similarly, \[[11' 2018-01-04](http://arxiv.org/abs/1801.01423v3)\] proposed pseudo-rehearsal using non-photorealistic images, demonstrating that synthetic data can be used for rehearsal without requiring high-fidelity representations \[[12' 2023-03-06](http://arxiv.org/abs/2303.02954v1)\].

In addition to rehearsal-based approaches, other methods have been developed to address catastrophic forgetting. \[[13' 2024-10-14](http://arxiv.org/abs/2410.10521v1)\] introduced a theoretical analysis of catastrophic forgetting using the NTK overlap matrix, showing that task similarity plays a key role in forgetting. This work also analyzed common gradient-based algorithms and proposed a variant of orthogonal gradient descent to mitigate forgetting \[[14' 2019-04-15](http://arxiv.org/abs/1904.07734v1)\]. Another study \[[15' 2023-08-20](http://arxiv.org/abs/2308.10328v3)\] explored the use of regularization techniques, such as elastic weight consolidation (EWC), to preserve knowledge from previous tasks while learning new ones \[[16' 2022-06-16](http://arxiv.org/abs/2206.07932v1)\].

Recent work has also focused on the efficiency and scalability of rehearsal strategies. \[[17' 2019-04-24](http://arxiv.org/abs/1904.10644v1)\] proposed SPARC, a scalable CL approach that eliminates the need for full-model surrogates or experience rehearsal by combining task-specific and task-agnostic memory.
