## Related Works

Cold start latency remains a critical challenge in serverless computing, impacting both performance and resource utilization \[[1' 2024-06-17](http://arxiv.org/abs/2406.11734v1)\]. Several studies have explored this issue, proposing various mitigation strategies. For instance, LibProf \[[1' 2024-06-17](http://arxiv.org/abs/2406.11734v1)\] introduces a Python profiler that identifies inefficient library initializations using dynamic program analysis, offering insights into cold start inefficiencies. This work highlights that static analysis techniques are insufficient for workload-dependent inefficiencies \[[1' 2024-06-17](http://arxiv.org/abs/2406.11734v1)\]. Similarly, SPES \[[2' 2024-03-26](http://arxiv.org/abs/2403.17574v2)\] addresses the cold start problem by optimizing function provision through accurate invocation prediction, reducing cold start rates and memory waste. These approaches focus on improving function initialization and pre-loading strategies.

The cold start problem is further analyzed in a systematic review \[[3' 2023-10-12](http://arxiv.org/abs/2310.08437v2)\], which classifies existing solutions into categories such as caching, application-level optimizations, and AI/ML-based methods. This review underscores the need for more comprehensive and adaptive strategies to mitigate cold starts effectively. Transformer-based models \[[4' 2025-04-15](http://arxiv.org/abs/2504.11338v1)\] have also been proposed to predict function initialization delays and optimize serverless performance, achieving significant reductions in cold start times. This approach leverages deep learning to model function behavior, offering a promising direction for adaptive optimization.

Proactive resource management techniques, such as the freshen primitive \[[5' 2020-10-09](http://arxiv.org/abs/2010.04312v1)\], aim to reduce overheads associated with serverless functions by performing preparatory tasks before execution. This method improves function responsiveness by mitigating cold start latencies. Additionally, a pool-based approach \[[8' 2019-03-28](http://arxiv.org/abs/1903.12221v1)\] maintains a set of warm containers to reduce cold start latency, achieving an 85% reduction in P99 response time. This strategy is particularly effective in environments where function invocations are predictable.

The complexity of cold starts is further explored in a detailed analysis of a large-scale serverless platform \[[6' 2024-10-08](http://arxiv.org/abs/2410.06145v1)\], which examines factors such as trigger types, runtime languages, and resource allocations. This study reveals that cold starts can vary significantly across different regions and workloads, emphasizing the need for region-aware optimization strategies. Time series forecasting models \[[7' 2022-06-30](http://arxiv.org/abs/2206.15176v1)\] have also been applied to predict incoming requests and adjust container provisioning accordingly, reducing resource wastage and cold start times.

Reinforcement learning \[[10' 2023-08-15](http://arxiv.org/abs/2308.07541v2)\] offers another promising approach to cold start mitigation by proactively initializing functions based on expected demand. This method improves throughput and reduces resource wastage, demonstrating the potential of adaptive learning techniques in serverless environments. Overall, these studies highlight the multifaceted nature of cold start latency and the need for diverse, context-aware solutions to address it effectively.
