## Related Works

Anomaly detection has become a critical component of modern manufacturing systems, enabling efficient quality control and fault identification. Several recent works have addressed the challenges of anomaly detection in industrial settings, particularly focusing on computational efficiency, model generalization, and the use of synthetic data. For instance, the MVTec dataset has been widely used to evaluate anomaly detection models, with many approaches relying on pre-trained feature extractors fine-tuned on normal and anomalous samples \[[1' 2024-08-27](http://arxiv.org/abs/2408.15113v2)\]. However, most traditional methods still rely on general-purpose feature extractors pre-trained on common image classification datasets, which may not be optimal for industrial applications \[[1' 2024-08-27](http://arxiv.org/abs/2408.15113v2)\]. 

To address the computational limitations of deep learning models in embedded systems, TinyAD was introduced as a memory-efficient framework for anomaly detection in time series data collected from Industrial Internet of Things (IIoT) devices \[[2' 2023-03-07](http://arxiv.org/abs/2303.03611v1)\]. This framework leverages depthwise separable CNNs and memory rescheduling strategies to reduce peak memory consumption by 2–5 times, making it suitable for deployment on resource-constrained microcontrollers \[[2' 2023-03-07](http://arxiv.org/abs/2303.03611v1)\]. This is particularly relevant for Small and Medium Enterprises (SMEs) that lack the computational infrastructure to run complex models \[[1' 2024-08-27](http://arxiv.org/abs/2408.15113v2)\]. 

In addition to computational constraints, the scarcity of labeled anomaly data has been a major challenge in training effective anomaly detection models \[[4' 2021-05-16](http://arxiv.org/abs/2105.07346v1)\]. To mitigate this, some approaches have utilized weakly-supervised learning, where synthetic data generated by Digital Twin systems is used to train models with minimal labeled anomalies \[[3' 2020-11-12](http://arxiv.org/abs/2011.06296v1)\]. This approach has shown promising results, especially when combined with clustering-based methods or neural architectures such as Siamese Autoencoders (SAE) \[[3' 2020-11-12](http://arxiv.org/abs/2011.06296v1)\]. 

Another important consideration in anomaly detection is the ability to distinguish between normal and anomalous patterns, particularly in multi-class settings. The Prior Normality Prompt Transformer (PNPT) addresses this by incorporating normal semantics into the reconstruction process, enabling more accurate discrimination between normal and abnormal instances \[[5' 2024-06-17](http://arxiv.org/abs/2406.11507v1)\]. This is especially useful in industrial inspection, where a unified model is often required to handle multiple anomaly categories \[[5' 2024-06-17](http://arxiv.org/abs/2406.11507v1)\]. 

For 3D objects and multi-pose scenarios, SplatPose has been proposed as a novel framework that uses Gaussian splatting to estimate the pose of unseen views and detect anomalies in them \[[10' 2024-04-10](http://arxiv.org/abs/2404.06832v1)\]. This method is particularly suitable for industrial settings where objects may be viewed from different angles, and it achieves state-of-the-art results in both training and inference speed \[[10' 2024-04-10](http://arxiv.org/abs/2404.06832v1)\].

[Snippet]: «Monitoring and detecting abnormal events in cyber-physical systems is crucial to industrial production. With the prevalent deployment of the Industrial Internet of Things (IIoT), an enormous amount of time series data is collected to facilitate machine learning models for anomaly detection, and it is of the utmost importance to directly deploy the trained models on the IIoT devices. However, it is most challenging to deploy complex deep learning models such as Convolutional Neural Networks (CNNs) on these memory-constrained IIoT devices embedded with microcontrollers (MCUs). To alleviate the memory constraints of MCUs, we propose a novel framework named Tiny Anomaly Detection (TinyAD) to efficiently facilitate onboard inference of CNNs for real-time anomaly detection. First, we conduct a comprehensive analysis of depthwise separable CNNs and regular CNNs for anomaly detection and find that the depthwise separable convolution operation can reduce the model size by 50-90% compared with the traditional CNNs. Then, to reduce the peak memory consumption of CNNs, we explore two complementary strategies, in-place, and patch-by-patch memory rescheduling, and integrate them into a unified framework. The in-place method decreases the peak memory of the depthwise convolution by sparing a temporary buffer to transfer the activation results, while the patch-by-patch method further reduces the peak memory of layer-wise execution by slicing the input data into corresponding receptive fields and executing in order. Furthermore, by adjusting the dimension of convolution filters, these strategies apply to both univariate time series and multidomain time series features. Extensive experiments on real-world industrial datasets show that our framework can reduce peak memory consumption by 2-5x with negligible computation overhead.»

PNPT comprises four essential modules: Class-Specific Normality Prompting Pool (CS-NPP), Hierarchical Patch Embedding (HPE), Semantic Alignment Coupling Encoding (SACE), and Contextual Semantic Conditional Decoding (CSCD). Moreover, it is necessary to estimate the scores for the entire system and its elements from a single framework, in order to identify relationships among the scores for localizing elements associated with anomaly. Here, we developed a new method to quantify anomalousness of an entire system and its elements simultaneously.
  The purpose of this paper is threefold. The first one is to propose a new anomaly detection method: Double Kernelized Scoring (DKS). DKS is a unified framework for entire-system anomaly scoring and element-wise anomaly scoring. Therefore, DKS allows for conducting simultaneously 1) anomaly detection for the entire system and 2) localization for identifying faulty elements responsible for the system anomaly. The second purpose is to propose a new kernel function: Matrix Kernel. The Matrix Kernel is defined between general matrices, which might have different dimensions, allowing for conducting anomaly detection on systems where the number of elements change over time. The third purpose is to demonstrate the effectiveness of the proposed method experimentally. We evaluated the proposed method with synthetic and real time series data. The results demonstrate that DKS is able to detect anomaly and localize the elements associated with it successfully.»
