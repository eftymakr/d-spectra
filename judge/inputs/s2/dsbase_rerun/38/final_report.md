## Related Works

Memory bandwidth regulation and cache partitioning have been extensively studied for achieving predictable timing in real-time computing systems \[[1' 2012-10-15](http://arxiv.org/abs/1210.4053v3)\]. These techniques are often combined with partitioned scheduling to co-allocate tasks and resources to cores, as task execution times strongly depend on the available allocated resources \[[1' 2012-10-15](http://arxiv.org/abs/1210.4053v3)\]. Prior work has explored various approaches to address this challenge, including heuristic algorithms for joint cache partition and job assignment \[[1' 2012-10-15](http://arxiv.org/abs/1210.4053v3)\]. These algorithms aim to minimize makespan by statically partitioning the cache and assigning jobs to cores, with some achieving a 2-approximation for specific cases \[[1' 2012-10-15](http://arxiv.org/abs/1210.4053v3)\].

Several studies have focused on dynamic memory bandwidth regulation, particularly in multi-core real-time systems, where contention over shared memory resources such as caches and DRAM introduces unpredictability \[[2' 2018-09-16](http://arxiv.org/abs/1809.05921v1)\]. Research has shown that the worst-case response time of tasks can be analyzed by considering the allocation of memory requests across different time intervals with varying bandwidth-to-core assignments \[[2' 2018-09-16](http://arxiv.org/abs/1809.05921v1)\]. This work has been applied to improve the schedulability of Integrated Modular Avionics systems under memory-intensive workloads \[[2' 2018-09-16](http://arxiv.org/abs/1809.05921v1)\].

Cache partitioning techniques have also been explored to mitigate interference among real-time tasks on multi-core processors \[[3' 2023-10-04](http://arxiv.org/abs/2310.02959v1)\]. Co-optimizing cache partitioning and task allocation improves system schedulability by considering the cache sensitivity of tasks \[[3' 2023-10-04](http://arxiv.org/abs/2310.02959v1)\]. A hybrid multi-layer design space exploration technique has been proposed to solve this multi-resource management problem, with results showing improvements in real-time schedulability by up to 233.6% for highly cache-sensitive tasks \[[3' 2023-10-04](http://arxiv.org/abs/2310.02959v1)\].

In the context of mixed-criticality systems, dynamic redistribution of shared cache has been proposed to enhance schedulability \[[8' 2017-04-28](http://arxiv.org/abs/1704.08876v1)\]. This approach allows for the reassignment of cache portions from lower-criticality tasks to higher-criticality tasks during mode changes, improving performance and ensuring provable schedulability \[[8' 2017-04-28](http://arxiv.org/abs/1704.08876v1)\]. The use of deadline-scaling techniques and WCET estimates that account for cache resources further supports this approach \[[8' 2017-04-28](http://arxiv.org/abs/1704.08876v1)\].

For multi-workflow scheduling in cloud environments, fairness has emerged as a critical objective alongside makespan and cost \[[7' 2022-05-23](http://arxiv.org/abs/2205.11173v1)\]. A new multi-objective optimization model has been introduced to address this, along with a global clustering-based scheduling strategy that improves fairness without significant compromises on makespan and cost \[[7' 2022-05-23](http://arxiv.org/abs/2205.11173v1)\].

In the area of mixed-variable black-box optimization, recent methods have been developed to handle continuous, integer, and categorical variables simultaneously \[[4' 2025-04-10](http://arxiv.org/abs/2504.07884v6)\]. We give a polynomial time algorithm for this scheduling problem for instances obtained by fixing the cache partition in a practical case of the joint cache partition and job assignment problem where job loads are step functions.»

	Document 1: \[[3' 2023-10-04](http://arxiv.org/abs/2310.02959v1)\] «Cache partitioning techniques have been successfully adopted to mitigate interference among concurrently executing real-time tasks on multi-core processors. Considering that the execution time of a cache-sensitive task strongly depends on the cache available for it to use, co-optimizing cache partitioning and task allocation improves the system's schedulability. In this paper, we propose a hybrid multi-layer design space exploration technique to solve this multi-resource management problem. We explore the interplay between cache partitioning and schedulability by systematically interleaving three optimization layers, viz., (i) in the outer layer, we perform a breadth-first search combined with proactive pruning for cache partitioning; (ii) in the middle layer, we exploit a first-fit heuristic for allocating tasks to cores; and (iii) in the inner layer, we use the well-known recurrence relation for the schedulability analysis of non-preemptive fixed-priority (NP-FP) tasks in a uniprocessor setting. Although our focus is on NP-FP scheduling, we evaluate the flexibility of our framework in supporting different scheduling policies (NP-EDF, P-EDF) by plugging in appropriate analysis methods in the inner layer. Experiments show that, compared to the state-of-the-art techniques, the proposed framework can improve the real-time schedulability of NP-FP task sets by an average of 15.2% with a maximum improvement of 233.6% (when tasks are highly cache-sensitive) and a minimum of 1.6% (when cache sensitivity is low). For such task sets, we found that clustering similar-period (or mutually compatible) tasks often leads to higher schedulability (on average 7.6%) than clustering by cache sensitivity. In our evaluation, the framework also achieves good results for preemptive and dynamic-priority scheduling policies.»
