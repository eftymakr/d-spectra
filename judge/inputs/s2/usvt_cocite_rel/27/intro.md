## Related Works

Recent advancements in information retrieval have focused on improving the efficiency and effectiveness of document and table retrieval systems. Traditional approaches rely on a pipeline consisting of representation, indexing, and search stages, where each stage is typically handled by separate components \[[15](http://arxiv.org/abs/2004.04906)\]. However, this approach can lead to error accumulation during the indexing and search phases, which negatively impacts retrieval accuracy \[[1](http://arxiv.org/abs/2206.10128)\]. To address these limitations, researchers have proposed differentiable search index (DSI) frameworks that unify indexing and retrieval into a single model \[[4](http://arxiv.org/abs/2202.06991)\]. These models encode all document information into the model parameters and directly map queries to relevant document identifiers, eliminating the need for separate indexing and retrieval stages \[[4](http://arxiv.org/abs/2202.06991)\]. This paradigm has been successfully applied to document retrieval, where DSI models outperform traditional methods by leveraging a unified encoder-decoder architecture \[[4](http://arxiv.org/abs/2202.06991)\].

In the context of table retrieval, existing methods often use dense vector search pipelines, which involve representing tables and queries as vectors, indexing them, and then performing a search \[[15](http://arxiv.org/abs/2004.04906)\]. While these methods achieve high accuracy, they face challenges in maintaining semantic alignment between queries and tables, especially when dealing with keyword mismatches or typos \[[14](http://arxiv.org/abs/2108.12139)\]. Furthermore, the indexing and search stages in these systems can introduce errors that propagate through the retrieval process, degrading overall performance \[[1](http://arxiv.org/abs/2206.10128)\]. To mitigate these issues, some approaches have introduced query generation models to create synthetic queries for each table, enabling more effective semantic alignment \[[12](http://arxiv.org/abs/2305.15115)\]. This idea is closely related to the approach used in the proposed Birdie framework, which generates synthetic queries for each table to enhance query-table interaction \[[1](http://arxiv.org/abs/2206.10128)\].

The Birdie framework also addresses the issue of catastrophic forgetting during continual indexing, a common challenge in online learning scenarios \[[10](http://arxiv.org/abs/2212.09744)\]. To mitigate this, Birdie introduces an index update strategy that isolates parameters during the update process, thereby reducing the risk of forgetting previously indexed tables \[[10](http://arxiv.org/abs/2212.09744)\]. This approach is inspired by continual learning techniques used in DSI models, where parameter isolation has been shown to improve model stability and performance during incremental updates \[[10](http://arxiv.org/abs/2212.09744)\].

In addition to DSI-based approaches, other works have explored the use of sparse representations for efficient retrieval \[[6](http://arxiv.org/abs/2107.05720)\]. For instance, SPLADE introduces a sparse lexical and expansion model that leverages explicit sparsity regularization to achieve competitive results with state-of-the-art dense and sparse methods \[[6](http://arxiv.org/abs/2107.05720)\]. Similarly, DeepImpact proposes a novel term-weighting scheme that improves impact-score modeling and tackles vocabulary-mismatch problems \[[5](http://arxiv.org/abs/2104.12016)\].
