## Related Works

Open-vocabulary object detection has emerged as a critical research direction, enabling detectors to recognize objects based on user-specified class vocabularies in natural language \[[1](http://arxiv.org/abs/2011.10678)\]. This capability is particularly valuable for applications requiring flexible and dynamic object recognition, such as content-based image retrieval and interactive vision systems \[[2](http://arxiv.org/abs/2104.13921)\]. However, the performance of such detectors can be significantly impacted by the quality and relevance of the user-defined vocabulary \[[3](http://arxiv.org/abs/2103.00020)\]. Prior work has explored various approaches to address these challenges, including weakly supervised learning, zero-shot detection, and vision-language pre-training \[[4](http://arxiv.org/abs/2205.06230)\].

Weakly supervised object detection methods aim to reduce the reliance on expensive bounding box annotations by using image-level labels or captions \[[5](http://arxiv.org/abs/2203.14940)\]. For instance, Cap2Det leverages unstructured textual descriptions to train detectors without requiring box annotations, demonstrating that captions can provide valuable supervision for object localization \[[6](http://arxiv.org/abs/2111.09452)\]. Similarly, Detic expands the vocabulary of detectors by training on image classification data, enabling detection of tens of thousands of classes without box annotations \[[7](http://arxiv.org/abs/2207.03482)\]. These approaches, however, often struggle with the accuracy of detecting novel or unseen objects, especially when the vocabulary is overly broad or mis-specified \[[8](http://arxiv.org/abs/2004.06165)\].

Zero-shot object detection methods attempt to detect novel object categories by leveraging semantic embeddings and pre-trained vision-language models \[[9](http://arxiv.org/abs/2201.02605)\]. CLIP, for example, aligns image and text representations to enable zero-shot recognition, but its performance in object detection is limited due to the lack of precise localization \[[10](http://arxiv.org/abs/2104.12763)\]. To address this, RegionCLIP was proposed to refine CLIP's region-level representations, enabling more accurate object detection \[[11](http://arxiv.org/abs/2207.08954)\]. Similarly, ViLD uses vision-language knowledge distillation to train detectors that can generalize to novel categories, achieving competitive performance on benchmarks like LVIS \[[12](http://arxiv.org/abs/1907.10164)\].

Recent advances in open-vocabulary detection have focused on improving scalability and performance through large-scale pre-training and pseudo-labeling \[[13](http://arxiv.org/abs/1908.03195)\]. For example, MDETR introduces an end-to-end modulated detector that conditions object detection on natural language queries, demonstrating the potential of vision-language models for open-vocabulary tasks \[[14](http://arxiv.org/abs/2111.12698)\]. Similarly, Open-Vocabulary DETR with Conditional Matching enables detectors to respond to both text and image queries, offering greater flexibility in user interaction \[[15](http://arxiv.org/abs/1405.0312)\]. These methods, however, often require extensive training or fine-tuning, which can be computationally expensive \[[16](https://www.semanticscholar.org/paper/c5ff974a69fd0c760b4855b819e61e89f31cfffe)\].

In contrast, the proposed Vocabulary Adapter (VocAda) offers a lightweight and plug-and-play solution for refining user-defined vocabularies at inference time \[[17](http://arxiv.org/abs/2112.09106)\].

Open-vocabulary object detection has emerged as a critical area of research, aiming to expand the capabilities of object detectors beyond fixed, pre-defined class sets \[[1](http://arxiv.org/abs/2011.10678)\]. Additionally, methods like VocAda have introduced novel ways to refine user-defined vocabularies at inference time, improving detection accuracy by dynamically adapting to the content of each image \[[1](http://arxiv.org/abs/2011.10678)\]. These advancements highlight the growing focus on scalable and flexible object detection frameworks that balance performance with practicality \[[1](http://arxiv.org/abs/2011.10678)\]\[[9](http://arxiv.org/abs/2201.02605)\].

Vision-language pre-training approaches have been increasingly explored to enhance open-vocabulary object detection and zero-shot transfer learning. Other works, such as Oscar \[[8](http://arxiv.org/abs/2004.06165)\], propose methods to align image regions with text by using object tags as anchor points, leading to better semantic alignments. These approaches highlight the potential of vision-language pre-training in addressing challenges such as long-tailed distributions and open-vocabulary settings, often achieving state-of-the-art results without requiring extensive labeled data \[[3](http://arxiv.org/abs/2103.00020)\]\[[8](http://arxiv.org/abs/2004.06165)\]\[[10](http://arxiv.org/abs/2104.12763)\]\[[17](http://arxiv.org/abs/2112.09106)\]\[[22](http://arxiv.org/abs/2204.05626)\].

### <a id='category-zero-shot-detection-techniques'></a>Zero-shot detection techniques: 4 papers found.
The category of zero-shot detection techniques focuses on detecting objects that were not present in the training data, leveraging semantic information from pre-trained models or external knowledge. Researchers have proposed various approaches to address the challenges of aligning visual and textual representations, handling class imbalance, and improving generalization to unseen categories. For instance, PromptDet introduces a two-stage open-vocabulary object detector that uses a text encoder from a pre-trained visual-language model to classify class-agnostic object proposals \[[18](http://arxiv.org/abs/2203.16513)\]. Similarly, OV-DETR extends DETR to support open-vocabulary detection by conditioning the Transformer decoder on input embeddings from a pre-trained vision-language model like CLIP, enabling detection based on class names or exemplar images \[[20](http://arxiv.org/abs/2203.11876)\]. Another work, ZSD, tackles zero-shot object detection by adapting visual-semantic embeddings and proposing background-aware approaches to enhance robustness \[[23](http://arxiv.org/abs/1804.04340)\]. Additionally, the Polarity loss framework addresses class imbalance and visual-semantic alignment by maximizing the gap between positive and negative predictions, resolving ambiguities between background and unseen classes \[[28](https://www.semanticscholar.org/paper/90dd5e8fe3e117d87c7029af5cfb811c16791a7f)\]. These methods collectively highlight the importance of semantic alignment, efficient learning strategies, and robust inference mechanisms in zero-shot detection.
