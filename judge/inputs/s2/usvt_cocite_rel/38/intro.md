## Related Works

Memory bandwidth regulation and cache partitioning have been widely studied as techniques to achieve predictable timing in real-time computing systems \[[1](https://www.semanticscholar.org/paper/bbebaeb1b00fdcde2aeb192543835d3ec1518f8d)\]. These approaches are often combined with partitioned scheduling to ensure that tasks are allocated to specific cores and resources in a way that minimizes interference \[[2](https://www.semanticscholar.org/paper/50d359dc737cb5c296b527f4eb1541dc55f3ed86)\]. Task execution times are heavily influenced by the availability of allocated resources, which necessitates careful co-allocation of tasks and resources \[[3](https://www.semanticscholar.org/paper/25ebad66dc10d7b01c22684cbb200ddeb6502475)\]. 

Several works have explored the challenges of memory contention in multi-core systems. For instance, \[[4](http://arxiv.org/abs/1809.05921)\] highlights that contention over shared memory resources, such as caches, interconnects, and DRAM, is a primary source of unpredictability in modern multi-core embedded systems. This unpredictability complicates the design of real-time systems that require deterministic behavior \[[5](https://www.semanticscholar.org/paper/0b1bc294dbd926f853a8ee41d1d8f8ecc3cfde13)\]. To address this, \[[6](https://www.semanticscholar.org/paper/dbd4eb5033815003e7f6519fd66e43e5fc297075)\] proposes a framework for dynamic allocation of main memory bandwidth, focusing on determining the worst-case response time of tasks under varying bandwidth-to-core assignments. This work demonstrates how such analysis can improve the schedulability of complex systems like Integrated Modular Avionics \[[7](https://www.semanticscholar.org/paper/f71c848137ac1398f84e6ab7d896641f801ca192)\].

Cache management is another critical area. \[[8](https://www.semanticscholar.org/paper/afca4afaaaa543a1da02b266e9b2ac46eb94793b)\] introduces a real-time cache management framework that addresses the challenges of managing shared cache resources in multi-core architectures. This work emphasizes the need for fine-grained control over cache behavior to ensure predictable performance \[[9](https://www.semanticscholar.org/paper/6e925ae85e385ac0e8810441d84be97c079f6b22)\]. Similarly, \[[10](https://www.semanticscholar.org/paper/d5336fd2234f431f554fc5d878503a04a27e366e)\] explores the use of programmable logic in-the-middle (PLIM) to manipulate memory transactions, offering a novel approach to cache coloring and reducing interference \[[11](https://www.semanticscholar.org/paper/e8d15aa827be70bebf15e217ac9295276ddebda7)\].

Memory interference in commercial-off-the-shelf (COTS) multi-core systems has also been studied. \[[12](http://arxiv.org/abs/1903.00999)\] presents techniques to bound worst-case memory interference delay, modeling key resources such as DRAM banks, buses, and memory controllers. This work is significant as it provides a tight upper bound on memory interference, which is crucial for predictable real-time systems \[[13](https://www.semanticscholar.org/paper/abbd6f8840092bd8e4e3684d3297e1b707abdc5d)\].
