## Related Works

Multi-Domain Recommendation (MDR) has emerged as a promising approach to enhance recommendation performance by leveraging knowledge transfer across different domains \[[1](http://arxiv.org/abs/2103.01696)\]. Traditional MDR methods often assume a single transfer structure, which may not be suitable for complex domain interactions \[[1](http://arxiv.org/abs/2103.01696)\]. This limitation has led to the Negative Transfer Problem (NTP), where unselective knowledge transfer can degrade performance, especially when domains conflict or have poor quality \[[1](http://arxiv.org/abs/2103.01696)\]. 

Several approaches have been proposed to address these challenges. For instance, CoNet introduces a deep transfer learning framework using neural networks to model complex user-item interactions and enable dual knowledge transfer across domains \[[3](http://arxiv.org/abs/1804.06769)\]. The model utilizes cross connections and joint loss functions to improve recommendation accuracy \[[3](http://arxiv.org/abs/1804.06769)\]. Similarly, the BiTGCF model employs a bi-directional transfer learning method based on graph collaborative filtering, enabling two-way knowledge transfer through common users and capturing high-order interactions \[[4](https://www.semanticscholar.org/paper/d5630291a4ba3f6266c77e6d00920502f986afa6)\]. 

The DDTCDR model further advances the field by introducing a dual learning mechanism that iteratively transfers information between domains until convergence \[[5](http://arxiv.org/abs/1910.05189)\]. This approach uses latent orthogonal mapping to preserve user relations across latent spaces and autoencoder techniques to extract feature essence, resulting in improved performance on multi-domain datasets \[[5](http://arxiv.org/abs/1910.05189)\]. 

In addition, the PPGN model addresses cross-domain sparsity by constructing a Cross-Domain Preference Matrix (CDPM) and using a preference propagation layer to model high-order information propagation \[[6](https://www.semanticscholar.org/paper/24a473700894dbfab0bfd9dc3d542acfeef66bca)\]. This approach simplifies cross-domain recommendation into a unified multi-task model, achieving significant improvements over existing methods \[[6](https://www.semanticscholar.org/paper/24a473700894dbfab0bfd9dc3d542acfeef66bca)\]. 

The AFT model introduces adversarial feature translation to capture domain-specific features and inter-domain interactions, using a generative adversarial network framework \[[8](https://www.semanticscholar.org/paper/7807d924fa46caec7b706b98156962caf8458d59)\]. This method enables the learning of feature translations between domains and explicitly models relationships between items, domains, and user representations \[[8](https://www.semanticscholar.org/paper/7807d924fa46caec7b706b98156962caf8458d59)\]. 

The MCF model, on the other hand, addresses data sparsity by considering multiple collaborative filtering tasks across domains and using probabilistic matrix factorization to adaptively transfer knowledge \[[9](http://arxiv.org/abs/1203.3535)\]. This approach introduces a link function to correct domain biases and improves performance on real-world applications \[[9](http://arxiv.org/abs/1203.3535)\]. 

The GA framework proposes a unified approach for cross-domain and cross-system recommendations, incorporating graph embedding and attention techniques to improve performance across multiple datasets \[[10](http://arxiv.org/abs/2108.07976)\]. This model uses personalized training strategies to minimize embedding differences between domains and achieves significant improvements over state-of-the-art approaches \[[10](http://arxiv.org/abs/2108.07976)\].
