## Related Works

Personalized outfit generation has gained significant attention in recent years due to its potential to enhance user experience in fashion recommendation systems. Prior work has primarily focused on two aspects: outfit compatibility and personalization. Early approaches relied on rule-based systems or simple similarity metrics to recommend compatible fashion items \[[1](http://arxiv.org/abs/1905.01866)\]. However, these methods lacked the ability to capture complex style patterns and user preferences effectively.

Recent advances in deep learning have enabled more sophisticated models for outfit generation and recommendation. For instance, \[[2](http://arxiv.org/abs/1608.03016)\] proposed a machine learning system to automatically compose fashion outfits by scoring candidates based on appearance and metadata, achieving an AUC of 85% for the scoring component. Similarly, \[[3](http://arxiv.org/abs/1807.03133)\] introduced a model that incorporated an unsupervised style extraction module to generate more flexible and interpretable outfits. This model outperformed baselines in fashion item prediction and style extraction tasks.

The importance of compatibility between fashion items has also been widely studied. \[[4](http://arxiv.org/abs/1803.09196)\] presented an approach to learn type-aware embeddings that respect item type and jointly model similarity and compatibility. This method improved compatibility prediction by 3–5% over state-of-the-art approaches. \[[5](http://arxiv.org/abs/1711.02231)\] further extended this work by learning visual-semantic embeddings using bidirectional LSTMs, enabling the model to predict compatibility relationships and generate outfits based on user preferences.

In addition to compatibility, personalization has become a key focus in outfit recommendation. \[[6](http://arxiv.org/abs/1712.02662)\] introduced a system that leverages user click behavior to recommend personalized outfits, demonstrating strong performance in offline experiments. \[[7](http://arxiv.org/abs/1904.00741)\] proposed a model that uses self-attention to learn mappings from current outfits to visual descriptors, enabling scalable and explainable outfit generation. This approach was evaluated on large datasets and showed promising results in generating coherent outfits.

Several studies have also explored the use of generative models for outfit generation. \[[8](http://arxiv.org/abs/1707.05691)\] introduced a framework that combines visual and textual features to learn embeddings in a latent style space, improving compatibility prediction and outfit generation. \[[9](http://arxiv.org/abs/1805.00313)\] proposed a neural compatibility modeling scheme with attentive knowledge distillation, integrating domain knowledge into the learning process to improve matching accuracy.

The challenge of generating diverse and personalized outfits has also been addressed in recent work. \[[10](http://arxiv.org/abs/1509.07473)\] introduced a method that uses text and image embeddings to represent fashion items, enabling the generation of outfits that match a specified theme. This approach outperformed existing methods in terms of compatibility prediction and query coherence. \[[11](http://arxiv.org/abs/1506.04757)\] further extended this idea by introducing a system that learns visual compatibility from user behavior data, improving the accuracy of outfit recommendations.
