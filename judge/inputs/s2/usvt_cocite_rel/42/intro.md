## Related Works

The growing adoption of cloud-native applications has led to increased reliance on containerization technologies and managed cloud services to achieve rapid deployment and scalability. Kubernetes, in particular, has emerged as a de facto standard for orchestrating containerized applications \[[1](https://www.semanticscholar.org/paper/d11e5c5c08af88ee8abb9ebaa166b1d6fd198501)\]. Prior research has focused on optimizing resource efficiency and cost at the system level, but network costs in Kubernetes clusters have remained underexplored \[[1](https://www.semanticscholar.org/paper/d11e5c5c08af88ee8abb9ebaa166b1d6fd198501)\]. This paper contributes to the emerging field of FinOps, which integrates financial management with cloud operations to optimize costs in cloud-based applications \[[1](https://www.semanticscholar.org/paper/d11e5c5c08af88ee8abb9ebaa166b1d6fd198501)\]. 

Several studies have examined the performance and resource management of containerized applications in cloud environments. For instance, \[[5](http://arxiv.org/abs/2010.10350)\] investigates the performance of computational-intensive applications such as big data and deep learning in cloud-native environments, highlighting the impact of resource management schemes on completion time and resource usage. The paper demonstrates that changing default settings can reduce completion time by up to 79.4%, while different resource management schemes can increase it by up to 96.7%. This underscores the importance of fine-tuning resource allocation strategies to achieve optimal performance and cost efficiency \[[5](http://arxiv.org/abs/2010.10350)\].

In addition, \[[15](http://arxiv.org/abs/1901.05998)\] addresses the scheduling problem in distributed computing frameworks, focusing on jobs with diverse resource requirements. The study proposes oblivious scheduling algorithms that can achieve at least 1/2 and 2/3 of the maximum throughput without requiring knowledge of traffic or resource requirement distributions. These algorithms are designed to handle high-dimensional settings where traditional scheduling approaches are less effective \[[15](http://arxiv.org/abs/1901.05998)\]. This work is relevant to the broader context of optimizing resource allocation and cost management in Kubernetes clusters.

The integration of container orchestration platforms like Kubernetes with cloud-native workflows has also been explored. For example, \[[13](https://www.semanticscholar.org/paper/d32b4e8ef3fbde009efa47249081feaa4aac8b27)\] presents a cloud provider-agnostic and scalable container orchestration setup for the Galaxy workflow environment, enabling it to run on and offload jobs to various cloud providers through Kubernetes. This approach enhances the scalability and reproducibility of bioinformatics workflows \[[13](https://www.semanticscholar.org/paper/d32b4e8ef3fbde009efa47249081feaa4aac8b27)\]. Similarly, \[[8](https://www.semanticscholar.org/paper/d1b8c407ddcf31dba806e580de02cb8c873ea2a6)\] describes the PhenoMeNal e-infrastructure, which provides a complete, workflow-oriented solution for metabolomics data analysis using Docker containers and Kubernetes orchestration. The platform supports dynamic scaling, reproducibility, and interoperability, making it suitable for large-scale analyses \[[8](https://www.semanticscholar.org/paper/d1b8c407ddcf31dba806e580de02cb8c873ea2a6)\].
