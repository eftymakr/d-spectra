## Related Works

Conversational recommender systems (CRSs) have emerged as a promising approach to address the limitations of traditional recommendation systems by enabling dynamic, multi-turn interactions with users to better capture their preferences \[[1](http://arxiv.org/abs/2004.00646)\]. Unlike static models that rely solely on historical data, CRSs allow for real-time feedback and clarification, which can significantly improve recommendation accuracy \[[2](http://arxiv.org/abs/2002.09102)\]. However, designing effective conversational recommendation systems remains challenging due to the complexity of user preferences and the need for efficient interaction strategies \[[3](http://arxiv.org/abs/2101.09459)\].

Several studies have explored the integration of conversational elements into recommendation frameworks. For instance, \[[4](http://arxiv.org/abs/2007.00194)\] introduced the Estimation-Action-Reflection (EAR) framework, which structures the interaction into three stages: estimating user preferences, deciding when to ask for attribute information or recommend items, and refining the model based on user feedback. This approach emphasizes the importance of dynamic adaptation during conversations \[[5](http://arxiv.org/abs/2007.04032)\]. Similarly, \[[6](http://arxiv.org/abs/2006.08732)\] proposed a multi-turn conversational recommendation system that leverages attribute-based feedback to refine recommendations iteratively. These methods highlight the need for mechanisms that can effectively model and adapt to user preferences in real-time \[[7](http://arxiv.org/abs/2105.09710)\].

To enhance the quality of recommendations, researchers have also focused on incorporating external knowledge and user feedback. For example, \[[8](http://arxiv.org/abs/1806.03277)\] introduced a framework that integrates knowledge graphs to bridge the semantic gap between natural language and item-level preferences, improving both recommendation accuracy and conversational coherence. Additionally, \[[9](https://www.semanticscholar.org/paper/3ae5bef6b0c8317603a2deab2527383580904fd8)\] proposed a system that uses user feedback to refine recommendations by aligning word-level and entity-level semantic representations, further improving the alignment between user intent and system responses \[[10](http://arxiv.org/abs/2206.09363)\].

The evaluation of conversational recommendation systems has also been a focus of recent research. \[[11](https://www.semanticscholar.org/paper/33e0fe2d4cf01b16da89ab0c180cdcbf37b3be17)\] developed a user simulation toolkit that enables automated evaluation of CRSs by simulating realistic user interactions. This approach is particularly useful for assessing the performance of recommendation systems in dynamic, multi-turn scenarios \[[12](https://www.semanticscholar.org/paper/2610b45131f31a7c58b0cd6a8fce21c02ba014be)\]. Furthermore, \[[13](http://arxiv.org/abs/2304.13874)\] proposed a user simulator that generates realistic feedback based on user preferences and interaction history, enabling more accurate and scalable evaluation of conversational recommendation systems \[[14](https://www.semanticscholar.org/paper/49846c2d069c324d5d3f3b53cb74b13e84b7caeb)\].

In addition to these efforts, some works have explored the use of reinforcement learning to optimize conversational recommendation strategies. \[[15](http://arxiv.org/abs/2005.14255)\] introduced a unified policy learning framework that integrates conversation and recommendation components, enabling the system to dynamically decide when to ask for attribute information or recommend items based on user feedback \[[16](http://arxiv.org/abs/2301.05544)\]. This approach has shown promising results in improving the efficiency and effectiveness of conversational recommendation systems \[[17](http://arxiv.org/abs/2009.14306)\].
