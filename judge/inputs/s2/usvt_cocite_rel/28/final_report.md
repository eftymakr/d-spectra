## Related Works

Federated Learning (FL) has emerged as a promising paradigm for training machine learning models on decentralized data while preserving privacy \[[4](http://arxiv.org/abs/1912.04977)\]. In FL, a central server coordinates the training of a global model using updates from multiple clients, each holding their own private data \[[2](http://arxiv.org/abs/1610.05492)\]. However, the heterogeneity of client data distributions poses significant challenges to model convergence and accuracy \[[10](http://arxiv.org/abs/1806.00582)\]. This issue is further compounded by the communication constraints inherent in FL, where clients often have limited bandwidth and computational resources \[[2](http://arxiv.org/abs/1610.05492)\].

Several works have addressed the problem of non-IID data in FL. For instance, \[[10](http://arxiv.org/abs/1806.00582)\] demonstrates that federated learning accuracy can degrade significantly under non-IID conditions, with reductions up to 55% for neural networks trained on highly skewed data. The paper proposes a strategy of sharing a small subset of data globally to improve accuracy, achieving a 30% improvement on the CIFAR-10 dataset with only 5% shared data. Similarly, \[[8](http://arxiv.org/abs/2102.02079)\] highlights the challenges posed by non-IID data in federated visual classification, showing that performance degrades as data distributions diverge. The paper introduces a mitigation strategy via server momentum, improving classification accuracy from 30.1% to 76.9% in the most skewed settings.

To improve convergence in heterogeneous settings, \[[11](http://arxiv.org/abs/1812.06127)\] introduces FedProx, a framework that generalizes and re-parameterizes FedAvg. Theoretical guarantees are provided for non-identical data distributions, and empirical results show that FedProx improves test accuracy by 22% on average. \[[12](http://arxiv.org/abs/1910.06378)\] further addresses the issue of client data heterogeneity by proposing SCAFFOLD, an algorithm that reduces drift between clients using control variates. Theoretical analysis shows that SCAFFOLD requires significantly fewer communication rounds and has favorable convergence guarantees.

In addition to addressing non-IID data, \[[13](http://arxiv.org/abs/2006.07242)\] explores more flexible aggregation schemes for FL, proposing ensemble distillation for model fusion. This technique allows for aggregation over heterogeneous client models, enabling faster convergence and fewer communication rounds compared to existing methods. \[[14](http://arxiv.org/abs/1910.01991)\] presents clustered FL (CFL), a novel framework that groups clients based on data distribution to improve model performance. CFL is model-agnostic and does not require prior knowledge of the number of clusters, offering strong mathematical guarantees on clustering quality.

Recent work has also focused on improving fairness in FL. \[[6](http://arxiv.org/abs/1905.10497)\] introduces q-FFL, an optimization objective inspired by fair resource allocation, aiming to achieve a more uniform accuracy

### <a id='category-federated-learning-frameworks'></a>Federated Learning Frameworks: 11 papers found.
Federated learning (FL) has emerged as a critical paradigm for training machine learning models while preserving data privacy by keeping training data decentralized \[[3](http://arxiv.org/abs/2003.00295)\]. However, the heterogeneity of client data and system constraints poses significant challenges to model convergence and performance \[[11](http://arxiv.org/abs/1812.06127)\]. Existing approaches, such as Federated Averaging (FedAvg), often struggle with non-identically distributed data, leading to slow convergence and poor generalization \[[12](http://arxiv.org/abs/1910.06378)\]. To address these issues, researchers have proposed adaptive optimization methods, including federated versions of Adagrad, Adam, and Yogi, which show improved convergence and performance in heterogeneous settings \[[3](http://arxiv.org/abs/2003.00295)\]. Additionally, frameworks like FedProx have been introduced to handle both statistical and systems heterogeneity by modifying FedAvg with a proximal term, resulting in more stable and accurate convergence \[[11](http://arxiv.org/abs/1812.06127)\]. Furthermore, novel approaches such as clustered FL (CFL) leverage geometric properties of the loss surface to group clients with similar data distributions, enabling more effective model training without altering the communication protocol \[[14](http://arxiv.org/abs/1910.01991)\]. These advancements highlight the ongoing efforts to improve the robustness and efficiency of federated learning in real-world scenarios \[[15](http://arxiv.org/abs/1909.12488)\].

	Document 1: [Snippet]: «Federated Learning is a machine learning setting where the goal is to train a high-quality centralized model while training data remains distributed over a large number of clients each with unreliable and relatively slow network connections. We consider learning algorithms for this setting where on each round, each client independently computes an update to the current model based on its local data, and communicates this update to a central server, where the client-side updates are aggregated to compute a new global model. Experiments on both convolutional and recurrent networks show that the proposed methods can reduce the communication cost by two orders of magnitude.»

### <a id='category-client-heterogeneity-mitigation'></a>Client Heterogeneity Mitigation: 1 papers found.

	Document 1: [Snippet]: «We envision a mobile edge computing (MEC) framework for machine learning (ML) technologies, which leverages distributed client data and computation resources for training high-performance ML models while preserving client privacy. Toward this future goal, this work aims to extend Federated Learning (FL), a decentralized learning framework that enables privacy-preserving training of models, to work with heterogeneous clients in a practical cellular network. The FL protocol iteratively asks random clients to download a trainable model from a server, update it with own data, and upload the updated model to the server, while asking the server to aggregate multiple client updates to further improve the model. Specifically, FedCS solves a client selection problem with resource constraints, which allows the server to aggregate as many client updates as possible and to accelerate performance improvement in ML models. We conducted an experimental evaluation using publicly-available large-scale image datasets to train deep neural networks on MEC environment simulations. The experimental results show that FedCS is able to complete its training process in a significantly shorter time compared to the original FL protocol.»

### <a id='category-non-iid-data-challenges'></a>Non-IID Data Challenges: 3 papers found.
Non-IID data distribution is a significant challenge in federated learning, as it leads to performance degradation in model training. This issue arises because the data across different clients is often not identically distributed, resulting in varying statistical properties and making it difficult for the global model to generalize effectively \[[7](http://arxiv.org/abs/1909.06335)\]. Research has shown that the accuracy of federated learning can decrease significantly, with some studies reporting reductions of up to 55% for neural networks trained on highly skewed non-IID data \[[10](http://arxiv.org/abs/1806.00582)\]. The degradation is attributed to weight divergence, which can be measured using the earth mover's distance between the local and global data distributions \[[10](http://arxiv.org/abs/1806.00582)\]. To mitigate these challenges, various strategies have been proposed, including the use of server momentum to stabilize training and the creation of a small globally shared dataset to improve model accuracy \[[7](http://arxiv.org/abs/1909.06335)\]. Additionally, there is a growing body of work that explores different data partitioning strategies to better understand and address the impact of non-IID data in federated learning \[[8](http://arxiv.org/abs/2102.02079)\]. These studies highlight the importance of addressing non-IID data distribution to enhance the effectiveness of federated learning systems.

### <a id='category-model-aggregation-techniques'></a>Model Aggregation Techniques: 1 papers found.
Context: 
	Document 1: [Snippet]: «Federated Learning (FL) is a machine learning setting where many devices collaboratively train a machine learning model while keeping the training data decentralized. In most of the current training schemes the central model is refined by averaging the parameters of the server model and the updated parameters from the client side. However, directly averaging model parameters is only possible if all models have the same structure and size, which could be a restrictive constraint in many scenarios. 
In this work we investigate more powerful and more flexible aggregation schemes for FL. Specifically, we propose ensemble distillation for model fusion, i.e. training the central classifier through unlabeled data on the outputs of the models from the clients. This knowledge distillation technique mitigates privacy risk and cost to the same extent as the baseline FL algorithms, but allows flexible aggregation over heterogeneous client models that can differ e.g. in size, numerical precision or structure. We show in extensive empirical experiments on various CV/NLP datasets (CIFAR-10/100, ImageNet, AG News, SST2) and settings (heterogeneous models/data) that the server model can be trained much faster, requiring fewer communication rounds than any existing FL technique so far.»
