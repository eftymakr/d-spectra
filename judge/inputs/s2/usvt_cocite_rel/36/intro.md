## Related Works

Deploying large language models (LLMs) on edge devices has been a focal point of recent research due to the increasing demand for privacy-preserving and low-latency AI applications \[[1](http://arxiv.org/abs/2306.00978)\]. Several approaches have been proposed to address the challenges of memory, computation, and energy constraints on resource-limited edge hardware. One notable effort is the development of quantization techniques that reduce model size while preserving performance. AWQ \[[1](http://arxiv.org/abs/2306.00978)\] introduces an activation-aware quantization method that identifies and protects salient weights, enabling up to 4x model size reduction and 3-4x acceleration across various edge platforms. Similarly, SmoothQuant \[[4](http://arxiv.org/abs/2211.10438)\] enables 8-bit weight and activation quantization without significant accuracy loss, achieving up to 1.56x speedup and 2x memory reduction for LLMs. These methods are crucial for enabling efficient inference on edge devices with limited resources.

Efficient memory management is another critical area of research. PagedAttention \[[2](http://arxiv.org/abs/2309.06180)\] addresses the issue of dynamic memory allocation for key-value (KV) caches by leveraging virtual memory and paging techniques, achieving near-zero waste in KV cache memory. This is particularly important for high-throughput serving of large LLMs. Additionally, LLM.int8() \[[14](http://arxiv.org/abs/2208.07339)\] enables 8-bit matrix multiplication for Transformers, reducing memory usage by half while maintaining full precision performance. This approach is essential for deploying large models on consumer-grade GPUs and edge devices.

Optimization at the hardware level has also seen significant advancements. T-MAC \[[6](http://arxiv.org/abs/2407.00088)\] introduces a lookup table (LUT)-based method for low-bit LLM inference on CPUs, directly supporting mixed precision matrix multiplication (mpGEMM) without dequantization. This leads to up to 4× increase in throughput and 70% reduction in energy consumption compared to llama.cpp. Similarly, LUT-GEMM \[[16](http://arxiv.org/abs/2206.09557)\] eliminates the resource-intensive dequantization process, reducing computational costs and improving inference speed. These methods demonstrate the potential of hardware-aware optimizations for efficient LLM deployment.

Edge computing has also been explored through collaborative frameworks. This approach is particularly useful for deploying large models on distributed edge environments.
