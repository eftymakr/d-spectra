## Related Works

Semi-supervised learning (SSL) has emerged as a powerful paradigm for improving model performance when labeled data is scarce \[[1](https://www.semanticscholar.org/paper/f3df804a7eef204b0c4fc4b81166dec9b4abc073)\]. Traditional SSL methods assume that labeled and unlabeled data share the same class distribution \[[1](https://www.semanticscholar.org/paper/f3df804a7eef204b0c4fc4b81166dec9b4abc073)\], but this assumption is often violated in practice, as unlabeled data may contain out-of-distribution (OOD) samples, i.e., outliers \[[1](https://www.semanticscholar.org/paper/f3df804a7eef204b0c4fc4b81166dec9b4abc073)\]. These outliers are typically treated as noise, which significantly degrades the performance of SSL models \[[1](https://www.semanticscholar.org/paper/f3df804a7eef204b0c4fc4b81166dec9b4abc073)\]. To address this issue, several methods have been proposed to handle open-set SSL, where unlabeled data may include OOD samples \[[1](https://www.semanticscholar.org/paper/f3df804a7eef204b0c4fc4b81166dec9b4abc073)\].

One approach is to detect OOD samples and filter them out before training \[[1](https://www.semanticscholar.org/paper/f3df804a7eef204b0c4fc4b81166dec9b4abc073)\]. For example, the work in \[[2](http://arxiv.org/abs/2007.11330)\] proposes a multi-task curriculum learning framework that jointly optimizes OOD detection and SSL. This method estimates the probability of a sample being OOD and uses a joint optimization framework to update the network parameters and OOD scores \[[2](http://arxiv.org/abs/2007.11330)\]. Similarly, \[[3](http://arxiv.org/abs/2001.07685)\] introduces a warm-up training phase that leverages all unlabeled data, including both in-distribution (ID) and OOD samples, to obtain discriminative features \[[3](http://arxiv.org/abs/2001.07685)\]. A cross-modal matching strategy is then used to detect OOD samples \[[3](http://arxiv.org/abs/2001.07685)\].

Another line of research focuses on improving the robustness of SSL models in the presence of OOD data. For instance, \[[4](http://arxiv.org/abs/2108.05617)\] proposes a method that combines FixMatch with novelty detection using one-vs-all (OVA) classifiers \[[4](http://arxiv.org/abs/2108.05617)\]. The OVA classifier outputs confidence scores for inlier detection, which are used to filter out outliers \[[4](http://arxiv.org/abs/2108.05617)\]. Additionally, \[[5](http://arxiv.org/abs/2105.14148)\] introduces an open-set soft-consistency regularization loss that enhances the smoothness of the OVA classifier with respect to input transformations, improving outlier detection \[[5](http://arxiv.org/abs/2105.14148)\].

The problem of OOD detection has also been addressed using confidence calibration techniques. \[[6](http://arxiv.org/abs/1905.02249)\] presents a method that trains classifiers to be more confident about in-distribution samples while being less confident about OOD samples \[[6](http://arxiv.org/abs/1905.02249)\]. This is achieved by adding additional terms to the loss function that encourage the model to be less confident about OOD samples \[[6](http://arxiv.org/abs/1905.02249)\]. \[[7](http://arxiv.org/abs/2107.08943)\] further extends this idea by proposing a method that jointly trains both classification and generative neural networks to improve OOD detection \[[7](http://arxiv.org/abs/2107.08943)\].

### <a id='category-outlier-treatment-in-ssl'></a>Outlier Treatment in SSL: 5 papers found.
In the context of outlier treatment in semi-supervised learning (SSL), existing methods often assume that labeled and unlabeled data share the same class distribution, which is frequently violated in real-world scenarios where unlabeled data may contain outliers from novel categories \[[1](https://www.semanticscholar.org/paper/f3df804a7eef204b0c4fc4b81166dec9b4abc073)\]. This assumption leads to performance degradation due to error propagation and poor handling of out-of-distribution (OOD) samples \[[1](https://www.semanticscholar.org/paper/f3df804a7eef204b0c4fc4b81166dec9b4abc073)\]. To address this, several approaches have been proposed. For instance, OpenMatch introduces an open-set SSL framework that combines FixMatch with novelty detection using one-vs-all (OVA) classifiers, enabling the identification of outliers through confidence scores \[[5](http://arxiv.org/abs/2105.14148)\]. Similarly, the Simple but Strong Baseline (SSB) leverages high-confidence pseudo-labeled data and non-linear transformations to separate inlier classification from outlier detection, improving both tasks simultaneously \[[13](http://arxiv.org/abs/2311.10572)\]. Additionally, the Transferable OOD data Recycling (TOOR) method treats OOD data as potentially useful if they are transferable to the in-distribution (ID) data, using adversarial domain adaptation to align their distribution with known classes \[[20](http://arxiv.org/abs/2011.13529)\]. Meanwhile, the Dash framework dynamically selects unlabeled examples based on loss thresholds, ensuring only relevant pseudo-labeled data are used during training \[[21](http://arxiv.org/abs/2109.00650)\]. These methods collectively highlight the challenges of handling outliers in SSL and demonstrate various strategies to improve robustness and performance in open-set settings.

### <a id='category-confidence-calibration-techniques'></a>Confidence Calibration Techniques: 5 papers found.
In the context of confidence calibration techniques for semi-supervised learning, several approaches have been proposed to improve model performance by effectively utilizing unlabeled data. Early methods like FixMatch \[[16](http://arxiv.org/abs/2110.08263)\] introduced a simple yet effective combination of pseudo-labeling and consistency regularization, achieving state-of-the-art results on benchmarks such as CIFAR-10 with limited labeled data. However, FixMatch used a fixed threshold for pseudo-label selection, which could limit its adaptability to varying learning dynamics \[[16](http://arxiv.org/abs/2110.08263)\]. Subsequent works, such as MixMatch \[[6](http://arxiv.org/abs/1905.02249)\], further advanced the field by incorporating data augmentation and label guessing strategies, significantly improving performance across multiple datasets. More recently, FreeMatch \[[14](http://arxiv.org/abs/2205.07246)\] introduced a self-adaptive threshold mechanism to better align with the model's learning status, leading to improved performance, especially in scenarios with extremely rare labeled data. Similarly, FlexMatch \[[16](http://arxiv.org/abs/2110.08263)\] built upon FixMatch by introducing a curriculum learning approach that dynamically adjusts class-specific thresholds, enhancing robustness and convergence speed. These methods highlight the importance of adaptive confidence calibration in semi-supervised learning, as they address limitations of fixed threshold approaches and improve generalization in challenging settings. Additionally, CoMatch \[[17](http://arxiv.org/abs/2011.11183)\] demonstrated the potential of unifying different SSL approaches to achieve state-of-the-art results by jointly learning class probabilities and embeddings, further emphasizing the role of confidence calibration in improving pseudo-label quality. Overall, these works underscore the critical role of confidence-based strategies in enhancing semi-supervised learning performance, particularly in scenarios where labeled data is scarce or imbalanced.
