## Related Works

Maximum Inner Product Search (MIPS) has been a central challenge in machine learning and information retrieval, particularly in high-dimensional data applications \[[1](http://arxiv.org/abs/1405.5869)\]. Traditional approaches to MIPS often rely solely on inner product (IP) similarity, which can suffer from local optima and redundant computations \[[1](http://arxiv.org/abs/1405.5869)\]. Alternatively, some methods reduce the MIPS problem to nearest neighbor search (NNS) under the Euclidean metric through space projection, which can lead to topology destruction and information loss \[[1](http://arxiv.org/abs/1405.5869)\]. Despite these divergent paradigms, recent work has argued that there is no inherent binary opposition between IP and Euclidean metrics \[[1](http://arxiv.org/abs/1405.5869)\]. Instead, by integrating both metrics in the design of indexing and search algorithms, significant performance improvements can be achieved \[[1](http://arxiv.org/abs/1405.5869)\].

Several hashing-based methods have been proposed to address MIPS. Asymmetric LSH (ALSH) was introduced as the first provably sublinear time algorithm for approximate MIPS, leveraging asymmetric transformations to convert inner product search into near neighbor search \[[2](http://arxiv.org/abs/1909.13459)\]. However, the existing LSH framework was found to be insufficient for solving MIPS, prompting the development of asymmetric hashing schemes \[[2](http://arxiv.org/abs/1909.13459)\]. Similarly, Norm-Ranging LSH was proposed to address the long-tail issue in the 2-norm distribution of real datasets, improving query efficiency by partitioning the dataset into sub-datasets \[[9](http://arxiv.org/abs/1809.08782)\]. These hashing-based approaches have demonstrated strong empirical performance but often require significant computational resources \[[2](http://arxiv.org/abs/1909.13459)\]\[[9](http://arxiv.org/abs/1809.08782)\].

Graph-based methods have also gained traction in MIPS. The inner-product navigable small world graph (ip-NSW) represents a state-of-the-art method for approximate MIPS, achieving an order of magnitude speedup over baseline methods \[[3](https://www.semanticscholar.org/paper/25454f456c514219c9d6eeb42200ebbf378db9ca)\]. ip-NSW leverages the norm bias in the MIPS problem, where large norm items are more likely to be the result of MIPS \[[3](https://www.semanticscholar.org/paper/25454f456c514219c9d6eeb42200ebbf378db9ca)\]. To further improve performance, ip-NSW+ was introduced, combining angular and inner-product proximity graphs to enhance search efficiency \[[3](https://www.semanticscholar.org/paper/25454f456c514219c9d6eeb42200ebbf378db9ca)\]. Similarly, the norm adjusted proximity graph (NAPG) was proposed to improve graph-based indexing for inner product search by adjusting factors based on sampled data \[[4](http://arxiv.org/abs/1610.03317)\]. These graph-based approaches have shown strong empirical advantages, particularly in real-world applications \[[4](http://arxiv.org/abs/1610.03317)\].

Recent work has also explored the use of extreme order statistics for approximate MIPS, introducing the CEOs method, which leverages the asymptotic behavior of concomitants to estimate inner products efficiently \[[10](https://www.semanticscholar.org/paper/d204d3848bb76ecca93a0674230303785b82c3b2)\]. This method provides sublinear time complexity with search recall guarantees and has been shown to achieve significant speedups over brute-force search \[[10](https://www.semanticscholar.org/paper/d204d3848bb76ecca93a0674230303785b82c3b2)\].

### <a id='category-mips-problem-definition-and-challenges'></a>MIPS Problem Definition and Challenges: 9 papers found.
The MIPS problem, which involves finding the maximum inner product between a query and a set of vectors, has been extensively studied due to its relevance in recommendation systems, high-dimensional similarity search, and other machine learning applications \[[1](http://arxiv.org/abs/1405.5869)\]. Existing approaches often rely on either IP similarity, which can suffer from local optima and redundant computations, or reduce MIPS to Euclidean nearest neighbor search, which may distort data topology and lead to information loss \[[1](http://arxiv.org/abs/1405.5869)\]. However, recent works have explored hybrid methods that combine IP and Euclidean metrics to improve performance \[[1](http://arxiv.org/abs/1405.5869)\]. For instance, some studies have proposed branch-and-bound algorithms with novel inner-product bounds, as well as dual-tree algorithms for handling multiple queries, achieving significant improvements in query time \[[2](http://arxiv.org/abs/1909.13459)\]. Additionally, there have been efforts to develop lightweight indexing structures, such as the iDistance index, which project high-dimensional vectors to lower dimensions while maintaining accuracy guarantees \[[3](https://www.semanticscholar.org/paper/25454f456c514219c9d6eeb42200ebbf378db9ca)\]. Other approaches, like the Greedy-MIPS algorithm, have been designed to handle budgeted MIPS by balancing search efficiency and quality, achieving superior performance on large-scale datasets \[[4](http://arxiv.org/abs/1610.03317)\]. Furthermore, the problem has been extended to reverse MIPS, where the goal is to find user vectors that maximize the inner product with a query, leading to the development of efficient indexing and filtering techniques \[[5](http://arxiv.org/abs/1202.6101)\]. These advancements highlight the ongoing efforts to address the challenges of MIPS, including scalability, accuracy, and computational efficiency.
