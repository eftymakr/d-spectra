## Related Works

Event cameras, which capture scene changes asynchronously on a per-pixel basis, have gained significant attention for their high temporal resolution and robustness in challenging environments \[[1](http://arxiv.org/abs/1904.08405)\]. However, the asynchronous nature of event data introduces challenges in terms of bandwidth, memory, and computational demands \[[1](http://arxiv.org/abs/1904.08405)\]. Prior work has explored various methods to address these challenges, including event downsampling \[[1](http://arxiv.org/abs/1904.08405)\]. Most existing approaches rely on fixed heuristics or threshold-based strategies, which limit their adaptability to different applications and environments \[[1](http://arxiv.org/abs/1904.08405)\]. For instance, some methods use static thresholds to filter out less significant events, but these thresholds are not optimized for scene-specific conditions \[[1](http://arxiv.org/abs/1904.08405)\]. Additionally, these methods often require task-specific adaptation to maintain performance, which increases the complexity of deployment \[[1](http://arxiv.org/abs/1904.08405)\].

To overcome these limitations, recent research has focused on developing more adaptive and flexible event processing techniques. For example, some studies have proposed learning-based approaches that adapt to the scene dynamics \[[1](http://arxiv.org/abs/1904.08405)\]. These methods often use recurrent neural networks (RNNs) or convolutional neural networks (CNNs) to model the temporal evolution of events \[[1](http://arxiv.org/abs/1904.08405)\]. However, these approaches typically require labeled data for training, which is not always available \[[1](http://arxiv.org/abs/1904.08405)\]. Moreover, they may not generalize well to new environments or tasks without additional fine-tuning \[[1](http://arxiv.org/abs/1904.08405)\].

Another line of research has explored the use of event cameras in conjunction with traditional frame-based cameras to improve performance in specific tasks, such as object detection and visual odometry \[[1](http://arxiv.org/abs/1904.08405)\]. For instance, some studies have demonstrated that combining event data with grayscale images can lead to more robust feature extraction and better performance in low-light or high-speed scenarios \[[1](http://arxiv.org/abs/1904.08405)\]. However, these hybrid approaches often require additional hardware or computational resources, which can be a limiting factor in real-world applications \[[1](http://arxiv.org/abs/1904.08405)\].

In addition to these approaches, some researchers have proposed self-supervised learning methods that can operate directly on event data without the need for labeled training samples \[[1](http://arxiv.org/abs/1904.08405)\]. These methods often use the temporal structure of events to learn meaningful representations, which can then be used for downstream tasks such as object classification and semantic segmentation \[[1](http://arxiv.org/abs/1904.08405)\]. For example, one study introduced a self-supervised framework that learns to reconstruct intensity images from event streams, enabling the use of off-the-shelf computer vision algorithms \[[1](http://arxiv.org/abs/1904.08405)\]. This approach has shown promising results in improving the performance of event-based systems without requiring extensive labeled data \[[1](http://arxiv.org/abs/1904.08405)\].

### <a id='category-event-camera-fundamentals'></a>Event Camera Fundamentals: 5 papers found.
Event cameras, which capture scene changes asynchronously on a per-pixel basis, offer significant advantages over traditional frame-based cameras, including high temporal resolution, wide dynamic range, and low power consumption \[[1](http://arxiv.org/abs/1904.08405)\]. These sensors operate by detecting changes in brightness at the pixel level, resulting in a stream of events that encode time, location, and sign of brightness changes \[[3](http://arxiv.org/abs/1812.08156)\]. This unique mechanism allows event cameras to excel in high-speed, low-latency applications and challenging lighting conditions \[[1](http://arxiv.org/abs/1904.08405)\]. However, the unconventional output format of event cameras poses challenges for processing, as existing methods often rely on fixed heuristics or threshold-based strategies, limiting adaptability \[[1](http://arxiv.org/abs/1904.08405)\]. Recent work has sought to address these limitations by exploring more intelligent sampling approaches, such as probabilistic frameworks that model event importance based on application-specific requirements \[[1](http://arxiv.org/abs/1904.08405)\]. Additionally, researchers have investigated zero-shot event downsampling, where downsampled events must remain usable for models trained on the original event stream without task-specific adaptation \[[1](http://arxiv.org/abs/1904.08405)\]. These efforts highlight the growing interest in developing more adaptive and efficient processing techniques for event-based vision systems \[[1](http://arxiv.org/abs/1904.08405)\].

### <a id='category-adaptive-event-processing-methods'></a>Adaptive Event Processing Methods: 1 papers found.

	Document 1: [Snippet]: «Today, state-of-the-art deep neural networks that process events first convert them into dense, grid-like input representations before using an off-the-shelf network. However, selecting the appropriate representation for the task traditionally requires training a neural network for each representation and selecting the best one based on the validation score, which is very time-consuming. This work eliminates this bottleneck by selecting representations based on the Gromov-Wasserstein Discrepancy (GWD) between raw events and their representation. It is about 200 times faster to compute than training a neural network and preserves the task performance ranking of event representations across multiple representations, network backbones, datasets, and tasks. Thus finding representations with high task scores is equivalent to finding representations with a low GWD. We use this insight to, for the first time, perform a hyperparameter search on a large family of event representations, revealing new and powerful representations that exceed the state-of-the-art. Our optimized representations outperform existing representations by 1.7 mAP on the 1 Mpx dataset and 0.3 mAP on the Gen1 dataset, two established object detection benchmarks, and reach a 3.8% higher classification score on the mini N-ImageNet benchmark. Moreover, we outperform state-of-the-art by 2.1 mAP on Gen1 and state-of-the-art feed-forward methods by 6.0 mAP on the 1 Mpx datasets. This work opens a new unexplored field of explicit representation optimization for event-based learning.»
