## Related Works

Vision Transformers (ViTs) have emerged as a powerful alternative to convolutional neural networks (CNNs) in computer vision tasks, leveraging the transformer architecture to effectively capture global context \[[3](http://arxiv.org/abs/2010.11929)\]. However, the deployment of ViTs on hardware, especially FPGAs, faces significant challenges due to the complex arithmetic operations such as Softmax and LayerNorm, which are sensitive to model accuracy and difficult to map onto efficient hardware with low precision \[[1](http://arxiv.org/abs/2208.05163)\]. Existing approaches often exploit parallelism in matrix multiplication operations while keeping these complex operations on the CPU, resulting in suboptimal performance due to communication overhead between the CPU and accelerator \[[1](http://arxiv.org/abs/2208.05163)\].

Several works have explored hardware acceleration for ViTs. Auto-ViT-Acc introduces an FPGA-aware automatic acceleration framework based on mixed-scheme quantization, achieving higher accuracy than state-of-the-art quantization methods while improving frame rates \[[1](http://arxiv.org/abs/2208.05163)\]. ViTCoD proposes a co-design framework that integrates algorithmic and hardware-level optimizations, achieving significant speedups by reducing dominant data movement costs \[[2](http://arxiv.org/abs/2210.09573)\]. I-ViT enables integer-only inference for ViTs by approximating non-linear operations with lightweight integer arithmetic methods, achieving comparable or slightly higher accuracy than full-precision models \[[4](http://arxiv.org/abs/2207.01405)\]. FQ-ViT addresses the challenges of post-training quantization for ViTs by introducing Power-of-Two Factor (PTF) and Log-Int-Softmax (LIS) to reduce performance degradation and inference complexity \[[7](http://arxiv.org/abs/2111.13824)\]. Patch Slimming reduces computational costs by discarding redundant patches in a top-down manner, achieving over 45% FLOPs reduction with minimal accuracy drop \[[8](http://arxiv.org/abs/2106.02852)\]. HeatViT introduces hardware-efficient token pruning for ViTs, achieving higher accuracy and significant computation reduction on embedded FPGAs \[[9](http://arxiv.org/abs/2211.08110)\]. VAQF presents a fully automatic software-hardware co-design framework for low-bit ViTs, enabling real-time execution on FPGAs \[[10](http://arxiv.org/abs/2201.06618)\]. Chasing Sparsity in Vision Transformers explores end-to-end sparsity integration, achieving significant computational cost reduction without sacrificing accuracy \[[11](http://arxiv.org/abs/2106.04533)\]. Transformer in Transformer (TNT) improves ViT performance by introducing a hierarchical attention mechanism, achieving higher accuracy with similar computational cost \[[12](http://arxiv.org/abs/2103.00112)\]. Unified Visual Transformer Compression proposes a framework combining pruning, layer skipping, and knowledge distillation, achieving substantial model size reduction without accuracy loss \[[13](http://arxiv.org/abs/2203.08243)\]. Swin Transformer introduces a hierarchical architecture with shifted windows, achieving state-of-the-art performance on various vision tasks \[[14](http://arxiv.org/abs/2103.14030)\]. ### <a id='category-quantization-techniques-for-vits'></a>Quantization Techniques for ViTs: 5 papers found.
Vision Transformers (ViTs) have gained significant attention for their ability to capture global context in computer vision tasks, yet their deployment on edge devices remains challenging due to high computational and storage demands \[[1](http://arxiv.org/abs/2208.05163)\]. To address these challenges, various quantization techniques have been proposed to reduce model complexity and enable efficient inference. For instance, mixed-scheme quantization has been explored to improve accuracy while maintaining high frame rates on FPGA platforms, achieving up to 5.6x speedup with minimal accuracy loss \[[1](http://arxiv.org/abs/2208.05163)\]. Similarly, integer-only quantization methods, such as I-ViT, aim to eliminate floating-point operations entirely by approximating non-linear components like Softmax and GELU using integer arithmetic and bit-shifting, achieving comparable accuracy to full-precision models \[[4](http://arxiv.org/abs/2207.01405)\]. Another approach, FQ-ViT, tackles the issue of inter-channel variation in LayerNorm inputs by introducing Power-of-Two Factor (PTF) and Log-Int-Softmax (LIS), enabling 4-bit quantization without significant accuracy degradation \[[7](http://arxiv.org/abs/2111.13824)\]. Additionally, VAQF presents an automatic framework for FPGA-based ViT acceleration, integrating quantization and hardware optimization to meet target frame rates while minimizing compilation time \[[10](http://arxiv.org/abs/2201.06618)\]. These methods collectively highlight the ongoing efforts to balance accuracy and efficiency in ViT inference, particularly through novel quantization strategies and hardware-aware design.

### <a id='category-challenges-in-vit-hardware-acceleration'></a>Challenges in ViT Hardware Acceleration: 1 papers found.

	Document 1: [Snippet]: «Vision Transformers (ViTs) have achieved state-of-the-art performance on various vision tasks. However, ViTs’ self-attention module is still arguably a major bottleneck, limiting their achievable hardware efficiency and more extensive applications to resource constrained platforms. Meanwhile, existing accelerators dedicated to NLP Transformers are not optimal for ViTs. This is because there is a large difference between ViTs and Transformers for natural language processing (NLP) tasks: ViTs have a relatively fixed number of input tokens, whose attention maps can be pruned by up to 90% even with fixed sparse patterns, without severely hurting the model accuracy (e.g., <=1.5% under 90% pruning ratio); while NLP Transformers need to handle input sequences of varying numbers of tokens and rely on on-the-fly predictions of dynamic sparse attention patterns for each input to achieve a decent sparsity (e.g., >=50%). To this end, we propose a dedicated algorithm and accelerator co-design framework dubbed ViTCoD for accelerating ViTs. Specifically, on the algorithm level, ViTCoD prunes and polarizes the attention maps to have either denser or sparser fixed patterns for regularizing two levels of workloads without hurting the accuracy, largely reducing the attention computations while leaving room for alleviating the remaining dominant data movements; on top of that, we further integrate a lightweight and learnable auto-encoder module to enable trading the dominant high-cost data movements for lower-cost computations. On the hardware level, we develop a dedicated accelerator to simultaneously coordinate the aforementioned enforced denser and sparser workloads for boosted hardware utilization, while integrating on-chip encoder and decoder engines to leverage ViTCoD’s algorithm pipeline for much reduced data movements. Extensive experiments and ablation studies validate that ViTCoD largely reduces the dominant data movement costs, achieving speedups of up to 235.3×, 142.9×, 86.0×, 10.1×, and 6.8× over general computing platforms CPUs, EdgeGPUs, GPUs, and prior-art Transformer accelerators SpAtten and Sanger under an attention sparsity of 90%, respectively. Our code implementation is available at https://github.com/GATECH-EIC/ViTCoD.»

### <a id='category-vision-transformer-(vit)-architecture-overview'></a>Vision Transformer (ViT) Architecture Overview: 5 papers found.
Vision Transformer (ViT) architectures have gained significant attention for their ability to capture global context in computer vision tasks, though they face challenges in hardware acceleration due to complex operations like Softmax and LayerNorm \[[3](http://arxiv.org/abs/2010.11929)\]. Early ViT models split images into patches and applied Transformer layers, but they struggled with performance on midsize datasets like ImageNet when trained from scratch, primarily due to inefficient tokenization and attention mechanisms \[[5](http://arxiv.org/abs/2101.11986)\]. To address these issues, researchers proposed variants such as T2T-ViT, which uses a Tokens-to-Token transformation to better model local structures and reduce computational overhead \[[5](http://arxiv.org/abs/2101.11986)\]. Similarly, the Transformer iN Transformer (TNT) architecture further refined this by introducing hierarchical attention within local patches, enhancing representation capabilities and achieving competitive performance with state-of-the-art models \[[12](http://arxiv.org/abs/2103.00112)\]. The Swin Transformer introduced a hierarchical design with shifted windows, enabling efficient modeling of visual features at multiple scales while maintaining linear computational complexity \[[14](http://arxiv.org/abs/2103.14030)\]. These advancements highlight the evolving strategies to improve ViT efficiency and performance, paving the way for more effective hardware implementations \[[3](http://arxiv.org/abs/2010.11929)\]\[[5](http://arxiv.org/abs/2101.11986)\]\[[12](http://arxiv.org/abs/2103.00112)\]\[[14](http://arxiv.org/abs/2103.14030)\].

### <a id='category-accuracy-vs.-efficiency-trade-offs'></a>Accuracy vs. Efficiency Trade-offs: 6 papers found.
Efforts to improve the efficiency of vision transformers (ViTs) have focused on reducing computational costs while maintaining accuracy, with several approaches addressing different aspects of the problem. For instance, methods like patch slimming \[[8](http://arxiv.org/abs/2106.02852)\] and token pruning \[[9](http://arxiv.org/abs/2211.08110)\] aim to remove redundant elements in ViTs, significantly lowering FLOPs without sacrificing performance. Similarly, dynamic token sparsification \[[15](http://arxiv.org/abs/2106.02034)\] enables progressive pruning of non-informative tokens based on input, achieving up to 37% FLOPs reduction with minimal accuracy loss. Additionally, hardware-efficient frameworks such as HeatViT \[[9](http://arxiv.org/abs/2211.08110)\] and unified compression techniques \[[13](http://arxiv.org/abs/2203.08243)\] combine pruning, layer skipping, and knowledge distillation to achieve efficient ViT acceleration. These methods highlight the growing interest in optimizing ViTs for resource-constrained environments, particularly through architectural and algorithmic innovations that balance speed and accuracy.
