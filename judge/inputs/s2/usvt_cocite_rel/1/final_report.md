KV cache mechanisms are essential for improving the efficiency of large language model (LLM) inference by reducing redundant computations \[[1](http://arxiv.org/abs/2402.02750)\]. Prior work has focused on optimizing memory usage and computational efficiency through various techniques such as quantization, sparsity, and cache eviction policies \[[2](http://arxiv.org/abs/2309.06180)\]\[[3](http://arxiv.org/abs/2305.17118)\]\[[4](http://arxiv.org/abs/2405.14366)\]. However, most existing studies have primarily considered synthetic workloads or simplified assumptions about cache behavior, leading to limited insights into real-world performance \[[5](http://arxiv.org/abs/2404.14469)\].

Several approaches have been proposed to reduce the memory footprint of KV caches. Quantization techniques, such as 2-bit quantization \[[1](http://arxiv.org/abs/2402.02750)\], have been shown to significantly reduce memory usage while maintaining model quality. Per-channel key quantization and per-token value quantization are particularly effective in preserving accuracy \[[1](http://arxiv.org/abs/2402.02750)\]. Additionally, methods like H2O \[[7](http://arxiv.org/abs/2306.14048)\] and GEAR \[[12](http://arxiv.org/abs/2403.05527)\] have introduced novel strategies for managing KV cache by identifying and retaining critical tokens or using mixed-precision quantization to minimize performance degradation.

Cache eviction policies have also been explored to manage memory constraints. For example, PagedAttention \[[2](http://arxiv.org/abs/2309.06180)\] leverages virtual memory concepts to efficiently manage dynamic KV cache memory, reducing fragmentation and enabling flexible sharing across requests. Efficient memory management in large language models (LLMs) has been a focal point of recent research, with a particular emphasis on optimizing the key-value (KV) cache, which is critical for inference speed and memory usage \[[1](http://arxiv.org/abs/2402.02750)\]. Prior work has explored quantization techniques to reduce the memory footprint of KV caches, as this cache is a major contributor to memory consumption, especially with large context lengths \[[1](http://arxiv.org/abs/2402.02750)\]. For instance, studies have shown that quantizing the KV cache can significantly reduce memory usage, enabling larger batch sizes and improved throughput \[[1](http://arxiv.org/abs/2402.02750)\]. However, existing methods often struggle with maintaining accuracy at low bit-widths, particularly below 4 bits \[[11](http://arxiv.org/abs/2401.18079)\]. To address these challenges, researchers have proposed advanced quantization strategies, such as per-channel key quantization and per-token value quantization, which better match the distribution of activations and improve quantization accuracy \[[1](http://arxiv.org/abs/2402.02750)\]. Additionally, some approaches incorporate techniques like pre-RoPE key quantization and non-uniform quantization to further enhance performance \[[11](http://arxiv.org/abs/2401.18079)\]. These methods have demonstrated promising results, achieving minimal perplexity degradation while enabling models to handle longer context lengths with reduced memory \[[11](http://arxiv.org/abs/2401.18079)\]. Overall, these studies highlight the importance of tailored quantization strategies for KV caches, aiming to balance memory efficiency with inference accuracy \[[1](http://arxiv.org/abs/2402.02750)\]\[[11](http://arxiv.org/abs/2401.18079)\].

### <a id='category-adaptive-kv-cache-compression-methods'></a>Adaptive KV Cache Compression Methods: 9 papers found.
Adaptive KV Cache Compression Methods focus on reducing the memory footprint of the Key-Value (KV) cache without compromising model performance, which is critical for efficient large language model (LLM) inference \[[3](http://arxiv.org/abs/2305.17118)\]. Various approaches have been proposed to address the growing memory demands of KV caches, particularly in long-context scenarios. For instance, Scissorhands leverages the persistence of token importance to prioritize storage of pivotal tokens, achieving up to 5X memory reduction \[[3](http://arxiv.org/abs/2305.17118)\]. Similarly, MiniCache compresses the KV cache across layers by exploiting the high similarity between adjacent layers, achieving a 5.02x compression ratio on LLaMA-2-7B with 4-bit quantization \[[4](http://arxiv.org/abs/2405.14366)\]. SnapKV further improves efficiency by identifying and retaining important KV positions for each attention head, leading to an 8.2x memory efficiency gain \[[5](http://arxiv.org/abs/2404.14469)\]. KVMerger introduces a merging strategy based on token-level similarity, enabling adaptive compression without significant performance degradation \[[8](http://arxiv.org/abs/2407.08454)\]. FastGen employs an adaptive KV cache construction method, selectively evicting or retaining KV pairs based on attention head characteristics, achieving substantial GPU memory reduction \[[9](http://arxiv.org/abs/2310.01801)\]. GEAR combines quantization, low-rank approximation, and sparsity to achieve near-lossless compression with up to 2.38x throughput improvement \[[12](http://arxiv.org/abs/2403.05527)\]. MiKV introduces mixed-precision quantization, preserving critical KV pairs at higher precision while compressing less important ones, thus mitigating performance degradation \[[13](http://arxiv.org/abs/2402.18096)\]. PyramidKV dynamically adjusts cache allocation across layers, retaining only 12% of the full cache while maintaining performance comparable to full caching \[[14](http://arxiv.org/abs/2406.02069)\]. QAQ proposes separate quantization strategies for key and value caches, achieving up to 10× compression with minimal performance impact \[[15](http://arxiv.org/abs/2403.04643)\]. These methods collectively highlight the ongoing efforts to balance memory efficiency and model quality in LLM inference.

In addition, we discover that adding a placeholder token as a dedicated attention sink during pre-training can further improve streaming deployment.
