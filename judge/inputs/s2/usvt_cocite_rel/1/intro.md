## Related Works

KV cache mechanisms are essential for improving the efficiency of large language model (LLM) inference by reducing redundant computations \[[1](http://arxiv.org/abs/2402.02750)\]. Prior work has focused on optimizing memory usage and computational efficiency through various techniques such as quantization, sparsity, and cache eviction policies \[[2](http://arxiv.org/abs/2309.06180)\]\[[3](http://arxiv.org/abs/2305.17118)\]\[[4](http://arxiv.org/abs/2405.14366)\]. However, most existing studies have primarily considered synthetic workloads or simplified assumptions about cache behavior, leading to limited insights into real-world performance \[[5](http://arxiv.org/abs/2404.14469)\].

Several approaches have been proposed to reduce the memory footprint of KV caches. Quantization techniques, such as 2-bit quantization \[[1](http://arxiv.org/abs/2402.02750)\], have been shown to significantly reduce memory usage while maintaining model quality. Per-channel key quantization and per-token value quantization are particularly effective in preserving accuracy \[[1](http://arxiv.org/abs/2402.02750)\]. Additionally, methods like H2O \[[7](http://arxiv.org/abs/2306.14048)\] and GEAR \[[12](http://arxiv.org/abs/2403.05527)\] have introduced novel strategies for managing KV cache by identifying and retaining critical tokens or using mixed-precision quantization to minimize performance degradation.

Cache eviction policies have also been explored to manage memory constraints. For example, PagedAttention \[[2](http://arxiv.org/abs/2309.06180)\] leverages virtual memory concepts to efficiently manage dynamic KV cache memory, reducing fragmentation and enabling flexible sharing across requests. Similarly, Scissorhands \[[3](http://arxiv.org/abs/2305.17118)\] exploits the persistence of importance hypothesis to retain pivotal tokens, achieving up to 5× compression without compromising model quality. These approaches highlight the importance of workload-aware strategies to optimize cache usage in real-world scenarios.

Adaptive KV cache compression methods, such as KVMerger \[[8](http://arxiv.org/abs/2407.08454)\] and FastGen \[[9](http://arxiv.org/abs/2310.01801)\], have further advanced the field by dynamically adjusting cache content based on the model's attention patterns. KVMerger identifies similar key states for merging, while FastGen selectively evicts non-essential tokens based on attention head characteristics. These techniques demonstrate the potential of adaptive strategies to balance memory efficiency and model performance.

Recent work has also emphasized the importance of understanding KV cache reuse patterns to inform more effective cache management. For instance, the study by \[[14](http://arxiv.org/abs/2406.02069)\] revealed that attention in LLMs follows a pyramidal funneling pattern, where information is consolidated progressively across layers. This insight has led to the development of PyramidKV \[[14](http://arxiv.org/abs/2406.02069)\], which dynamically adjusts cache size across layers to optimize memory usage while maintaining performance.

In addition, the concept of attention sinks has been explored to improve the generalization of LLMs to long sequences \[[6](http://arxiv.org/abs/2309.17453)\].
