## Related Works

Label noise is a pervasive issue in deep learning, affecting the performance of models trained on imperfectly annotated data. Several approaches have been proposed to address this challenge. Early work focused on modifying network architectures or estimating true labels from noisy ones \[[10](http://arxiv.org/abs/1712.09482)\]. For instance, \[[10](http://arxiv.org/abs/1712.09482)\] proposed loss functions that are inherently robust to label noise, showing that mean absolute error (MAE) can be used for risk minimization under noisy labels. This approach avoids the need for explicit label correction, relying instead on the robustness of the loss function itself. However, these methods often assume uniform noise distributions and may not generalize well to complex, real-world scenarios \[[15](http://arxiv.org/abs/1805.07836)\].

More recently, researchers have explored the use of semi-supervised learning to improve robustness against noisy labels. For example, \[[7](http://arxiv.org/abs/2002.07394)\] introduced DivideMix, a framework that leverages semi-supervised techniques to dynamically separate clean and noisy samples during training. This approach models the per-sample loss distribution using a mixture model, allowing the model to learn from both labeled and unlabeled data in a semi-supervised manner. Similarly, \[[11](http://arxiv.org/abs/1901.04215)\] proposed Co-teaching+, which builds upon the Co-teaching framework by incorporating disagreement-based learning to avoid confirmation bias. This method trains two diverged networks, where each network uses the dataset division from the other to improve robustness against noisy labels.

Another line of research focuses on loss correction and noise estimation. \[[1](http://arxiv.org/abs/1609.03683)\] introduced a loss correction approach that accounts for class-dependent label noise, proposing two procedures that amount to matrix inversion and multiplication, provided the probability of each class being corrupted is known. They also developed a method to estimate these probabilities, enabling an end-to-end framework for training robust models. This work was later extended in \[[14](http://arxiv.org/abs/2012.11854)\], which addressed instance-dependent label noise by leveraging second-order statistics to estimate noise rates and adjust the loss function accordingly. This approach allows for more accurate modeling of real-world label noise, which often depends on the difficulty of the task.

In addition to loss-based methods, some works have focused on reweighting examples to improve robustness. \[[12](http://arxiv.org/abs/1803.09050)\] proposed a meta-learning algorithm that learns to assign weights to training examples based on their gradient directions, without requiring additional hyperparameter tuning. This method can be applied to any deep network and has shown effectiveness in handling class imbalance and corrupted labels. ### <a id='category-label-noise-in-deep-learning'></a>Label Noise in Deep Learning: 11 papers found.
Label Noise in Deep Learning has been a focal point in recent research, with multiple approaches proposed to address the challenges posed by noisy labels. Existing methods often rely on human supervision, which is time-consuming and not scalable, while unsupervised methods, though scalable, tend to be less effective \[[1](http://arxiv.org/abs/1609.03683)\]. To mitigate this, researchers have introduced frameworks such as CleanNet, which leverages a fraction of manually verified labels to infer label noise patterns and transfer this knowledge to other classes \[[2](http://arxiv.org/abs/1711.07131)\]. Similarly, Co-teaching has emerged as a promising paradigm, where two neural networks are trained simultaneously, teaching each other by selecting and backpropagating data with potentially clean labels \[[3](http://arxiv.org/abs/1804.06872)\]. This approach has shown significant improvements in robustness against noisy labels, particularly on benchmark datasets like MNIST and CIFAR \[[4](http://arxiv.org/abs/1706.00038)\]. Another line of work focuses on semi-supervised learning, where models are trained using an undirected graphical model to represent the relationship between noisy and clean labels, allowing for effective inference and regularization during training \[[5](http://arxiv.org/abs/1806.02612)\]. Additionally, some studies have explored the impact of label noise on model generalization, showing that deep neural networks can memorize noisy labels, leading to overfitting or underfitting depending on the class \[[6](http://arxiv.org/abs/1703.02391)\]. To address this, methods like Symmetric Cross Entropy Learning (SL) have been proposed, combining Cross Entropy with a noise-robust Reverse Cross Entropy to balance learning across classes \[[7](http://arxiv.org/abs/2002.07394)\]. Furthermore, the issue of instance-dependent label noise has been tackled by leveraging second-order statistics to estimate noise rates and adjust loss functions accordingly \[[8](http://arxiv.org/abs/1908.06112)\]. These diverse approaches highlight the ongoing efforts to improve the robustness and effectiveness of deep learning models in the presence of label noise.

### <a id='category-loss-function-robustness'></a>Loss Function Robustness: 2 papers found.
In the context of loss function robustness for deep learning under label noise, recent research has focused on developing loss functions that are inherently tolerant to noisy labels. For binary classification, theoretical results have established conditions for loss functions that ensure robustness to label noise, and these findings have been extended to multiclass classification problems \[[10](http://arxiv.org/abs/1712.09482)\]. A key insight is that certain loss functions, such as the mean absolute error (MAE), can provide robustness without requiring complex modifications to network architecture or training procedures \[[10](http://arxiv.org/abs/1712.09482)\]. However, MAE has been shown to perform poorly in some challenging scenarios, prompting the development of more generalized noise-robust loss functions that extend beyond MAE and categorical cross-entropy (CCE) \[[15](http://arxiv.org/abs/1805.07836)\]. These new loss functions are designed to be compatible with existing deep learning architectures and algorithms, offering improved performance across a range of noisy label scenarios \[[15](http://arxiv.org/abs/1805.07836)\]. Experiments on datasets such as CIFAR-10, CIFAR-100, and FASHION-MNIST, along with synthetically generated noisy labels, have demonstrated the effectiveness of these approaches in maintaining model performance despite label corruption \[[15](http://arxiv.org/abs/1805.07836)\]. The theoretical grounding of these loss functions ensures that they can be applied broadly, addressing the limitations of traditional loss functions in noisy environments \[[15](http://arxiv.org/abs/1805.07836)\].
