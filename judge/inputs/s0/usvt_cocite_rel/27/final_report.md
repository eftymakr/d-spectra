## Related Works

Recent advancements in information retrieval have led to the development of various approaches for document and table retrieval. Traditional methods often rely on a separate indexing and retrieval pipeline, which can introduce error accumulation during the indexing phase and limit effective semantic alignment between queries and documents \[[14](http://arxiv.org/abs/2005.09207)\]. This limitation is particularly evident in dense vector search pipelines, where representation, indexing, and search are distinct stages \[[15](http://arxiv.org/abs/1906.00041)\]. These pipelines typically suffer from performance degradation due to the inability to directly optimize for the final retrieval target \[[3](http://arxiv.org/abs/2206.02743)\].

To address these limitations, differentiable search index (DSI) models have emerged as a promising alternative. DSI models unify indexing and retrieval within a single transformer model, allowing direct mapping of queries to document identifiers \[[2](http://arxiv.org/abs/2202.06991)\]. This approach eliminates the need for separate indexing and retrieval stages, thereby reducing error accumulation \[[1](http://arxiv.org/abs/2206.10128)\]. However, early DSI models faced challenges with data distribution mismatches between indexing and retrieval phases, especially in cross-lingual settings \[[1](http://arxiv.org/abs/2206.10128)\]. To mitigate this, DSI-QG was proposed, which generates relevant queries during indexing and re-ranks them using a cross-encoder ranker, improving alignment between queries and documents \[[1](http://arxiv.org/abs/2206.10128)\].

Similarly, the Neural Corpus Indexer (NCI) aims to unify training and indexing stages by using a sequence-to-sequence network that generates document identifiers directly for a given query \[[3](http://arxiv.org/abs/2206.02743)\]. NCI employs a prefix-aware weight-adaptive decoder and incorporates techniques such as query generation and semantic document identifiers to enhance recall performance \[[3](http://arxiv.org/abs/2206.02743)\]. This aligns with the idea of generating synthetic queries to improve query-document alignment, as seen in Birdie \[[1](http://arxiv.org/abs/2206.10128)\].

Autoregressive search engines have also been explored for document retrieval, where models generate and score distinctive ngrams as document identifiers \[[4](http://arxiv.org/abs/2204.10628)\]. This approach allows for efficient retrieval by mapping ngrams to full passages using an efficient data structure. It has been shown to outperform prior autoregressive methods and established retrieval solutions, achieving significant improvements on the KILT benchmark \[[4](http://arxiv.org/abs/2204.10628)\].

Continual learning in DSI models remains a challenge, as retraining the model for incremental indexing leads to forgetting of previously indexed documents \[[5](http://arxiv.org/abs/2212.09744)\]. DSI++ was introduced to address this issue by incorporating a generative memory that samples pseudo-queries during continual indexing, thereby preventing forgetting \[[5](http://arxiv.org/abs/2212.09744)\]. This is similar to the index update strategy in Birdie, which uses parameter isolation to mitigate catastrophic forgetting \[[1](http://arxiv.org/abs/2206.10128)\].

### <a id='category-differentiable-search-index-models'></a>Differentiable Search Index Models: 7 papers found.
Differentiable Search Index (DSI) models represent a paradigm shift in information retrieval by integrating indexing and retrieval into a single neural model, eliminating the need for separate components \[[2](http://arxiv.org/abs/2202.06991)\]. This approach allows the model to directly map queries to document identifiers, leveraging the full expressiveness of deep language models \[[5](http://arxiv.org/abs/2212.09744)\]. However, existing DSI models face challenges such as data distribution mismatches between indexing and retrieval phases, particularly when dealing with cross-lingual queries \[[1](http://arxiv.org/abs/2206.10128)\]. To address these issues, researchers have proposed enhancements like DSI-QG, which introduces query generation during indexing to better align with retrieval queries \[[1](http://arxiv.org/abs/2206.10128)\]. Similarly, the Semantic-Enhanced DSI (SE-DSI) model improves document identifier representation by incorporating elaborative descriptions and rehearsal strategies inspired by cognitive psychology \[[5](http://arxiv.org/abs/2212.09744)\]. These advancements highlight the ongoing efforts to refine DSI models for better performance and generalization. Additionally, other related works such as ColBERT introduce late interaction architectures to improve efficiency while maintaining effectiveness \[[6](http://arxiv.org/abs/2004.12832)\], and CorpusBrain proposes a single-step generative model for knowledge-intensive tasks, eliminating the need for traditional indexing \[[12](http://arxiv.org/abs/2208.07652)\]. These studies collectively underscore the potential of differentiable search indexes to revolutionize information retrieval by enabling end-to-end optimization and reducing error accumulation \[[3](http://arxiv.org/abs/2206.02743)\].

### <a id='category-catastrophic-forgetting-mitigation'></a>Catastrophic Forgetting Mitigation: 1 papers found.
Context: 
	Document 1: [Snippet]: «Differentiable Search Indices (DSIs) encode a corpus of documents in model parameters and use the same model to answer user queries directly. Despite the strong performance of DSI models, deploying them in situations where the corpus changes over time is computationally expensive because reindexing the corpus requires re-training the model. In this work, we introduce DSI++, a continual learning challenge for DSI to incrementally index new documents while being able to answer queries related to both previously and newly indexed documents. Across different model scales and document identifier representations, we show that continual indexing of new documents leads to considerable forgetting of previously indexed documents. We also hypothesize and verify that the model experiences forgetting events during training, leading to unstable learning. To mitigate these issues, we investigate two approaches. The first focuses on modifying the training dynamics. Flatter minima implicitly alleviate forgetting, so we optimize for flatter loss basins and show that the model stably memorizes more documents ($+12\%$). Next, we introduce a generative memory to sample pseudo-queries for documents and supplement them during continual indexing to prevent forgetting for the retrieval task. Extensive experiments on novel continual indexing benchmarks based on Natural Questions (NQ) and MS MARCO demonstrate that our proposed solution mitigates forgetting significantly. Concretely, it improves the average Hits@10 by $+21.1\%$ over competitive baselines for NQ and requires $6$ times fewer model updates compared to re-training the DSI model for incrementally indexing five corpora in a sequence.»
