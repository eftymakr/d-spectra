## Related Works

KV cache compression has emerged as a critical area of research for improving the efficiency of large language model (LLM) inference, particularly in serving scenarios where memory and throughput are paramount. Prior work has focused on various strategies, including quantization, compression, and eviction policies, to reduce the memory footprint of KV caches while maintaining model performance.

Quantization techniques have been widely explored for reducing the memory usage of KV caches. KIVI \[[1](http://arxiv.org/abs/2402.02750)\] introduces a tuning-free 2-bit quantization approach that differentiates between key and value caches, applying per-channel quantization to keys and per-token quantization to values. This method enables significant memory reduction, allowing models like Llama and Mistral to maintain similar quality while using 2.6× less peak memory. Similarly, KVQuant \[[9](http://arxiv.org/abs/2401.18079)\] proposes a comprehensive set of methods for low-precision KV cache quantization, including per-channel key quantization, pre-RoPE quantization, and non-uniform quantization, achieving less than 0.1 perplexity degradation with 3-bit quantization. These approaches demonstrate that quantization can effectively reduce memory usage without significant performance loss.

KV cache compression techniques have also been investigated through the lens of token importance and similarity. H2O \[[7](http://arxiv.org/abs/2306.14048)\] introduces a dynamic eviction policy based on the observation that a small subset of tokens, referred to as heavy hitters, contribute most to attention scores. By retaining these tokens, H2O achieves up to 29× throughput improvements over existing systems. Similarly, Scissorhands \[[4](http://arxiv.org/abs/2305.17118)\] leverages the persistence of importance hypothesis, prioritizing the storage of pivotal tokens to maintain model quality while reducing memory usage by up to 5×. These methods highlight the importance of identifying and retaining critical tokens for efficient inference.

Adaptive KV cache compression has also been explored, with approaches such as FastGen \[[8](http://arxiv.org/abs/2310.01801)\] and KVMerger \[[11](http://arxiv.org/abs/2407.08454)\] aiming to reduce memory usage while preserving performance. FastGen employs adaptive compression by selectively evicting non-critical tokens based on attention head behavior, while KVMerger focuses on merging similar key states within sequences to reduce cache size without significant performance degradation. These methods demonstrate that adaptive strategies can offer a balance between memory efficiency and model accuracy.

### <a id='category-kv-cache-quantization-techniques'></a>KV Cache Quantization Techniques: 2 papers found.
Efficient KV cache quantization is a critical area of research aimed at reducing memory usage and improving inference speed for large language models (LLMs). Prior work has explored various quantization strategies to mitigate the memory bottlenecks caused by the growing size of KV caches, especially with larger batch sizes and context lengths \[[1](http://arxiv.org/abs/2402.02750)\]. For instance, quantization has been proposed as a straightforward method to reduce the memory footprint of KV caches by decreasing the number of bits used to store key and value activations \[[1](http://arxiv.org/abs/2402.02750)\]. However, existing approaches often struggle with accurately representing activations in sub-4-bit precision, leading to performance degradation \[[9](http://arxiv.org/abs/2401.18079)\]. To address these limitations, recent studies have introduced novel techniques such as per-channel key quantization, which groups elements along the channel dimension to better match their distribution \[[9](http://arxiv.org/abs/2401.18079)\], and pre-RoPE key quantization, which mitigates the impact of rotary positional embeddings on quantization \[[9](http://arxiv.org/abs/2401.18079)\]. Additionally, non-uniform KV cache quantization has been proposed to use sensitivity-weighted datatypes that better capture the distribution of activations across layers \[[9](http://arxiv.org/abs/2401.18079)\]. These advancements highlight the ongoing efforts to optimize KV cache quantization while maintaining model quality and inference efficiency \[[1](http://arxiv.org/abs/2402.02750)\]\[[9](http://arxiv.org/abs/2401.18079)\].

### <a id='category-memory-footprint-reduction-methods'></a>Memory Footprint Reduction Methods: 9 papers found.
Memory Footprint Reduction Methods focus on optimizing the Key-Value (KV) cache, a critical component in Large Language Models (LLMs) serving systems, which significantly impacts memory usage and throughput. Various approaches have been proposed to address the challenges of dynamic and large KV cache memory. PagedAttention \[[2](http://arxiv.org/abs/2309.06180)\] introduces an attention algorithm inspired by virtual memory paging, enabling near-zero memory waste and flexible sharing of KV cache across requests. MiniCache \[[3](http://arxiv.org/abs/2405.14366)\] compresses the KV cache by leveraging similarities between adjacent layers, achieving up to 5.02x compression ratios and reducing memory footprint by 41%. Scissorhands \[[4](http://arxiv.org/abs/2305.17118)\] maintains a fixed KV cache budget by prioritizing pivotal tokens, reducing memory usage by up to 5X without compromising model quality. SnapKV \[[5](http://arxiv.org/abs/2404.14469)\] compresses KV caches by identifying and retaining important token clusters, improving memory efficiency by 8.2x. Heavy Hitter Oracle (H$_2$O) \[[7](http://arxiv.org/abs/2306.14048)\] dynamically retains recent and high-impact tokens, achieving up to 29x throughput improvements. Adaptive KV cache compression \[[8](http://arxiv.org/abs/2310.01801)\] constructs the cache based on attention head characteristics, reducing memory consumption with minimal quality loss. WKVQuant \[[10](http://arxiv.org/abs/2402.12065)\] integrates quantization strategies for both model weights and KV cache, achieving memory savings comparable to weight-activation quantization. GEAR \[[12](http://arxiv.org/abs/2403.05527)\] employs quantization and low-rank approximations to achieve near-lossless 4-bit compression with up to 2.29x memory reduction. PyramidKV \[[13](http://arxiv.org/abs/2406.02069)\] dynamically adjusts cache size across layers, retaining only 12% of the full cache while maintaining performance. These methods collectively highlight the importance of efficient KV cache management in enhancing LLM serving efficiency.

### <a id='category-token-importance-and-similarity-analysis'></a>Token Importance and Similarity Analysis: 1 papers found.
Context: 
	Document 1: [Snippet]: «Deploying Large Language Models (LLMs) in streaming applications such as multi-round dialogue, where long interactions are expected, is urgently needed but poses two major challenges. Firstly, during the decoding stage, caching previous tokens' Key and Value states (KV) consumes extensive memory. Secondly, popular LLMs cannot generalize to longer texts than the training sequence length. Window attention, where only the most recent KVs are cached, is a natural approach -- but we show that it fails when the text length surpasses the cache size. We observe an interesting phenomenon, namely attention sink, that keeping the KV of initial tokens will largely recover the performance of window attention. In this paper, we first demonstrate that the emergence of attention sink is due to the strong attention scores towards initial tokens as a"sink"even if they are not semantically important. Based on the above analysis, we introduce StreamingLLM, an efficient framework that enables LLMs trained with a finite length attention window to generalize to infinite sequence lengths without any fine-tuning. We show that StreamingLLM can enable Llama-2, MPT, Falcon, and Pythia to perform stable and efficient language modeling with up to 4 million tokens and more. In addition, we discover that adding a placeholder token as a dedicated attention sink during pre-training can further improve streaming deployment. In streaming settings, StreamingLLM outperforms the sliding window recomputation baseline by up to 22.2x speedup. Code and datasets are provided at https://github.com/mit-han-lab/streaming-llm.»

### <a id='category-adaptive-compression-strategies'></a>Adaptive Compression Strategies: 1 papers found.
Context: 
	Document 1: [Snippet]: «How to efficiently serve Large Language Models (LLMs) has become a pressing issue because of their huge computational cost in their autoregressive generation process. To mitigate computational costs, LLMs often employ the KV Cache technique to improve the generation speed. While improving the computational efficiency, the storage requirements of the KV cache are substantial, particularly in long-context scenarios, leading to significant memory consumption. Existing KV cache eviction methods often degrade the performance of LLMs in long-context scenarios due to the information loss introduced by eviction. In this paper, we propose a novel KV cache merging approach, called KVMerger, to achieve adaptive KV cache compression for long-context tasks without significant performance degradation under constrained memory budgets. Our approach is inspired by the intriguing observation that key states exhibit high similarity at the token level within a single sequence. To facilitate merging, we develop an effective yet straightforward merging set identification algorithm to identify suitable KV states for merging. Our merging set identification algorithm stimulates the second observation that KV cache sparsity, from similarity perspective, is independent of the dataset and remains persistent at the model level. Subsequently, we propose a Gaussian kernel weighted merging algorithm to selectively merge all states within each merging set. We conduct extensive experiments to demonstrate the effectiveness of KVMerger for long-context tasks under constrained memory budgets, applying it to models including Llama2-7B-chat and Llama2-13B-chat. Using the LongBench and ZeroScroll benchmarks, we compare our method with other KV cache compression techniques, including H2O and CaM, showing that our method achieves superior performance across tasks with both 50% and 35% KV cache budgets.»
