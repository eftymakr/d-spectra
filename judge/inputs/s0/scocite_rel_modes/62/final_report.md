## Related Works

Generative retrieval has emerged as a promising alternative to traditional search index-based approaches, aiming to replace static index structures with a single large-scale neural network that can directly generate document identifiers during retrieval \[[1](http://arxiv.org/abs/2204.10628)\]. This paradigm offers the potential for improved efficiency and seamless integration with generative large language models \[[1](http://arxiv.org/abs/2204.10628)\]. Prior work has explored various methods to implement this idea, including the use of autoregressive models to generate document identifiers \[[1](http://arxiv.org/abs/2204.10628)\], and the development of differentiable search indexes that encode the entire corpus within a single Transformer \[[9](http://arxiv.org/abs/2202.06991)\]. These models typically rely on constrained decoding strategies to generate document identifiers that are specific to the corpus \[[1](http://arxiv.org/abs/2204.10628)\].

Several studies have investigated the effectiveness of autoregressive models in document retrieval. For example, SEAL proposes an approach where all ngrams in a passage are used as potential identifiers, allowing for the use of autoregressive models to generate and score distinctive ngrams, which are then mapped to full passages \[[1](http://arxiv.org/abs/2204.10628)\]. This method outperforms prior autoregressive approaches and establishes new state-of-the-art performance on the KILT benchmark \[[1](http://arxiv.org/abs/2204.10628)\]. Similarly, CorpusBrain introduces a pre-trained generative retrieval model that replaces the traditional "index-retrieve-then-rank" pipeline with a single-step generative model, enabling end-to-end optimization and significantly improving retrieval performance \[[2](http://arxiv.org/abs/2208.07652)\].

Another line of research focuses on the use of dense representations for retrieval, such as in the case of Dense Passage Retrieval (DPR), which uses a dual-encoder framework to learn embeddings from a small number of questions and passages \[[4](http://arxiv.org/abs/2004.04906)\]. This approach outperforms traditional sparse retrieval methods like BM25 and helps establish new state-of-the-art results on open-domain QA benchmarks \[[4](http://arxiv.org/abs/2004.04906)\]. Additionally, ANCE introduces a training mechanism that constructs negative instances from an Approximate Nearest Neighbor (ANN) index, improving the alignment between training and testing data distributions \[[5](http://arxiv.org/abs/2007.00808)\].

The integration of retrieval and generation has also been explored in the form of retrieval-augmented generation (RAG) models, which combine pre-trained parametric and non-parametric memory for language generation \[[6](http://arxiv.org/abs/2005.11401)\]. These models leverage a dense vector index of Wikipedia and a pre-trained neural retriever to enhance the performance of large pre-trained language models on knowledge-intensive tasks \[[6](http://arxiv.org/abs/2005.11401)\]. Similarly, the Differentiable Search Index (DSI) demonstrates that a single Transformer can encode all information about the corpus, allowing for direct query-to-docid mapping without the need for external indexes \[[9](http://arxiv.org/abs/2202.06991)\].

### <a id='category-document-retrieval-techniques'></a>Document Retrieval Techniques: 7 papers found.
Document Retrieval Techniques involve various approaches to efficiently retrieve relevant documents or entities based on a query. Recent work has focused on leveraging autoregressive models to generate document identifiers or entity names directly, bypassing traditional index-based methods \[[6](http://arxiv.org/abs/2005.11401)\]. For instance, SEAL proposes using all ngrams in a passage as possible identifiers, allowing autoregressive models to generate and score distinctive ngrams, which are then mapped to full passages through an efficient data structure \[[1](http://arxiv.org/abs/2204.10628)\]. Similarly, GENRE introduces a system that retrieves entities by generating their unique names, token-by-token, in an autoregressive fashion, conditioned on the context, which mitigates issues related to dense representations and memory footprint \[[3](http://arxiv.org/abs/2010.00904)\]. Dense retrieval methods, such as those using dual-encoder frameworks, have also shown promise, outperforming traditional sparse methods like BM25 in passage retrieval accuracy \[[4](http://arxiv.org/abs/2004.04906)\]. Furthermore, the Neural Corpus Indexer (NCI) aims to unify training and indexing stages by using a sequence-to-sequence network that generates relevant document identifiers directly for a query, improving recall performance \[[7](http://arxiv.org/abs/2206.02743)\]. The Differentiable Search Index (DSI) takes this a step further by encoding all corpus information into a single Transformer model, enabling direct query-to-docid mapping without the need for separate indexing \[[9](http://arxiv.org/abs/2202.06991)\]. These approaches highlight the shift towards end-to-end generative retrieval systems that integrate seamlessly with large language models, offering improved efficiency and generalization capabilities \[[6](http://arxiv.org/abs/2005.11401)\].

### <a id='category-generative-retrieval-research'></a>Generative Retrieval Research: 5 papers found.
The category "Generative Retrieval Research" explores the shift from traditional index-retrieve pipelines to end-to-end generative models that directly produce document identifiers (docids) for retrieval tasks. This paradigm, popularized by the Differentiable Search Index (DSI), replaces external indexes with a single Transformer model, enabling seamless integration with large language models \[[11](http://arxiv.org/abs/2206.10128)\]. However, existing methods face challenges such as data distribution mismatches between indexing and retrieval, particularly in cross-lingual settings \[[11](http://arxiv.org/abs/2206.10128)\]. To address this, DSI-QG introduces an indexing framework that generates relevant queries during indexing, allowing the model to connect document identifiers to query representations, thereby improving retrieval performance \[[11](http://arxiv.org/abs/2206.10128)\]. Additionally, generative retrieval models like CorpusBrain and GenRet demonstrate the potential for end-to-end optimization, with CorpusBrain encoding entire corpora into model parameters and GenRet learning semantic docids through a discrete auto-encoding approach \[[2](http://arxiv.org/abs/2208.07652)\]\[[10](http://arxiv.org/abs/2304.04171)\]. These models also show effectiveness in zero- and low-resource settings, as well as scalability to large corpora \[[2](http://arxiv.org/abs/2208.07652)\]\[[10](http://arxiv.org/abs/2304.04171)\]. Despite these advances, challenges remain in scaling generative retrieval to millions of passages and maintaining performance under dynamic document collections \[[8](http://arxiv.org/abs/2305.11841)\]\[[13](http://arxiv.org/abs/2308.14968)\]. Overall, the field is advancing toward more robust and generalizable generative retrieval systems, though theoretical and practical limitations persist \[[1](http://arxiv.org/abs/2204.10628)\].
