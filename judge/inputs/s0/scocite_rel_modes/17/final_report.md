## Related Works

Semi-supervised learning (SSL) has been extensively studied to improve model performance by leveraging unlabeled data, especially when labeled data is scarce \[[1](https://www.semanticscholar.org/paper/f3df804a7eef204b0c4fc4b81166dec9b4abc073)\]. However, most traditional SSL methods assume that both labeled and unlabeled data share the same class distribution \[[1](https://www.semanticscholar.org/paper/f3df804a7eef204b0c4fc4b81166dec9b4abc073)\]. This assumption is often violated in practice, as unlabeled data may contain out-of-distribution (OOD) samples, or outliers, which are not present in the labeled set \[[2](http://arxiv.org/abs/2007.11330)\]. These outliers can significantly degrade model performance by introducing noise and bias \[[3](http://arxiv.org/abs/2001.07685)\]. To address this challenge, several open-set SSL approaches have been proposed to handle the presence of OOD samples in unlabeled data \[[4](http://arxiv.org/abs/2108.05617)\].

One line of work focuses on detecting and filtering out OOD samples before training \[[5](http://arxiv.org/abs/1905.02249)\]. For example, the Multi-Task Curriculum Framework for Open-Set SSL introduces a joint optimization framework that simultaneously detects OOD samples and trains a classifier on in-distribution (ID) data \[[6](https://www.semanticscholar.org/paper/9e4376e0572de32236e408469ffb2173d89eaab5)\]. This approach uses a probability estimation to identify OOD samples and selects ID samples with small OOD scores for training \[[6](https://www.semanticscholar.org/paper/9e4376e0572de32236e408469ffb2173d89eaab5)\]. Similarly, the Trash to Treasure method leverages all unlabeled data, including OOD samples, during warm-up training and introduces a cross-modal matching strategy to detect OOD samples \[[7](http://arxiv.org/abs/2102.03526)\]. This approach aims to exploit the presence of OOD data for enhanced feature learning while mitigating their adverse impact \[[7](http://arxiv.org/abs/2102.03526)\].

Another approach, such as FixMatch, relies on pseudo-labeling and consistency regularization to improve performance \[[8](http://arxiv.org/abs/2109.00650)\]. However, FixMatch assumes that labeled and unlabeled data share the same label space, which is not always the case in open-set scenarios \[[9](http://arxiv.org/abs/1606.04586)\]. To address this limitation, OpenMatch extends FixMatch with novelty detection using one-vs-all (OVA) classifiers, allowing the model to distinguish between inliers and outliers \[[10](http://arxiv.org/abs/1610.02242)\]. This method introduces an open-set soft-consistency regularization loss to improve outlier detection \[[10](http://arxiv.org/abs/1610.02242)\].

In addition, methods like MixMatch and ReMixMatch have been proposed to improve SSL performance by combining consistency regularization with data augmentation \[[11](http://arxiv.org/abs/2205.07246)\]. These methods aim to reduce the gap between intra-class variance of seen and novel classes \[[12](http://arxiv.org/abs/2105.14148)\]. Furthermore, methods such as CoMatch and SimMatch have been developed to enhance SSL performance by leveraging contrastive learning and similarity matching \[[13](http://arxiv.org/abs/2107.08943)\]. These approaches aim to improve the robustness of models in the presence of OOD data \[[14](http://arxiv.org/abs/1904.12848)\].

### <a id='category-open-set-semi-supervised-learning'></a>Open Set Semi Supervised Learning: 9 papers found.
Open-set semi-supervised learning (OSSL) addresses the challenge where unlabeled data may contain out-of-distribution (OOD) samples, which traditional SSL methods assume are absent \[[1](https://www.semanticscholar.org/paper/f3df804a7eef204b0c4fc4b81166dec9b4abc073)\]. Existing approaches often treat OOD samples as noise, leading to performance degradation \[[5](http://arxiv.org/abs/1905.02249)\]. To mitigate this, several methods have been proposed, such as UASD, which introduces a unified framework for self-distillation and OOD filtering to avoid error propagation \[[1](https://www.semanticscholar.org/paper/f3df804a7eef204b0c4fc4b81166dec9b4abc073)\]. Similarly, OpenMatch combines FixMatch with novelty detection using one-vs-all classifiers to identify and reject outliers \[[12](http://arxiv.org/abs/2105.14148)\]. Other works, like OpenCoS, leverage self-supervised contrastive learning to identify OOD samples and use pseudo-labels for both in-distribution and OOD data to enhance feature learning \[[13](http://arxiv.org/abs/2107.08943)\]. Additionally, TOOR recycles OOD data by projecting them into the space of in-distribution data using adversarial domain adaptation, thereby enriching the training process \[[20](http://arxiv.org/abs/2011.13529)\]. The Class-aware Contrastive Semi-Supervised Learning (CCSSL) further improves pseudo-label quality by separately handling in-distribution and out-of-distribution data, enhancing robustness in real-world settings \[[24](http://arxiv.org/abs/2203.02261)\]. The SSB method improves both inlier classification and outlier detection by incorporating high-confidence pseudo-labeled data and utilizing non-linear transformations to separate inlier and outlier features \[[25](http://arxiv.org/abs/2311.10572)\]. These approaches collectively highlight the importance of addressing OOD samples in SSL, emphasizing the need for robust mechanisms to detect and handle outliers while leveraging unlabeled data effectively.

### <a id='category-semi-supervised-learning-methods'></a>Semi-Supervised Learning Methods: 15 papers found.
In the realm of semi-supervised learning (SSL), recent methods have focused on leveraging unlabeled data to improve model performance, particularly in scenarios with limited labeled data \[[3](http://arxiv.org/abs/2001.07685)\]. Techniques such as consistency regularization and pseudo-labeling have been widely adopted, with FixMatch demonstrating state-of-the-art results by generating pseudo-labels from high-confidence predictions on weakly-augmented images and training the model to predict these labels on strongly-augmented versions \[[3](http://arxiv.org/abs/2001.07685)\]. Similarly, MixMatch extends this idea by incorporating data mixing (MixUp) and guessing low-entropy labels for unlabeled data, achieving significant performance improvements across various benchmarks \[[5](http://arxiv.org/abs/1905.02249)\]. However, existing methods often rely on fixed or predefined thresholds for pseudo-label selection, which may not adapt well to varying learning stages or class distributions \[[8](http://arxiv.org/abs/2109.00650)\]. To address this, FreeMatch introduces a self-adaptive threshold adjustment mechanism, improving performance especially when labeled data are scarce \[[11](http://arxiv.org/abs/2205.07246)\]. Additionally, methods like SimMatch combine semantic and instance-level consistency regularization, enhancing performance on large-scale benchmarks like ImageNet \[[27](http://arxiv.org/abs/2203.06915)\]. These approaches highlight the ongoing efforts to improve robustness and adaptability in SSL, particularly in handling outliers and improving generalization under limited supervision.
