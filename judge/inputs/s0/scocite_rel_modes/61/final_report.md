## Related Works

Personalized outfit generation has been a focal point in recent research, with a growing emphasis on generating compatible and personalized fashion items. Early approaches primarily focused on outfit compatibility, often using rule-based systems or simple similarity measures \[[1](http://arxiv.org/abs/1807.03133)\]. However, these methods lacked the flexibility and adaptability required to capture the nuanced preferences of individual users. With the advent of deep learning, several studies have explored the use of neural networks to model fashion compatibility and generate outfits \[[2](http://arxiv.org/abs/1608.03016)\].

A key challenge in outfit generation is ensuring compatibility between items, which has led to the development of various models that learn compatibility relationships from data. For instance, \[[3](http://arxiv.org/abs/1905.01866)\] proposed a bidirectional LSTM model to learn compatibility relationships by treating an outfit as a sequence of items. This approach enabled the model to predict the next item in a sequence based on previous items, thereby capturing compatibility. Similarly, \[[4](http://arxiv.org/abs/1803.09196)\] introduced a Siamese network to learn embeddings that respect item type and jointly model item similarity and compatibility. This work demonstrated significant improvements over state-of-the-art methods in outfit compatibility prediction and fill-in-the-blank tasks.

Another important direction is the integration of user preferences into the generation process. \[[5](http://arxiv.org/abs/1712.02662)\] introduced a model that connects user preferences regarding individual items and outfits with a Transformer architecture, enabling the generation of personalized outfits. This work was later extended in \[[6](http://arxiv.org/abs/1711.02231)\], where a Personalized Outfit Generation (POG) model was proposed, which not only improved compatibility but also incorporated user-specific preferences. The POG model was evaluated on a large-scale dataset and demonstrated strong performance in both compatibility and personalization metrics.

Recent work has also focused on the use of attention mechanisms to improve the quality and diversity of generated outfits. \[[7](http://arxiv.org/abs/1707.05691)\] proposed a framework that uses attention to model the compatibility of items within an outfit, allowing for more flexible and context-aware generation. This approach was further refined in \[[8](http://arxiv.org/abs/1712.01262)\], where a multi-expert feedback generation module was introduced to ensure comprehensive and objective feedback during the fine-tuning process. This module covers three evaluation perspectives: quality, compatibility, and personalization, which are critical for generating high-quality, personalized outfits.

Additionally, \[[9](http://arxiv.org/abs/1810.02443)\] introduced a model that learns visual-semantic embeddings and compatibility relationships in an end-to-end fashion, demonstrating strong performance on the Polyvore dataset. \[[10](http://arxiv.org/abs/1902.08009)\] extended this work by proposing a graph-based approach to model outfit compatibility, where each item is represented as a node in a graph, and edges capture interactions between items. This approach allowed for more accurate compatibility estimation by leveraging the complex relationships among items

### <a id='category-fashion-recommendation-techniques'></a>Fashion Recommendation Techniques: 13 papers found.
The related works in fashion recommendation techniques focus on improving outfit compatibility, personalization, and automated generation. Several studies address the challenge of compatibility between fashion items, proposing methods that leverage deep learning and user behavior data to enhance recommendation accuracy \[[3](http://arxiv.org/abs/1905.01866)\]. For instance, the Personalized Outfit Generation (POG) model utilizes Transformer architecture to connect user preferences with outfit generation, achieving better compatibility and personalization metrics \[[3](http://arxiv.org/abs/1905.01866)\]. Similarly, the Compatibility Family approach introduces a system that embeds items into a latent space and projects queries to compatible prototypes, improving compatibility prediction \[[8](http://arxiv.org/abs/1712.01262)\]. Additionally, research on learning visual compatibility from user-generated data, such as Polyvore outfits, has led to significant improvements in compatibility prediction and fill-in-the-blank tasks \[[4](http://arxiv.org/abs/1803.09196)\]. The use of Siamese CNNs to model compatibility based on co-occurrence in user behavior data has also shown promise in generating visually compatible outfits \[[12](http://arxiv.org/abs/1509.07473)\]. Furthermore, the development of end-to-end models that jointly learn visual-semantic embeddings and compatibility relationships has enabled more effective outfit recommendations \[[5](http://arxiv.org/abs/1712.02662)\]. These approaches collectively highlight the importance of combining deep learning with user-centric design to address the challenges of fashion recommendation.

### <a id='category-fashion-style-representation-learning'></a>Fashion Style Representation Learning: 2 papers found.
Context: 
	Document 1: [Snippet]: «With the rapid growth of online fashion market, demand for effective fashion recommendation systems has never been greater. In fashion recommendation, the ability to find items that goes well with a few other items based on style is more important than picking a single item based on the user's entire purchase history. Since the same user may have purchased dress suits in one month and casual denims in another, it is impossible to learn the latent style features of those items using only the user ratings. If we were able to represent the style features of fashion items in a reasonable way, we will be able to recommend new items that conform to some small subset of pre-purchased items that make up a coherent style set. We propose Style2Vec, a vector representation model for fashion items. Based on the intuition of distributional semantics used in word embeddings, Style2Vec learns the representation of a fashion item using other items in matching outfits as context. Two different convolutional neural networks are trained to maximize the probability of item co-occurrences. For evaluation, a fashion analogy test is conducted to show that the resulting representation connotes diverse fashion related semantics like shapes, colors, patterns and even latent styles. We also perform style classification using Style2Vec features and show that our method outperforms other baselines.»
