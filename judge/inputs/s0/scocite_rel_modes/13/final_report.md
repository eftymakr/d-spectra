## Related Works

Long-tailed recognition remains a challenging problem in computer vision due to the skewed class distribution in real-world datasets. Several approaches have been proposed to address this issue, primarily focusing on class imbalance through re-weighting, re-sampling, or modifying the loss function \[[1](http://arxiv.org/abs/1910.09217)\]. For instance, \[[2](http://arxiv.org/abs/2107.12028)\] introduced a class-balanced loss based on the effective number of samples, which helps in re-weighting the loss to achieve better performance on long-tailed datasets. Similarly, \[[3](http://arxiv.org/abs/2111.13998)\] proposed a label-distribution-aware margin (LDAM) loss, which minimizes a margin-based generalization bound and improves performance on imbalanced datasets.

Contrastive learning has also been explored for long-tailed recognition. \[[4](http://arxiv.org/abs/1904.05160)\] proposed supervised contrastive learning (SCL), which leverages label information to pull positive samples together and push negative samples apart in the embedding space. However, \[[5](http://arxiv.org/abs/2002.05709)\] pointed out that SCL tends to bias towards high-frequency classes, making it difficult to learn from imbalanced data. To address this, \[[6](http://arxiv.org/abs/1912.02413)\] introduced Parametric Contrastive Learning (PaCo), which uses class-wise learnable centers to rebalance the loss during training. This approach helps in adapting the intensity of pushing samples closer to their respective centers, thereby improving performance on long-tailed datasets.

Another approach, \[[7](http://arxiv.org/abs/2104.00466)\], focused on improving the uniformity of feature distributions in the hypersphere by introducing a targeted supervised contrastive learning (TSC) method. This method generates uniformly distributed targets and ensures that features of different classes converge to these targets, enhancing class boundaries and generalization. \[[8](http://arxiv.org/abs/2207.09052)\] further extended this idea by proposing a dynamic meta-embedding that combines direct image features with memory features, allowing the model to acknowledge novelty in open-world scenarios.

The decoupling of representation and classifier learning has also been explored as a solution to long-tailed recognition. \[[9](http://arxiv.org/abs/2010.01809)\] introduced a method where representation learning and classifier learning are treated separately, showing that simple instance-balanced sampling can lead to strong long-tailed recognition performance. \[[10](http://arxiv.org/abs/2103.16370)\] further explored this idea by proposing a two-stage training paradigm, where features are learned using cross-entropy loss, and classifiers are learned using class-balanced loss, leading to improved performance on benchmark datasets.

### <a id='category-long-tailed-visual-recognition'></a>Long Tailed Visual Recognition: 19 papers found.
The long-tailed recognition problem, where a few classes dominate the dataset while most are underrepresented, has been extensively studied in recent years, with various approaches proposed to address the class imbalance issue. Early methods primarily relied on class-balancing strategies such as loss re-weighting, data re-sampling, or transfer learning from head to tail classes \[[1](http://arxiv.org/abs/1910.09217)\]. However, these approaches often suffer from overfitting to tail classes or fail to capture sufficient discriminative features \[[6](http://arxiv.org/abs/1912.02413)\]. More recent work has focused on decoupling representation learning from classifier learning, showing that high-quality representations can be learned with simple instance-balanced sampling, and strong long-tailed recognition can be achieved by adjusting only the classifier \[[1](http://arxiv.org/abs/1910.09217)\]. This idea has been further refined with methods like Parametric Contrastive Learning (PaCo), which introduces parametric class-wise learnable centers to rebalance the optimization process and improve performance on benchmarks like CIFAR, ImageNet, and iNaturalist \[[2](http://arxiv.org/abs/2107.12028)\]. Additionally, methods such as Balanced Softmax and Logit Adjustment have been proposed to address the bias in gradient estimation and improve calibration, achieving state-of-the-art results on multiple benchmarks \[[13](http://arxiv.org/abs/2007.10740)\]\[[14](http://arxiv.org/abs/2007.07314)\]. Furthermore, the concept of weight balancing, including techniques like L2-normalization, weight decay, and MaxNorm, has been explored to reduce classifier variance and improve performance \[[11](http://arxiv.org/abs/2203.14197)\]. These approaches highlight the ongoing efforts to balance representation learning and classification in long-tailed scenarios, with a growing emphasis on theoretical foundations and unified frameworks \[[15](http://arxiv.org/abs/2109.04075)\]\[[18](http://arxiv.org/abs/2012.00321)\].

Recently, researchers have investigated the potential of supervised contrastive learning for long-tailed recognition, and demonstrated that it provides a strong performance gain. In this paper, we show that while supervised contrastive learning can help improve performance, past baselines suffer from poor uniformity brought in by imbalanced data distribution. This poor uniformity manifests in samples from the minority class having poor separability in the feature space. To address this problem, we propose targeted supervised contrastive learning (TSC), which improves the uniformity of the feature distribution on the hypersphere. TSC first generates a set of targets uniformly distributed on a hypersphere. It then makes the features of different classes converge to these distinct and uniformly distributed targets during training. This forces all classes, including minority classes, to maintain a uniform distribution in the feature space, improves class boundaries, and provides better generalization even in the presence of long-tail data. Experiments on multiple datasets show that TSC achieves state-of-the-art performance on long-tailed recognition tasks.»

In this work, we identify two key properties related to the contrastive loss: (1) alignment (closeness) of features from positive pairs, and (2) uniformity of the induced distribution of the (normalized) features on the hypersphere. We prove that, asymptotically, the contrastive loss optimizes these properties, and analyze their positive effects on downstream tasks. Empirically, we introduce an optimizable metric to quantify each property.
