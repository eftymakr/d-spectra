## Related Works

Deploying large language models (LLMs) on edge devices presents significant challenges due to limited storage, power, and computational resources \[[1](http://arxiv.org/abs/2309.06180)\]. Prior work has explored various techniques to optimize LLM inference on resource-constrained hardware. For instance, quantization methods such as SmoothQuant \[[8](http://arxiv.org/abs/2211.10438)\] enable 8-bit weight and activation quantization, reducing memory usage and improving inference speed without significant accuracy loss. Similarly, AWQ \[[6](http://arxiv.org/abs/2306.00978)\] introduces activation-aware weight quantization, further enhancing on-device deployment efficiency. These methods are crucial for enabling LLMs to run on edge devices with limited memory and computational power.

Efficient memory management is another critical area of research. PagedAttention \[[1](http://arxiv.org/abs/2309.06180)\] and vLLM \[[1](http://arxiv.org/abs/2309.06180)\] address the issue of dynamic key-value cache (KV cache) memory management, reducing fragmentation and improving throughput. These systems are particularly beneficial for handling long sequences and complex decoding algorithms, which are common in LLM inference. Additionally, FlashAttention \[[22](http://arxiv.org/abs/2205.14135)\] and FlashAttention-2 \[[5](http://arxiv.org/abs/2307.08691)\] improve the efficiency of attention mechanisms by optimizing memory access patterns and parallelism, achieving significant speedups over traditional attention implementations.

Hardware acceleration has also been extensively studied. FTRANS \[[10](http://arxiv.org/abs/2007.08563)\] leverages FPGAs to accelerate transformer-based models, achieving substantial improvements in performance and energy efficiency compared to CPUs and GPUs. Similarly, DFX \[[12](http://arxiv.org/abs/2209.10797)\] presents a multi-FPGA appliance for text generation, demonstrating low latency and high throughput for GPT-2 models. NPE \[[13](http://arxiv.org/abs/2104.06535)\] and LlamaF \[[14](http://arxiv.org/abs/2409.11424)\] further explore FPGA-based solutions for NLP tasks, emphasizing power efficiency and real-time performance. These works highlight the potential of FPGAs in accelerating LLM inference on edge devices.

Sparsity-aware techniques have also been proposed to reduce computational overhead. DejaVu \[[4](http://arxiv.org/abs/2310.17157)\] exploits contextual sparsity, allowing for faster inference by pruning unnecessary attention heads and MLP parameters. SpAtten \[[18](http://arxiv.org/abs/2012.09852)\] introduces cascade token and head pruning, reducing memory access and computation while maintaining model accuracy. These approaches are particularly useful for edge devices where computational resources are limited.

Inference optimization techniques such as speculative decoding \[[21](http://arxiv.org/abs/2302.01318)\] and speculative sampling \[[21](http://arxiv.org/abs/2302.01318)\] aim to accelerate the decoding process by generating multiple tokens in parallel. These methods reduce the number of model calls required, improving throughput without compromising output quality. Similarly, LLMA \[[19](http://arxiv.org/abs/2304.04487)\] leverages reference-based acceleration, reusing previously generated tokens to speed up inference in scenarios with high overlap between reference and output.

### <a id='category-hardware-accelerators-for-llms'></a>Hardware Accelerators for LLMs: 6 papers found.
Hardware accelerators for large language models (LLMs) have been extensively explored to address the computational and energy efficiency challenges associated with deploying LLMs on edge devices \[[4](http://arxiv.org/abs/2310.17157)\]. The self-attention mechanism, a core component of transformer-based models, is particularly resource-intensive due to its quadratic complexity with respect to input size, making it a key target for optimization \[[1](http://arxiv.org/abs/2309.06180)\]. Several approaches have been proposed to reduce the computational overhead of self-attention, such as ELSA, which introduces an approximation scheme to filter out less impactful relations, achieving a geomean speedup of 58.1× and significant energy savings \[[1](http://arxiv.org/abs/2309.06180)\]. Similarly, SpAtten leverages token and head sparsity, along with quantization, to reduce attention computation and memory access, demonstrating up to 347× speedup over GPUs \[[5](http://arxiv.org/abs/2307.08691)\]. FPGA-based solutions, such as Ftrans and NPE, have also been developed to accelerate transformer models, with Ftrans achieving up to 81× performance improvement over GPUs and NPE offering 4x lower power consumption than CPUs for BERT inference \[[2](http://arxiv.org/abs/2312.11514)\]\[[3](https://www.semanticscholar.org/paper/5af69480a7ae3b571df6782a11ec4437b386a7d9)\]. These accelerators highlight the growing focus on algorithm-hardware co-design to enhance both performance and energy efficiency in LLM deployment \[[4](http://arxiv.org/abs/2310.17157)\].

### <a id='category-efficient-large-language-model-techniques'></a>Efficient Large Language Model Techniques: 8 papers found.
Efficient Large Language Model Techniques focus on reducing computational and memory costs while maintaining model performance. Various methods have been proposed to address these challenges, including contextual sparsity \[[4](http://arxiv.org/abs/2310.17157)\], activation-aware weight quantization \[[6](http://arxiv.org/abs/2306.00978)\], and post-training quantization techniques like SmoothQuant \[[8](http://arxiv.org/abs/2211.10438)\]. Contextual sparsity enables inference speedup by leveraging input-dependent sparsity in attention mechanisms without compromising model quality. Activation-aware weight quantization, on the other hand, identifies and preserves critical weights based on activation patterns, allowing for significant model size reduction and performance preservation \[[6](http://arxiv.org/abs/2306.00978)\]. Similarly, SmoothQuant enables 8-bit weight and activation quantization through mathematical transformations that mitigate activation outliers, achieving speedups and memory reductions with minimal accuracy loss \[[8](http://arxiv.org/abs/2211.10438)\]. Additionally, speculative decoding \[[9](http://arxiv.org/abs/2211.17192)\] accelerates autoregressive model inference by parallelizing token generation, while StreamingLLM \[[11](http://arxiv.org/abs/2309.17453)\] addresses long-sequence generation by mitigating attention sink through caching and attention mechanisms. These techniques collectively aim to make LLMs more deployable on edge devices and reduce hardware costs \[[12](http://arxiv.org/abs/2209.10797)\].

### <a id='category-fpga-based-dnn-accelerators'></a>FPGA Based DNN Accelerators: 2 papers found.
FPGA-based DNN accelerators have emerged as a promising solution for deploying large language models (LLMs) on resource-constrained edge devices, addressing the challenges of memory and computational demands \[[14](http://arxiv.org/abs/2409.11424)\]. These accelerators leverage post-training quantization to reduce model size and optimize off-chip memory bandwidth, enabling faster inference on embedded FPGAs \[[14](http://arxiv.org/abs/2409.11424)\]. Additionally, they incorporate asynchronous computation and pipelined matrix-vector multiplication to enhance performance \[[14](http://arxiv.org/abs/2409.11424)\]. Research also highlights the need for efficient design methodologies to reduce development overhead, as traditional FPGA-based DNN accelerators require repeated synthesis passes and HDL reimplementation, increasing time and effort \[[15](http://arxiv.org/abs/2110.00478)\]. To address this, SECDA proposes a hardware/software co-design approach that integrates SystemC simulation with hardware execution, streamlining design space exploration and reducing evaluation time \[[15](http://arxiv.org/abs/2110.00478)\]. This methodology enables rapid iteration and performance optimization, achieving up to 3.5× speedup and 2.9× energy reduction compared to CPU-only inference \[[15](http://arxiv.org/abs/2110.00478)\]. These advancements underscore the growing importance of FPGA-based accelerators in enabling efficient LLM deployment on edge devices.
