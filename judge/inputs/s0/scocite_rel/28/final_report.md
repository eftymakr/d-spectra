## Related Works

Federated Learning (FL) has emerged as a promising paradigm for training machine learning models on decentralized data while preserving privacy \[[3](http://arxiv.org/abs/1912.04977)\]. In FL, a central server coordinates with multiple clients to collaboratively train a global model without sharing raw data \[[3](http://arxiv.org/abs/1912.04977)\]. However, the heterogeneity of client data distributions and the associated fluctuations in model parameters pose significant challenges to model accuracy \[[10](http://arxiv.org/abs/1806.00582)\]. Existing FL approaches, such as Federated Averaging (FedAvg), often struggle with these issues due to their inability to adapt to non-IID data \[[10](http://arxiv.org/abs/1806.00582)\]. 

To address the issue of non-IID data, several works have proposed adaptive optimization methods, including variants of Adagrad, Adam, and Yogi, which have shown improved convergence behavior in heterogeneous settings \[[2](http://arxiv.org/abs/2003.00295)\]. Additionally, communication efficiency remains a critical concern in FL, particularly in mobile edge computing environments where clients have limited computational resources and unreliable network connections \[[5](http://arxiv.org/abs/1804.08333)\]. Techniques such as structured and sketched updates have been proposed to reduce communication costs by compressing model updates \[[4](http://arxiv.org/abs/1610.05492)\].

Client selection strategies have also been explored to improve the efficiency of FL, especially in scenarios where some clients have limited resources or poor network conditions \[[5](http://arxiv.org/abs/1804.08333)\]. The FedCS protocol, for instance, actively manages clients based on their resource conditions, allowing the server to aggregate as many updates as possible and accelerate performance improvement \[[5](http://arxiv.org/abs/1804.08333)\]. Similarly, the Power-of-Choice strategy has been introduced to bias client selection towards those with higher local loss, achieving faster convergence \[[15](http://arxiv.org/abs/2010.01243)\].

In the context of model personalization, FL has been extended to incorporate meta-learning techniques, such as Model Agnostic Meta Learning (MAML), which enables the global model to be adapted to individual clients' data distributions \[[19](http://arxiv.org/abs/1909.12488)\]. This aligns with the goal of Federated Active Learning (FAL), which aims to reduce annotation costs by strategically selecting the most informative unlabeled data for annotation while preserving data privacy \[[1](http://arxiv.org/abs/1812.01097)\]. ### <a id='category-federated-learning-(fl)-overview'></a>Federated Learning (FL) Overview: 9 papers found.
Federated learning (FL) has emerged as a critical paradigm for training machine learning models across decentralized data sources while preserving privacy \[[2](http://arxiv.org/abs/2003.00295)\]. It enables collaborative model training across multiple clients, such as mobile devices or organizations, under the orchestration of a central server \[[3](http://arxiv.org/abs/1912.04977)\]. However, FL faces significant challenges, including statistical heterogeneity (non-identically distributed data) and systems heterogeneity (variability in device capabilities) \[[9](http://arxiv.org/abs/1812.06127)\]. To address these issues, researchers have proposed various frameworks and techniques. For instance, FedProx generalizes FedAvg by introducing a proximal term that allows for more robust convergence in heterogeneous settings \[[9](http://arxiv.org/abs/1812.06127)\]. Similarly, ensemble distillation has been proposed to enable flexible aggregation of client models with differing structures, improving training efficiency and reducing communication rounds \[[7](http://arxiv.org/abs/2006.07242)\]. Additionally, q-Fair Federated Learning introduces fairness considerations by promoting uniform accuracy distribution across devices \[[11](http://arxiv.org/abs/1905.10497)\]. These advancements highlight the ongoing efforts to enhance the scalability, efficiency, and fairness of FL systems. Furthermore, frameworks like Flower have been developed to support large-scale FL experiments on heterogeneous edge devices \[[16](http://arxiv.org/abs/2007.14390)\]. These contributions collectively address the challenges of FL, making it a promising direction for future research \[[1](http://arxiv.org/abs/1812.01097)\].

Model personalization in federated learning (FL) has garnered significant attention due to the inherent data heterogeneity across clients, which often leads to suboptimal performance with conventional FL approaches \[[19](http://arxiv.org/abs/1909.12488)\]. Recent works have explored ways to adapt global models to individual clients while preserving data privacy. For instance, Federated Averaging, a popular FL algorithm, has been interpreted as a meta learning framework, where the goal is to optimize for a fast adaptation to heterogeneous distributions \[[19](http://arxiv.org/abs/1909.12488)\]. This aligns with the objectives of Model Agnostic Meta Learning (MAML), which focuses on few-shot adaptation \[[19](http://arxiv.org/abs/1909.12488)\]. However, personalization remains challenging, as optimizing solely for global model accuracy does not necessarily improve individual client performance \[[19](http://arxiv.org/abs/1909.12488)\]. To address this, novel approaches like clustered FL (CFL) have been proposed, which leverage geometric properties of the FL loss surface to group clients into clusters with similar data distributions, enabling more specialized model training without modifying the FL communication protocol \[[6](http://arxiv.org/abs/1910.01991)\]. These methods highlight the growing interest in balancing global model quality with client-specific personalization, while maintaining privacy and efficiency.
