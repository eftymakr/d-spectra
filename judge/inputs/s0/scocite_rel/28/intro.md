## Related Works

Federated Learning (FL) has emerged as a promising paradigm for training machine learning models on decentralized data while preserving privacy \[[3](http://arxiv.org/abs/1912.04977)\]. In FL, a central server coordinates with multiple clients to collaboratively train a global model without sharing raw data \[[3](http://arxiv.org/abs/1912.04977)\]. However, the heterogeneity of client data distributions and the associated fluctuations in model parameters pose significant challenges to model accuracy \[[10](http://arxiv.org/abs/1806.00582)\]. Existing FL approaches, such as Federated Averaging (FedAvg), often struggle with these issues due to their inability to adapt to non-IID data \[[10](http://arxiv.org/abs/1806.00582)\]. 

To address the issue of non-IID data, several works have proposed adaptive optimization methods, including variants of Adagrad, Adam, and Yogi, which have shown improved convergence behavior in heterogeneous settings \[[2](http://arxiv.org/abs/2003.00295)\]. Additionally, communication efficiency remains a critical concern in FL, particularly in mobile edge computing environments where clients have limited computational resources and unreliable network connections \[[5](http://arxiv.org/abs/1804.08333)\]. Techniques such as structured and sketched updates have been proposed to reduce communication costs by compressing model updates \[[4](http://arxiv.org/abs/1610.05492)\].

Client selection strategies have also been explored to improve the efficiency of FL, especially in scenarios where some clients have limited resources or poor network conditions \[[5](http://arxiv.org/abs/1804.08333)\]. The FedCS protocol, for instance, actively manages clients based on their resource conditions, allowing the server to aggregate as many updates as possible and accelerate performance improvement \[[5](http://arxiv.org/abs/1804.08333)\]. Similarly, the Power-of-Choice strategy has been introduced to bias client selection towards those with higher local loss, achieving faster convergence \[[15](http://arxiv.org/abs/2010.01243)\].

In the context of model personalization, FL has been extended to incorporate meta-learning techniques, such as Model Agnostic Meta Learning (MAML), which enables the global model to be adapted to individual clients' data distributions \[[19](http://arxiv.org/abs/1909.12488)\]. This aligns with the goal of Federated Active Learning (FAL), which aims to reduce annotation costs by strategically selecting the most informative unlabeled data for annotation while preserving data privacy \[[1](http://arxiv.org/abs/1812.01097)\]. However, existing FAL methods often fail to account for the heterogeneity of data distribution across clients and the associated fluctuations in model parameters, which can significantly affect model accuracy \[[1](http://arxiv.org/abs/1812.01097)\].
