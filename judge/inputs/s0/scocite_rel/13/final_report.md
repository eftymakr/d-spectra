## Related Works

Long-tailed recognition remains a challenging problem in computer vision due to the skewed class distribution in real-world datasets. Several approaches have been proposed to address this issue, primarily focusing on class imbalance through re-weighting, re-sampling, or modifying the loss function \[[1](http://arxiv.org/abs/1910.09217)\]. For instance, \[[2](http://arxiv.org/abs/2107.12028)\] introduced a class-balanced loss based on the effective number of samples, which helps in re-weighting the loss to achieve better performance on long-tailed datasets. Similarly, \[[3](http://arxiv.org/abs/2111.13998)\] proposed a label-distribution-aware margin (LDAM) loss, which minimizes a margin-based generalization bound and improves performance on imbalanced datasets.

Contrastive learning has also been explored for long-tailed recognition. \[[4](http://arxiv.org/abs/1904.05160)\] proposed supervised contrastive learning (SCL), which leverages label information to pull positive samples together and push negative samples apart in the embedding space. However, \[[5](http://arxiv.org/abs/2002.05709)\] pointed out that SCL tends to bias towards high-frequency classes, making it difficult to learn from imbalanced data. To address this, \[[6](http://arxiv.org/abs/1912.02413)\] introduced Parametric Contrastive Learning (PaCo), which uses class-wise learnable centers to rebalance the loss during training. This approach helps in adapting the intensity of pushing samples closer to their respective centers, thereby improving performance on long-tailed datasets.

Another approach, \[[7](http://arxiv.org/abs/2104.00466)\], focused on improving the uniformity of feature distributions in the hypersphere by introducing a targeted supervised contrastive learning (TSC) method. This method generates uniformly distributed targets and ensures that features of different classes converge to these targets, enhancing class boundaries and generalization. \[[8](http://arxiv.org/abs/2207.09052)\] further extended this idea by proposing a dynamic meta-embedding that combines direct image features with memory features, allowing the model to acknowledge novelty in open-world scenarios.

The decoupling of representation and classifier learning has also been explored as a solution to long-tailed recognition. \[[9](http://arxiv.org/abs/2010.01809)\] introduced a method where representation learning and classifier learning are treated separately, showing that simple instance-balanced sampling can lead to strong long-tailed recognition performance. \[[10](http://arxiv.org/abs/2103.16370)\] further explored this idea by proposing a two-stage training paradigm, where features are learned using cross-entropy loss, and classifiers are learned using class-balanced loss, leading to improved performance on benchmark datasets.

In addition, \[[11](http://arxiv.org/abs/2203.14197)\] introduced a simple framework for contrastive learning of visual representations, showing that contrastive learning can significantly outperform previous methods in self-supervised learning. \[[12](http://arxiv.org/abs/2103.14267)\] extended this idea by proposing a hybrid network structure that combines supervised contrastive loss with cross-entropy

### <a id='category-class-imbalance-solutions'></a>Class Imbalance Solutions: 13 papers found.
Class imbalance remains a significant challenge in long-tailed recognition, with existing methods often suffering from poor uniformity in feature space or miscalibration issues \[[3](http://arxiv.org/abs/2111.13998)\]. Supervised contrastive learning (SCL) has shown promise but struggles with long-tailed data due to imbalanced attraction and repulsion gradients between positive and negative pairs \[[8](http://arxiv.org/abs/2207.09052)\]. To address this, several approaches have been proposed, such as Parametric Contrastive Learning (PaCo), which introduces class-wise learnable centers to rebalance the optimization process \[[2](http://arxiv.org/abs/2107.12028)\]. Similarly, Targeted Supervised Contrastive Learning (TSC) improves feature uniformity by generating uniformly distributed targets on a hypersphere \[[3](http://arxiv.org/abs/2111.13998)\]. The Bilateral-Branch Network (BBN) further tackles the issue by simultaneously enhancing representation and classifier learning through a cumulative learning strategy \[[6](http://arxiv.org/abs/1912.02413)\]. Additionally, methods like label-aware smoothing and shifted batch normalization have been introduced to improve calibration and mitigate dataset bias \[[7](http://arxiv.org/abs/2104.00466)\]. Theoretical analysis has also revealed that SCL fails to form a regular simplex for long-tailed data, leading to the proposal of Balanced Contrastive Learning (BCL) with class-averaging and class-complement improvements \[[8](http://arxiv.org/abs/2207.09052)\]. The RoutIng Diverse Experts (RIDE) framework reduces bias and variance by employing a distribution-aware diversity loss and dynamic expert routing \[[9](http://arxiv.org/abs/2010.01809)\]. Weight balancing techniques, including L2-normalization, weight decay, and MaxNorm, have also been explored to achieve more balanced class weights \[[11](http://arxiv.org/abs/2203.14197)\]. Overall, these approaches highlight the importance of addressing both representation learning and classifier learning in long-tailed recognition, with a growing emphasis on theoretical insights and unified frameworks \[[10](http://arxiv.org/abs/2103.16370)\].
