## Related Works

Deploying large language models (LLMs) on edge devices presents significant challenges due to limited storage, power, and computational resources \[[1](http://arxiv.org/abs/2309.06180)\]. Prior work has explored various techniques to optimize LLM inference on resource-constrained hardware. For instance, quantization methods such as SmoothQuant \[[8](http://arxiv.org/abs/2211.10438)\] enable 8-bit weight and activation quantization, reducing memory usage and improving inference speed without significant accuracy loss. Similarly, AWQ \[[6](http://arxiv.org/abs/2306.00978)\] introduces activation-aware weight quantization, further enhancing on-device deployment efficiency. These methods are crucial for enabling LLMs to run on edge devices with limited memory and computational power.

Efficient memory management is another critical area of research. PagedAttention \[[1](http://arxiv.org/abs/2309.06180)\] and vLLM \[[1](http://arxiv.org/abs/2309.06180)\] address the issue of dynamic key-value cache (KV cache) memory management, reducing fragmentation and improving throughput. These systems are particularly beneficial for handling long sequences and complex decoding algorithms, which are common in LLM inference. Additionally, FlashAttention \[[22](http://arxiv.org/abs/2205.14135)\] and FlashAttention-2 \[[5](http://arxiv.org/abs/2307.08691)\] improve the efficiency of attention mechanisms by optimizing memory access patterns and parallelism, achieving significant speedups over traditional attention implementations.

Hardware acceleration has also been extensively studied. FTRANS \[[10](http://arxiv.org/abs/2007.08563)\] leverages FPGAs to accelerate transformer-based models, achieving substantial improvements in performance and energy efficiency compared to CPUs and GPUs. Similarly, DFX \[[12](http://arxiv.org/abs/2209.10797)\] presents a multi-FPGA appliance for text generation, demonstrating low latency and high throughput for GPT-2 models. NPE \[[13](http://arxiv.org/abs/2104.06535)\] and LlamaF \[[14](http://arxiv.org/abs/2409.11424)\] further explore FPGA-based solutions for NLP tasks, emphasizing power efficiency and real-time performance. These works highlight the potential of FPGAs in accelerating LLM inference on edge devices.

Sparsity-aware techniques have also been proposed to reduce computational overhead. DejaVu \[[4](http://arxiv.org/abs/2310.17157)\] exploits contextual sparsity, allowing for faster inference by pruning unnecessary attention heads and MLP parameters. SpAtten \[[18](http://arxiv.org/abs/2012.09852)\] introduces cascade token and head pruning, reducing memory access and computation while maintaining model accuracy. These approaches are particularly useful for edge devices where computational resources are limited.

Inference optimization techniques such as speculative decoding \[[21](http://arxiv.org/abs/2302.01318)\] and speculative sampling \[[21](http://arxiv.org/abs/2302.01318)\] aim to accelerate the decoding process by generating multiple tokens in parallel. These methods reduce the number of model calls required, improving throughput without compromising output quality. Similarly, LLMA \[[19](http://arxiv.org/abs/2304.04487)\] leverages reference-based acceleration, reusing previously generated tokens to speed up inference in scenarios with high overlap between reference and output.
