## Related Works

Open-vocabulary object detection has emerged as a critical research direction, enabling detectors to recognize objects based on natural language inputs rather than a fixed set of predefined categories \[[1](http://arxiv.org/abs/2011.10678)\]. This capability is particularly valuable in scenarios where the target object categories are not known during training, such as in zero-shot or open-world settings \[[2](http://arxiv.org/abs/2104.13921)\]. However, the performance of these models can be significantly affected by the quality and relevance of the user-defined vocabulary \[[3](http://arxiv.org/abs/2103.00020)\]. In this work, we introduce a plug-and-play Vocabulary Adapter (VocAda) that dynamically refines the user-defined vocabulary at inference time, improving detection accuracy by focusing on relevant classes \[[4](http://arxiv.org/abs/2205.06230)\].

Several prior works have explored methods to expand the vocabulary of object detectors. For example, \[[5](http://arxiv.org/abs/2203.14940)\] proposed a method that leverages image-caption pairs to generate pseudo bounding-box annotations, enabling the training of detectors on a broader set of object categories without requiring extensive manual annotations. Similarly, \[[6](http://arxiv.org/abs/2207.03482)\] introduced a two-stage training approach that first uses image-caption matching to learn class labels for both novel and known classes in a weakly-supervised manner, then specializes the model for object detection using known class annotations. These methods, however, often require additional training or fine-tuning, which can be computationally expensive \[[7](http://arxiv.org/abs/2111.09452)\].

Another line of research focuses on aligning visual and language representations to enable zero-shot detection. For instance, \[[8](http://arxiv.org/abs/2203.11876)\] proposed a method that aligns object proposals with text embeddings from a pre-trained vision-language model, enabling the detection of novel classes without explicit bounding box annotations. This approach has been further refined in \[[9](http://arxiv.org/abs/2201.02605)\], where a novel framework was introduced that directly learns from image-text pairs without relying on expensive grounding annotations or distilling classification-oriented vision models. These methods demonstrate the potential of leveraging language supervision to improve detection performance, especially in open-vocabulary settings \[[10](http://arxiv.org/abs/2207.08954)\].

Additionally, \[[11](http://arxiv.org/abs/2111.12698)\] introduced a method that uses vision-language models to generate pseudo labels for object detection, effectively expanding the vocabulary of detectors by leveraging large-scale image-caption pairs. These methods typically leverage pre-trained models, like deep convolutional neural networks, to learn object detection capabilities from large-scale image classification tasks \[[20](http://arxiv.org/abs/1511.02853)\]. However, existing approaches often struggle with precise object localization and alignment between language and visual features \[[6](http://arxiv.org/abs/2207.03482)\]. For instance, CLIP-based models, while powerful, lack fine-grained localization, while image-level supervision often relies on heuristic methods that do not accurately capture object regions \[[6](http://arxiv.org/abs/2207.03482)\]. To address these limitations, recent work has focused on improving object-centric alignment of language embeddings and visually grounding objects using pseudo-labeling techniques \[[6](http://arxiv.org/abs/2207.03482)\]. Additionally, there is growing interest in utilizing unstructured textual descriptions to enhance detection performance, as they provide richer semantic information than image-level annotations alone \[[22](http://arxiv.org/abs/1907.10164)\]. These approaches aim to extract more meaningful features from textual data, enabling better generalization and detection accuracy. By integrating multiple sources of supervision and refining the alignment between visual and linguistic representations, these methods seek to bridge the gap between object-centric and image-centric representations in open-vocabulary detection \[[6](http://arxiv.org/abs/2207.03482)\].

### <a id='category-open-vocabulary-object-detection-frameworks'></a>Open-vocabulary object detection frameworks: 6 papers found.
Open-vocabulary object detection has emerged as a critical area of research, enabling detectors to identify objects based on natural language queries or exemplar images, thus expanding their applicability beyond fixed vocabularies \[[8](http://arxiv.org/abs/2203.11876)\]. Several approaches have been proposed to address the limitations of traditional detectors, which are constrained by the size and diversity of training data \[[9](http://arxiv.org/abs/2201.02605)\]. Additionally, F-VLM simplifies the training pipeline by utilizing frozen vision-language models, which retain locality-sensitive features and act as strong region classifiers, leading to significant improvements in mask AP on the LVIS benchmark \[[28](http://arxiv.org/abs/2209.15639)\]. These approaches collectively highlight the shift towards more flexible and scalable open-vocabulary detection frameworks that reduce dependency on manual annotations and enhance generalization to unseen classes.
