## Related Works

Federated learning (FL) has emerged as a promising paradigm for collaborative machine learning while preserving data privacy by keeping training data decentralized \[[23](http://arxiv.org/abs/1912.04977)\]. This has led to increased interest in the "right to be forgotten," which requires users to have the ability to remove their data from trained models \[[1](http://arxiv.org/abs/2203.07320)\]. This has spurred the development of federated unlearning (FU), a process that aims to eliminate the influence of specific data points or clients on the global model \[[2](https://www.semanticscholar.org/paper/39da2d48f2132b919405e3bb6df6ece44ac6e15a)\]. 

Several approaches have been proposed to achieve federated unlearning. One common method involves retraining the model from scratch after removing the data \[[1](http://arxiv.org/abs/2203.07320)\]. However, this approach is computationally expensive and impractical for large-scale FL systems \[[3](https://www.semanticscholar.org/paper/eadeffdec9fac8fd7f9aea732ca410eb082b7dcf)\]. To address this, researchers have explored alternative methods such as local unlearning followed by a few rounds of federated learning \[[4](http://arxiv.org/abs/2207.05521)\]. This approach reduces the computational overhead by leveraging the locally unlearned model as an initialization for the global unlearning process \[[4](http://arxiv.org/abs/2207.05521)\]. 

Another line of research focuses on using historical parameter updates to reconstruct the unlearned model without requiring full retraining \[[3](https://www.semanticscholar.org/paper/eadeffdec9fac8fd7f9aea732ca410eb082b7dcf)\]. For example, FedEraser reconstructs the unlearned model by leveraging the historical parameter updates of federated clients, which are retained at the central server during the training process \[[3](https://www.semanticscholar.org/paper/eadeffdec9fac8fd7f9aea732ca410eb082b7dcf)\]. This method significantly reduces the time required to construct the unlearned model while maintaining its performance \[[3](https://www.semanticscholar.org/paper/eadeffdec9fac8fd7f9aea732ca410eb082b7dcf)\]. 

In addition to retraining-based methods, some studies have proposed using knowledge distillation to restore model performance without accessing the clients' data \[[5](http://arxiv.org/abs/2201.09441)\]. This method subtracts the accumulated historical updates from the model and leverages knowledge distillation to restore the model's performance \[[5](http://arxiv.org/abs/2201.09441)\]. This approach is particularly useful in scenarios where clients are not willing to share their data \[[5](http://arxiv.org/abs/2201.09441)\]. 

The challenge of verifying the effectiveness of federated unlearning has also been addressed in recent studies. For example, VeriFi introduces a framework that allows for systematic analysis of federated unlearning and quantification of its effect \[[8](http://arxiv.org/abs/2205.12709)\]. This framework enables the verification of the unlearning effect by marking and checking the global model's performance change on the markers \[[8](http://arxiv.org/abs/2205.12709)\].

### <a id='category-retraining-based-unlearning-methods'></a>Retraining-Based Unlearning Methods: 2 papers found.
The category "Retraining-Based Unlearning Methods" focuses on techniques that enable the removal of specific data samples from machine learning models, particularly in distributed settings like Federated Learning (FL). These methods typically involve retraining the model from scratch or using a subset of data to erase the influence of the targeted data points \[[1](http://arxiv.org/abs/2203.07320)\]. In FL, where data remains decentralized and not shared with a central server, unlearning becomes more complex, as traditional centralized approaches are not directly applicable \[[1](http://arxiv.org/abs/2203.07320)\]. To address this, researchers have proposed frameworks such as SISA training, which strategically limits the influence of specific data points during training, thereby reducing the computational overhead of unlearning \[[26](http://arxiv.org/abs/1912.03817)\]. This approach is especially beneficial for stateful algorithms like stochastic gradient descent, where the model's state is continuously updated \[[26](http://arxiv.org/abs/1912.03817)\]. Additionally, prior knowledge about the distribution of unlearning requests can be leveraged to optimize the unlearning process, further improving efficiency \[[26](http://arxiv.org/abs/1912.03817)\]. These methods aim to balance the need for data privacy with the performance of the model, ensuring that unlearning does not significantly degrade utility \[[1](http://arxiv.org/abs/2203.07320)\]. The effectiveness of these approaches has been evaluated across various datasets, demonstrating significant improvements in unlearning speed compared to retraining from scratch \[[26](http://arxiv.org/abs/1912.03817)\]. Such advancements are crucial for compliance with privacy regulations like the "right to be forgotten," which require machine learning systems to support data removal requests \[[1](http://arxiv.org/abs/2203.07320)\].

### <a id='category-federated-unlearning-overview'></a>Federated Unlearning Overview: 23 papers found.
The category "Federated Unlearning Overview" encompasses a range of research efforts aimed at enabling the removal of specific data contributions from federated learning (FL) models, primarily to comply with the "right to be forgotten" and enhance privacy. These studies highlight the challenges inherent in FL, such as the inability to directly access training data and the need for efficient unlearning mechanisms that avoid full retraining \[[3](https://www.semanticscholar.org/paper/eadeffdec9fac8fd7f9aea732ca410eb082b7dcf)\]. Several approaches have been proposed, including methods that leverage historical parameter updates to reconstruct unlearned models without requiring global data access \[[4](http://arxiv.org/abs/2207.05521)\], and others that use differential privacy to ensure statistical indistinguishability between retrained and unlearned models \[[6](https://www.semanticscholar.org/paper/06edb1f6eadb6c141d720fcca4c854578dc5d670)\]. Additionally, techniques such as reverse stochastic gradient ascent (SGA) and elastic weight consolidation (EWC) have been explored to improve unlearning efficacy and efficiency \[[1](http://arxiv.org/abs/2203.07320)\]. Some works focus on specific unlearning types, such as client unlearning, where the influence of an entire client’s data is removed while maintaining model performance \[[16](http://arxiv.org/abs/2401.11018)\]. Others introduce frameworks like FedEraser, which significantly reduce the time required for unlearning by utilizing stored parameter updates \[[3](https://www.semanticscholar.org/paper/eadeffdec9fac8fd7f9aea732ca410eb082b7dcf)\], and Starfish, which enhances privacy through two-party computation (2PC) techniques \[[21](http://arxiv.org/abs/2404.09724)\]. Furthermore, the importance of evaluating unlearning effectiveness using multiple metrics has been emphasized, as single-metric evaluations often fail to capture the full scope of unlearning success \[[29](http://arxiv.org/abs/2401.05146)\]. These contributions collectively address the growing demand for efficient and privacy-preserving federated unlearning solutions.
