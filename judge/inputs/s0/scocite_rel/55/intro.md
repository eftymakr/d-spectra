## Related Works

Conversational Recommender Systems (CRSs) have emerged as a promising approach to dynamically capture user preferences through multi-turn interactions \[[1](http://arxiv.org/abs/2002.09102)\]. Traditional recommendation systems rely on static models that often fail to adapt to evolving user preferences \[[5](http://arxiv.org/abs/2101.09459)\]. In contrast, CRSs enable systems to ask users about item attributes and provide personalized recommendations in real-time \[[1](http://arxiv.org/abs/2002.09102)\]. However, accurately understanding user preferences from conversations remains a fundamental challenge due to the multifaceted and complex nature of user preferences \[[1](http://arxiv.org/abs/2002.09102)\].

Several approaches have been proposed to address this challenge. The Estimation-Action-Reflection (EAR) framework \[[1](http://arxiv.org/abs/2002.09102)\] introduces a three-stage process to better converse with users: (1) Estimation, which builds predictive models to estimate user preference on both items and item attributes; (2) Action, which learns a dialogue policy to determine whether to ask attributes or recommend items; and (3) Reflection, which updates the recommender model when a user rejects recommendations. This framework has shown significant improvements over state-of-the-art methods \[[1](http://arxiv.org/abs/2002.09102)\].

Another approach, Improving Conversational Recommender Systems via Knowledge Graph based Semantic Fusion \[[2](http://arxiv.org/abs/2007.04032)\], incorporates word-oriented and entity-oriented knowledge graphs (KG) to enhance data representations in CRSs. By aligning word-level and entity-level semantic spaces using Mutual Information Maximization, this approach improves both recommendation and conversation tasks \[[2](http://arxiv.org/abs/2007.04032)\].

Interactive Path Reasoning on Graph for Conversational Recommendation \[[3](http://arxiv.org/abs/2007.00194)\] proposes a framework that models conversational recommendation as an interactive path reasoning problem on a graph. By leveraging the graph structure, this approach prunes irrelevant candidate attributes, leading to better chances of hitting user-preferred attributes \[[3](http://arxiv.org/abs/2007.00194)\]. The proposed method, SCPR, significantly outperforms state-of-the-art CRS methods such as EAR and CRM \[[3](http://arxiv.org/abs/2007.00194)\].

The work in \[[4](http://arxiv.org/abs/2004.00646)\] provides a comprehensive survey of existing approaches to conversational recommendation, categorizing them based on supported user intents and background knowledge. It highlights the importance of natural language processing, voice-controlled assistants, and chatbot technology in advancing conversational recommendation \[[4](http://arxiv.org/abs/2004.00646)\].

Advances and Challenges in Conversational Recommender Systems: A Survey \[[5](http://arxiv.org/abs/2101.09459)\] discusses key challenges in developing CRSs, including question-based user preference elicitation, multi-turn conversational recommendation strategies, dialogue understanding and generation, exploitation-exploration trade-offs, and evaluation and user simulation \[[5](http://arxiv.org/abs/2101.09459)\].
