## Related Works

Semi-supervised learning (SSL) has been extensively studied to improve model performance by leveraging unlabeled data, especially when labeled data is scarce \[[1](https://www.semanticscholar.org/paper/f3df804a7eef204b0c4fc4b81166dec9b4abc073)\]. However, most traditional SSL methods assume that both labeled and unlabeled data share the same class distribution \[[1](https://www.semanticscholar.org/paper/f3df804a7eef204b0c4fc4b81166dec9b4abc073)\]. This assumption is often violated in practice, as unlabeled data may contain out-of-distribution (OOD) samples, or outliers, which are not present in the labeled set \[[2](http://arxiv.org/abs/2007.11330)\]. These outliers can significantly degrade model performance by introducing noise and bias \[[3](http://arxiv.org/abs/2001.07685)\]. To address this challenge, several open-set SSL approaches have been proposed to handle the presence of OOD samples in unlabeled data \[[4](http://arxiv.org/abs/2108.05617)\].

One line of work focuses on detecting and filtering out OOD samples before training \[[5](http://arxiv.org/abs/1905.02249)\]. For example, the Multi-Task Curriculum Framework for Open-Set SSL introduces a joint optimization framework that simultaneously detects OOD samples and trains a classifier on in-distribution (ID) data \[[6](https://www.semanticscholar.org/paper/9e4376e0572de32236e408469ffb2173d89eaab5)\]. This approach uses a probability estimation to identify OOD samples and selects ID samples with small OOD scores for training \[[6](https://www.semanticscholar.org/paper/9e4376e0572de32236e408469ffb2173d89eaab5)\]. Similarly, the Trash to Treasure method leverages all unlabeled data, including OOD samples, during warm-up training and introduces a cross-modal matching strategy to detect OOD samples \[[7](http://arxiv.org/abs/2102.03526)\]. This approach aims to exploit the presence of OOD data for enhanced feature learning while mitigating their adverse impact \[[7](http://arxiv.org/abs/2102.03526)\].

Another approach, such as FixMatch, relies on pseudo-labeling and consistency regularization to improve performance \[[8](http://arxiv.org/abs/2109.00650)\]. However, FixMatch assumes that labeled and unlabeled data share the same label space, which is not always the case in open-set scenarios \[[9](http://arxiv.org/abs/1606.04586)\]. To address this limitation, OpenMatch extends FixMatch with novelty detection using one-vs-all (OVA) classifiers, allowing the model to distinguish between inliers and outliers \[[10](http://arxiv.org/abs/1610.02242)\]. This method introduces an open-set soft-consistency regularization loss to improve outlier detection \[[10](http://arxiv.org/abs/1610.02242)\].

In addition, methods like MixMatch and ReMixMatch have been proposed to improve SSL performance by combining consistency regularization with data augmentation \[[11](http://arxiv.org/abs/2205.07246)\]. These methods aim to reduce the gap between intra-class variance of seen and novel classes \[[12](http://arxiv.org/abs/2105.14148)\]. Furthermore, methods such as CoMatch and SimMatch have been developed to enhance SSL performance by leveraging contrastive learning and similarity matching \[[13](http://arxiv.org/abs/2107.08943)\]. These approaches aim to improve the robustness of models in the presence of OOD data \[[14](http://arxiv.org/abs/1904.12848)\].
