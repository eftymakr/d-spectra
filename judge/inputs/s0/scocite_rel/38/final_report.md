## Related Works

Memory bandwidth regulation and cache partitioning have been widely studied as techniques to achieve predictable timing in real-time computing systems \[[14](http://arxiv.org/abs/1809.05921)\]. These approaches are often combined with partitioned scheduling to ensure that task execution times are tightly bounded by the allocated resources \[[14](http://arxiv.org/abs/1809.05921)\]. However, the co-allocation of tasks and resources to cores remains a complex challenge, as task execution times are highly dependent on the availability of allocated resources \[[14](http://arxiv.org/abs/1809.05921)\].

Several works have explored memory bandwidth management for performance isolation in multi-core platforms. MemGuard is a memory bandwidth reservation system designed to provide efficient performance isolation \[[2](https://www.semanticscholar.org/paper/bbebaeb1b00fdcde2aeb192543835d3ec1518f8d)\]. Similarly, PALLOC introduces a DRAM bank-aware memory allocator to enhance performance isolation on multi-core platforms \[[8](https://www.semanticscholar.org/paper/6e925ae85e385ac0e8810441d84be97c079f6b22)\]. These approaches aim to reduce interference between tasks by limiting their access to shared memory resources. However, they often rely on static resource allocation, which may not be optimal for dynamic workloads \[[14](http://arxiv.org/abs/1809.05921)\].

Cache partitioning has also been proposed as a means to improve predictability in multi-tasking real-time embedded systems \[[12](https://www.semanticscholar.org/paper/43cc4d0a998b9aa361264e5fc786c738a62382f1)\]. By isolating cache resources for different tasks, cache partitioning reduces contention and improves timing predictability. However, such approaches may suffer from suboptimal resource utilization due to the rigid allocation of cache resources \[[12](https://www.semanticscholar.org/paper/43cc4d0a998b9aa361264e5fc786c738a62382f1)\]. A more flexible approach is required to balance performance and resource usage effectively \[[14](http://arxiv.org/abs/1809.05921)\].

Real-time cache management frameworks have been developed to address the challenges of managing shared memory resources in multi-core architectures \[[3](https://www.semanticscholar.org/paper/25ebad66dc10d7b01c22684cbb200ddeb6502475)\]. These frameworks aim to provide fine-grained control over cache behavior to improve predictability and reduce interference. However, they often focus on individual components rather than the holistic management of memory and cache resources \[[3](https://www.semanticscholar.org/paper/25ebad66dc10d7b01c22684cbb200ddeb6502475)\].

In addition to memory bandwidth and cache partitioning, other approaches have been proposed to improve predictability in multi-core systems. For example, E-WarP is a system-wide framework for memory bandwidth profiling and management that enables realistic predictions of workload behavior and saturation-aware system consolidation \[[4](https://www.semanticscholar.org/paper/f71c848137ac1398f84e6ab7d896641f801ca192)\]. This work provides a full implementation on a commercial platform and demonstrates the effectiveness of profile-driven memory analysis \[[4](https://www.semanticscholar.org/paper/f71c848137ac1398f84e6ab7d896641f801ca192)\]. Similarly, RT-Gang introduces a real-time gang scheduling framework that enforces a one-gang-at-a-time policy to minimize worst-case execution time (WCET) and improve system predictability \[[10](http://arxiv.org/abs/1903.00999)\]. This approach integrates memory bandwidth throttling to allow safe execution of best-effort tasks without compromising the performance of real-time tasks \[[10](http://arxiv.org/abs/1903.00999)\].

partitioned scheduling, these methods require careful co-allocation of tasks
and resources to cores, as task execution times strongly depend on available
allocated resources. To address this challenge, this paper presents a 0-1
linear program for task-resource co-allocation, along with a multi-objective
