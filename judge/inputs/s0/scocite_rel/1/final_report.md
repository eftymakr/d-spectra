## Related Works

Efficient memory management and KV cache optimization have been central to improving the performance of large language model (LLM) serving systems. Prior work has focused on reducing memory usage and improving throughput through various techniques, including quantization, cache eviction policies, and compression strategies. 

Several studies have explored the use of quantization to reduce the memory footprint of the KV cache. For instance, KIVI \[[2](http://arxiv.org/abs/2402.02750)\] introduces a tuning-free 2-bit quantization method for the KV cache, achieving up to 2.6× memory reduction while maintaining model quality. Similarly, KVQuant \[[7](http://arxiv.org/abs/2401.18079)\] proposes a comprehensive set of methods to enable accurate low-precision KV cache quantization, including per-channel key quantization and non-uniform datatypes, achieving less than 0.1 perplexity degradation with 3-bit quantization. These approaches demonstrate that quantization can significantly reduce memory usage without sacrificing performance. 

Cache eviction policies have also been a focus of prior research. H2O \[[6](http://arxiv.org/abs/2306.14048)\] introduces a dynamic eviction policy based on the observation that a small subset of tokens, called Heavy Hitters, contribute most to attention scores. By retaining both recent and Heavy Hitter tokens, H2O achieves up to 29× throughput improvements over existing systems. Similarly, GEAR \[[13](http://arxiv.org/abs/2403.05527)\] proposes an efficient KV cache compression framework that combines quantization and low-rank matrix approximation to achieve near-lossless 4-bit compression with up to 2.38× throughput improvement. These methods highlight the importance of balancing memory efficiency with generation quality during cache management.

The importance of KV cache reuse has also been studied. Scissorhands \[[3](http://arxiv.org/abs/2305.17118)\] hypothesizes the persistence of importance, where only pivotal tokens significantly influence future generations. By prioritizing the storage of these tokens, Scissorhands reduces memory usage by up to 5× without compromising model quality. This aligns with the findings of Quest \[[11](http://arxiv.org/abs/2406.10774)\], which introduces a query-aware KV cache selection algorithm that identifies and loads only the most critical KV cache pages based on query vectors, achieving up to 2.23× self-attention speedup. These approaches emphasize the need for adaptive and context-aware strategies in managing the KV cache.

### <a id='category-quantization-techniques-for-kv-cache-optimization'></a>Quantization Techniques for KV Cache Optimization: 4 papers found.
Efficient KV cache quantization is a critical area of research aimed at reducing memory usage and improving inference throughput for large language models (LLMs). Several studies have explored quantization techniques to address the memory bottlenecks caused by the growing size of the KV cache. For instance, \[[2](http://arxiv.org/abs/2402.02750)\] highlights that quantization can significantly reduce the memory footprint of the KV cache, with a proposed method named KIVI achieving up to 2.6× memory reduction by quantizing the key cache per-channel and the value cache per-token. Similarly, \[[7](http://arxiv.org/abs/2401.18079)\] introduces KVQuant, which incorporates advanced quantization strategies such as per-channel key quantization and non-uniform datatypes to achieve sub-4-bit precision without significant accuracy loss. Additionally, \[[12](http://arxiv.org/abs/2402.12065)\] proposes WKVQuant, a PTQ framework that combines past-only quantization and a two-dimensional quantization strategy to enhance both memory savings and model performance. These approaches collectively demonstrate the potential of quantization to enable more efficient LLM serving, though challenges remain in balancing compression with generation quality \[[4](http://arxiv.org/abs/2402.18096)\].

### <a id='category-kv-cache-reuse-patterns-and-importance'></a>KV Cache Reuse Patterns and Importance: 1 papers found.
Context: 
	Document 1: [Snippet]: «Large language models(LLMs) have sparked a new wave of exciting AI applications. Hosting these models at scale requires significant memory resources. One crucial memory bottleneck for the deployment stems from the context window. It is commonly recognized that model weights are memory hungry; however, the size of key-value embedding stored during the generation process (KV cache) can easily surpass the model size. The enormous size of the KV cache puts constraints on the inference batch size, which is crucial for high throughput inference workload. Inspired by an interesting observation of the attention scores, we hypothesize the persistence of importance: only pivotal tokens, which had a substantial influence at one step, will significantly influence future generations. Based on our empirical verification and theoretical analysis around this hypothesis, we propose Scissorhands, a system that maintains the memory usage of the KV cache at a fixed budget without finetuning the model. In essence, Scissorhands manages the KV cache by storing the pivotal tokens with a higher probability. We validate that Scissorhands reduces the inference memory usage of the KV cache by up to 5X without compromising model quality. We further demonstrate that Scissorhands can be combined with 4-bit quantization, traditionally used to compress model weights, to achieve up to 20X compression.»

### <a id='category-query-aware-kv-cache-selection'></a>Query-Aware KV Cache Selection: 1 papers found.
Context: 
	Document 1: [Snippet]: «As the demand for long-context large language models (LLMs) increases, models with context windows of up to 128K or 1M tokens are becoming increasingly prevalent. However, long-context LLM inference is challenging since the inference speed decreases significantly as the sequence length grows. This slowdown is primarily caused by loading a large KV cache during self-attention. Previous works have shown that a small portion of critical tokens will dominate the attention outcomes. However, we observe the criticality of a token highly depends on the query. To this end, we propose Quest, a query-aware KV cache selection algorithm. Quest keeps track of the minimal and maximal Key values in KV cache pages and estimates the criticality of a given page using Query vectors. By only loading the Top-K critical KV cache pages for attention, Quest significantly speeds up self-attention without sacrificing accuracy. We show that Quest can achieve up to 2.23x self-attention speedup, which reduces inference latency by 7.03x while performing well on tasks with long dependencies with negligible accuracy loss. Code is available at http://github.com/mit-han-lab/Quest .»
