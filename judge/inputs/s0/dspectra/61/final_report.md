## Related Works

Personalized outfit generation has garnered significant attention in recent years, driven by the increasing demand for fashion recommendation systems that can produce both compatible and personalized fashion items \[[1](http://arxiv.org/abs/2305.18290)\]. Early approaches focused on item-item compatibility, often using rule-based systems or simple similarity metrics \[[2](http://arxiv.org/abs/1905.01866)\]. However, these methods lacked the ability to capture complex user preferences and generate diverse outfit combinations \[[3](http://arxiv.org/abs/1608.03016)\].

Recent advances in deep learning have enabled more sophisticated approaches to outfit generation and recommendation. For example, \[[4](https://www.semanticscholar.org/paper/ca3ad34ff2652cd922c3476514a758674bc7e76b)\] introduced a system that uses deep convolutional networks to extract features from fashion items and a matching network to compute compatibility between items. This approach was further refined in \[[5](http://arxiv.org/abs/1810.02443)\], where a two-stage training strategy was proposed to transfer a general compatibility model to a personalized one. These methods, while effective, often rely on supervised learning paradigms and may lack the flexibility needed to handle diverse user preferences \[[6](http://arxiv.org/abs/1904.00741)\].

To address the limitations of supervised learning, several works have explored unsupervised and self-supervised methods. \[[7](http://arxiv.org/abs/1712.02662)\] proposed a system that learns a style-coherent embedding from fashion images, enabling the retrieval of stylistically similar outfits without explicit labels. Similarly, \[[8](http://arxiv.org/abs/1710.07346)\] introduced a method that uses probabilistic topic models to discover latent style factors, allowing for the organization of outfits by style without requiring manual annotations \[[9](https://www.semanticscholar.org/paper/0157c94e753958610c732d3cbf753d9f640dee7c)\].

In the realm of personalized outfit generation, \[[10](https://www.semanticscholar.org/paper/255f90cd765d90e602cd35ab7e22c3a8db1acefa)\] presented a framework that combines item-item compatibility with user-specific preferences, using a generative adversarial network (GAN) to synthesize new fashion items. This approach was further enhanced in \[[11](http://arxiv.org/abs/1906.07273)\], where a personalized fashion design framework was proposed that jointly considers compatibility and personalization using generative adversarial training \[[12](http://arxiv.org/abs/1806.08977)\]. The model maps a query image into a latent vector and combines it with a user-specific style vector to generate new items \[[13](http://arxiv.org/abs/1807.03133)\].

Another notable work is \[[14](https://www.semanticscholar.org/paper/b1db62044adca574e4cf88b23c170f3cc089d513)\], which introduced a system that learns outfit representations using a self-attention mechanism, enabling the prediction of outfit compatibility and the retrieval of complementary items. This approach was further extended in \[[15](http://arxiv.org/abs/1804.09979)\], where a framework called OutfitTransformer was proposed, leveraging self-attention to model the relationships between items in an outfit \[[16](http://arxiv.org/abs/1205.2618)\].
