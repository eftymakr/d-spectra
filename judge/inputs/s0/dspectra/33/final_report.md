## Related Works

Rehearsal-based methods have been widely studied in continual learning (CL) to mitigate catastrophic forgetting. These methods store a subset of past data in a buffer and use it during training alongside new data, enabling the model to retain knowledge from previous tasks \[[1](http://arxiv.org/abs/2302.05836)\]. Early works such as \[[2](http://arxiv.org/abs/1805.12369)\] introduced the concept of using a rehearsal buffer to prevent forgetting, while \[[3](http://arxiv.org/abs/2104.07446)\] explored the effectiveness of memory replay in deep neural networks. The importance of rehearsal in CL has been further emphasized by \[[4](http://arxiv.org/abs/2203.17269)\], which showed that rehearsal helps maintain performance on previously learned tasks. However, the optimal design of rehearsal strategies remains an open question.

Several studies have investigated the effectiveness of different rehearsal strategies. For instance, \[[5](http://arxiv.org/abs/2307.02251)\] proposed a method that leverages a small episodic memory to improve generalization, while \[[6](http://arxiv.org/abs/1807.09536)\] demonstrated that a simple joint training approach on current and stored data outperforms state-of-the-art methods. The role of task similarity in rehearsal effectiveness was also explored in \[[7](http://arxiv.org/abs/2112.08654)\], where it was shown that rehearsal is more beneficial when tasks are dissimilar. This aligns with our findings that sequential rehearsal performs better when tasks are less similar \[[8](http://arxiv.org/abs/2003.09553)\].

The theoretical analysis of rehearsal strategies has been limited, but recent work has begun to address this gap. \[[9](http://arxiv.org/abs/1902.10486)\] provided a theoretical analysis of rehearsal-based CL in overparameterized linear models, showing that the expected forgetting and generalization error can be explicitly characterized. This work laid the foundation for our theoretical analysis comparing concurrent and sequential rehearsal strategies. Our analysis builds on this by extending the theoretical framework to more complex models and scenarios \[[10](http://arxiv.org/abs/2211.13218)\].

In practice, rehearsal-based methods face challenges related to memory usage and data privacy \[[11](http://arxiv.org/abs/1710.10368)\]. To address these limitations, several approaches have been proposed. For example, \[[12](http://arxiv.org/abs/1810.10612)\] introduced a method that uses a pseudo-rehearsal system to "recall" previous tasks without storing raw data, while \[[13](http://arxiv.org/abs/2103.07492)\] proposed a selective experience replay strategy that improves performance by focusing on the most informative experiences. These methods highlight the trade-offs between memory efficiency and performance in rehearsal-based CL.

Recent work has also explored hybrid approaches that combine different rehearsal strategies. For instance, \[[14](http://arxiv.org/abs/1906.00695)\] proposed a method that uses a dual memory system to separate task-specific and shared knowledge, while \[[15](http://arxiv.org/abs/2308.13646)\] introduced a framework that combines generative replay with distillation to improve performance. The category "Catastrophic forgetting mitigation strategies" encompasses a variety of approaches aimed at preventing the degradation of model performance when learning new tasks sequentially. These strategies include reinforcement learning-based continual learning \[[2](http://arxiv.org/abs/1805.12369)\], where models adaptively search for optimal neural architectures to minimize forgetting. Another approach involves pre-trained models with random projectors and class-prototype accumulation \[[5](http://arxiv.org/abs/2307.02251)\], which bypass the need for rehearsal memory by leveraging frozen layers and nonlinear activation. Additionally, methods such as incremental training with distillation loss \[[6](http://arxiv.org/abs/1807.09536)\] and dynamic prompting \[[7](http://arxiv.org/abs/2112.08654)\] have been proposed to retain knowledge from past tasks while learning new ones. The use of generative replay and dual memory systems \[[11](http://arxiv.org/abs/1710.10368)\] further mimics human memory mechanisms to improve long-term retention. Task-conditioned hypernetworks \[[14](http://arxiv.org/abs/1906.00695)\] offer another solution by generating task-specific weights, enabling efficient memory retention. Experience replay strategies, such as distribution matching \[[18](http://arxiv.org/abs/1802.10269)\], have also been explored to selectively store experiences and prevent forgetting. These methods collectively highlight the ongoing efforts to address catastrophic forgetting through diverse techniques, ranging from architectural innovations to memory-based strategies.

### <a id='category-rehearsal-based-methods-in-continual-learning'></a>Rehearsal-based methods in continual learning: 5 papers found.
Rehearsal-based methods in continual learning (CL) have been extensively studied to address catastrophic forgetting, where models lose previously learned knowledge when trained on new tasks \[[3](http://arxiv.org/abs/2104.07446)\]. These methods typically involve storing past data in a buffer and reusing it during training to maintain knowledge retention \[[9](http://arxiv.org/abs/1902.10486)\]. However, the effectiveness of rehearsal strategies varies depending on task similarity and data distribution. For instance, uniform sampling in a class-balanced manner has been shown to be highly effective, yet more sophisticated sample selection policies, such as GRASP, which prioritize prototypical samples first, have demonstrated improved performance by reducing the number of required updates while maintaining accuracy \[[15](http://arxiv.org/abs/2308.13646)\]. Additionally, the use of episodic memory with joint training on current and past data has been found to act as a regularizer, enhancing generalization without harming performance on prior tasks \[[9](http://arxiv.org/abs/1902.10486)\]. Furthermore, Bayesian approaches, such as Posterior-replay CL, have been proposed to enable flexible modeling of task-specific posteriors, allowing for principled updates without access to past data \[[17](http://arxiv.org/abs/2103.01133)\]. These findings highlight the ongoing efforts to refine rehearsal strategies, balancing efficiency with effectiveness in CL settings.

To address these issues, researchers have proposed novel attention-based schemes that allow for end-to-end learning of prompt components, improving performance on both class-incremental and domain-incremental task shifts \[[10](http://arxiv.org/abs/2211.13218)\]. Furthermore, methods like DualPrompt have been introduced to learn a small set of parameters that guide the model through sequential task learning without the need for a buffer \[[26](http://arxiv.org/abs/2204.04799)\].
