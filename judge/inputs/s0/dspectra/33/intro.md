## Related Works

Rehearsal-based methods have been widely studied in continual learning (CL) to mitigate catastrophic forgetting. These methods store a subset of past data in a buffer and use it during training alongside new data, enabling the model to retain knowledge from previous tasks \[[1](http://arxiv.org/abs/2302.05836)\]. Early works such as \[[2](http://arxiv.org/abs/1805.12369)\] introduced the concept of using a rehearsal buffer to prevent forgetting, while \[[3](http://arxiv.org/abs/2104.07446)\] explored the effectiveness of memory replay in deep neural networks. The importance of rehearsal in CL has been further emphasized by \[[4](http://arxiv.org/abs/2203.17269)\], which showed that rehearsal helps maintain performance on previously learned tasks. However, the optimal design of rehearsal strategies remains an open question.

Several studies have investigated the effectiveness of different rehearsal strategies. For instance, \[[5](http://arxiv.org/abs/2307.02251)\] proposed a method that leverages a small episodic memory to improve generalization, while \[[6](http://arxiv.org/abs/1807.09536)\] demonstrated that a simple joint training approach on current and stored data outperforms state-of-the-art methods. The role of task similarity in rehearsal effectiveness was also explored in \[[7](http://arxiv.org/abs/2112.08654)\], where it was shown that rehearsal is more beneficial when tasks are dissimilar. This aligns with our findings that sequential rehearsal performs better when tasks are less similar \[[8](http://arxiv.org/abs/2003.09553)\].

The theoretical analysis of rehearsal strategies has been limited, but recent work has begun to address this gap. \[[9](http://arxiv.org/abs/1902.10486)\] provided a theoretical analysis of rehearsal-based CL in overparameterized linear models, showing that the expected forgetting and generalization error can be explicitly characterized. This work laid the foundation for our theoretical analysis comparing concurrent and sequential rehearsal strategies. Our analysis builds on this by extending the theoretical framework to more complex models and scenarios \[[10](http://arxiv.org/abs/2211.13218)\].

In practice, rehearsal-based methods face challenges related to memory usage and data privacy \[[11](http://arxiv.org/abs/1710.10368)\]. To address these limitations, several approaches have been proposed. For example, \[[12](http://arxiv.org/abs/1810.10612)\] introduced a method that uses a pseudo-rehearsal system to "recall" previous tasks without storing raw data, while \[[13](http://arxiv.org/abs/2103.07492)\] proposed a selective experience replay strategy that improves performance by focusing on the most informative experiences. These methods highlight the trade-offs between memory efficiency and performance in rehearsal-based CL.

Recent work has also explored hybrid approaches that combine different rehearsal strategies. For instance, \[[14](http://arxiv.org/abs/1906.00695)\] proposed a method that uses a dual memory system to separate task-specific and shared knowledge, while \[[15](http://arxiv.org/abs/2308.13646)\] introduced a framework that combines generative replay with distillation to improve performance. These approaches demonstrate the potential of combining different strategies to achieve better results in CL.
