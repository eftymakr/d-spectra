This has led to their adoption in blockchain technologies, verifiable machine learning, and secure voting systems \[[6](https://www.semanticscholar.org/paper/65f1e83a53c5ce9dee04042e0dd4191a451df2b8)\]. However, the computational complexity of the proving process has hindered widespread adoption \[[1](http://arxiv.org/abs/2408.05890)\]. Recent efforts have focused on accelerating the key primitives of ZKP protocols using hardware accelerators, particularly GPUs and ASICs \[[1](http://arxiv.org/abs/2408.05890)\]. For instance, GZKP presents a GPU-accelerated zero-knowledge proof system that significantly improves performance by optimizing memory access patterns and parallelizing operations such as multi-scalar multiplication \[[3](https://www.semanticscholar.org/paper/e149d93531d8c07cf43f6cae327a4795144d1304)\]. Similarly, cuZK introduces a faster parallel multi-scalar multiplication algorithm on GPUs, achieving nearly linear speedup over existing methods \[[5](https://www.semanticscholar.org/paper/e4a4608e8e35379e63b9df5bda1b7599ee8ab9ac)\]. 

Despite these advancements, existing accelerators often face limitations. Some require a trusted setup for each application, which restricts their use in dynamic environments \[[1](http://arxiv.org/abs/2408.05890)\]. Others generate larger proof sizes or incur higher verification costs, limiting their applicability in scenarios with numerous verifiers or strict time constraints \[[1](http://arxiv.org/abs/2408.05890)\].
