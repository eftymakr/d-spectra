## Related Works

Conversational recommendation systems (CRSs) have gained significant attention in recent years due to their ability to dynamically capture user preferences through multi-turn interactions \[[1](https://www.semanticscholar.org/paper/3ae5bef6b0c8317603a2deab2527383580904fd8)\]. Traditional recommendation systems often rely on static models that estimate user preferences based on past behavior, limiting their ability to adapt to evolving user needs \[[4](http://arxiv.org/abs/2101.09459)\]. In contrast, CRSs enable more nuanced preference elicitation by engaging users in natural language dialogues, allowing the system to ask clarifying questions and refine recommendations iteratively \[[1](https://www.semanticscholar.org/paper/3ae5bef6b0c8317603a2deab2527383580904fd8)\]. This interactive approach has been shown to improve recommendation accuracy and user satisfaction \[[1](https://www.semanticscholar.org/paper/3ae5bef6b0c8317603a2deab2527383580904fd8)\].

Several studies have explored the challenges of modeling user preferences in conversational settings. For instance, \[[4](http://arxiv.org/abs/2101.09459)\] highlights the limitations of static models in accurately capturing what users like and why, emphasizing the need for dynamic interaction. To address this, \[[1](https://www.semanticscholar.org/paper/3ae5bef6b0c8317603a2deab2527383580904fd8)\] proposes a System Ask -- User Respond (SAUR) paradigm, where the system actively asks questions to clarify user needs, leading to more accurate recommendations. Similarly, \[[3](http://arxiv.org/abs/2002.09102)\] introduces the Estimation-Action-Reflection (EAR) framework, which divides the conversational process into three stages: estimating user preferences, deciding whether to ask or recommend, and reflecting on user feedback to improve future interactions.

The integration of conversational and recommendation components remains a key challenge in CRS development. \[[8](http://arxiv.org/abs/2105.09710)\] proposes a unified policy learning approach using graph-based reinforcement learning to simultaneously decide what to ask and what to recommend, enhancing the scalability and stability of conversational recommendation systems. Additionally, \[[14](http://arxiv.org/abs/2206.09363)\] introduces a knowledge-enhanced prompt learning approach to unify recommendation and conversation subtasks, improving the integration of these components within a single model.

To enhance the quality of interactions, \[[11](http://arxiv.org/abs/2304.13874)\] develops a user simulator, ConvSim, that generates realistic user feedback, enabling the evaluation of CRS performance in multi-turn settings. This aligns with the proposed GRSU (Generative Reward Simulated User) in the current work, which also utilizes simulated user feedback to improve recommendation accuracy. \[[13](http://arxiv.org/abs/2006.08732)\] further explores automated evaluation of conversational systems through user simulation, showing that preference modeling and interaction flow significantly impact the realism of simulated user behavior.

This approach improves the fine-grained utilization of feedback information, which is crucial for accurate recommendation in multi-round conversational settings. ### <a id='category-conversational-recommendation-systems-overview'></a>Conversational Recommendation Systems Overview: 7 papers found.
Conversational recommender systems (CRSs) have gained significant attention due to their ability to capture user preferences through multi-turn interactions, offering a more dynamic and personalized recommendation experience compared to traditional one-shot systems \[[1](https://www.semanticscholar.org/paper/3ae5bef6b0c8317603a2deab2527383580904fd8)\]. Unlike static models that rely solely on past behavior \[[2](http://arxiv.org/abs/2004.00646)\], CRSs enable users to ask questions, provide feedback, and engage in dialogue, which enhances the accuracy of preference elicitation \[[3](http://arxiv.org/abs/2002.09102)\]. This interactive approach allows for more nuanced understanding of user intent, as it incorporates explicit feedback and contextual information during the conversation \[[4](http://arxiv.org/abs/2101.09459)\]. However, developing effective CRSs remains challenging due to issues such as insufficient contextual information in conversation data \[[5](http://arxiv.org/abs/2007.00194)\], semantic gaps between natural language and item-level preferences \[[6](http://arxiv.org/abs/2007.04032)\], and the need for seamless integration between recommendation and dialogue modules \[[7](https://www.semanticscholar.org/paper/0056038b89647afcee84226adf19feb1023a54c0)\]. To address these challenges, researchers have explored various strategies, including the use of knowledge graphs to enhance semantic alignment \[[8](http://arxiv.org/abs/2105.09710)\], the development of unified frameworks that combine dialogue and recommendation \[[9](https://www.semanticscholar.org/paper/49846c2d069c324d5d3f3b53cb74b13e84b7caeb)\], and the creation of high-quality datasets that support proactive guidance in recommendation scenarios \[[10](http://arxiv.org/abs/1806.03277)\]. Additionally, the integration of deep reinforcement learning has been proposed to optimize per-session utility functions while considering both short-term and long-term user preferences \[[11](http://arxiv.org/abs/2304.13874)\]. These advancements highlight the growing interest in CRSs and the ongoing efforts to improve their effectiveness, efficiency, and user experience.

	Document 1: [Snippet]: «Traditional recommendation systems estimate user preference on items from past interaction history, thus suffering from the limitations of obtaining fine-grained and dynamic user preference. Conversational recommendation system (CRS) brings revolutions to those limitations by enabling the system to directly ask users about their preferred attributes on items. However, existing CRS methods do not make full use of such advantage --- they only use the attribute feedback in rather implicit ways such as updating the latent user representation. In this paper, we propose Conversational Path Reasoning (CPR), a generic framework that models conversational recommendation as an interactive path reasoning problem on a graph. It walks through the attribute vertices by following user feedback, utilizing the user preferred attributes in an explicit way. By leveraging on the graph structure, CPR is able to prune off many irrelevant candidate attributes, leading to a better chance of hitting user-preferred attributes. To demonstrate how CPR works, we propose a simple yet effective instantiation named SCPR (Simple CPR). We perform empirical studies on the multi-round conversational recommendation scenario, the most realistic CRS setting so far that considers multiple rounds of asking attributes and recommending items. Through extensive experiments on two datasets Yelp and LastFM, we validate the effectiveness of our SCPR, which significantly outperforms the state-of-the-art CRS methods EAR and CRM. In particular, we find that the more attributes there are, the more advantages our method can achieve.»

	Document 1: [Snippet]: «Conversational recommender systems (CRS) enable traditional recommender systems to interact with users by asking questions about attributes and recommending items. However, existing works do not fully exploit the advantage of explicit item feedback --- they only use the item feedback in rather implicit ways such as updating the latent user and item representation. Since CRS has multiple chances to interact with users, leveraging the context in the conversation may help infer users' implicit feedback (e.g., some specific attributes) when recommendations get rejected. Therefore, CRIF is able to achieve more accurate user preference estimation. Besides, in the decision module, to better utilize the attribute-level and item-level feedback, we adopt inverse reinforcement learning to learn a flexible decision strategy that selects the suitable action at each conversation turn. Through extensive experiments on four benchmark CRS datasets, we validate the effectiveness of our approach, which significantly outperforms the state-of-the-art CRS methods.»
