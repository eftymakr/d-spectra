## Related Works

KV cache management has emerged as a critical area of research for improving the efficiency of large language model (LLM) serving systems. Prior work has focused on reducing the memory footprint and computational overhead of KV caches, which are essential for enabling long-context inference. Several approaches have been proposed to address these challenges, including compression techniques, eviction policies, and adaptive reuse strategies.

Early efforts in KV cache compression focused on quantization and sparsity, aiming to reduce the memory usage of the cache while preserving generation quality. For instance, KIVI introduces a tuning-free 2bit quantization method that quantizes key caches per-channel and value caches per-token, achieving a 2.6× reduction in peak memory usage without significant performance degradation \[[7](http://arxiv.org/abs/2402.02750)\]. Similarly, MiniCache compresses the KV cache across layers by exploiting the high similarity between adjacent layers, achieving up to 5.02x compression ratios and improving inference throughput by approximately 5x \[[4](http://arxiv.org/abs/2405.14366)\]. These methods demonstrate the potential of compression to reduce memory demands, but they often require careful tuning or are limited in their applicability to specific model architectures.

In addition to compression, researchers have explored KV cache eviction strategies to manage memory constraints during inference. CAKE introduces a cascading and adaptive eviction policy that considers layer-specific attention patterns and temporal dynamics, enabling efficient resource allocation across layers \[[13](http://arxiv.org/abs/2503.12491)\]. This approach improves cache utilization by dynamically adjusting the cache size based on the importance of tokens over time. Similarly, KVMerger proposes an adaptive merging strategy that leverages the high similarity of key states within a sequence to reduce the cache size without significant performance loss \[[9](http://arxiv.org/abs/2407.08454)\]. These methods highlight the importance of adaptive and context-aware strategies in managing the KV cache effectively.

Another line of research focuses on the integration of KV cache compression with other optimization techniques, such as prompt compression and sparse attention. For example, VL-Cache extends KV cache compression to vision-language models (VLMs) by introducing sparsity-aware budget allocation and modality-aware token scoring, achieving a 90% reduction in memory footprint while maintaining high accuracy \[[5](http://arxiv.org/abs/2410.23317)\]. These methods demonstrate the versatility of KV cache management techniques across different model types and tasks.

Furthermore, recent studies have emphasized the need for comprehensive benchmarking of KV cache management strategies. SCBench provides a detailed analysis of long-context methods from a KV cache-centric perspective, evaluating techniques such as sparse attention, quantization, and retrieval \[[12](http://arxiv.org/abs/2412.10319)\]. This benchmarking framework helps identify the strengths and limitations of various approaches, guiding future research and development.

### <a id='category-kv-cache-compression-techniques'></a>KV Cache Compression Techniques: 6 papers found.
Key-value (KV) caching is a critical technique for improving the inference speed and throughput of large language models (LLMs) by storing attention keys and values to avoid redundant computations \[[11](http://arxiv.org/abs/2402.18096)\]. However, the memory footprint of the KV cache grows with sequence length and batch size, becoming a significant bottleneck in LLM deployment \[[7](http://arxiv.org/abs/2402.02750)\]. To address this, various compression techniques have been proposed. For instance, CacheGen leverages the distributional properties of the KV cache to encode it into compact bitstream representations, reducing the cache size by 3.5–4.3x and the total delay in fetching and processing contexts by 3.2–3.7x \[[1](http://arxiv.org/abs/2310.07240)\]. Similarly, MiniCache compresses the KV cache across layers by exploiting the high similarity between adjacent layers, achieving a compression ratio of up to 5.02x and reducing memory footprint by 41% \[[4](http://arxiv.org/abs/2405.14366)\]. VL-Cache extends these ideas to Vision-Language Models (VLMs), introducing a layer-adaptive sparsity-aware cache budget allocation method and a modality-aware token scoring policy, achieving a 90% reduction in GPU memory usage while maintaining accuracy \[[5](http://arxiv.org/abs/2410.23317)\]. KIVI further optimizes KV cache quantization by quantizing the key cache per-channel and the value cache per-token, enabling a 2.6x reduction in peak memory usage and up to 4x larger batch sizes \[[7](http://arxiv.org/abs/2402.02750)\]. KVMerger focuses on adaptive KV cache compression for long-context tasks by merging similar key states within a sequence, achieving superior performance under constrained memory budgets \[[9](http://arxiv.org/abs/2407.08454)\]. These methods collectively highlight the importance of workload-aware and adaptive strategies in KV cache management to balance memory efficiency and generation quality \[[11](http://arxiv.org/abs/2402.18096)\].

### <a id='category-benchmarking-and-evaluation-frameworks'></a>Benchmarking and Evaluation Frameworks: 2 papers found.
The category "Benchmarking and Evaluation Frameworks" focuses on the development and evaluation of methods to improve the efficiency and performance of long-context large language models (LLMs). Existing research highlights the challenges of handling long context inputs, such as the exponential growth of the KV cache and the computational complexity of attending to extended sequences \[[12](http://arxiv.org/abs/2412.10319)\]. To address these challenges, various efficiency-driven approaches have been proposed, including KV cache quantization, token dropping, prompt compression, and hybrid architectures that combine linear-time sequence models with attention mechanisms \[[2](http://arxiv.org/abs/2407.01527)\]. However, there is a lack of comprehensive benchmarking that evaluates these methods across a wide range of long-context tasks \[[2](http://arxiv.org/abs/2407.01527)\]. Recent work has introduced frameworks like SCBench, which provides a more realistic evaluation of long-context methods by focusing on the full lifecycle of the KV cache, including generation, compression, retrieval, and loading \[[12](http://arxiv.org/abs/2412.10319)\]. This benchmark covers multiple task categories, such as string retrieval, semantic retrieval, global information, and multi-task scenarios, and evaluates a variety of approaches, including sparse attention, efficient KV cache dropping, and hybrid architectures \[[12](http://arxiv.org/abs/2412.10319)\]. These frameworks aim to provide a more aligned and practical assessment of long-context capabilities, revealing previously unknown phenomena and guiding future development \[[2](http://arxiv.org/abs/2407.01527)\].

### <a id='category-real-world-deployment-and-scalability-considerations'></a>Real-World Deployment and Scalability Considerations: 3 papers found.
Real-World Deployment and Scalability Considerations highlight the critical role of Key-Value (KV) cache management in optimizing Large Language Models (LLMs) for practical applications \[[3](http://arxiv.org/abs/2412.19442)\]. Efficient KV cache strategies are essential for reducing computational redundancy and improving memory utilization during inference, especially in long-context and real-time scenarios \[[3](http://arxiv.org/abs/2412.19442)\]. Techniques such as token-level optimizations, including KV cache selection, merging, and quantization, along with model-level innovations like attention mechanism enhancements, contribute to better performance \[[3](http://arxiv.org/abs/2412.19442)\]. System-level approaches further address memory management and hardware compatibility, ensuring scalability across diverse environments \[[3](http://arxiv.org/abs/2412.19442)\]. Recent work, such as KVLink, demonstrates how precomputing and reusing KV caches across queries can significantly reduce inference time and improve accuracy by leveraging shared context \[[6](http://arxiv.org/abs/2502.16002)\]. Additionally, KV cache compression methods aim to minimize memory usage, though challenges remain in balancing efficiency with accuracy and throughput \[[10](http://arxiv.org/abs/2503.24000)\]. These strategies are vital for deploying LLMs in production, where workload-specific cache eviction policies and efficient resource management are crucial for maintaining performance under real-world conditions \[[3](http://arxiv.org/abs/2412.19442)\].

Serving LLM inference for generating long contents, however, poses a challenge due to the enormous memory footprint of the transient state, known as the key-value (KV) cache, which scales with the sequence length and batch size. In this paper, we present InfiniGen, a novel KV cache management framework tailored for long-text generation, which synergistically works with modern offloading-based inference systems.
