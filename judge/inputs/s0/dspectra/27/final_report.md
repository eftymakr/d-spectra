## Related Works

Recent advancements in information retrieval have focused on improving the efficiency and effectiveness of document and table retrieval systems. Traditional approaches rely on a pipeline consisting of representation, indexing, and search stages, where each stage is typically handled by separate components \[[3](http://arxiv.org/abs/1810.04805)\]. This approach, while effective, suffers from error accumulation during the indexing and search phases, which can degrade retrieval accuracy \[[1](http://arxiv.org/abs/2206.10128)\]. Additionally, insufficient interaction between queries and tables hinders semantic alignment, limiting performance improvements \[[1](http://arxiv.org/abs/2206.10128)\]. 

To address these limitations, differentiable search index (DSI) models have emerged as a promising alternative. DSI unifies indexing and retrieval into a single model, eliminating the need for separate components and reducing error accumulation \[[5](http://arxiv.org/abs/2202.06991)\]. This paradigm has been applied to various retrieval tasks, including passage retrieval \[[5](http://arxiv.org/abs/2202.06991)\], table retrieval \[[14](http://arxiv.org/abs/1802.06159)\], and document retrieval \[[15](http://arxiv.org/abs/2307.10323)\]. DSI models encode all necessary information about the corpus directly into the model parameters, allowing queries to be answered directly using only the model's parameters \[[5](http://arxiv.org/abs/2202.06991)\]. 

However, DSI models face challenges in handling dynamic updates and continual indexing. Re-training the model from scratch when new documents are added is computationally expensive and impractical for real-time applications \[[15](http://arxiv.org/abs/2307.10323)\]. To mitigate this, DSI++ was introduced, which enables incremental indexing of new documents while maintaining retrieval performance \[[10](http://arxiv.org/abs/2212.09744)\]. This approach uses continual learning techniques to update the model without retraining on the entire dataset, significantly reducing computational overhead \[[10](http://arxiv.org/abs/2212.09744)\]. 

Another related approach is the Neural Corpus Indexer (NCI), which also aims to unify indexing and retrieval within a single model. NCI uses a sequence-to-sequence architecture to generate relevant document identifiers directly for a given query \[[7](http://arxiv.org/abs/2206.02743)\]. To improve recall performance, NCI incorporates techniques such as query generation, semantic document identifiers, and consistency-based regularization \[[7](http://arxiv.org/abs/2206.02743)\]. These methods have shown significant improvements over traditional retrieval systems \[[7](http://arxiv.org/abs/2206.02743)\]. 

In addition to DSI-based approaches, other models have explored the use of contextualized language models for retrieval tasks. ColBERT, for example, leverages BERT for efficient retrieval by introducing a late interaction architecture that independently encodes queries and documents \[[9](http://arxiv.org/abs/2004.12832)\]. This approach allows for faster query processing and the use of vector-similarity indexes for end-to-end retrieval \[[9](http://arxiv.org/abs/2004.12832)\]. Similarly, DistilBERT, a distilled version of BERT, has been used for efficient language understanding tasks, offering a smaller, faster, and more lightweight alternative \[[11](http://arxiv.org/abs/1910.01108)\].

### <a id='category-differentiable-search-index-models'></a>Differentiable Search Index Models: 5 papers found.
Differentiable Search Index (DSI) models represent a novel paradigm in information retrieval, where a single transformer model is used for both indexing and retrieval, eliminating the need for separate components \[[1](http://arxiv.org/abs/2206.10128)\]. This approach allows for direct mapping of queries to document identifiers, simplifying the retrieval process \[[5](http://arxiv.org/abs/2202.06991)\]. However, current DSI models face challenges such as data distribution mismatches between indexing and retrieval, where indexed documents are often longer than the queries used during retrieval \[[1](http://arxiv.org/abs/2206.10128)\]. Additionally, DSI models struggle with distinguishing relevant documents from irrelevant ones, impacting retrieval effectiveness \[[2](http://arxiv.org/abs/2305.02073)\]. To address these issues, researchers have proposed enhancements such as DSI-QG, which generates relevant queries during indexing to improve alignment between queries and documents \[[1](http://arxiv.org/abs/2206.10128)\], and a multi-task distillation approach to enhance retrieval quality without altering the model structure \[[2](http://arxiv.org/abs/2305.02073)\]. Furthermore, the Semantic-Enhanced DSI (SE-DSI) model improves document memorization by incorporating elaborative descriptions and semantic features inspired by cognitive psychology \[[3](http://arxiv.org/abs/1810.04805)\]. These advancements highlight the ongoing efforts to refine DSI models for better performance in both mono-lingual and cross-lingual retrieval tasks \[[1](http://arxiv.org/abs/2206.10128)\]\[[3](http://arxiv.org/abs/1810.04805)\].

	Document 1: [Snippet]: «Differentiable Search Indices (DSIs) encode a corpus of documents in model parameters and use the same model to answer user queries directly. Despite the strong performance of DSI models, deploying them in situations where the corpus changes over time is computationally expensive because reindexing the corpus requires re-training the model. In this work, we introduce DSI++, a continual learning challenge for DSI to incrementally index new documents while being able to answer queries related to both previously and newly indexed documents. Across different model scales and document identifier representations, we show that continual indexing of new documents leads to considerable forgetting of previously indexed documents. We also hypothesize and verify that the model experiences forgetting events during training, leading to unstable learning. To mitigate these issues, we investigate two approaches. The first focuses on modifying the training dynamics. Flatter minima implicitly alleviate forgetting, so we optimize for flatter loss basins and show that the model stably memorizes more documents ($+12\%$). Next, we introduce a generative memory to sample pseudo-queries for documents and supplement them during continual indexing to prevent forgetting for the retrieval task. Extensive experiments on novel continual indexing benchmarks based on Natural Questions (NQ) and MS MARCO demonstrate that our proposed solution mitigates forgetting significantly. Concretely, it improves the average Hits@10 by $+21.1\%$ over competitive baselines for NQ and requires $6$ times fewer model updates compared to re-training the DSI model for incrementally indexing five corpora in a sequence.»
