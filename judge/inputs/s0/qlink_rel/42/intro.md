## Related Works

The growing adoption of cloud-native applications has led to increased interest in optimizing both resource usage and financial costs. Several studies have explored system-level optimizations for containerized environments, particularly focusing on resource allocation and performance improvements \[[9](http://arxiv.org/abs/2010.10350)\]. However, the analysis of network costs in Kubernetes clusters remains underexplored, despite its critical role in overall cloud expenditures \[[1](http://arxiv.org/abs/2501.14753)\]. This paper contributes to the emerging field of FinOps, which integrates financial management with cloud operations to optimize costs in cloud-based applications \[[1](http://arxiv.org/abs/2501.14753)\].

Kubernetes has become the de facto standard for container orchestration, offering features such as automated deployment, scaling, and monitoring \[[6](https://www.semanticscholar.org/paper/b5634b15badc73f3cda72b960fd51ef03ac1265d)\]. Despite its advantages, challenges persist in ensuring efficient scheduling and resource management. For instance, the default scheduling mechanisms in Kubernetes may not align with the optimized task execution order required by workflow systems, leading to inefficiencies in workflow execution \[[5](http://arxiv.org/abs/2207.01222)\]. To address this, KubeAdaptor was proposed as a docking framework that ensures consistency in task scheduling order between workflow systems and Kubernetes \[[5](http://arxiv.org/abs/2207.01222)\].

In addition to scheduling, security remains a critical concern for Kubernetes deployments. Several studies have highlighted vulnerabilities in Kubernetes environments, such as those experienced by Tesla in 2018 \[[3](http://arxiv.org/abs/2006.15275)\]. To mitigate these risks, best practices such as role-based access control (RBAC), regular patching, and network-specific security policies are recommended \[[3](http://arxiv.org/abs/2006.15275)\]. These practices are essential for maintaining the integrity and security of containerized applications.

Cloud cost optimization is another key area of research, particularly in the context of AI and machine learning workloads, which often require significant GPU resources \[[4](http://arxiv.org/abs/2307.12479)\]. Techniques such as model quantization, GPU instance selection, and inference optimization have been explored to reduce costs while maintaining performance \[[4](http://arxiv.org/abs/2307.12479)\]. The paper also highlights the importance of strategic resource allocation and the potential for achieving cost savings of up to 90% through optimized strategies \[[4](http://arxiv.org/abs/2307.12479)\].

Furthermore, the integration of workflow systems with Kubernetes has been a focus of recent research. Pachyderm, for example, is an open-source workflow system that leverages Kubernetes for container orchestration, providing a data pipelining and versioning layer to support reproducibility and scalability in data science workflows \[[7](https://www.semanticscholar.org/paper/51e2cba5a013cbd11f2ab760a4e3906cfff44780)\]. Such tools are essential for managing complex, multi-stage analyses in scientific and industrial applications.

Finally, the use of Kubernetes for auto-scaling and load balancing has been explored to improve the availability and performance of cloud-native applications \[[16](https://www.semanticscholar.org/paper/4d4080e1a2e26fe1ead433741602ab6eccc22b72)\]. These approaches enable dynamic resource allocation based on workload demands, ensuring high availability and efficient resource utilization \[[16](https://www.semanticscholar.org/paper/4d4080e1a2e26fe1ead433741602ab6eccc22b72)\].
