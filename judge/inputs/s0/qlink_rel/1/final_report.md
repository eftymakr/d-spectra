## Related Works

Efficient memory management and KV cache optimization have been central to improving the performance of large language model (LLM) serving systems. Prior work has focused on reducing memory usage and improving throughput through various techniques, including quantization, cache eviction policies, and adaptive compression strategies. These approaches are crucial for enabling high-throughput inference, especially with the growing demand for long-context LLMs.

Several studies have explored KV cache quantization as a means to reduce memory consumption. For example, KIVI introduces a tuning-free 2-bit quantization method that reduces peak memory usage by up to 2.6× while maintaining model quality \[[2](http://arxiv.org/abs/2402.02750)\]. Similarly, KVQuant proposes a comprehensive set of techniques for low-precision KV cache quantization, including per-channel key quantization and non-uniform datatypes, achieving less than 0.1 perplexity degradation with 3-bit quantization \[[6](http://arxiv.org/abs/2401.18079)\]. These methods demonstrate the potential of quantization to significantly reduce memory footprints without compromising performance.

Cache eviction policies have also been a focus of recent research. Scissorhands leverages the persistence of importance hypothesis, retaining pivotal tokens with higher probability to reduce memory usage by up to 5× without model fine-tuning \[[3](http://arxiv.org/abs/2305.17118)\]. H2O introduces a dynamic eviction policy based on the Heavy Hitter Oracle, which identifies and retains critical tokens that contribute most to attention scores, achieving up to 29× throughput improvements over existing systems \[[5](http://arxiv.org/abs/2306.14048)\]. These approaches highlight the importance of adaptive strategies that balance memory efficiency with generation quality.

Another line of work focuses on the structural properties of attention mechanisms to enable more efficient KV cache compression. GEAR combines quantization, low-rank approximation, and sparse correction to achieve near-lossless 4-bit compression, improving throughput by up to 2.38× while reducing peak memory usage by 2.29× \[[11](http://arxiv.org/abs/2403.05527)\]. Similarly, No Token Left Behind proposes a mixed-precision quantization approach that preserves critical KV pairs at higher precision while allowing less important ones to be stored at lower precision, mitigating the risk of hallucinations and context loss \[[12](http://arxiv.org/abs/2402.18096)\]. These methods demonstrate the value of carefully balancing precision and retention to maintain generation quality.

### <a id='category-memory-management-techniques-for-llms'></a>Memory Management Techniques for LLMs: 4 papers found.
Memory management techniques for large language models (LLMs) have been a focal point in improving inference efficiency, particularly in managing the key-value (KV) cache, which is critical for high-throughput serving. Several approaches have been proposed to address the memory constraints and performance bottlenecks associated with KV caching. For instance, PagedAttention introduces a memory-efficient attention mechanism inspired by virtual memory paging, enabling near-zero waste in KV cache memory and flexible sharing across requests \[[1](http://arxiv.org/abs/2309.06180)\]. Similarly, Scissorhands focuses on maintaining a fixed memory budget for the KV cache by prioritizing the storage of pivotal tokens, reducing memory usage by up to 5X without compromising model quality \[[3](http://arxiv.org/abs/2305.17118)\]. InfiniGen further enhances KV cache management for long-text generation by prefetching essential entries, thereby reducing fetch overhead in offloading-based systems \[[10](http://arxiv.org/abs/2406.19707)\]. Additionally, GEAR proposes a compression framework that combines quantization, low-rank approximation, and sparse correction to achieve near-lossless 4-bit KV cache compression, resulting in significant throughput improvements and reduced peak memory usage \[[11](http://arxiv.org/abs/2403.05527)\]. These methods collectively highlight the importance of optimizing KV cache management to enhance both the efficiency and scalability of LLM serving systems.

### <a id='category-kv-cache-quantization-methods'></a>KV Cache Quantization Methods: 3 papers found.
Efficient KV cache management is a critical area of research for improving the performance and memory efficiency of large language models (LLMs) during inference. Several studies have explored quantization techniques to reduce the memory footprint of the KV cache, which is a major contributor to memory consumption, especially with large context windows \[[12](http://arxiv.org/abs/2402.18096)\]. For instance, KIVI introduces a tuning-free 2-bit quantization method that quantizes the key cache per-channel and the value cache per-token, achieving a 2.6× reduction in peak memory usage while maintaining model quality \[[1](http://arxiv.org/abs/2309.06180)\]. Similarly, KVQuant proposes a series of novel methods, including per-channel key quantization, pre-RoPE key quantization, non-uniform KV cache quantization, and per-vector dense-and-sparse quantization, to enable accurate 3-bit quantization with less than 0.1 perplexity degradation \[[6](http://arxiv.org/abs/2401.18079)\]. Additionally, MiKV introduces a mixed-precision approach, where evicted KV pairs are stored in low precision to reduce memory usage, while important KV pairs are retained at higher precision to maintain generation quality \[[12](http://arxiv.org/abs/2402.18096)\]. These approaches highlight the ongoing efforts to balance memory efficiency with inference accuracy, addressing the challenges posed by the growing size of KV caches in LLMs.

We show that StreamingLLM can enable Llama-2, MPT, Falcon, and Pythia to perform stable and efficient language modeling with up to 4 million tokens and more. In addition, we discover that adding a placeholder token as a dedicated attention sink during pre-training can further improve streaming deployment. In streaming settings, StreamingLLM outperforms the sliding window recomputation baseline by up to 22.2x speedup. Code and datasets are provided at https://github.com/mit-han-lab/streaming-llm.»
