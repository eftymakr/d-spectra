## Related Works

Deploying large language models (LLMs) on edge devices presents significant challenges due to limited storage, power, and computational resources \[[1](http://arxiv.org/abs/2309.06180)\]. Prior work has explored various techniques to optimize LLM inference on resource-constrained hardware. For instance, AWQ introduces activation-aware weight quantization to reduce model size and accelerate inference on edge devices, achieving up to 4x model size reduction and 3-4x speedup \[[4](http://arxiv.org/abs/2306.00978)\]. Similarly, SmoothQuant enables 8-bit weight and activation quantization without accuracy loss, allowing the deployment of 530B LLMs on a single node \[[7](http://arxiv.org/abs/2211.10438)\]. These methods focus on reducing memory footprint and improving inference speed through quantization.

Efficient memory management is also a critical area of research. PagedAttention and vLLM address the issue of dynamic key-value cache (KV cache) memory management, achieving near-zero waste and flexible sharing of memory across requests \[[1](http://arxiv.org/abs/2309.06180)\]. FlashAttention further improves attention computation by exploiting the GPU memory hierarchy, reducing memory usage from quadratic to linear in sequence length \[[18](http://arxiv.org/abs/2205.14135)\]. FlashAttention-2 builds upon this by optimizing work partitioning and parallelism, achieving up to 2× speedup over FlashAttention and reaching 50-73% of the theoretical maximum FLOPs/s \[[6](http://arxiv.org/abs/2307.08691)\].

Hardware accelerators for LLMs have also been extensively studied. FPGA-based solutions, such as Ftrans, enable model compression and efficient execution, reducing model size by up to 16 times and achieving significant performance and energy efficiency improvements over CPU and GPU \[[5](http://arxiv.org/abs/2007.08563)\]. NPE presents an FPGA-based overlay processor for NLP tasks, offering 4× lower power than CPUs and 6× lower power than GPUs for BERT inference \[[14](http://arxiv.org/abs/2104.06535)\]. SECDA introduces a hardware/software co-design methodology for FPGA-based DNN accelerators, reducing design time and improving performance and energy efficiency \[[21](http://arxiv.org/abs/2110.00478)\].

Efficient inference techniques, such as speculative decoding and contextual sparsity, have also been proposed. Speculative decoding enables parallel token generation, achieving up to 2-3× speedup without changing model outputs \[[12](http://arxiv.org/abs/2211.17192)\]. DejaVu exploits contextual sparsity to reduce inference latency, achieving over 2× speedup for OPT-175B compared to state-of-the-art implementations \[[9](http://arxiv.org/abs/2310.17157)\]. These methods aim to reduce computational overhead while maintaining model accuracy.

### <a id='category-dynamic-memory-management-in-llm-inference'></a>Dynamic Memory Management in LLM Inference: 2 papers found.
Dynamic Memory Management in LLM Inference has been a critical area of research, particularly due to the challenges posed by the high memory demands of large language models (LLMs). Existing systems face significant limitations in efficiently managing the key-value cache (KV cache) memory, which grows and shrinks dynamically during inference, leading to memory fragmentation and redundant duplication \[[1](http://arxiv.org/abs/2309.06180)\]. To address these issues, PagedAttention was introduced, inspired by virtual memory and paging techniques, enabling near-zero memory waste and flexible sharing of KV cache across requests \[[1](http://arxiv.org/abs/2309.06180)\]. Additionally, methods such as "windowing" and "row-column bundling" have been proposed to optimize data transfer and chunk size from flash memory, allowing models up to twice the size of available DRAM to be run with significant speed improvements \[[2](http://arxiv.org/abs/2312.11514)\]. These approaches highlight the importance of hardware-aware design and memory management in enhancing the efficiency and scalability of LLM inference on resource-constrained devices.

A3 is another accelerator designed specifically for attention mechanisms, leveraging algorithmic approximation and hardware specialization to achieve multiple orders of magnitude improvements in energy efficiency \[[16](http://arxiv.org/abs/2002.10941)\]. FlashAttention also introduces an IO-aware approach, reducing memory reads/writes and enabling faster training of Transformers with longer context \[[18](http://arxiv.org/abs/2205.14135)\]. SpAtten further enhances efficiency by utilizing token and head sparsity, along with quantization, to reduce computation and memory access, achieving substantial speedup and energy savings over existing accelerators \[[19](http://arxiv.org/abs/2012.09852)\]. These works collectively highlight the importance of algorithmic innovation and hardware specialization in improving the efficiency of attention mechanisms for practical deployment.

Efficient inference techniques for large language models (LLMs) have been a focal point of recent research, with several approaches aiming to reduce latency while maintaining output quality. Speculative decoding, for instance, enables the generation of multiple tokens in parallel by leveraging a faster, less powerful draft model to approximate the output of a larger, more accurate target model, thereby reducing the number of serial model calls \[[12](http://arxiv.org/abs/2211.17192)\]. This method has been shown to accelerate decoding by up to 2X-3X without altering the final output distribution \[[12](http://arxiv.org/abs/2211.17192)\]. Similarly, LLMA utilizes reference-based parallelism by identifying and reusing identical text spans from available references, such as retrieved documents, to speed up inference while preserving the accuracy of greedy decoding \[[13](http://arxiv.org/abs/2304.04487)\]. Another approach, speculative sampling, combines a draft model with a rejection sampling scheme to generate multiple tokens per transformer call, achieving a 2-2.5x speedup on large models like Chinchilla without compromising sample quality \[[22](http://arxiv.org/abs/2302.01318)\]. These methods highlight the growing interest in parallel and approximation-based strategies to enhance the efficiency of LLM inference, particularly in resource-constrained environments.
