## Related Works

Deploying large language models (LLMs) on edge devices presents significant challenges due to limited storage, power, and computational resources \[[1](http://arxiv.org/abs/2309.06180)\]. Prior work has explored various techniques to optimize LLM inference on resource-constrained hardware. For instance, AWQ introduces activation-aware weight quantization to reduce model size and accelerate inference on edge devices, achieving up to 4x model size reduction and 3-4x speedup \[[4](http://arxiv.org/abs/2306.00978)\]. Similarly, SmoothQuant enables 8-bit weight and activation quantization without accuracy loss, allowing the deployment of 530B LLMs on a single node \[[7](http://arxiv.org/abs/2211.10438)\]. These methods focus on reducing memory footprint and improving inference speed through quantization.

Efficient memory management is also a critical area of research. PagedAttention and vLLM address the issue of dynamic key-value cache (KV cache) memory management, achieving near-zero waste and flexible sharing of memory across requests \[[1](http://arxiv.org/abs/2309.06180)\]. FlashAttention further improves attention computation by exploiting the GPU memory hierarchy, reducing memory usage from quadratic to linear in sequence length \[[18](http://arxiv.org/abs/2205.14135)\]. FlashAttention-2 builds upon this by optimizing work partitioning and parallelism, achieving up to 2× speedup over FlashAttention and reaching 50-73% of the theoretical maximum FLOPs/s \[[6](http://arxiv.org/abs/2307.08691)\].

Hardware accelerators for LLMs have also been extensively studied. FPGA-based solutions, such as Ftrans, enable model compression and efficient execution, reducing model size by up to 16 times and achieving significant performance and energy efficiency improvements over CPU and GPU \[[5](http://arxiv.org/abs/2007.08563)\]. NPE presents an FPGA-based overlay processor for NLP tasks, offering 4× lower power than CPUs and 6× lower power than GPUs for BERT inference \[[14](http://arxiv.org/abs/2104.06535)\]. SECDA introduces a hardware/software co-design methodology for FPGA-based DNN accelerators, reducing design time and improving performance and energy efficiency \[[21](http://arxiv.org/abs/2110.00478)\].

Efficient inference techniques, such as speculative decoding and contextual sparsity, have also been proposed. Speculative decoding enables parallel token generation, achieving up to 2-3× speedup without changing model outputs \[[12](http://arxiv.org/abs/2211.17192)\]. DejaVu exploits contextual sparsity to reduce inference latency, achieving over 2× speedup for OPT-175B compared to state-of-the-art implementations \[[9](http://arxiv.org/abs/2310.17157)\]. These methods aim to reduce computational overhead while maintaining model accuracy.
