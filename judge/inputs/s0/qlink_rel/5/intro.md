## Related Works

Instruction-following text embedding has emerged as a critical area in natural language processing (NLP), aiming to generate dynamic text embeddings that adapt to user instructions \[[20](http://arxiv.org/abs/2109.01652)\]. This task is particularly important for applications requiring real-time adaptation, such as information retrieval, semantic similarity, and task-specific modeling \[[19](http://arxiv.org/abs/2204.07705)\]. However, existing methods often suffer from significant computational overhead due to the necessity of re-encoding the entire corpus for each new instruction \[[20](http://arxiv.org/abs/2109.01652)\]. This limitation motivates the development of more efficient frameworks that can adapt pre-computed embeddings in real time \[[20](http://arxiv.org/abs/2109.01652)\].

Several approaches have been proposed to improve the efficiency of instruction-following text embeddings. One line of work focuses on instruction tuning, where language models are fine-tuned on a collection of tasks described via instructions \[[20](http://arxiv.org/abs/2109.01652)\]. This method has shown substantial improvements in zero-shot performance on unseen tasks \[[20](http://arxiv.org/abs/2109.01652)\]. For instance, FLAN, a model instruction-tuned on over 60 NLP tasks, outperforms zero-shot GPT-3 on 20 of 25 evaluated tasks \[[20](http://arxiv.org/abs/2109.01652)\]. Similarly, InstructGPT demonstrates significant improvements in instruction-following capabilities by leveraging human feedback during fine-tuning \[[9](http://arxiv.org/abs/2203.02155)\]. These methods, however, still require re-encoding the entire dataset for each instruction, which is computationally expensive \[[20](http://arxiv.org/abs/2109.01652)\].

Another approach involves the use of contrastive learning for sentence embeddings, such as SimCSE, which achieves state-of-the-art results on semantic textual similarity tasks \[[12](http://arxiv.org/abs/2104.08821)\]. SimCSE uses a contrastive learning framework to generate sentence embeddings that are robust and perform well across various tasks \[[12](http://arxiv.org/abs/2104.08821)\]. Similarly, E5, a family of text embeddings trained with weakly-supervised contrastive pre-training, achieves strong performance in both zero-shot and fine-tuned settings \[[18](http://arxiv.org/abs/2212.03533)\]. These models, while effective, still require re-encoding the entire dataset for each instruction, which limits their scalability \[[20](http://arxiv.org/abs/2109.01652)\].

Recent work on instruction tuning with GPT-4 has shown that machine-generated instruction-following data can lead to superior zero-shot performance on new tasks \[[8](http://arxiv.org/abs/2304.03277)\]. This approach reduces the dependency on human-written instruction data, which is often limited in quantity and diversity \[[8](http://arxiv.org/abs/2304.03277)\]. Similarly, Self-Instruct introduces a framework for improving instruction-following capabilities by bootstrapping off the model's own generations \[[4](http://arxiv.org/abs/2212.10560)\]. This method generates instructions, input, and output samples from a language model, then filters and uses them for fine-tuning \[[4](http://arxiv.org/abs/2212.10560)\].
