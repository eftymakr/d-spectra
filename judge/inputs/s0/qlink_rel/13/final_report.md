## Related Works

Long-tailed recognition remains a challenging problem in visual recognition due to the skewed class distribution in real-world datasets \[[1](http://arxiv.org/abs/1910.09217)\]. Many existing methods have attempted to address this issue by either re-balancing the data, adjusting the loss function, or modifying the classifier \[[2](http://arxiv.org/abs/2207.09052)\]. For instance, class-balancing strategies such as loss re-weighting, data re-sampling, or transfer learning from head to tail classes have been widely explored \[[1](http://arxiv.org/abs/1910.09217)\]. However, most of these approaches still follow a joint learning scheme for representation and classification \[[1](http://arxiv.org/abs/1910.09217)\].

Recent work has focused on decoupling the learning process into separate representation and classification stages, which has shown promising results \[[1](http://arxiv.org/abs/1910.09217)\]. For example, the paper by \[[1](http://arxiv.org/abs/1910.09217)\] demonstrates that data imbalance might not be a significant issue in learning high-quality representations, and that a simple instance-balanced sampling can lead to strong long-tailed recognition performance when combined with a well-designed classifier. Similarly, \[[2](http://arxiv.org/abs/2207.09052)\] proposes a novel loss function for contrastive learning, called Balanced Contrastive Learning (BCL), which addresses the issue of forming a regular simplex in long-tailed data. This is crucial for improving the feature representation and classification performance.

Another approach to improving long-tailed recognition is through contrastive learning, which has been shown to be effective in learning discriminative features \[[3](http://arxiv.org/abs/2107.12028)\]. However, supervised contrastive learning (SCL) often suffers from gradient conflicts and imbalanced attraction and repulsion gradients between positive and negative pairs \[[4](http://arxiv.org/abs/2111.13998)\]. This issue has been further analyzed in \[[5](http://arxiv.org/abs/1904.05160)\], where the authors show that SCL fails to form a regular simplex in long-tailed data, leading to suboptimal performance. To address this, \[[6](http://arxiv.org/abs/1912.02413)\] proposes a method called Targeted Supervised Contrastive Learning (TSC), which improves the uniformity of the feature distribution on the hypersphere. This ensures that all classes, including minority classes, maintain a uniform distribution in the feature space, improving class boundaries and generalization.

### <a id='category-long-tailed-recognition-challenges'></a>Long-tailed Recognition Challenges: 10 papers found.
The long-tailed recognition problem, where data is unevenly distributed across classes, has been extensively studied, with various approaches focusing on class re-balancing, representation learning, and classifier optimization \[[16](http://arxiv.org/abs/2110.04596)\]. Techniques such as class re-weighting and re-sampling have been widely used to alleviate the imbalance, but they often compromise the model's ability to generalize to tail classes \[[6](http://arxiv.org/abs/1912.02413)\]. To address these limitations, more advanced methods have been proposed, such as the Bilateral-Branch Network (BBN), which integrates representation and classifier learning simultaneously \[[6](http://arxiv.org/abs/1912.02413)\], and RoutIng Diverse Experts (RIDE), which employs a dynamic routing mechanism to improve performance on both head and tail classes \[[10](http://arxiv.org/abs/2010.01809)\]. Additionally, weight balancing strategies, including L2-normalization, weight decay, and MaxNorm, have been explored to ensure balanced classifier behavior \[[11](http://arxiv.org/abs/2203.14197)\]. Recent work has also emphasized the importance of causal inference frameworks to better understand and mitigate the biases introduced by long-tailed distributions \[[15](http://arxiv.org/abs/2009.12991)\]. Furthermore, domain adaptation and meta-learning approaches have been introduced to account for distribution mismatches between training and test data \[[21](http://arxiv.org/abs/2003.10780)\]. These methods collectively highlight the challenges and potential solutions in long-tailed recognition, setting the stage for more robust and generalized recognition systems.

### <a id='category-loss-function-adjustments'></a>Loss Function Adjustments: 8 papers found.
The category "Loss Function Adjustments" encompasses a range of techniques aimed at improving the performance of deep learning models on long-tailed datasets, where certain classes are underrepresented. These methods typically modify standard loss functions like cross-entropy or softmax to better handle class imbalance. For instance, logit adjustment based on label frequencies has been proposed to increase the relative margin between rare and dominant labels \[[13](http://arxiv.org/abs/2007.07314)\]. Similarly, Balanced Softmax is an unbiased extension of the softmax function that addresses the label distribution shift between training and testing data \[[14](http://arxiv.org/abs/2007.10740)\]. The equalization loss is another approach that ignores gradients for rare categories during training, protecting them from being overshadowed by more frequent classes \[[18](http://arxiv.org/abs/2003.05176)\]. Additionally, the class-balanced loss introduces a theoretical framework to measure data overlap and re-balance the loss based on the effective number of samples per class \[[19](http://arxiv.org/abs/1901.05555)\]. The LADE loss further disentangles the source label distribution from model predictions during training, leading to better generalization on long-tailed datasets \[[20](http://arxiv.org/abs/2012.00321)\]. The LDAM loss is designed to minimize a margin-based generalization bound, offering a theoretically-principled approach to label distribution-aware training \[[23](http://arxiv.org/abs/1906.07413)\]. Finally, a robustness-based loss encourages the model to learn high-quality representations for both head and tail classes, reducing representation bias in the feature space \[[25](http://arxiv.org/abs/2104.03066)\]. These approaches collectively highlight the importance of adjusting loss functions to address the challenges posed by long-tailed data distributions.
