## Related Works

Conversational Recommender Systems (CRSs) have emerged as a promising approach to dynamically capture user preferences through multi-turn interactions \[[1](http://arxiv.org/abs/2002.09102)\]. Traditional recommender systems often rely on static models that struggle to accurately infer user preferences due to their inability to incorporate explicit user feedback \[[4](http://arxiv.org/abs/2101.09459)\]. In contrast, CRSs enable systems to actively engage with users, allowing for more precise preference elicitation and improved recommendation accuracy \[[5](http://arxiv.org/abs/2004.00646)\]. However, frequent user involvement can degrade the user experience, necessitating the development of automated evaluation methods \[[15](http://arxiv.org/abs/2006.08732)\].

Several studies have explored the integration of conversational elements into recommendation systems. The EAR framework \[[1](http://arxiv.org/abs/2002.09102)\] introduces a three-stage approach—Estimation, Action, and Reflection—to better converse with users by dynamically deciding whether to ask for attribute information or recommend items. This framework has been validated on datasets from Yelp and LastFM, showing significant improvements over existing methods \[[1](http://arxiv.org/abs/2002.09102)\]. Similarly, the CPR framework \[[3](http://arxiv.org/abs/2007.00194)\] models conversational recommendation as an interactive path reasoning problem on a graph, leveraging user feedback to prune irrelevant attributes and improve recommendation accuracy. The SCPR instantiation of CPR outperforms state-of-the-art methods such as EAR and CRM \[[3](http://arxiv.org/abs/2007.00194)\].

To enhance the semantic understanding of user preferences, knowledge graph (KG)-based approaches have been proposed \[[2](http://arxiv.org/abs/2007.04032)\]. These methods incorporate both word-oriented and entity-oriented KGs to align semantic spaces and improve the accuracy of recommendations and dialog generation. The alignment of word-level and entity-level representations enables more effective use of contextual information, leading to better performance in conversational recommendation tasks \[[2](http://arxiv.org/abs/2007.04032)\].

The development of conversational recommendation policies has also been addressed through reinforcement learning (RL) \[[6](http://arxiv.org/abs/2105.09710)\]. Existing methods often focus on solving one or two decision-making problems, limiting scalability and generality. A unified policy learning approach has been proposed, integrating conversation and recommendation components through a dynamic weighted graph-based RL method \[[6](http://arxiv.org/abs/2105.09710)\]. This approach improves sample efficiency and enhances the scalability and stability of CRSs.

To enable more natural and efficient user interactions, the SAUR paradigm \[[7](https://www.semanticscholar.org/paper/3ae5bef6b0c8317603a2deab2527383580904fd8)\] proposes a System Ask—User Respond framework for conversational search and recommendation. This paradigm allows the system to ask questions to clarify user needs while conducting personalized search during the conversation. ### <a id='category-conversational-frameworks-and-their-approaches'></a>Conversational Frameworks and Their Approaches: 8 papers found.
Conversational recommendation systems (CRSs) have been extensively studied, with a focus on dynamically capturing user preferences through multi-turn interactions \[[1](http://arxiv.org/abs/2002.09102)\]. Early approaches, such as the Estimation-Action-Reflection (EAR) framework, aimed to address the challenge of determining when to recommend items versus asking for attribute-level feedback, and how to adapt to user responses \[[1](http://arxiv.org/abs/2002.09102)\]. However, these systems often overlooked the relationship between attribute-level and item-level feedback, limiting their ability to refine recommendations effectively \[[10](https://www.semanticscholar.org/paper/33e0fe2d4cf01b16da89ab0c180cdcbf37b3be17)\]. To overcome this, the Feedback-guided Preference Adaptation Network (FPAN) was introduced, which uses gating modules to adapt user embeddings and item-level feedback based on attribute-level feedback, thereby improving preference estimation \[[10](https://www.semanticscholar.org/paper/33e0fe2d4cf01b16da89ab0c180cdcbf37b3be17)\]. Additionally, the Conversational Path Reasoning (CPR) framework models CRS as an interactive path reasoning problem on a graph, allowing the system to prune irrelevant attributes and better align with user preferences \[[3](http://arxiv.org/abs/2007.00194)\]. The Multi-Interest Multi-round Conversational Recommendation (MIMCR) setting further expands the scope by considering users with multiple, overlapping interests, requiring more sophisticated strategies for question generation and item recommendation \[[11](http://arxiv.org/abs/2112.11775)\]. The Knowledge-Based Question Generation System (KBQG) enhances the quality of generated questions by leveraging a structured knowledge graph to identify relevant relations, leading to more effective user preference elicitation \[[12](http://arxiv.org/abs/2105.04774)\]. Meanwhile, the Q&R (Question & Recommendation) system integrates RNN-based models to generate topic-related questions and refine recommendations based on user feedback, demonstrating improvements in real-world applications \[[13](https://www.semanticscholar.org/paper/2610b45131f31a7c58b0cd6a8fce21c02ba014be)\]. These approaches collectively highlight the ongoing efforts to improve the accuracy and efficiency of conversational recommendation systems through better question generation, feedback utilization, and user preference modeling.

### <a id='category-reinforcement-learning-in-conversational-policies'></a>Reinforcement Learning in Conversational Policies: 2 papers found.
Conversational recommender systems (CRSs) have been increasingly explored for their ability to capture user preferences through interactive dialogue, with reinforcement learning (RL) playing a pivotal role in shaping recommendation policies \[[6](http://arxiv.org/abs/2105.09710)\]. Existing approaches often focus on isolated decision-making tasks, such as determining which attributes to ask or which items to recommend, leading to limited scalability and training stability \[[6](http://arxiv.org/abs/2105.09710)\]. To address these limitations, recent work has aimed to unify these decision-making processes under a single policy learning framework, integrating conversation and recommendation components more systematically \[[6](http://arxiv.org/abs/2105.09710)\]. This approach enables the system to dynamically select actions—either asking for attribute values or recommending items—based on a learned policy \[[6](http://arxiv.org/abs/2105.09710)\]. Additionally, to improve sample efficiency, researchers have introduced strategies for reducing the candidate action space by leveraging user preference and entropy information \[[6](http://arxiv.org/abs/2105.09710)\]. Another line of research has focused on integrating dialog systems with recommender systems through deep reinforcement learning frameworks, aiming to optimize session-based utility functions while incorporating both historical user data and real-time conversational inputs \[[9](http://arxiv.org/abs/1806.03277)\]. These efforts highlight the growing interest in developing more adaptive and efficient conversational recommendation agents that can better align with user preferences while maintaining a seamless interaction experience \[[9](http://arxiv.org/abs/1806.03277)\].
