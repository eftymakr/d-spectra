## Related Works

Event cameras, which capture scene changes asynchronously on a per-pixel basis, offer significant advantages over traditional frame-based cameras, particularly in high-speed and high dynamic range scenarios \[[3](http://arxiv.org/abs/1904.08405)\]. However, their high bandwidth, memory, and computational demands pose challenges for real-time processing and efficient data utilization \[[1](http://arxiv.org/abs/1802.06898)\]. Prior work has addressed these challenges through event downsampling techniques, but most approaches rely on fixed heuristics or threshold-based strategies, limiting their adaptability to varying scene conditions \[[1](http://arxiv.org/abs/1802.06898)\]. For instance, some methods use static thresholds to discard events, which may not be optimal for all applications \[[3](http://arxiv.org/abs/1904.08405)\]. Others attempt to reduce the event stream by discarding events that do not contribute to the overall scene understanding, but these methods often lack the flexibility to adapt to different tasks or environments \[[1](http://arxiv.org/abs/1802.06898)\].

To overcome these limitations, this paper introduces a probabilistic framework, POLED, which models event importance through an event-importance probability density function (ePDF) \[[1](http://arxiv.org/abs/1802.06898)\]. This approach allows for arbitrary definitions of event importance, enabling scene-specific adaptation \[[1](http://arxiv.org/abs/1802.06898)\]. Unlike previous methods, POLED operates in a purely online setting, estimating event importance on-the-fly from raw event streams \[[1](http://arxiv.org/abs/1802.06898)\]. This enables the system to dynamically adjust to changing scene conditions without requiring pre-defined thresholds or extensive preprocessing \[[1](http://arxiv.org/abs/1802.06898)\].

Additionally, the paper introduces zero-shot event downsampling, where downsampled events must remain usable for models trained on the original event stream, without task-specific adaptation \[[1](http://arxiv.org/abs/1802.06898)\]. This is a significant advancement, as it ensures that the downsampling process does not compromise the performance of downstream tasks \[[1](http://arxiv.org/abs/1802.06898)\]. The proposed contour-preserving ePDF prioritizes structurally important events, ensuring that critical visual information is retained even under event-budget constraints \[[1](http://arxiv.org/abs/1802.06898)\].

Several studies have explored the use of event cameras for various vision tasks, such as optical flow estimation, object detection, and visual SLAM \[[3](http://arxiv.org/abs/1904.08405)\]\[[4](http://arxiv.org/abs/1709.06310)\]\[[5](http://arxiv.org/abs/2009.13436)\]. For example, EV-FlowNet is a self-supervised deep learning pipeline for optical flow estimation that uses grayscale images captured from the same camera at the same time as the events as a supervisory signal \[[1](http://arxiv.org/abs/1802.06898)\]. Similarly, the paper "Learning to Detect Objects with a 1 Megapixel Event Camera" addresses the challenge of object detection by introducing a novel recurrent architecture and a temporal consistency loss for better-behaved training \[[5](http://arxiv.org/abs/2009.13436)\]. These works highlight the potential of event cameras for complex vision tasks, but they often rely on frame-based training data or require significant computational resources \[[5](http://arxiv.org/abs/2009.13436)\].

Thanks to these characteristics, event cameras are particularly suited for scenarios with high motion, challenging lighting conditions and requiring low latency. The main reasons for this performance gap are: the lower spatial resolution of event sensors, compared to frame cameras; the lack of large-scale training datasets; the absence of well established deep learning architectures for event-based processing. In this paper, we address all these problems in the context of an event-based object detection task. First, we publicly release the first high-resolution large-scale dataset for object detection. Second, we introduce a novel recurrent architecture for event-based detection and a temporal consistency loss for better-behaved training. [Snippet]: «Event cameras are bio-inspired vision sensors that output pixel-level brightness changes instead of standard intensity frames. These cameras do not suffer from motion blur and have a very high dynamic range, which enables them to provide reliable visual information during high-speed motions or in scenes characterized by high dynamic range. These features, along with a very low power consumption, make event cameras an ideal complement to standard cameras for VR/AR and video game applications. With these applications in mind, this paper tackles the problem of accurate, low-latency tracking of an event camera from an existing photometric depth map (i.e., intensity plus depth information) built via classic dense reconstruction pipelines.
