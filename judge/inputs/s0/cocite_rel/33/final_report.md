## Related Works

Rehearsal-based methods have been widely studied in continual learning (CL) to address catastrophic forgetting, where models lose previously learned knowledge when trained on new tasks \[[1](http://arxiv.org/abs/1612.00796)\]. These methods typically store a subset of past data and train it alongside new data during the current task \[[2](http://arxiv.org/abs/1811.11682)\]. While concurrent rehearsal, where past and new data are trained together, is a common approach, recent work has questioned whether this strategy is always optimal \[[3](http://arxiv.org/abs/1705.08690)\]. Inspired by human learning, where revisiting tasks sequentially helps mitigate forgetting, there is growing interest in exploring sequential rehearsal as a potentially more effective strategy \[[4](http://arxiv.org/abs/1801.01423)\].

Several studies have investigated the effectiveness of rehearsal-based approaches in mitigating catastrophic forgetting. For instance, experience replay buffers have been proposed as a general solution to reduce forgetting by storing and reusing past experiences \[[5](http://arxiv.org/abs/2012.12631)\]. This approach has been shown to be effective in both reinforcement learning and classification tasks \[[6](http://arxiv.org/abs/1606.09282)\]. Similarly, generative replay has been explored as a method to sample and reuse past data, particularly in scenarios where task identity is not known \[[7](http://arxiv.org/abs/1902.10486)\]. The idea of using generative models to replay past experiences has been further refined by integrating feedback connections, enabling more efficient and scalable solutions \[[8](https://www.semanticscholar.org/paper/90e04f3ae23ca7df5f59b11453341e3db943b6f4)\].

The importance of task similarity in determining the effectiveness of rehearsal strategies has also been highlighted. For example, in class-incremental learning scenarios, where tasks are not disjoint, methods like Elastic Weight Consolidation (EWC) and Memory Aware Synapses (MAS) have been proposed to selectively protect important weights \[[9](http://arxiv.org/abs/1904.07734)\]. These methods aim to preserve knowledge from previous tasks while allowing the model to learn new tasks \[[10](http://arxiv.org/abs/1809.10635)\]. Additionally, the role of memory in continual learning has been extensively studied, with approaches such as the Deep Generative Replay framework proposing a dual model architecture to sample and interleave past and new data \[[11](https://www.semanticscholar.org/paper/7bfb4ef17eabec1acd266958bdb08622eebfbb05)\].

In the context of sequential rehearsal, recent work has suggested that training similar tasks concurrently and revisiting dissimilar tasks sequentially may offer better performance \[[12](http://arxiv.org/abs/1908.04742)\]. This hybrid approach leverages the strengths of both strategies, allowing for efficient learning while minimizing forgetting \[[13](http://arxiv.org/abs/1706.08840)\]. Theoretical analysis of rehearsal-based CL in overparameterized linear models has further supported this idea, showing that sequential rehearsal performs better when tasks are less similar \[[14](http://arxiv.org/abs/1906.00695)\]. These findings are consistent with empirical results from deep neural networks, where hybrid rehearsal methods have been shown to outperform standard concurrent rehearsal \[[15](http://arxiv.org/abs/1805.12369)\].

The category "Catastrophic Forgetting in Continual Learning" encompasses a range of approaches aimed at mitigating the degradation of model performance on previously learned tasks when training sequentially on new tasks. A primary challenge in continual learning is catastrophic forgetting, where models lose previously acquired knowledge due to the overwriting of critical parameters during training \[[1](http://arxiv.org/abs/1612.00796)\]. To address this, several methods have been proposed, including task-based hard attention mechanisms that preserve previous task information without interfering with current learning \[[2](http://arxiv.org/abs/1811.11682)\], modular architectures that enable knowledge transfer through reusable components \[[3](http://arxiv.org/abs/1705.08690)\], and methods like Learning without Forgetting, which maintain original capabilities while training on new data \[[4](http://arxiv.org/abs/1801.01423)\]. Additionally, frameworks such as Gradient Episodic Memory (GEM) and task-conditioned hypernetworks have been introduced to alleviate forgetting by either maintaining task-specific weight realizations or leveraging episodic memory \[[7](http://arxiv.org/abs/1902.10486)\]\[[8](https://www.semanticscholar.org/paper/90e04f3ae23ca7df5f59b11453341e3db943b6f4)\]. The concept of rehearsal-based methods, where past data is stored and retrained alongside new data, has also been explored, with recent work comparing concurrent and sequential rehearsal strategies to determine their effectiveness under varying task similarity \[[9](http://arxiv.org/abs/1904.07734)\]. These approaches highlight the ongoing efforts to develop robust continual learning systems that can maintain performance across sequential tasks without requiring full retraining or access to original task data \[[10](http://arxiv.org/abs/1809.10635)\].

### <a id='category-experience-replay-buffers'></a>Experience Replay Buffers: 2 papers found.
Experience replay buffers have been widely explored as a strategy to mitigate catastrophic forgetting in continual learning, particularly in reinforcement learning settings where agents encounter sequential tasks without explicit task boundaries \[[1](http://arxiv.org/abs/1612.00796)\]. The core idea is to store past experiences in a buffer and use them alongside new data during training, enabling the model to retain knowledge from previous tasks while learning new ones \[[1](http://arxiv.org/abs/1612.00796)\]. This approach leverages both on-policy and off-policy learning, often combined with behavioral cloning to improve performance \[[1](http://arxiv.org/abs/1612.00796)\]. Research has shown that using experience replay buffers can significantly reduce catastrophic forgetting, even matching the performance of methods that rely on explicit task identities \[[1](http://arxiv.org/abs/1612.00796)\]. Moreover, when buffer storage is limited, simple mechanisms such as random data discarding can allow a constrained buffer to perform nearly as well as an unbounded one \[[1](http://arxiv.org/abs/1612.00796)\]. Building on these insights, more recent work has introduced novel approaches like Meta-Experience Replay (MER), which combines experience replay with meta-learning to optimize the trade-off between transfer and interference by aligning gradients across examples \[[2](http://arxiv.org/abs/1811.11682)\]. These methods demonstrate that experience replay can be a powerful tool for continual learning, especially in non-stationary environments where data distributions change over time \[[2](http://arxiv.org/abs/1811.11682)\].

### <a id='category-rehearsal-based-methods-in-continual-learning'></a>Rehearsal-Based Methods in Continual Learning: 3 papers found.
Rehearsal-based methods in continual learning (CL) have been extensively explored to mitigate catastrophic forgetting by leveraging past data during training. These methods typically involve storing a subset of previous examples in a memory buffer and using them alongside new data from the current task \[[18](http://arxiv.org/abs/1809.05922)\]. This approach has been shown to improve generalization, as joint training on both current and past data acts as a form of data-dependent regularization \[[1](http://arxiv.org/abs/1612.00796)\]. However, the effectiveness of such methods depends on the strategy used to populate the memory buffer. For instance, reservoir sampling has been found to work well in most scenarios, although it may not be optimal when memory size is extremely limited, where strategies ensuring equal class representation perform better \[[1](http://arxiv.org/abs/1612.00796)\]. Additionally, the use of rehearsal in streaming learning settings has been highlighted as a critical technique to prevent catastrophic forgetting, with memory-efficient approaches like ExStream offering significant improvements over full rehearsal by reducing computational and memory overhead \[[18](http://arxiv.org/abs/1809.05922)\]. The theoretical analysis of rehearsal-based CL in overparameterized linear models further suggests that sequential rehearsal, where new data is trained first before revisiting past data, can outperform concurrent rehearsal, especially when tasks are less similar \[[1](http://arxiv.org/abs/1612.00796)\]. These findings underscore the importance of carefully designing rehearsal strategies to balance memory usage and performance, with hybrid approaches that combine concurrent and sequential rehearsal showing promise in improving both forgetting and generalization \[[1](http://arxiv.org/abs/1612.00796)\].
