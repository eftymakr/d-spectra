## Related Works

Efficient memory management and KV cache optimization have been extensively studied in the context of large language model (LLM) serving systems. Early work focused on the challenges of managing the key-value (KV) cache, which stores attention keys and values to avoid recomputation during inference \[[1](http://arxiv.org/abs/2309.06180)\]. The memory footprint of the KV cache, which grows dynamically with sequence length and batch size, has been identified as a critical bottleneck in LLM deployment \[[2](http://arxiv.org/abs/2402.02750)\]. Traditional approaches often rely on static memory allocation, leading to significant waste due to fragmentation and redundant duplication \[[1](http://arxiv.org/abs/2309.06180)\]. 

Recent research has introduced more sophisticated techniques to manage the KV cache. PagedAttention, inspired by virtual memory paging, enables near-zero memory waste and flexible sharing of KV cache across requests \[[1](http://arxiv.org/abs/2309.06180)\]. Similarly, KIVI proposes a tuning-free 2-bit quantization method for KV cache, reducing peak memory usage by up to 2.6× while maintaining model quality \[[2](http://arxiv.org/abs/2402.02750)\]. These methods highlight the importance of memory-aware design in improving throughput and latency.

The importance of KV cache reuse has also been explored. Scissorhands leverages the persistence of importance hypothesis, assuming that only pivotal tokens influence future generations \[[3](http://arxiv.org/abs/2305.17118)\]. This leads to a 5× reduction in memory usage without compromising model quality \[[3](http://arxiv.org/abs/2305.17118)\]. Similarly, InfiniGen introduces dynamic KV cache management for long-text generation, prefetching essential KV cache entries to mitigate fetch overhead \[[9](http://arxiv.org/abs/2406.19707)\]. These approaches demonstrate the potential of adaptive and context-aware cache strategies.

Another line of work focuses on the impact of cache eviction on generation quality. H2O introduces a Heavy Hitter Oracle (H$_2$O) that dynamically retains recent and important tokens, improving throughput by up to 29× compared to existing systems \[[5](http://arxiv.org/abs/2306.14048)\]. This approach emphasizes the need for balancing memory efficiency with generation accuracy. Similarly, GEAR employs a combination of quantization and low-rank matrix approximation to achieve near-lossless compression with up to 2.38× throughput improvement \[[10](http://arxiv.org/abs/2403.05527)\]. These methods show that careful design of cache compression can significantly enhance performance.

The role of KV cache in inference latency has also been addressed. Prompt Cache enables low-latency inference by reusing attention states across prompts with overlapping text segments \[[11](http://arxiv.org/abs/2311.04934)\]. This reduces time-to-first-token latency by up to 60× on CPU-based inference while maintaining output accuracy \[[11](http://arxiv.org/abs/2311.04934)\]. LESS integrates a constant-sized cache with eviction-based methods to retain information throughout decoding, improving performance on tasks requiring recollection of previous tokens \[[12](http://arxiv.org/abs/2402.09398)\]. The category "KV Cache Memory Management Techniques" explores various methods to optimize the memory usage of key-value (KV) caches in large language models (LLMs), which are critical for efficient inference and serving. Techniques like PagedAttention \[[1](http://arxiv.org/abs/2309.06180)\] and vLLM aim to reduce memory waste and enable flexible sharing of KV cache across requests, significantly improving throughput. Similarly, StreamingLLM \[[2](http://arxiv.org/abs/2402.02750)\] addresses the challenge of long-sequence generation by introducing attention sink mechanisms and placeholder tokens to enhance generalization. Heavy Hitter Oracle (H$_2$O) \[[3](http://arxiv.org/abs/2305.17118)\] dynamically retains important tokens based on their contribution to attention scores, leading to substantial memory reduction and performance improvements. SnapKV \[[4](http://arxiv.org/abs/2309.17453)\] leverages the consistent attention patterns of model heads to compress KV caches, achieving faster generation and better memory efficiency. Adaptive KV cache compression \[[5](http://arxiv.org/abs/2306.14048)\] further refines this by tailoring cache construction to the specific needs of attention heads, reducing memory consumption without sacrificing quality. Lastly, LESS \[[6](http://arxiv.org/abs/2404.14469)\] integrates a constant-sized cache with eviction-based strategies to maintain information retention across decoding steps, offering a balance between performance and efficiency. These approaches collectively highlight the importance of workload-aware and dynamic management of KV caches to enhance the scalability and practical deployment of LLMs.

### <a id='category-cache-compression-and-quantization-methods'></a>Cache Compression and Quantization Methods: 5 papers found.
Cache compression and quantization methods have emerged as critical techniques to address the memory bottlenecks in large language model (LLM) inference, particularly concerning the key-value (KV) cache. The KV cache, which stores attention keys and values to avoid re-computation, significantly increases memory demands with larger batch sizes and longer context lengths, often surpassing the model size itself \[[1](http://arxiv.org/abs/2309.06180)\]. To mitigate this, various approaches have been proposed, such as quantization, which reduces the memory footprint by lowering the precision of stored values \[[1](http://arxiv.org/abs/2309.06180)\]. However, the effectiveness of quantization depends on the distribution of elements within the KV cache, leading to the development of methods like KIVI, which quantizes keys per-channel and values per-token to achieve efficient compression without compromising quality \[[1](http://arxiv.org/abs/2309.06180)\]. Additionally, methods like Scissorhands focus on maintaining only pivotal tokens in the KV cache, reducing memory usage by up to 5X while preserving model quality \[[2](http://arxiv.org/abs/2402.02750)\]. Similarly, MiKV introduces mixed-precision quantization, retaining important KV pairs at higher precision while compressing less critical ones to lower precision, thus balancing compression ratio and performance \[[3](http://arxiv.org/abs/2305.17118)\]. GEAR further improves compression by combining quantization, low-rank matrix approximation, and sparse matrix techniques to achieve near-lossless 4-bit compression with significant throughput improvements \[[4](http://arxiv.org/abs/2309.17453)\]. PyramidKV, on the other hand, dynamically adjusts KV cache allocation across model layers, reducing memory usage while maintaining generation quality \[[5](http://arxiv.org/abs/2306.14048)\]. These methods collectively highlight the importance of workload-aware strategies and precision management in optimizing KV cache efficiency.
