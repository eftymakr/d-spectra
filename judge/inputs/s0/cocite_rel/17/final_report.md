## Related Works

Semi-supervised learning (SSL) has been a focal point in machine learning research, aiming to leverage unlabeled data to improve model performance when labeled data is scarce \[[1](https://www.semanticscholar.org/paper/f3df804a7eef204b0c4fc4b81166dec9b4abc073)\]. However, traditional SSL methods typically assume that labeled and unlabeled data share the same class distribution \[[1](https://www.semanticscholar.org/paper/f3df804a7eef204b0c4fc4b81166dec9b4abc073)\]. This assumption is often violated in practice, as unlabeled data may contain out-of-distribution (OOD) samples, which are referred to as outliers \[[1](https://www.semanticscholar.org/paper/f3df804a7eef204b0c4fc4b81166dec9b4abc073)\]. These outliers can significantly degrade model performance by introducing noise \[[1](https://www.semanticscholar.org/paper/f3df804a7eef204b0c4fc4b81166dec9b4abc073)\]. 

Several approaches have been proposed to address the issue of OOD data in SSL. For instance, FixMatch \[[3](http://arxiv.org/abs/2001.07685)\] introduces a simple yet effective method that combines consistency regularization and pseudo-labeling. It generates pseudo-labels for unlabeled data based on high-confidence predictions and trains the model to maintain consistency between different augmented views of the same instance \[[3](http://arxiv.org/abs/2001.07685)\]. While FixMatch achieves state-of-the-art results on various benchmarks, it assumes that unlabeled data is in-distribution (ID), and thus does not explicitly handle OOD samples \[[3](http://arxiv.org/abs/2001.07685)\].

To address the challenges posed by OOD data, OpenMatch \[[8](http://arxiv.org/abs/2105.14148)\] extends FixMatch by integrating novelty detection based on one-vs-all (OVA) classifiers. This allows the model to distinguish between inliers and outliers, improving robustness against OOD samples \[[8](http://arxiv.org/abs/2105.14148)\]. Similarly, OpenCoS \[[13](http://arxiv.org/abs/2107.08943)\] leverages contrastive learning to identify OOD samples in the unlabeled dataset and uses both one-hot pseudo-labels and soft-labels to improve model performance \[[13](http://arxiv.org/abs/2107.08943)\]. 

Another approach, Temporal Ensembling \[[9](http://arxiv.org/abs/1610.02242)\], introduces self-ensembling, where the model forms a consensus prediction using outputs from different training epochs and augmentation conditions. This helps improve the robustness of SSL models by leveraging the consistency of predictions across different views \[[9](http://arxiv.org/abs/1610.02242)\]. 

The problem of class distribution mismatch between labeled and unlabeled data has also been addressed in the context of open-set SSL. For example, the Multi-Task Curriculum Framework \[[2](http://arxiv.org/abs/2007.11330)\] proposes a joint optimization framework that detects OOD samples and trains the model to classify in-distribution data effectively \[[2](http://arxiv.org/abs/2007.11330)\]. Similarly, the Trash to Treasure approach \[[4](http://arxiv.org/abs/2108.05617)\] leverages all unlabeled data, including OOD samples, through a warm-up training phase and cross-modal matching strategies to enhance feature learning \[[4](http://arxiv.org/abs/2108.05617)\].

However, pseudo-labeling faces challenges when dealing with out-of-distribution data, as highlighted in \[[29](http://arxiv.org/abs/2301.06010)\], where methods like Re-balanced Pseudo-Labeling (RPL) and Semantic Exploration Clustering (SEC) are proposed to mitigate class-mismatch issues. These studies collectively highlight the evolving landscape of pseudo-labeling techniques, emphasizing the need for robustness against distribution shifts and outliers.

### <a id='category-dynamic-threshold-adjustment'></a>Dynamic Threshold Adjustment: 3 papers found.
Dynamic threshold adjustment is a critical area in semi-supervised learning (SSL) that aims to improve the selection of pseudo-labeled examples from unlabeled data. Existing methods often use a fixed threshold or ad-hoc schemes, which can lead to suboptimal performance and slow convergence \[[12](http://arxiv.org/abs/2205.07246)\]. For instance, FixMatch, which has achieved state-of-the-art results, employs a pre-defined constant threshold across all classes, failing to account for varying learning statuses and difficulties among different classes \[[14](http://arxiv.org/abs/2110.08263)\]. To address these limitations, researchers have proposed adaptive threshold adjustment strategies. Dash dynamically adjusts the threshold during training iterations, ensuring only examples with losses below a given threshold are used for training, thereby improving adaptivity and theoretical guarantees \[[1](https://www.semanticscholar.org/paper/f3df804a7eef204b0c4fc4b81166dec9b4abc073)\]. Similarly, FreeMatch introduces a self-adaptive threshold adjustment mechanism based on the model's learning status, further enhancing performance, especially when labeled data is scarce \[[12](http://arxiv.org/abs/2205.07246)\]. Additionally, Curriculum Pseudo Labeling (CPL) extends this idea by adjusting thresholds for different classes at each training step, allowing for more informed pseudo-label selection and improved convergence \[[14](http://arxiv.org/abs/2110.08263)\]. These approaches highlight the importance of dynamic threshold adjustment in improving the robustness and efficiency of SSL methods.
