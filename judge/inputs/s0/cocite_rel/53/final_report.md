## Related Works

Sequential recommendation systems aim to predict the next item a user will interact with, based on their historical behavior. These systems have evolved significantly, incorporating advanced neural network architectures to better capture sequential patterns and user preferences. Early approaches, such as Markov Chains (MCs), assume that the next action is determined solely by the last few actions \[[1](http://arxiv.org/abs/1808.09781)\]. While effective in sparse datasets, they lack the capacity to model long-term dependencies. Recurrent Neural Networks (RNNs), on the other hand, can capture longer-term semantics but often suffer from computational inefficiency and difficulty in handling sparse data \[[1](http://arxiv.org/abs/1808.09781)\]. 

To address these limitations, attention-based models have emerged, such as SASRec, which uses self-attention to selectively focus on relevant items in a user's history \[[1](http://arxiv.org/abs/1808.09781)\]. This approach allows for more efficient modeling of long-term dependencies while maintaining the simplicity of MC-based methods. Similarly, Caser employs convolutional filters to extract local features from item sequences, enabling the model to capture both general preferences and sequential patterns \[[2](http://arxiv.org/abs/1809.07426)\]. These models demonstrate the importance of leveraging both item-level and sequence-level information.

Recent work has also emphasized the need for incorporating temporal information, as many existing models treat behavior sequences as static \[[5](https://www.semanticscholar.org/paper/5574d6123deea94eba2cb35b2486851e826c16ce)\]. The paper "Time Matters" introduces the concept of absolute and relative time patterns, highlighting how temporal dynamics influence user behavior \[[5](https://www.semanticscholar.org/paper/5574d6123deea94eba2cb35b2486851e826c16ce)\]. This has led to the development of models that explicitly model time-related signals, such as FEARec, which shifts the perspective to the frequency domain to better capture periodic patterns \[[14](http://arxiv.org/abs/2304.09184)\].

Noise in logged user behavior data remains a challenge, particularly for deep learning models that are prone to overfitting \[[6](http://arxiv.org/abs/2202.13556)\]. To mitigate this, FMLP-Rec integrates filtering algorithms with an all-MLP architecture, effectively reducing noise and improving performance \[[6](http://arxiv.org/abs/2202.13556)\]. Additionally, the use of self-supervised learning has gained traction, as seen in S3-Rec, which leverages mutual information maximization to enhance data representations \[[3](http://arxiv.org/abs/2008.07873)\]. This approach allows for better utilization of both item and subsequence correlations, especially in low-data scenarios.

Another key challenge is modeling diverse user interests and preferences, which has led to the development of controllable multi-interest frameworks like ComiRec \[[8](http://arxiv.org/abs/2005.09347)\]. These models capture multiple user interests from their behavior sequences and balance recommendation accuracy with diversity. Furthermore, hierarchical attention networks have been proposed to better model both long-term and short-term user preferences \[[10](https://www.semanticscholar.org/paper/0b42168f22713c48d8b0ce3bc8f680d347184d88)\]. These models use attention mechanisms at different levels to capture evolving user behavior over time.

### <a id='category-attention-based-sequential-recommendation-models'></a>Attention-Based Sequential Recommendation Models: 4 papers found.
Attention-based sequential recommendation models have gained significant traction due to their ability to capture complex user behavior patterns \[[1](http://arxiv.org/abs/1808.09781)\]. These models leverage attention mechanisms to prioritize relevant items in a user's history, enabling more accurate next-item predictions \[[1](http://arxiv.org/abs/1808.09781)\]. While Markov Chains (MCs) and Recurrent Neural Networks (RNNs) have traditionally been used for sequential recommendation, attention-based models offer a middle ground by combining the efficiency of MCs with the expressive power of RNNs \[[1](http://arxiv.org/abs/1808.09781)\]. For instance, SASRec introduces a self-attention mechanism that allows for capturing long-term semantics while maintaining computational efficiency \[[1](http://arxiv.org/abs/1808.09781)\]. Similarly, Feature-level Deeper Self-Attention Network (FDSA) extends this idea by incorporating feature-level sequences to better model both item and feature transition patterns \[[2](http://arxiv.org/abs/1809.07426)\]. Additionally, models like NARM integrate attention mechanisms with session-based approaches to better capture user intent and sequential behavior within short sessions \[[3](http://arxiv.org/abs/2008.07873)\]. Recent advancements also explore the use of frequency domain analysis to enhance attention-based models, such as FEARec, which introduces a frequency-enhanced hybrid attention network to better capture periodic and high-frequency patterns in user behavior \[[4](http://arxiv.org/abs/1904.06690)\]. These developments highlight the ongoing evolution of attention-based models in sequential recommendation, emphasizing their adaptability to diverse user behaviors and dataset characteristics.

### <a id='category-convolutional-approaches-for-sequential-recommendation'></a>Convolutional Approaches for Sequential Recommendation: 2 papers found.
Convolutional approaches for sequential recommendation have been increasingly explored to better capture sequential patterns in user behavior. These models treat sequences of user interactions as 2D latent matrices, enabling the use of convolutional filters to extract local features that represent sequential dependencies \[[15](http://arxiv.org/abs/1808.05163)\]. This approach allows for the modeling of both short- and long-range dependencies without relying heavily on pooling operations, which can limit the receptive field \[[15](http://arxiv.org/abs/1808.05163)\]. Additionally, the integration of residual blocks into the network architecture facilitates the training of deeper models by mitigating the vanishing gradient problem \[[15](http://arxiv.org/abs/1808.05163)\]. The Caser model, for instance, employs a convolutional sequence embedding strategy to learn sequential patterns from item sequences, effectively capturing the impact of recent interactions on future recommendations \[[2](http://arxiv.org/abs/1809.07426)\]. These methods highlight the potential of convolutional neural networks in sequential recommendation tasks, particularly in scenarios involving long user sessions or diverse interaction patterns.

### <a id='category-self-supervised-learning-in-sequential-recommendation'></a>Self-Supervised Learning in Sequential Recommendation: 3 papers found.
Recent advancements in sequential recommendation have focused on addressing challenges such as data sparsity and the limitations of unidirectional models. For instance, the S3-Rec model introduces self-supervised learning to enhance data representations by capturing correlations among attributes, items, subsequences, and sequences through mutual information maximization \[[3](http://arxiv.org/abs/2008.07873)\]. Similarly, BERT4Rec employs a bidirectional self-attention mechanism to model user behavior sequences, allowing for more comprehensive context utilization by conditioning on both left and right contexts during training \[[4](http://arxiv.org/abs/1904.06690)\]. Additionally, the DuoRec model addresses representation degeneration in item embeddings by introducing a contrastive regularization based on the uniformity property of contrastive learning, reshaping the distribution of sequence representations to improve semantic consistency \[[16](http://arxiv.org/abs/2110.05730)\]. These approaches highlight the growing trend of leveraging self-supervised learning and advanced architectures to better capture the complexities of user behavior in sequential recommendation tasks.
