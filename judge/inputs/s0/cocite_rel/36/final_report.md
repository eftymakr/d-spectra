Deploying large language models (LLMs) on edge devices presents significant challenges due to the limited storage, computational power, and energy resources available \[[14](https://www.semanticscholar.org/paper/ec93fc7ec82c65a7bf7213488327d391014539ed)\]. Prior work has explored various techniques to address these limitations, including model compression, efficient inference, and hardware acceleration. For instance, \[[15](http://arxiv.org/abs/2306.00978)\] introduced AWQ, an activation-aware weight quantization method that enables on-device LLM deployment by reducing model size while preserving performance. This approach has been shown to achieve up to 4x model size reduction and 3–4x acceleration across various edge platforms. Similarly, \[[21](http://arxiv.org/abs/2211.10438)\] proposed SmoothQuant, a post-training quantization method that enables 8-bit weight and activation quantization for LLMs, achieving up to 1.56x speedup and 2x memory reduction with negligible accuracy loss. ### <a id='category-efficient-memory-management'></a>Efficient Memory Management: 4 papers found.
Efficient memory management in large language models (LLMs) has been a focal point of recent research, with several approaches addressing the challenges of memory fragmentation, cache inefficiency, and scalability. Techniques such as PagedAttention \[[1](http://arxiv.org/abs/2309.06180)\] introduce a memory management framework inspired by virtual memory paging, enabling near-zero waste in key-value (KV) cache memory and flexible sharing across requests. Similarly, FlashAttention \[[3](https://www.semanticscholar.org/paper/5af69480a7ae3b571df6782a11ec4437b386a7d9)\] optimizes the attention layer by reducing memory usage from quadratic to linear in sequence length, achieving significant runtime improvements. However, FlashAttention-2 \[[7](http://arxiv.org/abs/2307.08691)\] further refines this by improving work partitioning on GPUs, leading to a 2× speedup and closer alignment with theoretical FLOPs/s limits. Meanwhile, methods like window attention \[[17](http://arxiv.org/abs/2309.17453)\] aim to reduce memory consumption by caching only recent tokens, though they face limitations when text length exceeds cache size. To address this, StreamingLLM \[[17](http://arxiv.org/abs/2309.17453)\] introduces attention sink mechanisms, allowing models to generalize to longer sequences without fine-tuning. Additionally, hardware-aware strategies, such as those in \[[2](http://arxiv.org/abs/2312.11514)\], leverage flash memory to extend model capacity beyond available DRAM, enabling inference on resource-constrained devices. These approaches collectively highlight the importance of memory optimization in enabling efficient LLM deployment across diverse hardware and application scenarios.

To address these challenges, hybrid in-memory accelerators like X-Former have been proposed, integrating both NVM and CMOS processing elements to enhance performance \[[1](http://arxiv.org/abs/2309.06180)\]. Additionally, innovative dataflow strategies, such as sequence blocking, have been introduced to improve hardware utilization by overlapping computations between the two processing elements \[[1](http://arxiv.org/abs/2309.06180)\]. These advancements highlight the ongoing efforts to optimize in-memory computing architectures for the demanding workloads of modern deep learning models.
