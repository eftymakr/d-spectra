The category "Model and Dataset Documentation Practices" highlights critical gaps and trends in how machine learning datasets and models are documented on platforms like Hugging Face. Practitioners tend to prioritize sections such as Dataset Description and Dataset Structure, while sections like Considerations for Using the Data are underdeveloped \[[2](http://arxiv.org/abs/2311.13380)\]. Furthermore, the analysis of the Hugging Face supply chain reveals that documentation shortcomings persist across both models and datasets, with issues ranging from licensing transparency to inadequate metadata \[[4](http://arxiv.org/abs/2401.13822)\]. These challenges are compounded by the complexity of modern ML systems, which often involve intricate dependencies and supply chains that are not well captured in current documentation practices \[[5](http://arxiv.org/abs/2402.07323)\]. Addressing these issues requires more standardized documentation frameworks and greater emphasis on the social and ethical implications of dataset usage \[[6](http://arxiv.org/abs/2406.08205)\].
