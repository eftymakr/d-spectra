## Related Works

Conversational Recommender Systems (CRSs) have emerged as a promising approach to dynamically capture user preferences through multi-turn interactions \[[1](http://arxiv.org/abs/2002.09102)\]. Traditional recommender systems often rely on static models that estimate user preferences based on past behavior, which limits their ability to adapt to dynamic user needs \[[4](http://arxiv.org/abs/2101.09459)\]. In contrast, CRSs enable systems to actively engage with users by asking questions about item attributes and recommending items in real-time \[[1](http://arxiv.org/abs/2002.09102)\]. This interactive approach allows for more accurate preference elicitation and personalized recommendations \[[1](http://arxiv.org/abs/2002.09102)\].

Several studies have explored the challenges of conversational recommendation, particularly in understanding user preferences from natural language interactions. For instance, the Estimation-Action-Reflection (EAR) framework was introduced to address three key problems in CRSs: determining what questions to ask, when to recommend items, and how to adapt to user feedback \[[1](http://arxiv.org/abs/2002.09102)\]. The framework consists of three stages—Estimation, Action, and Reflection—to better converse with users \[[1](http://arxiv.org/abs/2002.09102)\]. However, existing methods often struggle with effectively integrating conversation and recommendation components, leading to suboptimal performance \[[6](http://arxiv.org/abs/2105.09710)\].

To improve the interaction process, the Conversational Path Reasoning (CPR) framework was proposed, which models conversational recommendation as an interactive path reasoning problem on a graph \[[2](http://arxiv.org/abs/2007.00194)\]. CPR leverages the graph structure to prune irrelevant attributes and enhance the chances of hitting user-preferred attributes \[[2](http://arxiv.org/abs/2007.00194)\]. This approach has shown significant improvements over state-of-the-art methods like EAR and CRM \[[2](http://arxiv.org/abs/2007.00194)\]. Additionally, the Knowledge Graph based Semantic Fusion approach enhances CRSs by incorporating both word-oriented and entity-oriented knowledge graphs to align semantic representations \[[3](http://arxiv.org/abs/2007.04032)\]. This helps bridge the semantic gap between natural language and item-level preferences \[[3](http://arxiv.org/abs/2007.04032)\].

The development of conversational recommendation systems has also been influenced by reinforcement learning (RL) techniques. A unified policy learning framework was proposed to integrate conversation and recommendation components, enabling the system to decide whether to ask for attributes or recommend items at each turn \[[6](http://arxiv.org/abs/2105.09710)\]. This approach improves scalability and stability by using a dynamic weighted graph-based RL method \[[6](http://arxiv.org/abs/2105.09710)\]. Moreover, the SAUR paradigm, which involves System Ask – User Respond, has been proposed to formalize conversational search and recommendation tasks \[[5](https://www.semanticscholar.org/paper/3ae5bef6b0c8317603a2deab2527383580904fd8)\]. This framework enables systems to ask questions to clarify user needs and provide personalized recommendations during the conversation \[[5](https://www.semanticscholar.org/paper/3ae5bef6b0c8317603a2deab2527383580904fd8)\].

To evaluate the effectiveness of conversational recommenders, user simulation techniques have been introduced. These simulations generate realistic user responses based on individual preferences and interaction patterns \[[13](http://arxiv.org/abs/2006.08732)\]. The proposed UserSimCRS toolkit allows for automated evaluation of CRSs

### <a id='category-reinforcement-learning-in-conversational-interaction'></a>Reinforcement Learning in Conversational Interaction: 3 papers found.
Reinforcement learning (RL) has been increasingly applied to conversational recommender systems (CRSs) to address challenges in dynamically capturing user preferences through interaction \[[1](http://arxiv.org/abs/2002.09102)\]. Existing approaches often focus on isolated decision-making problems, such as determining when to ask for item attributes or when to recommend items, leading to limited scalability and unstable training processes \[[2](http://arxiv.org/abs/2007.00194)\]. To overcome these limitations, recent work has proposed unified policy learning frameworks that integrate conversation and recommendation components, enabling more coherent and adaptive dialogue strategies \[[3](http://arxiv.org/abs/2007.04032)\]. For instance, one study introduces a dynamic weighted graph-based RL method to learn a policy for selecting actions—either asking for attributes or recommending items—at each conversation turn, while also incorporating strategies to reduce the action space for improved efficiency \[[2](http://arxiv.org/abs/2007.00194)\]. Another approach emphasizes the integration of dialog systems and recommender systems into a deep reinforcement learning framework, allowing the system to optimize a per-session utility function by leveraging both historical user data and real-time conversational inputs \[[3](http://arxiv.org/abs/2007.04032)\]. These methods aim to enhance the personalization and effectiveness of CRSs by better aligning with user preferences through iterative, multi-turn interactions. Additionally, efforts have been made to improve the scalability of CRSs by incorporating long-term user preferences and optimizing business-oriented metrics such as conversion rates \[[3](http://arxiv.org/abs/2007.04032)\]. Overall, the field is moving toward more integrated, adaptive, and efficient conversational recommendation frameworks that balance user engagement with system performance.
