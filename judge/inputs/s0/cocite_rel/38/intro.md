## Related Works

Memory bandwidth regulation and cache partitioning have been widely studied as techniques to achieve predictable timing in real-time computing systems \[[1](https://www.semanticscholar.org/paper/50d359dc737cb5c296b527f4eb1541dc55f3ed86)\]. These approaches are often combined with partitioned scheduling to ensure that tasks receive sufficient resources for predictable execution \[[2](https://www.semanticscholar.org/paper/25ebad66dc10d7b01c22684cbb200ddeb6502475)\]. However, the co-allocation of tasks and resources to cores remains a complex challenge, as task execution times are strongly influenced by the allocated resources \[[3](https://www.semanticscholar.org/paper/bbebaeb1b00fdcde2aeb192543835d3ec1518f8d)\]. 

Several works have explored the use of hardware and software techniques to manage memory bandwidth and cache resources. For example, MemGuard is a memory bandwidth reservation system designed to provide efficient performance isolation on multi-core platforms \[[4](https://www.semanticscholar.org/paper/dbd4eb5033815003e7f6519fd66e43e5fc297075)\]. It enables fine-grained control over memory access, which is critical for real-time applications \[[5](https://www.semanticscholar.org/paper/abbd6f8840092bd8e4e3684d3297e1b707abdc5d)\]. Similarly, PALLOC is a DRAM bank-aware memory allocator that improves performance isolation by leveraging memory bank partitioning \[[6](https://www.semanticscholar.org/paper/d5336fd2234f431f554fc5d878503a04a27e366e)\]. This approach helps reduce memory interference between tasks, which is a significant concern in multi-core systems \[[7](https://www.semanticscholar.org/paper/6e925ae85e385ac0e8810441d84be97c079f6b22)\].

Cache partitioning has also been extensively studied to mitigate the effects of shared cache resources on real-time performance. Cache coloring and cache bleaching are two techniques that have been proposed to address this issue. Cache bleaching, in particular, leverages programmable logic in-the-middle (PLIM) to manipulate memory transactions and recompact colored sparse addresses in main memory \[[8](https://www.semanticscholar.org/paper/cf5b78d3e292fda8f6a8aa132da468f6d8e6a730)\]. This approach has shown promise in improving cache isolation and reducing interference \[[9](https://www.semanticscholar.org/paper/0b1bc294dbd926f853a8ee41d1d8f8ecc3cfde13)\]. 

In addition to hardware-based solutions, software techniques have also been developed to manage memory bandwidth and cache resources. For instance, E-WarP is a system-wide framework for memory bandwidth profiling and management that enables workload-aware analysis and performance prediction \[[10](https://www.semanticscholar.org/paper/afca4afaaaa543a1da02b266e9b2ac46eb94793b)\]. It provides a profile-driven approach to analyze memory demand and predict the temporal behavior of applications running on multi-core platforms \[[11](https://www.semanticscholar.org/paper/43cc4d0a998b9aa361264e5fc786c738a62382f1)\]. The framework also supports saturation-aware system consolidation, which is essential for maintaining predictable performance in real-time environments \[[12](https://www.semanticscholar.org/paper/f71c848137ac1398f84e6ab7d896641f801ca192)\].

The scheduling of parallel real-time tasks on multi-core processors has also been a focus of recent research. RT-Gang introduces a novel real-time gang scheduling framework that enforces a one-gang-at-a-time policy to reduce worst-case execution time (WCET) and improve schedulability \[[13](https://www.semanticscholar.org/paper/31e4e1bb57bd04bc02d7f7110e66122a215d7bfa)\]. This approach ensures that parallel tasks are scheduled as a group, minimizing contention for shared hardware resources such as cache and DRAM controllers \[[14](http://arxiv.org/abs/1903.00999)\]. To further enhance predictability, RT-Gang integrates a memory bandwidth throttling framework to limit the impact of best-effort tasks on real-time gang tasks .
