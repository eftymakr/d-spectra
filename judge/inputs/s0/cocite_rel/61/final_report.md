## Related Works

Personalized outfit generation has been a focal point in recent research, driven by the increasing demand for fashion recommendation systems that can provide both compatibility and personalization \[[1](http://arxiv.org/abs/1905.01866)\]. Early approaches focused on item-level compatibility, often using rule-based systems or simple similarity metrics \[[12](http://arxiv.org/abs/1805.00313)\]. However, these methods lacked the ability to model complex interactions between items and user preferences \[[14](http://arxiv.org/abs/1810.02443)\]. 

Recent works have explored deep learning models to address these challenges. For instance, \[[1](http://arxiv.org/abs/1905.01866)\] proposed a Personalized Outfit Generation (POG) model that connects user preferences with a Transformer architecture, achieving strong performance in both compatibility and personalization metrics. Similarly, \[[15](https://www.semanticscholar.org/paper/762ec45448e915142f355848265d10dd55ab470f)\] introduced OutfitNet, which uses attention-based multiple instance learning to model the compatibility between items and user preferences, showing improved results in fill-in-the-blank and personalized outfit recommendation tasks. 

The importance of style in outfit generation has also been emphasized. \[[2](http://arxiv.org/abs/1807.03133)\] incorporated an unsupervised style extraction module to learn global style information, enabling more flexible and interpretable outfit generation. \[[16](http://arxiv.org/abs/1509.07473)\] further extended this idea by learning a visual compatibility metric from co-occurrence data, which proved effective in generating compatible outfits across categories. 

Compatibility modeling has been another key area of research. \[[13](http://arxiv.org/abs/1712.01262)\] proposed a compatibility family learning framework that embeds items into a latent space and projects queries into compatible prototypes, achieving state-of-the-art performance on multiple datasets. \[[17](http://arxiv.org/abs/1506.04757)\] introduced a Siamese CNN architecture to learn compatibility from user behavior data, demonstrating the effectiveness of cross-category fit learning. 

Personalization in outfit recommendation has also received significant attention. \[[6](https://www.semanticscholar.org/paper/b5f488dd55024f0db2cabb73b055002b5d995be9)\] introduced a framework that uses a two-level attention mechanism to capture user preferences, improving the accuracy of outfit recommendations. \[[24](https://www.semanticscholar.org/paper/30fb5c24cc15eb8cde5e389bf368d65fb96513e4)\] proposed a partitioned embedding network that enables interpretable and customizable outfit composition, addressing the limitations of black-box deep learning models.

### <a id='category-item-level-compatibility-models'></a>Item-Level Compatibility Models: 3 papers found.
The category "Item-Level Compatibility Models" focuses on the challenge of learning compatibility between fashion items, which is crucial for tasks such as outfit generation and recommendation. These models aim to capture both similarity and compatibility between items of different types, such as tops, bottoms, and shoes, by embedding them into a shared latent space \[[1](http://arxiv.org/abs/1905.01866)\]. Compatibility is often defined as the ability of items to coexist in an outfit, and it differs from similarity in that it involves broader and asymmetric relationships \[[13](http://arxiv.org/abs/1712.01262)\]. To address this, researchers have proposed end-to-end trainable systems that embed items into latent vectors and project queries into compatible prototypes, ensuring diversity and avoiding incompatibility \[[13](http://arxiv.org/abs/1712.01262)\]. Additionally, compatibility can be learned from user behavior data, such as co-purchase information, to model cross-category fit \[[16](http://arxiv.org/abs/1509.07473)\]. These models often use architectures like Siamese CNNs, where training examples are pairs of compatible or incompatible items, and they are trained to distinguish between these relationships \[[16](http://arxiv.org/abs/1509.07473)\]. The learned representations support tasks like outfit compatibility prediction and fill-in-the-blank, with improvements over existing methods \[[1](http://arxiv.org/abs/1905.01866)\]. The use of differentiable distance functions, such as the Projected Compatibility Distance (PCD), further enhances the ability to model compatibility while ensuring diversity in generated outputs \[[13](http://arxiv.org/abs/1712.01262)\]. These approaches highlight the importance of combining both compatibility and style-aware learning to improve the realism and personalization of generated outfits.

[Snippet]: «Intelligent fashion outfit composition becomes more and more popular in these years. Some deep learning based approaches reveal competitive composition recently. However, the uninterpretable characteristic makes such deep learning based approach cannot meet the designers, businesses and consumers' urge to comprehend the importance of different attributes in an outfit composition. To realize interpretable and customized multi-item fashion outfit compositions, we propose a partitioned embedding network to learn interpretable embeddings from clothing items. The network consists of two vital components: attribute partition module and partition adversarial module. In the attribute partition module, multiple attribute labels are adopted to ensure that different parts of the overall embedding correspond to different attributes. In the partition adversarial module, adversarial operations are adopted to achieve the independence of different parts. With the interpretable and partitioned embedding, we then construct an outfit composition graph and an attribute matching map. Extensive experiments demonstrate that 1) the partitioned embedding have unmingled parts which corresponding to different attributes and 2) outfits recommended by our model are more desirable in comparison with the existing methods.»
