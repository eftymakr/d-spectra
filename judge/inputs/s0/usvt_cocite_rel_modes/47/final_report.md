## Related Works

Multi-Domain Recommendation (MDR) has emerged as a promising approach to address the data sparsity and cold start problems in recommender systems by leveraging knowledge transfer across multiple domains \[[15](http://arxiv.org/abs/2308.05508)\]. Traditional MDR methods often rely on a single structure to transfer domain-shared knowledge, which can be limiting when the transfer information varies across domains \[[17](http://arxiv.org/abs/2211.11964)\]. This limitation leads to the Negative Transfer Problem (NTP), where unselectively transferring information from all domains can degrade recommendation performance, especially when there is knowledge conflict or poor quality in certain domains \[[17](http://arxiv.org/abs/2211.11964)\]. 

To mitigate NTP, several studies have explored domain adaptation and knowledge transfer mechanisms. For instance, \[[1](http://arxiv.org/abs/1804.06769)\] proposes a deep transfer learning approach for cross-domain recommendation, which enables dual knowledge transfer across domains by introducing cross connections between networks. This method improves performance by learning complex user-item interaction relationships. Similarly, \[[3](https://www.semanticscholar.org/paper/d5630291a4ba3f6266c77e6d00920502f986afa6)\] introduces BiTGCF, a bi-directional transfer learning method that realizes two-way knowledge transfer across domains by using common users as bridges. It also fuses domain-specific and common features during transfer, enhancing recommendation accuracy.

Another line of research focuses on the challenges of multi-target cross-domain recommendation. \[[5](https://www.semanticscholar.org/paper/2b031c7170c9dccbe506f3d3a1d6104f65e835ae)\] presents DTCDR, a framework that simultaneously improves recommendation performance on both richer and sparser domains by leveraging rating and multi-source content information. It employs Multi-Task Learning (MTL) to combine embeddings of common users across domains, enabling dual-target CDR. \[[12](http://arxiv.org/abs/2108.07976)\] further extends this idea by proposing a unified framework for cross-domain and cross-system recommendations, aiming to improve performance across all datasets simultaneously. This approach uses graph embeddings and attention mechanisms to combine embeddings of common entities across domains.

The issue of domain-specific preferences and the need for adaptive knowledge transfer has also been addressed in recent works. \[[14](http://arxiv.org/abs/2211.11191)\] introduces a hierarchical hypergraph network for MDR, which captures correlative preferences across domains by representing user-item interactions in a unified graph. It incorporates dynamic item transfer and adaptive user aggregation modules to improve representation learning. \[[15](http://arxiv.org/abs/2308.05508)\] proposes EDDA, which disentangles embeddings to separate domain-invariant and domain-specific knowledge, and uses domain alignment to enhance knowledge transfer across domains with small overlaps.

### <a id='category-cross-domain-recommendation-methods'></a>Cross Domain Recommendation Methods: 12 papers found.
Cross-domain recommendation (CDR) has emerged as a critical approach to alleviate data sparsity in recommender systems by leveraging knowledge from multiple domains \[[1](http://arxiv.org/abs/1804.06769)\]. Various methods have been proposed to facilitate knowledge transfer between domains, including collaborative cross networks (CoNet) \[[1](http://arxiv.org/abs/1804.06769)\], which introduces cross connections between base networks to enable dual knowledge transfer, and BiTGCF \[[3](https://www.semanticscholar.org/paper/d5630291a4ba3f6266c77e6d00920502f986afa6)\], which employs a graph collaborative filtering network to enable bidirectional knowledge transfer through common users. Additionally, the Deep Dual Transfer Cross Domain Recommendation (DDTCDR) model \[[4](http://arxiv.org/abs/1910.05189)\] utilizes dual learning to iteratively transfer information between domains, while the Preference Propagation GraphNet (PPGN) \[[6](https://www.semanticscholar.org/paper/24a473700894dbfab0bfd9dc3d542acfeef66bca)\] addresses challenges in cross-domain knowledge transfer by constructing a Cross-Domain Preference Matrix (CDPM) and simplifying the optimization process. Furthermore, the Adversarial feature translation (AFT) model \[[8](https://www.semanticscholar.org/paper/7807d924fa46caec7b706b98156962caf8458d59)\] is designed for multi-domain recommendation (MDR), using a generative adversarial network framework to learn feature translations between domains. These methods highlight the importance of modeling domain-specific and domain-invariant preferences, as well as the need for efficient and adaptive knowledge transfer mechanisms. The Multi-Sparse-Domain Collaborative Recommendation (MSDCR) model \[[10](http://arxiv.org/abs/2201.05973)\] further advances MDR by treating all domains as sparse and using adversarial training to preserve domain-specific preferences. Lastly, the Star Topology Adaptive Recommender (STAR) \[[16](http://arxiv.org/abs/2101.11427)\] proposes a hierarchical model that captures domain-specific and shared characteristics, enabling effective cross-domain recommendation. These approaches collectively demonstrate the ongoing efforts to improve cross-domain recommendation through advanced transfer learning and collaborative filtering techniques.

### <a id='category-cross-domain-recommendation-systems'></a>Cross Domain Recommendation Systems: 4 papers found.
Cross Domain Recommendation (CDR) systems aim to improve recommendation performance by leveraging information from a source domain to enhance a target domain with sparse data \[[12](http://arxiv.org/abs/2108.07976)\]. Recent advancements have focused on dual-target CDR, where both the source and target domains benefit simultaneously \[[5](https://www.semanticscholar.org/paper/2b031c7170c9dccbe506f3d3a1d6104f65e835ae)\]. For instance, DTCDR introduces a framework that utilizes rating and multi-source content information to generate embeddings, combined with an adaptable embedding-sharing strategy via Multi-Task Learning (MTL) to improve performance across domains \[[5](https://www.semanticscholar.org/paper/2b031c7170c9dccbe506f3d3a1d6104f65e835ae)\]. Similarly, GA proposes a unified framework that addresses dual-target, multi-target, and CDR+CSR scenarios by constructing heterogeneous graphs and employing attention mechanisms to combine embeddings of common entities \[[12](http://arxiv.org/abs/2108.07976)\]. Additionally, EDDA tackles challenges in multi-domain recommendation (MDR) by disentangling domain-specific and shared knowledge and aligning domains through random walks \[[15](http://arxiv.org/abs/2308.05508)\]. Meanwhile, RC-DFM focuses on deeply fusing review texts and item contents with ratings to address cold start and data sparsity issues in cross-domain settings \[[19](https://www.semanticscholar.org/paper/54dedd4d06f36a00cde7084c1cd1a92ad8cf9168)\]. These approaches highlight the growing interest in leveraging cross-domain information, with a focus on improving generalization, avoiding negative transfer, and enhancing performance across multiple domains.

### <a id='category-others'></a>Others: 3 papers found.
Collaborative filtering faces significant challenges due to data sparsity, where users typically rate only a small subset of items, leading to a sparse rating matrix \[[9](http://arxiv.org/abs/1203.3535)\]. To address this, multi-domain collaborative filtering (MCF) has been proposed, which leverages multiple domains simultaneously and exploits relationships between them to improve recommendation accuracy \[[9](http://arxiv.org/abs/1203.3535)\]. This approach uses probabilistic matrix factorization to model each domain and allows knowledge transfer across domains by learning correlations between them \[[9](http://arxiv.org/abs/1203.3535)\]. Additionally, cross-domain recommendation has been explored to enhance performance, especially in scenarios with sparse data, by transferring knowledge from source domains to target domains \[[17](http://arxiv.org/abs/2211.11964)\]. However, this can lead to the negative transfer problem, where knowledge from a source domain may not always benefit the target domain, particularly when the source domain has poor data quality \[[17](http://arxiv.org/abs/2211.11964)\]. To mitigate this, methods like CAT-ART have been introduced, which use representation learning and embedding transfer to improve recommendations across multiple domains \[[17](http://arxiv.org/abs/2211.11964)\]. Similarly, sequential recommendation in shared-account and cross-domain settings has been addressed with models like π-Net, which handles shared user accounts and cross-domain behavior by using parallel information-sharing networks \[[13](https://www.semanticscholar.org/paper/fa990aee9a8f157b5d393f5f3eaa014e1e5c67aa)\]. These approaches highlight the ongoing efforts to improve recommendation systems by addressing domain-specific challenges and enabling effective knowledge transfer \[[9](http://arxiv.org/abs/1203.3535)\]\[[13](https://www.semanticscholar.org/paper/fa990aee9a8f157b5d393f5f3eaa014e1e5c67aa)\]\[[17](http://arxiv.org/abs/2211.11964)\].
