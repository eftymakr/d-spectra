## Related Works

KV cache compression has emerged as a critical area of research for improving the efficiency of large language model (LLM) inference, particularly in serving scenarios where memory and throughput are paramount. Prior work has focused on various strategies, including quantization, compression, and eviction policies, to reduce the memory footprint of KV caches while maintaining model performance.

Quantization techniques have been widely explored for reducing the memory usage of KV caches. KIVI \[[1](http://arxiv.org/abs/2402.02750)\] introduces a tuning-free 2-bit quantization approach that differentiates between key and value caches, applying per-channel quantization to keys and per-token quantization to values. This method enables significant memory reduction, allowing models like Llama and Mistral to maintain similar quality while using 2.6× less peak memory. Similarly, KVQuant \[[9](http://arxiv.org/abs/2401.18079)\] proposes a comprehensive set of methods for low-precision KV cache quantization, including per-channel key quantization, pre-RoPE quantization, and non-uniform quantization, achieving less than 0.1 perplexity degradation with 3-bit quantization. These approaches demonstrate that quantization can effectively reduce memory usage without significant performance loss.

KV cache compression techniques have also been investigated through the lens of token importance and similarity. H2O \[[7](http://arxiv.org/abs/2306.14048)\] introduces a dynamic eviction policy based on the observation that a small subset of tokens, referred to as heavy hitters, contribute most to attention scores. By retaining these tokens, H2O achieves up to 29× throughput improvements over existing systems. Similarly, Scissorhands \[[4](http://arxiv.org/abs/2305.17118)\] leverages the persistence of importance hypothesis, prioritizing the storage of pivotal tokens to maintain model quality while reducing memory usage by up to 5×. These methods highlight the importance of identifying and retaining critical tokens for efficient inference.

Adaptive KV cache compression has also been explored, with approaches such as FastGen \[[8](http://arxiv.org/abs/2310.01801)\] and KVMerger \[[11](http://arxiv.org/abs/2407.08454)\] aiming to reduce memory usage while preserving performance. FastGen employs adaptive compression by selectively evicting non-critical tokens based on attention head behavior, while KVMerger focuses on merging similar key states within sequences to reduce cache size without significant performance degradation. These methods demonstrate that adaptive strategies can offer a balance between memory efficiency and model accuracy.

### <a id='category-kv-cache-optimization-techniques'></a>KV Cache Optimization Techniques: 7 papers found.
The category "KV Cache Optimization Techniques" encompasses various approaches aimed at reducing the memory and computational overhead associated with the Key-Value (KV) cache in large language models (LLMs). These techniques address the challenges posed by increasing context lengths and batch sizes, which lead to significant memory demands and computational bottlenecks \[[1](http://arxiv.org/abs/2402.02750)\]. One approach, KIVI, introduces a tuning-free 2-bit quantization method that quantizes the key cache per-channel and the value cache per-token, significantly reducing memory usage and enabling larger batch sizes \[[1](http://arxiv.org/abs/2402.02750)\]. Similarly, SnapKV leverages the observation that attention heads focus on specific prompt features, allowing for efficient compression of KV caches by retaining only critical positions \[[5](http://arxiv.org/abs/2404.14469)\]. Another method, StreamingLLM, introduces the concept of attention sink, where retaining initial token KV states helps generalize to longer sequences without fine-tuning \[[6](http://arxiv.org/abs/2309.17453)\]. Heavy Hitter Oracle (H2O) identifies and retains critical tokens (Heavy Hitters) that contribute most to attention scores, achieving substantial throughput improvements \[[7](http://arxiv.org/abs/2306.14048)\]. Adaptive KV cache compression, as seen in FastGen, dynamically constructs the KV cache based on attention module structures, reducing memory consumption with minimal quality loss \[[8](http://arxiv.org/abs/2310.01801)\]. KVMerger, inspired by the similarity of key states within sequences, proposes a merging strategy that selectively combines KV states to reduce cache size while maintaining performance \[[11](http://arxiv.org/abs/2407.08454)\]. PyramidKV further optimizes memory usage by dynamically adjusting cache size across layers, retaining only essential information while preserving model performance \[[13](http://arxiv.org/abs/2406.02069)\]. These methods collectively highlight the importance of workload-aware and adaptive strategies in optimizing KV cache efficiency for real-world LLM deployment.

This approach is implemented in the vLLM system, which significantly improves throughput by 2–4× compared to state-of-the-art systems like FasterTransformer and Orca, particularly for longer sequences and more complex decoding algorithms \[[2](http://arxiv.org/abs/2309.06180)\]. Additionally, another study presents MiniCache, a method that compresses the KV cache across layers by exploiting high similarity between adjacent layers, reducing memory footprint and enhancing inference throughput by up to 5× while maintaining near-lossless performance \[[3](http://arxiv.org/abs/2405.14366)\]. These approaches highlight the importance of optimizing KV cache management to improve the efficiency and scalability of LLM serving systems.

One crucial memory bottleneck for the deployment stems from the context window. It is commonly recognized that model weights are memory hungry; however, the size of key-value embedding stored during the generation process (KV cache) can easily surpass the model size. The enormous size of the KV cache puts constraints on the inference batch size, which is crucial for high throughput inference workload. Inspired by an interesting observation of the attention scores, we hypothesize the persistence of importance: only pivotal tokens, which had a substantial influence at one step, will significantly influence future generations. Based on our empirical verification and theoretical analysis around this hypothesis, we propose Scissorhands, a system that maintains the memory usage of the KV cache at a fixed budget without finetuning the model. In essence, Scissorhands manages the KV cache by storing the pivotal tokens with a higher probability. We validate that Scissorhands reduces the inference memory usage of the KV cache by up to 5X without compromising model quality. We further demonstrate that Scissorhands can be combined with 4-bit quantization, traditionally used to compress model weights, to achieve up to 20X compression.»

### <a id='category-llm-quantization-techniques'></a>LLM Quantization Techniques: 2 papers found.
The category "LLM Quantization Techniques" explores methods to reduce memory consumption and improve efficiency in large language models (LLMs) during inference, particularly focusing on KV cache activations. Existing quantization approaches struggle with maintaining accuracy at sub-4-bit precision, but recent work such as KVQuant introduces novel strategies like Per-Channel Key Quantization and Non-Uniform KV Cache Quantization to better match activation distributions \[[9](http://arxiv.org/abs/2401.18079)\]. Similarly, WKVQuant proposes PTQ frameworks that incorporate past-only quantization and two-dimensional quantization strategies to enhance attention computation and handle KV cache distributions effectively \[[10](http://arxiv.org/abs/2402.12065)\]. These methods aim to achieve significant memory savings while preserving model performance, as demonstrated by experiments showing minimal perplexity degradation with 3-bit quantization \[[9](http://arxiv.org/abs/2401.18079)\]. Custom CUDA kernels further enhance the efficiency of these techniques, enabling faster inference on large models like LLaMA-7B \[[9](http://arxiv.org/abs/2401.18079)\].
