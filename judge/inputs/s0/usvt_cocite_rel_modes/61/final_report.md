## Related Works

Personalized outfit generation has gained significant attention in recent years due to its potential to enhance user experience in fashion recommendation systems. Prior work has primarily focused on two aspects: outfit compatibility and personalization. Early approaches relied on rule-based systems or simple similarity metrics to recommend compatible fashion items \[[1](http://arxiv.org/abs/1905.01866)\]. However, these methods lacked the ability to capture complex style relationships and user preferences. 

Recent advances in deep learning have enabled more sophisticated models for outfit generation and recommendation. For instance, POG \[[1](http://arxiv.org/abs/1905.01866)\] introduces a Transformer-based model that connects user preferences with outfit generation, improving both compatibility and personalization. Similarly, the work by \[[2](http://arxiv.org/abs/1608.03016)\] proposes a multimodal deep learning system to score outfit candidates based on appearance and metadata, leveraging popularity to supervise the scoring process. These models demonstrate the importance of incorporating both visual and semantic information to enhance recommendation accuracy.

The concept of style extraction and its role in outfit generation has also been explored. \[[3](http://arxiv.org/abs/1807.03133)\] introduces a model that incorporates an unsupervised style extraction module to learn global information from outfits, enabling more flexible and interpretable outfit generation. This approach is particularly useful for generating outfits that align with user preferences while maintaining visual coherence. 

Compatibility between fashion items remains a critical challenge, especially when considering different item types and their stylistic relationships. \[[4](http://arxiv.org/abs/1803.09196)\] presents a method to learn type-aware embeddings that respect item type and jointly model similarity and compatibility. This work improves upon existing methods by achieving better performance in outfit compatibility prediction and fill-in-the-blank tasks. 

In addition to compatibility, the ability to generate visually appealing and personalized outfits has been a key focus. \[[5](http://arxiv.org/abs/1711.02231)\] proposes a generative image model that learns fashion-aware image representations directly, enabling the system to generate new clothing items that align with a user's personal taste. This approach not only improves recommendation accuracy but also allows for creative design and style suggestion. 

Another important aspect is the automatic creation of capsule wardrobes, which involves selecting a minimal set of items that can be mixed and matched to form various outfits. \[[6](http://arxiv.org/abs/1712.02662)\] addresses this by developing submodular objective functions that capture visual compatibility, versatility, and user preferences. This work demonstrates the potential of automated capsule creation to mimic skilled fashionistas while being more scalable.

### <a id='category-fashion-recommendation-research'></a>Fashion Recommendation Research: 13 papers found.
The related works in fashion recommendation research focus on addressing the challenges of compatibility and personalization in outfit generation and recommendation. Early works, such as the Personalized Outfit Generation (POG) model, introduced a Transformer-based approach to connect user preferences with outfit generation, leveraging large-scale user behavior data \[[1](http://arxiv.org/abs/1905.01866)\]. Similarly, the automatic composition system proposed in another study used multimodal deep learning to score outfit candidates based on popularity and aesthetics, achieving an AUC of 85% \[[2](http://arxiv.org/abs/1608.03016)\]. The importance of compatibility between items was further emphasized in studies that developed image embeddings to capture both item similarity and compatibility, improving performance on outfit compatibility prediction tasks \[[3](http://arxiv.org/abs/1807.03133)\]. Additionally, research on capsule wardrobes explored submodular optimization to maximize mix-and-match potential while maintaining visual compatibility \[[4](http://arxiv.org/abs/1803.09196)\]. The integration of domain knowledge with deep learning models, such as the neural compatibility modeling scheme with attentive knowledge distillation, also demonstrated significant improvements over existing methods \[[6](http://arxiv.org/abs/1712.02662)\]. Furthermore, the use of co-occurrence data from user behavior, such as Amazon co-purchase data, enabled the learning of cross-category compatibility, leading to more effective outfit recommendations \[[7](http://arxiv.org/abs/1904.00741)\]. These approaches collectively highlight the growing emphasis on combining user preferences, compatibility metrics, and scalable learning methods to enhance personalized fashion recommendations.

In the realm of fashion outfit generation and recommendation, recent studies have focused on improving the flexibility and interpretability of outfit generation models. One approach involves incorporating an unsupervised style extraction module to learn global style information from outfits, enabling more flexible and style-aware generation without requiring additional input \[[3](http://arxiv.org/abs/1807.03133)\]. This method has shown effectiveness in tasks such as missing item prediction and style extraction, where the model can generate outfits that align with specific style preferences \[[3](http://arxiv.org/abs/1807.03133)\]. Another line of research emphasizes the importance of color and compatibility in fashion recommendations, utilizing siamese networks for feature extraction and fully-connected networks to learn compatibility metrics, with color histogram features enhancing the model's ability to capture visual compatibility \[[21](http://arxiv.org/abs/1905.03703)\]. These approaches highlight the growing interest in leveraging both global style information and local compatibility metrics to improve the personalization and realism of generated outfits.

[Snippet]: «With the rapid growth of online fashion market, demand for effective fashion recommendation systems has never been greater. In fashion recommendation, the ability to find items that goes well with a few other items based on style is more important than picking a single item based on the user's entire purchase history. Since the same user may have purchased dress suits in one month and casual denims in another, it is impossible to learn the latent style features of those items using only the user ratings. If we were able to represent the style features of fashion items in a reasonable way, we will be able to recommend new items that conform to some small subset of pre-purchased items that make up a coherent style set. We propose Style2Vec, a vector representation model for fashion items. Based on the intuition of distributional semantics used in word embeddings, Style2Vec learns the representation of a fashion item using other items in matching outfits as context. Two different convolutional neural networks are trained to maximize the probability of item co-occurrences. For evaluation, a fashion analogy test is conducted to show that the resulting representation connotes diverse fashion related semantics like shapes, colors, patterns and even latent styles. We also perform style classification using Style2Vec features and show that our method outperforms other baselines.»
