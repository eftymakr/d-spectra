## Related Works

Semi-supervised learning (SSL) has emerged as a powerful paradigm for improving model performance when labeled data is scarce. Traditional SSL methods assume that labeled and unlabeled data share the same class distribution \[[1](https://www.semanticscholar.org/paper/f3df804a7eef204b0c4fc4b81166dec9b4abc073)\]. However, this assumption is often violated in practice, as unlabeled data may contain out-of-distribution (OOD) samples, i.e., outliers \[[2](http://arxiv.org/abs/2007.11330)\]. These outliers are typically treated as noise, leading to significant performance degradation \[[3](http://arxiv.org/abs/2105.14148)\]. To address this limitation, numerous approaches have been proposed to handle open-set SSL, where the presence of OOD samples is explicitly considered \[[4](http://arxiv.org/abs/2001.07685)\].

One line of work focuses on filtering OOD samples before applying SSL. For instance, \[[5](http://arxiv.org/abs/2108.05617)\] introduces a method that detects OOD samples in unlabeled data by estimating the probability of a sample belonging to OOD. This approach uses a joint optimization framework that alternates between updating network parameters and OOD scores. Similarly, \[[6](https://www.semanticscholar.org/paper/9e4376e0572de32236e408469ffb2173d89eaab5)\] proposes a multi-task curriculum learning framework that detects OOD samples and trains a classifier on in-distribution (ID) data simultaneously. Another approach, \[[7](http://arxiv.org/abs/1905.02249)\], leverages cross-modal matching to detect OOD samples by training the network to predict whether a data sample matches an assigned one-hot class label, generating a compatible feature space aligned with the core classification task.

Another line of work focuses on improving SSL performance by incorporating OOD data in a controlled manner. \[[8](http://arxiv.org/abs/2107.08943)\] proposes OpenMatch, which unifies FixMatch with novelty detection based on one-vs-all (OVA) classifiers. The OVA classifier outputs confidence scores for inlier detection, providing a threshold to detect outliers. Additionally, \[[9](http://arxiv.org/abs/2308.13168)\] introduces an open-set soft-consistency regularization loss that enhances the smoothness of the OVA classifier with respect to input transformations, improving outlier detection. \[[10](http://arxiv.org/abs/2102.03526)\] further explores the use of OOD data by proposing a warm-up training phase that leverages all unlabeled data, including both ID and OOD samples, to learn more discriminative features.

To address the issue of unreliable outlier detection when labeled data is scarce, \[[11](http://arxiv.org/abs/2205.07246)\] introduces IOMatch, a framework that jointly utilizes inliers and outliers. It employs a multi-binary classifier in combination with a standard closed-set classifier to produce unified open-set classification targets, treating all outliers as a single new class. This approach allows the model to optimize an open-set classifier using all unlabeled samples, including both inliers and outliers.

### <a id='category-open-set-semi-supervised-learning'></a>Open Set Semi Supervised Learning: 10 papers found.
In the context of open-set semi-supervised learning, existing methods often assume that unlabeled data shares the same class distribution as labeled data, which is frequently violated in real-world scenarios where unlabeled data may contain out-of-distribution (OOD) samples \[[1](https://www.semanticscholar.org/paper/f3df804a7eef204b0c4fc4b81166dec9b4abc073)\]. These OOD samples, often treated as noise, can significantly degrade model performance \[[2](http://arxiv.org/abs/2007.11330)\]. To address this, several approaches have been proposed, such as Uncertainty-Aware Self-Distillation (UASD), which introduces a unified framework for joint self-distillation and OOD filtering to avoid error propagation \[[1](https://www.semanticscholar.org/paper/f3df804a7eef204b0c4fc4b81166dec9b4abc073)\]. Similarly, OpenMatch combines FixMatch with novelty detection using one-vs-all classifiers to identify inliers and reject outliers \[[3](http://arxiv.org/abs/2105.14148)\]. Other methods, like ORCA, introduce an uncertainty adaptive margin mechanism to handle novel classes during training \[[10](http://arxiv.org/abs/2102.03526)\]. Additionally, methods such as SSB utilize non-linear transformations to separate features for inlier classification and outlier detection, while pseudo-negative mining further improves outlier detection \[[15](http://arxiv.org/abs/2311.10572)\]. The Cross-modal Matching strategy proposed in another work also aims to generate a compatible feature space that aligns with the core classification task, improving performance on open-set SSL \[[5](http://arxiv.org/abs/2108.05617)\]. These approaches highlight the growing interest in handling open-set scenarios by leveraging OOD data effectively while mitigating their adverse effects \[[26](http://arxiv.org/abs/2301.06010)\].

### <a id='category-semi-supervised-learning-methods'></a>Semi-Supervised Learning Methods: 13 papers found.
The category "Semi-Supervised Learning Methods" encompasses a variety of approaches aimed at improving model performance by leveraging both labeled and unlabeled data. Key techniques include consistency regularization, pseudo-labeling, and self-ensembling, which are used to enhance the robustness of models in scenarios with limited labeled data \[[12](http://arxiv.org/abs/1610.02242)\]. For instance, FixMatch employs pseudo-labeling combined with consistency regularization, generating high-confidence predictions on weakly-augmented unlabeled data and training the model to match these predictions on strongly-augmented versions \[[1](https://www.semanticscholar.org/paper/f3df804a7eef204b0c4fc4b81166dec9b4abc073)\]. Similarly, MixMatch extends this idea by incorporating data mixing (MixUp) and low-entropy label guessing, achieving significant improvements across multiple benchmarks \[[7](http://arxiv.org/abs/1905.02249)\]. FreeMatch further refines threshold selection for pseudo-labeling, adapting thresholds dynamically based on the model's learning progress, which leads to better performance, especially in cases with extremely rare labeled data \[[11](http://arxiv.org/abs/2205.07246)\]. Additionally, methods like Dash focus on adaptive selection of unlabeled data by dynamically adjusting thresholds based on loss values, ensuring that only relevant examples contribute to training \[[13](http://arxiv.org/abs/2109.00650)\]. Self-ensembling methods, such as those used in the SVHN and CIFAR-10 benchmarks, form consensus predictions across different training epochs and augmentation conditions, leading to improved accuracy \[[12](http://arxiv.org/abs/1610.02242)\]. Curriculum Pseudo Labeling (CPL) builds upon FixMatch by introducing class-specific threshold adjustments, enhancing performance when labeled data is scarce \[[17](http://arxiv.org/abs/2110.08263)\]. The use of advanced data augmentation techniques, such as RandAugment, has also been shown to improve the quality of pseudo-labels and overall model performance \[[18](http://arxiv.org/abs/1904.12848)\]. These methods collectively highlight the importance of adaptive strategies, dynamic thresholding, and effective utilization of unlabeled data to enhance semi-supervised learning outcomes.

### <a id='category-semisupervised-learning-methods'></a>SemiSupervised Learning Methods: 3 papers found.
In the realm of semi-supervised learning (SSL), recent research has focused on addressing the challenges posed by unlabeled data containing unseen-class outliers, a common issue in open-world scenarios \[[6](https://www.semanticscholar.org/paper/9e4376e0572de32236e408469ffb2173d89eaab5)\]. Traditional SSL methods assume that unlabeled data follows the same class distribution as labeled data, but this assumption is often violated in practice, leading to performance degradation \[[6](https://www.semanticscholar.org/paper/9e4376e0572de32236e408469ffb2173d89eaab5)\]. To mitigate this, several approaches have been proposed, such as SAFE<bold>R</bold>-STUDENT, which introduces a teacher-student framework to identify and filter out unseen-class instances while improving seen-class classification \[[6](https://www.semanticscholar.org/paper/9e4376e0572de32236e408469ffb2173d89eaab5)\]. Similarly, IOMatch tackles the open-set SSL problem by jointly utilizing inliers and outliers, even when distinguishing between them is difficult, through a multi-binary classifier combined with a closed-set classifier \[[9](http://arxiv.org/abs/2308.13168)\]. Another approach, OOD Semantic Pruning (OSP), addresses the issue of corrupted semantic information by pruning out-of-distribution (OOD) semantics from in-distribution (ID) features, enhancing both OOD detection and ID classification \[[30](http://arxiv.org/abs/2305.18158)\]. These methods highlight the ongoing efforts to improve robustness in SSL by effectively handling unlabeled data with potential outliers, ensuring better generalization and performance in real-world applications.
