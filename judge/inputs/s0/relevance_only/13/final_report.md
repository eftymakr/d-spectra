## Related Works

Long-tailed recognition remains a challenging problem in computer vision due to the significant imbalance in class distribution, where a few dominant classes (head classes) dominate the dataset, while many rare classes (tail classes) contain only a few samples \[[1](http://arxiv.org/abs/2312.01753)\]. This imbalance leads to biased feature learning and poor generalization on tail classes \[[17](http://arxiv.org/abs/1910.09217)\]. Several approaches have been proposed to address this issue, primarily focusing on data augmentation, loss reweighting, and contrastive learning strategies \[[20](http://arxiv.org/abs/2110.04596)\].

Contrastive learning has shown promising results in representation learning by pulling positive samples together and pushing negative samples apart \[[1](http://arxiv.org/abs/2312.01753)\]. However, in long-tailed scenarios, supervised contrastive learning (SCL) tends to bias toward high-frequency classes, exacerbating the imbalance \[[10](http://arxiv.org/abs/2107.12028)\]. This bias is attributed to imbalanced attraction and repulsion gradients between positive and negative pairs, which hinder the model's ability to generalize to tail classes \[[1](http://arxiv.org/abs/2312.01753)\]. To address this, researchers have proposed various modifications, such as decoupling the training objectives for head and tail classes \[[2](http://arxiv.org/abs/2403.06151)\], introducing class frequency-based loss balancing \[[1](http://arxiv.org/abs/2312.01753)\], and enforcing uniformity in feature space distribution \[[13](http://arxiv.org/abs/2111.13998)\].

One approach, Rebalanced Contrastive Learning (RCL), aims to improve feature space balancedness, intra-class compactness, and regularization for tail classes by adjusting the supervised contrastive loss based on class frequency \[[1](http://arxiv.org/abs/2312.01753)\]. Similarly, Decoupled Contrastive Learning (DCL) decouples the training of positive samples to alleviate the influence of class imbalance \[[2](http://arxiv.org/abs/2403.06151)\]. These methods attempt to balance the learning process by adjusting how positive and negative samples are treated during training.

Another line of research focuses on improving the representation of tail classes through specialized loss functions and data augmentation. For instance, the Equalization Loss \[[18](http://arxiv.org/abs/2210.05566)\] introduces a gradient-driven mechanism to rebalance the positive/negative gradients dynamically, improving performance on long-tailed tasks. This was further refined in Equalization Loss v2 \[[21](http://arxiv.org/abs/2012.08548)\], which outperforms previous methods by achieving better gradient balance and improving performance on rare categories.

Additionally, methods such as Subclass-Balancing Contrastive Learning (SBCL) \[[3](http://arxiv.org/abs/2306.15925)\] and Long-Tail Augmented Graph Contrastive Learning (LAGCL) \[[4](http://arxiv.org/abs/2309.11177)\] address the imbalance by clustering head classes into subclasses or enhancing tail nodes through augmentation. These approaches aim to capture richer semantic structures and improve the representation of underrepresented classes.

### <a id='category-contrastive-learning-in-imbalanced-datasets'></a>Contrastive Learning in Imbalanced Datasets: 15 papers found.
Contrastive learning has emerged as a powerful paradigm for representation learning, particularly in addressing the challenges posed by long-tailed datasets \[[1](http://arxiv.org/abs/2312.01753)\]. However, traditional contrastive learning methods often struggle with class imbalance, as they tend to favor majority classes and neglect the underrepresented tail classes \[[2](http://arxiv.org/abs/2403.06151)\]. This issue is exacerbated by the inherent bias in supervised contrastive loss (SCL), which does not account for class distribution during training \[[4](http://arxiv.org/abs/2309.11177)\]. To mitigate these challenges, several approaches have been proposed, such as Rebalanced Contrastive Learning (RCL), which introduces feature space balancedness, intra-class compactness, and regularization to improve performance on imbalanced data \[[1](http://arxiv.org/abs/2312.01753)\]. Similarly, the Balanced Contrastive Learning (BCL) framework addresses the failure of SCL to form a regular simplex in long-tailed data by incorporating class-averaging and class-complement strategies \[[5](https://www.semanticscholar.org/paper/4de2921b4ddda8abaa657da7d1742ca52a430968)\]. Additionally, methods like Parametric Contrastive Learning (PaCo) introduce learnable class-wise centers to rebalance the optimization process \[[8](http://arxiv.org/abs/2110.10048)\], while Targeted Supervised Contrastive Learning (TSC) ensures uniform distribution of features across the hypersphere to improve class separability \[[10](http://arxiv.org/abs/2107.12028)\]. These approaches highlight the ongoing efforts to enhance contrastive learning for long-tailed recognition by addressing issues such as gradient conflicts, imbalanced attraction and repulsion, and poor generalization on tail classes \[[1](http://arxiv.org/abs/2312.01753)\].

### <a id='category-long-tailed-recognition-challenges'></a>Long-tailed Recognition Challenges: 3 papers found.
The long-tailed recognition problem, where a few dominant classes have abundant samples while most tail classes are severely underrepresented, poses significant challenges for model generalization and fairness \[[1](http://arxiv.org/abs/2312.01753)\]. This issue is exacerbated by the fact that models trained on imbalanced datasets tend to converge to a bounded neighborhood of the head class weights, with the bound scaling inversely with the square root of the imbalance factor \[[1](http://arxiv.org/abs/2312.01753)\]. To address this, researchers have proposed various strategies, including class re-balancing, information augmentation, and module improvement, which aim to mitigate the bias toward dominant classes and enhance performance on tail classes \[[2](http://arxiv.org/abs/2403.06151)\]. Recent approaches, such as reflecting learning, integrate mechanisms for reviewing past predictions, summarizing feature relations, and correcting gradient conflicts to improve learning from imbalanced data \[[3](http://arxiv.org/abs/2306.15925)\]. These methods are often designed to be lightweight and compatible with existing long-tailed learning frameworks, enabling seamless integration and performance improvements across multiple benchmarks \[[3](http://arxiv.org/abs/2306.15925)\]. Theoretical insights into the connection between long-tailed recognition and continual learning have further informed the development of principled approaches like CLTR, which leverages standard continual learning methods to sequentially learn head and tail classes without forgetting prior knowledge \[[1](http://arxiv.org/abs/2312.01753)\]. These efforts highlight the ongoing research into addressing the long-tailed recognition challenge through both theoretical analysis and practical algorithmic innovations.
