## Related Works

Recent advancements in table retrieval have focused on leveraging deep learning techniques to improve the accuracy and efficiency of identifying relevant tables based on natural language queries. Traditional approaches often rely on a representation-index-search pipeline, where tables are represented as dense vectors, indexed, and then searched using these vectors \[[14](http://arxiv.org/abs/2105.06365)\]. However, these methods face significant limitations, including error accumulation during the indexing phase and insufficient interaction between queries and tables, which hinders semantic alignment \[[1](http://arxiv.org/abs/2005.09207)\]. 

Several studies have explored alternative approaches to address these limitations. For instance, \[[14](http://arxiv.org/abs/2105.06365)\] introduced a semantic table retrieval framework that represents queries and tables in multiple semantic spaces and uses various similarity measures to improve matching. This work demonstrated significant improvements over existing baselines by incorporating both discrete and continuous vector representations \[[14](http://arxiv.org/abs/2105.06365)\]. Similarly, \[[15](http://arxiv.org/abs/1802.06159)\] proposed a method for semantic matching between queries and tables, which also considered multiple semantic spaces and similarity measures, leading to better performance on Wikipedia-based test collections \[[15](http://arxiv.org/abs/1802.06159)\].

The Differentiable Search Index (DSI) has emerged as a promising paradigm that unifies indexing and retrieval into a single model, enabling more direct and efficient query-to-table mapping \[[5](http://arxiv.org/abs/2206.10128)\]. DSI models encode all documents into the model parameters and use a sequence-to-sequence architecture to directly map queries to relevant document identifiers \[[5](http://arxiv.org/abs/2206.10128)\]. However, early DSI implementations faced challenges in distinguishing relevant documents from random ones, which affected retrieval effectiveness \[[2](http://arxiv.org/abs/2305.02073)\]. To address this, researchers proposed multi-task distillation approaches to enhance retrieval quality without altering the model structure \[[2](http://arxiv.org/abs/2305.02073)\]. Additionally, the DSI-QG framework was introduced to mitigate data distribution mismatches by generating relevant queries during indexing \[[5](http://arxiv.org/abs/2206.10128)\].

In the context of dynamic table indexing, the IncDSI model enables real-time updates to the retrieval system without retraining the entire model, allowing for incremental addition of new documents \[[7](http://arxiv.org/abs/2307.10323)\]. This is particularly important for applications where the corpus evolves over time. Furthermore, the De-DSI framework introduces a decentralized approach that leverages large language models and distributes computational complexity across a network, enabling efficient query-document identifier matching without direct document access \[[6](http://arxiv.org/abs/2404.12237)\].

To further enhance diversity in retrieval results, the Inducing Diversity in DSI work explored balancing relevance and diversity using Maximal Marginal Relevance (MMR) principles, showing that diversity can be achieved without significant impact on relevance \[[8](http://arxiv.org/abs/2502.02788)\]. This is crucial for applications requiring both relevant and diverse results, such as sub-topic retrieval.

### <a id='category-differentiable-search-index-(dsi)-approaches'></a>Differentiable Search Index (DSI) Approaches: 7 papers found.
Differentiable Search Index (DSI) approaches have emerged as a novel paradigm in information retrieval, aiming to unify indexing and retrieval into a single neural model \[[1](http://arxiv.org/abs/2005.09207)\]. Unlike traditional systems that separate index construction and query processing, DSI models encode document identifiers and semantic relationships directly within their parameters, enabling end-to-end query-to-document mapping \[[2](http://arxiv.org/abs/2305.02073)\]. However, early DSI implementations faced challenges in distinguishing relevant documents from random ones, limiting retrieval effectiveness \[[1](http://arxiv.org/abs/2005.09207)\]. To address this, researchers proposed multi-task distillation techniques to enhance retrieval quality without altering model structure \[[1](http://arxiv.org/abs/2005.09207)\]. Additionally, the issue of data distribution mismatch between indexing (long documents) and retrieval (short queries) was identified, leading to the development of DSI-QG, which generates relevant queries during indexing to improve alignment \[[3](http://arxiv.org/abs/2504.15849)\]. Furthermore, the inability to incrementally update DSI models without retraining was a significant limitation, which was tackled by IncDSI, a method enabling real-time document addition with minimal parameter changes \[[4](http://arxiv.org/abs/2305.15115)\]. Recent work has also focused on balancing relevance and diversity in retrieval, inspired by Maximal Marginal Relevance (MMR), demonstrating that DSI can be trained to produce diverse yet relevant results without post-processing \[[5](http://arxiv.org/abs/2206.10128)\]. These advancements highlight the evolving capabilities of DSI, addressing key limitations in scalability, updateability, and semantic alignment.

[Snippet]: «This study introduces De-DSI, a novel framework that fuses large language models (LLMs) with genuine decentralization for information retrieval, particularly employing the differentiable search index (DSI) concept in a decentralized setting. Focused on efficiently connecting novel user queries with document identifiers without direct document access, De-DSI operates solely on query-docid pairs. To enhance scalability, an ensemble of DSI models is introduced, where the dataset is partitioned into smaller shards for individual model training. This approach not only maintains accuracy by reducing the number of data each model needs to handle but also facilitates scalability by aggregating outcomes from multiple models. This aggregation uses a beam search to identify top docids and applies a softmax function for score normalization, selecting documents with the highest scores for retrieval. The decentralized implementation demonstrates that retrieval success is comparable to centralized methods, with the added benefit of the possibility of distributing computational complexity across the network. This setup also allows for the retrieval of multimedia items through magnet links, eliminating the need for platforms or intermediaries.»
