## Related Works

Deploying large language models (LLMs) on edge devices presents significant challenges due to limited storage, power, and computational resources \[[3](https://www.semanticscholar.org/paper/ec93fc7ec82c65a7bf7213488327d391014539ed)\]. Prior research has focused on reducing model size, improving inference efficiency, and optimizing hardware-software co-design to enable feasible deployment \[[3](https://www.semanticscholar.org/paper/ec93fc7ec82c65a7bf7213488327d391014539ed)\]\[[12](http://arxiv.org/abs/2409.03384)\]. For instance, quantization techniques such as W2A8KV4 have been proposed to reduce memory and bandwidth usage while maintaining performance \[[1](http://arxiv.org/abs/2505.03745)\]. Similarly, activation-aware weight quantization (AWQ) enables on-device LLM compression and acceleration by preserving critical weights based on activation patterns \[[19](http://arxiv.org/abs/2306.00978)\]. These methods are essential for reducing the computational footprint of LLMs on resource-constrained edge devices.

Efforts to optimize inference speed and memory usage have also led to the development of specialized hardware accelerators. FPGA-based accelerators, such as those in the AccLLM framework, offer reconfigurable computing engines that can adapt to algorithmic optimizations like pruning and quantization \[[1](http://arxiv.org/abs/2505.03745)\]. Additionally, the SECDA-LLM platform streamlines the design of FPGA-based accelerators for LLM inference, demonstrating significant improvements in latency and throughput \[[4](http://arxiv.org/abs/2408.00462)\]. These hardware solutions are crucial for achieving the high performance required for real-time applications on edge devices.

KV cache management has emerged as a key optimization technique for improving memory utilization and reducing redundant computations during LLM inference \[[14](http://arxiv.org/abs/2412.19442)\]. Techniques such as PagedAttention and efficient KV cache sharing help minimize memory fragmentation and enable higher throughput by managing dynamic memory allocation \[[13](http://arxiv.org/abs/2309.06180)\]. These methods are particularly important for handling long-context sequences and maintaining high inference speeds on edge devices.

Moreover, the deployment of LLMs on edge devices often requires lightweight models that can operate with minimal resources. Small Language Models (SLMs) have been developed to address this need, offering efficient performance with reduced computational requirements \[[22](http://arxiv.org/abs/2410.20011)\]. Techniques such as model compression, pruning, and quantization are commonly used to achieve this efficiency \[[6](http://arxiv.org/abs/2404.14294)\]\[[22](http://arxiv.org/abs/2410.20011)\]. These approaches are vital for enabling LLM deployment on edge devices where hardware resources are limited.

Recent work has also explored the use of hardware-aware evolutionary search to design efficient hybrid networks for edge devices \[[15](http://arxiv.org/abs/2408.15395)\]. This approach enables the creation of architectures that are optimized for specific hardware constraints, leading to improved performance and reduced latency. Additionally, the integration of sparsity-aware techniques, such as activation sparsity, has shown promise in reducing memory and computational demands while maintaining model accuracy \[[10](http://arxiv.org/abs/2412.12178)\].

### <a id='category-fpga-based-accelerator-design'></a>FPGA-Based Accelerator Design: 3 papers found.
FPGA-based accelerators have emerged as a promising solution for deploying large language models (LLMs) on resource-constrained edge devices, addressing challenges such as high computational demands and memory limitations \[[1](http://arxiv.org/abs/2505.03745)\]. Researchers have proposed frameworks like AccLLM, which integrate algorithmic optimizations such as pruning, $\Lambda$-shaped attention, and W2A8KV4 quantization to reduce memory and bandwidth usage while enabling efficient long-sequence generation \[[1](http://arxiv.org/abs/2505.03745)\]. These algorithmic innovations are complemented by hardware-level designs, such as FPGA-based accelerators with reconfigurable computing engines (RCEs), which provide flexibility and performance improvements \[[1](http://arxiv.org/abs/2505.03745)\]. Additionally, platforms like SECDA-LLM have been introduced to streamline the design and deployment of FPGA accelerators for LLMs, leveraging block floating point quantization and model-specific optimizations to enhance efficiency \[[2](http://arxiv.org/abs/2312.11514)\]. Furthermore, co-design methodologies that combine FPGA and deep neural network (DNN) design have been explored to improve accuracy, throughput, and energy efficiency, demonstrating significant improvements in metrics such as Intersection-over-Union (IoU), frames per second (FPS), and power consumption \[[3](https://www.semanticscholar.org/paper/ec93fc7ec82c65a7bf7213488327d391014539ed)\]. These advancements highlight the growing focus on FPGA-based solutions for LLM inference, emphasizing their potential to balance performance, energy efficiency, and adaptability in edge computing environments.

### <a id='category-hardware-accelerated-inference'></a>Hardware-Accelerated Inference: 7 papers found.
Hardware-accelerated inference for large language models (LLMs) has been a focal point of recent research, addressing the computational and memory constraints of deploying LLMs on edge devices \[[1](http://arxiv.org/abs/2505.03745)\]. Key challenges include the high memory footprint of LLMs and the need for efficient data transfer between flash and DRAM \[[1](http://arxiv.org/abs/2505.03745)\]. To mitigate these issues, researchers have proposed techniques such as "windowing" and "row-column bundling," which reduce data transfer and improve data chunk sizes for flash memory \[[1](http://arxiv.org/abs/2505.03745)\]. These methods enable running models up to twice the size of available DRAM and significantly boost inference speed, with improvements of 4–5x on CPU and 20–25x on GPU \[[1](http://arxiv.org/abs/2505.03745)\]. Additionally, the integration of sparsity awareness and context-adaptive loading further enhances performance \[[1](http://arxiv.org/abs/2505.03745)\]. Beyond hardware-specific optimizations, studies have surveyed efficient inference methods across various platforms, including CPU, GPU, FPGA, and ASIC, highlighting the importance of hardware-software co-design \[[2](http://arxiv.org/abs/2312.11514)\]. These surveys also emphasize the role of hardware characteristics in improving inference performance and energy efficiency \[[2](http://arxiv.org/abs/2312.11514)\]. Furthermore, the development of specialized accelerators, such as the 28nm hardware accelerator used in CLONE, demonstrates the potential for tailored solutions to enhance both speed and energy efficiency \[[6](http://arxiv.org/abs/2404.14294)\]. Overall, the field is advancing through a combination of algorithmic improvements, hardware innovations, and system-level optimizations \[[3](https://www.semanticscholar.org/paper/ec93fc7ec82c65a7bf7213488327d391014539ed)\].

Additionally, Activation-aware Weight Quantization (AWQ) has emerged as a novel approach, reducing model size while preserving performance by leveraging activation distribution to identify and protect salient weights \[[4](http://arxiv.org/abs/2408.00462)\]. These methods collectively highlight the growing emphasis on algorithm-hardware co-design to achieve efficient on-device LLM deployment \[[1](http://arxiv.org/abs/2505.03745)\].

However, existing systems struggle because the key-value cache (KV cache) memory for each request is huge and grows and shrinks dynamically.
