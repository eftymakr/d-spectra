## Related Works

Vision Transformers (ViTs) have gained significant attention for their ability to capture global context through self-attention mechanisms, leading to strong performance in computer vision tasks \[[15](http://arxiv.org/abs/2205.11397)\]. However, the high computational complexity and memory demands of ViTs pose challenges for efficient hardware acceleration, particularly on resource-constrained devices \[[18](http://arxiv.org/abs/2503.02891)\]. Existing approaches often rely on CPU-based execution for complex operations like Softmax and LayerNorm, which are sensitive to model accuracy and difficult to map onto low-precision hardware \[[1](https://www.semanticscholar.org/paper/0ade4d722e48379761d17cf1efc05200315c27d9)\]. This results in suboptimal performance due to communication overhead between the CPU and accelerator \[[1](https://www.semanticscholar.org/paper/0ade4d722e48379761d17cf1efc05200315c27d9)\].

Several works have explored hardware acceleration for ViTs. HDViT introduces a heterogeneous FPGA accelerator that addresses the mismatch between operators and hardware architectures, achieving significant performance improvements \[[1](https://www.semanticscholar.org/paper/0ade4d722e48379761d17cf1efc05200315c27d9)\]. Auto-ViT-Acc proposes an FPGA-aware automatic acceleration framework with mixed-scheme quantization, achieving up to 5.6x speedup on frame rate with minimal accuracy drop \[[2](http://arxiv.org/abs/2208.05163)\]. HeatViT introduces hardware-efficient adaptive token pruning, reducing computation by up to 65.3% while maintaining high accuracy \[[3](http://arxiv.org/abs/2211.08110)\]. ME-ViT focuses on minimizing memory traffic through a single-load policy, achieving up to 17.89x improvement in memory bandwidth \[[5](http://arxiv.org/abs/2402.09709)\]. ReViT leverages hierarchical visual semantics to accelerate ViTs, achieving 2.3x speedup and 3.6x energy efficiency \[[6](https://www.semanticscholar.org/paper/f47b726ad00e1a93adc5b3e266c71d75bb05e1ff)\]. EfficientViT combines convolution and transformer modules for improved accuracy and hardware efficiency, but existing accelerators fail to fully exploit its benefits \[[7](http://arxiv.org/abs/2403.20230)\]. Trio-ViT eliminates Softmax and integrates low-complexity linear attention, achieving up to 7.3x speedup in FPS \[[9](http://arxiv.org/abs/2405.03882)\]. Q-ViT introduces a fully quantized ViT with an information rectification module, achieving 6.14x acceleration and 80.9% Top-1 accuracy \[[10](http://arxiv.org/abs/2210.06707)\]. CHOSEN provides a software-hardware co-design framework for ViT deployment on FPGAs, achieving 1.5x throughput improvement \[[11](http://arxiv.org/abs/2407.12736)\]. ViTA is a configurable accelerator for edge applications, achieving nearly 90% hardware utilization \[[12](http://arxiv.org/abs/2302.09108)\]. Accelerating ViT inference through static and dynamic pruning achieves up to 3.4x computation reduction with minimal accuracy drop \[[13](http://arxiv.org/abs/2403.14047)\]. ViTCoD proposes a dedicated algorithm and accelerator co-design framework, achieving up to 235.3x speedup over general computing platforms \[[14](http://arxiv.org/abs/2210.09573)\].
