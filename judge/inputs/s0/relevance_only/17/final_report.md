## Related Works

Semi-supervised learning (SSL) has been widely studied for its ability to leverage unlabeled data to improve model performance when labeled data is scarce \[[1](http://arxiv.org/abs/2311.10572)\]. However, conventional SSL methods assume that both labeled and unlabeled data share the same class distribution \[[2](http://arxiv.org/abs/2303.12091)\], which is often violated in real-world applications where unlabeled data may contain out-of-distribution (OOD) samples, i.e., outliers \[[3](http://arxiv.org/abs/2401.07551)\]. These outliers, often treated as noise, significantly degrade the performance of SSL models \[[4](http://arxiv.org/abs/2308.13168)\]. To address this challenge, various open-set SSL approaches have been proposed, aiming to detect and mitigate the negative impact of outliers \[[5](http://arxiv.org/abs/2412.18256)\].

Early methods, such as FixMatch \[[6](http://arxiv.org/abs/2105.14148)\], assume that unlabeled data are from the same distribution as labeled data, which limits their applicability in open-world scenarios \[[7](http://arxiv.org/abs/2109.00650)\]. To handle open-set scenarios, methods like OpenMatch \[[8](http://arxiv.org/abs/2107.08943)\] introduce novelty detection to distinguish inliers from outliers, while also incorporating soft-consistency regularization to improve outlier detection \[[9](http://arxiv.org/abs/2007.08844)\]. Similarly, IOMatch \[[10](http://arxiv.org/abs/2007.11330)\] proposes a framework that jointly utilizes inliers and outliers by combining a multi-binary classifier with a standard closed-set classifier, treating all outliers as a single new class \[[11](https://www.semanticscholar.org/paper/f3df804a7eef204b0c4fc4b81166dec9b4abc073)\]. This approach helps avoid the performance degradation caused by unreliable outlier detectors when labeled data is scarce \[[12](http://arxiv.org/abs/2203.02261)\].

Another line of research focuses on improving the robustness of SSL in the presence of class distribution mismatch \[[13](http://arxiv.org/abs/2308.11874)\]. For example, UASD \[[14](https://www.semanticscholar.org/paper/cfcdf167b3756735f230e72e4d2713bb063587b2)\] introduces uncertainty-aware self-distillation to avoid catastrophic error propagation and improve generalization under class distribution mismatch \[[15](http://arxiv.org/abs/2308.14119)\]. Similarly, WAD \[[16](http://arxiv.org/abs/2110.10368)\] proposes a framework that selectively transfers knowledge from unsupervised contrastive representations to the target classifier, using adaptive weights to filter unknown categories \[[17](https://www.semanticscholar.org/paper/9e4376e0572de32236e408469ffb2173d89eaab5)\]. These methods demonstrate that robust SSL is possible even when labeled and unlabeled data come from different distributions \[[18](http://arxiv.org/abs/2405.16093)\].

Additionally, methods such as OpenCoS \[[19](http://arxiv.org/abs/2405.06979)\] utilize contrastive learning to identify out-of-class samples in unlabeled data, enabling the use of both inlier and outlier data for training \[[20](http://arxiv.org/abs/2403.15567)\]. This approach helps overcome the failure modes of existing SSL methods by leveraging one-hot pseudo-labels for inliers and soft-labels for outliers \[[21](https://www.semanticscholar.org/paper/1c952a381a5175f9dd936435b8f1a2bd706c8ffb)\]. Similarly, SAFER-STUDENT \[[22](http://arxiv.org/abs/2306.17699)\] introduces a teacher-student framework that enhances the ability to identify seen and unseen classes, and calibrates the student model using newly proposed losses \[[23](http://arxiv.org/abs/2303.08978)\].

### <a id='category-open-set-ssl-methodologies'></a>Open-Set SSL Methodologies: 12 papers found.
Open-set semi-supervised learning (OSSL) addresses the challenge where unlabeled data may contain out-of-distribution (OOD) samples, which can degrade model performance \[[1](http://arxiv.org/abs/2311.10572)\]. Existing methods often assume that OOD data is harmful and aim to exclude it during training \[[11](https://www.semanticscholar.org/paper/f3df804a7eef204b0c4fc4b81166dec9b4abc073)\], while others employ separate modules for outlier detection \[[2](http://arxiv.org/abs/2303.12091)\]. For instance, the Adaptive Negative Evidential Deep Learning (ANEDL) framework introduces evidential deep learning to quantify uncertainty and designs adaptive negative optimization strategies to better handle unlabeled data with both inliers and outliers \[[2](http://arxiv.org/abs/2303.12091)\]. Similarly, the Simple but Strong Baseline (SSB) method improves inlier classification by incorporating high-confidence pseudo-labeled data and uses non-linear transformations to separate inlier and outlier features \[[1](http://arxiv.org/abs/2311.10572)\]. The IOMatch framework jointly utilizes inliers and outliers by introducing a multi-binary classifier and treating all outliers as a single class, thereby improving performance even with scarce labels \[[4](http://arxiv.org/abs/2308.13168)\]. The OpenMatch approach unifies FixMatch with novelty detection using one-vs-all classifiers to distinguish inliers from outliers \[[6](http://arxiv.org/abs/2105.14148)\]. Additionally, the WiseOpen framework proposes a data selection strategy to selectively leverage open-set data, reducing the negative impact of unfriendly samples \[[8](http://arxiv.org/abs/2107.08943)\]. These methods highlight the importance of handling OOD data effectively, either through outlier detection, pseudo-label refinement, or data selection strategies, to improve robustness in open-set SSL settings.

### <a id='category-uncertainty-aware-learning-techniques'></a>Uncertainty-Aware Learning Techniques: 5 papers found.
In the context of uncertainty-aware learning techniques, several approaches have been proposed to improve the robustness and performance of semi-supervised learning (SSL) in realistic scenarios. Existing SSL methods often assume that labeled and unlabeled data share the same class distribution, which is frequently violated in practice due to the presence of outliers or out-of-distribution (OOD) samples \[[2](http://arxiv.org/abs/2303.12091)\]. This assumption leads to severe performance degradation as irrelevant or incorrect pseudo-labels are used during training \[[1](http://arxiv.org/abs/2311.10572)\]. To address this, researchers have developed methods that focus on uncertainty-aware pseudo-labeling and selection of unlabeled data. For instance, Dash introduces a dynamic thresholding mechanism to filter pseudo-labels based on loss values, ensuring only high-quality examples are used for training \[[7](http://arxiv.org/abs/2109.00650)\]. Similarly, Uncertainty-Aware Self-Distillation (UASD) addresses class distribution mismatch by producing soft targets that reduce error propagation and enable effective learning from unlabeled data with OOD samples \[[11](https://www.semanticscholar.org/paper/f3df804a7eef204b0c4fc4b81166dec9b4abc073)\]. Another approach, proposed in \[[3](http://arxiv.org/abs/2401.07551)\], highlights the miscalibration issue in SSL methods and introduces a penalty term to prevent overconfidence in predictions, thereby improving calibration and discriminative power. Additionally, Active Semi-supervised Learning (ASSL) integrates active learning with SSL to enhance model performance while reducing the cost of labeling \[[23](http://arxiv.org/abs/2303.08978)\]. These methods collectively emphasize the importance of uncertainty estimation and robust pseudo-labeling in improving SSL performance under challenging conditions.

Additionally, methods such as the Suppressed Consistency Loss (SCL) focus on improving SSL performance in class-imbalanced settings by introducing regularization that is robust to class imbalance \[[5](http://arxiv.org/abs/2412.18256)\]. These approaches collectively emphasize the need for adaptive strategies that account for class distribution mismatches and enhance the robustness of SSL models in real-world applications.

### <a id='category-assumptions-of-conventional-ssl'></a>Assumptions of Conventional SSL: 2 papers found.
The assumption of identical class distribution between labeled and unlabeled data in conventional semi-supervised learning (SSL) is a common but often violated premise, as unlabeled data may contain outliers that are treated as noise, thereby degrading model performance \[[1](http://arxiv.org/abs/2311.10572)\]. This issue is particularly problematic in open-set scenarios where the presence of unknown classes is not accounted for \[[1](http://arxiv.org/abs/2311.10572)\]. Existing methods typically rely on prediction discrepancies between inliers and outliers from a single model trained on limited labeled data, which can lead to performance degradation when labeled data is insufficient \[[1](http://arxiv.org/abs/2311.10572)\]. In contrast, recent approaches such as PruneSSL propose modifying the unlabeled dataset to enhance separability by selectively removing examples, thereby improving SSL performance without relying on the assumption of identical class distribution \[[2](http://arxiv.org/abs/2303.12091)\]. Similarly, other works have explored the use of auxiliary classifiers to address class imbalance in SSL, introducing techniques like consistency regularization to ensure balanced class representation during training \[[1](http://arxiv.org/abs/2311.10572)\]. These methods highlight the limitations of conventional SSL assumptions and the need for more robust strategies that account for real-world data complexities.

### <a id='category-novelty-detection-and-consistency-regularization'></a>Novelty Detection and Consistency Regularization: 1 papers found.

[Snippet]: «Semi-Supervised Learning (SSL) has been an effective way to leverage abundant unlabeled data with extremely scarce labeled data. However, most SSL methods are commonly based on instance-wise consistency between different data transformations. Therefore, the label guidance on labeled data is hard to be propagated to unlabeled data. Consequently, the learning process on labeled data is much faster than on unlabeled data which is likely to fall into a local minima that does not favor unlabeled data, leading to sub-optimal generalization performance. In this paper, we propose FlatMatch which minimizes a cross-sharpness measure to ensure consistent learning performance between the two datasets. Specifically, we increase the empirical risk on labeled data to obtain a worst-case model which is a failure case that needs to be enhanced. Then, by leveraging the richness of unlabeled data, we penalize the prediction difference (i.e., cross-sharpness) between the worst-case model and the original model so that the learning direction is beneficial to generalization on unlabeled data. Therefore, we can calibrate the learning process without being limited to insufficient label information. As a result, the mismatched learning performance can be mitigated, further enabling the effective exploitation of unlabeled data and improving SSL performance. Through comprehensive validation, we show FlatMatch achieves state-of-the-art results in many SSL settings.»
