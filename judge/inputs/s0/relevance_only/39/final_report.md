## Related Works

De novo genome assembly is a fundamental challenge in computational genomics, requiring the reconstruction of genomic sequences from short, overlapping, and potentially erroneous DNA reads without a reference genome \[[1](http://arxiv.org/abs/1705.11147)\]. This process is computationally intensive, especially with the exponential growth of genomic data, necessitating scalable and high-performance approaches \[[3](http://arxiv.org/abs/2207.04350)\]. Traditional assemblers often face limitations in memory usage, computational efficiency, and handling complex data structures \[[5](https://www.semanticscholar.org/paper/c6e319a023f932d6d2ff8897c2c91e56e872db8e)\]. Several studies have explored distributed-memory parallel algorithms to address these challenges, such as HipMER \[[1](http://arxiv.org/abs/1705.11147)\], which utilizes efficient parallelization of the Meraculous code for extreme-scale analysis \[[1](http://arxiv.org/abs/1705.11147)\]. Similarly, PPA-assembler \[[2](http://arxiv.org/abs/1801.04453)\] employs the de Bruijn graph approach on the Pregel framework, achieving superior performance compared to existing assemblers \[[2](http://arxiv.org/abs/1801.04453)\]. 

The computational complexity of de novo assembly is further exacerbated by the need for handling large memory footprints and irregular data patterns \[[5](https://www.semanticscholar.org/paper/c6e319a023f932d6d2ff8897c2c91e56e872db8e)\]. SparseAssembler \[[11](http://arxiv.org/abs/1106.2603)\] and SparseAssembler2 \[[12](http://arxiv.org/abs/1108.3556)\] introduced sparse k-mer graphs to reduce memory consumption, with the latter achieving significant memory savings while maintaining robustness \[[12](http://arxiv.org/abs/1108.3556)\]. These approaches demonstrate that reducing memory usage is crucial for improving scalability and performance. Additionally, the use of quantum and quantum-inspired annealing techniques has been explored for solving genome assembly tasks \[[13](http://arxiv.org/abs/2004.06719)\], offering potential for future advancements in computational efficiency.

The importance of memory-efficient algorithms is further emphasized by the development of tools like SOAPdenovo2 \[[9](https://www.semanticscholar.org/paper/f8d1052e2c9d1cdd63093427ccc9169e848d777d)\], which improves upon earlier versions by reducing memory consumption and increasing coverage and length in scaffold construction \[[9](https://www.semanticscholar.org/paper/f8d1052e2c9d1cdd63093427ccc9169e848d777d)\]. Similarly, PASHA \[[16](https://www.semanticscholar.org/paper/7bf2f1c55f90e11a4d1df4dd608ac621a08f8b33)\] leverages hybrid computing architectures to enhance scalability and performance for large genomes \[[16](https://www.semanticscholar.org/paper/7bf2f1c55f90e11a4d1df4dd608ac621a08f8b33)\]. These tools highlight the ongoing efforts to optimize both software and hardware for genome assembly. 

Recent advancements in hardware-software co-design have also been proposed to address the computational bottlenecks in de novo assembly. For instance, the use of near-memory processing (NMP) architectures has been explored to mitigate memory bottlenecks and improve throughput \[[20](http://arxiv.org/abs/2309.07270)\]. These approaches demonstrate that custom hardware solutions can significantly enhance the performance of de novo assembly tasks.

In summary, the field of de novo genome assembly has seen significant advancements in both algorithmic and hardware design, with a focus on reducing memory usage, improving computational efficiency, and handling large-scale genomic data. These contributions form the foundation for the proposed NMP-PaK approach, which aims to further enhance scalability and performance through a hardware-software co-design \[[1](http://arxiv.org/abs/1705.11147)\]\[[2](http://arxiv.org/abs/1801.04453)\]\[[9](https://www.semanticscholar.org/paper/f8d1052e2c9d1cdd63093427ccc9169e848d777d)\][

### <a id='category-distributed-and-parallel-assemblers'></a>Distributed and Parallel Assemblers: 7 papers found.
Distributed and parallel assemblers have been developed to address the computational challenges of de novo genome assembly, particularly for large genomes. These assemblers leverage parallel computing frameworks and distributed memory architectures to improve scalability and performance. For instance, HipMER employs efficient parallelization of the Meraculous code to handle extreme-scale analysis, demonstrating performance on supercomputers with tens of thousands of cores \[[1](http://arxiv.org/abs/1705.11147)\]. Similarly, PPA-assembler utilizes the de Bruijn graph approach on Google's Pregel framework, achieving strong performance guarantees and superior results compared to existing assemblers \[[2](http://arxiv.org/abs/1801.04453)\]. The diBELLA 2D pipeline introduces new distributed-memory parallel algorithms for overlap detection and layout simplification, using linear-algebra operations over semirings with 2D sparse matrices, achieving near-linear scaling and significant runtime reductions \[[4](http://arxiv.org/abs/2011.05013)\]. SWAP-Assembler, based on a small-world asynchronous parallel model, scales up to 2048 cores, showing better performance than other assemblers like ABySS and Ray \[[5](https://www.semanticscholar.org/paper/c6e319a023f932d6d2ff8897c2c91e56e872db8e)\]. PASHA combines hybrid parallelism, utilizing both shared-memory multi-core CPUs and distributed-memory clusters, to achieve competitive assembly quality and faster execution times on large datasets \[[6](http://arxiv.org/abs/2010.10055)\]. Additionally, ELBA, a state-of-the-art distributed-memory parallel algorithm, has been enhanced with three GPU schedulers to improve performance, achieving up to 7-8× speed-up over the baseline \[[7](https://www.semanticscholar.org/paper/fe8d86bc5520b5049104ff58ee7e980982816ebf)\]. These advancements highlight the ongoing efforts to optimize de novo assembly through distributed and parallel computing techniques.

### <a id='category-de-novo-assembly-fundamentals'></a>De Novo Assembly Fundamentals: 7 papers found.
The de novo genome assembly process involves reconstructing the original genome from short sequencing reads, which presents significant computational challenges due to the complexity of the problem and the volume of data \[[1](http://arxiv.org/abs/1705.11147)\]. This task is often approached by finding a Hamiltonian path in a directed graph, but the presence of local structures and biological features complicates this process, necessitating graph simplification techniques \[[1](http://arxiv.org/abs/1705.11147)\]. Recent advancements in graph representation learning and neural execution have enabled the training of models like MPNN with max-aggregators to perform graph simplification effectively, allowing for scalability to large datasets \[[1](http://arxiv.org/abs/1705.11147)\]. Additionally, the use of long-read sequencing technologies has improved scaffolding by providing long-range evidence to resolve repetitive regions, as demonstrated by tools like ntLink, which utilizes minimizer-based mappings to enhance assembly quality \[[4](http://arxiv.org/abs/2011.05013)\]. While short-read technologies remain prevalent, they are limited in their ability to produce high-quality assemblies, highlighting the need for more sophisticated methods \[[6](http://arxiv.org/abs/2010.10055)\]. The integration of genetic linkage maps with de novo assemblies can further improve accuracy by resolving misassemblies and anchoring chromosome-scale sequences \[[3](http://arxiv.org/abs/2207.04350)\]. Overall, the field is evolving with new methodologies and tools aimed at overcoming the inherent challenges of de novo assembly \[[7](https://www.semanticscholar.org/paper/fe8d86bc5520b5049104ff58ee7e980982816ebf)\].

The category also includes the development of colored de Bruijn graphs for detecting genetic variants and genotyping complex structural variations, demonstrating the versatility of these graph-based methods in handling diverse genomic data \[[4](http://arxiv.org/abs/2011.05013)\].
