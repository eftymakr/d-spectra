## Related Works

Memory bandwidth regulation and cache partitioning have been extensively studied for achieving predictable timing in real-time computing systems \[[1](http://arxiv.org/abs/2310.02959)\]. These techniques are often combined with partitioned scheduling to manage task execution times, which are highly dependent on allocated resources \[[1](http://arxiv.org/abs/2310.02959)\]. Prior work has focused on optimizing the co-allocation of tasks and resources to cores, which is critical for improving schedulability and reducing interference \[[1](http://arxiv.org/abs/2310.02959)\]. 

Several studies have explored the co-optimization of cache partitioning and task scheduling. For instance, a hybrid multi-layer design space exploration technique was proposed to improve real-time schedulability by interleaving cache partitioning, task allocation, and schedulability analysis \[[1](http://arxiv.org/abs/2310.02959)\]. This approach uses a breadth-first search combined with proactive pruning for cache partitioning, a first-fit heuristic for task allocation, and a recurrence relation for schedulability analysis \[[1](http://arxiv.org/abs/2310.02959)\]. The results showed that this framework can improve the real-time schedulability of non-preemptive fixed-priority (NP-FP) task sets by an average of 15.2% \[[1](http://arxiv.org/abs/2310.02959)\]. 

In addition to cache partitioning, memory bandwidth regulation has also been investigated as a means to reduce contention and improve predictability in multi-core systems \[[2](http://arxiv.org/abs/1809.05921)\]. A study focused on dynamic allocation of main memory bandwidth, showing that response time computation can be reduced to a maximization problem over assignment of memory requests to different time intervals \[[2](http://arxiv.org/abs/1809.05921)\]. This approach was applied to improve the schedulability of Integrated Modular Avionics systems \[[2](http://arxiv.org/abs/1809.05921)\]. 

The problem of cache bank contention and its impact on real-time systems has also been addressed. A per-bank bandwidth regulation approach was proposed to prevent unnecessary throttling of cache accesses to non-contended banks, thereby improving performance without compromising isolation benefits \[[3](http://arxiv.org/abs/2410.14003)\]. This method was implemented on a RISC-V system-on-chip (SoC) platform and showed significant improvements in handling cache bank-aware denial-of-service (DoS) attacks \[[3](http://arxiv.org/abs/2410.14003)\]. 

Another line of research has focused on the multiframe model for timing analysis in real-time systems, aiming to eliminate pessimism in schedulability analysis \[[4](https://www.semanticscholar.org/paper/e8d15aa827be70bebf15e217ac9295276ddebda7)\]. However, this model was found to be optimistic and unsafe for multicore systems with shared memory controllers \[[4](https://www.semanticscholar.org/paper/e8d15aa827be70bebf15e217ac9295276ddebda7)\]. A solution was proposed by adapting existing stall analyses for memory-regulated systems to the multiframe model, resulting in up to 85% higher scheduling success ratio compared to frame-agnostic analysis \[[4](https://www.semanticscholar.org/paper/e8d15aa827be70bebf15e217ac9295276ddebda7)\].

### <a id='category-cache-partitioning-methods'></a>Cache Partitioning Methods: 2 papers found.
Cache partitioning methods have been extensively studied to improve schedulability in real-time systems, particularly in multi-core environments where task execution times are heavily influenced by cache availability \[[1](http://arxiv.org/abs/2310.02959)\]. Early approaches focused on static cache partitioning, where the cache is divided among cores to minimize interference and ensure predictable execution times \[[6](http://arxiv.org/abs/1210.4053)\]. These methods often combined cache partitioning with task assignment heuristics, such as first-fit, to balance resource allocation and system performance \[[1](http://arxiv.org/abs/2310.02959)\]. More recent work has introduced multi-layer optimization frameworks that integrate cache partitioning with scheduling policies, such as non-preemptive fixed-priority (NP-FP) and EDF, by systematically interleaving optimization layers for resource allocation, task assignment, and schedulability analysis \[[1](http://arxiv.org/abs/2310.02959)\]. For instance, some studies have demonstrated that clustering tasks based on period or compatibility can enhance schedulability by up to 7.6% compared to clustering by cache sensitivity \[[1](http://arxiv.org/abs/2310.02959)\]. Additionally, theoretical analyses have explored the complexity of joint cache partitioning and job assignment problems, leading to approximation algorithms that improve upon traditional heuristic approaches \[[6](http://arxiv.org/abs/1210.4053)\]. These advancements highlight the growing importance of co-optimizing cache resources and task scheduling to achieve both predictability and efficiency in real-time computing systems.

### <a id='category-memory-bandwidth-regulation-techniques'></a>Memory Bandwidth Regulation Techniques: 4 papers found.
Memory Bandwidth Regulation Techniques focus on managing and optimizing memory resources to ensure predictable timing in real-time systems, particularly in multi-core and heterogeneous platforms \[[1](http://arxiv.org/abs/2310.02959)\]. These techniques are crucial for mitigating contention over shared memory resources such as caches, interconnects, and DRAM, which can lead to unpredictable behavior in embedded systems \[[2](http://arxiv.org/abs/1809.05921)\]. One approach involves dynamic allocation of main memory bandwidth, where the worst-case response time of tasks is analyzed across different time intervals with varying bandwidth-to-core assignments \[[1](http://arxiv.org/abs/2310.02959)\]. This is further extended to per-bank bandwidth regulation in multi-banked shared LLCs, which helps prevent unnecessary throttling of non-contended banks, thereby improving performance without compromising isolation \[[2](http://arxiv.org/abs/1809.05921)\]. Additionally, the multiframe model has been adapted to address the limitations of existing stall analyses in memory-regulated systems, offering a more accurate and less pessimistic approach to schedulability analysis \[[3](http://arxiv.org/abs/2410.14003)\]. In mixed-criticality systems, memory bandwidth reservation mechanisms like H-MBR are proposed to ensure temporal isolation and predictability by leveraging VM-centric approaches, offering reduced overhead and platform agnosticism \[[4](https://www.semanticscholar.org/paper/e8d15aa827be70bebf15e217ac9295276ddebda7)\]. These techniques collectively aim to enhance the reliability and performance of real-time applications by addressing both memory contention and resource allocation challenges.

[Snippet]: «Reducing the average memory access time is crucial for improving the performance of applications running on multicore architectures. With workload consolidation this becomes increasingly challenging due to shared resource contention. In this paper, we propose CBP a coordination mechanism for dynamically managing prefetching throttling, cache and bandwidth partitioning, in order to reduce average memory access time and improve performance. CBP works by employing individual resource managers to determine the appropriate setting for each resource and a coordinating mechanism in order to enable inter-resource trade-offs. Our evaluation on a 16-core CMP shows that CBP, on average, improves performance by 11% compared to the state-of-the-art technique that manages cache partitioning and prefetching and by 50% compared to the baseline without cache partitioning, bandwidth partitioning and prefetch throttling.»

### <a id='category-optimization-algorithms-for-real-time-systems'></a>Optimization Algorithms for Real-Time Systems: 3 papers found.
The category "Optimization Algorithms for Real-Time Systems" encompasses several key themes, including the challenges of scheduling hard real-time tasks on multicore architectures, the complexity of resource sharing in multiprocessor systems, and the development of mathematical formulations for efficient task-resource co-allocation. For instance, the need to minimize cache misses in multicore systems while ensuring predictable timing behavior has led to the exploration of static scheduling strategies that leverage communication affinities \[[1](http://arxiv.org/abs/2310.02959)\]. Additionally, the synchronization of real-time tasks in multiprocessor environments is a complex problem, with studies showing that even simplified versions of this problem are NP-hard in the strong sense, regardless of the number of processors or scheduling paradigm \[[2](http://arxiv.org/abs/1809.05921)\]. This complexity is further compounded by the trade-offs between preemptive and non-preemptive scheduling, as well as partitioned and semi-partitioned scheduling approaches \[[2](http://arxiv.org/abs/1809.05921)\]. To address these challenges, researchers have proposed various optimization formulations, such as mixed-integer nonlinear programs and fluid models, which aim to improve the efficiency of task-resource co-allocation by incorporating dynamic models and allowing for time-varying speed profiles \[[3](http://arxiv.org/abs/2410.14003)\]. These formulations are designed to meet hard constraints while optimizing energy usage and schedulability, demonstrating the ongoing efforts to enhance real-time system performance through advanced algorithmic approaches.
