## Related Works

Conversational recommendation systems (CRSs) have gained significant attention in recent years due to their ability to dynamically capture user preferences through multi-turn interactions \[[1](https://www.semanticscholar.org/paper/3ae5bef6b0c8317603a2deab2527383580904fd8)\]. Traditional recommendation systems often rely on static models that estimate user preferences based on past behavior, limiting their ability to adapt to evolving user needs \[[4](http://arxiv.org/abs/2101.09459)\]. In contrast, CRSs enable more nuanced preference elicitation by engaging users in natural language dialogues, allowing the system to ask clarifying questions and refine recommendations iteratively \[[1](https://www.semanticscholar.org/paper/3ae5bef6b0c8317603a2deab2527383580904fd8)\]. This interactive approach has been shown to improve recommendation accuracy and user satisfaction \[[1](https://www.semanticscholar.org/paper/3ae5bef6b0c8317603a2deab2527383580904fd8)\].

Several studies have explored the challenges of modeling user preferences in conversational settings. For instance, \[[4](http://arxiv.org/abs/2101.09459)\] highlights the limitations of static models in accurately capturing what users like and why, emphasizing the need for dynamic interaction. To address this, \[[1](https://www.semanticscholar.org/paper/3ae5bef6b0c8317603a2deab2527383580904fd8)\] proposes a System Ask -- User Respond (SAUR) paradigm, where the system actively asks questions to clarify user needs, leading to more accurate recommendations. Similarly, \[[3](http://arxiv.org/abs/2002.09102)\] introduces the Estimation-Action-Reflection (EAR) framework, which divides the conversational process into three stages: estimating user preferences, deciding whether to ask or recommend, and reflecting on user feedback to improve future interactions.

The integration of conversational and recommendation components remains a key challenge in CRS development. \[[8](http://arxiv.org/abs/2105.09710)\] proposes a unified policy learning approach using graph-based reinforcement learning to simultaneously decide what to ask and what to recommend, enhancing the scalability and stability of conversational recommendation systems. Additionally, \[[14](http://arxiv.org/abs/2206.09363)\] introduces a knowledge-enhanced prompt learning approach to unify recommendation and conversation subtasks, improving the integration of these components within a single model.

To enhance the quality of interactions, \[[11](http://arxiv.org/abs/2304.13874)\] develops a user simulator, ConvSim, that generates realistic user feedback, enabling the evaluation of CRS performance in multi-turn settings. This aligns with the proposed GRSU (Generative Reward Simulated User) in the current work, which also utilizes simulated user feedback to improve recommendation accuracy. \[[13](http://arxiv.org/abs/2006.08732)\] further explores automated evaluation of conversational systems through user simulation, showing that preference modeling and interaction flow significantly impact the realism of simulated user behavior.

### <a id='category-conversational-recommender-systems'></a>Conversational Recommender Systems: 8 papers found.
Conversational recommender systems (CRSs) have gained significant attention for their ability to dynamically capture user preferences through multi-turn interactions, offering a more nuanced understanding compared to traditional one-shot recommendation approaches \[[2](http://arxiv.org/abs/2004.00646)\]. These systems leverage natural language dialogues to ask targeted questions about item attributes, enabling the system to clarify user needs and provide more personalized recommendations \[[1](https://www.semanticscholar.org/paper/3ae5bef6b0c8317603a2deab2527383580904fd8)\]. Several studies have proposed frameworks to address the challenges of preference elicitation and recommendation in conversational settings, such as the System Ask -- User Respond (SAUR) paradigm, which structures interactions around question-answering cycles \[[1](https://www.semanticscholar.org/paper/3ae5bef6b0c8317603a2deab2527383580904fd8)\]. Additionally, the Estimation"Action" Reflection (EAR) framework has been introduced to manage the flow of conversation by determining when to ask for attribute information versus when to recommend items, based on user feedback and historical data \[[3](http://arxiv.org/abs/2002.09102)\]. Another approach, Conversational Path Reasoning (CPR), models the recommendation process as an interactive path reasoning problem on a graph, allowing the system to navigate through attribute vertices based on user feedback \[[5](http://arxiv.org/abs/2007.00194)\]. Furthermore, the integration of knowledge graphs and mutual information maximization has been explored to enhance both recommendation accuracy and dialogue understanding by aligning semantic representations across different levels of user feedback \[[6](http://arxiv.org/abs/2007.04032)\]. These advancements highlight the ongoing efforts to improve the effectiveness and efficiency of conversational recommendation systems, particularly in handling complex user preferences and facilitating seamless, multi-turn interactions \[[16](https://www.semanticscholar.org/paper/33e0fe2d4cf01b16da89ab0c180cdcbf37b3be17)\].

[Snippet]: «Conversational recommender systems (CRS) enable traditional recommender systems to interact with users by asking questions about attributes and recommending items. The attribute-level and item-level feedback of users can be utilized to estimate users' preferences. However, existing works do not fully exploit the advantage of explicit item feedback --- they only use the item feedback in rather implicit ways such as updating the latent user and item representation. Since CRS has multiple chances to interact with users, leveraging the context in the conversation may help infer users' implicit feedback (e.g., some specific attributes) when recommendations get rejected. To address the limitations of existing methods, we propose a new CRS framework called Conversational Recommender with Implicit Feedback (CRIF). CRIF formulates the conversational recommendation scheme as a four-phase process consisting of offline representation learning, tracking, decision, and inference. In the inference module, by fully utilizing the relation between users' attribute-level and item-level feedback, our method can explicitly deduce users' implicit preferences. Therefore, CRIF is able to achieve more accurate user preference estimation. Besides, in the decision module, to better utilize the attribute-level and item-level feedback, we adopt inverse reinforcement learning to learn a flexible decision strategy that selects the suitable action at each conversation turn. Through extensive experiments on four benchmark CRS datasets, we validate the effectiveness of our approach, which significantly outperforms the state-of-the-art CRS methods.»

[Snippet]: «This research aims to explore various methods for assessing user feedback in mixed-initiative conversational search (CS ) systems. While CS systems enjoy profuse advancements across multiple aspects, recent research fails to successfully incorporate feedback from the users. One of the main reasons for that is the lack of system-user conversational interaction data. To this end, we propose a user simulator-based framework for multi-turn interactions with a variety of mixed-initiative CS systems. Specifically, we develop a user simulator, dubbed ConvSim, that, once initialized with an information need description, is capable of providing feedback to system's responses, as well as answering potential clarifying questions. Our experiments on a wide variety of state-of-the-art passage retrieval and neural re-ranking models show that effective utilization of user feedback can lead to 16% retrieval performance increase in terms of nDCG@3. Moreover, we observe consistent improvements as the number of feedback rounds increases (35% relative improvement in terms of nDCG@3 after three rounds). This points to a research gap in the development of specific feedback processing modules and opens a potential for significant advancements in CS. To support further research in the topic, we release over 30 000 transcripts of system-simulator interactions based on well-established CS datasets.»

[Snippet]: «Conversational recommender systems (CRS) aim to proactively elicit user preference and recommend high-quality items through natural language conversations. Typically, a CRS consists of a recommendation module to predict preferred items for users and a conversation module to generate appropriate responses. To develop an effective CRS, it is essential to seamlessly integrate the two modules. Existing works either design semantic alignment strategies, or share knowledge resources and representations between the two modules. However, these approaches still rely on different architectures or techniques to develop the two modules, making it difficult for effective module integration. To address this problem, we propose a unified CRS model named UniCRS based on knowledge-enhanced prompt learning. Our approach unifies the recommendation and conversation subtasks into the prompt learning paradigm, and utilizes knowledge-enhanced prompts based on a fixed pre-trained language model (PLM) to fulfill both subtasks in a unified approach. In the prompt design, we include fused knowledge representations, task-specific soft tokens, and the dialogue context, which can provide sufficient contextual information to adapt the PLM for the CRS task. Besides, for the recommendation subtask, we also incorporate the generated response template as an important part of the prompt, to enhance the information interaction between the two subtasks. Extensive experiments on two public CRS datasets have demonstrated the effectiveness of our approach. Our code is publicly available at the link: https://github.com/RUCAIBox/UniCRS.»
