## Related Works

Semi-supervised learning (SSL) has emerged as a powerful paradigm for improving model performance by leveraging unlabeled data when labeled data is scarce \[[1](http://arxiv.org/abs/2205.07246)\]. Traditional SSL methods, such as FixMatch \[[15](http://arxiv.org/abs/2001.07685)\], assume that both labeled and unlabeled data share the same class distribution \[[1](http://arxiv.org/abs/2205.07246)\]. However, this assumption is often violated in real-world scenarios, where unlabeled data may contain out-of-distribution (OOD) samples, i.e., outliers, that do not belong to any of the known classes \[[26](http://arxiv.org/abs/2412.18256)\]. These outliers are typically treated as noise, which can significantly degrade the performance of SSL models \[[1](http://arxiv.org/abs/2205.07246)\]. 

To address this issue, several open-set SSL methods have been proposed. For example, OpenMatch \[[9](http://arxiv.org/abs/2105.14148)\] introduces a novel framework that combines FixMatch with novelty detection based on one-vs-all (OVA) classifiers. This allows the model to distinguish between inliers and outliers. Similarly, IOMatch \[[5](http://arxiv.org/abs/2308.13168)\] proposes a framework that jointly utilizes inliers and outliers, even when it is difficult to distinguish between them. This approach avoids the performance degradation caused by unreliable outlier detection when labeled data is scarce \[[5](http://arxiv.org/abs/2308.13168)\]. 

Another line of research focuses on improving the robustness of SSL in the presence of class imbalance. For instance, CReST \[[10](http://arxiv.org/abs/2102.09559)\] introduces a class-rebalancing self-training framework that improves existing SSL methods on class-imbalanced data. This is achieved by iteratively expanding the labeled set with pseudo-labeled samples from the unlabeled set, with a focus on minority classes \[[10](http://arxiv.org/abs/2102.09559)\]. Similarly, ABC \[[22](http://arxiv.org/abs/2110.10368)\] proposes an auxiliary balanced classifier to mitigate class imbalance by introducing a single-layer classifier that is trained with a class-balanced loss \[[22](http://arxiv.org/abs/2110.10368)\]. 

Additionally, methods like FreeMatch \[[1](http://arxiv.org/abs/2205.07246)\] and Dash \[[8](http://arxiv.org/abs/2109.00650)\] have been developed to dynamically adjust confidence thresholds during training, which helps in better utilization of unlabeled data. FreeMatch, in particular, introduces a self-adaptive class fairness regularization penalty to encourage diverse predictions during the early training stage \[[1](http://arxiv.org/abs/2205.07246)\]. 

Moreover, contrastive learning has been explored for SSL, with methods like SimCLR \[[29](http://arxiv.org/abs/2002.05709)\] showing that contrastive learning can lead to better visual representations by leveraging data augmentations and learnable transformations \[[29](http://arxiv.org/abs/2002.05709)\]. Contrastive regularization has also been used to improve SSL performance by encouraging features of confident pseudo-labels to aggregate within the same cluster while pushing away features from different clusters \[[17](http://arxiv.org/abs/2201.06247)\].

Traditional SSL methods often assume balanced class distributions, which can lead to biased pseudo-labels and poor generalization when applied to real-world imbalanced datasets \[[6](http://arxiv.org/abs/2007.08844)\]. Additionally, methods like Dash have been introduced to dynamically select high-quality pseudo-labeled examples based on loss thresholds, enhancing the adaptability of SSL algorithms \[[8](http://arxiv.org/abs/2109.00650)\]. Furthermore, uncertainty-aware pseudo-label selection (UPS) has been proposed to reduce noise in training by filtering out low-confidence predictions, thereby improving the accuracy of pseudo-labels \[[14](http://arxiv.org/abs/2101.06329)\]. These methods highlight the ongoing efforts to enhance SSL performance by addressing issues such as class imbalance, noisy pseudo-labels, and the challenges posed by outliers \[[1](http://arxiv.org/abs/2205.07246)\]\[[6](http://arxiv.org/abs/2007.08844)\]\[[8](http://arxiv.org/abs/2109.00650)\]\[[14](http://arxiv.org/abs/2101.06329)\].

### <a id='category-open-set-semi-supervised-learning'></a>Open Set Semi Supervised Learning: 8 papers found.
Open-set semi-supervised learning (open-set SSL) addresses the challenge where unlabeled data may contain out-of-distribution (OOD) samples, which are not present in the labeled set and can degrade model performance \[[16](http://arxiv.org/abs/2108.05617)\]. Traditional SSL methods assume that labeled and unlabeled data share the same class distribution, but this assumption is often violated in real-world scenarios \[[13](https://www.semanticscholar.org/paper/f3df804a7eef204b0c4fc4b81166dec9b4abc073)\]. To handle OOD samples, various approaches have been proposed, such as filtering OOD samples during training \[[16](http://arxiv.org/abs/2108.05617)\], using contrastive learning to identify OOD samples \[[3](http://arxiv.org/abs/2107.08943)\], and incorporating multi-task learning to separate features for inlier classification and outlier detection \[[5](http://arxiv.org/abs/2308.13168)\]. Some methods, like OpenCoS, utilize pseudo-labels and soft-labels to distinguish between in-class and out-of-class samples \[[3](http://arxiv.org/abs/2107.08943)\], while others, such as OpenMatch, integrate novelty detection with SSL to reject outliers \[[9](http://arxiv.org/abs/2105.14148)\]. Additionally, frameworks like CCSSL improve pseudo-label quality by leveraging class-wise clustering and image-wise contrastive learning \[[1](http://arxiv.org/abs/2205.07246)\]. These methods aim to enhance robustness and generalization in open-set SSL by effectively managing the presence of OOD samples \[[16](http://arxiv.org/abs/2108.05617)\].

### <a id='category-others'></a>Others: 4 papers found.
In the context of semi-supervised learning (SSL), recent research has focused on addressing the challenges posed by class imbalance and open-set environments, where unlabeled data may contain outliers or unknown classes \[[1](http://arxiv.org/abs/2205.07246)\]. Traditional SSL methods often assume a balanced class distribution and consistent data environments, which can lead to performance degradation when these assumptions are violated \[[2](http://arxiv.org/abs/2203.02261)\]. For instance, class-imbalanced SSL (CISSL) has been introduced to handle datasets with uneven class distributions, and methods like Suppressed Consistency Loss (SCL) have been proposed to improve robustness in such scenarios \[[1](http://arxiv.org/abs/2205.07246)\]. Similarly, in open-set SSL, where unlabeled data may include out-of-distribution samples, studies have highlighted the risks of performance degradation due to the inclusion of outliers \[[2](http://arxiv.org/abs/2203.02261)\]. To mitigate these issues, researchers have explored techniques such as contrastive regularization, which improves the efficiency and accuracy of consistency-based methods by leveraging well-clustered features of unlabeled data \[[3](http://arxiv.org/abs/2107.08943)\]. Additionally, methods like FullMatch have been developed to better utilize unlabeled examples by incorporating entropy-based loss and adaptive negative learning, leading to improved performance on standard benchmarks \[[2](http://arxiv.org/abs/2203.02261)\]. ### <a id='category-semisupervised-learning-safety'></a>SemiSupervised Learning Safety: 2 papers found.
In the realm of semi-supervised learning (SSL), handling outliers in unlabeled data remains a critical challenge, particularly in open-set scenarios where unseen classes are present \[[1](http://arxiv.org/abs/2205.07246)\]. Traditional approaches often rely on detecting and filtering out outliers, but this can lead to significant performance degradation when labeled data is scarce, as unreliable detectors may exclude valuable inliers \[[1](http://arxiv.org/abs/2205.07246)\]. To address this, recent works have proposed novel frameworks that jointly utilize inliers and outliers, even when distinguishing between them is difficult \[[1](http://arxiv.org/abs/2205.07246)\]. For instance, IOMatch introduces a multi-binary classifier combined with a closed-set classifier to generate unified open-set classification targets, treating all outliers as a single class, thereby improving robustness \[[1](http://arxiv.org/abs/2205.07246)\]. Similarly, SAFE-R-STUDENT enhances SSL safety by incorporating a scoring framework to better identify seen and unseen classes, along with calibration and bias elimination techniques to improve model performance \[[2](http://arxiv.org/abs/2203.02261)\]. These methods highlight the growing interest in developing more resilient SSL approaches that can effectively handle the complexities of real-world data distributions.

### <a id='category-semi-supervised-learning-methods'></a>Semi Supervised Learning Methods: 5 papers found.
In the realm of semi-supervised learning (SSL), recent works have focused on addressing class imbalance and improving robustness in the presence of outliers. Several methods have been proposed to enhance SSL performance on imbalanced datasets, such as Class-Rebalancing Self-Training (CReST) \[[10](http://arxiv.org/abs/2102.09559)\], which iteratively expands the labeled set with pseudo-labels from minority classes to improve model performance. Similarly, CoSSL \[[20](http://arxiv.org/abs/2112.04564)\] introduces a co-learning framework that decouples representation and classifier learning while handling data imbalance through Tail-class Feature Enhancement (TFE). Additionally, FlatMatch \[[27](http://arxiv.org/abs/2310.16412)\] addresses the issue of inconsistent learning performance between labeled and unlabeled data by minimizing a cross-sharpness measure to ensure consistent learning. SimiS \[[28](http://arxiv.org/abs/2211.11086)\] further simplifies the problem of imbalanced SSL by supplementing labeled data with pseudo-labels based on class distribution differences, achieving significant improvements over existing methods. These approaches highlight the ongoing efforts to improve SSL in realistic scenarios where data imbalance and outlier presence are common challenges.

[Snippet]: «Pseudo-labeling has proven to be a promising semi-supervised learning (SSL) paradigm. Existing pseudo-labeling methods commonly assume that the class distributions of training data are balanced. However, such an assumption is far from realistic scenarios and thus severely limits the performance of current pseudo-labeling methods under the context of class-imbalance. To alleviate this problem, we design a bias adaptive classifier that targets the imbalanced SSL setups. The core idea is to automatically assimilate the training bias caused by class imbalance via the bias adaptive classifier, which is composed of a novel bias attractor and the original linear classifier. The bias attractor is designed as a light-weight residual network and optimized through a bi-level learning framework. Such a learning strategy enables the bias adaptive classifier to fit imbalanced training data, while the linear classifier can provide unbiased label prediction for each class. We conduct extensive experiments under various imbalanced semi-supervised setups, and the results demonstrate that our method can be applied to different pseudo-labeling models and is superior to current state-of-the-art methods.»

[Snippet]: «The problem of detecting whether a test sample is from in-distribution (i.e., training distribution by a classifier) or out-of-distribution sufficiently different from it arises in many real-world machine learning applications.
