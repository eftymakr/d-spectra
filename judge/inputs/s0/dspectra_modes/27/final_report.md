## Related Works

Recent advancements in information retrieval have focused on improving the efficiency and effectiveness of document and table retrieval systems. Traditional approaches rely on a pipeline consisting of representation, indexing, and search stages, where each stage is typically handled by separate components \[[3](http://arxiv.org/abs/1810.04805)\]. This approach, while effective, suffers from error accumulation during the indexing and search phases, which can degrade retrieval accuracy \[[1](http://arxiv.org/abs/2206.10128)\]. Additionally, insufficient interaction between queries and tables hinders semantic alignment, limiting performance improvements \[[1](http://arxiv.org/abs/2206.10128)\]. 

To address these limitations, differentiable search index (DSI) models have emerged as a promising alternative. DSI unifies indexing and retrieval into a single model, eliminating the need for separate components and reducing error accumulation \[[5](http://arxiv.org/abs/2202.06991)\]. This paradigm has been applied to various retrieval tasks, including passage retrieval \[[5](http://arxiv.org/abs/2202.06991)\], table retrieval \[[14](http://arxiv.org/abs/1802.06159)\], and document retrieval \[[15](http://arxiv.org/abs/2307.10323)\]. DSI models encode all necessary information about the corpus directly into the model parameters, allowing queries to be answered directly using only the model's parameters \[[5](http://arxiv.org/abs/2202.06991)\]. 

However, DSI models face challenges in handling dynamic updates and continual indexing. Re-training the model from scratch when new documents are added is computationally expensive and impractical for real-time applications \[[15](http://arxiv.org/abs/2307.10323)\]. To mitigate this, DSI++ was introduced, which enables incremental indexing of new documents while maintaining retrieval performance \[[10](http://arxiv.org/abs/2212.09744)\]. This approach uses continual learning techniques to update the model without retraining on the entire dataset, significantly reducing computational overhead \[[10](http://arxiv.org/abs/2212.09744)\]. 

Another related approach is the Neural Corpus Indexer (NCI), which also aims to unify indexing and retrieval within a single model. NCI uses a sequence-to-sequence architecture to generate relevant document identifiers directly for a given query \[[7](http://arxiv.org/abs/2206.02743)\]. To improve recall performance, NCI incorporates techniques such as query generation, semantic document identifiers, and consistency-based regularization \[[7](http://arxiv.org/abs/2206.02743)\]. These methods have shown significant improvements over traditional retrieval systems \[[7](http://arxiv.org/abs/2206.02743)\]. 

In addition to DSI-based approaches, other models have explored the use of contextualized language models for retrieval tasks. ColBERT, for example, leverages BERT for efficient retrieval by introducing a late interaction architecture that independently encodes queries and documents \[[9](http://arxiv.org/abs/2004.12832)\]. This approach allows for faster query processing and the use of vector-similarity indexes for end-to-end retrieval \[[9](http://arxiv.org/abs/2004.12832)\]. Similarly, DistilBERT, a distilled version of BERT, has been used for efficient language understanding tasks, offering a smaller, faster, and more lightweight alternative \[[11](http://arxiv.org/abs/1910.01108)\].

### <a id='category-differentiable-search-indexing-techniques'></a>Differentiable Search Indexing Techniques: 9 papers found.
Differentiable Search Indexing (DSI) has emerged as a promising paradigm for information retrieval, aiming to unify indexing and retrieval into a single model \[[1](http://arxiv.org/abs/2206.10128)\]. Unlike traditional systems that separate these processes, DSI leverages a transformer model to encode document identifiers and directly map queries to relevant documents \[[4](http://arxiv.org/abs/2305.15115)\]. This approach eliminates error accumulation during indexing and search, as noted in the paper abstract \[[1](http://arxiv.org/abs/2206.10128)\]. However, challenges remain, such as the difficulty of adding new documents after training and the risk of catastrophic forgetting during continual indexing \[[10](http://arxiv.org/abs/2212.09744)\]. To address these issues, researchers have proposed various improvements, including DSI-QG, which generates synthetic queries during indexing to enhance retrieval effectiveness \[[1](http://arxiv.org/abs/2206.10128)\], and DSI++, which introduces continual learning strategies to incrementally update the model with new documents \[[10](http://arxiv.org/abs/2212.09744)\]. Additionally, IncDSI enables real-time addition of new documents without retraining the entire model, making it suitable for dynamic environments \[[15](http://arxiv.org/abs/2307.10323)\]. These advancements highlight the evolving landscape of DSI, focusing on improving efficiency, scalability, and adaptability in real-world applications \[[1](http://arxiv.org/abs/2206.10128)\]\[[4](http://arxiv.org/abs/2305.15115)\]\[[10](http://arxiv.org/abs/2212.09744)\]\[[15](http://arxiv.org/abs/2307.10323)\].
