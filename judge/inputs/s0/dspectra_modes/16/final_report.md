## Related Works

Open-vocabulary object detection (OVD) has gained significant attention in recent years due to its ability to detect objects from arbitrary text descriptions, enabling flexible and user-driven detection \[[1](http://arxiv.org/abs/2011.10678)\]. Traditional object detection methods are limited to a fixed set of categories, requiring extensive manual annotation for expansion \[[1](http://arxiv.org/abs/2011.10678)\]. To overcome this limitation, researchers have explored weakly supervised and zero-shot learning techniques, but these approaches have not been as effective as fully supervised methods \[[1](http://arxiv.org/abs/2011.10678)\]. 

Several works have focused on leveraging large-scale image-text pairs to expand the vocabulary of object detectors. For instance, \[[2](http://arxiv.org/abs/1411.4952)\] proposed a method that generates pseudo bounding-box annotations from image-caption pairs, allowing detectors to be trained on a broader set of categories. This approach significantly reduces the need for manual annotations and improves performance on novel categories. Similarly, \[[3](http://arxiv.org/abs/2111.09452)\] introduced a framework that uses pre-trained vision-language models to generate pseudo labels, leading to improved detection accuracy on benchmarks like COCO and LVIS. 

Another line of research has focused on aligning visual and language representations to enable open-vocabulary detection. \[[4](http://arxiv.org/abs/2211.14843)\] proposed a novel framework that directly learns from image-text pairs by formulating object-language alignment as a set matching problem. This method enables detectors to be trained without requiring explicit bounding-box annotations, improving performance on novel categories. \[[5](http://arxiv.org/abs/2304.00788)\] further extended this idea by proposing a method that connects textual and point-cloud representations, enabling open-vocabulary 3D object detection without 3D annotations. 

Weakly supervised detection methods have also been explored to reduce the reliance on manual annotations. \[[6](http://arxiv.org/abs/2203.16513)\] introduced a two-stage open-vocabulary detector that uses a text encoder from a pre-trained vision-language model to classify object proposals. This approach allows detectors to generalize to novel categories without requiring additional training data. \[[7](http://arxiv.org/abs/2004.06165)\] proposed a method that uses regional prompt learning to align textual embeddings with visual features, improving the performance of open-vocabulary detectors. 

Recent work has also focused on improving the efficiency and scalability of open-vocabulary detection. \[[8](http://arxiv.org/abs/2306.05493)\] introduced a self-training framework that uses noisy web images to expand the vocabulary of detectors, achieving superior performance on benchmarks like LVIS and MS-COCO. \[[9](http://arxiv.org/abs/2205.06230)\] proposed a method that leverages contrastive image-text pre-training and end-to-end detection fine-tuning, demonstrating consistent improvements on downstream detection tasks. 

In addition to detection, some works have explored open-vocabulary segmentation. \[[10](http://arxiv.org/abs/2211.12914)\] introduced a framework that jointly learns from segmentation and detection datasets, bridging the gap between different annotation granularities

### <a id='category-open-vocabulary-object-detection'></a>Open Vocabulary Object Detection: 15 papers found.
Open-vocabulary object detection (OVD) has emerged as a critical research direction, enabling detectors to recognize objects from novel categories without requiring retraining \[[1](http://arxiv.org/abs/2011.10678)\]. This is particularly valuable in scenarios where expanding the vocabulary is costly or impractical due to the need for extensive bounding box annotations \[[3](http://arxiv.org/abs/2111.09452)\]. Recent approaches leverage pre-trained vision-language models (VLMs) to bridge the gap between visual and textual representations, allowing for zero-shot or one-shot detection of unseen objects \[[8](http://arxiv.org/abs/2306.05493)\]. For instance, methods like ViLD and DetCLIPv2 use image-text pairs to generate pseudo labels or align region proposals with semantic embeddings, significantly improving performance on benchmarks like COCO and LVIS \[[10](http://arxiv.org/abs/2211.12914)\]\[[15](http://arxiv.org/abs/2009.13682)\]. However, challenges remain, including the misalignment between image and text features, confidence bias toward base categories, and the need for efficient proposal-level alignment \[[11](http://arxiv.org/abs/2211.16312)\]. To address these, techniques such as regional prompt learning \[[6](http://arxiv.org/abs/2203.16513)\], object-centric alignment \[[16](http://arxiv.org/abs/2207.03482)\], and dynamic network heads \[[29](http://arxiv.org/abs/2212.12130)\] have been proposed to enhance generalization and detection accuracy. Additionally, pseudo-label generation from large-scale image-caption pairs has shown promise in reducing reliance on manual annotations \[[3](http://arxiv.org/abs/2111.09452)\]. These advancements collectively contribute to the growing body of work on scalable and flexible open-vocabulary object detection systems.

### <a id='category-vision-language-pre-training-models'></a>Vision Language Pre-training Models: 6 papers found.
The category "Vision Language Pre-training Models" encompasses a range of approaches aimed at improving the alignment between visual and linguistic data. These models often leverage large-scale image-text datasets to learn cross-modal representations, enabling tasks such as image captioning, object detection, and semantic understanding \[[2](http://arxiv.org/abs/1411.4952)\]. For instance, methods like Oscar introduce object tags as anchor points to ease the learning of semantic alignments, leading to state-of-the-art performance on multiple vision-language tasks \[[7](http://arxiv.org/abs/2004.06165)\]. Similarly, VIVO addresses the challenge of generating captions for novel objects by pre-training on image-tag data without relying on caption annotations, thereby expanding the visual vocabulary \[[15](http://arxiv.org/abs/2009.13682)\]. Another approach, CoDA, tackles open-vocabulary 3D object detection by jointly learning novel object localization and classification through cross-modal alignment \[[22](http://arxiv.org/abs/2310.02960)\]. These models highlight the importance of leveraging both image and text modalities effectively, often through pre-training on extensive datasets and fine-tuning for specific downstream tasks. Additionally, methods such as the one described in \[[27](http://arxiv.org/abs/1612.00576)\] focus on improving out-of-domain captioning by incorporating image taggers at test time, enabling vocabulary expansion without retraining. Overall, these works emphasize the potential of vision-language pre-training models to enhance the flexibility and performance of systems in real-world applications \[[2](http://arxiv.org/abs/1411.4952)\]\[[7](http://arxiv.org/abs/2004.06165)\]\[[15](http://arxiv.org/abs/2009.13682)\]\[[22](http://arxiv.org/abs/2310.02960)\]\[[27](http://arxiv.org/abs/1612.00576)\].

### <a id='category-open-vocabulary-scene-understanding'></a>Open Vocabulary Scene Understanding: 2 papers found.
Open-vocabulary scene understanding has emerged as a critical area in computer vision, aiming to enable models to recognize and localize unseen object categories beyond the scope of traditional closed-vocabulary approaches \[[23](http://arxiv.org/abs/2307.09220)\]. This shift is driven by the need for models to generalize to new, unseen classes, which is particularly important in real-world applications where predefined datasets are insufficient \[[11](http://arxiv.org/abs/2211.16312)\]. Recent advances have leveraged large-scale image-text pairs to enhance open-vocabulary perception, particularly in 2D settings, where models can learn to associate visual content with semantic descriptions \[[11](http://arxiv.org/abs/2211.16312)\]. However, extending these methods to 3D scenarios remains challenging due to the lack of extensive 3D-text paired data \[[11](http://arxiv.org/abs/2211.16312)\]. To address this, researchers have explored distilling knowledge from pretrained vision-language models by using multi-view images to generate semantic-rich captions, thereby bridging the gap between 3D scenes and language \[[11](http://arxiv.org/abs/2211.16312)\]. Additionally, methods such as contrastive learning and hierarchical captioning have been proposed to improve visual-semantic alignment, enabling more accurate open-vocabulary segmentation and detection \[[11](http://arxiv.org/abs/2211.16312)\]. These efforts align with broader trends in open-vocabulary detection and segmentation, where weak supervision and transfer learning play key roles in improving model generalization \[[23](http://arxiv.org/abs/2307.09220)\]. The development of such techniques is crucial for advancing scene understanding in dynamic and unstructured environments.

[Snippet]: «We present OpenSeeD, a simple Open-vocabulary Segmentation and Detection framework that jointly learns from different segmentation and detection datasets.
