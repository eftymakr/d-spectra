## Related Works

Memory bandwidth regulation and cache partitioning have been extensively studied in the context of real-time systems to ensure predictable timing behavior \[[1](http://arxiv.org/abs/1809.05921)\]. These techniques are particularly important in multi-core environments where shared memory resources such as caches, interconnects, and DRAM can introduce significant contention and variability in execution times \[[1](http://arxiv.org/abs/1809.05921)\]. Early work focused on analyzing the worst-case response times of tasks under varying memory bandwidth allocations, highlighting the need for theoretical frameworks to reason about the worst-case behavior of real-time workloads \[[1](http://arxiv.org/abs/1809.05921)\]. This has led to the development of methods that reduce response time computation to a maximization problem over memory request assignments \[[1](http://arxiv.org/abs/1809.05921)\].

DDR DRAMs, commonly used in real-time systems, suffer from inherent limitations in terms of predictable memory behavior due to variable access latencies and overly pessimistic latency bounds \[[2](http://arxiv.org/abs/1810.07059)\]. These limitations make DDR DRAMs unsuitable for systems with strict timing constraints, prompting the exploration of alternative memory solutions such as Reduced Latency DRAM (RLDRAM) \[[2](http://arxiv.org/abs/1810.07059)\]. RLDRAM-based memory controllers, like RLDC, offer improved timing predictability with up to 11× less timing variability and 6.4× reduction in worst-case latency compared to DDR controllers \[[2](http://arxiv.org/abs/1810.07059)\].

Cache partitioning has also been widely adopted to mitigate interference among real-time tasks on multi-core processors \[[14](http://arxiv.org/abs/2310.02959)\]. Recent work has focused on co-optimizing cache partitioning and task scheduling to improve schedulability, particularly for cache-sensitive tasks \[[14](http://arxiv.org/abs/2310.02959)\]. A hybrid multi-layer design space exploration technique has been proposed to address this challenge, combining breadth-first search with proactive pruning for cache partitioning, first-fit heuristic for task allocation, and recurrence relations for schedulability analysis \[[14](http://arxiv.org/abs/2310.02959)\]. This approach has shown significant improvements in real-time schedulability, with up to 233.6% improvement in some cases \[[14](http://arxiv.org/abs/2310.02959)\].

Memory interference in COTS-based multi-core systems has also been a focus of recent research, with techniques proposed to provide tight upper bounds on worst-case memory interference delays \[[11](https://www.semanticscholar.org/paper/afca4afaaaa543a1da02b266e9b2ac46eb94793b)\]. These methods model key resources in the DRAM system, including banks, buses, and memory controllers, to analyze the worst-case memory interference delay imposed on a task by other tasks running in parallel \[[11](https://www.semanticscholar.org/paper/afca4afaaaa543a1da02b266e9b2ac46eb94793b)\]. This work also evaluates the effectiveness of DRAM bank partitioning in reducing memory interference \[[11](https://www.semanticscholar.org/paper/afca4afaaaa543a1da02b266e9b2ac46eb94793b)\].

Despite significant achievements in the design and analysis of multi-core systems, there is a need for a theoretical framework that can be used to reason on the worst-case behavior of real-time workload when both processors and memory resources are subject to scheduling decisions. In this paper, we focus our attention on dynamic allocation of main memory bandwidth. In particular, we study how to determine the worst-case response time of tasks spanning through a sequence of time intervals, each with a different bandwidth-to-core assignment. [Snippet]: «Predictable execution time upon accessing shared memories in multi-core real-time systems is a stringent requirement. A plethora of existing works focus on the analysis of Double Data Rate Dynamic Random Access Memories (DDR DRAMs), or redesigning its memory to provide predictable memory behavior. In this paper, we show that DDR DRAMs by construction suffer inherent limitations associated with achieving such predictability. These limitations lead to 1) highly variable access latencies that fluctuate based on various factors such as access patterns and memory state from previous accesses, and 2) overly pessimistic latency bounds. As a result, DDR DRAMs can be ill-suited for some real-time systems that mandate a strict predictable performance with tight timing constraints. Targeting these systems, we promote an alternative off-chip memory solution that is based on the emerging Reduced Latency DRAM (RLDRAM) protocol, and propose a predictable memory controller (RLDC) managing accesses to this memory. Comparing with the state-of-the-art predictable DDR controllers, the proposed solution provides up to 11× less timing variability and 6.4× reduction in the worst case memory latency.»

[Snippet]: «We propose three novel mathematical optimization formulations that solve the same two-type heterogeneous multiprocessor scheduling problem for a real-time taskset with hard constraints. Our formulations are based on a global scheduling scheme and a fluid model. The first formulation is a mixed-integer nonlinear program, since the scheduling problem is intuitively considered as an assignment problem. However, by changing the scheduling problem to first determine a task workload partition and then to find the execution order of all tasks, the computation time can be significantly reduced. Specifically, the workload partitioning problem can be formulated as a continuous nonlinear program for a system with continuous operating frequency, and as a continuous linear program for a practical system with a discrete speed level set. The latter problem can therefore be solved by an interior point method to any accuracy in polynomial time. The task ordering problem can be solved by an algorithm with a complexity that is linear in the total number of tasks. The work is evaluated against existing global energy/feasibility optimal workload allocation formulations. The results illustrate that our algorithms are both feasibility optimal and energy optimal for both implicit and constrained deadline tasksets. Specifically, our algorithm can achieve up to 40% energy saving for some simulated tasksets with constrained deadlines. The benefit of our formulation compared with existing work is that our algorithms can solve a more general class of scheduling problems due to incorporating a scheduling dynamic model in the formulations and allowing for a time-varying speed profile.»
