## Related Works

Memory bandwidth regulation and cache partitioning have been extensively studied in the context of real-time systems to ensure predictable timing behavior \[[1](http://arxiv.org/abs/1809.05921)\]. These techniques are particularly important in multi-core environments where shared memory resources such as caches, interconnects, and DRAM can introduce significant contention and variability in execution times \[[1](http://arxiv.org/abs/1809.05921)\]. Early work focused on analyzing the worst-case response times of tasks under varying memory bandwidth allocations, highlighting the need for theoretical frameworks to reason about the worst-case behavior of real-time workloads \[[1](http://arxiv.org/abs/1809.05921)\]. This has led to the development of methods that reduce response time computation to a maximization problem over memory request assignments \[[1](http://arxiv.org/abs/1809.05921)\].

DDR DRAMs, commonly used in real-time systems, suffer from inherent limitations in terms of predictable memory behavior due to variable access latencies and overly pessimistic latency bounds \[[2](http://arxiv.org/abs/1810.07059)\]. These limitations make DDR DRAMs unsuitable for systems with strict timing constraints, prompting the exploration of alternative memory solutions such as Reduced Latency DRAM (RLDRAM) \[[2](http://arxiv.org/abs/1810.07059)\]. RLDRAM-based memory controllers, like RLDC, offer improved timing predictability with up to 11× less timing variability and 6.4× reduction in worst-case latency compared to DDR controllers \[[2](http://arxiv.org/abs/1810.07059)\].

Cache partitioning has also been widely adopted to mitigate interference among real-time tasks on multi-core processors \[[14](http://arxiv.org/abs/2310.02959)\]. Recent work has focused on co-optimizing cache partitioning and task scheduling to improve schedulability, particularly for cache-sensitive tasks \[[14](http://arxiv.org/abs/2310.02959)\]. A hybrid multi-layer design space exploration technique has been proposed to address this challenge, combining breadth-first search with proactive pruning for cache partitioning, first-fit heuristic for task allocation, and recurrence relations for schedulability analysis \[[14](http://arxiv.org/abs/2310.02959)\]. This approach has shown significant improvements in real-time schedulability, with up to 233.6% improvement in some cases \[[14](http://arxiv.org/abs/2310.02959)\].

Memory interference in COTS-based multi-core systems has also been a focus of recent research, with techniques proposed to provide tight upper bounds on worst-case memory interference delays \[[11](https://www.semanticscholar.org/paper/afca4afaaaa543a1da02b266e9b2ac46eb94793b)\]. These methods model key resources in the DRAM system, including banks, buses, and memory controllers, to analyze the worst-case memory interference delay imposed on a task by other tasks running in parallel \[[11](https://www.semanticscholar.org/paper/afca4afaaaa543a1da02b266e9b2ac46eb94793b)\]. This work also evaluates the effectiveness of DRAM bank partitioning in reducing memory interference \[[11](https://www.semanticscholar.org/paper/afca4afaaaa543a1da02b266e9b2ac46eb94793b)\].
