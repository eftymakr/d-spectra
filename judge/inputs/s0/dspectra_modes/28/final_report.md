## Related Works

Federated Learning (FL) has emerged as a promising framework for collaborative machine learning while preserving data privacy \[[1](http://arxiv.org/abs/1804.08333)\]. Traditional FL methods, such as Federated Averaging (FedAvg), assume that all clients contribute equally and that their data distributions are similar \[[7](http://arxiv.org/abs/1910.06378)\]. However, in practice, client data is often non-IID (non-independent and identically distributed), leading to suboptimal model performance \[[16](http://arxiv.org/abs/1909.06335)\]. This heterogeneity in data distribution has motivated the development of advanced FL techniques that address these challenges.

Several works have focused on improving FL by addressing data heterogeneity. For example, Clustered Federated Learning (CFL) groups clients with similar data distributions into clusters, enabling more effective model aggregation \[[4](http://arxiv.org/abs/1910.01991)\]. Similarly, the Iterative Federated Clustering Algorithm (IFCA) has been proposed to handle clustered FL scenarios by alternating between estimating cluster identities and optimizing model parameters \[[10](http://arxiv.org/abs/2006.04088)\]. These approaches demonstrate the importance of clustering in improving FL performance under heterogeneous conditions.

Another key challenge in FL is the inefficiency of client participation, especially when clients have varying computational resources or network conditions \[[12](http://arxiv.org/abs/2010.01243)\]. To address this, the Power-of-Choice selection strategy has been introduced, which biases client selection toward those with higher local loss to accelerate convergence \[[12](http://arxiv.org/abs/2010.01243)\]. This approach highlights the need for adaptive client selection strategies in FL systems.

In addition to data heterogeneity, the issue of label noise and model personalization has also been explored. For instance, the Robust Heterogeneous Federated Learning (RHFL) framework simultaneously handles label noise and performs federated learning in a single framework, using a novel client confidence re-weighting scheme \[[11](https://www.semanticscholar.org/paper/1ace65d958cd27ae9ad857c49d8caa9aa5740526)\]. This work demonstrates the importance of robustness in FL when dealing with noisy and heterogeneous clients.

Furthermore, the problem of non-IID data has been studied extensively, with solutions such as synthetic data generation using GANs \[[18](http://arxiv.org/abs/2206.05507)\] and federated transfer learning (FTL) \[[2](http://arxiv.org/abs/1812.03337)\]\[[9](https://www.semanticscholar.org/paper/cc8379abcda8faa78e2c5e17deb96785ea447461)\]. FTL allows knowledge to be transferred between domains without compromising user privacy, enabling more flexible and powerful models \[[2](http://arxiv.org/abs/1812.03337)\]. These techniques illustrate the broader landscape of FL research, where privacy, efficiency, and model performance are critical considerations.

Recent work has also focused on improving the efficiency of FL by addressing communication constraints. The Communication-Efficient Federated Learning algorithm, for example, supports data and client heterogeneity while maintaining convergence guarantees \[[14](http://arxiv.org/abs/2206.10032)\]. This work underscores the need for algorithms that can handle real-world FL challenges, including partial client participation and asynchronous updates.

This approach is particularly relevant in mobile edge computing environments where clients may have varying computational capabilities and network conditions, leading to delays in model training. FedCS tackles the client selection problem under resource constraints, enabling the server to aggregate more updates and improve model performance more rapidly. This work builds upon the foundational concept of FL, which allows for decentralized training without exposing raw data \[[6](http://arxiv.org/abs/1909.12488)\]. The challenge of personalizing global models to individual devices in FL settings is also addressed in related work, where Model Agnostic Meta Learning (MAML) is explored as a potential solution for adapting models to heterogeneous data distributions \[[6](http://arxiv.org/abs/1909.12488)\]. ### <a id='category-others'></a>Others: 6 papers found.
Federated learning (FL) has emerged as a critical paradigm for enabling collaborative machine learning while preserving data privacy, with numerous studies addressing its challenges such as non-IID data, communication constraints, and heterogeneous client environments \[[12](http://arxiv.org/abs/2010.01243)\]. Early works focused on unbiased client participation and uniform sampling, which often led to slow convergence due to system and statistical heterogeneity \[[15](http://arxiv.org/abs/2112.11256)\]. Recent advancements have introduced adaptive sampling strategies to minimize wall-clock convergence time by optimizing sampling probabilities based on convergence bounds \[[15](http://arxiv.org/abs/2112.11256)\]. Additionally, biased client selection strategies, such as Power-of-Choice, have been proposed to accelerate convergence by favoring clients with higher local loss, achieving up to 3× faster convergence and 10% higher accuracy compared to random selection \[[12](http://arxiv.org/abs/2010.01243)\]. In multi-device environments, FL faces additional complexities due to user and device heterogeneity, prompting the development of user-centered approaches like FLAME, which improves inference consistency across devices and enhances energy efficiency \[[17](http://arxiv.org/abs/2202.08922)\]. To address non-IID data challenges, frameworks like Synthetic Data Aided Federated Learning (SDA-FL) have been introduced, utilizing synthetic data generated via GANs to align data distributions across clients and improve model consistency \[[18](http://arxiv.org/abs/2206.05507)\]. Furthermore, methods that combine global model aggregation with client-specific parameters have been proposed to handle disjoint classes and multi-modality in FL, demonstrating significant performance improvements in both public and proprietary datasets \[[19](http://arxiv.org/abs/2011.06393)\]. These developments highlight the ongoing efforts to enhance FL's scalability, accuracy, and efficiency in real-world applications.

### <a id='category-federated-learning-with-heterogeneity'></a>Federated Learning with Heterogeneity: 3 papers found.
The category "Federated Learning with Heterogeneity" encompasses research addressing the challenges of training machine learning models across distributed clients with non-identical data distributions. Existing federated learning approaches often assume fully labeled data at the client side, but in reality, clients may have only partially labeled or no labels at all, leading to the emergence of Federated Semi-Supervised Learning (FSSL) \[[3](http://arxiv.org/abs/2006.12097)\]. To tackle this, FedMatch introduces a novel method that incorporates an inter-client consistency loss and decomposes parameters to handle labeled and unlabeled data separately, improving performance over naive approaches \[[3](http://arxiv.org/abs/2006.12097)\]. Additionally, the heterogeneity of data across clients, such as in EEG classification tasks, poses significant challenges due to variations in data sources and subject-specific characteristics \[[13](http://arxiv.org/abs/1909.05784)\]. Recent work has proposed heterogeneous federated learning approaches that preserve data privacy while effectively training models on diverse, heterogeneous data \[[13](http://arxiv.org/abs/1909.05784)\]. Furthermore, federated learning faces practical challenges such as data heterogeneity, asynchrony in client computation, and communication constraints, which are addressed by variants of the classic FedAvg algorithm that support these system-level relaxations while maintaining convergence guarantees \[[14](http://arxiv.org/abs/2206.10032)\]. These studies collectively highlight the importance of addressing data heterogeneity in federated learning to improve model performance and scalability.

Albeit its popularity, it has been observed that FL yields suboptimal results if the local clients’ data distributions diverge. To address this issue, we present clustered FL (CFL), a novel federated multitask learning (FMTL) framework, which exploits geometric properties of the FL loss surface to group the client population into clusters with jointly trainable data distributions. CFL is flexible enough to handle client populations that vary over time and can be implemented in a privacy-preserving way. As clustering is only performed after FL has converged to a stationary point, CFL can be viewed as a postprocessing method that will always achieve greater or equal performance than conventional FL by allowing clients to arrive at more specialized models. ### <a id='category-federated-learning-robustness'></a>Federated Learning Robustness: 3 papers found.

[Snippet]: «A central challenge in training classification models in the real-world federated system is learning with non-IID data. To cope with this, most of the existing works involve enforcing regularization in local optimization or improving the model aggregation scheme at the server. Other works also share public datasets or synthesized samples to supplement the training of under-represented classes or introduce a certain level of personalization. Though effective, they lack a deep understanding of how the data heterogeneity affects each layer of a deep classification model. In this paper, we bridge this gap by performing an experimental analysis of the representations learned by different layers. Our observations are surprising: (1) there exists a greater bias in the classifier than other layers, and (2) the classification performance can be significantly improved by post-calibrating the classifier after federated training. Motivated by the above findings, we propose a novel and simple algorithm called Classifier Calibration with Virtual Representations (CCVR), which adjusts the classifier using virtual representations sampled from an approximated gaussian mixture model. Experimental results demonstrate that CCVR achieves state-of-the-art performance on popular federated learning benchmarks including CIFAR-10, CIFAR-100, and CINIC-10.»

[Snippet]: «We introduce a new and increasingly relevant setting for distributed optimization in machine learning, where the data defining the optimization are distributed (unevenly) over an extremely large number of \nodes, but the goal remains to train a high-quality centralized model. We refer to this setting as Federated Optimization. In this setting, communication efficiency is of utmost importance. 
A motivating example for federated optimization arises when we keep the training data locally on users' mobile devices rather than logging it to a data center for training. Instead, the mobile devices are used as nodes performing computation on their local data in order to update a global model. We suppose that we have an extremely large number of devices in our network, each of which has only a tiny fraction of data available totally; in particular, we expect the number of data points available locally to be much smaller than the number of devices. Additionally, since different users generate data with different patterns, we assume that no device has a representative sample of the overall distribution. 
We show that existing algorithms are not suitable for this setting, and propose a new algorithm which shows encouraging experimental results. This work also sets a path for future research needed in the context of federated optimization.»
