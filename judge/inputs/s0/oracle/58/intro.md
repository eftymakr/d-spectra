## Related Works

Table discovery has emerged as a critical task in data management, especially with the proliferation of data lakes and repositories containing vast amounts of tabular data. Existing approaches primarily rely on keyword-based or query table-based retrieval, often leading to large result sets that require manual filtering \[[12](http://arxiv.org/abs/1802.06159)\]. This limitation highlights the need for more sophisticated methods that can incorporate natural language (NL) requirements to refine search results. Our proposed task, NL-conditional table discovery (nlcTD), aligns with this need by enabling users to combine a query table with NL conditions to improve search accuracy \[[1](http://arxiv.org/abs/2105.01736)\].

Several recent works have explored table retrieval and discovery, focusing on improving semantic understanding and structural awareness. For instance, StruBERT introduces a structure-aware BERT model that fuses textual and structural information of a table to produce context-aware representations \[[2](http://arxiv.org/abs/2203.14278)\]. This model is integrated into an end-to-end neural ranking system to solve keyword- and content-based table retrieval and table similarity tasks. Similarly, GTR proposes a generalizable framework with multi-granular graph representation learning, converting tables into tabular graphs and using a Graph Transformer to capture both content and layout structures \[[1](http://arxiv.org/abs/2105.01736)\]. These approaches emphasize the importance of integrating structural and semantic information for better retrieval performance.

In the context of data lakes, several studies have focused on discovering joinable and unionable tables. PEXESO, for example, embeds textual values as high-dimensional vectors and uses similarity predicates to identify joinable tables, addressing limitations of equi-join approaches \[[8](http://arxiv.org/abs/2010.13273)\]. SANTOS improves union search by leveraging semantic relationships between columns, introducing a new notion of unionability that considers column relationships and semantics \[[5](http://arxiv.org/abs/2209.13589)\]. Starmie, on the other hand, proposes a contrastive learning method for column encoders, enabling efficient and effective table union search \[[6](http://arxiv.org/abs/2210.01922)\]. These methods highlight the importance of semantic and structural understanding in table discovery tasks.

DeepJoin further advances the field by proposing a deep learning model that uses pre-trained language models (PLMs) to embed columns into vectors, enabling accurate and efficient joinable table discovery \[[9](http://arxiv.org/abs/2212.07588)\]. This approach is designed to handle both equi- and semantic joins, offering a flexible and scalable solution. Additionally, TURL introduces a pre-training/fine-tuning paradigm for relational Web tables, learning deep contextualized representations through a structure-aware Transformer encoder and a new Masked Entity Recovery (MER) objective \[[7](http://arxiv.org/abs/2006.14806)\]. These models demonstrate the potential of leveraging pre-trained language models for table understanding and retrieval.
