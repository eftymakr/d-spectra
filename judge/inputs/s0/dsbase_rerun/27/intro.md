## Related Works

Recent advancements in information retrieval have introduced differentiable search indexing (DSI) as a promising paradigm for improving both relevance and diversity in retrieval tasks \[[1' 2025-02-05](http://arxiv.org/abs/2502.02788v1)\]. Traditional dense vector search pipelines, which follow a representation-index-search workflow, have been widely used for table discovery tasks \[[11' 2022-05-31](http://arxiv.org/abs/2205.15503v3)\]. However, these methods face limitations such as error accumulation during representation and indexing, and insufficient query-table interaction, which hinders semantic alignment \[[1' 2025-02-05](http://arxiv.org/abs/2502.02788v1)\]. 

Several works have explored the use of DSI for information retrieval. For instance, \[[1' 2025-02-05](http://arxiv.org/abs/2502.02788v1)\] investigates the balance between relevance and diversity in DSI training, showing that diversity can be achieved without compromising relevance. This aligns with the goal of Birdie, which aims to unify indexing and search within a single encoder-decoder language model to eliminate error accumulation \[[1' 2025-02-05](http://arxiv.org/abs/2502.02788v1)\]. 

The concept of differentiable search indexing has also been extended to decentralized settings, as seen in De-DSI, which enables efficient query-document retrieval without direct access to documents \[[4' 2024-04-18](http://arxiv.org/abs/2404.12237v2)\]. This is particularly relevant for Birdie, which operates on query-docid pairs and leverages large language models (LLMs) for query generation \[[1' 2025-02-05](http://arxiv.org/abs/2502.02788v1)\]. 

Moreover, the use of synthetic data for training and improving table representations has been explored in \[[3' 2024-11-04](http://arxiv.org/abs/2411.03356v1)\], where LLMs are used to generate high-quality synthetic data for table-level representation learning. This approach is similar to how Birdie generates synthetic queries for each table to enhance query-table interactions \[[1' 2025-02-05](http://arxiv.org/abs/2502.02788v1)\]. 

In the context of continual learning, \[[7' 2021-04-21](http://arxiv.org/abs/2104.10450v1)\] addresses performance collapse in differentiable neural architecture search (DARTS) by proposing a global optimization scheme that improves the discovery of better architectures. This is analogous to the parameter isolation strategy in Birdie, which mitigates catastrophic forgetting during continual indexing \[[1' 2025-02-05](http://arxiv.org/abs/2502.02788v1)\]. 

Additionally, \[[13' 2024-09-30](http://arxiv.org/abs/2410.00169v1)\] introduces a differentiable regularizer that promotes numerical stability in neural networks by reducing the condition number of weight matrices. While not directly related to table discovery, this work highlights the importance of numerical stability in training models that perform complex tasks like query-table alignment \[[1' 2025-02-05](http://arxiv.org/abs/2502.02788v1)\]. 

The field of semantic communication has also seen significant progress, with \[[14' 2022-12-02](http://arxiv.org/abs/2212.01485v4)\] introducing a framework for characterizing semantic communication through language exploitation and design. Although not directly related to table discovery, this work underscores the importance of semantic alignment in information retrieval, which is a key component of Birdie's approach \[[1' 2025-02-05](http://arxiv.org/abs/2502.02788v1)\].
