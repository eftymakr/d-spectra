## Related Works

De novo genome assembly has been a central challenge in bioinformatics, with significant advancements in both algorithmic approaches and computational infrastructure. Early methods, such as those based on de Bruijn graphs, have been widely used for their ability to handle short-read sequencing data \[[5' 2011-06-14](http://arxiv.org/abs/1106.2603v1)\]. However, these methods face limitations in terms of memory usage and scalability, especially with the growing volume of genomic data \[[5' 2011-06-14](http://arxiv.org/abs/1106.2603v1)\]. The large memory footprint and memory-bound behavior of these algorithms have been well documented, highlighting the need for more efficient approaches \[[19' 2012-11-08](http://arxiv.org/abs/1211.1737v1)\]. 

Several studies have explored the use of distributed systems to address the computational demands of de novo assembly. For instance, the PPA-assembler toolkit leverages the de Bruijn graph approach within a distributed setting, demonstrating improved efficiency over state-of-the-art methods \[[6' 2018-01-13](http://arxiv.org/abs/1801.04453v1)\]. Similarly, the ELBA algorithm has been enhanced with GPU schedulers to improve performance, particularly in handling the pairwise alignment bottleneck \[[3' 2023-09-13](http://arxiv.org/abs/2309.07270v2)\]. These efforts underscore the importance of parallelism and distributed computing in scaling de novo assembly to large datasets.

The use of long-read sequencing has also been a key area of research, enabling more accurate and contiguous assemblies. Tools like Minimap and Miniasm have been developed to efficiently map and assemble long reads without requiring an error correction stage, significantly reducing the time required for bacterial and higher eukaryotic genome assembly \[[10' 2015-12-06](http://arxiv.org/abs/1512.01801v2)\]. Additionally, the Bermuda assembler has been designed to handle uneven coverage and expression levels in RNA-seq data, offering improved performance over existing de novo assemblers \[[14' 2015-06-18](http://arxiv.org/abs/1506.05538v1)\].

Recent advancements in hardware-software co-design have further addressed the computational challenges of de novo assembly. For example, the SparseAssembler introduces a sparse de Bruijn graph structure, significantly reducing memory requirements while maintaining comparable assembly quality \[[5' 2011-06-14](http://arxiv.org/abs/1106.2603v1)\]. This approach is particularly beneficial for large-scale genome analysis and for sequencing centers handling multiple genomes simultaneously. Furthermore, the hifiasm assembler has been developed to achieve haplotype-resolved assemblies, leveraging long, high-fidelity reads to accurately represent haplotype information \[[16' 2020-08-03](http://arxiv.org/abs/2008.01237v1)\].

The challenges of de novo assembly have also been addressed through novel algorithmic approaches. The Pregel framework has been used to implement scalable de novo assembly algorithms, demonstrating improved performance on large real and simulated datasets \[[6' 2018-01-13](http://arxiv.org/abs/1801.04453v1)\]. Additionally, the development of GPU-based schedulers and memory-aware algorithms has shown promise in reducing computational bottlenecks and improving overall efficiency \[[3' 2023-09-13](http://arxiv.org/abs/2309.07270v2)\]\[[12' 2022-08-10](http://arxiv.org/abs/2208.05429v1)\].
