## Related Works

Event cameras, also known as neuromorphic sensors, capture changes in local light intensity at the pixel level, producing asynchronously generated data termed ``events`` \[[2' 2024-08-19](http://arxiv.org/abs/2408.10395v1)\]. This distinct data format mitigates common issues observed in conventional cameras, such as under-sampling when capturing fast-moving objects, thereby preserving critical information that might otherwise be lost \[[2' 2024-08-19](http://arxiv.org/abs/2408.10395v1)\]. However, leveraging this data often necessitates the development of specialized, handcrafted event representations that can integrate seamlessly with conventional Convolutional Neural Networks (CNNs), considering the unique attributes of event data \[[2' 2024-08-19](http://arxiv.org/abs/2408.10395v1)\].

Prior work has explored event downsampling to address the high bandwidth, memory, and computational demands of event cameras \[[1' 2025-04-25](http://arxiv.org/abs/2504.18235v2)\]. Most approaches rely on fixed heuristics or threshold-based strategies, limiting their adaptability \[[1' 2025-04-25](http://arxiv.org/abs/2504.18235v2)\]. For instance, some methods use fixed thresholds to filter events, which may not be optimal for all applications \[[5' 2021-05-02](http://arxiv.org/abs/2105.00409v1)\]. These methods are typically offline and cannot adapt to scene-specific requirements \[[1' 2025-04-25](http://arxiv.org/abs/2504.18235v2)\].

In contrast, our approach introduces a probabilistic framework, POLED, that models event importance through an event-importance probability density function (ePDF), which can be arbitrarily defined and adapted to different applications \[[1' 2025-04-25](http://arxiv.org/abs/2504.18235v2)\]. This is a significant advancement over fixed heuristics, as it enables scene-specific adaptation \[[1' 2025-04-25](http://arxiv.org/abs/2504.18235v2)\]. Additionally, we introduce zero-shot event downsampling, where downsampled events must remain usable for models trained on the original event stream, without task-specific adaptation \[[1' 2025-04-25](http://arxiv.org/abs/2504.18235v2)\]. This is a novel contribution, as most prior work assumes task-specific adaptation \[[1' 2025-04-25](http://arxiv.org/abs/2504.18235v2)\].

The design of the ePDF is crucial for maintaining performance under event-budget constraints. We propose a contour-preserving ePDF that prioritizes structurally important events \[[1' 2025-04-25](http://arxiv.org/abs/2504.18235v2)\]. This approach is inspired by the need for intelligent sampling to maintain performance, as demonstrated in various applications such as object classification, image interpolation, surface normal estimation, and object detection \[[1' 2025-04-25](http://arxiv.org/abs/2504.18235v2)\].

Several studies have focused on simulating event camera data for training models for detection and estimation tasks \[[3' 2025-04-16](http://arxiv.org/abs/2504.12515v2)\]. However, the fundamentally different sensor design of event cameras compared to traditional frame-based cameras poses a challenge for accurate simulation \[[3' 2025-04-16](http://arxiv.org/abs/2504.12515v2)\]. As a result, most simulated data fail to mimic data captured by real event cameras \[[3' 2025-04-16](http://arxiv.org/abs/2504.12515v2)\]. To address this, researchers have proposed metrics like the Event Quality Score (EQS), which utilizes activations of the RVT architecture to assess the realism of simulated event camera streams \[[3' 2025-04-16](http://arxiv.org/abs/2504.12515v2)\].
