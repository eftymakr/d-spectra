## Related Works

Semi-supervised learning (SSL) has been widely studied for its ability to leverage unlabeled data to improve model performance with limited labeled data \[[1' 2021-05-28](http://arxiv.org/abs/2105.14148v2)\]. However, conventional SSL methods typically assume that both labeled and unlabeled data share the same class distribution \[[1' 2021-05-28](http://arxiv.org/abs/2105.14148v2)\]. This assumption is often violated in practice, as unlabeled data may contain outliers—samples from unknown classes \[[1' 2021-05-28](http://arxiv.org/abs/2105.14148v2)\]. These outliers are typically treated as noise, which can significantly degrade SSL performance \[[1' 2021-05-28](http://arxiv.org/abs/2105.14148v2)\]. Several recent works have attempted to address this issue by introducing open-set semi-supervised learning (OSSL) frameworks \[[1' 2021-05-28](http://arxiv.org/abs/2105.14148v2)\].

One early approach, OpenMatch, integrates FixMatch with novelty detection using one-vs-all (OVA) classifiers to detect outliers \[[1' 2021-05-28](http://arxiv.org/abs/2105.14148v2)\]. The OVA classifier provides a confidence score for inlier classification, which helps in identifying outliers \[[1' 2021-05-28](http://arxiv.org/abs/2105.14148v2)\]. Another method, SSB, improves both inlier classification and outlier detection by incorporating high-confidence pseudo-labeled data and utilizing non-linear transformations to separate features used for inlier classification and outlier detection \[[2' 2023-11-17](http://arxiv.org/abs/2311.10572v1)\]. This separation prevents adverse effects between the two tasks \[[2' 2023-11-17](http://arxiv.org/abs/2311.10572v1)\].

In the domain of object detection, OpenCoS introduces a framework that leverages self-supervised contrastive learning to identify out-of-class samples in the unlabeled dataset \[[8' 2021-06-29](http://arxiv.org/abs/2107.08943v3)\]. This helps overcome failure modes in existing semi-supervised methods by using one-hot pseudo-labels and soft-labels for inlier and out-of-class samples, respectively \[[8' 2021-06-29](http://arxiv.org/abs/2107.08943v3)\]. Similarly, IOMatch proposes a framework that jointly utilizes inliers and outliers, even when distinguishing between them is challenging \[[4' 2023-08-25](http://arxiv.org/abs/2308.13168v1)\]. This approach avoids the performance degradation caused by unreliable outlier detectors \[[4' 2023-08-25](http://arxiv.org/abs/2308.13168v1)\].

WiseOpen introduces a robust open-set data selection strategy that selectively leverages open-set data for training \[[5' 2024-05-11](http://arxiv.org/abs/2405.06979v2)\]. This strategy improves ID classification performance by using a gradient-variance-based selection mechanism \[[5' 2024-05-11](http://arxiv.org/abs/2405.06979v2)\]. Additionally, self-supervision has been explored in OSSL to learn from all unlabeled data, as seen in the work of \[[6' 2023-01-24](http://arxiv.org/abs/2301.10127v3)\], which utilizes an energy-based score to accurately recognize data from known classes \[[6' 2023-01-24](http://arxiv.org/abs/2301.10127v3)\].

Contrastive regularization has also been proposed to improve the efficiency and accuracy of consistency regularization in SSL \[[13' 2022-01-17](http://arxiv.org/abs/2201.06247v2)\]. This method leverages well-clustered features of unlabeled data to propagate information of confident pseudo-labels into more unlabeled samples during training \[[13' 2022-01-17](http://arxiv.org/abs/2201.06247v2)\].
