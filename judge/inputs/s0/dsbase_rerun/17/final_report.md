## Related Works

Semi-supervised learning (SSL) has been widely studied for its ability to leverage unlabeled data to improve model performance with limited labeled data \[[1' 2021-05-28](http://arxiv.org/abs/2105.14148v2)\]. However, conventional SSL methods typically assume that both labeled and unlabeled data share the same class distribution \[[1' 2021-05-28](http://arxiv.org/abs/2105.14148v2)\]. This assumption is often violated in practice, as unlabeled data may contain outliers—samples from unknown classes \[[1' 2021-05-28](http://arxiv.org/abs/2105.14148v2)\]. These outliers are typically treated as noise, which can significantly degrade SSL performance \[[1' 2021-05-28](http://arxiv.org/abs/2105.14148v2)\]. Several recent works have attempted to address this issue by introducing open-set semi-supervised learning (OSSL) frameworks \[[1' 2021-05-28](http://arxiv.org/abs/2105.14148v2)\].

One early approach, OpenMatch, integrates FixMatch with novelty detection using one-vs-all (OVA) classifiers to detect outliers \[[1' 2021-05-28](http://arxiv.org/abs/2105.14148v2)\]. The OVA classifier provides a confidence score for inlier classification, which helps in identifying outliers \[[1' 2021-05-28](http://arxiv.org/abs/2105.14148v2)\]. Another method, SSB, improves both inlier classification and outlier detection by incorporating high-confidence pseudo-labeled data and utilizing non-linear transformations to separate features used for inlier classification and outlier detection \[[2' 2023-11-17](http://arxiv.org/abs/2311.10572v1)\]. This separation prevents adverse effects between the two tasks \[[2' 2023-11-17](http://arxiv.org/abs/2311.10572v1)\].

In the domain of object detection, OpenCoS introduces a framework that leverages self-supervised contrastive learning to identify out-of-class samples in the unlabeled dataset \[[8' 2021-06-29](http://arxiv.org/abs/2107.08943v3)\]. This helps overcome failure modes in existing semi-supervised methods by using one-hot pseudo-labels and soft-labels for inlier and out-of-class samples, respectively \[[8' 2021-06-29](http://arxiv.org/abs/2107.08943v3)\]. Similarly, IOMatch proposes a framework that jointly utilizes inliers and outliers, even when distinguishing between them is challenging \[[4' 2023-08-25](http://arxiv.org/abs/2308.13168v1)\]. This approach avoids the performance degradation caused by unreliable outlier detectors \[[4' 2023-08-25](http://arxiv.org/abs/2308.13168v1)\].

### <a id='category-open-set-ssl-frameworks'></a>Open-Set SSL Frameworks: 9 papers found.
Open-set semi-supervised learning (Open-set SSL) addresses the challenge where unlabeled data may contain outliers from novel categories not present in the labeled set, which can degrade model performance \[[1' 2021-05-28](http://arxiv.org/abs/2105.14148v2)\]. Existing methods often rely on outlier detection via binary classifiers or assume that pseudo-labeled data is reliable, which can lead to performance degradation when labels are scarce \[[2' 2023-11-17](http://arxiv.org/abs/2311.10572v1)\]. To mitigate this, frameworks like OpenMatch integrate novelty detection with FixMatch, using one-vs-all classifiers to identify inliers and reject outliers \[[1' 2021-05-28](http://arxiv.org/abs/2105.14148v2)\]. Similarly, the Simple but Strong Baseline (SSB) improves inlier classification by incorporating high-confidence pseudo-labeled data and utilizes non-linear transformations to separate inlier and outlier features in a multi-task learning framework \[[2' 2023-11-17](http://arxiv.org/abs/2311.10572v1)\]. Another approach, IOMatch, jointly utilizes inliers and outliers by introducing a multi-binary classifier that treats all outliers as a single class, enhancing robustness even when distinguishing between them is difficult \[[4' 2023-08-25](http://arxiv.org/abs/2308.13168v1)\]. Additionally, Adaptive Negative Evidential Deep Learning (ANEDL) introduces evidential deep learning to quantify uncertainty and employs an adaptive negative optimization strategy to improve outlier detection \[[7' 2023-03-21](http://arxiv.org/abs/2303.12091v4)\]. OpenCoS leverages self-supervised contrastive learning to identify out-of-class samples in open-set unlabeled data, using one-hot pseudo-labels and soft-labels for inliers and outliers respectively \[[8' 2021-06-29](http://arxiv.org/abs/2107.08943v3)\]. These methods collectively highlight the importance of robust outlier detection, uncertainty quantification, and leveraging both inlier and outlier data to improve performance in open-set SSL scenarios.

[Snippet]: «A new semi-supervised ensemble algorithm called XGBOD (Extreme Gradient Boosting Outlier Detection) is proposed, described and demonstrated for the enhanced detection of outliers from normal observations in various practical datasets. The proposed framework combines the strengths of both supervised and unsupervised machine learning methods by creating a hybrid approach that exploits each of their individual performance capabilities in outlier detection. XGBOD uses multiple unsupervised outlier mining algorithms to extract useful representations from the underlying data that augment the predictive capabilities of an embedded supervised classifier on an improved feature space. The novel approach is shown to provide superior performance in comparison to competing individual detectors, the full ensemble and two existing representation learning based algorithms across seven outlier datasets.»
