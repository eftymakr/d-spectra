## Related Works

Multi-token prediction (MTP) has emerged as a promising alternative to traditional next-token prediction (NTP) in language model pre-training. While NTP focuses on predicting one token at a time, MTP extends this by predicting multiple tokens simultaneously, using multiple prediction heads \[[6' 2024-04-30](http://arxiv.org/abs/2404.19737v1)\]. This approach has shown potential in improving downstream performance, inference speed, and training efficiency, particularly for large language models \[[6' 2024-04-30](http://arxiv.org/abs/2404.19737v1)\]. However, smaller language models (SLMs) have struggled with the MTP objective, prompting researchers to explore curriculum learning strategies to address this limitation \[[6' 2024-04-30](http://arxiv.org/abs/2404.19737v1)\].

Curriculum learning has been widely studied in various domains, including computer vision and machine translation, where it has been used to improve model training speed and performance \[[3' 2021-08-04](http://arxiv.org/abs/2108.02170v1)\]. In the context of language modeling, prior work has not found compelling evidence that curriculum learning methods improve language model training \[[3' 2021-08-04](http://arxiv.org/abs/2108.02170v1)\]. However, recent studies have demonstrated that curriculum learning can significantly enhance the performance of small decoder-only code language models on code execution tasks \[[2' 2024-07-14](http://arxiv.org/abs/2407.10194v1)\]. This suggests that curriculum learning may be particularly beneficial for SLMs when applied to specific tasks like code generation.

In the realm of multi-token prediction, several approaches have been proposed. For instance, Future Token Prediction (FTP) introduces a novel pretraining method where a large transformer encoder generates embedding vectors that are cross-attended by a small decoder to predict multiple future tokens \[[1' 2024-10-23](http://arxiv.org/abs/2410.18160v1)\]. This method has shown improvements in topic coherence and text classification performance compared to standard GPT models \[[1' 2024-10-23](http://arxiv.org/abs/2410.18160v1)\]. Similarly, DynaMo proposes a suite of multi-token prediction language models that dynamically predict multiple tokens based on their confidence in the joint probability distribution, achieving significant speedups in inference time \[[5' 2024-05-01](http://arxiv.org/abs/2405.00888v1)\].

Another approach, Leap Multi-Token Prediction (L-MTP), extends multi-token prediction by introducing a leap-based mechanism that skips intermediate tokens, enabling non-sequential token prediction in a single forward pass \[[7' 2025-05-23](http://arxiv.org/abs/2505.17505v2)\]. This method enhances the model's ability to capture long-range dependencies and improves inference efficiency \[[7' 2025-05-23](http://arxiv.org/abs/2505.17505v2)\]. Additionally, MuToR introduces a simple and effective approach to multi-token prediction by interleaving learnable register tokens into the input sequence, offering advantages such as minimal parameter overhead and compatibility with off-the-shelf pretrained models \[[8' 2025-05-15](http://arxiv.org/abs/2505.10518v1)\].

[Snippet]: «Causal decoder-only transformer models used for generative language modelling, such as Generative Pre-trained Transformers (GPT), are trained to predict the next token in a sequence based only on its previous tokens. Despite this simple training objective, they have proved to be powerful AI tools. However, only predicting the next token results in top layer embedding vectors that are highly token-focused. There may be benefits in generating embedding vectors at each token position that better capture the overall meaning of longer sequences of future text. Recent studies matching brain scans with deep language models suggest that humans also predict upcoming words when listening or reading but consider multiple future tokens rather than just one.
  This research investigates a new pretraining method called Future Token Prediction (FTP). In FTP, a large transformer encoder generates top layer embedding vectors for each token position, which, instead of being passed to a language head, are linearly and expansively projected to a pseudo-sequence, which is cross attended to by a small transformer decoder to predict the next N tokens forward from that position in the sequence.
  The top layer embedding vectors from FTP models exhibit distinct properties compared to those from standard GPT models, varying smoothly along a text sequence as measured by cosine similarity between adjacent tokens. Text generated by FTP models show improved topic coherence compared to standard GPT-like models trained with the same prediction perplexity for the next single token. The vectors are shown to better represent the topic of text based on the results of text classification examples. On a toy, but complex, coding problem, FTP networks produce significantly better results than GPT networks.»

### <a id='category-curriculum-learning-in-language-models'></a>Curriculum Learning in Language Models: 5 papers found.
Curriculum learning has been explored in various contexts within language models, with differing outcomes across domains. In code language models, curriculum learning has shown promising results, particularly in improving the accuracy of small decoder-only models on code execution tasks, although its impact on code completion remains less significant \[[2' 2024-07-14](http://arxiv.org/abs/2407.10194v1)\]. In contrast, for natural language processing, studies have found limited evidence that curriculum learning enhances language model pretraining, despite its success in computer vision and machine translation \[[3' 2021-08-04](http://arxiv.org/abs/2108.02170v1)\]. Additionally, curriculum learning has been applied in reinforcement learning to guide agents through increasingly complex tasks, improving initial performance and reducing suboptimal actions during exploration \[[4' 2019-01-31](http://arxiv.org/abs/1901.11478v3)\]. In clinical settings, a student-teacher network with reinforcement learning has been used to create a curriculum based on data entropy, leading to improved performance in hospital admission prediction \[[13' 2020-07-01](http://arxiv.org/abs/2007.01135v1)\]. Furthermore, in quantum machine learning, curriculum learning has been proposed to address training complexity and generalization issues by introducing simpler tasks before progressing to more complex ones, showing robustness to noise and data limitations \[[14' 2024-07-02](http://arxiv.org/abs/2407.02419v4)\]. These findings highlight the varied effectiveness of curriculum learning across different model types and tasks, underscoring the need for tailored approaches.

### <a id='category-inference-efficiency-enhancements'></a>Inference Efficiency Enhancements: 3 papers found.
Inference efficiency enhancements have been a focal point in improving the performance and scalability of large language models (LLMs). Recent approaches such as DynaMo \[[5' 2024-05-01](http://arxiv.org/abs/2405.00888v1)\] and Leap Multi-Token Prediction (L-MTP) \[[7' 2025-05-23](http://arxiv.org/abs/2505.17505v2)\] aim to reduce inference times by predicting multiple tokens simultaneously, deviating from the traditional next-token prediction (NTP) paradigm. DynaMo dynamically predicts multiple tokens based on confidence in the joint probability distribution, achieving a 2.57× speed-up with minimal overhead, while L-MTP introduces a leap-based mechanism to skip intermediate tokens, enabling non-sequential prediction and improving inference efficiency through optimized decoding strategies. Additionally, multi-word tokenizers like MWT \[[11' 2024-02-15](http://arxiv.org/abs/2402.09949v2)\] offer efficiency gains by compactly representing frequent multi-word expressions, reducing sequence length and enabling faster inference without significant performance loss. These methods collectively address the computational bottlenecks of autoregressive models, enhancing both inference speed and model efficiency.

### <a id='category-multi-token-prediction-(mtp)-frameworks'></a>Multi-Token Prediction (MTP) Frameworks: 2 papers found.
Multi-Token Prediction (MTP) frameworks have gained traction as a more efficient alternative to traditional next-token prediction (NTP) in training large language models. By predicting multiple future tokens simultaneously, MTP can enhance sample efficiency and improve downstream performance, particularly for large models, as demonstrated by models achieving up to 17% better results on benchmarks like MBPP \[[6' 2024-04-30](http://arxiv.org/abs/2404.19737v1)\]. This approach also leads to faster inference times, with models trained using 4-token prediction showing up to 3 times speed improvements \[[6' 2024-04-30](http://arxiv.org/abs/2404.19737v1)\]. However, smaller language models face challenges with MTP, prompting the development of curriculum learning strategies to gradually adapt models to the MTP objective \[[1' 2024-10-23](http://arxiv.org/abs/2410.18160v1)\]. Recent work such as MuToR introduces a flexible and efficient method for multi-token prediction, integrating learnable register tokens into the input sequence, which allows for scalable prediction horizons without significant architectural changes or parameter overhead \[[8' 2025-05-15](http://arxiv.org/abs/2505.10518v1)\]. These advancements highlight the potential of MTP to improve both training efficiency and model capabilities across a range of tasks, from coding to vision \[[8' 2025-05-15](http://arxiv.org/abs/2505.10518v1)\].
