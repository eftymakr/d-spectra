## Related Works

Long-tailed recognition remains a challenging problem in computer vision due to the significant imbalance in class distribution, where a few dominant classes (head classes) contain the majority of the data, while the remaining classes (tail classes) are severely underrepresented \[[1](http://arxiv.org/abs/2403.06151)\]. This imbalance leads to biased feature learning and poor generalization performance on tail classes \[[2](http://arxiv.org/abs/2306.15925)\]. Several approaches have been proposed to address this issue, primarily focusing on data augmentation, loss function design, and contrastive learning strategies.

Contrastive learning has emerged as a powerful technique for representation learning, particularly in visual tasks. Supervised Contrastive Loss (SCL) is widely used, as it pulls positive samples (augmented versions of the anchor and other same-class images) together while pushing negative samples apart \[[3](http://arxiv.org/abs/2309.11177)\]. However, in long-tailed recognition, SCL suffers from imbalanced intra-category distances and ignores the semantic relationships among negative samples \[[3](http://arxiv.org/abs/2309.11177)\]. To address these issues, decoupled contrastive learning has been proposed, which separates the optimization of positive samples to alleviate the bias caused by class imbalance \[[1](http://arxiv.org/abs/2403.06151)\]. Additionally, subclass-balancing contrastive learning (SBCL) has been introduced to cluster head classes into subclasses of similar sizes as tail classes, enabling the model to learn a two-layer class hierarchy and capture semantic substructures \[[2](http://arxiv.org/abs/2306.15925)\].

To further improve performance, methods such as Balanced Contrastive Learning (BCL) have been proposed, which introduces class-averaging and class-complement strategies to balance the gradient contributions of negative classes and ensure all classes appear in every mini-batch \[[5](http://arxiv.org/abs/2207.09052)\]. This helps in forming a regular simplex, which is crucial for effective representation learning \[[5](http://arxiv.org/abs/2207.09052)\]. Similarly, Targeted Supervised Contrastive Learning (TSC) has been developed to improve the uniformity of feature distribution on the hypersphere, ensuring that minority classes are not overshadowed by majority classes \[[8](http://arxiv.org/abs/2111.13998)\].

Another approach, SMCL (Saliency Masked Contrastive Learning), uses saliency masking to reduce the influence of background features common to all classes, thereby improving the generalizability of the model \[[6](http://arxiv.org/abs/2406.02223)\]. In addition, methods like Rebalanced Siamese Contrastive Mining (ResCom) have been proposed to address the dual class-imbalance problem at both the original batch and Siamese batch levels, ensuring more effective contrastive learning \[[25](http://arxiv.org/abs/2203.11506)\].

### <a id='category-class-imbalance-in-recognition-tasks'></a>Class Imbalance in Recognition Tasks: 14 papers found.
Long-tailed recognition remains a critical challenge in visual recognition tasks due to the imbalance in class distribution, where a few head classes dominate the dataset while tail classes are severely underrepresented \[[1](http://arxiv.org/abs/2403.06151)\]. Existing methods, such as data reweighing, resampling, and supervised contrastive learning (SCL), have attempted to address this issue, but they often introduce imbalances between head and tail classes or fail to capture the rich semantic substructures of head classes \[[2](http://arxiv.org/abs/2306.15925)\]. For example, SCL pulls positive samples together and pushes negative samples apart, but treating both types of positives equally can lead to biased intra-category distances in long-tailed scenarios \[[1](http://arxiv.org/abs/2403.06151)\]. To mitigate this, researchers have proposed approaches like subclass-balancing contrastive learning (SBCL), which clusters head classes into subclasses to enforce a two-layer class hierarchy and preserve semantic substructures \[[2](http://arxiv.org/abs/2306.15925)\]. Additionally, methods like saliency masked contrastive learning use saliency detection to mask important image regions, reducing background feature correlations and improving generalizability \[[6](http://arxiv.org/abs/2406.02223)\]. Others, such as the Latent Categories based long-tail Recognition (LCReg), focus on learning shared latent features between head and tail classes to enhance feature representation \[[12](http://arxiv.org/abs/2309.07186)\]. Furthermore, probabilistic contrastive (ProCo) learning estimates class distributions in the feature space to generate contrastive pairs, addressing the challenge of insufficient data for tail classes \[[17](http://arxiv.org/abs/2403.06726)\]. These approaches highlight the evolving strategies for tackling long-tailed recognition, emphasizing the need for more principled and theoretically grounded solutions \[[14](http://arxiv.org/abs/2408.00483)\].

[Snippet]: «Deep neural networks perform poorly on heavily class-imbalanced datasets. Given the promising performance of contrastive learning, we propose Rebalanced Siamese Contrastive Mining (ResCom) to tackle imbalanced recognition. Based on the mathematical analysis and simulation results, we claim that supervised contrastive learning suffers a dual class-imbalance problem at both the original batch and Siamese batch levels, which is more serious than long-tailed classification learning. In this paper, at the original batch level, we introduce a class-balanced supervised contrastive loss to assign adaptive weights for different classes. At the Siamese batch level, we present a class-balanced queue, which maintains the same number of keys for all classes. Furthermore, we note that the imbalanced contrastive loss gradient with respect to the contrastive logits can be decoupled into the positives and negatives, and easy positives and easy negatives will make the contrastive gradient vanish. We propose supervised hard positive and negative pairs mining to pick up informative pairs for contrastive computation and improve representation learning. Finally, to approximately maximize the mutual information between the two views, we propose Siamese Balanced Softmax and joint it with the contrastive loss for one-stage training. Extensive experiments demonstrate that ResCom outperforms the previous methods by large margins on multiple long-tailed recognition benchmarks. Our code and models are made publicly available at: https://github.com/dvlab-research/ResCom.»
