## Related Works

Calibration of predictive models has been a central topic in machine learning, particularly for ensuring that predicted probabilities reflect the true likelihood of events. Traditional approaches to calibration often rely on predefined transformation functions, such as Platt Scaling or isotonic regression, which are order-preserving but limited in expressiveness \[[13](http://arxiv.org/abs/1710.08901)\]. These methods typically assume a fixed functional form, such as piece-wise linear, which may not be sufficient for complex calibration tasks \[[13](http://arxiv.org/abs/1710.08901)\]. In contrast, recent work has explored the use of neural networks to learn more flexible and expressive calibration functions \[[11](http://arxiv.org/abs/2203.09278)\]. 

The use of monotonic neural networks for calibration has been explored in several studies. For example, the Unconstrained Monotonic Neural Network (UMNN) has been proposed as a flexible architecture that can learn arbitrary monotonic functions while preserving the ordering of predictions \[[1](http://arxiv.org/abs/1908.05164)\]. This property is crucial for calibration, as it ensures that the calibrated predictions maintain the relative order of the original outputs. The UMNN has been applied in distributional reinforcement learning, where it enables the efficient modeling of different representations of the random return distribution \[[2](http://arxiv.org/abs/2106.03228)\]. This work highlights the potential of monotonic neural networks to improve the flexibility and expressiveness of calibration methods.

In the context of ranking systems, the importance of both calibration and ranking quality has been emphasized. The Self-Boosted framework for Calibrated Ranking (SBCR) addresses the limitations of existing multi-objective methods by introducing a calibration module that decouples the point loss and ranking loss \[[4](http://arxiv.org/abs/2406.08010)\]. This approach allows for a more optimal trade-off between calibration and ranking performance. Additionally, the work on improving model calibration with accuracy versus uncertainty optimization introduces a differentiable accuracy versus uncertainty calibration (AvUC) loss function, which enables models to learn well-calibrated uncertainties while maintaining high accuracy \[[5](http://arxiv.org/abs/2012.07923)\]. This method has been shown to outperform existing calibration techniques on large-scale image classification tasks under distributional shift.

Furthermore, the concept of self-calibrating conformal prediction has been introduced, combining Venn-Abers calibration with conformal prediction to deliver both calibrated point predictions and prediction intervals with finite-sample validity \[[7](http://arxiv.org/abs/2402.07307)\]. This approach extends the original Venn-Abers procedure to regression, allowing for the construction of conditionally valid prediction intervals based on calibrated predictions. The results show that model calibration can significantly improve interval efficiency.
