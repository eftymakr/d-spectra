## Related Works

KV cache management has emerged as a critical area of research for improving the efficiency and performance of large language model (LLM) serving systems. Prior work has focused on reducing redundant computations and improving memory utilization during inference. For instance, KV cache reuse has been widely studied as a means to accelerate LLM inference by avoiding recomputation of previously generated tokens \[[2](http://arxiv.org/abs/2412.19442)\]. This approach has been extended to multi-tenant scenarios, where shared KV caches across requests are managed to maintain model accuracy while improving system efficiency \[[1](http://arxiv.org/abs/2503.16525)\]. 

Several studies have explored the design of cache eviction policies to optimize memory usage and performance. For example, \[[12](http://arxiv.org/abs/2408.03675)\] introduces a general framework for long-context KV cache eviction, combining accurate attention score statistics with diversified random eviction strategies to mitigate attention bias and enhance robustness. This approach achieves significant performance improvements on both short- and long-text tasks, reducing KV cache size by up to 50% while maintaining over 95% performance \[[12](http://arxiv.org/abs/2408.03675)\]. Similarly, \[[5](http://arxiv.org/abs/2503.12491)\] proposes a cascading and adaptive KV cache eviction method that frames cache eviction as a "cake-slicing problem," allocating cache size based on layer-specific attention dynamics and temporal token importance. This approach maintains model performance with only 3.2% of the KV cache and achieves over 10x speedup in decoding latency \[[5](http://arxiv.org/abs/2503.12491)\].

Efforts to reduce the memory footprint of KV caches have also been explored through compression techniques. For example, \[[8](http://arxiv.org/abs/2405.14366)\] introduces MiniCache, which compresses the KV cache across layers by leveraging the high similarity between adjacent layers in the middle-to-deep portion of LLMs. This approach reduces the memory footprint by up to 41% while maintaining near-lossless performance \[[8](http://arxiv.org/abs/2405.14366)\]. Additionally, \[[9](http://arxiv.org/abs/2410.23317)\] proposes VL-Cache, a sparsity- and modality-aware KV cache compression method tailored for vision-language models (VLMs). This method reduces the memory footprint of KV cache in GPU by 90% while maintaining accuracy comparable to full cache \[[9](http://arxiv.org/abs/2410.23317)\].

Cloud-based KV cache storage and reuse have also been investigated for their potential to reduce both delay and cost. \[[3](http://arxiv.org/abs/2503.14647)\] presents an analytical model to evaluate the economic benefits of storing and reusing KV caches in public cloud services, showing that it can save both delay and cloud cost across a range of workloads with long context \[[3](http://arxiv.org/abs/2503.14647)\].
