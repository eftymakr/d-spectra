## Related Works

Event cameras, which capture scene changes asynchronously on a per-pixel basis, have gained significant attention due to their high temporal resolution and dynamic range \[[1](http://arxiv.org/abs/2209.08597)\]. However, the asynchronous nature of event streams introduces challenges in processing, particularly in terms of bandwidth, memory, and computational demands \[[1](http://arxiv.org/abs/2209.08597)\]. Prior work has explored methods to mitigate these challenges, primarily through event downsampling techniques \[[1](http://arxiv.org/abs/2209.08597)\]. Most existing approaches rely on fixed heuristics or threshold-based strategies, which limit their adaptability to varying scene dynamics and application requirements \[[1](http://arxiv.org/abs/2209.08597)\]. These methods often fail to account for the importance of individual events, leading to suboptimal performance under event-budget constraints \[[1](http://arxiv.org/abs/2209.08597)\].

To address these limitations, researchers have proposed adaptive and context-aware approaches. For instance, ASAP \[[1](http://arxiv.org/abs/2209.08597)\] introduces an adaptive scheme to manage the event stream through variable-size packages that accommodate the event processing times, ensuring responsiveness and preventing overflow. This approach is particularly useful for asynchronous event-by-event clustering algorithms \[[1](http://arxiv.org/abs/2209.08597)\]. Similarly, EventFly \[[2](http://arxiv.org/abs/2503.19916)\] focuses on cross-platform adaptation in event camera perception, introducing techniques like EventBlend and EventMatch to enhance feature alignment and domain-invariant learning across diverse platforms. These methods highlight the need for more flexible and context-aware processing strategies \[[2](http://arxiv.org/abs/2503.19916)\].

Another line of research explores the integration of event data with traditional computer vision techniques. For example, Events-To-Video \[[3](http://arxiv.org/abs/1904.08298)\] proposes a recurrent neural network to reconstruct videos from event data, enabling the use of off-the-shelf computer vision algorithms on event-based data. This approach demonstrates that event data can be effectively converted into a format compatible with conventional algorithms, improving performance on tasks like object classification and visual-inertial odometry \[[3](http://arxiv.org/abs/1904.08298)\]. Similarly, Event-based Asynchronous Sparse Convolutional Networks \[[6](http://arxiv.org/abs/2003.09148)\] present a framework for converting models trained on synchronous image-like event representations into asynchronous models, leveraging the intrinsic sparsity of event data to reduce computational complexity and latency \[[6](http://arxiv.org/abs/2003.09148)\].

The importance of event importance modeling has also been explored. For instance, the work in \[[7](http://arxiv.org/abs/1904.11578)\] presents a neural asynchronous approach to process event streams, extracting dynamic information from events by leveraging previous motion and critical features of gray-scale frames. This method enables more accurate motion estimation compared to traditional synchronous approaches \[[7](http://arxiv.org/abs/1904.11578)\]. Additionally, the work in \[[11](http://arxiv.org/abs/2412.14705)\] proposes a dual-camera system with an event camera and an RGB camera to improve alignment between low dynamic range (LDR) frames in dynamic scenes, reducing ghosting artifacts caused by motion \[[11](http://arxiv.org/abs/2412.14705)\].

[Snippet]: «Event cameras can capture pixel-level illumination changes with very high temporal resolution and dynamic range. They have received increasing research interest due to their robustness to lighting conditions and motion blur. Two main approaches exist in the literature to feed the event-based processing algorithms: packaging the triggered events in event packages and sending them one-by-one as single events. These approaches suffer limitations from either processing overflow or lack of responsivity. Processing overflow is caused by high event generation rates when the algorithm cannot process all the events in real-time. Conversely, lack of responsivity happens in cases of low event generation rates when the event packages are sent at too low frequencies. This paper presents ASAP, an adaptive scheme to manage the event stream through variable-size packages that accommodate to the event package processing times. The experimental results show that ASAP is capable of feeding an asynchronous event-by-event clustering algorithm in a responsive and efficient manner and at the same time prevents overflow.»

Event cameras, which capture scene changes asynchronously on a per-pixel basis, offer significant advantages such as high temporal resolution, low latency, and high dynamic range \[[1](http://arxiv.org/abs/2209.08597)\]. However, these benefits come with challenges, including high bandwidth, memory, and computational demands, which have led to the development of event downsampling techniques \[[1](http://arxiv.org/abs/2209.08597)\]. Prior approaches to event downsampling often rely on fixed heuristics or threshold-based strategies, limiting their adaptability to different applications and scenarios \[[1](http://arxiv.org/abs/2209.08597)\]. In contrast, recent work has introduced more sophisticated methods, such as the probabilistic framework POLED, which models event importance using an event-importance probability density function (ePDF) that can be arbitrarily defined and adapted to specific tasks \[[1](http://arxiv.org/abs/2209.08597)\]. This approach operates in an online setting, estimating event importance from raw event streams in real-time, allowing for scene-specific adaptation \[[1](http://arxiv.org/abs/2209.08597)\]. Additionally, the concept of zero-shot event downsampling has been proposed, where downsampled events must remain usable for models trained on the original event stream without requiring task-specific adaptation \[[1](http://arxiv.org/abs/2209.08597)\]. These advancements highlight the growing interest in improving the efficiency and adaptability of event cameras, while also addressing the limitations of traditional frame-based cameras \[[1](http://arxiv.org/abs/2209.08597)\]. The development of such methods is crucial for enabling the broader adoption of event cameras in applications such as object classification, image interpolation, surface normal estimation, and object detection \[[1](http://arxiv.org/abs/2209.08597)\].

Another work introduced a novel deep neural network capable of processing event streams asynchronously, extracting dynamic information from events using motion and critical features of gray-scale frames, thereby preserving the advantages of event-based cameras like DAVIS \[[7](http://arxiv.org/abs/1904.11578)\]. These approaches highlight the growing interest in developing more efficient and adaptive asynchronous neural networks that can handle the unique challenges posed by event-based data.
