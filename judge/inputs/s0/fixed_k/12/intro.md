## Related Works

Event cameras, which capture scene changes asynchronously on a per-pixel basis, have gained significant attention due to their high temporal resolution and dynamic range \[[1](http://arxiv.org/abs/2209.08597)\]. However, the asynchronous nature of event streams introduces challenges in processing, particularly in terms of bandwidth, memory, and computational demands \[[1](http://arxiv.org/abs/2209.08597)\]. Prior work has explored methods to mitigate these challenges, primarily through event downsampling techniques \[[1](http://arxiv.org/abs/2209.08597)\]. Most existing approaches rely on fixed heuristics or threshold-based strategies, which limit their adaptability to varying scene dynamics and application requirements \[[1](http://arxiv.org/abs/2209.08597)\]. These methods often fail to account for the importance of individual events, leading to suboptimal performance under event-budget constraints \[[1](http://arxiv.org/abs/2209.08597)\].

To address these limitations, researchers have proposed adaptive and context-aware approaches. For instance, ASAP \[[1](http://arxiv.org/abs/2209.08597)\] introduces an adaptive scheme to manage the event stream through variable-size packages that accommodate the event processing times, ensuring responsiveness and preventing overflow. This approach is particularly useful for asynchronous event-by-event clustering algorithms \[[1](http://arxiv.org/abs/2209.08597)\]. Similarly, EventFly \[[2](http://arxiv.org/abs/2503.19916)\] focuses on cross-platform adaptation in event camera perception, introducing techniques like EventBlend and EventMatch to enhance feature alignment and domain-invariant learning across diverse platforms. These methods highlight the need for more flexible and context-aware processing strategies \[[2](http://arxiv.org/abs/2503.19916)\].

Another line of research explores the integration of event data with traditional computer vision techniques. For example, Events-To-Video \[[3](http://arxiv.org/abs/1904.08298)\] proposes a recurrent neural network to reconstruct videos from event data, enabling the use of off-the-shelf computer vision algorithms on event-based data. This approach demonstrates that event data can be effectively converted into a format compatible with conventional algorithms, improving performance on tasks like object classification and visual-inertial odometry \[[3](http://arxiv.org/abs/1904.08298)\]. Similarly, Event-based Asynchronous Sparse Convolutional Networks \[[6](http://arxiv.org/abs/2003.09148)\] present a framework for converting models trained on synchronous image-like event representations into asynchronous models, leveraging the intrinsic sparsity of event data to reduce computational complexity and latency \[[6](http://arxiv.org/abs/2003.09148)\].

The importance of event importance modeling has also been explored. For instance, the work in \[[7](http://arxiv.org/abs/1904.11578)\] presents a neural asynchronous approach to process event streams, extracting dynamic information from events by leveraging previous motion and critical features of gray-scale frames. This method enables more accurate motion estimation compared to traditional synchronous approaches \[[7](http://arxiv.org/abs/1904.11578)\]. Additionally, the work in \[[11](http://arxiv.org/abs/2412.14705)\] proposes a dual-camera system with an event camera and an RGB camera to improve alignment between low dynamic range (LDR) frames in dynamic scenes, reducing ghosting artifacts caused by motion \[[11](http://arxiv.org/abs/2412.14705)\].
