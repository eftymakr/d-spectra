## Related Works

Natural language (NL)-driven table discovery has gained significant attention in recent years due to the increasing availability of tabular data and the need for efficient retrieval mechanisms. Traditional approaches rely on dense vector search pipelines, which involve representation, indexing, and search stages \[[10](http://arxiv.org/abs/2105.06365)\]. While these methods achieve high accuracy, they suffer from error accumulation during representation and indexing, which degrades search performance \[[10](http://arxiv.org/abs/2105.06365)\]. Additionally, limited query-table interaction hinders semantic alignment, preventing further accuracy improvements \[[10](http://arxiv.org/abs/2105.06365)\]. 

Several works have explored the use of neural networks for table discovery. Neural Enquirer \[[6](http://arxiv.org/abs/1512.00965)\] is a neural architecture that executes natural language queries on knowledge-base tables to retrieve answers. It generates distributed representations of queries and executes them on tables as differentiable operations, enabling end-to-end training. However, it focuses on answering queries rather than retrieving tables based on NL conditions. Similarly, the nlcTables dataset \[[2](http://arxiv.org/abs/2504.15849)\] provides a benchmark for NL-conditional table discovery, where users combine a query table with natural language conditions to refine search results. While this dataset highlights the need for advanced techniques, it does not directly address the issue of error accumulation or query-table interaction.

Recent advances in differentiable search indexing (DSI) have shown promise in unifying indexing and retrieval into a single model \[[11](http://arxiv.org/abs/2202.06991)\]. DSI leverages a transformer-based architecture to map queries directly to document identifiers, eliminating the need for separate indexing and retrieval components. However, early DSI models faced challenges in distinguishing relevant documents from random ones due to the black-box nature of the neural architecture \[[1](http://arxiv.org/abs/2305.02073)\]. To address this, a multi-task distillation approach was proposed to enhance retrieval quality without altering the model structure \[[1](http://arxiv.org/abs/2305.02073)\]. Additionally, DSI-QG \[[3](http://arxiv.org/abs/2206.10128)\] was introduced to mitigate data distribution mismatches by generating and re-ranking queries during indexing, improving cross-lingual retrieval performance.

The decentralized DSI framework, De-DSI \[[4](http://arxiv.org/abs/2404.12237)\], further extends the DSI paradigm by enabling efficient query-docid pair processing without direct document access. It uses an ensemble of DSI models trained on shard datasets, allowing for scalability and distributed computation. This approach maintains retrieval accuracy comparable to centralized methods while distributing computational complexity across the network. 

To enhance diversity in retrieval results, Inducing Diversity in Differentiable Search Indexing \[[5](http://arxiv.org/abs/2502.02788)\] proposes a training strategy inspired by Maximal Marginal Relevance (MMR), balancing relevance and diversity. This method enables the DSI model to learn to diversify while maintaining relevance, eliminating the need for post-processing steps

### <a id='category-differentiable-search-indexing-(dsi)-frameworks'></a>Differentiable Search Indexing (DSI) Frameworks: 4 papers found.
Differentiable Search Indexing (DSI) frameworks represent a novel approach in information retrieval, leveraging neural networks to directly map queries to document identifiers without the need for traditional indexing structures \[[11](http://arxiv.org/abs/2202.06991)\]. These frameworks, such as the Differentiable Search Index (DSI), encode all corpus information into model parameters, enabling a streamlined retrieval process by eliminating the need for separate indexing and search stages \[[11](http://arxiv.org/abs/2202.06991)\]. However, early DSI models exhibited limitations in distinguishing relevant documents from random ones, impacting retrieval effectiveness \[[1](http://arxiv.org/abs/2305.02073)\]. To address this, researchers proposed multi-task distillation approaches to enhance retrieval quality while preserving model structure \[[1](http://arxiv.org/abs/2305.02073)\]. Additionally, DSI systems have been explored for balancing relevance and diversity in retrieval, inspired by Maximal Marginal Relevance (MMR), allowing for diverse yet relevant results without post-processing \[[5](http://arxiv.org/abs/2502.02788)\]. Furthermore, DSI has been compared to traditional learned indexes, which use machine learning models to speed up binary search with minimal additional space \[[9](http://arxiv.org/abs/2107.09480)\]. These studies highlight the evolving capabilities of DSI, from improving retrieval accuracy to enabling efficient, dynamic indexing \[[11](http://arxiv.org/abs/2202.06991)\]. The integration of large language models for query generation and table identification in DSI-based frameworks, such as Birdie, further demonstrates the potential of DSI to address limitations in semantic alignment and error accumulation \[[1](http://arxiv.org/abs/2305.02073)\]. Overall, DSI frameworks are advancing the field of information retrieval by offering more efficient and effective retrieval mechanisms \[[11](http://arxiv.org/abs/2202.06991)\].

### <a id='category-query-generation-for-improved-retrieval'></a>Query Generation for Improved Retrieval: 1 papers found.
Context: 
	Document 1: [Category]: «Query Generation for Improved Retrieval»
[Snippet]: «The Differentiable Search Index (DSI) is an emerging paradigm for information retrieval. Unlike traditional retrieval architectures where index and retrieval are two different and separate components, DSI uses a single transformer model to perform both indexing and retrieval. In this paper, we identify and tackle an important issue of current DSI models: the data distribution mismatch that occurs between the DSI indexing and retrieval processes. Specifically, we argue that, at indexing, current DSI methods learn to build connections between the text of long documents and the identifier of the documents, but then retrieval of document identifiers is based on queries that are commonly much shorter than the indexed documents. This problem is further exacerbated when using DSI for cross-lingual retrieval, where document text and query text are in different languages. To address this fundamental problem of current DSI models, we propose a simple yet effective indexing framework for DSI, called DSI-QG. When indexing, DSI-QG represents documents with a number of potentially relevant queries generated by a query generation model and re-ranked and filtered by a cross-encoder ranker. The presence of these queries at indexing allows the DSI models to connect a document identifier to a set of queries, hence mitigating data distribution mismatches present between the indexing and the retrieval phases. Empirical results on popular mono-lingual and cross-lingual passage retrieval datasets show that DSI-QG significantly outperforms the original DSI model.»

	Document 1: [Category]: «Decentralized DSI for Scalability»
[Snippet]: «This study introduces De-DSI, a novel framework that fuses large language models (LLMs) with genuine decentralization for information retrieval, particularly employing the differentiable search index (DSI) concept in a decentralized setting. Focused on efficiently connecting novel user queries with document identifiers without direct document access, De-DSI operates solely on query-docid pairs. To enhance scalability, an ensemble of DSI models is introduced, where the dataset is partitioned into smaller shards for individual model training. This approach not only maintains accuracy by reducing the number of data each model needs to handle but also facilitates scalability by aggregating outcomes from multiple models. This aggregation uses a beam search to identify top docids and applies a softmax function for score normalization, selecting documents with the highest scores for retrieval. The decentralized implementation demonstrates that retrieval success is comparable to centralized methods, with the added benefit of the possibility of distributing computational complexity across the network. This setup also allows for the retrieval of multimedia items through magnet links, eliminating the need for platforms or intermediaries.»

[Snippet]: «We proposed Neural Enquirer as a neural network architecture to execute a natural language (NL) query on a knowledge-base (KB) for answers. Basically, Neural Enquirer finds the distributed representation of a query and then executes it on knowledge-base tables to obtain the answer as one of the values in the tables. Unlike similar efforts in end-to-end training of semantic parsers, Neural Enquirer is fully "neuralized": it not only gives distributional representation of the query and the knowledge-base, but also realizes the execution of compositional queries as a series of differentiable operations, with intermediate results (consisting of annotations of the tables at different levels) saved on multiple layers of memory. Neural Enquirer can be trained with gradient descent, with which not only the parameters of the controlling components and semantic parsing component, but also the embeddings of the tables and query words can be learned from scratch. The training can be done in an end-to-end fashion, but it can take stronger guidance, e.g., the step-by-step supervision for complicated queries, and benefit from it. Neural Enquirer is one step towards building neural network systems which seek to understand language by executing it on real-world. Our experiments show that Neural Enquirer can learn to execute fairly complicated NL queries on tables with rich structures.»
