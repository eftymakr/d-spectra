## Related Works

Event cameras, which capture scene changes asynchronously on a per-pixel basis, offer significant advantages over traditional frame-based cameras, particularly in high-speed and high dynamic range scenarios \[[3](http://arxiv.org/abs/1904.08405)\]. However, their high bandwidth, memory, and computational demands pose challenges for real-time processing and efficient data utilization \[[1](http://arxiv.org/abs/1802.06898)\]. Prior work has addressed these challenges through event downsampling techniques, but most approaches rely on fixed heuristics or threshold-based strategies, limiting their adaptability to varying scene conditions \[[1](http://arxiv.org/abs/1802.06898)\]. For instance, some methods use static thresholds to discard events, which may not be optimal for all applications \[[3](http://arxiv.org/abs/1904.08405)\]. Others attempt to reduce the event stream by discarding events that do not contribute to the overall scene understanding, but these methods often lack the flexibility to adapt to different tasks or environments \[[1](http://arxiv.org/abs/1802.06898)\].

To overcome these limitations, this paper introduces a probabilistic framework, POLED, which models event importance through an event-importance probability density function (ePDF) \[[1](http://arxiv.org/abs/1802.06898)\]. This approach allows for arbitrary definitions of event importance, enabling scene-specific adaptation \[[1](http://arxiv.org/abs/1802.06898)\]. Unlike previous methods, POLED operates in a purely online setting, estimating event importance on-the-fly from raw event streams \[[1](http://arxiv.org/abs/1802.06898)\]. This enables the system to dynamically adjust to changing scene conditions without requiring pre-defined thresholds or extensive preprocessing \[[1](http://arxiv.org/abs/1802.06898)\].

Additionally, the paper introduces zero-shot event downsampling, where downsampled events must remain usable for models trained on the original event stream, without task-specific adaptation \[[1](http://arxiv.org/abs/1802.06898)\]. This is a significant advancement, as it allows for the use of event cameras in a broader range of applications without the need for additional training or adaptation \[[1](http://arxiv.org/abs/1802.06898)\]. The proposed contour-preserving ePDF prioritizes structurally important events, ensuring that critical visual information is retained even under event-budget constraints \[[1](http://arxiv.org/abs/1802.06898)\].

Several studies have explored the use of event cameras in various vision tasks, such as optical flow estimation, object detection, and visual SLAM \[[3](http://arxiv.org/abs/1904.08405)\]\[[4](http://arxiv.org/abs/1709.06310)\]\[[7](http://arxiv.org/abs/1904.08298)\]. For example, EV-FlowNet presents a self-supervised deep learning pipeline for optical flow estimation from event streams, using grayscale images as a supervisory signal \[[3](http://arxiv.org/abs/1904.08405)\]. Similarly, the paper "Event-Based Vision Meets Deep Learning on Steering Prediction for Self-Driving Cars" demonstrates the effectiveness of event cameras in predicting vehicle steering angles, even in challenging illumination conditions \[[2](http://arxiv.org/abs/1804.01310)\]. These works highlight the potential of event cameras in real-world applications, but they often rely on fixed or task-specific approaches \[[2](http://arxiv.org/abs/1804.01310)\]\[[3](http://arxiv.org/abs/1904.08405)\].

The proposed method in this paper addresses these limitations by introducing a more flexible and adaptive framework for event processing, which can be applied across a wide range of vision tasks \[[1](http://arxiv.org/abs/1802.06898)\].
