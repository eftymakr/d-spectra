## Related Works

Sequential recommendation systems aim to predict the next item a user will interact with, based on their historical behavior. These systems have evolved significantly, incorporating advanced neural network architectures to better capture sequential patterns and user preferences. Early approaches, such as Markov Chains (MCs), assume that the next action is determined solely by the last few actions \[[1](http://arxiv.org/abs/1808.09781)\]. While effective in sparse datasets, they lack the capacity to model long-term dependencies. Recurrent Neural Networks (RNNs), on the other hand, can capture longer-term semantics but often suffer from computational inefficiency and difficulty in handling sparse data \[[1](http://arxiv.org/abs/1808.09781)\]. 

To address these limitations, attention-based models have emerged, such as SASRec, which uses self-attention to selectively focus on relevant items in a user's history \[[1](http://arxiv.org/abs/1808.09781)\]. This approach allows for more efficient modeling of long-term dependencies while maintaining the simplicity of MC-based methods. Similarly, Caser employs convolutional filters to extract local features from item sequences, enabling the model to capture both general preferences and sequential patterns \[[2](http://arxiv.org/abs/1809.07426)\]. These models demonstrate the importance of leveraging both item-level and sequence-level information.

Recent work has also emphasized the need for incorporating temporal information, as many existing models treat behavior sequences as static \[[5](https://www.semanticscholar.org/paper/5574d6123deea94eba2cb35b2486851e826c16ce)\]. The paper "Time Matters" introduces the concept of absolute and relative time patterns, highlighting how temporal dynamics influence user behavior \[[5](https://www.semanticscholar.org/paper/5574d6123deea94eba2cb35b2486851e826c16ce)\]. This has led to the development of models that explicitly model time-related signals, such as FEARec, which shifts the perspective to the frequency domain to better capture periodic patterns \[[14](http://arxiv.org/abs/2304.09184)\].

Noise in logged user behavior data remains a challenge, particularly for deep learning models that are prone to overfitting \[[6](http://arxiv.org/abs/2202.13556)\]. To mitigate this, FMLP-Rec integrates filtering algorithms with an all-MLP architecture, effectively reducing noise and improving performance \[[6](http://arxiv.org/abs/2202.13556)\]. Additionally, the use of self-supervised learning has gained traction, as seen in S3-Rec, which leverages mutual information maximization to enhance data representations \[[3](http://arxiv.org/abs/2008.07873)\]. This approach allows for better utilization of both item and subsequence correlations, especially in low-data scenarios.

Another key challenge is modeling diverse user interests and preferences, which has led to the development of controllable multi-interest frameworks like ComiRec \[[8](http://arxiv.org/abs/2005.09347)\]. These models capture multiple user interests from their behavior sequences and balance recommendation accuracy with diversity. Furthermore, hierarchical attention networks have been proposed to better model both long-term and short-term user preferences \[[10](https://www.semanticscholar.org/paper/0b42168f22713c48d8b0ce3bc8f680d347184d88)\]. These models use attention mechanisms at different levels to capture evolving user behavior over time.

In summary, recent advances in sequential recommendation have focused on improving model efficiency, capturing complex temporal dynamics, and handling data sparsity. These developments have led to more accurate and adaptive recommendation systems capable of handling diverse user behaviors and varying sequence lengths.

### <a id='category-attention-based-sequential-recommendation'></a>Attention-Based Sequential Recommendation: 4 papers found.
Attention-based sequential recommendation methods have gained significant traction due to their ability to model complex user behavior patterns. These approaches leverage self-attention mechanisms to capture long-term dependencies in user interaction sequences, offering advantages over traditional methods like Markov Chains and Recurrent Neural Networks \[[1](http://arxiv.org/abs/1808.09781)\]. While MC-based methods excel in sparse datasets by focusing on recent actions, RNNs are more suitable for dense data with richer semantic information \[[1](http://arxiv.org/abs/1808.09781)\]. Recent works, such as SASRec, aim to bridge this gap by using self-attention to identify relevant items from a user's history, enabling efficient and effective predictions \[[1](http://arxiv.org/abs/1808.09781)\]. Furthermore, models like FDSA extend attention-based approaches by incorporating feature-level sequences to capture both item and feature transition patterns, enhancing the ability to extract full sequential patterns \[[7](https://www.semanticscholar.org/paper/63555b4f363ee72dd8d49d8deca68760542c0cd2)\]. Similarly, NARM introduces a hybrid encoder with attention mechanisms to model user intent within sessions, improving recommendation accuracy by capturing both sequential behavior and session-specific purposes \[[9](http://arxiv.org/abs/1711.04725)\]. Additionally, FEARec addresses limitations of existing self-attention models by introducing frequency domain analysis, enabling the capture of both low- and high-frequency information, as well as periodic patterns in user behavior \[[14](http://arxiv.org/abs/2304.09184)\]. These advancements highlight the growing importance of attention mechanisms in sequential recommendation, emphasizing their flexibility in handling diverse interaction patterns and varying sequence lengths.

### <a id='category-convolutional-approaches-for-sequential-data'></a>Convolutional Approaches for Sequential Data: 2 papers found.
Convolutional approaches for sequential data have been increasingly utilized in recommendation systems to capture sequential patterns and user preferences effectively \[[15](http://arxiv.org/abs/1808.05163)\]. These methods typically embed sequences of user interactions into 2D latent matrices, treating them as images, and apply convolutional filters to extract local features that represent sequential dependencies \[[15](http://arxiv.org/abs/1808.05163)\]. This approach enables the modeling of both short-term and long-term dependencies without relying on pooling operations, thereby improving the efficiency of capturing temporal dynamics \[[15](http://arxiv.org/abs/1808.05163)\]. Additionally, the use of residual blocks in these architectures helps in training deeper networks by mitigating the vanishing gradient problem \[[15](http://arxiv.org/abs/1808.05163)\]. The Caser model, for instance, leverages convolutional filters to learn sequential patterns from item embeddings, providing a unified framework for capturing both general preferences and sequential behaviors \[[2](http://arxiv.org/abs/1809.07426)\]. Such convolutional methods have demonstrated superior performance over traditional sequential recommendation models, particularly in handling long sequences and diverse user interactions \[[2](http://arxiv.org/abs/1809.07426)\]\[[15](http://arxiv.org/abs/1808.05163)\].

### <a id='category-self-supervised-learning-for-recommendations'></a>Self-Supervised Learning for Recommendations: 4 papers found.
Recent advancements in self-supervised learning for sequential recommendations have addressed key limitations of traditional models, such as data sparsity and poor handling of dynamic user preferences \[[3](http://arxiv.org/abs/2008.07873)\]. For instance, S3-Rec introduces self-supervised objectives based on mutual information maximization to better capture correlations between attributes, items, and sequences, improving model robustness with limited data \[[3](http://arxiv.org/abs/2008.07873)\]. Similarly, BERT4Rec employs a bidirectional self-attention mechanism to overcome the limitations of unidirectional models, allowing for more comprehensive modeling of user behavior by jointly conditioning on left and right contexts \[[4](http://arxiv.org/abs/1904.06690)\]. Additionally, UniSRec proposes a universal sequence representation learning approach that leverages item descriptions to enable transferability across recommendation scenarios, reducing reliance on explicit item IDs \[[12](http://arxiv.org/abs/2206.05941)\]. Meanwhile, DuoRec tackles representation degeneration in item embeddings by introducing a contrastive regularization that reshapes the distribution of sequence representations, enhancing semantic consistency \[[16](http://arxiv.org/abs/2110.05730)\]. These approaches collectively highlight the growing trend of using self-supervised learning to improve sequential recommendation models by leveraging intrinsic data correlations and enhancing model adaptability to diverse user behaviors.

### <a id='category-temporal-dynamics-in-recommendation-systems'></a>Temporal Dynamics in Recommendation Systems: 2 papers found.
Recent research in temporal dynamics within recommendation systems has emphasized the importance of incorporating temporal information to better model user behavior and improve recommendation accuracy. Studies have identified two key temporal patterns—absolute time patterns, which capture user time-sensitive interactions, and relative time patterns, which reflect how time intervals affect action relationships \[[1](http://arxiv.org/abs/1808.09781)\]. These insights highlight the need for models that can effectively integrate both types of temporal signals to capture dynamic user preferences \[[1](http://arxiv.org/abs/1808.09781)\]. Additionally, sequential recommender systems (SRSs) have gained traction for their ability to model sequential user interactions, evolving preferences, and item popularity over time, leading to more personalized and accurate recommendations \[[2](http://arxiv.org/abs/1809.07426)\]. However, existing methods often simplify temporal information into behavior sequences, neglecting crucial time-related signals \[[1](http://arxiv.org/abs/1808.09781)\]. To address these limitations, researchers have proposed neural architectures that jointly learn temporal patterns, enabling more robust modeling of user dynamics \[[1](http://arxiv.org/abs/1808.09781)\]. Furthermore, SRSs face challenges in handling variable-length sequences and diverse interaction patterns, prompting innovations such as preference-aware attention mechanisms and state-space modeling to enhance performance \[[2](http://arxiv.org/abs/1809.07426)\]. These developments underscore the growing focus on temporal modeling in recommendation systems, aiming to better align with real-world user behavior and improve recommendation quality.

Traditional approaches, such as matrix factorization, often struggle with these limitations, as they rely on extensive user history data \[[13](http://arxiv.org/abs/1511.06939)\].
