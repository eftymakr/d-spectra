## Related Works

Sequential recommendation systems aim to predict the next item a user will interact with, based on their historical behavior. These systems have evolved significantly, incorporating advanced neural network architectures to better capture sequential patterns and user preferences. Early approaches, such as Markov Chains (MCs), assume that the next action is determined solely by the last few actions \[[1](http://arxiv.org/abs/1808.09781)\]. While effective in sparse datasets, they lack the capacity to model long-term dependencies. Recurrent Neural Networks (RNNs), on the other hand, can capture longer-term semantics but often suffer from computational inefficiency and difficulty in handling sparse data \[[1](http://arxiv.org/abs/1808.09781)\]. 

To address these limitations, attention-based models have emerged, such as SASRec, which uses self-attention to selectively focus on relevant items in a user's history \[[1](http://arxiv.org/abs/1808.09781)\]. This approach allows for more efficient modeling of long-term dependencies while maintaining the simplicity of MC-based methods. Similarly, Caser employs convolutional filters to extract local features from item sequences, enabling the model to capture both general preferences and sequential patterns \[[2](http://arxiv.org/abs/1809.07426)\]. These models demonstrate the importance of leveraging both item-level and sequence-level information.

Recent work has also emphasized the need for incorporating temporal information, as many existing models treat behavior sequences as static \[[5](https://www.semanticscholar.org/paper/5574d6123deea94eba2cb35b2486851e826c16ce)\]. The paper "Time Matters" introduces the concept of absolute and relative time patterns, highlighting how temporal dynamics influence user behavior \[[5](https://www.semanticscholar.org/paper/5574d6123deea94eba2cb35b2486851e826c16ce)\]. This has led to the development of models that explicitly model time-related signals, such as FEARec, which shifts the perspective to the frequency domain to better capture periodic patterns \[[14](http://arxiv.org/abs/2304.09184)\].

Noise in logged user behavior data remains a challenge, particularly for deep learning models that are prone to overfitting \[[6](http://arxiv.org/abs/2202.13556)\]. To mitigate this, FMLP-Rec integrates filtering algorithms with an all-MLP architecture, effectively reducing noise and improving performance \[[6](http://arxiv.org/abs/2202.13556)\]. Additionally, the use of self-supervised learning has gained traction, as seen in S3-Rec, which leverages mutual information maximization to enhance data representations \[[3](http://arxiv.org/abs/2008.07873)\]. This approach allows for better utilization of both item and subsequence correlations, especially in low-data scenarios.

Another key challenge is modeling diverse user interests and preferences, which has led to the development of controllable multi-interest frameworks like ComiRec \[[8](http://arxiv.org/abs/2005.09347)\]. These models capture multiple user interests from their behavior sequences and balance recommendation accuracy with diversity. Furthermore, hierarchical attention networks have been proposed to better model both long-term and short-term user preferences \[[10](https://www.semanticscholar.org/paper/0b42168f22713c48d8b0ce3bc8f680d347184d88)\]. These models use attention mechanisms at different levels to capture evolving user behavior over time.

In summary, recent advances in sequential recommendation have focused on improving model efficiency, capturing complex temporal dynamics, and handling data sparsity. These developments have led to more accurate and adaptive recommendation systems capable of handling diverse user behaviors and varying sequence lengths.
