## Related Works

Semi-supervised learning (SSL) has been a focal point in machine learning research, aiming to leverage unlabeled data to improve model performance when labeled data is scarce \[[1](https://www.semanticscholar.org/paper/f3df804a7eef204b0c4fc4b81166dec9b4abc073)\]. However, traditional SSL methods typically assume that labeled and unlabeled data share the same class distribution \[[1](https://www.semanticscholar.org/paper/f3df804a7eef204b0c4fc4b81166dec9b4abc073)\]. This assumption is often violated in practice, as unlabeled data may contain out-of-distribution (OOD) samples, which are referred to as outliers \[[1](https://www.semanticscholar.org/paper/f3df804a7eef204b0c4fc4b81166dec9b4abc073)\]. These outliers can significantly degrade model performance by introducing noise \[[1](https://www.semanticscholar.org/paper/f3df804a7eef204b0c4fc4b81166dec9b4abc073)\]. 

Several approaches have been proposed to address the issue of OOD data in SSL. For instance, FixMatch \[[3](http://arxiv.org/abs/2001.07685)\] introduces a simple yet effective method that combines consistency regularization and pseudo-labeling. It generates pseudo-labels for unlabeled data based on high-confidence predictions and trains the model to maintain consistency between different augmented views of the same instance \[[3](http://arxiv.org/abs/2001.07685)\]. While FixMatch achieves state-of-the-art results on various benchmarks, it assumes that unlabeled data is in-distribution (ID), and thus does not explicitly handle OOD samples \[[3](http://arxiv.org/abs/2001.07685)\].

To address the challenges posed by OOD data, OpenMatch \[[8](http://arxiv.org/abs/2105.14148)\] extends FixMatch by integrating novelty detection based on one-vs-all (OVA) classifiers. This allows the model to distinguish between inliers and outliers, improving robustness against OOD samples \[[8](http://arxiv.org/abs/2105.14148)\]. Similarly, OpenCoS \[[13](http://arxiv.org/abs/2107.08943)\] leverages contrastive learning to identify OOD samples in the unlabeled dataset and uses both one-hot pseudo-labels and soft-labels to improve model performance \[[13](http://arxiv.org/abs/2107.08943)\]. 

Another approach, Temporal Ensembling \[[9](http://arxiv.org/abs/1610.02242)\], introduces self-ensembling, where the model forms a consensus prediction using outputs from different training epochs and augmentation conditions. This helps improve the robustness of SSL models against label noise and distribution shifts \[[9](http://arxiv.org/abs/1610.02242)\]. 

In addition, methods such as MixMatch \[[5](http://arxiv.org/abs/1905.02249)\] and SimMatch \[[19](http://arxiv.org/abs/2203.06915)\] have been proposed to enhance SSL performance by combining consistency regularization with data augmentation and similarity matching. MixMatch \[[5](http://arxiv.org/abs/1905.02249)\] uses a combination of pseudo-labeling and consistency regularization to improve model performance, while SimMatch \[[19](http://arxiv.org/abs/2203.06915)\] focuses on semantic and instance-level consistency to generate more reliable pseudo-labels \[[19](http://arxiv.org/abs/2203.06915)\]. 

Recent work has also explored the use of curriculum learning to adaptively adjust pseudo-labeling thresholds \[[14](http://arxiv.org/abs/2110.08263)\]. FlexMatch \[[14](http://arxiv.org/abs/2110.08263)\] introduces a curriculum pseudo-labeling strategy that dynamically adjusts thresholds for different classes based on the model's learning status, improving performance in scenarios with limited labeled data \[[14](http://arxiv.org/abs/2110.08263)\]. 

In contrast to these methods, our proposed framework, Diversify and Conquer (DAC), leverages prediction disagreements among multiple models trained with different biases toward the unlabeled distribution. This approach enables robust outlier detection even when labeled data is insufficient \[[1](https://www.semanticscholar.org/paper/f3df804a7eef204b0c4fc4b81166dec9b4abc073)\]. By encouraging divergent models to be differently biased toward outliers while maintaining consistent predictions for inliers, DAC effectively identifies unknown concepts through model disagreement \[[1](https://www.semanticscholar.org/paper/f3df804a7eef204b0c4fc4b81166dec9b4abc073)\].
