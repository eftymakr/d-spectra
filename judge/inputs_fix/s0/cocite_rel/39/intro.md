## Related Works

De novo genome assembly has been a focal point of bioinformatics research, driven by the advent of next-generation sequencing technologies that generate massive volumes of short reads \[[1](https://www.semanticscholar.org/paper/7279acd9c61a8de019ea2d55d23124dfbb6b5269)\]. Early approaches, such as string-based and overlap-layout-consensus (OLC) assemblers, were well-suited for small genomes and short reads \[[1](https://www.semanticscholar.org/paper/7279acd9c61a8de019ea2d55d23124dfbb6b5269)\]. However, as sequencing technologies evolved to produce longer reads, new challenges emerged, particularly with the high error rates associated with long-read sequencing platforms like Oxford Nanopore and PacBio \[[24](https://www.semanticscholar.org/paper/e18b489f02530ff144db28cb44537173e4296616)\]. These error rates necessitated the development of more robust and accurate assemblers, such as Canu, which introduces adaptive k-mer weighting and repeat separation to improve assembly continuity and reduce runtime \[[4](https://www.semanticscholar.org/paper/2b59fd18ada769ef76fb7fcc7382f063791abfab)\].

The computational complexity of de novo assembly has also spurred the development of parallel and distributed assemblers. For example, PASHA leverages de Bruijn graphs and hybrid computing architectures to improve scalability and efficiency for large genomes \[[13](https://www.semanticscholar.org/paper/7bf2f1c55f90e11a4d1df4dd608ac621a08f8b33)\]. Similarly, SWAP-Assembler is designed for massive parallel processing using thousands of cores, demonstrating superior scalability and contig quality compared to other assemblers \[[3](https://www.semanticscholar.org/paper/fe8d86bc5520b5049104ff58ee7e980982816ebf)\]. These tools highlight the growing need for efficient algorithms that can handle the increasing size and complexity of sequencing data.

Despite these advancements, many assemblers still face challenges related to memory usage and computational efficiency. For instance, traditional assemblers often require substantial memory and exhibit memory-bound behavior due to the interdependent nature of data structures \[[1](https://www.semanticscholar.org/paper/7279acd9c61a8de019ea2d55d23124dfbb6b5269)\]. This has led to the exploration of hardware-software co-design solutions, such as NMP-PaK, which integrates near-memory processing (NMP) to reduce memory footprints and improve performance \[[1](https://www.semanticscholar.org/paper/7279acd9c61a8de019ea2d55d23124dfbb6b5269)\]. The proposed solution addresses these limitations by optimizing both software and hardware components, achieving a 14X smaller memory footprint and 16X performance improvement over CPU-based methods \[[1](https://www.semanticscholar.org/paper/7279acd9c61a8de019ea2d55d23124dfbb6b5269)\].

Several studies have also focused on improving the accuracy and contiguity of assemblies, particularly for complex genomes. For example, Minimap and miniasm enable fast mapping and de novo assembly of noisy long sequences without an error correction stage, achieving high-speed assembly of bacterial and eukaryotic genomes \[[6](http://arxiv.org/abs/1512.01801)\]. Similarly, Minimap2 is designed for long reads, offering improved alignment accuracy and speed compared to short-read mappers \[[7](http://arxiv.org/abs/1708.01492)\]. These tools demonstrate the importance of optimizing both mapping and assembly steps to achieve high-quality results.

Moreover, the role of k-mer frequency analysis in estimating genomic characteristics has been explored as an assembly-independent method \[[16](http://arxiv.org/abs/1308.2012)\]. This approach provides insights into genome size, repeat content, and heterozygosity, which are critical for designing effective sequencing strategies and improving assembly algorithms. The use of k-mer-based methods has also been extended to error correction and hybrid assembly workflows, such as in the case of Nanocorr, which corrects Oxford Nanopore reads using complementary MiSeq data \[[24](https://www.semanticscholar.org/paper/e18b489f02530ff144db28cb44537173e4296616)\].

In summary, while existing assemblers have made significant strides in handling large datasets and improving accuracy, there remains a need for more efficient and scalable solutions that can address the inherent challenges of de novo assembly. The proposed NMP-PaK framework represents a promising direction in this regard, offering a hardware-software co-design approach that significantly enhances computational efficiency and reduces resource requirements.
