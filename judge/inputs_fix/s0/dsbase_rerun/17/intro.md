## Related Works

Semi-supervised learning (SSL) has emerged as a powerful paradigm for improving model performance by leveraging both labeled and unlabeled data. However, traditional SSL methods assume that labeled and unlabeled data share the same class distribution, which is often violated in practice due to the presence of outliers—unlabeled data from unknown classes \[[1' 2021-05-28](http://arxiv.org/abs/2105.14148v2)\]. These outliers are typically treated as noise, leading to significant performance degradation \[[1' 2021-05-28](http://arxiv.org/abs/2105.14148v2)\]. To address this limitation, several approaches have been proposed to handle open-set semi-supervised learning (OSSL), where the goal is to both classify inliers and detect outliers \[[1' 2021-05-28](http://arxiv.org/abs/2105.14148v2)\].

Early methods, such as FixMatch, assume that unlabeled data is from the same distribution as labeled data and rely on pseudo-labeling to improve performance \[[1' 2021-05-28](http://arxiv.org/abs/2105.14148v2)\]. However, this assumption breaks down in the presence of outliers, which can be misclassified as inliers and negatively impact model performance \[[1' 2021-05-28](http://arxiv.org/abs/2105.14148v2)\]. To tackle this issue, OpenMatch was introduced, which integrates novelty detection with FixMatch by using one-vs-all (OVA) classifiers to identify outliers \[[1' 2021-05-28](http://arxiv.org/abs/2105.14148v2)\]. This approach improves outlier detection by providing a threshold for distinguishing inliers from outliers \[[1' 2021-05-28](http://arxiv.org/abs/2105.14148v2)\].

More recently, SSB was proposed as a simple yet effective baseline for open-set SSL. It incorporates high-confidence pseudo-labeled data, regardless of whether they are inliers or outliers, to improve inlier classification performance \[[2' 2023-11-17](http://arxiv.org/abs/2311.10572v1)\]. Additionally, SSB utilizes non-linear transformations to separate features used for inlier classification and outlier detection, preventing adverse interactions between tasks \[[2' 2023-11-17](http://arxiv.org/abs/2311.10572v1)\]. Pseudo-negative mining further enhances outlier detection performance, leading to significant improvements over existing methods \[[2' 2023-11-17](http://arxiv.org/abs/2311.10572v1)\].

In the context of object detection, OpenCoS was introduced to handle open-set unlabeled data by leveraging self-supervised contrastive learning to identify out-of-class samples \[[8' 2021-06-29](http://arxiv.org/abs/2107.08943v3)\]. This method improves existing semi-supervised object detection approaches by utilizing one-hot pseudo-labels and soft-labels for inlier and out-of-class samples, respectively \[[8' 2021-06-29](http://arxiv.org/abs/2107.08943v3)\]. Similarly, IOMatch was proposed to jointly utilize inliers and outliers by introducing a multi-binary classifier that treats all outliers as a single class \[[4' 2023-08-25](http://arxiv.org/abs/2308.13168v1)\]. This approach avoids the need for explicit outlier detection, leading to improved performance in open-set scenarios \[[4' 2023-08-25](http://arxiv.org/abs/2308.13168v1)\].

The challenge of handling outliers in SSL has also been addressed through self-supervision. For instance, a method was proposed that leverages self-supervision to learn from all unlabeled data, including out-of-distribution samples, by using an energy-based score to accurately recognize known classes \[[6' 2023-01-24](http://arxiv.org/abs/2301.10127v3)\]. This approach is particularly useful for handling uncurated data in deployment \[[6' 2023-01-24](http://arxiv.org/abs/2301.10127v3)\].

In summary, the field of open-set semi-supervised learning has seen significant advancements, with methods like OpenMatch, SSB, OpenCoS, and IOMatch addressing the challenges posed by outliers in unlabeled data. These approaches have demonstrated improved performance in both inlier classification and outlier detection, contributing to the robustness of SSL in real-world scenarios.
