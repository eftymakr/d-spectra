Activation sparsity has further been explored as a method to compress LLMs by reducing the number of non-zero activations, leading to significant memory and computational savings with minimal accuracy loss \[[9' 2024-12-13](http://arxiv.org/abs/2412.12178v2)\]. These approaches are crucial for enabling LLMs to run on resource-constrained edge devices \[[1' 2024-09-05](http://arxiv.org/abs/2409.03384v1)\].
