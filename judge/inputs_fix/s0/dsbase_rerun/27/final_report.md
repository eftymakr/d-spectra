## Related Works

Recent advancements in information retrieval have introduced differentiable search indexing (DSI) as a promising paradigm for improving both relevance and diversity in retrieval tasks \[[1' 2025-02-05](http://arxiv.org/abs/2502.02788v1)\]. Traditional methods often rely on dense vector search pipelines, which involve representation, indexing, and search stages, leading to error accumulation during the indexing and search phases \[[1' 2025-02-05](http://arxiv.org/abs/2502.02788v1)\]. This issue is exacerbated by insufficient query-table interaction, which limits semantic alignment and hinders accuracy improvements \[[1' 2025-02-05](http://arxiv.org/abs/2502.02788v1)\]. 

Several works have explored DSI to address these limitations. For instance, \[[2' 2023-05-03](http://arxiv.org/abs/2305.02073v2)\] investigates the retrieval effectiveness of DSI, highlighting that while DSI can memorize unidirectional mappings from pseudo queries to document identifiers, it struggles to distinguish relevant documents from random ones. To mitigate this, the authors propose a multi-task distillation approach to enhance retrieval quality without altering the model structure \[[2' 2023-05-03](http://arxiv.org/abs/2305.02073v2)\]. This aligns with the goal of Birdie, which unifies indexing and search into a single encoder-decoder language model to eliminate error accumulation \[[1' 2025-02-05](http://arxiv.org/abs/2502.02788v1)\].

In the context of table retrieval, \[[3' 2024-11-04](http://arxiv.org/abs/2411.03356v1)\] presents a synthetic data generation pipeline using large language models (LLMs) to create high-quality training data for table-level representation learning. This approach improves table similarity and enhances recommendation performance, which is crucial for the indexing phase of Birdie \[[3' 2024-11-04](http://arxiv.org/abs/2411.03356v1)\]. Additionally, \[[4' 2024-04-18](http://arxiv.org/abs/2404.12237v2)\] introduces De-DSI, a decentralized DSI framework that enables efficient query-document identifier matching without direct document access. This decentralized approach is relevant for scalable and distributed indexing systems, similar to the continual indexing capabilities of Birdie \[[4' 2024-04-18](http://arxiv.org/abs/2404.12237v2)\].

The use of LLMs for query generation and semantic alignment is also explored in \[[5' 2015-12-03](http://arxiv.org/abs/1512.00965v2)\], where Neural Enquirer is proposed as a neural network architecture to execute natural language queries on knowledge-base tables. This framework enables compositional query execution and end-to-end training, which is essential for deep query-table interactions in Birdie \[[5' 2015-12-03](http://arxiv.org/abs/1512.00965v2)\]. Furthermore, \[[6' 2024-06-28](http://arxiv.org/abs/2406.19708v3)\] presents a multi-scale differentiable brain modeling workflow, demonstrating the potential of differentiable models in complex data representation tasks. This work highlights the broader applicability of differentiable approaches in various domains, including information retrieval \[[6' 2024-06-28](http://arxiv.org/abs/2406.19708v3)\].

To address the issue of catastrophic forgetting in continual learning, \[[7' 2021-04-21](http://arxiv.org/abs/2104.10450v1)\] proposes a global optimization scheme for differentiable neural architecture search (DARTS), which improves the discovery of robust architectures by exploring a more extensive search space \[[7' 2021-04-21](http://arxiv.org/abs/2104.10450v1)\]. This is relevant to Birdie's index update strategy, which uses parameter isolation to mitigate forgetting during continual indexing \[[1' 2025-02-05](http://arxiv.org/abs/2502.02788v1)\].

In summary, the related works highlight the importance of differentiable indexing, query-table interaction, and continual learning in improving retrieval accuracy and robustness. These contributions form the foundation for the proposed Birdie framework.

Additionally, DSI has been explored in the context of weighted sequences, where it enables efficient pattern matching with optimized time and space complexities \[[12' 2017-04-25](http://arxiv.org/abs/1704.07625v2)\]. These advancements highlight the evolving landscape of DSI, focusing on improving both the foundational capabilities and the practical applicability of differentiable search indexing frameworks.
