## Related Works

The growing adoption of cloud-native applications has led to increased interest in optimizing both computational and network resources in containerized environments. Prior research has primarily focused on system-level optimization strategies for cost and resource efficiency in containerized systems \[[1' 2024-12-22](http://arxiv.org/abs/2501.14753v1)\]. However, the analysis of network costs in Kubernetes clusters remains underexplored, despite the critical role of network usage in determining overall cloud expenditures \[[2' 2020-06-27](http://arxiv.org/abs/2006.15275v1)\]. This paper addresses this gap by investigating the network usage and cost implications of containerized applications running on Kubernetes clusters.

Several studies have explored the use of Kubernetes for managing containerized workloads. For instance, KubeAdaptor was introduced as a docking framework to ensure consistency in task scheduling order between workflow systems and Kubernetes \[[6' 2022-07-04](http://arxiv.org/abs/2207.01222v1)\]. This work highlights the challenges of integrating workflow systems with Kubernetes, particularly due to the inherent scheduling mechanisms of Kubernetes that may conflict with optimized task execution orders. Similarly, the paper on rearchitecting Kubernetes for the edge discusses the limitations of strong consistency in Kubernetes, particularly in large-scale edge deployments, and proposes an eventually consistent approach to improve performance and scalability \[[7' 2021-04-06](http://arxiv.org/abs/2104.02423v1)\]. These studies underscore the importance of optimizing both scheduling and network performance in Kubernetes environments.

In the realm of FinOps, ABACUS was introduced as an automated solution for cloud cost optimization by setting budgets, enforcing them through deployment blocking, and alerting teams when budgets are exceeded \[[1' 2024-12-22](http://arxiv.org/abs/2501.14753v1)\]. This work aligns with the goals of this paper, which aims to provide actionable insights into network cost optimization for cloud-native applications. Additionally, the paper on optimal strategies for operating energy storage in an arbitrage market presents an algorithm for determining profit-maximizing strategies under various constraints \[[10' 2014-12-02](http://arxiv.org/abs/1412.0829v1)\]. While this work focuses on energy storage, the algorithmic approach could be adapted to optimize network resource allocation in cloud environments.

The study on 5G network slice isolation based on native cloud and edge computing tools highlights the challenges of ensuring proper slice isolation in private 5G networks \[[3' 2025-02-05](http://arxiv.org/abs/2502.02842v2)\]. This is relevant to the broader context of managing network costs in cloud environments, as slice isolation can impact resource allocation and, consequently, network expenditures. Similarly, the paper on decentralized protection strategies against SIS epidemics in networks provides insights into managing network vulnerabilities through decentralized strategies \[[5' 2014-09-05](http://arxiv.org/abs/1409.1730v2)\]. These studies, while not directly focused on network cost optimization, contribute to the broader field of network management and security in cloud environments.

Finally, the paper on Bayesian analysis of biological networks discusses the detection of functional units through statistical analysis of network structures \[[20' 2006-09-28](http://arxiv.org/abs/q-bio/0609050v1)\]. While this work is specific to biological networks, the methodologies used for identifying functional units could be adapted to analyze network cost patterns in cloud environments. These studies collectively highlight the importance of understanding network behavior and cost implications in cloud-native applications, which is the focus of this paper.
