## Related Works

Open-vocabulary object detection has emerged as a critical research direction, enabling detectors to recognize objects beyond the training vocabulary using natural language inputs \[[1](http://arxiv.org/abs/2011.10678)\]. This capability is particularly valuable for real-world applications where the set of target objects is not known in advance \[[1](http://arxiv.org/abs/2011.10678)\]. However, the effectiveness of such models is often limited by the quality and specificity of the user-defined vocabulary \[[1](http://arxiv.org/abs/2011.10678)\]. Prior work has explored various strategies to enhance open-vocabulary detection, including leveraging vision-language pre-training \[[1](http://arxiv.org/abs/2011.10678)\], using pseudo labels generated from image-caption pairs \[[10](http://arxiv.org/abs/2111.09452)\], and employing weakly supervised learning \[[23](http://arxiv.org/abs/1511.02853)\]. 

Several approaches have focused on improving the alignment between visual and textual representations. For instance, CLIP \[[22](http://arxiv.org/abs/2102.05918)\] and RegionCLIP \[[18](http://arxiv.org/abs/2112.09106)\] have demonstrated that pre-trained vision-language models can be adapted for object detection by aligning image regions with textual descriptions. These models achieve strong performance on zero-shot and open-vocabulary tasks, often outperforming traditional supervised methods \[[18](http://arxiv.org/abs/2112.09106)\]. Similarly, ViLD \[[2](http://arxiv.org/abs/2104.13921)\] and MDETR \[[11](http://arxiv.org/abs/2104.12763)\] have introduced methods that use vision-language knowledge distillation to train detectors that can detect objects described by arbitrary text inputs. ViLD, in particular, achieves significant improvements on benchmark datasets such as LVIS and COCO, even when trained with a strong teacher model like ALIGN \[[2](http://arxiv.org/abs/2104.13921)\].

Another line of research has focused on improving the scalability and efficiency of open-vocabulary detection. Detic \[[7](http://arxiv.org/abs/2201.02605)\] expands the vocabulary of detectors by training on image-level supervision, allowing them to detect tens of thousands of object categories without requiring extensive bounding box annotations. This approach simplifies the training process and improves performance on long-tail detection benchmarks \[[7](http://arxiv.org/abs/2201.02605)\]. Similarly, PromptDet \[[8](http://arxiv.org/abs/2203.16513)\] proposes a two-stage open-vocabulary object detector that uses regional prompt learning to align visual and textual features, enabling zero manual annotations \[[8](http://arxiv.org/abs/2203.16513)\]. The method is validated on challenging datasets like LVIS and MS-COCO, demonstrating superior performance over existing approaches \[[8](http://arxiv.org/abs/2203.16513)\].

Recent work has also explored the use of pseudo-labeling and self-training frameworks to improve open-vocabulary detection. For example, PB-OVD \[[10](http://arxiv.org/abs/2111.09452)\] generates pseudo bounding-box annotations from large-scale image-caption pairs, enabling detectors to be trained on a broader set of object categories. This approach significantly improves performance on benchmarks such as COCO and LVIS, outperforming state-of-the-art methods by a notable margin \[[10](http://arxiv.org/abs/2111.09452)\]. Similarly, the work in \[[16](http://arxiv.org/abs/2111.12698)\] proposes a cross-modal pseudo-labeling framework that aligns word semantics in captions with visual features of object masks, leading to improved performance on instance segmentation tasks \[[16](http://arxiv.org/abs/2111.12698)\].

In addition to these methods, several studies have investigated the challenges of weakly supervised and zero-shot object detection. For example, \[[21](http://arxiv.org/abs/1804.04340)\] introduces zero-shot object detection, where the goal is to detect object classes not observed during training. This work explores the use of visual-semantic embeddings and background-aware approaches to improve detection performance on unseen categories \[[21](http://arxiv.org/abs/1804.04340)\]. Similarly, \[[29](https://www.semanticscholar.org/paper/90dd5e8fe3e117d87c7029af5cfb811c16791a7f)\] proposes a polarity loss function to address class imbalance and improve visual-semantic alignment in zero-shot detection \[[29](https://www.semanticscholar.org/paper/90dd5e8fe3e117d87c7029af5cfb811c16791a7f)\].

In summary, the field of open-vocabulary object detection has seen significant advancements, with a growing emphasis on leveraging vision-language pre-training, pseudo-labeling, and weakly supervised learning to expand the vocabulary of detectors. These approaches aim to improve the flexibility and performance of object detection models in real-world scenarios where the set of target objects is not known in advance.

### <a id='category-vision-language-pre-training-models'></a>Vision-language pre-training models: 5 papers found.
Vision-language pre-training models have emerged as a powerful approach to learning cross-modal representations, enabling zero-shot transfer and improving performance on a wide range of vision and language tasks. These models are typically trained on large-scale image-text datasets, where they learn to align visual and textual information through tasks such as image caption matching or region-level alignment \[[1](http://arxiv.org/abs/2011.10678)\]. For instance, CLIP leverages a simple pre-training task of predicting which caption matches an image, leading to state-of-the-art results on tasks like image classification and object detection without requiring explicit class labels \[[4](http://arxiv.org/abs/2103.00020)\]. Similarly, RegionCLIP extends this approach by focusing on fine-grained alignment between image regions and textual concepts, significantly improving performance on object detection tasks \[[3](http://arxiv.org/abs/2205.06230)\]. Other methods, such as Oscar, use object tags detected in images as anchor points to enhance semantic alignment during pre-training, achieving new state-of-the-art results on vision-language understanding and generation tasks \[[2](http://arxiv.org/abs/2104.13921)\]. Additionally, models like ViLBERT extend BERT to a multi-modal architecture, enabling joint processing of visual and textual inputs through co-attentional transformer layers, and achieving strong performance on tasks like visual question answering and image retrieval \[[5](http://arxiv.org/abs/2203.14940)\]. These approaches highlight the growing importance of vision-language pre-training in enabling flexible, zero-shot, and transferable models for a variety of applications.
