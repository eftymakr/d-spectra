## Related Works

Long-tailed recognition remains a challenging problem in visual recognition due to the imbalance in class distribution, where a few head classes dominate the training data while tail classes are underrepresented \[[1](http://arxiv.org/abs/1910.09217)\]. Several approaches have been proposed to address this issue, primarily focusing on class-balancing strategies, such as loss re-weighting, data resampling, or transfer learning from head to tail classes \[[1](http://arxiv.org/abs/1910.09217)\]. However, most of these methods jointly learn representations and classifiers, which may not be optimal for long-tailed scenarios \[[1](http://arxiv.org/abs/1910.09217)\]. 

Recent work has explored the potential of contrastive learning for long-tailed recognition. Supervised Contrastive Learning (SCL) has shown promising performance on balanced data, but it struggles with long-tailed distributions due to its inability to form a regular simplex in the feature space \[[2](http://arxiv.org/abs/2207.09052)\]. This leads to imbalanced attraction and repulsion gradients between positive and negative pairs, which hinder the generalization of the model \[[2](http://arxiv.org/abs/2207.09052)\]. To address this, several methods have been proposed. For example, Balanced Contrastive Learning (BCL) introduces class-averaging and class-complement strategies to balance the gradient contributions and improve the formation of a regular simplex \[[2](http://arxiv.org/abs/2207.09052)\]. Similarly, Parametric Contrastive Learning (PaCo) introduces class-wise learnable centers to rebalance the optimization process and improve performance on long-tailed datasets \[[4](http://arxiv.org/abs/2107.12028)\]. 

Another line of research focuses on decoupling representation learning from classifier learning. The Decoupling Representation and Classifier (DRC) approach suggests that data imbalance may not be a significant issue in learning high-quality representations, and that adjusting the classifier alone can lead to strong long-tailed recognition performance \[[1](http://arxiv.org/abs/1910.09217)\]. This idea has been further explored in methods like Equalization Loss (EQL), which aims to re-balance gradients during training to improve performance on rare categories \[[14](http://arxiv.org/abs/2003.05176)\]. EQL v2, an improved version of EQL, introduces a gradient-guided reweighing mechanism that independently balances the training process for each category, leading to significant improvements on benchmarks like LVIS \[[5](http://arxiv.org/abs/2012.08548)\]. 

Additionally, methods like Subclass-Balancing Contrastive Learning (SBCL) and Latent Categories based long-tail Recognition (LCReg) have been proposed to address the limitations of existing approaches. SBCL clusters head classes into subclasses to enforce a two-layer class hierarchy, while LCReg leverages latent features shared by both head and tail classes to improve feature representation \[[3](http://arxiv.org/abs/2306.15925)\]\[[8](http://arxiv.org/abs/2309.07186)\]. 

In summary, while contrastive learning has shown promise in long-tailed recognition, challenges such as gradient imbalance, poor feature representation for tail classes, and the need for class-balancing strategies remain. The proposed Aligned Contrastive Learning (ACL) algorithm aims to address these issues by eliminating gradient conflicts and improving generalization across multiple benchmarks \[[1](http://arxiv.org/abs/1910.09217)\].

Similarly, Supervised Contrastive Learning on Mixed Classes (SMC) enhances generalization by creating a set of positives based on class labels and weighting their contribution in the training loss \[[25](http://arxiv.org/abs/2211.11938)\]. These methods aim to reduce the skewed feature space caused by imbalanced data \[[6](http://arxiv.org/abs/2110.04596)\]. Theoretical analyses further reveal that gradient conflicts and imbalanced attraction/repulsion gradients between positive and negative pairs hinder model performance \[[4](http://arxiv.org/abs/2107.12028)\]. As a result, recent works emphasize the need for adaptive mechanisms to enhance the learning of rare classes, often through data augmentation or loss function modifications \[[6](http://arxiv.org/abs/2110.04596)\]. These strategies collectively highlight the importance of balancing the latent feature space and improving the model's ability to generalize across class distributions.

Gradient imbalance issues in long-tailed object detection have been a focal point of recent research, with several studies highlighting the challenges posed by imbalanced gradients between positive and negative samples \[[5](http://arxiv.org/abs/2012.08548)\]. One such approach, the equalization loss, was introduced to mitigate the adverse effects of these imbalances by effectively ignoring gradients from rare categories during training \[[14](http://arxiv.org/abs/2003.05176)\]. This mechanism helps protect the learning of rare categories from being overshadowed by more frequent ones, allowing the model to better capture discriminative features for underrepresented classes \[[14](http://arxiv.org/abs/2003.05176)\]. However, the original equalization loss was found to be insufficient in fully addressing the gradient imbalance problem, as it did not adequately rebalance the training process for each category independently \[[5](http://arxiv.org/abs/2012.08548)\]. To overcome these limitations, a novel variant, equalization loss v2 (EQL v2), was proposed, which introduces a gradient-guided reweighing mechanism to achieve more balanced training \[[5](http://arxiv.org/abs/2012.08548)\]. This advancement not only improves performance on the LVIS benchmark but also demonstrates strong generalization across different datasets, achieving significant improvements over the original EQL and even surpassing decoupled training methods \[[5](http://arxiv.org/abs/2012.08548)\].

In the context of feature representation techniques for long-tailed classification, recent works have focused on improving discriminative image representations to address class imbalance. One approach involves leveraging supervised contrastive learning, where a hybrid network structure combines a supervised contrastive loss with a cross-entropy loss to progressively transition from feature learning to classifier learning \[[1](http://arxiv.org/abs/1910.09217)\]. This strategy aims to enhance classification accuracy by pulling same-class samples closer and pushing different-class samples apart in the embedding space \[[1](http://arxiv.org/abs/1910.09217)\]. Another variant, prototypical supervised contrastive (PSC) learning, reduces memory consumption compared to standard SC loss, making it more suitable for resource-constrained settings \[[1](http://arxiv.org/abs/1910.09217)\]. Additionally, there is growing interest in addressing attribute-wise imbalance, which extends beyond class-wise imbalance by considering variations in sample attributes within each class \[[2](http://arxiv.org/abs/2207.09052)\]. This has led to the introduction of generalized long-tailed classification (GLT), which jointly tackles both class and attribute imbalances \[[2](http://arxiv.org/abs/2207.09052)\]. To address these challenges, methods like invariant feature learning (IFL) have been proposed to learn attribute-invariant features across diverse environments, improving performance across various long-tailed classification approaches \[[2](http://arxiv.org/abs/2207.09052)\]. These developments highlight the evolving strategies in feature representation for long-tailed recognition, emphasizing the need for robust and adaptable learning paradigms.
