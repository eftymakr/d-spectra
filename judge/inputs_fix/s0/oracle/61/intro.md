## Related Works

Personalized outfit generation has emerged as a critical area within fashion recommendation, aiming to produce sets of compatible and personalized fashion items that align with user preferences \[[3](http://arxiv.org/abs/1905.01866)\]. Early approaches focused on predefined outfit recommendations and personalized outfit composition, but these were constrained by existing fashion products, limiting their ability to address diverse user needs \[[6](http://arxiv.org/abs/2402.17279)\]. Recent advancements have leveraged AI-generated content to transcend these limitations, enabling more flexible and personalized outfit generation \[[6](http://arxiv.org/abs/2402.17279)\]. 

Several works have explored the use of generative models for fashion recommendation. For instance, the Hierarchical Fashion Graph Network (HFGN) integrates user-outfit and outfit-item relationships to improve compatibility and personalization \[[3](http://arxiv.org/abs/1905.01866)\]. Similarly, the Personalized Outfit Generation (POG) model connects user preferences with Transformer-based architectures to enhance both compatibility and personalization \[[3](http://arxiv.org/abs/1905.01866)\]. However, these models often rely on supervised learning paradigms, which can limit diversity and adaptability \[[6](http://arxiv.org/abs/2402.17279)\]. 

To address these limitations, recent research has focused on unsupervised and semi-supervised approaches. The CRAFT framework, for example, leverages visual cues and adversarial feature transformers to learn complementary item relationships in an unsupervised manner \[[8](http://arxiv.org/abs/1804.10871)\]. This approach is particularly useful in domains like fashion, where visual data is dominant \[[8](http://arxiv.org/abs/1804.10871)\]. Similarly, the VITON model enables image-based virtual try-on without using 3D information, using a coarse-to-fine strategy to transfer clothing onto a person \[[9](http://arxiv.org/abs/1711.08447)\]. These methods demonstrate the potential of generative models in fashion recommendation but often lack the ability to align with user preferences without explicit feedback \[[9](http://arxiv.org/abs/1711.08447)\].

To improve alignment with user preferences, some works have explored reinforcement learning from human feedback (RLHF). For example, the Diffusion-DPO method aligns diffusion models with human preferences by directly optimizing on human comparison data, eliminating the need for a reward model \[[16](http://arxiv.org/abs/2311.12908)\]. This approach is more efficient and computationally lightweight compared to traditional RLHF methods \[[16](http://arxiv.org/abs/2311.12908)\]. Similarly, the D3PO method fine-tunes diffusion models using direct preference optimization without requiring a reward model, making the process more direct and cost-effective \[[17](http://arxiv.org/abs/2311.13231)\]. These methods demonstrate the potential of preference-based optimization in improving the alignment of generated outfits with user preferences.

In addition to these methods, some works have focused on improving the diversity and quality of generated outfits. The DiFashion model, for instance, uses diffusion models to generate multiple fashion images and compose them into a visually compatible outfit \[[6](http://arxiv.org/abs/2402.17279)\]. It employs three types of conditions to guide the generation process and uses Classifier-Free-Guidance to enhance alignment with the conditions \[[6](http://arxiv.org/abs/2402.17279)\]. This approach ensures high fidelity, compatibility, and personalization in the generated outfits \[[6](http://arxiv.org/abs/2402.17279)\].

Overall, while existing methods have made significant progress in personalized outfit generation, they often rely on supervised learning paradigms or require extensive manual tuning. The proposed FashionDPO framework aims to address these limitations by using direct preference optimization to fine-tune fashion outfit generation models with automatically generated feedback, without the need for task-specific reward functions \[[6](http://arxiv.org/abs/2402.17279)\].
