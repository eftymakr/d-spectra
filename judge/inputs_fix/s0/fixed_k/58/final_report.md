## Related Works

Table discovery has emerged as a critical area of research in database systems, driven by the increasing complexity and diversity of tabular data in modern information systems. Early efforts in this domain focused on improving semantic connections between unrelated tables, often through concept-driven frameworks that aimed to enhance the semantic capabilities of database systems \[[1](http://arxiv.org/abs/1208.4016)\]. These approaches sought to bridge the gap between syntactically unrelated tables by leveraging semantic relationships, which was a significant step toward more meaningful data retrieval \[[1](http://arxiv.org/abs/1208.4016)\].

Recent advancements have shifted the focus toward deep learning methods for table detection, particularly in the context of document layout analysis. The introduction of large-scale, diverse datasets has enabled the development of more robust and scalable solutions. For instance, the STDW dataset, containing over 7,000 samples with varied table structures, has been instrumental in evaluating and improving convolutional neural network-based methods for table detection \[[2](http://arxiv.org/abs/2209.09207)\]. This dataset addresses previous limitations such as lack of diversity and poor sample quality, thereby enabling more accurate and generalizable models \[[2](http://arxiv.org/abs/2209.09207)\].

In parallel, the field of TableQA has also seen significant contributions, particularly in addressing the challenges posed by large language models (LLMs). The HiddenTables framework introduces a cooperative game between an LLM "Solver" and an "Oracle" to evaluate and improve the performance of LLMs in table question-answering tasks \[[3](http://arxiv.org/abs/2406.10803)\]. This approach not only enhances the ability of LLMs to handle complex queries but also ensures data privacy and security during the process \[[3](http://arxiv.org/abs/2406.10803)\]. The associated PyQTax dataset, comprising 116,671 question-table-answer triplets, further supports this effort by providing a rich source of annotated data for training and evaluation \[[3](http://arxiv.org/abs/2406.10803)\].

The proposed nlcTD task represents a novel direction in table discovery, combining natural language conditions with query tables to refine search results . This task addresses the limitations of existing methods that rely solely on query tables or vague keywords, often leading to large result sets requiring manual filtering . The nlcTables dataset, which includes 627 diverse queries and 22,200 candidate tables, provides a comprehensive benchmark for evaluating the performance of state-of-the-art methods in this new paradigm . The results from evaluating six state-of-the-art methods on nlcTables highlight the substantial performance gaps that exist, underscoring the need for more advanced techniques to tackle this challenging task .

These contributions collectively highlight the evolving landscape of table discovery and related tasks, emphasizing the importance of semantic understanding, data diversity, and model robustness in advancing the field.

Recent advancements have introduced concept-driven approaches that build upon latent table discovery, aiming to improve the accuracy and relevance of query results by incorporating semantic understanding \[[1](http://arxiv.org/abs/1208.4016)\]. The integration of natural language processing into these frameworks further enhances their ability to interpret user intent, making them a promising direction for future research in database systems.

### <a id='category-tableqa-and-large-language-models'></a>TableQA and Large Language Models: 1 papers found.

	Document 1: [Snippet]: «A myriad of different Large Language Models (LLMs) face a common challenge in contextually analyzing table question-answering tasks. These challenges are engendered from (1) finite context windows for large tables, (2) multi-faceted discrepancies amongst tokenization patterns against cell boundaries, and (3) various limitations stemming from data confidentiality in the process of using external models such as gpt-3.5-turbo. We propose a cooperative game dubbed"HiddenTables"as a potential resolution to this challenge. In essence,"HiddenTables"is played between the code-generating LLM"Solver"and the"Oracle"which evaluates the ability of the LLM agents to solve Table QA tasks. This game is based on natural language schemas and importantly, ensures the security of the underlying data. We provide evidential experiments on a diverse set of tables that demonstrate an LLM's collective inability to generalize and perform on complex queries, handle compositional dependencies, and align natural language to programmatic commands when concrete table schemas are provided. Unlike encoder-based models, we have pushed the boundaries of"HiddenTables"to not be limited by the number of rows - therefore we exhibit improved efficiency in prompt and completion tokens. Our infrastructure has spawned a new dataset"PyQTax"that spans across 116,671 question-table-answer triplets and provides additional fine-grained breakdowns&labels for varying question taxonomies. Therefore, in tandem with our academic contributions regarding LLMs' deficiency in TableQA tasks,"HiddenTables"is a tactile manifestation of how LLMs can interact with massive datasets while ensuring data security and minimizing generation costs.»

Recent research has highlighted the limitations of large language models (LLMs) in handling table question-answering (TableQA) tasks, particularly in scenarios involving complex queries and compositional dependencies \[[3](http://arxiv.org/abs/2406.10803)\]. Challenges such as finite context windows, tokenization discrepancies, and data confidentiality constraints have hindered the performance of existing models, including popular ones like gpt-3.5-turbo \[[3](http://arxiv.org/abs/2406.10803)\]. To address these issues, novel approaches such as the "HiddenTables" cooperative game have been proposed, where an LLM agent (Solver) interacts with an Oracle to evaluate its ability to solve TableQA tasks based on natural language schemas \[[3](http://arxiv.org/abs/2406.10803)\]. This framework not only enhances the security of underlying data but also improves efficiency by reducing reliance on encoder-based models \[[3](http://arxiv.org/abs/2406.10803)\]. Additionally, the development of datasets like "PyQTax" with over 116,671 question-table-answer triplets has provided valuable resources for evaluating and improving LLM performance in TableQA \[[3](http://arxiv.org/abs/2406.10803)\]. These advancements underscore the ongoing efforts to enhance the capabilities of LLMs in interacting with structured data while addressing practical challenges such as scalability and data privacy.
