## Related Works

Open-vocabulary object detection (OVD) has gained significant attention in recent years due to its ability to detect objects from an unrestricted set of categories, often defined by natural language prompts \[[1](http://arxiv.org/abs/2211.14843)\]. Early approaches relied on pre-trained vision-language models (VLMs) such as CLIP to align visual features with textual descriptions, enabling zero-shot detection \[[2](http://arxiv.org/abs/2205.06160)\]. However, these methods often struggled with fine-grained object-language alignment and lacked robustness to long-tailed distributions \[[3](http://arxiv.org/abs/2211.12914)\]. 

Several works have attempted to address these limitations by introducing novel frameworks that improve the alignment between image regions and text descriptions. For instance, VLDet directly learns from image-text pairs without requiring expensive grounding annotations, formulating object-language alignment as a set matching problem \[[4](http://arxiv.org/abs/2205.06230)\]. Similarly, Locov proposes a two-stage training approach that first uses location-guided image-caption matching to learn class labels and then specializes the model for object detection \[[5](http://arxiv.org/abs/2503.14862)\]. These methods demonstrate that weakly supervised learning can be effective for open-vocabulary detection.

Another line of research focuses on improving the generalization of open-vocabulary detectors by leveraging large-scale pre-training and efficient fine-tuning strategies. For example, the work in \[[6](http://arxiv.org/abs/2411.16833)\] shows that increasing image-level pre-training and model size consistently improves performance on downstream detection tasks. Similarly, \[[7](http://arxiv.org/abs/2502.16486)\] introduces a simple open-vocabulary object detection framework using Vision Transformers, demonstrating that minimal modifications to standard architectures can yield strong results. 

To further enhance detection accuracy, especially for unseen and linguistically complex categories, MQADet proposes a plug-and-play paradigm that leverages multimodal question answering capabilities of large language models (LLMs) to guide detectors toward semantically relevant regions \[[8](http://arxiv.org/abs/2304.00788)\]. This approach enables seamless integration with pre-trained object detectors without requiring additional training or fine-tuning. 

In addition to improving detection accuracy, researchers have also focused on addressing challenges such as class imbalance and misalignment between visual and textual modalities. For example, \[[9](http://arxiv.org/abs/2411.18207)\] introduces a framework that enables open-vocabulary detectors to operate in open-world settings by identifying and incrementally learning previously unseen objects. This is achieved through techniques such as Open World Embedding Learning (OWEL) and Multi-Scale Contrastive Anchor Learning (MSCAL), which help mitigate the issues of near-out-of-distribution (NOOD) and far-out-of-distribution (FOOD) objects \[[10](http://arxiv.org/abs/2206.11134)\].

Recent advances have also focused on improving the efficiency and scalability of open-vocabulary detection. For instance, \[[11](http://arxiv.org/abs/2207.03482)\] proposes a framework that bridges the gap between object and image-level representations by performing object-centric alignment of language embeddings from CLIP models. This allows for more accurate and generalizable detection across novel categories. Similarly, \[[12](http://arxiv.org/abs/2212.12130)\] introduces CondHead, a dynamic network design that conditions the detection process on semantic embeddings, enabling better generalization for open-vocabulary settings \[[13](http://arxiv.org/abs/2312.08876)\].

In summary, the field of open-vocabulary object detection has seen rapid advancements, with a focus on improving alignment, generalization, and efficiency. These works collectively highlight the importance of leveraging vision-language pre-training, weakly supervised learning, and efficient fine-tuning strategies to achieve robust and scalable open-vocabulary detection.

### <a id='category-open-vocabulary-object-detection-frameworks'></a>Open-vocabulary object detection frameworks: 14 papers found.
Open-vocabulary object detection frameworks aim to detect objects of novel categories using natural language supervision, often relying on image-text pairs or pre-trained vision-language models to bridge the semantic gap between visual and textual modalities \[[1](http://arxiv.org/abs/2211.14843)\]. These methods typically address the challenge of fine-grained object-language alignment by employing techniques such as set matching \[[1](http://arxiv.org/abs/2211.14843)\], location-guided image-caption matching \[[2](http://arxiv.org/abs/2205.06160)\], or cross-modal contrastive learning \[[3](http://arxiv.org/abs/2211.12914)\]. Some approaches focus on improving the alignment between vision and language by leveraging pre-trained models like CLIP \[[5](http://arxiv.org/abs/2503.14862)\], while others introduce novel strategies such as proposal mining and prediction equalization to reduce confidence bias toward base categories \[[4](http://arxiv.org/abs/2205.06230)\]. Additionally, methods like Object2Scene and OVM3D-Det extend open-vocabulary detection to 3D point cloud data, using pseudo-LiDAR or large-scale 3D object datasets to enrich vocabulary and improve detection accuracy \[[6](http://arxiv.org/abs/2411.16833)\]\[[7](http://arxiv.org/abs/2502.16486)\]. Recent works also emphasize the importance of weakly supervised learning, using image-level supervision or pseudo-labeling to generate high-quality object proposals and enhance detection performance \[[8](http://arxiv.org/abs/2304.00788)\]. Techniques such as consistency regularization \[[2](http://arxiv.org/abs/2205.06160)\] and dynamic label queues \[[9](http://arxiv.org/abs/2411.18207)\] further improve the robustness of open-vocabulary detectors by ensuring reliable pseudo-label generation and maintaining high-quality training data. Overall, these frameworks demonstrate significant progress in enabling detectors to generalize to unseen categories while maintaining efficiency and scalability \[[10](http://arxiv.org/abs/2206.11134)\].

### <a id='category-zero-shot-and-open-world-detection-methods'></a>Zero-shot and open-world detection methods: 7 papers found.

However, the effectiveness of these models is often constrained by the quality and specificity of the user-defined vocabulary, which can be overly broad or mis-specified, leading to suboptimal detection performance \[[9](http://arxiv.org/abs/2411.18207)\]. To address this limitation, researchers have proposed various approaches to enhance the adaptability of OVD models. For instance, the OVAD benchmark was introduced to evaluate attribute detection in an open-vocabulary setting, emphasizing the importance of object-level attribute information \[[3](http://arxiv.org/abs/2211.12914)\]. Similarly, the 3F-OVD task extends fine-grained object detection to open-vocabulary settings, requiring a deep understanding of image details and captions \[[5](http://arxiv.org/abs/2503.14862)\]. Additionally, the Open-World Embedding Learning (OWEL) framework was proposed to enable OVD models to operate in open-world settings by identifying and learning previously unseen objects \[[9](http://arxiv.org/abs/2411.18207)\]. These efforts highlight the growing interest in improving the robustness and adaptability of open-vocabulary detection systems. Furthermore, the OVCOS task and OVCamo dataset were introduced to address the challenges of detecting camouflaged objects in complex scenes, emphasizing the need for more realistic and challenging benchmarks \[[27](http://arxiv.org/abs/2311.11241)\]. Overall, these studies demonstrate the ongoing efforts to refine open-vocabulary detection methods, ensuring they can handle diverse and dynamic real-world environments.
