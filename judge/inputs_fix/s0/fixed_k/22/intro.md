## Related Works

Unsupervised domain adaptation (UDA) for semantic segmentation has been extensively studied to address the domain shift between labeled source and unlabeled target domains \[[1](http://arxiv.org/abs/2405.19899)\]. Traditional UDA methods assume a shared label space between source and target, which is often unrealistic in real-world scenarios where novel classes may appear in the target domain \[[1](http://arxiv.org/abs/2405.19899)\]. This limitation leads to performance degradation when private classes exist \[[1](http://arxiv.org/abs/2405.19899)\]. Several approaches have been proposed to address this issue, including open-set domain adaptation (OSDA) \[[1](http://arxiv.org/abs/2405.19899)\], which explicitly accounts for unknown classes in the target domain.

Early methods focused on aligning feature distributions between domains using adversarial learning \[[1](http://arxiv.org/abs/2405.19899)\]. For instance, \[[2](http://arxiv.org/abs/2110.10639)\] introduced a two-step semi-supervised dual-domain adaptation (SSDDA) approach to address both cross- and intra-domain gaps in semantic segmentation. This method uses an image-level mixing strategy for cross-domain adaptation and a student-teacher network for intra-domain adaptation \[[2](http://arxiv.org/abs/2110.10639)\]. Similarly, \[[3](http://arxiv.org/abs/2012.12545)\] proposed a zero-style loss to reduce the domain gap by separating content and style in images, enabling effective semantic segmentation using synthetic data \[[3](http://arxiv.org/abs/2012.12545)\].

More recently, methods have been developed to handle the open-set scenario, where the target domain may include unknown classes \[[1](http://arxiv.org/abs/2405.19899)\]. \[[4](http://arxiv.org/abs/2103.15467)\] introduced a category-adaptive threshold mechanism to improve pseudo-label generation for self-supervised learning (SSL) in UDA \[[4](http://arxiv.org/abs/2103.15467)\]. Additionally, \[[5](http://arxiv.org/abs/2005.10876)\] proposed a novel category anchor-guided (CAG) UDA model that enforces category-aware feature alignment to learn shared discriminative features and classifiers simultaneously \[[5](http://arxiv.org/abs/2005.10876)\].

Another line of research focuses on improving pseudo-label quality through self-training and consistency regularization \[[6](http://arxiv.org/abs/2103.16372)\]. For example, \[[7](http://arxiv.org/abs/2405.06502)\] introduced a threshold-adaptive unsupervised focal loss to regularize predictions in the target domain, helping to optimize hard samples and avoid generating unreliable pseudo-labels \[[7](http://arxiv.org/abs/2405.06502)\]. This approach was later extended to incorporate cross-domain image mixing (CIM) to bridge semantic knowledge between domains \[[7](http://arxiv.org/abs/2405.06502)\].

In addition to pseudo-label refinement, some methods have explored domain-specific feature alignment to enhance generalization \[[8](http://arxiv.org/abs/1910.13049)\]. \[[9](http://arxiv.org/abs/2208.10716)\] proposed a geometric UDA method (GUDA) that uses self-supervised monocular depth estimation as a proxy task to bridge the domain gap in sim-to-real adaptation \[[9](http://arxiv.org/abs/2208.10716)\]. This approach combines synthetic semantic supervision with real-world geometric constraints to learn domain-invariant representations \[[9](http://arxiv.org/abs/2208.10716)\].

Furthermore, methods have been developed to handle the challenge of class imbalance in UDA \[[10](http://arxiv.org/abs/2205.11419)\]. \[[11](http://arxiv.org/abs/2201.01003)\] introduced a multi-level learning framework that leverages prototype-based pseudo-label aggregation and cross-domain alignment loss to improve performance on benchmark datasets \[[11](http://arxiv.org/abs/2201.01003)\]. This approach was further extended to handle multi-source UDA, where labeled data comes from multiple source domains \[[12](http://arxiv.org/abs/2011.08502)\].

In summary, the field of UDA for semantic segmentation has seen significant advancements, with methods focusing on domain alignment, pseudo-label refinement, and class imbalance mitigation. These approaches have laid the groundwork for the proposed UniDA-SS framework, which addresses the limitations of traditional UDA by introducing a novel solution that operates without prior knowledge of category settings \[[1](http://arxiv.org/abs/2405.19899)\].
