## Related Works

Anomaly detection has gained significant attention in recent years due to its critical role in quality control and fault diagnosis in industrial settings. Several approaches have been proposed to address the challenges of deploying anomaly detection models on resource-constrained embedded devices, particularly in the context of industrial IoT and smart manufacturing. For instance, TinyAD \[[1](http://arxiv.org/abs/2303.03611)\] introduces a memory-efficient framework for deploying convolutional neural networks (CNNs) on microcontroller units (MCUs), reducing peak memory consumption by 2–5× while maintaining negligible computation overhead. This is particularly relevant for real-time anomaly detection in embedded systems. Similarly, the tiled ensemble approach in \[[4](http://arxiv.org/abs/2403.04932)\] reduces memory consumption by dividing images into tiles and training dedicated models for each tile, enabling high-resolution anomaly detection within GPU memory constraints.

In addition to memory efficiency, the ability to handle incomplete or multimodal data is crucial for practical anomaly detection. CMDIAD \[[2](http://arxiv.org/abs/2405.13571)\] proposes a cross-modal distillation framework that enables Multi-modal Training, Few-modal Inference (MTFI), allowing models to leverage incomplete multimodal information during inference. This is especially useful in industrial settings where only a subset of samples can be inspected using all available modalities. Furthermore, the use of synthetic data and digital twin systems has been explored for training anomaly detection models when real-world labeled anomalies are scarce. For example, \[[9](http://arxiv.org/abs/2011.06296)\] introduces weakly supervised approaches using Digital Twin systems to generate synthetic datasets, which are then used for training anomaly detection models with minimal labeled data.

Another important aspect is the integration of deep learning models with real-time processing capabilities. The LSTM-based Encoder-Decoder (EncDec-AD) \[[5](http://arxiv.org/abs/1607.00148)\] is designed to detect anomalies in time-series data by learning to reconstruct normal behavior and using reconstruction error as a detection metric. This approach is effective for both predictable and unpredictable time-series, making it suitable for a wide range of industrial applications. Similarly, the use of vision foundation models for semantic anomaly detection \[[8](http://arxiv.org/abs/2505.07998)\] leverages the semantic priors of state-of-the-art vision models to detect contextually invalid visual patterns, which is critical for autonomous systems.

In the context of industrial anomaly detection, the use of patch-based methods has also been explored. AnomalousPatchCore \[[13](http://arxiv.org/abs/2408.15113)\] proposes a system that fine-tunes a feature extractor using both normal and anomalous in-domain samples, enabling more accurate anomaly detection. This approach is particularly useful in industrial settings where anomalous samples are frequently available. Additionally, the use of mixed graphical models for anomaly detection and localization \[[12](http://arxiv.org/abs/1607.05974)\] has been proposed, allowing for precise localization of anomalies in heterogeneous data.

In summary, recent works have focused on improving the efficiency, robustness, and adaptability of anomaly detection models for industrial applications. These approaches range from memory-efficient CNNs \[[1](http://arxiv.org/abs/2303.03611)\] to multimodal and synthetic data-driven methods \[[2](http://arxiv.org/abs/2405.13571)\]\[[9](http://arxiv.org/abs/2011.06296)\], as well as real-time processing frameworks \[[4](http://arxiv.org/abs/2403.04932)\]\[[5](http://arxiv.org/abs/1607.00148)\]\[[8](http://arxiv.org/abs/2505.07998)\]\[[13](http://arxiv.org/abs/2408.15113)\]. These contributions highlight the ongoing efforts to develop practical and scalable anomaly detection solutions for industrial environments.
