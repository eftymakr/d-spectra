## Related Works

Vision Transformers (ViTs) have gained significant attention for their ability to capture global context through self-attention mechanisms, leading to strong performance in computer vision tasks \[[15](http://arxiv.org/abs/2205.11397)\]. However, the high computational complexity and memory demands of ViTs pose challenges for efficient hardware acceleration, especially on resource-constrained devices \[[18](http://arxiv.org/abs/2503.02891)\]. Existing approaches often rely on CPU-based execution for complex operations like Softmax and LayerNorm, which are sensitive to model accuracy and difficult to map onto low-precision hardware \[[1](https://www.semanticscholar.org/paper/0ade4d722e48379761d17cf1efc05200315c27d9)\]. This results in suboptimal performance due to communication overhead between the CPU and accelerator \[[1](https://www.semanticscholar.org/paper/0ade4d722e48379761d17cf1efc05200315c27d9)\].

Several works have explored hardware acceleration for ViTs. HDViT proposes a heterogeneous FPGA accelerator that addresses the mismatch between operators and hardware architectures, achieving significant performance improvements \[[1](https://www.semanticscholar.org/paper/0ade4d722e48379761d17cf1efc05200315c27d9)\]. Auto-ViT-Acc introduces an FPGA-aware automatic acceleration framework with mixed-scheme quantization, achieving up to 5.6x speedup on frame rate with minimal accuracy drop \[[2](http://arxiv.org/abs/2208.05163)\]. HeatViT focuses on hardware-efficient token pruning, reducing computation and memory usage while maintaining accuracy \[[3](http://arxiv.org/abs/2211.08110)\]. ME-ViT introduces a memory-efficient design to minimize off-chip memory access, achieving substantial improvements in memory bandwidth and throughput \[[5](http://arxiv.org/abs/2402.09709)\]. ReViT leverages visual semantics to accelerate ViT execution, achieving speedup and energy efficiency improvements \[[6](https://www.semanticscholar.org/paper/f47b726ad00e1a93adc5b3e266c71d75bb05e1ff)\]. EfficientViT, a hybrid convolution-transformer architecture, has also been targeted for hardware acceleration \[[7](http://arxiv.org/abs/2403.20230)\].

Quantization techniques have been widely explored to reduce the computational and memory demands of ViTs. Q-ViT introduces a fully quantized ViT with an information rectification module to mitigate performance degradation \[[10](http://arxiv.org/abs/2210.06707)\]. Trio-ViT focuses on post-training quantization for softmax-free efficient ViTs, achieving significant speedup and DSP efficiency improvements \[[9](http://arxiv.org/abs/2405.03882)\]. BSViT employs dynamic patch and weight bit-group quantization, enhancing energy efficiency and performance \[[16](https://www.semanticscholar.org/paper/b2e51759f910101691039846bec4401a85b53309)\]. These methods highlight the importance of algorithm-hardware co-design for efficient ViT acceleration \[[18](http://arxiv.org/abs/2503.02891)\].

Recent works have also focused on reducing computational complexity through pruning and token reorganization. EViT reorganizes image tokens during inference, reducing redundant computations and improving inference speed with minimal accuracy loss \[[17](http://arxiv.org/abs/2202.07800)\]. ViTCoD proposes a dedicated algorithm and accelerator co-design framework, achieving substantial speedups by optimizing attention computations and data movements \[[14](http://arxiv.org/abs/2210.09573)\]. These approaches demonstrate the potential of combining algorithmic optimizations with hardware-specific designs to enhance ViT performance \[[18](http://arxiv.org/abs/2503.02891)\].

In summary, while existing methods have made progress in ViT acceleration, there remains a need for comprehensive solutions that address both algorithmic and hardware challenges. Our work introduces a novel approach that maps all ViT operations onto FPGAs using a new arithmetic format, achieving significant speedup and hardware efficiency improvements \[[1](https://www.semanticscholar.org/paper/0ade4d722e48379761d17cf1efc05200315c27d9)\].

### <a id='category-challenges-in-vit-hardware-acceleration'></a>Challenges in ViT Hardware Acceleration: 5 papers found.
Vision Transformer (ViT) hardware acceleration faces significant challenges due to the model's complex arithmetic operations, such as Softmax and LayerNorm, which are sensitive to model accuracy and difficult to map onto efficient hardware with low precision \[[1](https://www.semanticscholar.org/paper/0ade4d722e48379761d17cf1efc05200315c27d9)\]. Existing accelerators often offload these operations to the CPU, leading to suboptimal performance due to communication overhead between the CPU and accelerator \[[1](https://www.semanticscholar.org/paper/0ade4d722e48379761d17cf1efc05200315c27d9)\]. To address these challenges, several works have proposed specialized hardware solutions. HDViT introduces a heterogeneous FPGA accelerator that incorporates multiple processing engines (PEs) to handle different operators in ViT models, along with a hybrid-oriented dataflow mapping strategy to reduce data transmission granularity and alleviate storage pressure \[[1](https://www.semanticscholar.org/paper/0ade4d722e48379761d17cf1efc05200315c27d9)\]. ME-ViT focuses on minimizing memory traffic by implementing a single-load policy, where model parameters are loaded once and intermediate results are stored on-chip, achieving significant improvements in memory bandwidth and throughput \[[5](http://arxiv.org/abs/2402.09709)\]. EfficientViT, a Convolution-Transformer hybrid architecture, has also been targeted by FPGA-based accelerators that aim to enhance hardware utilization through reconfigurable architectures and time-multiplexed dataflows \[[7](http://arxiv.org/abs/2403.20230)\]. CHOSEN proposes a software-hardware co-design framework that includes multi-kernel design, approximate non-linear functions, and an efficient compiler to maximize performance and memory efficiency on FPGAs \[[11](http://arxiv.org/abs/2407.12736)\]. ViTA, designed for resource-constrained edge devices, employs head-level pipelining and inter-layer MLP optimizations to reduce off-chip memory accesses, achieving high hardware utilization and suitable power efficiency for edge applications \[[12](http://arxiv.org/abs/2302.09108)\]. These approaches collectively highlight the need for tailored hardware solutions that address the unique computational and memory demands of ViT models.

### <a id='category-quantization-techniques-for-vits'></a>Quantization Techniques for ViTs: 5 papers found.
Vision Transformers (ViTs) have emerged as a powerful alternative to convolutional neural networks (CNNs) in computer vision tasks, offering strong performance in capturing global context \[[2](http://arxiv.org/abs/2208.05163)\]. However, their deployment on resource-constrained devices is hindered by high computational and memory demands, necessitating efficient quantization and hardware acceleration techniques \[[4](http://arxiv.org/abs/2405.00314)\]. Existing methods often rely on algorithmic quantization without hardware optimization, leading to limited performance gains \[[2](http://arxiv.org/abs/2208.05163)\]. To address this, recent work has focused on FPGA-aware quantization frameworks that integrate both algorithmic and hardware design considerations \[[2](http://arxiv.org/abs/2208.05163)\]. For instance, one study proposed a mixed-scheme quantization approach that achieves higher Top-1 accuracy compared to state-of-the-art quantization methods while significantly improving frame rates on FPGA accelerators \[[2](http://arxiv.org/abs/2208.05163)\]. Another approach, Trio-ViT, eliminates the quantization-sensitive Softmax operation and integrates linear attention, enabling efficient hardware acceleration with substantial speedup and DSP efficiency improvements \[[9](http://arxiv.org/abs/2405.03882)\]. Similarly, the Q-ViT framework addresses performance degradation in low-bit quantization by introducing an information rectification module and distribution-guided distillation, achieving competitive accuracy with significant speedup \[[10](http://arxiv.org/abs/2210.06707)\]. Additionally, BSViT introduces a bit-serial accelerator with dynamic patch and weight bit-group quantization, enhancing both speed and energy efficiency through algorithm-hardware co-design \[[16](https://www.semanticscholar.org/paper/b2e51759f910101691039846bec4401a85b53309)\]. These efforts highlight the growing interest in quantization techniques tailored to ViTs, aiming to reduce computational costs while maintaining model accuracy \[[4](http://arxiv.org/abs/2405.00314)\].

### <a id='category-algorithmic-optimizations-for-vit-efficiency'></a>Algorithmic Optimizations for ViT Efficiency: 8 papers found.
The related works section focuses on algorithmic optimizations for ViT efficiency, which aim to reduce computational costs and improve hardware deployment while maintaining model accuracy. Several studies have explored pruning techniques, such as token pruning and weight pruning, to reduce the complexity of ViT models \[[3](http://arxiv.org/abs/2211.08110)\]\[[13](http://arxiv.org/abs/2403.14047)\]. For instance, HeatViT introduces an image-adaptive token pruning framework that dynamically identifies and consolidates non-informative tokens, achieving significant computation reduction without sacrificing much accuracy \[[3](http://arxiv.org/abs/2211.08110)\]. Similarly, ReViT leverages hierarchical visual semantics to reduce computation and communication in a differential attention mechanism, offering speedup and energy efficiency improvements over existing accelerators \[[6](https://www.semanticscholar.org/paper/f47b726ad00e1a93adc5b3e266c71d75bb05e1ff)\]. The EViT method reorganizes image tokens during the feed-forward process, preserving attentive tokens and fusing inattentive ones to expedite subsequent computations, achieving a 50% increase in inference speed with minimal accuracy loss \[[17](http://arxiv.org/abs/2202.07800)\]. Additionally, the SuperViT approach enables models to handle varying computational costs by preserving informative tokens with different keeping rates, demonstrating performance improvements and reduced computational costs \[[15](http://arxiv.org/abs/2205.11397)\]. These methods highlight the importance of combining algorithmic and hardware-level optimizations to enhance ViT efficiency for real-world applications \[[3](http://arxiv.org/abs/2211.08110)\]\[[6](https://www.semanticscholar.org/paper/f47b726ad00e1a93adc5b3e266c71d75bb05e1ff)\]\[[13](http://arxiv.org/abs/2403.14047)\]\[[15](http://arxiv.org/abs/2205.11397)\]\[[17](http://arxiv.org/abs/2202.07800)\].
