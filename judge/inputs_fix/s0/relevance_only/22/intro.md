## Related Works

Unsupervised domain adaptation (UDA) for semantic segmentation has been extensively studied to address the challenge of transferring knowledge from a labeled source domain to an unlabeled target domain \[[1](http://arxiv.org/abs/2405.19899)\]. Traditional UDA methods typically assume a shared label space between the source and target domains, which limits their applicability in real-world scenarios where novel classes may appear in the target domain \[[1](http://arxiv.org/abs/2405.19899)\]. This assumption leads to performance degradation when private classes exist, as these classes are not accounted for during the adaptation process \[[1](http://arxiv.org/abs/2405.19899)\].

To overcome this limitation, several works have explored open-set domain adaptation (OSDA) scenarios, where the target domain may contain unknown classes \[[1](http://arxiv.org/abs/2405.19899)\]. For instance, \[[2](http://arxiv.org/abs/2110.10639)\] introduces a semi-supervised domain adaptation (SSDA) approach that leverages both labeled source and a small amount of labeled target data to address cross- and intra-domain gaps. This work proposes a two-step adaptation framework that first aligns feature distributions between domains and then improves intra-domain consistency using a student-teacher network \[[2](http://arxiv.org/abs/2110.10639)\]. Similarly, \[[3](https://www.semanticscholar.org/paper/5f9ce93f82dcd9b0f9ffe4274b81682f40d86253)\] proposes a source data-free UDA method, where only a pre-trained source model and unlabeled target data are available for adaptation. This method constructs virtual source domain data to mimic the source distribution and uses adversarial learning and self-training strategies to align the virtual and target domains \[[3](https://www.semanticscholar.org/paper/5f9ce93f82dcd9b0f9ffe4274b81682f40d86253)\].

Another line of research focuses on improving the robustness of UDA methods by addressing uncertainty in target domain predictions. For example, \[[4](https://www.semanticscholar.org/paper/6518b0e6334c6ffb9b94c551c57ad79c7008cbb5)\] introduces an uncertainty reduction approach that minimizes the entropy of predicted posteriors and maximizes the noise robustness of feature representations. This method is evaluated on transferring segmentation from synthetic to real-world driving images and achieves performance comparable to methods that have access to source data \[[4](https://www.semanticscholar.org/paper/6518b0e6334c6ffb9b94c551c57ad79c7008cbb5)\]. Additionally, \[[5](http://arxiv.org/abs/2012.12545)\] proposes a zero-style loss to separate content and style in images, enabling semantic segmentation using only synthetic data. This approach also addresses class imbalance by transferring content from tail classes from the synthetic to real domain \[[5](http://arxiv.org/abs/2012.12545)\].

In the context of multi-target UDA, \[[6](http://arxiv.org/abs/2103.15467)\] introduces a method that adapts a model to a new unseen target domain without accessing external data. This approach uses self-distillation and adversarial learning to preserve knowledge from the external data during adaptation \[[6](http://arxiv.org/abs/2103.15467)\]. Furthermore, \[[7](http://arxiv.org/abs/1904.01886)\] presents a universal domain adaptation (UDA) framework that requires no prior knowledge about the label sets of source and target domains. This method identifies common and private classes and aligns the model accordingly, achieving stable performance across different commonness levels \[[7](http://arxiv.org/abs/1904.01886)\].

In summary, existing UDA methods have made significant strides in addressing domain shift and improving generalization to target domains. However, they often rely on assumptions about the label space or require access to source data, which limits their applicability in real-world scenarios. Our proposed UniDA-SS approach addresses these limitations by introducing a novel framework that operates without prior knowledge of category settings and effectively handles private classes \[[1](http://arxiv.org/abs/2405.19899)\].
