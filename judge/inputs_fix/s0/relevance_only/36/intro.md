## Related Works

Deploying large language models (LLMs) on edge devices presents significant challenges due to limited storage, power, and computational resources \[[3](https://www.semanticscholar.org/paper/ec93fc7ec82c65a7bf7213488327d391014539ed)\]. Prior research has focused on reducing model size, improving inference efficiency, and optimizing hardware-software co-design to enable feasible deployment \[[3](https://www.semanticscholar.org/paper/ec93fc7ec82c65a7bf7213488327d391014539ed)\]\[[12](http://arxiv.org/abs/2409.03384)\]. For instance, quantization techniques such as W2A8KV4 have been proposed to reduce memory and bandwidth usage while maintaining performance \[[1](http://arxiv.org/abs/2505.03745)\]. Similarly, activation-aware weight quantization (AWQ) enables on-device LLM compression and acceleration by preserving critical weights based on activation patterns \[[19](http://arxiv.org/abs/2306.00978)\]. These methods are essential for reducing the computational footprint of LLMs on resource-constrained edge devices.

Efforts to optimize inference speed and memory usage have also led to the development of specialized hardware accelerators. FPGA-based accelerators, such as those in the AccLLM framework, offer reconfigurable computing engines that can adapt to algorithmic optimizations like pruning and quantization \[[1](http://arxiv.org/abs/2505.03745)\]. Additionally, the SECDA-LLM platform streamlines the design of FPGA-based accelerators for LLM inference, demonstrating significant improvements in latency and throughput \[[4](http://arxiv.org/abs/2408.00462)\]. These hardware solutions are crucial for achieving the high performance required for real-time applications on edge devices.

KV cache management has emerged as a key optimization technique for improving memory utilization and reducing redundant computations during LLM inference \[[14](http://arxiv.org/abs/2412.19442)\]. Techniques such as PagedAttention and efficient KV cache sharing help minimize memory fragmentation and enable higher throughput by managing dynamic memory allocation \[[13](http://arxiv.org/abs/2309.06180)\]. These methods are particularly important for handling long-context sequences and maintaining high inference speeds on edge devices.

Moreover, the deployment of LLMs on edge devices often requires lightweight models that can operate with minimal resources. Small Language Models (SLMs) have been developed to address this need, offering efficient performance with reduced computational requirements \[[22](http://arxiv.org/abs/2410.20011)\]. Techniques such as model compression, pruning, and quantization are commonly used to achieve this efficiency \[[6](http://arxiv.org/abs/2404.14294)\]\[[22](http://arxiv.org/abs/2410.20011)\]. These approaches are vital for enabling LLM deployment on edge devices where hardware resources are limited.

Recent work has also explored the use of hardware-aware evolutionary search to design efficient hybrid networks for edge devices \[[15](http://arxiv.org/abs/2408.15395)\]. This approach enables the creation of architectures that are optimized for specific hardware constraints, leading to improved performance and reduced latency. Additionally, the integration of sparsity-aware techniques, such as activation sparsity, has shown promise in reducing memory and computational demands while maintaining model accuracy \[[10](http://arxiv.org/abs/2412.12178)\].

In summary, the field of LLM deployment on edge devices is rapidly evolving, with a growing body of research focused on algorithmic, hardware, and system-level optimizations. These efforts aim to address the challenges of limited resources while maintaining high performance and accuracy. Future work should continue to explore hybrid approaches that combine software and hardware innovations to enable efficient and scalable LLM deployment on edge devices.
