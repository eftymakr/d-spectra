## Related Works

Memory bandwidth regulation and cache partitioning have been extensively studied for achieving predictable timing in real-time computing systems \[[1](http://arxiv.org/abs/2310.02959)\]. These techniques are often combined with partitioned scheduling to manage task execution times, which are highly dependent on allocated resources \[[1](http://arxiv.org/abs/2310.02959)\]. Prior work has focused on optimizing the co-allocation of tasks and resources to cores, which is critical for improving schedulability and reducing interference \[[1](http://arxiv.org/abs/2310.02959)\]. 

Several studies have explored the co-optimization of cache partitioning and task scheduling. For instance, a hybrid multi-layer design space exploration technique was proposed to improve real-time schedulability by interleaving cache partitioning, task allocation, and schedulability analysis \[[1](http://arxiv.org/abs/2310.02959)\]. This approach uses a breadth-first search combined with proactive pruning for cache partitioning, a first-fit heuristic for task allocation, and a recurrence relation for schedulability analysis \[[1](http://arxiv.org/abs/2310.02959)\]. The results showed that this framework can improve the real-time schedulability of non-preemptive fixed-priority (NP-FP) task sets by an average of 15.2% \[[1](http://arxiv.org/abs/2310.02959)\]. 

In addition to cache partitioning, memory bandwidth regulation has been investigated to reduce contention in shared memory resources \[[2](http://arxiv.org/abs/1809.05921)\]. A dynamic allocation of main memory bandwidth was studied, where the worst-case response time of tasks spanning through different time intervals with varying bandwidth-to-core assignments was analyzed \[[2](http://arxiv.org/abs/1809.05921)\]. The response time computation was reduced to a maximization problem over memory request assignments, and the proposed analysis was demonstrated to improve the schedulability of Integrated Modular Avionics systems \[[2](http://arxiv.org/abs/1809.05921)\]. 

Another line of research focuses on the regulation of shared last-level cache (LLC) bandwidth, particularly in multi-banked LLCs \[[3](http://arxiv.org/abs/2410.14003)\]. A per-bank bandwidth regulation approach was proposed to prevent unnecessary throttling of non-contended banks, thereby improving performance without compromising isolation benefits \[[3](http://arxiv.org/abs/2410.14003)\]. This approach was implemented on a RISC-V system-on-chip (SoC) platform using FireSim and showed significant performance improvements over prior bank-oblivious bandwidth throttling approaches \[[3](http://arxiv.org/abs/2410.14003)\]. 

The multiframe model was introduced to eliminate pessimism in the schedulability analysis of systems with tasks whose worst-case execution times vary from job to job \[[4](https://www.semanticscholar.org/paper/e8d15aa827be70bebf15e217ac9295276ddebda7)\]. However, this model is optimistic and unsafe for multicores with shared memory controllers, as it ignores memory contention \[[4](https://www.semanticscholar.org/paper/e8d15aa827be70bebf15e217ac9295276ddebda7)\]. To address this, existing stall analyses were adapted to the multiframe model, leading to a higher scheduling success ratio and improved platform utilization \[[4](https://www.semanticscholar.org/paper/e8d15aa827be70bebf15e217ac9295276ddebda7)\]. 

In the context of multi-objective optimization, a new parallel optimization method was proposed to reduce execution time and energy consumption in cache memory designs \[[5](http://arxiv.org/abs/2302.11236)\]. This method uses Multi-Objective Evolutionary Algorithms to find optimal cache configurations for target applications, achieving up to 64.43% improvement in execution time and 91.69% reduction in energy consumption \[[5](http://arxiv.org/abs/2302.11236)\]. 

The joint cache partition and job assignment problem has also been studied, with a constant approximation algorithm proposed for this problem \[[6](http://arxiv.org/abs/1210.4053)\]. The algorithm was shown to be more efficient than existing approaches, and further improvements were explored by allowing dynamic cache partitions and job assignments \[[6](http://arxiv.org/abs/1210.4053)\]. 

In summary, the proposed approach in this paper builds upon and extends these prior works by introducing a 0-1 linear program for task-resource co-allocation and a multi-objective heuristic designed to minimize resource usage while guaranteeing schedulability under a preemptive EDF scheduling policy \[[1](http://arxiv.org/abs/2310.02959)\].
