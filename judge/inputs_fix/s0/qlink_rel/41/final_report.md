## Related Works

Serverless computing has gained significant traction due to its ability to abstract server management, enabling automatic scaling, efficient resource utilization, and cost-effective pricing models \[[8](http://arxiv.org/abs/1911.01296)\]. However, a critical challenge remains: cold-start latency, which significantly impacts end-to-end performance \[[1](https://www.semanticscholar.org/paper/d911b03bfda4fc6fc92f8080bb81b3a967d6a9e7)\]. This issue arises when a function is invoked and no pre-provisioned "warm" container is available, leading to delays in initializing the runtime environment and dependencies \[[16](http://arxiv.org/abs/1903.12221)\]. Several studies have explored strategies to mitigate this problem.

Early work focused on reducing the duration of cold starts by optimizing the initialization process. For instance, Catalyzer introduces an initialization-less booting mechanism, restoring function instances from checkpoint images to achieve sub-millisecond startup latency \[[2](https://www.semanticscholar.org/paper/f14446970a5ed7145a6d350e1aff07ca203cece8)\]. Similarly, FaaSLight reduces cold-start latency by optimizing code loading through application-level analysis, separating essential code from optional components \[[10](http://arxiv.org/abs/2207.08175)\]. These approaches demonstrate that reducing initialization overhead can significantly improve performance.

Another line of research addresses the frequency of cold starts rather than their duration. Techniques such as adaptive warm-up strategies and container pool management aim to pre-warm resources based on predicted invocation patterns \[[5](https://www.semanticscholar.org/paper/81b8db7a20f1aa859143c716b38a1443e3eca9a0)\]. For example, the Adaptive Function Launching Acceleration approach predicts function invocation times and pre-warms functions, thereby reducing cold starts \[[5](https://www.semanticscholar.org/paper/81b8db7a20f1aa859143c716b38a1443e3eca9a0)\]. Similarly, the WLEC architecture minimizes cold start time by managing containers using a modified S2LRU cache structure \[[13](https://www.semanticscholar.org/paper/fde534d033dea54e1b9066bad32d7330febe54f3)\]. These methods highlight the importance of proactive resource management in mitigating cold starts.

Recent work has also explored the use of reinforcement learning to predict and prepare function instances in advance, reducing the frequency of cold starts \[[7](https://www.semanticscholar.org/paper/96d4fea8d034a7605af936f2e2b6a44becdf6585)\]. This approach leverages CPU utilization and invocation patterns to optimize resource allocation, demonstrating the potential of machine learning in serverless environments. Additionally, the FaasCache system employs caching-inspired keep-alive policies to maintain warm function instances, reducing cold-start overhead by over 3× compared to existing methods \[[15](https://www.semanticscholar.org/paper/3c05fec4087d94c61233a482e59b613388b2c3ae)\].

The cascading cold start problem, where a sequence of function invocations in a workflow incurs multiple delays, has also been addressed. Xanadu mitigates this issue by using speculative and just-in-time provisioning of resources, effectively eliminating cascading cold starts with minimal overhead \[[12](https://www.semanticscholar.org/paper/1cd137e77753ee6c51c97c520d64f91d484dbddc)\]. These optimizations are particularly relevant for workflows that require sequential function execution.

In summary, while various strategies have been proposed to reduce cold-start latency, the challenge persists due to the dynamic and unpredictable nature of serverless workloads. The proposed SLIMSTART tool addresses this by leveraging profile-guided optimization, identifying and mitigating inefficient library usage patterns through statistical sampling and call-path profiling \[[1](https://www.semanticscholar.org/paper/d911b03bfda4fc6fc92f8080bb81b3a967d6a9e7)\]. By integrating with CI/CD pipelines, SLIMSTART enables continuous optimization, demonstrating the potential of adaptive monitoring in improving serverless performance.
