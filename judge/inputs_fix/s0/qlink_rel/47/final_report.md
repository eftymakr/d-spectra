## Related Works

Multi-Domain Recommendation (MDR) has emerged as a promising approach to enhance recommendation performance by leveraging knowledge transfer across different domains \[[16](http://arxiv.org/abs/2201.05973)\]. Traditional MDR methods often assume a single structure for transferring domain-shared knowledge, which may not be effective when the transferable information varies across domains \[[16](http://arxiv.org/abs/2201.05973)\]. This limitation can lead to the Negative Transfer Problem (NTP), where knowledge from a source domain negatively affects the target domain's performance, especially when there is a conflict in domain knowledge or when the source domain has poor quality \[[16](http://arxiv.org/abs/2201.05973)\]. 

To address these challenges, several studies have proposed frameworks that aim to improve the adaptability of MDR systems. For instance, CoNet \[[2](http://arxiv.org/abs/1804.06769)\] introduces a deep transfer learning approach using neural networks to enable dual knowledge transfer across domains. This method uses cross connections between base networks to improve the learning of complex user-item interaction relationships. Similarly, DDTCDR \[[3](http://arxiv.org/abs/1910.05189)\] proposes a model based on dual learning that iteratively transfers information between domains until the learning process stabilizes. This approach explicitly models bidirectional latent relations between users and items, which helps in preserving the relationships across different latent spaces.

Another approach, DTCDR \[[4](https://www.semanticscholar.org/paper/2b031c7170c9dccbe506f3d3a1d6104f65e835ae)\], focuses on dual-target cross-domain recommendation by utilizing multi-source content information and designing an adaptable embedding-sharing strategy. This strategy allows for the simultaneous improvement of recommendation performance in both richer and sparser domains. The method also incorporates Multi-Task Learning (MTL) to combine and share embeddings of common users across domains. 

In addition to these, the work in \[[5](https://www.semanticscholar.org/paper/d5630291a4ba3f6266c77e6d00920502f986afa6)\] proposes a Bi-directional Transfer learning method using Graph Collaborative Filtering networks (BiTGCF). This method not only exploits high-order connectivity in user-item graphs but also enables two-way knowledge transfer across domains by using common users as a bridge. The fusion of users' common and domain-specific features during transfer further enhances the recommendation performance.

The work in \[[6](https://www.semanticscholar.org/paper/24a473700894dbfab0bfd9dc3d542acfeef66bca)\] introduces the Preference Propagation GraphNet (PPGN), which addresses the limitations of existing cross-domain recommendation algorithms by constructing a Cross-Domain Preference Matrix (CDPM) and using a propagation layer to capture how user preferences propagate in the graph. This approach simplifies cross-domain recommendation into a unified multi-task model, improving the overall performance.

These studies highlight the need for more flexible and adaptive MDR frameworks that can dynamically select and transfer relevant domain knowledge while avoiding the NTP. The proposed Similar Domain Selection Principle (SDSP) in this paper aims to address these issues by introducing a lightweight and dynamic method for selecting suitable domain knowledge based on domain-level gaps and unsupervised distance measures \[[19](http://arxiv.org/abs/2211.11964)\].

### <a id='category-multi-task-learning-(mtl)-in-cross-domain-recommendations'></a>Multi-Task Learning (MTL) in Cross-Domain Recommendations: 5 papers found.
Cross-domain recommendation (CDR) has been widely studied to address the data sparsity problem in recommender systems by leveraging information from richer domains \[[1](http://arxiv.org/abs/2103.01696)\]. Recent approaches have focused on improving performance in both source and target domains, leading to the development of dual-target CDR methods \[[2](http://arxiv.org/abs/1804.06769)\]. These methods aim to enhance recommendation accuracy across multiple domains simultaneously by utilizing shared embeddings and multi-source content information \[[2](http://arxiv.org/abs/1804.06769)\]. Multi-task learning (MTL) has emerged as a key technique in this context, enabling the joint optimization of multiple recommendation tasks \[[3](http://arxiv.org/abs/1910.05189)\]. However, MTL models often suffer from negative transfer due to complex task correlations, where improving one task may degrade another \[[4](https://www.semanticscholar.org/paper/2b031c7170c9dccbe506f3d3a1d6104f65e835ae)\]. To mitigate this, researchers have proposed progressive layered extraction (PLE) models that separate shared and task-specific components, improving efficiency and performance across different task correlations \[[4](https://www.semanticscholar.org/paper/2b031c7170c9dccbe506f3d3a1d6104f65e835ae)\]. Additionally, multi-sparse-domain collaborative recommendation (MSDCR) has been introduced to handle scenarios where all domains are sparse, using domain-specific and domain-invariant preference modeling to enhance recommendation accuracy \[[5](https://www.semanticscholar.org/paper/d5630291a4ba3f6266c77e6d00920502f986afa6)\]. These approaches highlight the ongoing efforts to refine CDR methods through advanced MTL strategies and domain adaptation techniques.
