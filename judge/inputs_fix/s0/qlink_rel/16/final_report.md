## Related Works

Open-vocabulary object detection has emerged as a critical research direction, enabling detectors to recognize objects from a vocabulary specified at test time, often in natural language \[[1](http://arxiv.org/abs/2011.10678)\]. This capability is particularly valuable for applications requiring flexible and dynamic object recognition, such as robotics and augmented reality \[[2](http://arxiv.org/abs/2104.13921)\]. However, the performance of these detectors can be significantly impacted by the quality and relevance of the user-defined vocabulary \[[3](http://arxiv.org/abs/2205.06230)\]. Prior work has explored various approaches to improve detection accuracy by leveraging pre-trained models, weak supervision, and language-visual alignment \[[4](http://arxiv.org/abs/2103.00020)\].

Several studies have focused on improving open-vocabulary detection by using vision-language pre-training models like CLIP and ALIGN \[[5](http://arxiv.org/abs/2203.14940)\]. These models enable zero-shot transfer by aligning visual and textual representations, allowing detectors to recognize objects without explicit bounding box annotations \[[6](http://arxiv.org/abs/2203.11876)\]. For instance, ViLD leverages vision-language knowledge distillation to train a two-stage detector, achieving competitive performance on benchmark datasets like LVIS and COCO \[[7](http://arxiv.org/abs/2207.03482)\]. Similarly, RegionCLIP extends CLIP to learn region-level visual representations, enabling fine-grained alignment between image regions and textual concepts \[[8](http://arxiv.org/abs/2111.09452)\].

Another line of research has explored the use of pseudo-labeling and self-training frameworks to generate bounding box annotations from large-scale image-caption pairs \[[9](http://arxiv.org/abs/2207.08954)\]. This approach reduces the reliance on manual annotations and enables the detection of novel object categories \[[10](http://arxiv.org/abs/2201.02605)\]. For example, the PB-OVD method generates pseudo bounding-box labels from image-caption pairs, leading to significant improvements in performance on datasets like COCO and LVIS \[[11](http://arxiv.org/abs/2203.16513)\]. Similarly, the Detic framework trains detectors on image classification data, expanding the vocabulary of detectors to tens of thousands of concepts \[[12](http://arxiv.org/abs/2211.14843)\].

Recent advances have also focused on improving the efficiency and scalability of open-vocabulary detection by simplifying training pipelines and reducing the need for complex pretraining \[[13](http://arxiv.org/abs/2104.12763)\]. For instance, F-VLM demonstrates that frozen vision-language models can be effectively used for open-vocabulary detection by fine-tuning only the detector head \[[14](http://arxiv.org/abs/1405.0312)\]. This approach simplifies the training process and improves inference speed \[[15](http://arxiv.org/abs/1908.03195)\].

In addition, methods like Grounding DINO have been proposed to enable open-set object detection by integrating language and vision modalities \[[16](https://www.semanticscholar.org/paper/c5ff974a69fd0c760b4855b819e61e89f31cfffe)\]. This model uses grounded pre-training to detect arbitrary objects based on natural language inputs, achieving state-of-the-art performance on benchmarks like COCO and LVIS \[[17](http://arxiv.org/abs/2112.09106)\]. The success of these methods highlights the importance of aligning visual and textual representations for effective open-vocabulary detection \[[18](http://arxiv.org/abs/2303.13076)\].

Finally, the development of efficient and scalable detection frameworks, such as DETR and YOLO, has enabled real-time object detection with high accuracy \[[19](http://arxiv.org/abs/2203.10593)\]. These models have been adapted for open-vocabulary settings by incorporating vision-language pre-training and pseudo-labeling techniques \[[20](http://arxiv.org/abs/2102.05918)\]. The integration of these approaches has led to significant improvements in detection performance, particularly for novel and rare object categories \[[21](http://arxiv.org/abs/2205.06160)\].

### <a id='category-zero-shot-and-open-set-detection-methods'></a>Zero-shot and open-set detection methods: 4 papers found.
The category of zero-shot and open-set detection methods focuses on extending object detection to novel or arbitrary categories without explicit training data. These methods aim to bridge the gap between closed-set detectors, which are limited to pre-defined classes, and open-vocabulary systems that allow for flexible, natural language-based class specifications \[[1](http://arxiv.org/abs/2011.10678)\]. Recent approaches, such as open-vocabulary object detection, have introduced novel formulations that enable detectors to recognize objects beyond the training set by leveraging pre-trained visual-language models and semantic alignment \[[19](http://arxiv.org/abs/2203.10593)\]. For instance, methods like Grounding DINO integrate language into the detection process, enabling the detection of arbitrary objects using category names or referring expressions, and achieving state-of-the-art performance on zero-shot benchmarks \[[22](http://arxiv.org/abs/2303.05499)\]. Similarly, zero-shot object detection (ZSD) has been explored to detect unseen classes by adapting visual-semantic embeddings and addressing challenges such as background class selection and semantic label space sampling \[[25](http://arxiv.org/abs/1804.04340)\]. These methods often rely on efficient knowledge distillation techniques to transfer knowledge from pre-trained models to detectors, improving performance on both seen and unseen categories \[[19](http://arxiv.org/abs/2203.10593)\]. Additionally, some works focus on refining user-defined vocabularies during inference, as seen in the proposed Vocabulary Adapter (VocAda), which dynamically tailors the detection process to the image content \[[1](http://arxiv.org/abs/2011.10678)\]. Overall, these approaches highlight the growing interest in scalable, flexible, and robust object detection systems that can generalize to unseen or arbitrary categories \[[1](http://arxiv.org/abs/2011.10678)\]\[[19](http://arxiv.org/abs/2203.10593)\]\[[22](http://arxiv.org/abs/2303.05499)\]\[[25](http://arxiv.org/abs/1804.04340)\].

Several methods have leveraged pre-trained vision-language models to enable detection of novel classes without requiring extensive labeled data \[[5](http://arxiv.org/abs/2203.14940)\]. ### <a id='category-vision-language-pre-training-models'></a>Vision-language pre-training models: 4 papers found.
Vision-language pre-training models have been increasingly explored for their ability to learn rich, transferable visual and textual representations, enabling zero-shot and few-shot learning across diverse tasks. These models, such as CLIP, are trained on large-scale image-text pairs to align visual and linguistic data in a shared feature space, allowing for flexible downstream applications without explicit task-specific training \[[17](http://arxiv.org/abs/2112.09106)\]. However, applying such models directly to object detection tasks faces challenges due to the mismatch between whole-image-text alignment and fine-grained region-level alignment required for detecting specific objects \[[17](http://arxiv.org/abs/2112.09106)\]. To address this, RegionCLIP was proposed, extending CLIP to learn region-level visual representations by aligning image regions with textual descriptions, thereby improving performance on object detection tasks like COCO and LVIS \[[17](http://arxiv.org/abs/2112.09106)\]. Similarly, GLIP further advances this by unifying object detection and phrase grounding during pre-training, leveraging both human-annotated and web-crawled data to generate semantic-rich representations that support strong zero-shot and few-shot transferability \[[29](http://arxiv.org/abs/2112.03857)\]. Additionally, methods like CoOp have been developed to simplify prompt engineering for vision-language models, enabling efficient adaptation to downstream tasks with minimal manual intervention \[[24](http://arxiv.org/abs/2109.01134)\]. These approaches collectively highlight the growing importance of vision-language pre-training in enabling flexible, open-vocabulary object detection and recognition, while addressing challenges related to domain adaptation and prompt design \[[17](http://arxiv.org/abs/2112.09106)\]\[[24](http://arxiv.org/abs/2109.01134)\]\[[29](http://arxiv.org/abs/2112.03857)\].
