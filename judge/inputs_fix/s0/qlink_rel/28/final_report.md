## Related Works

Federated learning (FL) has emerged as a promising paradigm for training machine learning models on decentralized data while preserving privacy \[[2](http://arxiv.org/abs/1912.04977)\]. It enables multiple clients to collaboratively train a model without sharing raw data, with a central server aggregating model updates \[[2](http://arxiv.org/abs/1912.04977)\]. However, FL faces significant challenges due to the heterogeneity of client data distributions and communication constraints \[[8](http://arxiv.org/abs/1812.06127)\]. This section reviews related works that address these challenges, particularly those focusing on communication efficiency, data heterogeneity, and model personalization.

Early works in FL, such as FedAvg, assume that data across clients is independently and identically distributed (IID), which is often not the case in real-world scenarios \[[6](http://arxiv.org/abs/1806.00582)\]. Non-IID data can lead to significant accuracy degradation, as demonstrated in experiments where accuracy reduced by up to 55% for neural networks trained on highly skewed data \[[6](http://arxiv.org/abs/1806.00582)\]. To address this, researchers have proposed strategies such as creating a small subset of globally shared data to improve training performance \[[6](http://arxiv.org/abs/1806.00582)\]. Additionally, FedProx was introduced to handle statistical and system heterogeneity by allowing devices to perform variable amounts of work and improving convergence behavior in non-IID settings \[[8](http://arxiv.org/abs/1812.06127)\].

Communication efficiency is another critical challenge in FL, especially for mobile devices with limited bandwidth \[[3](http://arxiv.org/abs/1610.05492)\]. Techniques such as structured and sketched updates have been proposed to reduce uplink communication costs by compressing model updates before sending them to the server \[[3](http://arxiv.org/abs/1610.05492)\]. Adaptive optimization methods, including FedAdam and FedYogi, have also been introduced to improve performance in heterogeneous settings by adjusting learning rates dynamically \[[4](http://arxiv.org/abs/2003.00295)\].

Model personalization has gained attention as a way to address the limitations of a single global model in FL. FedPer introduces a base + personalization layer approach, allowing clients to learn personalized models while maintaining a shared global model \[[17](http://arxiv.org/abs/1912.00818)\]. Similarly, pFedMe uses Moreau envelopes to decouple personalized model optimization from global learning, achieving state-of-the-art convergence rates \[[19](http://arxiv.org/abs/2006.08848)\]. These approaches demonstrate the importance of personalization in improving model performance on heterogeneous data.

In addition to these, clustered FL (CFL) has been proposed to group clients with similar data distributions, enabling more efficient and accurate model training \[[5](http://arxiv.org/abs/1910.01991)\]. This approach does not require modifications to the FL communication protocol and can be applied to nonconvex objectives, such as deep neural networks \[[5](http://arxiv.org/abs/1910.01991)\]. Furthermore, client selection strategies, such as Power-of-Choice, have been introduced to improve convergence speed by biasing selection towards clients with higher local loss \[[15](http://arxiv.org/abs/2010.01243)\].

The concept of federated active learning (FAL), which combines active learning with FL, has also been explored to reduce annotation costs while preserving data privacy \[[1](http://arxiv.org/abs/1812.01097)\]. CHASe, the proposed method in this paper, builds upon these prior works by addressing the challenges of client heterogeneity and model parameter fluctuations through epistemic variation tracking and decision boundary alignment \[[1](http://arxiv.org/abs/1812.01097)\].

### <a id='category-federated-learning-(fl)-overview'></a>Federated Learning (FL) Overview: 9 papers found.
Federated learning (FL) is a distributed machine learning paradigm where multiple clients collaboratively train a model while keeping their data decentralized, addressing privacy and data collection challenges \[[2](http://arxiv.org/abs/1912.04977)\]. This approach is particularly relevant in scenarios involving mobile devices, wearable systems, or autonomous vehicles, where data is generated in massive quantities but cannot be centrally aggregated due to privacy and resource constraints \[[1](http://arxiv.org/abs/1812.01097)\]. However, FL faces significant challenges, including statistical heterogeneity (non-identically distributed data) and systems heterogeneity (variations in device capabilities) \[[8](http://arxiv.org/abs/1812.06127)\]. To address these issues, researchers have proposed various methods, such as FedProx, which generalizes FedAvg and allows for more robust convergence in heterogeneous settings \[[4](http://arxiv.org/abs/2003.00295)\]. Additionally, adaptive optimization techniques like Adagrad, Adam, and Yogi have been adapted for FL to improve performance in the presence of client heterogeneity \[[3](http://arxiv.org/abs/1610.05492)\]. Furthermore, ensemble distillation has been introduced to enable flexible aggregation of heterogeneous client models, improving training efficiency and reducing communication rounds \[[5](http://arxiv.org/abs/1910.01991)\]. These advancements highlight the ongoing efforts to enhance the practicality and effectiveness of FL in real-world applications.

### <a id='category-clustered-federated-learning-(cfl)'></a>Clustered Federated Learning (CFL): 2 papers found.
Clustered Federated Learning (CFL) represents an advancement in addressing the limitations of traditional federated learning (FL) by incorporating clustering techniques to improve model performance in heterogeneous client environments \[[5](http://arxiv.org/abs/1910.01991)\]. Unlike conventional FL, which assumes uniform data distribution across clients, CFL leverages the geometric properties of the FL loss surface to dynamically group clients into clusters with similar data distributions, enabling more effective collaborative training \[[5](http://arxiv.org/abs/1910.01991)\]. This approach is particularly beneficial in scenarios where client data is non-convex and varies over time, as it allows for the development of more specialized models without requiring prior knowledge of the number of clusters \[[5](http://arxiv.org/abs/1910.01991)\]. Additionally, CFL is designed to be a postprocessing method, meaning it can be applied after FL has converged, thereby enhancing performance by allowing clients to refine their models based on clustered insights \[[5](http://arxiv.org/abs/1910.01991)\]. Another related work, the Iterative Federated Clustering Algorithm (IFCA), further explores the integration of clustering within FL by alternating between estimating user cluster identities and optimizing model parameters through gradient descent \[[14](http://arxiv.org/abs/2006.04088)\]. IFCA is supported by theoretical guarantees on convergence and statistical error rates, making it a robust framework for clustered FL, especially in non-convex settings such as neural networks \[[14](http://arxiv.org/abs/2006.04088)\]. These approaches collectively highlight the growing interest in leveraging clustering to enhance the efficiency and effectiveness of FL in diverse and heterogeneous environments.

Existing approaches often assume unbiased client participation, where clients are selected randomly or based on data distribution \[[15](http://arxiv.org/abs/2010.01243)\]. For instance, FedCS introduces a client selection mechanism that dynamically manages resource-constrained clients, allowing the server to aggregate more updates and enhance model performance \[[7](http://arxiv.org/abs/1804.08333)\]. Similarly, the Power-of-Choice framework leverages biased selection to achieve faster convergence and higher test accuracy compared to random selection \[[15](http://arxiv.org/abs/2010.01243)\]. These strategies demonstrate that tailoring client selection based on local conditions can significantly impact the overall efficiency and effectiveness of FL systems.

### <a id='category-model-personalization-techniques'></a>Model Personalization Techniques: 3 papers found.
Federated learning (FL) has emerged as a privacy-preserving approach to train machine learning models across decentralized data sources without sharing raw data \[[12](http://arxiv.org/abs/1909.12488)\]. However, the inherent statistical heterogeneity across clients poses challenges for achieving high performance on individual devices \[[17](http://arxiv.org/abs/1912.00818)\]. To address this, researchers have explored personalization techniques, such as Model Agnostic Meta Learning (MAML), which enables fast adaptation to diverse distributions \[[12](http://arxiv.org/abs/1909.12488)\]. This has led to the development of specialized algorithms like FedPer, which introduces a base + personalization layer to combat data heterogeneity \[[17](http://arxiv.org/abs/1912.00818)\]. Additionally, pFedMe leverages Moreau envelopes to decouple global and personalized model learning, achieving state-of-the-art convergence rates \[[19](http://arxiv.org/abs/2006.08848)\]. These approaches highlight the growing interest in personalization within FL, emphasizing the need for methods that balance global model accuracy with individual device performance.
