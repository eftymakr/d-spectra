## Related Works

Long-tailed recognition remains a challenging problem in visual recognition due to the skewed class distribution in real-world datasets \[[1](http://arxiv.org/abs/1910.09217)\]. Many existing methods have attempted to address this issue by either re-balancing the data, adjusting the loss function, or modifying the classifier \[[2](http://arxiv.org/abs/2207.09052)\]. For instance, class-balancing strategies such as loss re-weighting, data re-sampling, or transfer learning from head to tail classes have been widely explored \[[1](http://arxiv.org/abs/1910.09217)\]. However, most of these approaches still follow a joint learning scheme for representation and classification \[[1](http://arxiv.org/abs/1910.09217)\].

Recent work has focused on decoupling the learning process into separate representation and classification stages, which has shown promising results \[[1](http://arxiv.org/abs/1910.09217)\]. For example, the paper by \[[1](http://arxiv.org/abs/1910.09217)\] demonstrates that data imbalance might not be a significant issue in learning high-quality representations, and that a simple instance-balanced sampling can lead to strong long-tailed recognition performance when combined with a well-designed classifier. Similarly, \[[2](http://arxiv.org/abs/2207.09052)\] proposes a novel loss function for contrastive learning, called Balanced Contrastive Learning (BCL), which addresses the issue of forming a regular simplex in long-tailed data. This is crucial for improving the feature representation and classification performance.

Another approach to improving long-tailed recognition is through contrastive learning, which has been shown to be effective in learning discriminative features \[[3](http://arxiv.org/abs/2107.12028)\]. Supervised contrastive learning (SCL) has been widely used, but it suffers from issues such as gradient conflicts and imbalanced attraction and repulsion gradients between positive and negative pairs \[[4](http://arxiv.org/abs/2111.13998)\]. These issues are identified through theoretical gradient analysis in \[[4](http://arxiv.org/abs/2111.13998)\], which highlights the need for a more robust contrastive learning framework. The paper \[[5](http://arxiv.org/abs/1904.05160)\] further explores the effectiveness of contrastive learning in long-tailed scenarios and proposes a hybrid network structure that combines supervised contrastive loss with cross-entropy loss to improve classification accuracy.

Additionally, methods such as Parametric Contrastive Learning (PaCo) have been introduced to address the bias towards high-frequency classes in supervised contrastive loss \[[6](http://arxiv.org/abs/1912.02413)\]. PaCo introduces class-wise learnable centers to rebalance the optimization process and improve the performance of long-tailed recognition. Similarly, Targeted Supervised Contrastive Learning (TSC) has been proposed to improve the uniformity of the feature distribution on the hypersphere \[[7](http://arxiv.org/abs/2103.14267)\]. TSC generates targets uniformly distributed on a hypersphere and ensures that features of different classes converge to these targets during training, which improves class boundaries and generalization.

In summary, while various methods have been proposed to address the long-tailed recognition problem, the challenge remains in designing a framework that effectively balances representation learning and classification, while also addressing the inherent biases in the data distribution \[[1](http://arxiv.org/abs/1910.09217)\]\[[2](http://arxiv.org/abs/2207.09052)\]\[[3](http://arxiv.org/abs/2107.12028)\]\[[4](http://arxiv.org/abs/2111.13998)\]\[[5](http://arxiv.org/abs/1904.05160)\]\[[6](http://arxiv.org/abs/1912.02413)\]\[[7](http://arxiv.org/abs/2103.14267)\].
