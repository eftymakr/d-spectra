## Related Works

Vision Transformers (ViTs) have revolutionized computer vision by leveraging self-attention mechanisms to capture global context, outperforming traditional convolutional neural networks (CNNs) in many tasks \[[2208.05163](http://arxiv.org/abs/2208.05163)\]. However, their deployment on resource-constrained hardware, such as FPGAs, remains challenging due to the high computational complexity and model size, especially in operations like Softmax and LayerNorm that are sensitive to precision and hard to implement efficiently on hardware \[[2210.09573](http://arxiv.org/abs/2210.09573)\]\[[2201.06618](http://arxiv.org/abs/2201.06618)\]. Existing FPGA accelerators often focus on optimizing matrix multiplication kernels while offloading these complex operations to CPUs, incurring communication overhead and limiting performance \[[2210.09573](http://arxiv.org/abs/2210.09573)\].

Several algorithmic and hardware approaches have been proposed to improve ViT efficiency and facilitate deployment. Quantization methods have been explored to reduce the bit-width of weights and activations. Auto-ViT-Acc presents an FPGA-aware automatic acceleration framework using mixed-scheme quantization, achieving improved frame rates with minimal accuracy loss compared to floating-point baselines \[[2208.05163](http://arxiv.org/abs/2208.05163)\]. VAQF similarly proposes a fully automatic software-hardware co-design framework that leverages low-bit quantization for ViTs on FPGAs, meeting real-time frame rates by selecting optimal quantization precisions for activations and weights \[[2201.06618](http://arxiv.org/abs/2201.06618)\]. These methods, however, primarily quantize matrix multiplication operations and do not fully map complex functions like Softmax and LayerNorm onto hardware.

Token pruning and adaptive token selection have been investigated to reduce computational redundancy in ViTs. HeatViT introduces a hardware-efficient, image-adaptive token pruning mechanism that dynamically identifies and consolidates non-informative tokens, achieving significant computation reductions and speedups on embedded FPGAs with only slight resource overhead \[[2211.0811](http://arxiv.org/abs/2211.08110)\]. Similarly, sparsity-based training frameworks like SViTE integrate structured and unstructured sparsity, including learnable token selectors to prune less important patches during training, resulting in considerable reductions in FLOPs and runtime without compromising accuracy \[[2106.04533](http://arxiv.org/abs/2106.04533)\]. These approaches reduce the overall workload by decreasing token counts and attention computations but still rely on partially offloaded or approximated complex operations.

Algorithm-hardware co-design frameworks have demonstrated promising results by jointly optimizing ViT architectures and accelerators. ViTCoD proposes pruning and polarizing attention maps to fixed sparse patterns combined with an auto-encoder to trade data movement costs for cheaper computations. Its dedicated accelerator coordinates sparse and dense workloads to greatly reduce data movement overhead, achieving large speedups over CPUs, GPUs, and prior Transformer accelerators \[[2210.09573](http://arxiv.org/abs/2210.09573)\]. ViTALiTy unifies low-rank and sparse approximations using a linear Taylor attention mechanism to linearize attention complexity, combined with a dedicated hardware pipeline, resulting in 3× faster and more energy-efficient inference at comparable accuracy \[[2211.05109](http://arxiv.org/abs/2211.05109)\]. These co-design methods highlight the importance of reducing both computation and data movement costs to improve hardware efficiency.

Other architectural innovations focus on multi-scale token processing and dynamic token allocation to balance accuracy and computational cost. CrossViT employs a dual-branch multi-scale token approach fused via cross-attention to enhance feature representation with linear computational complexity \[[2103.14899](http://arxiv.org/abs/2103.14899)\]. CF-ViT proposes a coarse-to-fine inference process that first classifies with coarse tokens and refines only informative regions with fine-grained patches, reducing FLOPs and increasing throughput \[[2203.03821](http://arxiv.org/abs/2203.03821)\]. The SuperViT training paradigm enables a single model to adaptively process variable token sizes and keeping rates, allowing flexible trade-offs between accuracy and computation \[[2205.11397](http://arxiv.org/abs/2205.11397)\]. Dynamic ViTs further adapt token count per image based on difficulty, activating deeper token sequences only when necessary to reduce redundant computation \[[2105.15075](http://arxiv.org/abs/2105.15075)\]. These methods improve model efficiency but do not fully address hardware mapping challenges of complex arithmetic.

Regarding hardware accelerators, ViTA presents a configurable inference accelerator targeting edge devices that avoids repeated off-chip memory access and supports various ViT models with high utilization and low power consumption \[[2302.09108](http://arxiv.org/abs/2302.09108)\]. ME-ViT proposes a single-load policy on FPGA that loads model parameters once and stores intermediate results on-chip, minimizing memory bandwidth bottlenecks and improving throughput and power efficiency significantly \[[2402.09709](http://arxiv.org/abs/2402.09709)\]. An FPGA-based reconfigurable accelerator for EfficientViT—a convolution-transformer hybrid model—supports diverse operation types with pipelined dataflows to reduce off-chip data access and improve utilization and energy efficiency \[[2403.2023](http://arxiv.org/abs/2403.20230)\]. These hardware designs demonstrate diverse strategies to improve ViT inference efficiency but often still treat non-matrix operations as software tasks or approximations.

Lastly, several works have addressed the challenge of efficiently implementing Softmax and normalization on hardware. Hardware-friendly Softmax alternatives have been proposed, such as ConSmax and Softermax, which use differentiable normalization parameters or base replacement techniques to enable parallelization and low-precision computations, improving energy efficiency while preserving functionality \[[2103.14899](http://arxiv.org/abs/2103.14899)\]\[[2201.06618](http://arxiv.org/abs/2201.06618)\]. Nonetheless, these solutions are algorithmic approximations rather than full hardware mappings integrated with ViT accelerators.

In summary, prior works have made significant progress in quantization, token pruning, sparsity, multi-scale processing, and hardware accelerator design to improve ViT efficiency and deployability on FPGAs and edge devices. However, they largely focus on accelerating matrix multiplications and approximating or offloading complex Softmax and LayerNorm operations. The proposed approach in this work uniquely addresses this gap by fully mapping all ViT operations, including Softmax and LayerNorm, onto FPGA hardware using a novel Microscaling Integer (MXInt) arithmetic format, enabling substantial speedups and improved hardware utilization without significant accuracy loss.
