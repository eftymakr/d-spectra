## Related Works

Memory bandwidth regulation and cache partitioning are established techniques to enhance predictability in real-time multicore systems by controlling interference from shared memory resources \[[1809.05921](http://arxiv.org/abs/1809.05921)\]\[[https://www.semanticscholar.org/paper/afca4afaaaa543a1da02b266e9b2ac46eb94793b](https://www.semanticscholar.org/paper/afca4afaaaa543a1da02b266e9b2ac46eb94793b)\]\[[2410.14003](http://arxiv.org/abs/2410.14003)\]. These techniques mitigate contention in caches, memory controllers, and DRAM banks, which otherwise induce significant variability in task execution times. Prior studies emphasize that careful co-allocation of tasks and memory resources to cores is crucial since execution times strongly depend on allocated resources \[[1809.05921](http://arxiv.org/abs/1809.05921)\]\[[2310.02959](http://arxiv.org/abs/2310.02959)\].

Memory interference modeling and mitigation have been extensively studied. For example, bounding worst-case memory interference in commercial off-the-shelf (COTS) multicore systems involves detailed modeling of DRAM resources such as banks, buses, and controllers to provide tight upper bounds on interference delays \[[https://www.semanticscholar.org/paper/afca4afaaaa543a1da02b266e9b2ac46eb94793b](https://www.semanticscholar.org/paper/afca4afaaaa543a1da02b266e9b2ac46eb94793b)\]. Techniques like memory bandwidth regulation have been proposed to throttle memory accesses and enforce predictable performance, with frameworks such as MemGuard providing efficient performance isolation by reserving memory bandwidth per core \[[https://www.semanticscholar.org/paper/bbebaeb1b00fdcde2aeb192543835d3ec1518f8d](https://www.semanticscholar.org/paper/bbebaeb1b00fdcde2aeb192543835d3ec1518f8d)\]. Recent advances also include per-bank bandwidth regulation of shared last-level caches (LLCs), allowing fine-grained control that prevents unnecessary throttling on uncontended cache banks and mitigates denial-of-service attacks targeting cache banks, thus improving overall throughput and predictability \[[2410.14003](http://arxiv.org/abs/2410.14003)\].

The challenge of co-optimizing cache partitioning and task scheduling has been addressed through multi-layer optimization frameworks. These frameworks explore the interplay between cache allocation and task schedulability, employing layered search and heuristic methods to improve schedulability under fixed-priority and EDF scheduling policies \[[2310.02959](http://arxiv.org/abs/2310.02959)\]. Such approaches systematically interleave cache partitioning strategies with task-to-core allocations, often leveraging dynamic programming or knapsack problem formulations to find efficient task-resource assignments. The benefits include significant improvements in schedulability, especially for cache-sensitive task sets, and better resource utilization.

In addition to cache management, memory bandwidth regulation has seen algorithmic advances that reduce pessimism in worst-case execution time (WCET) analysis. For instance, adapting stall analyses to multiframe task models reduces pessimism associated with memory contention and improves schedulability predictions by up to 85% compared to frame-agnostic approaches \[[https://www.semanticscholar.org/paper/e8d15aa827be70bebf15e217ac9295276ddebda7](https://www.semanticscholar.org/paper/e8d15aa827be70bebf15e217ac9295276ddebda7)\]. These analytical advancements allow for more accurate reasoning about task timing under dynamic memory bandwidth assignments.

Alternative memory technologies and controllers have also been explored to improve predictability. Studies show that DDR DRAMs inherently suffer from variable access latencies due to internal state dependencies and access patterns, leading to overly pessimistic worst-case latency bounds \[[1810.07059](http://arxiv.org/abs/1810.07059)\]. Emerging Reduced Latency DRAM (RLDRAM) combined with predictable memory controllers can significantly reduce timing variability and worst-case latency by factors of up to 11× and 6.4× respectively, making them promising candidates for real-time systems with stringent timing requirements \[[1810.07059](http://arxiv.org/abs/1810.07059)\].

Energy-efficient scheduling and heterogeneous multiprocessor task allocation also intersect with resource co-allocation problems. Optimization formulations that incorporate continuous and discrete speed scaling, combined with workload partitioning and task ordering, have demonstrated both feasibility and energy optimality in real-time scheduling contexts \[[1607.07763](http://arxiv.org/abs/1607.07763)\]. These methods complement memory and cache management by considering dynamic resource capabilities and energy constraints.

Profiling-driven frameworks provide practical tools for memory bandwidth management and system consolidation. For example, E-WarP offers a profile-based predictive model for analyzing memory demand and making runtime predictions under bandwidth regulation, achieving accurate runtime bounds while considering system saturation effects \[[https://www.semanticscholar.org/paper/f71c848137ac1398f84e6ab7d896641f801ca192](https://www.semanticscholar.org/paper/f71c848137ac1398f84e6ab7d896641f801ca192)\]. Such frameworks support workload-aware resource allocation, which aligns with multi-objective optimization goals for balancing schedulability and resource efficiency.

Security integration in real-time systems further complicates resource management. Approaches like Contego incorporate opportunistic execution and hierarchical scheduling to integrate security tasks without violating timing constraints, highlighting the need for flexible yet predictable resource scheduling frameworks \[[1705.00138](http://arxiv.org/abs/1705.00138)\].

Overall, the state-of-the-art in real-time systems emphasizes multi-resource co-allocation strategies that integrate cache partitioning, memory bandwidth regulation, task scheduling, and workload profiling. Multi-layer heuristics and optimization algorithms based on linear and integer programming, dynamic programming, and Pareto optimization have shown promising results in improving schedulability, resource utilization, and computational efficiency compared to earlier monolithic or single-resource approaches \[[2310.02959](http://arxiv.org/abs/2310.02959)\]\[[https://www.semanticscholar.org/paper/e8d15aa827be70bebf15e217ac9295276ddebda7](https://www.semanticscholar.org/paper/e8d15aa827be70bebf15e217ac9295276ddebda7)\]\[[https://www.semanticscholar.org/paper/bbebaeb1b00fdcde2aeb192543835d3ec1518f8d](https://www.semanticscholar.org/paper/bbebaeb1b00fdcde2aeb192543835d3ec1518f8d)\]. These advances provide a strong foundation for the proposed 0-1 linear program and multi-objective heuristic framework presented in this paper.
