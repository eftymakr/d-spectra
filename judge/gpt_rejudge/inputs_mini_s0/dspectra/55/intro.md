## Related Works

Conversational recommender systems (CRSs) have evolved as an effective paradigm to capture user preferences through multi-turn interactions, enabling personalized recommendations beyond static, one-shot approaches \[[2004.00646](http://arxiv.org/abs/2004.00646)\]. A core challenge in CRSs lies in accurately understanding complex and multifaceted user preferences from conversational signals, which often requires active user involvement. Prior methodologies have leveraged dialog-based preference elicitation strategies, reinforcement learning for policy optimization, and neural architectures to address this challenge.

Early works introduced frameworks where the system actively asks clarifying questions about item attributes to better infer user needs, exemplified by the System Ask–User Respond (SAUR) paradigm, which integrates multi-memory networks to order aspect-based questions and interleave personalized search with dialogue \[[https://www.semanticscholar.org/paper/3ae5bef6b0c8317603a2deab2527383580904fd8](https://www.semanticscholar.org/paper/3ae5bef6b0c8317603a2deab2527383580904fd8)\]. Similarly, frameworks like EAR (Estimation-Action-Reflection) formalize CRS interaction as a three-stage process—estimating user preferences, deciding actions (ask or recommend), and reflecting on user feedback to adapt the model—enabling more efficient conversations with fewer turns and higher recommendation accuracy \[[2002.09102](http://arxiv.org/abs/2002.09102)\]. Such models emphasize the interplay between attribute-level and item-level feedback to refine preference estimation.

Reinforcement learning (RL) has been widely adopted to unify the decision-making tasks in CRSs, such as selecting which attribute to inquire about, when to recommend, and how to balance exploration-exploitation trade-offs. Recent graph-based RL approaches represent conversation and recommendation components jointly, improving scalability, sample efficiency, and policy stability \[[2105.09710](http://arxiv.org/abs/2105.09710)\]. These methods benefit from dynamically pruning candidate actions using preference and entropy information, enhancing the learning process.

Another significant line of research focuses on explicit modeling and reasoning over user preferences through knowledge integration. Knowledge-enhanced prompt learning unifies recommendation and conversation subtasks under a single pre-trained language model, leveraging fused knowledge representations and task-specific prompts to improve both recommendation accuracy and response generation \[[2206.09363](http://arxiv.org/abs/2206.09363)\]. Knowledge graph-based semantic fusion further addresses the semantic gap between natural language dialogue and item-level preferences by aligning word-level and entity-level information, resulting in more context-aware recommendations and informative conversation responses \[[2007.04032](http://arxiv.org/abs/2007.04032)\]. Interactive path reasoning on graphs extends this by explicitly modeling user feedback as traversals in attribute-item graphs, pruning irrelevant attributes and providing more precise preference inference in multi-round dialogues \[[2007.00194](http://arxiv.org/abs/2007.00194)\].

The use of simulated users has emerged as an important approach to automate the evaluation and training of CRSs, mitigating the cost and complexity of human-in-the-loop experiments. User simulators can generate realistic responses that consider individual preferences and conversation flow, enabling the assessment of recommendation quality and conversational robustness \[[2006.08732](http://arxiv.org/abs/2006.08732)\]. Simulated feedback mechanisms have demonstrated substantial improvements in retrieval and ranking metrics when incorporated into conversational search and recommendation pipelines \[[2304.13874](http://arxiv.org/abs/2304.13874)\]. These simulators facilitate iterative multi-turn interactions, which are crucial for CRSs to refine user preference models.

More recent works have emphasized the fine-grained exploitation of user feedback by modeling the relationship between attribute-level critiques and item-level acceptance or rejection. Models such as Feedback-guided Preference Adaptation Network (FPAN) and Conversational Recommender with Implicit Feedback (CRIF) explicitly connect these feedback types to better infer implicit user preferences, enabling more accurate and adaptive recommendations during conversations \[[https://www.semanticscholar.org/paper/33e0fe2d4cf01b16da89ab0c180cdcbf37b3be17](https://www.semanticscholar.org/paper/33e0fe2d4cf01b16da89ab0c180cdcbf37b3be17)\]\[[https://www.semanticscholar.org/paper/0056038b89647afcee84226adf19feb1023a54c0](https://www.semanticscholar.org/paper/0056038b89647afcee84226adf19feb1023a54c0)\]. These approaches also employ inverse reinforcement learning or gating mechanisms to dynamically adjust user embeddings and decision policies based on observed feedback, thereby improving the interaction efficiency and recommendation relevance.

Variational reasoning and latent variable models have also been proposed to capture both short-term and long-term user preferences within conversations, employing topic tracking and multi-hop reasoning over heterogeneous knowledge graphs to achieve more robust preference understanding \[[https://www.semanticscholar.org/paper/49846c2d069c324d5d3f3b53cb74b13e84b7caeb](https://www.semanticscholar.org/paper/49846c2d069c324d5d3f3b53cb74b13e84b7caeb)\]. This helps address challenges arising from sparse feedback and complex semantic correlations among items.

Finally, foundational research on personalized conversational agents predates recent advances and highlights the importance of integrating long-term user models with conversational belief tracking to minimize user effort and improve recommendation satisfaction \[[1107.0029](http://arxiv.org/abs/1107.0029)\]\[[1806.03277](http://arxiv.org/abs/1806.03277)\]. These works demonstrate that adaptive conversational strategies, informed by historical user data and current dialogue context, significantly reduce the number of interactions required to reach satisfactory recommendations.

In summary, the landscape of CRS research encompasses diverse methodologies including multi-turn attribute-questioning, reinforcement learning, knowledge integration, user simulation, and advanced feedback modeling. The proposed GRSU framework builds upon these foundations by leveraging generative reward models to simulate user feedback in both coarse-grained item scoring and fine-grained attribute critique, unified via instruction tuning. This approach enables efficient, automatic multi-turn interaction with CRSs, drawing on prior insights from reward-guided search and user simulation to balance effectiveness and user effort \[[https://www.semanticscholar.org/paper/3ae5bef6b0c8317603a2deab2527383580904fd8](https://www.semanticscholar.org/paper/3ae5bef6b0c8317603a2deab2527383580904fd8)\]\[[2002.09102](http://arxiv.org/abs/2002.09102)\]\[[2105.09710](http://arxiv.org/abs/2105.09710)\]\[[2206.09363](http://arxiv.org/abs/2206.09363)\]\[[2304.13874](http://arxiv.org/abs/2304.13874)\]\[[2006.08732](http://arxiv.org/abs/2006.08732)\]\[[https://www.semanticscholar.org/paper/33e0fe2d4cf01b16da89ab0c180cdcbf37b3be17](https://www.semanticscholar.org/paper/33e0fe2d4cf01b16da89ab0c180cdcbf37b3be17)\]\[[https://www.semanticscholar.org/paper/0056038b89647afcee84226adf19feb1023a54c0](https://www.semanticscholar.org/paper/0056038b89647afcee84226adf19feb1023a54c0)\]\[[2007.00194](http://arxiv.org/abs/2007.00194)\].
