## Related Works

Natural language-driven table discovery aims to retrieve relevant tables from large repositories based on natural language queries, often relying on dense vector search pipelines that involve separate stages of representation, indexing, and retrieval. While these traditional pipelines have achieved notable accuracy, they suffer from error accumulation across stages and limited query-table interaction, which restricts semantic alignment and retrieval effectiveness \[[1802.06159](http://arxiv.org/abs/1802.06159)\]\[[2005.09207](http://arxiv.org/abs/2005.09207)\]. Recent efforts have sought to overcome these limitations by integrating query and table representations more tightly and improving semantic matching.

Early approaches to table retrieval emphasize semantic similarity between queries and tables by representing both in multiple semantic spaces, such as discrete sparse and continuous dense embeddings, and employing various similarity measures to improve matching quality \[[1802.06159](http://arxiv.org/abs/1802.06159)\]. The use of pretrained deep contextualized language models like BERT has further advanced table retrieval, enabling richer encoding of table content and query semantics while overcoming structural and input length challenges inherent in tabular data \[[2005.09207](http://arxiv.org/abs/2005.09207)\]. These models exploit deep bidirectional context representations, as introduced by BERT \[[1810.04805](http://arxiv.org/abs/1810.04805)\], to enhance natural language understanding in retrieval tasks. However, dense retrieval methods still operate within the conventional index-retrieve paradigm, which decouples indexing and retrieval and thus inherits error propagation issues.

Differentiable Search Indexes (DSIs) represent a paradigm shift by unifying indexing and retrieval into a single end-to-end trainable model. DSIs encode the entire corpus within the parameters of a sequence-to-sequence transformer that directly maps queries to document or table identifiers, eliminating separate indexing and retrieval components \[[2202.06991](http://arxiv.org/abs/2202.06991)\]. This approach allows deeper interaction between queries and the indexed content and avoids errors introduced at intermediate stages. Various works have explored enhancements to the DSI framework, including improved document identifier design, query generation for indexing, and continual learning strategies to handle dynamic corpora \[[2206.10128](http://arxiv.org/abs/2206.10128)\]\[[2307.10323](http://arxiv.org/abs/2307.10323)\]\[[2212.09744](http://arxiv.org/abs/2212.09744)\]\[[2305.15115](http://arxiv.org/abs/2305.15115)\]. Specifically, query generation techniques for indexing enable DSIs to better align the training data distribution with retrieval queries, mitigating mismatch issues \[[2206.10128](http://arxiv.org/abs/2206.10128)\]. Semantic-enhanced DSI variants incorporate elaborative document descriptors and fine-grained semantic rehearsal to strengthen memorization and retrieval quality \[[2305.15115](http://arxiv.org/abs/2305.15115)\].

Continual indexing remains a key challenge for DSIs since re-training on the full corpus to add new documents is computationally expensive and prone to catastrophic forgetting. Solutions such as IncDSI formulate incremental document addition as a constrained optimization problem to update model parameters efficiently without forgetting previously indexed content \[[2307.10323](http://arxiv.org/abs/2307.10323)\]. Similarly, DSI++ introduces generative replay and optimization for flatter minima to stabilize continual learning and substantially reduce forgetting \[[2212.09744](http://arxiv.org/abs/2212.09744)\]. These advances make DSIs more practical for real-world applications with evolving data.

In the broader retrieval landscape, autoregressive models have been employed to generate document identifiers as sequences, enabling retrieval via identifier generation with improved flexibility and efficiency \[[2204.10628](http://arxiv.org/abs/2204.10628)\]. Additionally, neural corpus indexers leverage sequence-to-sequence architectures with prefix-aware decoders and semantic document identifiers to further optimize recall and retrieval performance \[[2206.02743](http://arxiv.org/abs/2206.02743)\]. These methods share the goal of unifying indexing and retrieval in a single model to overcome the limitations of traditional pipelines.

In summary, natural language-driven table discovery traditionally relies on dense vector search with separate indexing and retrieval steps, which leads to accumulated errors and limited semantic alignment. The emergence of Differentiable Search Indexes offers a promising alternative by integrating indexing and retrieval into an end-to-end transformer model that directly maps queries to table identifiers, enabling deeper query-table interactions and reducing error propagation. Enhancements such as query generation for indexing, semantic document identifiers, and continual learning strategies address key challenges in this paradigm. Meanwhile, advances in neural autoregressive retrieval and semantic similarity modeling complement these efforts. These developments collectively inform the design of Birdie, which leverages a prefix-aware identifier scheme, large language model-based query generation, and parameter-isolation-based continual learning to improve accuracy and mitigate forgetting in table retrieval.
