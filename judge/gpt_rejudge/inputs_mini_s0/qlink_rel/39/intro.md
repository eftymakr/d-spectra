## Related Works

De novo genome assembly reconstructs genomes from sequencing reads without relying on a reference, a process critical for studying unknown organisms and advancing personalized medicine. This task is computationally intensive due to the massive data volumes and complex data structures involved \[[https://www.semanticscholar.org/paper/7279acd9c61a8de019ea2d55d23124dfbb6b5269](https://www.semanticscholar.org/paper/7279acd9c61a8de019ea2d55d23124dfbb6b5269)\]\[[https://www.semanticscholar.org/paper/d206ac8572f7480e5d1e92620060a39a8c3fd3ce](https://www.semanticscholar.org/paper/d206ac8572f7480e5d1e92620060a39a8c3fd3ce)\]. Early assemblers primarily employed two algorithmic paradigms: overlap-layout-consensus (OLC) and de Bruijn graph-based methods. OLC assemblers perform well with longer reads and smaller genomes, while de Bruijn graph assemblers are better suited for handling large datasets of short reads typical of next-generation sequencing platforms \[[https://www.semanticscholar.org/paper/7279acd9c61a8de019ea2d55d23124dfbb6b5269](https://www.semanticscholar.org/paper/7279acd9c61a8de019ea2d55d23124dfbb6b5269)\]\[[https://www.semanticscholar.org/paper/d206ac8572f7480e5d1e92620060a39a8c3fd3ce](https://www.semanticscholar.org/paper/d206ac8572f7480e5d1e92620060a39a8c3fd3ce)\].

Short-read assemblers such as SSAKE, SHARCGS, and Velvet exploit de Bruijn graphs or string-based methods to handle the high coverage but short read lengths from Illumina and similar platforms \[[https://www.semanticscholar.org/paper/fbd59e17f72c3aedb3cd06af2e50a91526ccd81a](https://www.semanticscholar.org/paper/fbd59e17f72c3aedb3cd06af2e50a91526ccd81a)\]\[[https://www.semanticscholar.org/paper/dbb41f80dc43d139761a863eb7d6da773a726261](https://www.semanticscholar.org/paper/dbb41f80dc43d139761a863eb7d6da773a726261)\]\[[https://www.semanticscholar.org/paper/7bf2f1c55f90e11a4d1df4dd608ac621a08f8b33](https://www.semanticscholar.org/paper/7bf2f1c55f90e11a4d1df4dd608ac621a08f8b33)\]. However, these methods often require substantial memory and computational resources, limiting scalability for large genomes. Distributed-memory parallel assemblers like ABySS, Ray, and HipMer have been developed to address scalability by distributing data and computation across clusters, enabling assembly of large genomes including human-scale datasets \[[https://www.semanticscholar.org/paper/fe8d86bc5520b5049104ff58ee7e980982816ebf](https://www.semanticscholar.org/paper/fe8d86bc5520b5049104ff58ee7e980982816ebf)\]\[[https://www.semanticscholar.org/paper/3db83bc91d0aa801301a9c063bbfd9d4202f89f2](https://www.semanticscholar.org/paper/3db83bc91d0aa801301a9c063bbfd9d4202f89f2)\]\[[https://www.semanticscholar.org/paper/38410204a2977a9484e6d1205697b4103b5482f7](https://www.semanticscholar.org/paper/38410204a2977a9484e6d1205697b4103b5482f7)\]. While effective, these approaches still contend with large memory footprints and irregular data access patterns, which challenge efficient parallelism and resource utilization \[[1512.01801](http://arxiv.org/abs/1512.01801)\].

Long-read sequencing technologies (e.g., PacBio, Oxford Nanopore) have revolutionized assembly by producing reads exceeding 10 kb, simplifying repeat resolution and improving contiguity. Nevertheless, high error rates (~10–15%) complicate assembly, necessitating specialized algorithms and error correction strategies \[[https://www.semanticscholar.org/paper/2b59fd18ada769ef76fb7fcc7382f063791abfab](https://www.semanticscholar.org/paper/2b59fd18ada769ef76fb7fcc7382f063791abfab)\]\[[1512.01801](http://arxiv.org/abs/1512.01801)\]\[[https://www.semanticscholar.org/paper/618d82a202bb0408e388eba250c66c8a90700c81](https://www.semanticscholar.org/paper/618d82a202bb0408e388eba250c66c8a90700c81)\]. Assemblers like Canu and Flye leverage adaptive k-mer weighting and repeat graph models to improve accuracy and contiguity in long-read assembly, while maintaining manageable runtime and memory usage \[[https://www.semanticscholar.org/paper/2b59fd18ada769ef76fb7fcc7382f063791abfab](https://www.semanticscholar.org/paper/2b59fd18ada769ef76fb7fcc7382f063791abfab)\]\[[https://www.semanticscholar.org/paper/e0f860a608ecfb4ac6d0010e16db5c13cca14da1](https://www.semanticscholar.org/paper/e0f860a608ecfb4ac6d0010e16db5c13cca14da1)\]. Minimap and miniasm provide fast mapping and assembly pipelines that bypass error correction, achieving rapid bacterial and eukaryotic assemblies with trade-offs in consensus accuracy \[[1512.01801](http://arxiv.org/abs/1512.01801)\]. Shasta further demonstrates efficient human genome assembly using nanopore data with hardware-conscious optimizations and polishing steps that yield high accuracy in significantly reduced wall-clock times \[[https://www.semanticscholar.org/paper/f9d407ce133ec096ab4321e6d98e8f0081f5bdcc](https://www.semanticscholar.org/paper/f9d407ce133ec096ab4321e6d98e8f0081f5bdcc)\].

The computational complexity and memory demands of de novo assembly have motivated the use of compressed data structures and succinct graph representations. These approaches reduce memory footprints by encoding de Bruijn graphs more compactly, enabling assembly on commodity hardware while maintaining quality \[[1008.2555](http://arxiv.org/abs/1008.2555)\]. Parallel algorithms employing sparse matrix operations have been introduced for overlap detection and layout simplification, improving scalability and runtime efficiency. For instance, diBELLA 2D applies distributed sparse matrix algebra to accelerate overlap graph construction and transitive reduction, achieving near-linear scaling with high parallel efficiency on human genome datasets \[[2010.10055](http://arxiv.org/abs/2010.10055)\].

Hardware acceleration and co-designed architectures have been explored to alleviate bottlenecks inherent in assembly workflows. SWAP-Assembler demonstrates scalability to thousands of cores using asynchronous parallel models to reduce runtime drastically while producing high-quality contigs \[[https://www.semanticscholar.org/paper/fe8d86bc5520b5049104ff58ee7e980982816ebf](https://www.semanticscholar.org/paper/fe8d86bc5520b5049104ff58ee7e980982816ebf)\]. GPU acceleration has also been employed to speed up specific assembly steps, but is often limited by data transfer overhead and bandwidth constraints \[[https://www.semanticscholar.org/paper/f27decfab0389e2003e7ca66260b34eb3c1b8827](https://www.semanticscholar.org/paper/f27decfab0389e2003e7ca66260b34eb3c1b8827)\]. Despite these advances, existing hardware approaches rarely address the irregular memory-bound behavior and complex, dynamic data dependencies intrinsic to assembly tasks comprehensively.

The challenge of handling irregular data patterns and large, interdependent data structures motivates recent efforts in near-memory processing (NMP) architectures. By situating computation close to memory, NMP reduces costly data movement and provides scratchpad memory tailored for dynamic data structures. This enables customized processing elements to exploit parallelism more effectively and manage memory-bound computations more efficiently, addressing underutilization issues caused by irregular data access patterns \[[https://www.semanticscholar.org/paper/f9d407ce133ec096ab4321e6d98e8f0081f5bdcc](https://www.semanticscholar.org/paper/f9d407ce133ec096ab4321e6d98e8f0081f5bdcc)\]\[[2010.10055](http://arxiv.org/abs/2010.10055)\].

Overall, while distributed algorithms, long-read assemblers, compressed data structures, and hardware acceleration have significantly advanced de novo assembly scalability and performance, substantial challenges remain. These include reducing memory footprints, improving resource efficiency, and managing irregular and dynamic data dependencies. Solutions like NMP-PaK that integrate hardware-software co-design and near-memory processing are promising directions to overcome these limitations and enable faster, more memory-efficient large-scale genome assembly \[[https://www.semanticscholar.org/paper/fe8d86bc5520b5049104ff58ee7e980982816ebf](https://www.semanticscholar.org/paper/fe8d86bc5520b5049104ff58ee7e980982816ebf)\]\[[https://www.semanticscholar.org/paper/f9d407ce133ec096ab4321e6d98e8f0081f5bdcc](https://www.semanticscholar.org/paper/f9d407ce133ec096ab4321e6d98e8f0081f5bdcc)\]\[[2010.10055](http://arxiv.org/abs/2010.10055)\].
