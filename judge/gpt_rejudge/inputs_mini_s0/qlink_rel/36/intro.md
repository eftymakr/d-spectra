## Related Works

Deploying large language models (LLMs) on edge devices presents significant challenges due to limited storage, compute capacity, and power constraints. To address these, research has focused on model compression, quantization, hardware acceleration, and algorithm-hardware co-design techniques.

### Model Compression and Quantization

Model compression through pruning and quantization is a fundamental approach to reducing LLM size and inference latency. Wanda introduces a pruning method that leverages weight magnitudes scaled by activation values to induce sparsity without retraining, enabling efficient pruning of large models like LLaMA and LLaMA-2 while maintaining accuracy \[[2306.11695](http://arxiv.org/abs/2306.11695)\]. Quantization techniques such as Activation-aware Weight Quantization (AWQ) improve on-device deployment by identifying salient weights based on activation distributions, achieving up to 4x model size reduction and 3-4x acceleration on edge devices without significant performance degradation \[[2306.00978](http://arxiv.org/abs/2306.00978)\]. SmoothQuant enables post-training 8-bit weight and activation quantization by migrating quantization difficulty from activations to weights, offering up to 2x memory reduction and 1.56x speedup for various LLMs without retraining \[[2211.10438](http://arxiv.org/abs/2211.10438)\]. Together, these approaches demonstrate that combining pruning and quantization is effective for edge deployment.

### Efficient Attention Mechanisms

Self-attention layers dominate LLM compute and memory costs, especially for long sequences. FlashAttention and its successor FlashAttention-2 optimize exact attention by IO-aware tiling and improved GPU work partitioning, achieving 2-4× speedups over baselines without approximation, and attaining near-peak GPU efficiency \[[2205.14135](http://arxiv.org/abs/2205.14135)\]\[[2307.08691](http://arxiv.org/abs/2307.08691)\]. These methods enable longer context windows that are critical for many LLM applications. Complementing these, SpAtten leverages token and head sparsity with cascade pruning and progressive quantization to reduce DRAM accesses by 10× and achieve orders of magnitude speedup and energy reductions, specifically targeting attention layers \[[2012.09852](http://arxiv.org/abs/2012.09852)\]. StreamingLLM introduces the concept of attention sinks to maintain performance when caching key-value pairs for long contexts, enabling efficient streaming inference for LLMs beyond their training context length \[[2309.17453](http://arxiv.org/abs/2309.17453)\]. These advances highlight the importance of optimizing attention computation and memory usage for edge scenarios.

### Hardware-Software Co-Design and FPGA Acceleration

FPGAs offer a promising platform for LLM acceleration on edge devices due to their reconfigurability and energy efficiency. FTRANS compresses large NLP models using block-circulant matrices combined with architecture-level acceleration, achieving up to 16× model size reduction and significant energy efficiency gains compared to CPUs and GPUs \[[2007.08563](http://arxiv.org/abs/2007.08563)\]. NPE presents an FPGA overlay processor designed for transformer-based NLP workloads, providing real-time conversational latency with substantially lower power consumption than CPUs and GPUs, and efficient resource utilization without requiring frequent reconfiguration \[[2104.06535](http://arxiv.org/abs/2104.06535)\]. SECDA proposes a hardware/software co-design methodology to reduce development overhead for FPGA-based DNN accelerators, demonstrating up to 3.5× speedup and 2.9× energy reduction on edge FPGA platforms \[[2110.00478](http://arxiv.org/abs/2110.00478)\]. Building on this, SECDA-LLM extends these principles to LLM inference by integrating block floating point quantized matrix multiplication accelerators, achieving over 11× latency reduction on a tiny LLM model on an edge FPGA board \[[2408.00462](http://arxiv.org/abs/2408.00462)\]. These works illustrate the critical role of co-design in tailoring both software algorithms and hardware architectures for edge LLM acceleration.

### Algorithmic Acceleration and Approximate Computing

Algorithmic innovations that reduce inference latency without compromising output quality are crucial for practical edge deployment. Speculative decoding and sampling techniques enable parallel generation of multiple tokens per transformer invocation, effectively accelerating decoding by 2-3× without model modifications \[[2211.17192](http://arxiv.org/abs/2211.17192)\]\[[2302.01318](http://arxiv.org/abs/2302.01318)\]. LLMA exploits token overlap between generated outputs and reference texts to achieve over 2× speedup via lossless acceleration in generation tasks \[[2304.04487](http://arxiv.org/abs/2304.04487)\]. DejaVu leverages contextual sparsity by dynamically pruning input-dependent attention heads and MLP parameters on the fly, yielding over 2× latency reduction on large models like OPT-175B without hurting model quality or in-context learning \[[2310.17157](http://arxiv.org/abs/2310.17157)\]. These methods demonstrate that combining model-aware approximations with hardware-aware implementations can yield significant real-time improvements.

### Memory Management and Data Movement Optimization

Efficient memory management is a key bottleneck in deploying LLMs on limited-resource devices. PagedAttention adopts a virtual memory-inspired paging mechanism for KV cache management, enabling near-zero memory waste and flexible sharing across requests, which improves throughput by 2-4× compared to state-of-the-art systems \[[2309.06180](http://arxiv.org/abs/2309.06180)\]. LLM in a Flash tackles the problem of limited DRAM by storing model parameters in flash memory and optimizing data transfer through windowing and row-column bundling strategies, allowing models up to twice the DRAM size to run efficiently with 4-5× speedup over naive approaches \[[2312.11514](http://arxiv.org/abs/2312.11514)\]. These hardware-informed memory management strategies are essential for scaling LLMs on edge hardware with constrained memory bandwidth and capacity.

### Summary

The deployment of LLMs on edge devices requires a multifaceted approach integrating model compression, efficient attention mechanisms, algorithmic acceleration, memory optimization, and hardware-software co-design. Advances in pruning and quantization reduce model size and computation \[[2306.00978](http://arxiv.org/abs/2306.00978)\]\[[2211.10438](http://arxiv.org/abs/2211.10438)\]\[[2306.11695](http://arxiv.org/abs/2306.11695)\], while specialized attention algorithms and streaming techniques lower memory and latency costs \[[2205.14135](http://arxiv.org/abs/2205.14135)\]\[[2307.08691](http://arxiv.org/abs/2307.08691)\]\[[2309.17453](http://arxiv.org/abs/2309.17453)\]\[[2012.09852](http://arxiv.org/abs/2012.09852)\]. FPGA-based co-design methodologies enable energy-efficient and high-throughput inference tailored for edge constraints \[[2007.08563](http://arxiv.org/abs/2007.08563)\]\[[2104.06535](http://arxiv.org/abs/2104.06535)\]\[[2110.00478](http://arxiv.org/abs/2110.00478)\]\[[2408.00462](http://arxiv.org/abs/2408.00462)\]. Algorithm-level innovations like speculative decoding and contextual sparsity further accelerate inference without loss of quality \[[2211.17192](http://arxiv.org/abs/2211.17192)\]\[[2310.17157](http://arxiv.org/abs/2310.17157)\]\[[2304.04487](http://arxiv.org/abs/2304.04487)\]\[[2302.01318](http://arxiv.org/abs/2302.01318)\]. Memory management techniques inspired by OS principles and hardware characteristics unlock efficient LLM scaling on limited-resource devices \[[2309.06180](http://arxiv.org/abs/2309.06180)\]\[[2312.11514](http://arxiv.org/abs/2312.11514)\]. Together, these lines of work provide a comprehensive foundation for the design of systems like CLONE that balance latency, energy, and accuracy in edge LLM deployment.
