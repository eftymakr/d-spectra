## Related Works

Natural language-driven table discovery aims to retrieve relevant tables from large repositories using natural language queries, a task that has gained attention due to the increasing availability of structured tabular data on the web. Traditional retrieval systems primarily rely on dense vector search pipelines that separate the processes of table representation, indexing, and search. These conventional methods, while effective, suffer from error accumulation across the representation and indexing stages, which negatively impacts retrieval accuracy. Additionally, they often lack deep interaction between queries and tables, limiting semantic alignment and further constraining performance improvements \[[1802.06159](http://arxiv.org/abs/1802.06159)\]\[[2206.10128](http://arxiv.org/abs/2206.10128)\].

Earlier approaches to table retrieval and query understanding involve structured search engines that match keyword queries to web tables by modeling column-level correspondences and exploiting content overlap across tables \[[1207.0132](http://arxiv.org/abs/1207.0132)\]. However, these methods rely heavily on heuristic or sparse representations and are less effective at capturing semantic nuances compared to deep learning models. Recent advances incorporate deep neural models to improve representation and retrieval, such as methods that perform semantic matching between queries and tables using multiple vector spaces and supervised learning to enhance ranking quality \[[1802.06159](http://arxiv.org/abs/1802.06159)\].

The rise of large pre-trained language models (LLMs) and transformer architectures has significantly influenced information retrieval and table discovery. Models like BERT have been adapted for document and passage ranking, demonstrating strong performance by encoding queries and documents independently and computing fine-grained interactions to balance effectiveness and efficiency \[[2004.12832](http://arxiv.org/abs/2004.12832)\]\[[1910.14424](http://arxiv.org/abs/1910.14424)\]\[[1810.04805](http://arxiv.org/abs/1810.04805)\]. Dense passage retrieval frameworks using dual-encoder architectures further improve retrieval accuracy by learning dense embeddings for queries and passages, outperforming traditional sparse methods like BM25 \[[2004.04906](http://arxiv.org/abs/2004.04906)\]. 

Differentiable Search Index (DSI) models represent a paradigm shift by unifying indexing and retrieval into a single end-to-end trainable transformer model that directly maps queries to document or table identifiers encoded in the model’s parameters. This approach eliminates the need for explicit indexing structures, reducing error propagation between indexing and retrieval and enabling deep query-document interaction within the model itself \[[2202.06991](http://arxiv.org/abs/2202.06991)\]\[[2206.10128](http://arxiv.org/abs/2206.10128)\]. Enhancements to DSI include query generation strategies that create synthetic queries for documents, improving the model’s ability to associate queries with identifiers and mitigating distribution mismatches between indexing and retrieval \[[2206.10128](http://arxiv.org/abs/2206.10128)\]\[[2305.15115](http://arxiv.org/abs/2305.15115)\]. Furthermore, continual learning methods such as DSI++ address the challenge of updating the model with new documents without retraining from scratch, employing techniques like parameter isolation and generative memory to reduce catastrophic forgetting and maintain retrieval performance over time \[[2212.09744](http://arxiv.org/abs/2212.09744)\].

Parallel to DSI, neural corpus indexers (NCI) employ sequence-to-sequence models to generate document identifiers directly for queries, incorporating prefix-aware decoders and semantic document identifiers to optimize recall and retrieval accuracy \[[2206.02743](http://arxiv.org/abs/2206.02743)\]. Autoregressive search engines further explore generating substrings or n-grams as document identifiers to improve passage-level retrieval efficiency and accuracy, achieving state-of-the-art results on benchmarks while maintaining a lightweight memory footprint \[[2204.10628](http://arxiv.org/abs/2204.10628)\]. Pre-trained generative retrieval models like CorpusBrain extend these ideas by encoding the corpus into model parameters and pre-training on large-scale tasks to support knowledge-intensive language applications with strong zero-shot and low-resource performance \[[2208.07652](http://arxiv.org/abs/2208.07652)\].

In the specific domain of table retrieval, semantic query generation and query reformulation techniques have been explored to improve alignment between user queries and table content. Methods inspired by cognitive psychology, such as elaboration and rehearsal strategies, have been used to enhance document memorization and identifier assignment in semantic-enhanced DSI models, leading to improved retrieval outcomes \[[2305.15115](http://arxiv.org/abs/2305.15115)\]. Early work on natural language interfaces to databases also emphasized semantic alignment and query reformulation to facilitate effective table discovery \[[2004.04906](http://arxiv.org/abs/2004.04906)\].

Despite these advances, challenges remain in mitigating error accumulation, enabling richer query-table interactions, and supporting dynamic indexing in evolving table repositories. The Birdie framework builds upon these foundations by integrating prefix-aware identifiers and LLM-based synthetic query generation into a unified encoder-decoder model for table retrieval. It further introduces a continual indexing strategy via parameter isolation to address catastrophic forgetting, positioning itself within the growing trend of end-to-end differentiable retrieval models that unify indexing and search to overcome the limitations of traditional dense retrieval pipelines \[[2206.10128](http://arxiv.org/abs/2206.10128)\]\[[2202.06991](http://arxiv.org/abs/2202.06991)\]\[[2212.09744](http://arxiv.org/abs/2212.09744)\]\[[2206.02743](http://arxiv.org/abs/2206.02743)\]\[[2305.15115](http://arxiv.org/abs/2305.15115)\].
