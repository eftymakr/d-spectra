## Related Works

Memory bandwidth regulation and cache partitioning have been extensively studied as fundamental techniques to achieve predictable timing behavior in multi-core real-time systems. These methods are crucial to mitigate the interference caused by shared hardware resources such as caches, DRAM banks, and memory controllers, which directly impact task execution times and overall system schedulability \[[1809.05921](http://arxiv.org/abs/1809.05921)\]\[[https://www.semanticscholar.org/paper/afca4afaaaa543a1da02b266e9b2ac46eb94793b](https://www.semanticscholar.org/paper/afca4afaaaa543a1da02b266e9b2ac46eb94793b)\]. 

A significant body of work focuses on dynamic memory bandwidth allocation to manage contention in multi-core embedded systems. For example, the analysis of dynamic memory bandwidth regulation models worst-case response times by formulating the problem as a maximization over memory request assignments to time intervals with varying bandwidth allocations. This approach enables improved schedulability in Integrated Modular Avionics (IMA) systems under memory-intensive workloads \[[https://www.semanticscholar.org/paper/afca4afaaaa543a1da02b266e9b2ac46eb94793b](https://www.semanticscholar.org/paper/afca4afaaaa543a1da02b266e9b2ac46eb94793b)\]. Complementary to this, MemGuard provides a practical memory bandwidth reservation system that enforces isolation by throttling bandwidth usage per core, enhancing predictability in multi-core platforms \[[https://www.semanticscholar.org/paper/0b1bc294dbd926f853a8ee41d1d8f8ecc3cfde13](https://www.semanticscholar.org/paper/0b1bc294dbd926f853a8ee41d1d8f8ecc3cfde13)\].

Cache partitioning techniques, including cache coloring and utility-based partitioning, are employed to reduce inter-task cache interference. Utility-Based Cache Partitioning dynamically adapts cache allocations at runtime to optimize performance isolation with low overhead \[[https://www.semanticscholar.org/paper/333da42f4369dff8ca905ad21ea6ee2f5dc99d55](https://www.semanticscholar.org/paper/333da42f4369dff8ca905ad21ea6ee2f5dc99d55)\]. Cache-coloring schemes are also leveraged to reduce cache interference by assigning distinct "colors" (cache sets) to different tasks, mitigating conflicts and improving timing predictability \[[https://www.semanticscholar.org/paper/dbd4eb5033815003e7f6519fd66e43e5fc297075](https://www.semanticscholar.org/paper/dbd4eb5033815003e7f6519fd66e43e5fc297075)\]. The Cache Bleaching approach extends this concept by introducing programmable logic between the processor and memory, enabling manipulation of memory transactions to re-compact sparse cache colors in main memory, thus addressing limitations of traditional coloring methods \[[https://www.semanticscholar.org/paper/dbd4eb5033815003e7f6519fd66e43e5fc297075](https://www.semanticscholar.org/paper/dbd4eb5033815003e7f6519fd66e43e5fc297075)\].

Several works explicitly address the challenge of co-allocating tasks and resources (cache and memory bandwidth) to cores in a manner that guarantees schedulability. The theoretical framework for such co-allocation often involves formulating optimization problems, such as mixed-integer linear programs (MILP), that consider both task execution demands and resource constraints \[[https://www.semanticscholar.org/paper/afca4afaaaa543a1da02b266e9b2ac46eb94793b](https://www.semanticscholar.org/paper/afca4afaaaa543a1da02b266e9b2ac46eb94793b)\]. These formulations can be computationally expensive; hence, heuristic or multi-layer optimization approaches are proposed. For instance, a multi-layer framework that combines Pareto-pruned search for resource allocation with dynamic programming solutions to knapsack problems for task assignment has shown promising improvements in computational efficiency and solution quality \[[https://www.semanticscholar.org/paper/afca4afaaaa543a1da02b266e9b2ac46eb94793b](https://www.semanticscholar.org/paper/afca4afaaaa543a1da02b266e9b2ac46eb94793b)\].

Bounding worst-case memory interference is a critical aspect of ensuring timing predictability. Techniques modeling DRAM components (banks, buses, controllers) provide upper bounds on interference delays caused by concurrent tasks in commercial-off-the-shelf (COTS) systems, which are often subject to unpredictable reordering of memory requests. Partitioning DRAM banks reduces interference by isolating memory accesses, thus improving real-time performance guarantees \[[https://www.semanticscholar.org/paper/afca4afaaaa543a1da02b266e9b2ac46eb94793b](https://www.semanticscholar.org/paper/afca4afaaaa543a1da02b266e9b2ac46eb94793b)\].

In addition to pure software-based approaches, hardware-assisted methods have been investigated. PLIM (Programmable Logic In-the-Middle) introduces reconfigurable logic between the processor and main memory, which facilitates fine-grained control over memory transactions. This approach not only enhances predictable memory behavior but also enables innovative cache management techniques like Cache Bleaching, offering new directions for mitigating resource interference in real-time systems \[[https://www.semanticscholar.org/paper/dbd4eb5033815003e7f6519fd66e43e5fc297075](https://www.semanticscholar.org/paper/dbd4eb5033815003e7f6519fd66e43e5fc297075)\].

Furthermore, resource management strategies integrating memory bandwidth regulation and cache partitioning with task scheduling policies—particularly preemptive Earliest Deadline First (EDF)—have been explored to enhance schedulability. These integrated approaches emphasize the importance of co-designing resource allocation and scheduling to meet real-time constraints effectively \[[https://www.semanticscholar.org/paper/afca4afaaaa543a1da02b266e9b2ac46eb94793b](https://www.semanticscholar.org/paper/afca4afaaaa543a1da02b266e9b2ac46eb94793b)\]\[[https://www.semanticscholar.org/paper/0b1bc294dbd926f853a8ee41d1d8f8ecc3cfde13](https://www.semanticscholar.org/paper/0b1bc294dbd926f853a8ee41d1d8f8ecc3cfde13)\].

In summary, the state-of-the-art in predictable multi-core real-time systems involves a combination of theoretical worst-case analysis, optimization-based co-allocation frameworks, runtime adaptive partitioning mechanisms, and emerging hardware-assisted solutions. These collectively address the challenges of interference in shared memory hierarchies and aim to provide tight guarantees on task timing behavior while maintaining resource efficiency.
