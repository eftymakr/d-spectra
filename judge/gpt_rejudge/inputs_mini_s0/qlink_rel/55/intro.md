## Related Works

Conversational recommender systems (CRSs) have gained significant attention as they enable multi-turn interactions to dynamically capture user preferences and provide personalized recommendations \[[2002.09102](http://arxiv.org/abs/2002.09102)\]. Unlike traditional recommender systems that rely on static models and one-shot interactions, CRSs leverage dialogue to resolve ambiguities in user intent and better understand preferences through explicit user feedback \[[2002.09102](http://arxiv.org/abs/2002.09102)\]\[[2004.00646](http://arxiv.org/abs/2004.00646)\]. This interactive paradigm addresses two critical questions: what users like and why they like certain items, which static models struggle to answer effectively \[[2101.09459](http://arxiv.org/abs/2101.09459)\].

A core challenge in CRSs lies in designing effective interaction strategies, including deciding what questions to ask, when to recommend, and how to update user preference models based on feedback \[[2002.09102](http://arxiv.org/abs/2002.09102)\]\[[2105.09710](http://arxiv.org/abs/2105.09710)\]. Early approaches often used rule-based or heuristic policies, while recent advances apply reinforcement learning (RL) to jointly optimize these decisions, improving scalability and adaptability \[[2105.09710](http://arxiv.org/abs/2105.09710)\]\[[1806.03277](http://arxiv.org/abs/1806.03277)\]. RL-based methods dynamically balance exploration and exploitation by learning optimal policies to ask about item attributes or recommend items, guided by user responses \[[2105.09710](http://arxiv.org/abs/2105.09710)\].

Another prominent direction is modeling user preferences more precisely through multi-round interactions. Frameworks like EAR (Estimation-Action-Reflection) integrate preference estimation, action selection, and feedback-based model updates to enhance recommendation accuracy and reduce conversation length \[[2002.09102](http://arxiv.org/abs/2002.09102)\]\[[https://www.semanticscholar.org/paper/33e0fe2d4cf01b16da89ab0c180cdcbf37b3be17](https://www.semanticscholar.org/paper/33e0fe2d4cf01b16da89ab0c180cdcbf37b3be17)\]. Extensions incorporate relations between item-level and attribute-level feedback to refine user embeddings and adapt recommendations more effectively \[[https://www.semanticscholar.org/paper/33e0fe2d4cf01b16da89ab0c180cdcbf37b3be17](https://www.semanticscholar.org/paper/33e0fe2d4cf01b16da89ab0c180cdcbf37b3be17)\]. Multi-interest models further acknowledge that users may have diverse, overlapping preferences across attribute combinations, leading to frameworks that generate multiple-choice questions and union-based candidate selection to avoid over-filtering \[[2112.11775](http://arxiv.org/abs/2112.11775)\].

User simulation plays a vital role in developing and evaluating CRSs by enabling automated testing of dialogue policies without costly human studies \[[2006.08732](http://arxiv.org/abs/2006.08732)\]. Simulated users model realistic user behaviors and preferences, facilitating efficient training and benchmarking of CRS components. Recent work improves simulation fidelity by combining preference modeling and task-specific interaction models, achieving high correlation with human evaluations \[[2006.08732](http://arxiv.org/abs/2006.08732)\]. Simulated users also enable systems to learn intrinsic rewards from user feedback, reducing the need for explicit user involvement \[[2007.04032](http://arxiv.org/abs/2007.04032)\].

Incorporating external knowledge, especially knowledge graphs (KGs), has been explored to bridge the semantic gap between natural language expressions and item attributes, enriching user preference representations and enabling more informative question generation \[[2007.04032](http://arxiv.org/abs/2007.04032)\]\[[2105.04774](http://arxiv.org/abs/2105.04774)\]. KG-enhanced dialogue components can generate entity-aware clarifying questions, improving the efficiency of preference elicitation and recommendation quality \[[2007.04032](http://arxiv.org/abs/2007.04032)\]\[[2105.04774](http://arxiv.org/abs/2105.04774)\].

Conversational recommendation policies have also been unified using graph-based RL methods, which integrate conversation and recommendation components into a single framework. This approach allows dynamic action selection—asking attributes or recommending items—while addressing sample efficiency via candidate action pruning strategies \[[2105.09710](http://arxiv.org/abs/2105.09710)\]. Graph-structured reasoning further enhances attribute exploration by explicitly traversing attribute vertices based on user feedback, pruning irrelevant candidates and improving hit rates in multi-round scenarios \[[2007.00194](http://arxiv.org/abs/2007.00194)\].

Question generation strategies are critical for reducing user burden while maintaining recommendation effectiveness. Some works propose algorithms to select optimal questions based on user responses and item features, employing generalized binary search or topic-guided dialogs to guide conversations toward relevant recommendations efficiently \[[2005.14255](http://arxiv.org/abs/2005.14255)\]\[[2010.04125](http://arxiv.org/abs/2010.04125)\]\[[2105.04774](http://arxiv.org/abs/2105.04774)\]. Others advocate for multiple-choice question formats to capture multi-faceted user interests more naturally and avoid over-filtering items during dialogue \[[2112.11775](http://arxiv.org/abs/2112.11775)\].

Finally, advances in natural language processing and large language models (LLMs) have been leveraged to enhance conversational search and recommendation, enabling systems to ask semantically coherent, aspect-based questions and generate personalized recommendations with fewer conversational turns \[[https://www.semanticscholar.org/paper/3ae5bef6b0c8317603a2deab2527383580904fd8](https://www.semanticscholar.org/paper/3ae5bef6b0c8317603a2deab2527383580904fd8)\]. These methods show promise in balancing user experience and recommendation accuracy, though challenges remain in user involvement reduction and transferability across domains.

In summary, prior work has extensively explored user preference elicitation, dialogue policy learning, user simulation, knowledge integration, and question generation in CRSs. However, most approaches either rely heavily on frequent user input or lack efficient mechanisms to integrate multi-granular feedback seamlessly. The proposed generative reward model based simulated user (GRSU) advances this field by unifying coarse-grained item scoring and fine-grained attribute critiques into an instruction-based feedback format, enabling automatic, efficient multi-turn interaction with CRSs inspired by reward-guided search and beam search techniques. This approach builds on and extends prior efforts in user simulation, RL-based policy learning, and knowledge-enhanced question generation to address the trade-off between interaction effectiveness and user experience \[[2002.09102](http://arxiv.org/abs/2002.09102)\]\[[2004.00646](http://arxiv.org/abs/2004.00646)\]\[[2006.08732](http://arxiv.org/abs/2006.08732)\]\[[2007.04032](http://arxiv.org/abs/2007.04032)\]\[[2105.09710](http://arxiv.org/abs/2105.09710)\]\[[https://www.semanticscholar.org/paper/33e0fe2d4cf01b16da89ab0c180cdcbf37b3be17](https://www.semanticscholar.org/paper/33e0fe2d4cf01b16da89ab0c180cdcbf37b3be17)\]\[[2112.11775](http://arxiv.org/abs/2112.11775)\]\[[2105.04774](http://arxiv.org/abs/2105.04774)\].
