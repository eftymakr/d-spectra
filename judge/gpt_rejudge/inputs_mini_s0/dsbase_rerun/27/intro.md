## Related Works

Natural language-driven table discovery has gained significant attention as a critical task in information retrieval, aiming to identify relevant tables from large repositories using natural language (NL) queries. Traditional approaches predominantly rely on dense vector search pipelines that separate table representation, indexing, and search stages. While effective, these pipelines suffer from error accumulation during representation learning and indexing phases, which adversely impacts retrieval accuracy. Additionally, limited interaction between queries and tables at the representation level restricts semantic alignment and further performance gains \[[2305.02073v2](http://arxiv.org/abs/2305.02073v2)\].

Differentiable Search Indexing (DSI) is a recent paradigm that reconceptualizes the indexing and retrieval process as a single neural network model, typically based on transformer architectures. By learning a direct mapping from queries to document (or table) identifiers, DSI eliminates the need for explicit indexing structures and enables end-to-end optimization. However, vanilla DSI models have been shown to struggle with relevance ordering and distinguishing relevant documents from irrelevant ones, limiting their retrieval effectiveness \[[2305.02073v2](http://arxiv.org/abs/2305.02073v2)\]. To mitigate this, multi-task distillation techniques have been proposed to improve DSI’s indexing abilities without altering its architecture \[[2305.02073v2](http://arxiv.org/abs/2305.02073v2)\]. Furthermore, extensions such as De-DSI incorporate decentralization and ensemble learning to improve scalability and efficiency by partitioning datasets into shards trained via multiple DSI models, aggregating results through beam search and softmax normalization \[[2404.12237v2](http://arxiv.org/abs/2404.12237v2)\]. These approaches demonstrate the potential of DSI frameworks for unifying indexing and search, which aligns closely with the goals of Birdie’s encoder-decoder model.

Inducing diversity and balancing relevance in DSI training has also been explored to enhance the quality of retrieved results, inspired by classical techniques like Maximal Marginal Relevance (MMR). These methods aim to integrate diversity directly into model training to avoid reliance on costly post-processing steps, which is pertinent when retrieving heterogeneous data such as tables with varying subtopics \[[2502.02788v1](http://arxiv.org/abs/2502.02788v1)\]. Such advances indicate that differentiable indexing can be adapted to improve semantic richness and recall diversity, which are crucial for effective table discovery.

Large Language Models (LLMs) have become instrumental in enhancing natural language understanding and generation tasks relevant to table retrieval. LLMs have been employed to generate synthetic queries for training retrieval models, effectively augmenting data diversity and addressing cold-start problems in new domains \[[2205.15503v3](http://arxiv.org/abs/2205.15503v3)\]. Synthetic data generation has also been successfully applied to improve table-level representations, leveraging LLMs’ code and data manipulation capabilities to create large-scale, high-quality datasets tailored for table recommendation and similarity tasks \[[2411.03356v1](http://arxiv.org/abs/2411.03356v1)\]. These synthetic query generation techniques enable deeper query-table interactions and support training models to better capture semantic relationships, a key aspect of Birdie’s framework.

Continual learning and dynamic indexing present additional challenges in table retrieval systems, especially when tables are frequently updated or added. Parameter isolation strategies have been proposed to mitigate catastrophic forgetting during incremental index updates, enabling models to retain previously learned information while incorporating new data \[[2210.12828v1](http://arxiv.org/abs/2210.12828v1)\]. This is critical for practical deployment where the index must remain current without retraining from scratch. Differentiable indexing frameworks that integrate continual learning mechanisms offer a promising direction for handling dynamic table repositories.

Beyond indexing, advances in neural query execution on tables have informed approaches to semantic alignment between NL queries and structured data. Neural Enquirer exemplifies fully differentiable architectures capable of executing compositional NL queries on knowledge-base tables by learning distributed representations and executing differentiable operations end-to-end \[[1512.00965v2](http://arxiv.org/abs/1512.00965v2)\]. Such architectures demonstrate the feasibility of deep neural models to comprehend and manipulate table data based on natural language inputs, complementing the retrieval-focused differentiable indexing models.

In summary, Birdie’s approach synthesizes key developments in differentiable search indexing, synthetic query generation via LLMs, and continual learning to address core limitations of traditional dense retrieval pipelines for table discovery. By unifying indexing and search into a single encoder-decoder model and employing prefix-aware identifiers with synthetic queries, Birdie aligns with and extends the state of the art in end-to-end semantic retrieval and dynamic indexing \[[2502.02788v1](http://arxiv.org/abs/2502.02788v1)\]\[[2205.15503v3](http://arxiv.org/abs/2205.15503v3)\]\[[2404.12237v2](http://arxiv.org/abs/2404.12237v2)\]\[[2411.03356v1](http://arxiv.org/abs/2411.03356v1)\]\[[2305.02073v2](http://arxiv.org/abs/2305.02073v2)\]\[[2210.12828v1](http://arxiv.org/abs/2210.12828v1)\]\[[1512.00965v2](http://arxiv.org/abs/1512.00965v2)\].
