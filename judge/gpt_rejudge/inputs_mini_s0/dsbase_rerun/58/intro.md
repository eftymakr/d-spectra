## Related Works

Table discovery has gained significant attention due to the increasing availability of tabular data across diverse domains. Traditional table retrieval methods predominantly rely on keyword matching or query tables, which often result in large candidate sets requiring extensive manual filtering. This limitation motivates the need for more refined search paradigms, such as the proposed NL-conditional table discovery (nlcTD), where natural language (NL) conditions accompany query tables to specify more precise retrieval criteria \[[2410.12164v2](http://arxiv.org/abs/2410.12164v2)\].

A critical foundation for effective table discovery lies in the availability of diverse and well-annotated datasets. Existing benchmarks for table detection and understanding often suffer from limited diversity in table structure, size, and domain, which constrains the generalizability of models trained on them. For instance, a large-scale, diverse table detection dataset was introduced to address these shortcomings, containing over 7,000 samples with varied table structures sourced from multiple domains, demonstrating improved detection performance when using convolutional neural network-based methods over classical approaches \[[2209.09207v2](http://arxiv.org/abs/2209.09207v2)\]. This underscores the importance of diverse data in training robust table-related models.

Beyond detection, challenges in tabular data processing also involve tasks such as table structure recognition, data cleaning, and NL-to-code generation. Recent work on Table-LLM-Specialist proposes a self-training fine-tuning paradigm that leverages the duality of generative and classification formulations to iteratively generate and validate training data without manual labels. This approach achieves superior performance across multiple table tasks compared to base language models and enables smaller models to perform competitively with lower latency and cost. Such advances highlight the potential of language models fine-tuned specifically for tabular data tasks, which could be leveraged for more nuanced table discovery scenarios involving natural language conditions \[[2103.13686v4](http://arxiv.org/abs/2103.13686v4)\].

In the broader context of interpretable data mining, robust subgroup discovery methods aim to identify statistically significant, non-redundant subgroups within datasets. Techniques such as SSD++ utilize the Minimum Description Length principle to optimize subgroup lists, balancing quality and generalization. While primarily focused on subgroup discovery rather than table retrieval, these methods emphasize the importance of modeling robustness and interpretability, which are also desirable in table discovery when integrating complex NL conditions .

The integration of natural language understanding in table-related tasks is also exemplified by datasets and methods developed for table-based question answering and table-to-text generation. These efforts reveal the challenges of aligning NL queries with heterogeneous table structures and semantics, a core difficulty that the nlcTD task seeks to address by combining query tables with NL predicates. Furthermore, the need for richly annotated datasets with diverse query types and relevance judgments is a recurring theme, which the nlcTables dataset directly addresses by providing thousands of queries with NL-only, union, join, and fuzzy conditions, along with extensive candidate tables and relevance annotations \[[2410.12164v2](http://arxiv.org/abs/2410.12164v2)\]\[[2209.09207v2](http://arxiv.org/abs/2209.09207v2)\]\[[2103.13686v4](http://arxiv.org/abs/2103.13686v4)\].

In summary, the current literature highlights key challenges in table discovery including dataset diversity, structural complexity, interpretability, and the integration of natural language. The proposed nlcTD task and nlcTables dataset build on these insights by offering a benchmark that captures complex NL-conditioned table retrieval scenarios, fostering the development of more advanced and semantically aware table discovery methods.
