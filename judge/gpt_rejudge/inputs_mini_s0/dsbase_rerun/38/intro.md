## Related Works

Memory bandwidth regulation and cache partitioning are established techniques to enforce predictable execution times in real-time systems by controlling interference among tasks sharing hardware resources. These methods, when combined with partitioned scheduling, necessitate careful co-allocation of tasks and resources to processor cores because execution times are heavily influenced by allocated resources \[[1405.2916v1](http://arxiv.org/abs/1405.2916v1)\]. The challenge of jointly optimizing task and resource allocation under such constraints has motivated various research directions.

Several works have explored exact and heuristic optimization approaches for task-resource co-allocation. Integer linear programming (ILP), particularly 0-1 ILP, has been a natural formulation for such combinatorial allocation problems. Recent advances have improved exact algorithms for 0-1 ILP with linear numbers of constraints, offering exponential speedups over exhaustive search by leveraging problem structure and reductions to subproblems such as Vector Domination \[[1401.5512v2](http://arxiv.org/abs/1401.5512v2)\]. Additionally, alternative formulations and strengthening of linearizations have been proposed, such as improved Balas and Mazzola linearizations for quadratic 0-1 programs, which enhance cutting plane algorithms and can be adapted for scheduling contexts \[[1204.4829v1](http://arxiv.org/abs/1204.4829v1)\]. However, these exact methods often struggle with scalability, especially under multiple resource constraints and real-time schedulability requirements.

To address computational complexity, heuristic and multi-objective methods have been developed. Multi-layer frameworks that separate resource allocation and task assignment have shown promise. For example, frameworks combining Pareto-pruned search in the outer layer for resource allocation with inner-layer optimization of task assignment via knapsack problem solvers based on dynamic programming have been proposed, demonstrating effectiveness in balancing resource usage and schedulability \[[1903.03494v1](http://arxiv.org/abs/1903.03494v1)\]\[[2110.12115v2](http://arxiv.org/abs/2110.12115v2)\]. The knapsack problem itself is a well-studied NP-hard problem, with dynamic programming and metaheuristics like genetic algorithms applied to various knapsack variants, including difficult classes such as spanner knapsack instances, indicating the suitability of such methods for task allocation subproblems \[[1903.03494v1](http://arxiv.org/abs/1903.03494v1)\].

Cache partitioning and memory bandwidth regulation techniques have been studied extensively to reduce inter-core interference and enforce timing predictability. Approaches such as cache coloring and dynamic cache reconfiguration have been proposed to mitigate cache-related variability and improve energy efficiency, which are essential in embedded real-time environments \[[1904.04860v1](http://arxiv.org/abs/1904.04860v1)\]. Memory bandwidth regulation tools like MemGuard provide fine-grained control over the memory traffic per core, enabling predictable timing despite shared DRAM access \[[2110.12115v2](http://arxiv.org/abs/2110.12115v2)\]. Integrating these resource partitioning techniques with task scheduling has been shown to improve schedulability and system performance \[[0803.3165v6](http://arxiv.org/abs/0803.3165v6)\].

The integration of resource allocation and task scheduling strategies has also been approached through co-design frameworks, which jointly optimize resource distribution and timing parameters such as deadlines. Such frameworks leverage profiling and generative modeling to capture task execution characteristics under varying resource allocations, enabling more accurate schedulability analysis and better resource efficiency \[[1405.2916v1](http://arxiv.org/abs/1405.2916v1)\]\[[0803.3165v6](http://arxiv.org/abs/0803.3165v6)\]. These co-design strategies align with the multi-objective optimization goals of minimizing resource usage while guaranteeing schedulability.

Heuristic multi-objective optimization algorithms, including genetic and evolutionary algorithms, have been applied to similar problems in real-time system optimization. These methods balance multiple competing objectives, such as resource minimization and deadline adherence, by exploring the Pareto front of solutions and have demonstrated superior performance compared to single-objective or exact optimization approaches in complex, multi-resource environments \[[1903.03494v1](http://arxiv.org/abs/1903.03494v1)\]\[[2212.04268v1](http://arxiv.org/abs/2212.04268v1)\].

Finally, the use of deep learning and Lagrangian dual frameworks for approximating solutions to combinatorial optimization problems like the knapsack problem has emerged as a promising direction to scale optimization under constraints. These methods improve constraint satisfaction while maintaining near-optimality, suggesting potential future integration with heuristic task-resource co-allocation algorithms in real-time systems \[[2312.03413v1](http://arxiv.org/abs/2312.03413v1)\].

Collectively, these lines of research provide a foundation for the presented 0-1 linear programming formulation and multi-objective heuristic. The proposed multi-layer framework, combining Pareto-pruned search and dynamic programming-based knapsack solvers, is strongly grounded in prior work on exact and heuristic optimization for 0-1 problems and task scheduling in resource-constrained real-time environments \[[1204.4829v1](http://arxiv.org/abs/1204.4829v1)\]\[[1903.03494v1](http://arxiv.org/abs/1903.03494v1)\]\[[1401.5512v2](http://arxiv.org/abs/1401.5512v2)\]\[[2110.12115v2](http://arxiv.org/abs/2110.12115v2)\]. The integration of fine-grained cache partitioning and memory bandwidth regulation techniques further leverages advances in predictable resource management \[[1904.04860v1](http://arxiv.org/abs/1904.04860v1)\]\[[2110.12115v2](http://arxiv.org/abs/2110.12115v2)\]. This work advances the state of the art by offering improved solution quality and computational efficiency compared to existing mixed-integer programming and multi-resource task co-allocation algorithms.
