## Related Works

The optimization of cloud-native applications running on container orchestration platforms like Kubernetes has been extensively studied in recent years, with particular emphasis on cost efficiency, resource management, and operational scalability. Kubernetes, as the leading container orchestration system, offers powerful features such as autoscaling, load balancing, and resource scheduling, but it also introduces challenges related to cost control, especially when deployed at scale in cloud environments.

Resource management and cost optimization strategies in Kubernetes have been explored through various lenses. Traditional autoscaling mechanisms—including Horizontal Pod Autoscaler (HPA), Vertical Pod Autoscaler (VPA), and Cluster Autoscaler (CA)—often face limitations in balancing resource utilization and application performance, which can lead to inefficiencies and increased costs \[[https://www.semanticscholar.org/paper/2ce38cfb0bf3be6e875f5feb8c4b5e140587bb10](https://www.semanticscholar.org/paper/2ce38cfb0bf3be6e875f5feb8c4b5e140587bb10)\]. To address these issues, recent research has focused on leveraging AI and machine learning techniques for predictive scaling and dynamic resource allocation, significantly enhancing cost-effectiveness while maintaining service quality \[[https://www.semanticscholar.org/paper/2ce38cfb0bf3be6e875f5feb8c4b5e140587bb10](https://www.semanticscholar.org/paper/2ce38cfb0bf3be6e875f5feb8c4b5e140587bb10)\]. Additionally, improvements to Kubernetes’ core components such as scheduling, load balancing, and autoscaling have demonstrated measurable gains in performance and resource efficiency, which indirectly contribute to cost reductions \[[https://www.semanticscholar.org/paper/e7d7f1366e96c3970cfdabb69372b774fe9c5e26](https://www.semanticscholar.org/paper/e7d7f1366e96c3970cfdabb69372b774fe9c5e26)\]\[[https://www.semanticscholar.org/paper/d11e5c5c08af88ee8abb9ebaa166b1d6fd198501](https://www.semanticscholar.org/paper/d11e5c5c08af88ee8abb9ebaa166b1d6fd198501)\].

Cloud cost optimization as a discipline has evolved into FinOps, integrating financial accountability with cloud operations to provide enterprises with frameworks for managing and optimizing cloud expenditures. The FinOps approach emphasizes budgeting, cost monitoring, and enforcement mechanisms to prevent uncontrolled spending and promote cost-awareness among teams \[[2501.14753](http://arxiv.org/abs/2501.14753)\]. ABACUS, a FinOps service, exemplifies this by automating budget analysis, usage surveillance, and deployment cost estimation, thereby enabling proactive cost control in cloud environments \[[2501.14753](http://arxiv.org/abs/2501.14753)\]. Despite the progress in FinOps for compute and storage, the specific domain of network cost optimization in Kubernetes clusters remains relatively underexplored.

Network costs represent a significant and often overlooked component of total cloud expenditure, particularly in distributed containerized applications where inter-pod and cross-node communication is frequent. While prior work has addressed system-level optimization and infrastructure cost management broadly—including GPU resource optimization for AI workloads and large-scale cloud infrastructure \[[2307.12479](http://arxiv.org/abs/2307.12479)\]—the financial impact of network traffic within Kubernetes clusters has not been sufficiently analyzed. Existing cloud cost optimization studies primarily focus on computational resources, storage, and AI-specific overheads, with limited attention to network utilization patterns and their cost implications \[[https://www.semanticscholar.org/paper/8335555ae08140dc2fe0da4807040fc88b0cace1](https://www.semanticscholar.org/paper/8335555ae08140dc2fe0da4807040fc88b0cace1)\]\[[2307.12479](http://arxiv.org/abs/2307.12479)\].

Moreover, the complexity of multi-cloud and hybrid-cloud Kubernetes deployments introduces additional challenges in cost estimation and optimization, as pricing models vary across providers and network egress charges can be substantial \[[https://www.semanticscholar.org/paper/8335555ae08140dc2fe0da4807040fc88b0cace1](https://www.semanticscholar.org/paper/8335555ae08140dc2fe0da4807040fc88b0cace1)\]. Tools and frameworks that incorporate cost prediction and alerting for deployments, like ABACUS, provide foundational elements for managing these costs but require further extension to encompass detailed network cost analytics \[[2501.14753](http://arxiv.org/abs/2501.14753)\].

Security considerations, while crucial for Kubernetes management, have been treated separately from cost optimization studies. Comprehensive reviews on Kubernetes security practices highlight the importance of access control, network policies, and continuous monitoring to protect cluster infrastructure but do not address cost-related implications of security configurations on network overhead or financial impact \[[https://www.semanticscholar.org/paper/8e1ccea4a7235a295ddf13ba43061889e39bcb13](https://www.semanticscholar.org/paper/8e1ccea4a7235a295ddf13ba43061889e39bcb13)\]\[[https://www.semanticscholar.org/paper/1d0a33d8477cec7c984272310a8168493384b3d6](https://www.semanticscholar.org/paper/1d0a33d8477cec7c984272310a8168493384b3d6)\]. Still, these security practices indirectly influence network traffic patterns and potential cost.

Finally, container orchestration research has also investigated performance bottlenecks and scalability concerns that affect cost-efficiency. Work on optimizing cluster state management, consistency models, and edge deployment scenarios reflect ongoing efforts to enhance Kubernetes’ suitability for diverse environments while controlling operational expenses \[[2104.02423](http://arxiv.org/abs/2104.02423)\]\[[2010.10350](http://arxiv.org/abs/2010.10350)\]. These improvements contribute to reducing resource wastage and improving scheduling efficiency, which can translate into cost savings but have not yet been explicitly linked to network cost analysis.

In summary, while there is a rich body of literature addressing Kubernetes performance, resource management, and cloud cost optimization through FinOps frameworks and AI-driven techniques, the explicit study of network usage and cost within Kubernetes clusters is a gap that this paper seeks to fill. By combining measurement, experimentation, and cost modeling, the current work contributes novel insights to the FinOps discipline, focusing on network cost management in cloud-native containerized applications.
