## Related Works

Serverless computing has emerged as a transformative cloud paradigm, offering automatic scaling, efficient resource utilization, and a pay-as-you-go pricing model that abstracts infrastructure management from developers \[[2406.11734](http://arxiv.org/abs/2406.11734)\]. Despite these benefits, cold-start latency—delays incurred when initializing runtime environments for serverless functions—remains a major performance bottleneck, particularly for latency-sensitive applications \[[2206.15176](http://arxiv.org/abs/2206.15176)\]\[[https://www.semanticscholar.org/paper/d911b03bfda4fc6fc92f8080bb81b3a967d6a9e7](https://www.semanticscholar.org/paper/d911b03bfda4fc6fc92f8080bb81b3a967d6a9e7)\]. Cold start typically results from provisioning containers, loading libraries, and initializing application code, which can introduce significant overhead.

A substantial body of research has focused on mitigating cold-start latency through diverse strategies. One prominent approach is container pre-warming, which maintains active containers to reduce startup delays. However, static pre-warming intervals can either waste resources if too long or fail to prevent cold starts if too short \[[https://www.semanticscholar.org/paper/b99668ae35c4b6796b827657a318fe4b84a757ff](https://www.semanticscholar.org/paper/b99668ae35c4b6796b827657a318fe4b84a757ff)\]. Adaptive models employing machine learning, especially Deep Neural Networks and Long Short-Term Memory (LSTM) networks, have been proposed to predict invocation patterns and dynamically adjust container warm-up windows, balancing latency and resource consumption effectively \[[https://www.semanticscholar.org/paper/b99668ae35c4b6796b827657a318fe4b84a757ff](https://www.semanticscholar.org/paper/b99668ae35c4b6796b827657a318fe4b84a757ff)\]\[[https://www.semanticscholar.org/paper/27cd21426fe51167dd6ac79d1c83db55a07a2046](https://www.semanticscholar.org/paper/27cd21426fe51167dd6ac79d1c83db55a07a2046)\]\[[https://www.semanticscholar.org/paper/81b8db7a20f1aa859143c716b38a1443e3eca9a0](https://www.semanticscholar.org/paper/81b8db7a20f1aa859143c716b38a1443e3eca9a0)\].

Time series forecasting techniques have also been applied to anticipate function invocations and optimize resource allocation. SARIMA models and Temporal Convolutional Networks (TCNs) have demonstrated improved container scaling and reduced cold-start times compared to conventional autoscalers \[[https://www.semanticscholar.org/paper/d911b03bfda4fc6fc92f8080bb81b3a967d6a9e7](https://www.semanticscholar.org/paper/d911b03bfda4fc6fc92f8080bb81b3a967d6a9e7)\]\[[https://www.semanticscholar.org/paper/891a89fad669dc7d107ad2d5a047b288b5cc9832](https://www.semanticscholar.org/paper/891a89fad669dc7d107ad2d5a047b288b5cc9832)\]. Reinforcement learning has been explored to refine resource management policies by learning invocation patterns and adjusting container provisioning, achieving reductions in cold start frequency and memory usage \[[https://www.semanticscholar.org/paper/27cd21426fe51167dd6ac79d1c83db55a07a2046](https://www.semanticscholar.org/paper/27cd21426fe51167dd6ac79d1c83db55a07a2046)\]\[[https://www.semanticscholar.org/paper/efd35130c34c0f955066ec4452531e1bf2411abd](https://www.semanticscholar.org/paper/efd35130c34c0f955066ec4452531e1bf2411abd)\]\[[https://www.semanticscholar.org/paper/96d4fea8d034a7605af936f2e2b6a44becdf6585](https://www.semanticscholar.org/paper/96d4fea8d034a7605af936f2e2b6a44becdf6585)\].

Application-level optimizations focus on minimizing the overhead of loading code and dependencies. Notably, LibProf employs dynamic program analysis and statistical sampling to profile Python serverless applications, identifying inefficient library initializations that contribute significantly to cold-start delays. It guides developers in optimizing these patterns, achieving over 2x speedup in cold-start execution and memory reduction \[[2310.08437](http://arxiv.org/abs/2310.08437)\]. Similarly, FaaSLight reduces code loading latency by separating essential from optional libraries, while InstaInfer targets ML inference workloads by opportunistically preloading model artifacts to minimize loading latency beyond container warm-up \[[https://www.semanticscholar.org/paper/fbf4355d06ddb5f6c81e67cffadf57f6939b8940](https://www.semanticscholar.org/paper/fbf4355d06ddb5f6c81e67cffadf57f6939b8940)\]\[[https://www.semanticscholar.org/paper/481983adf5c2c1ae5ffe82eec138f40262429406](https://www.semanticscholar.org/paper/481983adf5c2c1ae5ffe82eec138f40262429406)\].

Resource scheduling and container management approaches have also been developed. SSC employs gradient-based pre-warming and priority queue algorithms to reduce cold start hit rates and cost, achieving nearly 50% reduction in cold starts and 30% cost savings \[[https://www.semanticscholar.org/paper/fbf4355d06ddb5f6c81e67cffadf57f6939b8940](https://www.semanticscholar.org/paper/fbf4355d06ddb5f6c81e67cffadf57f6939b8940)\]. SPES introduces differentiated scheduling by predicting invocation patterns to preload function instances selectively, significantly reducing cold start rates and wasted memory time \[[2403.17574](http://arxiv.org/abs/2403.17574)\]. LCS proposes an affinity-based scheduling strategy that extends container lifetime using Least Recently Used policies to further mitigate cold starts \[[https://www.semanticscholar.org/paper/d45518ce5741587c4c37ccbc5e74b3fcfd6f80f1](https://www.semanticscholar.org/paper/d45518ce5741587c4c37ccbc5e74b3fcfd6f80f1)\].

Emerging research integrates AI-driven resource management for serverless edge environments, where resource constraints amplify cold-start challenges. ATOM utilizes deep reinforcement learning to predict cold start events and manage resources sustainably, balancing prediction accuracy with energy consumption and emissions \[[https://www.semanticscholar.org/paper/891a89fad669dc7d107ad2d5a047b288b5cc9832](https://www.semanticscholar.org/paper/891a89fad669dc7d107ad2d5a047b288b5cc9832)\]. Similarly, adaptive container pool scaling combined with warm-up strategies (AWUS and ACPSS) dynamically adjusts container pools based on predicted invocation behavior, reducing both latency and resource waste \[[https://www.semanticscholar.org/paper/81b8db7a20f1aa859143c716b38a1443e3eca9a0](https://www.semanticscholar.org/paper/81b8db7a20f1aa859143c716b38a1443e3eca9a0)\].

For serverless inference involving large language models (LLMs), cold start is exacerbated by the need to load large checkpoints and initialize GPU resources. ServerlessLLM addresses this through multi-tier storage, optimized checkpoint formats, token-level live migration, and startup-aware scheduling, yielding startup time reductions of up to 6-8× and dramatically lower latency compared to traditional methods \[[2411.15664](http://arxiv.org/abs/2411.15664)\].

Despite advances, many existing solutions either focus on static optimizations or rely on coarse heuristics that do not fully exploit workload-dependent behaviors. Static analysis techniques identify unreachable libraries but cannot address dynamic inefficiencies arising from varying invocation patterns \[[2310.08437](http://arxiv.org/abs/2310.08437)\]. This gap motivates profile-guided optimization tools such as SLIMSTART, which leverage runtime library usage data collected via statistical sampling and call-path profiling to identify workload-specific inefficiencies. Such tools can automate code transformations and integrate with CI/CD pipelines to adapt continuously to evolving workloads, providing more targeted and effective cold-start mitigation.

In summary, the literature spans container pre-warming, time series and reinforcement learning-based prediction, application-level code optimizations, and advanced scheduling strategies. SLIMSTART builds upon these by focusing on fine-grained, runtime-informed library usage profiling to optimize cold start overheads at the application layer, complementing existing infrastructure-centric methods and addressing their limitations
