## Related Works

Natural language-driven table discovery has attracted significant research interest due to the growing availability of large-scale tabular data on the web. Traditional table retrieval methods typically follow a dense vector search pipeline—representing tables and queries as embeddings, indexing these representations, and then performing similarity search. While these approaches have achieved promising accuracy, they suffer from accumulated errors during the representation and indexing phases, which negatively impact retrieval performance. Moreover, limited interaction between queries and tables hampers effective semantic alignment and restricts further accuracy gains \[[2105.06365](http://arxiv.org/abs/2105.06365)\]\[[1802.06159](http://arxiv.org/abs/1802.06159)\].

Deep learning techniques have been widely applied to table retrieval, focusing on semantic matching between queries and tables. Early work introduced semantic representations in multiple vector spaces (discrete sparse and continuous dense) combined with various similarity measures, integrated via supervised learning, which demonstrated improvements over traditional baselines on Wikipedia table datasets \[[2105.06365](http://arxiv.org/abs/2105.06365)\]\[[1802.06159](http://arxiv.org/abs/1802.06159)\]. More recent advances leverage pretrained contextualized language models such as BERT to encode table content alongside query information, enhancing table retrieval by capturing complex syntactic and semantic relations. Jointly training BERT with features from prior literature further improves performance beyond classical baselines, indicating the importance of deep query-table interaction \[[2005.09207](http://arxiv.org/abs/2005.09207)\].

The paradigm of Differentiable Search Index (DSI) has emerged to overcome the inherent limitations of separate indexing and retrieval components in traditional pipelines. DSI models unify indexing and search by directly mapping queries to document or table identifiers using a single transformer-based neural network. This end-to-end approach reduces error propagation and enables richer query-document interactions encoded in model parameters \[[2206.10128](http://arxiv.org/abs/2206.10128)\]\[[2305.02073](http://arxiv.org/abs/2305.02073)\]\[[2305.15115](http://arxiv.org/abs/2305.15115)\]. However, vanilla DSI models face challenges including data distribution mismatch between indexing and retrieval phases, limited ability to discriminate relevant documents, and difficulties in incremental updates. Several works address these issues by augmenting DSI with query generation during indexing, multi-task distillation for improved retrieval quality, and parameter-isolation strategies for continual learning to mitigate catastrophic forgetting \[[2206.10128](http://arxiv.org/abs/2206.10128)\]\[[2305.02073](http://arxiv.org/abs/2305.02073)\]\[[2307.10323](http://arxiv.org/abs/2307.10323)\]\[[2212.09744](http://arxiv.org/abs/2212.09744)\].

Incremental and continual indexing are crucial for dynamic table repositories. Models such as IncDSI formulate document addition as a constrained optimization problem to quickly adapt the neural index without full retraining, achieving real-time updates while maintaining retrieval quality comparable to retraining \[[2307.10323](http://arxiv.org/abs/2307.10323)\]. Similarly, DSI++ explores continual learning challenges, proposing training schemes that stabilize model memory and prevent forgetting by sampling pseudo-queries and optimizing for flatter loss basins. These techniques significantly improve the retention of previously indexed documents while enabling new document indexing \[[2212.09744](http://arxiv.org/abs/2212.09744)\].

Enhancements to DSI frameworks via semantic-enriched identifiers and rehearsal strategies inspired by cognitive psychology further improve document memorization and retrieval accuracy. By assigning elaborative, meaningful identifiers generated through query generation, and selecting fine-grained semantic features as rehearsal content, Semantic-Enhanced DSI (SE-DSI) achieves superior retrieval performance compared to vanilla DSI models \[[2305.15115](http://arxiv.org/abs/2305.15115)\]. Additionally, inducing diversity in DSI retrieval results has been proposed, balancing relevance and novelty inspired by Maximal Marginal Relevance (MMR). This training approach avoids costly post-processing and can be extended to incremental DSI, aligning well with applications requiring both relevance and diversity in retrieved tables \[[2502.02788](http://arxiv.org/abs/2502.02788)\].

In the specific context of table discovery under natural language conditions, datasets like nlcTables have been introduced to benchmark systems that combine query tables with natural language constraints for refined retrieval. Evaluations reveal substantial performance gaps in existing methods, underscoring the need for advanced semantic modeling and better query-table interaction capabilities \[[2504.15849](http://arxiv.org/abs/2504.15849)\]. Neural network architectures such as Neural Enquirer demonstrate the feasibility of executing compositional natural language queries on structured tables end-to-end, learning table and query embeddings jointly and enabling complex query execution \[[1512.00965](http://arxiv.org/abs/1512.00965)\].

Finally, related work in learned index structures for sorted tables investigates the balance between model size and search speed, proposing learned k-ary search models and recursive model indexes that accelerate binary search within limited additional space. Although primarily focused on sorted data indexing rather than semantic retrieval, these techniques inform efficient indexing strategies that could complement differentiable search paradigms \[[2107.0948](http://arxiv.org/abs/2107.09480)\].

In summary, the landscape of natural language-driven table discovery has evolved from traditional dense vector search pipelines toward integrated encoder-decoder models such as DSI that unify indexing and retrieval. Addressing challenges such as query-table semantic alignment, dynamic incremental indexing, and retrieval diversity remains a focus. The integration of large language models for query generation and semantic identifier assignment, alongside continual learning methods, represents a promising direction for overcoming limitations of prior approaches and achieving robust, scalable table discovery.
