## Related Works

Memory bandwidth regulation and cache partitioning have been extensively studied as key techniques to mitigate timing unpredictability in real-time multicore systems. These approaches are critical in ensuring temporal isolation and improving schedulability by managing shared resource contention, which significantly affects task execution times \[[2310.02959](http://arxiv.org/abs/2310.02959)\]\[[1809.05921](http://arxiv.org/abs/1809.05921)\]\[[2410.14003](http://arxiv.org/abs/2410.14003)\]\[[2102.11528](http://arxiv.org/abs/2102.11528)\].

Cache partitioning, either static or dynamic, has been shown to reduce inter-task interference by isolating cache usage among cores. Early work explored joint cache partitioning and task assignment to minimize makespan and improve predictability, proposing approximation algorithms for complex scheduling problems on multicore processors with shared caches \[[1210.4053](http://arxiv.org/abs/1210.4053)\]. More recent frameworks integrate cache partitioning with task scheduling heuristics to exploit task cache sensitivity, achieving notable schedulability improvements under various scheduling policies, including non-preemptive fixed priority and EDF \[[2310.02959](http://arxiv.org/abs/2310.02959)\]. These approaches often cluster tasks by period or cache sensitivity to enhance schedulability, confirming the importance of co-optimizing cache allocation and task placement.

Memory bandwidth regulation complements cache partitioning by controlling access to shared DRAM resources, which are another major source of interference in multicore systems. Dynamic memory bandwidth allocation frameworks analyze worst-case response times under varying bandwidth-to-core assignments, framing response time computation as an optimization problem that enables improved schedulability, especially for memory-intensive workloads such as Integrated Modular Avionics systems \[[1809.05921](http://arxiv.org/abs/1809.05921)\]. More fine-grained regulation techniques, such as per-bank bandwidth regulation for multi-banked last-level caches, have been proposed to prevent cache bank contention and denial-of-service attacks, significantly enhancing predictability and performance isolation \[[2410.14003](http://arxiv.org/abs/2410.14003)\].

The challenge of integrating cache and bandwidth regulation has motivated coordinated resource management frameworks. For instance, the CBP mechanism dynamically manages cache partitioning, bandwidth allocation, and prefetch throttling to reduce average memory access time and improve workload consolidation performance on multicore CMPs, achieving substantial gains over approaches managing these resources independently \[[2102.11528](http://arxiv.org/abs/2102.11528)\]. Such coordinated management underscores the benefit of jointly optimizing multiple shared resources instead of isolated treatment.

Real-time scheduling frameworks have also evolved to incorporate resource-aware task models and heuristics that consider the varying execution times induced by resource allocation levels. The CORD framework profiles tasks’ resource usage dynamically and co-designs resource allocation with deadline decomposition to maximize schedulability for DAG-based tasks, demonstrating the advantage of generative profiling for precise resource allocation decisions \[[2501.08484](http://arxiv.org/abs/2501.08484)\]. Similarly, static scheduling approaches minimize cache misses by exploiting task communication affinities, showing the benefits of cache-aware scheduling in hard real-time multicore systems \[[1312.4509](http://arxiv.org/abs/1312.4509)\].

The integration of memory bandwidth regulation into real-time virtualization environments has been addressed by mechanisms like H-MBR, which provides VM-centric bandwidth reservation compatible with hypervisor-level isolation. This approach addresses the challenge of temporal isolation in mixed-criticality systems running on shared hardware, with low overhead and platform agnosticism \[[2502.02437](http://arxiv.org/abs/2502.02437)\].

Multi-objective optimization methods have been applied to balance conflicting metrics such as resource usage, schedulability, execution time, and energy consumption. Techniques based on evolutionary algorithms and multi-layer heuristic frameworks optimize cache configurations and resource allocation, achieving significant reductions in execution time and energy while maintaining schedulability guarantees \[[2302.11236](http://arxiv.org/abs/2302.11236)\]. These methods align with the use of Pareto-pruned searches and knapsack-based task allocation heuristics in recent works to efficiently explore the resource allocation space \[[2310.02959](http://arxiv.org/abs/2310.02959)\]\[[2501.08484](http://arxiv.org/abs/2501.08484)\].

Other synchronization and interference mitigation mechanisms, such as co-runner locking, complement resource partitioning by controlling task concurrency to avoid excessive interference, further improving schedulability in multicore real-time systems \[[https://www.semanticscholar.org/paper/6ca5ab717934109c6424d996c4d7d914373ab8d0](https://www.semanticscholar.org/paper/6ca5ab717934109c6424d996c4d7d914373ab8d0)\]. Additionally, theoretical analyses have extended classical schedulability tests to account for memory contention and variable execution times in multiframe task models, enabling less pessimistic and more accurate timing analysis under memory bandwidth regulation \[[https://www.semanticscholar.org/paper/e8d15aa827be70bebf15e217ac9295276ddebda7](https://www.semanticscholar.org/paper/e8d15aa827be70bebf15e217ac9295276ddebda7)\].

Overall, the literature emphasizes the necessity of co-optimizing cache partitioning, memory bandwidth regulation, and task scheduling to achieve predictable and efficient execution on multicore real-time platforms. The presented approaches leverage a range of analytical, heuristic, and system-level techniques, highlighting the multi-dimensional nature of resource management challenges in this domain \[[2310.02959](http://arxiv.org/abs/2310.02959)\]\[[1809.05921](http://arxiv.org/abs/1809.05921)\]\[[2410.14003](http://arxiv.org/abs/2410.14003)\]\[[https://www.semanticscholar.org/paper/e8d15aa827be70bebf15e217ac9295276ddebda7](https://www.semanticscholar.org/paper/e8d15aa827be70bebf15e217ac9295276ddebda7)\]\[[1210.4053](http://arxiv.org/abs/1210.4053)\]\[[2502.02437](http://arxiv.org/abs/2502.02437)\]\[[2501.08484](http://arxiv.org/abs/2501.08484)\]\[[2102.11528](http://arxiv.org/abs/2102.11528)\]\[[https://www.semanticscholar.org/paper/6ca5ab717934109c6424d996c4d7d914373ab8d0](https://www.semanticscholar.org/paper/6ca5ab717934109c6424d996c4d7d914373ab8d0)\]\[[2302.11236](http://arxiv.org/abs/2302.11236)\]\[[1312.4509](http://arxiv.org/abs/1312.4509)\].
