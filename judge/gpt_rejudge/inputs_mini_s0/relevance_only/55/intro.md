## Related Works

Conversational recommender systems (CRSs) focus on multi-turn interactions to dynamically elicit user preferences and provide personalized recommendations. Early approaches typically relied on one-shot interactions and static user preference models, which limited their ability to fully capture the complexity and multifaceted nature of user preferences \[[2004.00646](http://arxiv.org/abs/2004.00646)\]\[[2101.09459](http://arxiv.org/abs/2101.09459)\]. To overcome these limitations, CRS research has increasingly emphasized multi-turn dialogue strategies that enable richer user-system interactions, allowing systems to clarify and refine user preferences through explicit feedback and questioning \[[2004.00646](http://arxiv.org/abs/2004.00646)\]\[[2101.09459](http://arxiv.org/abs/2101.09459)\].

A key challenge in CRSs is accurately modeling both short-term and long-term user preferences amid complex and ambiguous user feedback. Variational reasoning methods that model latent user preferences as probabilistic variables have been proposed to better capture these dynamics, leveraging knowledge graphs and multi-hop reasoning to improve recommendation accuracy \[[https://www.semanticscholar.org/paper/49846c2d069c324d5d3f3b53cb74b13e84b7caeb](https://www.semanticscholar.org/paper/49846c2d069c324d5d3f3b53cb74b13e84b7caeb)\]. Similarly, frameworks combining attribute-level and item-level feedback, along with inverse reinforcement learning, have been developed to infer implicit user preferences from conversational context, thus enhancing preference estimation and decision-making policies \[[https://www.semanticscholar.org/paper/0056038b89647afcee84226adf19feb1023a54c0](https://www.semanticscholar.org/paper/0056038b89647afcee84226adf19feb1023a54c0)\]. These approaches highlight the importance of exploiting the full spectrum of user feedback—both explicit and implicit—during multi-turn interactions.

Reinforcement learning (RL) has been widely adopted to optimize dialogue policies in CRSs, where the system learns to decide when to ask questions, what to ask, and when to recommend items. However, conventional RL approaches often suffer from short-sighted training objectives that focus on immediate rewards, neglecting the long-term impact of dialogue strategies. To address this, user simulators have been introduced to enable long-term reinforcement learning by simulating realistic user behavior and feedback during training. For example, frameworks integrating user simulators with dual reward signals—covering both recommendation quality and conversational engagement—have shown significant improvements in recommendation recall and dialogue informativeness \[[https://www.semanticscholar.org/paper/c987b6440da17d48366304ba2d44fda636a8f728](https://www.semanticscholar.org/paper/c987b6440da17d48366304ba2d44fda636a8f728)\]. Moreover, multi-objective intrinsic reward learning has been proposed to automatically learn reward functions aligned with CRS-specific goals such as maximizing success rate and minimizing dialogue length, further enhancing policy learning \[[2310.20109](http://arxiv.org/abs/2310.20109)\].

The use of user simulators is not limited to reinforcement learning. Simulated users also facilitate automatic evaluation and training of CRSs by providing consistent and scalable multi-turn interactions without requiring real users. Recent advances in generative models and instruction tuning have enabled the development of more sophisticated simulated users capable of providing nuanced feedback, such as coarse-grained item scoring and fine-grained attribute-based critiques, in a unified instruction-driven format. These generative reward model-based simulators can effectively replicate complex user preferences and behaviors, enabling automatic interaction that balances recommendation effectiveness and user experience \[[https://www.semanticscholar.org/paper/c987b6440da17d48366304ba2d44fda636a8f728](https://www.semanticscholar.org/paper/c987b6440da17d48366304ba2d44fda636a8f728)\]\[[2304.13874](http://arxiv.org/abs/2304.13874)\].

To improve recommendation accuracy and dialogue naturalness, many CRSs incorporate external knowledge sources such as knowledge graphs, which help bridge the semantic gap between user language and item attributes. Techniques including mutual information maximization to align word-level and entity-level representations have enhanced both recommendation precision and conversational relevance \[[2007.04032](http://arxiv.org/abs/2007.04032)\]. Collaborative augmentation approaches also exploit interaction histories across users by constructing user-item graphs, thereby improving item representation learning and user preference modeling beyond single conversations \[[2212.07767](http://arxiv.org/abs/2212.07767)\].

Recent efforts have explored alternative paradigms to reinforcement learning for CRS policy optimization. Decision tree-based methods offer interpretable and data-efficient solutions for question selection, candidate ranking, and recommendation timing, addressing issues of RL models’ complexity and training data demands while maintaining competitive performance \[[2208.14614](http://arxiv.org/abs/2208.14614)\]. Additionally, time-aware models have been proposed to track dynamic user preferences influenced by temporal factors, enabling CRS agents to adapt query strategies and recommendations based on evolving user interests and conversation context \[[https://www.semanticscholar.org/paper/4ca875a32737f61e5bd7a01ccfc92ebe041d728c](https://www.semanticscholar.org/paper/4ca875a32737f61e5bd7a01ccfc92ebe041d728c)\].

In summary, the landscape of CRS research encompasses diverse methods for preference elicitation, user simulation, dialogue policy learning, and knowledge integration. Challenges remain in balancing accurate preference modeling with minimal user burden, efficiently leveraging user feedback, and ensuring transferability across domains. The proposed GRSU framework builds upon these foundations by introducing a generative reward model-based simulated user that unifies coarse and fine-grained feedback in an instruction-tuned format, enabling efficient and effective automatic multi-turn interaction with CRSs. This approach draws on prior advances in user simulation, intrinsic reward learning, and instruction-based generative modeling to address key CRS challenges \[[https://www.semanticscholar.org/paper/c987b6440da17d48366304ba2d44fda636a8f728](https://www.semanticscholar.org/paper/c987b6440da17d48366304ba2d44fda636a8f728)\]\[[2304.13874](http://arxiv.org/abs/2304.13874)\]\[[2310.20109](http://arxiv.org/abs/2310.20109)\].
