## Related Works

Table discovery has gained considerable attention due to the exponential growth of tabular data repositories and the need for efficient retrieval methods. Traditional table discovery approaches often rely on matching query tables or vague keyword searches, which tend to produce large sets of results requiring extensive manual filtering by users. This limitation has spurred research into leveraging semantic and structural information to enhance retrieval quality and user experience \[[1208.4016](http://arxiv.org/abs/1208.4016)\].

Early efforts to imbue database systems with semantic capabilities include latent table discovery, which seeks to connect unrelated tables through semantic relationships rather than syntactic links, thereby enriching the information retrieval process beyond conventional SQL queries \[[1208.4016](http://arxiv.org/abs/1208.4016)\]. This concept underpins the motivation to incorporate natural language (NL) conditions into table discovery tasks, as proposed in NL-conditional table discovery (nlcTD), where users can refine queries with NL requirements.

Several datasets and methods have been developed to support the understanding and processing of tables in various contexts. For example, large-scale diverse datasets for table detection in documents have been introduced to address limitations in previous benchmarks—such as sample diversity, table structure complexity, and data quality—enabling the development of convolutional neural network-based methods that outperform classical approaches in detecting table layouts \[[2209.09207](http://arxiv.org/abs/2209.09207)\]. These efforts highlight the importance of comprehensive and varied data to improve model robustness in table understanding tasks.

In parallel, challenges in table question answering (TableQA) have been studied, where large language models (LLMs) face difficulties due to limited context windows, tokenization mismatches with cell boundaries, and data privacy constraints when using external models. The cooperative game "HiddenTables" was proposed to address these challenges by enabling interaction between code-generating LLMs and an evaluation oracle, ensuring data security while improving the handling of complex queries and compositional dependencies. This work also introduced the PyQTax dataset, containing over 116,000 question-table-answer triplets with detailed taxonomy labels, emphasizing the complexity and diversity required for effective TableQA model training \[[2406.10803](http://arxiv.org/abs/2406.10803)\].

The connection between table discovery and question answering is particularly relevant, as aligning natural language queries with table structures remains a significant obstacle. Existing benchmarks in table structure recognition and table-to-text generation provide foundational resources but often lack the complexity of NL-conditioned retrieval or the integration of multiple query types such as unions, joins, and fuzzy conditions \[[2406.10803](http://arxiv.org/abs/2406.10803)\]. These gaps underscore the necessity for datasets like nlcTables that encompass diverse query forms and extensive relevance annotations to facilitate research on NL-conditional table discovery.

Collectively, these works demonstrate a trajectory toward richer semantic integration, diverse and realistic datasets, and advanced modeling techniques to improve table-related tasks. However, the performance gaps identified in state-of-the-art table discovery methods on benchmarks that combine tabular and NL inputs indicate that further advances are required to fully realize effective nlcTD systems \[[1208.4016](http://arxiv.org/abs/1208.4016)\]\[[2209.09207](http://arxiv.org/abs/2209.09207)\]\[[2406.10803](http://arxiv.org/abs/2406.10803)\]. The proposed nlcTables dataset and task contribute to this emerging direction by providing a structured framework and comprehensive evaluation environment tailored to NL-conditional table discovery challenges.
