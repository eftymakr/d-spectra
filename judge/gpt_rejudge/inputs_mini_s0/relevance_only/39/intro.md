## Related Works

De novo genome assembly reconstructs entire genomes from short or long DNA sequencing reads without using a reference sequence, enabling the study of unknown genomes crucial for personalized medicine and disease management \[[1705.11147](http://arxiv.org/abs/1705.11147)\]. The process faces substantial computational challenges due to the massive data volumes, complex graph structures, and algorithmic intricacies involved \[[1705.11147](http://arxiv.org/abs/1705.11147)\]\[[2207.04350](http://arxiv.org/abs/2207.04350)\]. Early approaches predominantly relied on de Bruijn graphs and overlap-layout-consensus (OLC) methods to model sequence overlaps and build contiguous sequences (contigs) \[[https://www.semanticscholar.org/paper/c6e319a023f932d6d2ff8897c2c91e56e872db8e](https://www.semanticscholar.org/paper/c6e319a023f932d6d2ff8897c2c91e56e872db8e)\]\[[1801.04453](http://arxiv.org/abs/1801.04453)\]. However, these traditional methods often incur high memory consumption and limited scalability when applied to large and complex genomes, motivating the need for scalable, memory-efficient algorithms and parallelization techniques.

Distributed-memory parallel algorithms have become prominent to address scalability and computational demands. Tools like HipMER exploit large-scale parallelization on supercomputers to assemble human and large plant genomes with tens of thousands of cores, demonstrating that genome assembly can scale to extreme sizes \[[1705.11147](http://arxiv.org/abs/1705.11147)\]. Similarly, PPA-assembler utilizes Google's Pregel framework for scalable de Bruijn graph-based assembly in distributed environments, achieving improved performance over existing assemblers \[[1801.04453](http://arxiv.org/abs/1801.04453)\]. Distributed string graph construction and layout simplification algorithms, as implemented in diBELLA 2D, leverage sparse matrix operations and achieve near-linear scaling with high parallel efficiency for large genomes such as human and C. elegans \[[2010.10055](http://arxiv.org/abs/2010.10055)\]. These efforts confirm the value of distributed-memory architectures but also highlight persistent challenges in memory footprint and irregular data access patterns that limit efficiency \[[1705.11147](http://arxiv.org/abs/1705.11147)\]\[[2207.04350](http://arxiv.org/abs/2207.04350)\]\[[2010.10055](http://arxiv.org/abs/2010.10055)\].

Memory efficiency remains a critical bottleneck in de novo assembly. SparseAssembler introduces a sparse de Bruijn graph structure that reduces memory requirements by skipping intermediate k-mers, achieving up to 90% memory savings while maintaining accuracy through error correction algorithms \[[1106.2603](http://arxiv.org/abs/1106.2603)\]. SparseAssembler2 further generalizes this concept by replacing the standard de Bruijn graph with a sparse k-mer graph model, enabling robust assembly with minimal memory usage and efficient error handling via adapted graph traversal algorithms \[[1108.3556](http://arxiv.org/abs/1108.3556)\]. Additionally, succinct data structures leveraging entropy compression have been proposed to represent de Bruijn graphs with significantly reduced storage footprints, enabling practical genome assembly on commodity servers \[[1008.2555](http://arxiv.org/abs/1008.2555)\]. Despite these advances, managing the dynamic and interdependent data structures inherent to genome assembly remains challenging, especially under limited memory conditions \[[1106.2603](http://arxiv.org/abs/1106.2603)\]\[[1108.3556](http://arxiv.org/abs/1108.3556)\]\[[1008.2555](http://arxiv.org/abs/1008.2555)\].

Parallelization on heterogeneous hardware has also been explored to accelerate critical steps. ELBA is a distributed-memory algorithm for overlap detection and layout simplification optimized with GPU schedulers to alleviate bottlenecks in pairwise alignment, achieving up to 7–8× speed-ups with multiple MPI processes \[[2309.07270](http://arxiv.org/abs/2309.07270)\]. However, GPU-based methods often face limitations related to memory bandwidth and data transfer overhead, particularly for large and irregular datasets \[[2309.07270](http://arxiv.org/abs/2309.07270)\]. Recent research into hardware-software co-design has started to address these issues through near-memory processing (NMP) and custom processing elements that maximize parallelism while mitigating memory bottlenecks and irregular data patterns \[[2111.01916](http://arxiv.org/abs/2111.01916)\]. Such approaches promise substantial performance gains by closely coupling computation and memory resources.

Beyond hardware acceleration, algorithmic innovations have sought to optimize workload balancing and reduce computational complexity. Distributed memory algorithms employing sparse matrices and graph partitioning effectively localize assembly to reduce redundant computation and improve load balance \[[2207.04350](http://arxiv.org/abs/2207.04350)\]\[[2010.10055](http://arxiv.org/abs/2010.10055)\]. Hybrid CPU-NMP processing strategies further address hardware underutilization caused by irregular data dependencies \[[2207.04350](http://arxiv.org/abs/2207.04350)\]\[[2111.01916](http://arxiv.org/abs/2111.01916)\]. Moreover, tools like PASHA utilize hybrid parallelism combining multi-threading and distributed computing to achieve efficient short-read assembly for large genomes with modest resources \[[https://www.semanticscholar.org/paper/7bf2f1c55f90e11a4d1df4dd608ac621a08f8b33](https://www.semanticscholar.org/paper/7bf2f1c55f90e11a4d1df4dd608ac621a08f8b33)\]. SWAP-Assembler demonstrates scalability to thousands of cores, implementing asynchronous parallel models and multi-step graph cleaning to produce high-quality contigs rapidly \[[https://www.semanticscholar.org/paper/fe8d86bc5520b5049104ff58ee7e980982816ebf](https://www.semanticscholar.org/paper/fe8d86bc5520b5049104ff58ee7e980982816ebf)\].

Recent trends in genome assembly also include leveraging long-read sequencing data for scaffolding and gap filling, improving contiguity and accuracy. ntLink uses minimizer-based mappings of long reads to scaffold draft assemblies efficiently, enabling overlap detection and gap closing while maintaining computational efficiency \[[2301.08785](http://arxiv.org/abs/2301.08785)\]. Such hybrid approaches complement the assembly process by resolving complex repetitive regions that short reads alone cannot address \[[2301.08785](http://arxiv.org/abs/2301.08785)\]\[[2308.07877](http://arxiv.org/abs/2308.07877)\].

Alternative paradigms employing machine learning and emerging quantum computing methods have been proposed to tackle the NP-hard nature of genome assembly. Neural models trained for graph simplification show promise in scaling graph algorithms for assembly \[[2011.05013](http://arxiv.org/abs/2011.05013)\], while quantum annealing and quantum walk algorithms have been experimentally explored for overlap graph pathfinding, offering potential future acceleration avenues \[[2004.06719](http://arxiv.org/abs/2004.06719)\]\[[2308.03532](http://arxiv.org/abs/2308.03532)\]. Though nascent, these approaches highlight the multifaceted research directions in assembly methodologies.

In summary, while distributed-memory parallel assemblers and memory-efficient graph representations have significantly advanced de novo genome assembly scalability and performance, challenges persist in balancing memory footprint, irregular data dependencies, and computational resource utilization. Hardware-software co-designs, including near-memory processing architectures, represent a promising direction to overcome these limitations by integrating customized processing elements with optimized software frameworks, achieving superior throughput and reduced memory usage compared to existing solutions \[[1705.11147](http://arxiv.org/abs/1705.11147)\]\[[2207.04350](http://arxiv.org/abs/2207.04350)\]\[[2309.07270](http://arxiv.org/abs/2309.07270)\]\[[2111.01916](http://arxiv.org/abs/2111.01916)\].
