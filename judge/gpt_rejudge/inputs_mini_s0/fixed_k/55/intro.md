## Related Works

Conversational recommender systems (CRSs) have been extensively studied for their capacity to engage users in multi-turn dialogues to elicit preferences and provide personalized recommendations \[[1806.03277](http://arxiv.org/abs/1806.03277)\]. Early systems focused on integrating recommendation and dialog capabilities, capturing user preferences through interactive questioning and adapting future sessions based on long-term user models \[[1806.03277](http://arxiv.org/abs/1806.03277)\]\[[1107.0029](http://arxiv.org/abs/1107.0029)\]. However, these systems often rely heavily on user input, which can degrade the user experience due to frequent interruptions.

To improve preference elicitation and recommendation accuracy, recent approaches leverage reinforcement learning (RL) to optimize conversational policies that decide when to ask questions and when to recommend items \[[1806.03277](http://arxiv.org/abs/1806.03277)\]\[[2310.14609](http://arxiv.org/abs/2310.14609)\]\[[2105.0971](http://arxiv.org/abs/2105.09710)\]. These RL-based methods consider multiple decision-making tasks—such as selecting attributes to inquire about or items to recommend—within a unified policy learning framework, enhancing both scalability and interaction efficiency \[[2105.0971](http://arxiv.org/abs/2105.09710)\]. Notably, intrinsic reward learning techniques have been proposed to better align RL rewards with user intent by learning rewards from user interactions, thereby improving success rates and reducing dialogue length \[[2310.20109](http://arxiv.org/abs/2310.20109)\].

Simulated users have become a valuable tool to automate and evaluate multi-turn conversational interactions without the need for costly real-user studies. User simulators generate feedback to conversational agents, enabling extensive training and testing. For instance, ConvSim simulates multi-turn feedback and clarifying responses, facilitating improvements in retrieval and ranking tasks within conversational search systems \[[2304.13874](http://arxiv.org/abs/2304.13874)\]. The use of simulated users also allows exploration of user feedback processing modules, which is crucial for advancing the effectiveness of conversational recommendation \[[2304.13874](http://arxiv.org/abs/2304.13874)\]\[[2310.20109](http://arxiv.org/abs/2310.20109)\].

Another important research direction is enhancing CRS with external knowledge and semantic representations. Knowledge graph (KG)-based methods integrate item and attribute relations to improve recommendation accuracy and context awareness \[[2112.0814](http://arxiv.org/abs/2112.08140)\]\[[2412.02415](http://arxiv.org/abs/2412.02415)\]\[[2408.01342](http://arxiv.org/abs/2408.01342)\]. For example, Transformer-based sequential models leverage the sequential dependencies of items and related entities mentioned in conversations, further augmented by multi-hop KG paths, to better capture user preferences and improve recommendations \[[2412.02415](http://arxiv.org/abs/2412.02415)\]. However, KG-based approaches often require costly engineering efforts to maintain domain-specific graphs and may overlook conversational context; recent models address these issues by directly embedding item metadata and aligning it with dialog history using pre-trained language models, reducing complexity while maintaining strong performance \[[2112.0814](http://arxiv.org/abs/2112.08140)\]\[[2408.01342](http://arxiv.org/abs/2408.01342)\].

Explainability and transparency in CRS have also been actively investigated. Generating natural language explanations alongside recommendations helps users understand system reasoning, which builds trust and improves user satisfaction \[[2208.08035](http://arxiv.org/abs/2208.08035)\]\[[2112.05197](http://arxiv.org/abs/2112.05197)\]. Approaches incorporating user reviews or subjective aspect critiques enable interactive refinement of recommendations through conversational critiquing, facilitating more flexible and informed user feedback \[[2112.05197](http://arxiv.org/abs/2112.05197)\]\[[2208.08035](http://arxiv.org/abs/2208.08035)\].

Addressing the challenge of diverse and multifaceted user preferences, novel policy learning frameworks consider multiple interests simultaneously rather than assuming a single clear target. Multi-choice question strategies and union-set candidate selection have been proposed to accommodate users with varying or overlapping preferences across attributes, leading to more realistic and effective conversational strategies \[[2112.11775](http://arxiv.org/abs/2112.11775)\]. These methods improve the agent's ability to handle complex preference distributions and reduce over-filtering of items during dialogue.

Privacy concerns in CRS have motivated federated learning frameworks that decentralize user preference estimation and interaction stages, enforcing differential privacy to protect sensitive data while maintaining competitive recommendation performance \[[2503.00999](http://arxiv.org/abs/2503.00999)\]. This line of work highlights the growing importance of user privacy in conversational settings.

Finally, the integration of large language models (LLMs) and collaborative filtering signals has shown promise in bridging conversational and interaction-based representations. Methods aligning LLM-generated recommendations with collaborative embeddings achieve significant improvements in recommendation accuracy and ranking metrics, demonstrating the benefit of combining conversational context with collaborative knowledge \[[2412.06949](http://arxiv.org/abs/2412.06949)\].

The proposed GRSU framework advances this landscape by introducing a generative reward model-based simulated user that provides both coarse-grained item scoring and fine-grained attribute critiques in an instruction-based unified format. This design draws on prior work in user simulation \[[2304.13874](http://arxiv.org/abs/2304.13874)\]\[[2310.20109](http://arxiv.org/abs/2310.20109)\], intrinsic reward learning \[[2310.20109](http://arxiv.org/abs/2310.20109)\]\[[2310.14609](http://arxiv.org/abs/2310.14609)\], and efficient policy learning \[[2105.0971](http://arxiv.org/abs/2105.09710)\], while leveraging beam search strategies inspired by complex reasoning tasks to balance interaction effectiveness and efficiency. The use of instruction tuning on synthesized data for unified simulation represents a novel contribution toward more seamless and generalizable automatic multi-turn interaction with CRSs.
