## Related Works

De novo genome assembly reconstructs unknown genomes from short DNA reads, a computationally demanding task due to data volume and algorithmic complexity \[[1705.11147](http://arxiv.org/abs/1705.11147)\]. Early assemblers predominantly utilized de Bruijn graphs and overlap-layout-consensus (OLC) paradigms. De Bruijn graph-based methods, while effective, often suffer from excessive memory usage that scales with k-mer diversity and length, limiting their application to large genomes \[[1106.2603](http://arxiv.org/abs/1106.2603)\]\[[1108.3556](http://arxiv.org/abs/1108.3556)\]. Sparse de Bruijn graph approaches, such as SparseAssembler and SparseAssembler2, alleviate memory demands by selectively storing fewer k-mers and employing novel graph traversal algorithms to handle sequencing errors and polymorphisms, achieving up to 90% memory savings without sacrificing assembly quality \[[1106.2603](http://arxiv.org/abs/1106.2603)\]\[[1108.3556](http://arxiv.org/abs/1108.3556)\].

Distributed-memory parallel algorithms have been developed to address scalability challenges inherent to large genomic datasets. Tools like HipMER demonstrate end-to-end scalable assembly on supercomputers with tens of thousands of cores by parallelizing components of the Meraculous pipeline, enabling assembly of complex genomes such as hexaploid wheat \[[1705.11147](http://arxiv.org/abs/1705.11147)\]. Similarly, PPA-assembler leverages the Pregel framework for scalable graph-based assembly, improving performance on distributed systems \[[1801.04453](http://arxiv.org/abs/1801.04453)\]. Other frameworks, including diBELLA 2D, implement distributed sparse matrix operations for overlap detection and layout simplification, achieving near-linear scaling and substantial speed-ups over prior methods \[[2010.10055](http://arxiv.org/abs/2010.10055)\]. These approaches reduce runtime and memory bottlenecks but still require significant computational resources and suffer from irregular data patterns that impair hardware utilization \[[1705.11147](http://arxiv.org/abs/1705.11147)\]\[[2010.10055](http://arxiv.org/abs/2010.10055)\].

Long-read sequencing technologies have driven new assembly methodologies addressing high error rates and repetitive regions. Minimap and miniasm rapidly assemble noisy long reads without prior error correction, drastically reducing runtime at the expense of consensus accuracy \[[1512.01801](http://arxiv.org/abs/1512.01801)\]. ntLink uses long-read data for scaffolding draft assemblies through efficient minimizer-based mappings, incorporating overlap detection and gap filling to improve contiguity while maintaining computational efficiency \[[2301.08785](http://arxiv.org/abs/2301.08785)\]. Distributed contig generation algorithms using sparse matrix abstractions further accelerate assembly by localizing computation and balancing load across nodes, achieving up to 80% parallel efficiency on large clusters \[[2207.0435](http://arxiv.org/abs/2207.04350)\]. Despite these advances, the irregularity and dynamic nature of assembly data structures continue to limit hardware resource utilization.

Hardware acceleration efforts for genome assembly focus on alleviating memory bandwidth limitations and computation overhead. GPU-accelerated schedulers for ELBA, a distributed-memory overlap and layout simplification pipeline, improve performance by enabling multiple MPI processes to share GPUs effectively, achieving up to 8× speed-ups \[[2309.0727](http://arxiv.org/abs/2309.07270)\]. Co-design frameworks such as GenASM and SeGraM target key bottlenecks in sequence analysis pipelines, combining efficient algorithms with specialized hardware accelerators for tasks like approximate string matching and sequence-to-graph alignment, delivering significant performance and energy-efficiency gains \[[2111.01916](http://arxiv.org/abs/2111.01916)\]\[[2205.05883](http://arxiv.org/abs/2205.05883)\]. However, GPU and FPGA solutions often face trade-offs between parallelism and overhead and can be constrained by irregular access patterns inherent in assembly graphs \[[2309.0727](http://arxiv.org/abs/2309.07270)\]\[[2111.01916](http://arxiv.org/abs/2111.01916)\].

Emerging approaches explore machine learning and quantum computing to tackle assembly complexity. Reinforcement learning frameworks have been proposed to automate genome assembly decisions, showing potential but facing scalability challenges due to large state-action spaces \[[2102.02649](http://arxiv.org/abs/2102.02649)\]. Neural execution models based on graph neural networks demonstrate promise in learning graph simplification algorithms critical for assembly \[[2011.05013](http://arxiv.org/abs/2011.05013)\]. Quantum algorithms, including quantum walks and annealing, offer novel paradigms for solving NP-hard assembly problems by exploiting graph partitioning and pathfinding, though these remain largely experimental \[[2308.03532](http://arxiv.org/abs/2308.03532)\]\[[2004.06719](http://arxiv.org/abs/2004.06719)\].

Algorithmic innovations also address data representation and memory efficiency. K-mer counting, a foundational step in assembly, has seen improvements via HySortK, a distributed memory sorter that reduces communication and memory usage while enabling flexible parallelism \[[2407.07718](http://arxiv.org/abs/2407.07718)\]. Estimation techniques based on k-mer frequency analysis aid in genome characteristic inference independent of assembly, informing sequencing strategies \[[1308.2012](http://arxiv.org/abs/1308.2012)\]. Theoretical studies quantify mate-pair library requirements to guarantee accurate assembly, highlighting fundamental limits and conditions for efficient reconstruction \[[1310.1653](http://arxiv.org/abs/1310.1653)\].

Despite these significant advances, existing assemblers and accelerators often encounter limitations in memory footprint, irregular data access, and suboptimal hardware utilization. Large dynamic data structures and complex interdependencies challenge conventional architectures, motivating the need for specialized near-memory processing (NMP) designs. NMP architectures that integrate processing close to memory can mitigate bandwidth bottlenecks and provide dedicated scratchpad memory for dynamic data, enabling efficient parallelism and reduced data movement \[[2309.0727](http://arxiv.org/abs/2309.07270)\]\[[2111.01916](http://arxiv.org/abs/2111.01916)\]. Hybrid CPU-NMP processing and software-level batch optimizations further address irregularity and underutilization issues.

In summary, prior work spans distributed parallel algorithms, memory-efficient graph representations, hardware acceleration, and emerging quantum and ML techniques, each contributing to tackling the computational demands of de novo genome assembly. However, comprehensive solutions that jointly minimize memory footprint, optimize data movement, and handle irregular, dynamic data structures remain an open challenge, motivating hardware-software co-design approaches such as NMP-PaK.
