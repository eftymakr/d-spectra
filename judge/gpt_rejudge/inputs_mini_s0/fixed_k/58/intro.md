## Related Works

Table discovery in large repositories has attracted increasing attention due to the proliferation of tabular data and the challenges in efficiently retrieving relevant tables. Traditional table discovery approaches mainly rely on either query tables or keyword-based search, which often yield large, noisy result sets requiring extensive manual filtering. This limitation motivates the exploration of more nuanced methods that integrate natural language (NL) conditions to refine search results, as proposed in the NL-conditional table discovery (nlcTD) task \[[1208.4016](http://arxiv.org/abs/1208.4016)\].

Semantics-driven approaches have been investigated to improve table discovery beyond syntactic matching. For example, concept-driven frameworks for latent table discovery aim to semantically connect unrelated tables lacking explicit syntactic relationships, thereby enriching the retrieval process with meaningful latent links \[[1208.4016](http://arxiv.org/abs/1208.4016)\]. Such semantic techniques align with the need for NL-conditional queries to better capture user intent.

The complexity of table detection and understanding is underscored by recent advances in deep learning for table detection in diverse document layouts. Efforts to curate large-scale, diverse datasets with varied table structures have demonstrated the superiority of convolutional neural network-based methods over classical computer vision approaches for identifying table boundaries and structure \[[2209.09207](http://arxiv.org/abs/2209.09207)\]. These datasets and methods provide foundational tools for downstream table discovery and analysis tasks, emphasizing the importance of diverse and realistic training data.

Table question answering (TableQA) represents a related domain where natural language queries interact with tabular data. Challenges in TableQA include handling large tables within limited context windows, aligning tokenization with table cell boundaries, and ensuring data privacy when using external language models. The recently introduced HiddenTables cooperative game framework and its associated PyQTax dataset address these issues by enabling secure and scalable TableQA across various taxonomies, revealing fundamental limitations of current large language models in compositional reasoning and schema alignment \[[2406.10803](http://arxiv.org/abs/2406.10803)\]. This work highlights challenges similar to those faced in NL-conditional table discovery, such as interpreting complex NL queries in the context of structured data.

While prior benchmarks have targeted table structure recognition and table-to-text generation, these tasks differ from table discovery in that they focus on either structural parsing or natural language generation rather than retrieval conditioned on NL requirements. Existing datasets for table detection and TableQA emphasize the need for comprehensive annotations and diverse examples to support model generalization \[[2209.09207](http://arxiv.org/abs/2209.09207)\]\[[2406.10803](http://arxiv.org/abs/2406.10803)\]. However, the integration of NL conditions with query tables, as in the nlcTD task, remains underexplored.

In summary, prior works have laid important groundwork by advancing semantic frameworks for latent table connections \[[1208.4016](http://arxiv.org/abs/1208.4016)\], providing diverse datasets and deep learning methods for table detection \[[2209.09207](http://arxiv.org/abs/2209.09207)\], and addressing NL-table interactions in the form of TableQA with privacy and scalability considerations \[[2406.10803](http://arxiv.org/abs/2406.10803)\]. Despite these advances, significant gaps remain in developing methods that can effectively combine query tables with complex natural language constraints to retrieve relevant tables from large repositories. The proposed nlcTables dataset and benchmark aim to fill this gap by offering a rich resource for evaluating and advancing NL-conditional table discovery methods.
