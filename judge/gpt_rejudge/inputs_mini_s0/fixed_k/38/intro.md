## Related Works

Memory bandwidth regulation and cache partitioning have been extensively studied as key techniques to ensure timing predictability in real-time multicore systems. These methods reduce interference caused by shared hardware resources, such as caches and memory controllers, which directly affect task execution times and schedulability \[[2310.02959](http://arxiv.org/abs/2310.02959)\]\[[1809.05921](http://arxiv.org/abs/1809.05921)\]\[[2410.14003](http://arxiv.org/abs/2410.14003)\]. The challenge lies in co-allocating tasks and resources to processor cores in a manner that accounts for the sensitivity of tasks to cache availability and dynamic memory bandwidth, especially under preemptive scheduling policies.

Several works have proposed optimization frameworks that jointly consider cache partitioning and task scheduling to improve real-time schedulability. For instance, a multi-layer design space exploration framework systematically interleaves cache partitioning, task-to-core allocation, and schedulability analysis, demonstrating significant improvements in schedulability for cache-sensitive tasks under non-preemptive fixed-priority scheduling \[[2310.02959](http://arxiv.org/abs/2310.02959)\]. This approach highlights the benefits of clustering tasks by compatible periods to enhance schedulability, which is relevant to multi-objective scheduling heuristics targeting resource usage minimization.

Dynamic memory bandwidth regulation has been analyzed to better understand and bound the worst-case response times of tasks affected by varying memory bandwidth allocations over time intervals. Such analysis enables schedulability improvements in integrated modular avionics by dynamically adjusting bandwidth-to-core assignments \[[1809.05921](http://arxiv.org/abs/1809.05921)\]. Complementing this, per-bank bandwidth regulation of shared last-level caches (LLCs) has been introduced to mitigate contention and denial-of-service attacks targeting cache banks. This fine-grained regulation improves throughput and timing predictability by isolating cache bandwidth usage on a per-bank basis, which is essential for predictable real-time performance in commercial multicore processors \[[2410.14003](http://arxiv.org/abs/2410.14003)\].

The joint cache partition and job assignment problem has been theoretically studied with approximation algorithms designed to minimize makespan on multicore shared cache processors. These algorithms explore static and dynamic cache partitioning and job assignment strategies, addressing the complexity of scheduling on ordered unrelated machines—a model that captures varying core strengths and cache allocations. These insights inform heuristic designs for task-resource co-allocation that balance optimality and computational efficiency \[[1210.4053](http://arxiv.org/abs/1210.4053)\].

Coordinated management of cache partitioning, memory bandwidth partitioning, and prefetch throttling has been proposed to reduce average memory access time and improve application performance on multicore processors. By dynamically adjusting these resources in concert, such frameworks outperform solutions that manage these resources in isolation, demonstrating that integrated resource management can yield significant performance gains during workload consolidation \[[2102.11528](http://arxiv.org/abs/2102.11528)\]. This coordination is critical in real-time systems where resource contention impacts worst-case execution times.

In addition to resource partitioning, recent work has emphasized the importance of precise execution models that capture time-varying resource usage profiles of tasks under different resource budgets. Generative profiling techniques enable more accurate prediction of task execution times, facilitating joint resource allocation and deadline decomposition that improve schedulability for DAG-based real-time tasks on multicore platforms \[[2501.08484](http://arxiv.org/abs/2501.08484)\]. Such models align with multi-layer heuristic frameworks that interleave resource allocation and task scheduling to optimize schedulability and resource usage trade-offs.

Energy consumption and execution time optimization in cache memories have also been addressed through multi-objective evolutionary algorithms. These methods select cache configurations that balance conflicting metrics such as energy and performance, achieving substantial reductions in execution time and energy usage for embedded multimedia applications. Although focusing on energy, these optimization principles are applicable to real-time resource co-allocation where multiple objectives must be balanced \[[2302.11236](http://arxiv.org/abs/2302.11236)\].

Finally, real-time gang scheduling frameworks enforce strict scheduling policies to mitigate unpredictable interference caused by concurrent execution of parallel tasks on multicore platforms. By combining gang scheduling with memory bandwidth throttling, these frameworks provide tight bounds on execution times and improve system predictability, demonstrating the importance of resource-aware scheduling policies in real-time multicore systems \[[1903.00999](http://arxiv.org/abs/1903.00999)\].

Collectively, these works underscore the significance of integrated optimization of cache partitioning, memory bandwidth regulation, and task scheduling. They motivate the development of multi-layer heuristics and 0-1 integer linear programming formulations that co-allocate tasks and resources under preemptive EDF scheduling policies, achieving better schedulability and resource efficiency than existing methods \[[2310.02959](http://arxiv.org/abs/2310.02959)\]\[[1809.05921](http://arxiv.org/abs/1809.05921)\]\[[2410.14003](http://arxiv.org/abs/2410.14003)\]\[[1210.4053](http://arxiv.org/abs/1210.4053)\]\[[2501.08484](http://arxiv.org/abs/2501.08484)\]\[[2102.11528](http://arxiv.org/abs/2102.11528)\]\[[1903.00999](http://arxiv.org/abs/1903.00999)\].
