## Related Works

Natural language-driven table discovery has gained significant attention due to the increasing availability of large-scale tabular data repositories and the need to retrieve relevant tables using natural language (NL) queries. Traditional deep learning-based approaches predominantly rely on the dense vector search pipeline, which decomposes the problem into three stages: table representation, indexing, and search. In these pipelines, tables and queries are encoded into continuous vector spaces, followed by approximate nearest neighbor search over indices built on table embeddings. Although effective, this separation leads to accumulated errors across stages that degrade overall retrieval accuracy. Moreover, limited query-table interaction during encoding restricts semantic alignment, resulting in suboptimal performance \[[2105.06365](http://arxiv.org/abs/2105.06365)\].

To address limitations in table retrieval, recent works have explored semantic representation and retrieval frameworks. Semantic Table Retrieval proposes representing queries and tables in multiple semantic spaces (discrete sparse and continuous dense vectors) and combines various similarity measures within supervised models, improving retrieval effectiveness on Wikipedia tables \[[2404.12237](http://arxiv.org/abs/2404.12237)\]. Similarly, nlcTables introduces a benchmark for NL-conditional table discovery, where users refine table search results by combining query tables with natural language conditions. Evaluations on this dataset reveal substantial gaps in current methods, highlighting the challenge of semantic alignment and the importance of richer query-table interactions \[[2504.15849](http://arxiv.org/abs/2504.15849)\].

In the realm of neural architectures for querying tables, Neural Enquirer presents a fully differentiable network that directly executes NL queries on knowledge-base tables by learning distributed representations and compositional query execution steps. This approach supports deep query-table interaction, enabling the model to handle complex queries end-to-end, which contrasts with traditional pipelines that process query and table representations separately \[[1512.00965](http://arxiv.org/abs/1512.00965)\]. Similarly, Table-LLM-Specialist employs a dual generator-validator fine-tuning paradigm tailored to table tasks, improving performance across NL-to-code translation and data cleaning by iteratively generating and validating synthetic training data, demonstrating the potential of LLMs in enhancing table understanding \[[2410.12164](http://arxiv.org/abs/2410.12164)\].

A novel paradigm that directly unifies indexing and retrieval is the Differentiable Search Index (DSI). Unlike traditional modular retrieval systems, DSI encodes the entire corpus and its indexing structure within a single transformer model’s parameters, mapping queries directly to document or table identifiers as output strings. This approach eliminates the conventional index-search separation, reducing error propagation and enabling end-to-end optimization. Initial studies show that DSI outperforms strong baselines such as dual encoders and BM25 in zero-shot setups, but also reveal challenges like data distribution mismatch between indexing (long documents) and retrieval (short queries), and limited ability to distinguish relevant documents \[[2202.06991](http://arxiv.org/abs/2202.06991)\]\[[2305.02073](http://arxiv.org/abs/2305.02073)\]\[[2206.10128](http://arxiv.org/abs/2206.10128)\].

Several enhancements to DSI have been proposed. DSI-QG addresses the aforementioned distribution mismatch by augmenting indexing with synthetic queries generated per document via query generation models, which are then re-ranked to better represent retrieval queries. This improves retrieval performance in both mono-lingual and cross-lingual settings \[[2206.10128](http://arxiv.org/abs/2206.10128)\]. The De-DSI framework introduces decentralization by partitioning datasets and training ensembles of DSI models on shards, aggregating results with beam search and score normalization to maintain retrieval accuracy while enabling scalability and decentralized operation \[[2404.12237](http://arxiv.org/abs/2404.12237)\]. Furthermore, methods to induce diversity during DSI training have been proposed to balance relevance with novel information, improving sub-topic retrieval without sacrificing accuracy \[[2502.02788](http://arxiv.org/abs/2502.02788)\].

Synthetic data generation also plays a pivotal role in improving table representations and retrieval. Leveraging large language models (LLMs) to generate high-quality synthetic queries and table transformations has been shown to enhance table-level representations, leading to better recommendation and discovery performance \[[2411.03356](http://arxiv.org/abs/2411.03356)\]. These synthetic datasets align with semantic definitions of table similarity and support more robust model training.

Finally, continual learning and dynamic indexing remain critical for evolving table repositories. Parameter isolation techniques to update differentiable indexes mitigate catastrophic forgetting, a key challenge in lifelong learning scenarios for retrieval systems \[[2209.09207](http://arxiv.org/abs/2209.09207)\]. This allows models to accommodate new tables incrementally without significant performance degradation on previously indexed data.

In summary, the Birdie framework builds upon and advances these lines of research by unifying indexing and retrieval via a differentiable search index tailored for table discovery. By integrating LLM-generated synthetic queries, prefix-aware table identifiers, and continual learning strategies, Birdie addresses key limitations of traditional dense retrieval pipelines, enabling deeper query-table interaction and dynamic updates that result in substantial accuracy improvements.
