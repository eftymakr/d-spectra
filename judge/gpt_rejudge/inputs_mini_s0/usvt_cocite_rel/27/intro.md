## Related Works

Natural language-driven table discovery has been extensively studied as a key task for retrieving relevant tables from large-scale repositories based on user queries. Traditional solutions predominantly follow a dense vector search pipeline comprising separate stages of table representation, indexing, and search. While effective, these multi-step methods suffer from error propagation across stages, which adversely impacts retrieval accuracy. Moreover, they often lack deep query-table interaction, limiting semantic alignment and further performance gains \[[2005.09207](http://arxiv.org/abs/2005.09207)\]\[[1906.00041](http://arxiv.org/abs/1906.00041)\].

Early approaches to table retrieval leveraged semantic matching through multiple representation spaces and similarity measures to improve ranking accuracy \[[1802.06159](http://arxiv.org/abs/1802.06159)\]. Neural embedding techniques have also been employed to encode various table components—such as captions, columns, and cells—into dense vectors, which are then integrated into retrieval models to enhance row and column population as well as table retrieval tasks \[[1906.00041](http://arxiv.org/abs/1906.00041)\]. However, these methods still rely on a traditional index-retrieve paradigm, which inherently separates indexing and retrieval processes.

Recent advances in information retrieval have introduced differentiable search indexes (DSI) that unify indexing and retrieval within a single neural encoder-decoder model. In this framework, the model directly maps queries to document or table identifiers by storing all relevant information in its parameters, thus eliminating intermediate indexing errors and enabling end-to-end optimization \[[2202.06991](http://arxiv.org/abs/2202.06991)\]\[[2208.07652](http://arxiv.org/abs/2208.07652)\]. Variants of DSI employ query generation techniques to represent documents with multiple synthetic queries during indexing, improving the model’s ability to associate short queries with long documents and mitigating data distribution mismatches between indexing and retrieval \[[2206.10128](http://arxiv.org/abs/2206.10128)\]. Enhancements inspired by cognitive psychology, such as elaborative document identifiers and rehearsal-based semantic features, further improve document memorization and retrieval performance in DSIs \[[2305.15115](http://arxiv.org/abs/2305.15115)\].

Handling dynamic corpora and continual indexing remains a significant challenge for DSI models due to catastrophic forgetting when new data is incorporated. Solutions like DSI++ propose parameter isolation and generative memory mechanisms to supplement training with pseudo-queries, effectively reducing forgetting and enabling stable incremental indexing \[[2212.09744](http://arxiv.org/abs/2212.09744)\].

Autoregressive search engines represent an alternative paradigm, generating distinctive n-grams as document identifiers via sequence models. This approach achieves strong passage retrieval performance on benchmarks like KILT while maintaining a smaller memory footprint compared to conventional retrieval systems \[[2204.10628](http://arxiv.org/abs/2204.10628)\]. Likewise, pre-trained generative models such as CorpusBrain leverage large-scale pretraining tasks to encode corpus knowledge directly into model parameters, supporting end-to-end retrieval and demonstrating superior zero- and low-resource performance on knowledge-intensive tasks \[[2208.07652](http://arxiv.org/abs/2208.07652)\].

Complementary to these trends, transformer-based architectures such as ColBERT enable efficient and effective passage search by encoding queries and documents separately and performing late interaction over contextualized embeddings. This design balances retrieval quality with computational efficiency and supports scalable indexing and search \[[2004.12832](http://arxiv.org/abs/2004.12832)\]. Multi-stage ranking architectures combining models like BERT have also been successful in trading off latency and accuracy for document ranking tasks \[[1910.14424](http://arxiv.org/abs/1910.14424)\].

In the domain of table search specifically, approaches that incorporate semantic similarity measures and leverage pretrained language models improve ad hoc table retrieval by better capturing the structural and contextual aspects of tables \[[2005.09207](http://arxiv.org/abs/2005.09207)\]\[[1802.06159](http://arxiv.org/abs/1802.06159)\]. However, these methods still typically rely on discrete index structures and separate retrieval steps, constraining joint optimization and deeper query-table interaction.

Overall, the emerging differentiable search index paradigm addresses the key limitations of traditional dense retrieval pipelines by integrating indexing and search into a unified model, enabling richer query-table interactions and mitigating error accumulation. Advances in query generation, identifier design, and continual learning further enhance the applicability of DSIs to dynamic table retrieval scenarios. Birdie builds upon these foundations by introducing prefix-aware identifiers, large language model-based query generation, and parameter-isolation-based continual indexing to substantially improve accuracy and robustness in natural language-driven table discovery.
