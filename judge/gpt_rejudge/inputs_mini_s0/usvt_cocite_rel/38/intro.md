## Related Works

Memory bandwidth regulation and cache partitioning are critical techniques widely studied to achieve predictable timing behavior in real-time multi-core systems. These approaches aim to mitigate interference arising from shared hardware resources such as caches, DRAM controllers, and interconnects, which otherwise introduce significant unpredictability in task execution times \[[1809.05921](http://arxiv.org/abs/1809.05921)\]\[[1903.00999](http://arxiv.org/abs/1903.00999)\]. 

Several frameworks propose memory bandwidth regulation mechanisms to isolate performance among cores. MemGuard, for example, enforces per-core memory bandwidth reservations to provide efficient performance isolation, ensuring that real-time tasks meet their timing requirements despite contention in shared memory subsystems \[[https://www.semanticscholar.org/paper/bbebaeb1b00fdcde2aeb192543835d3ec1518f8d](https://www.semanticscholar.org/paper/bbebaeb1b00fdcde2aeb192543835d3ec1518f8d)\]\[[https://www.semanticscholar.org/paper/0b1bc294dbd926f853a8ee41d1d8f8ecc3cfde13](https://www.semanticscholar.org/paper/0b1bc294dbd926f853a8ee41d1d8f8ecc3cfde13)\]. Similarly, dynamic memory bandwidth regulation schemes have been analyzed to compute worst-case response times under varying bandwidth allocations, offering theoretical foundations for schedulability analysis in multi-core real-time systems \[[1809.05921](http://arxiv.org/abs/1809.05921)\]. These works highlight the importance of fine-grained control and dynamic adaptation of memory bandwidth to improve predictability.

Cache partitioning, often realized through cache coloring or set partitioning, has also been extensively explored for reducing cache interference. Techniques such as cache coloring assign disjoint cache sets to tasks, thereby minimizing inter-task cache conflicts and improving worst-case execution time (WCET) bounds \[[https://www.semanticscholar.org/paper/50d359dc737cb5c296b527f4eb1541dc55f3ed86](https://www.semanticscholar.org/paper/50d359dc737cb5c296b527f4eb1541dc55f3ed86)\]\[[https://www.semanticscholar.org/paper/43cc4d0a998b9aa361264e5fc786c738a62382f1](https://www.semanticscholar.org/paper/43cc4d0a998b9aa361264e5fc786c738a62382f1)\]. Hardware-software co-design approaches have been proposed to support cache management at the OS level, enabling practical implementations in embedded multi-core platforms \[[https://www.semanticscholar.org/paper/50d359dc737cb5c296b527f4eb1541dc55f3ed86](https://www.semanticscholar.org/paper/50d359dc737cb5c296b527f4eb1541dc55f3ed86)\]. Advanced concepts like Programmable Logic In-the-Middle (PLIM) have been introduced to manipulate memory transactions between the processor and main memory, facilitating novel cache management techniques such as Cache Bleaching to mitigate fragmentation and improve cache utilization \[[https://www.semanticscholar.org/paper/dbd4eb5033815003e7f6519fd66e43e5fc297075](https://www.semanticscholar.org/paper/dbd4eb5033815003e7f6519fd66e43e5fc297075)\].

The integration of memory bandwidth regulation and cache partitioning within scheduling frameworks is essential for predictable task execution. RT-Gang, a real-time gang scheduling framework, enforces a one-gang-at-a-time policy to avoid simultaneous contention for memory and cache resources by co-scheduled parallel tasks. It combines this with bandwidth throttling for best-effort tasks to tightly bound interference, demonstrating improved system predictability and schedulability \[[1903.00999](http://arxiv.org/abs/1903.00999)\]. This work exemplifies the benefits of coordinated resource management across multiple layers of the system stack.

Multi-objective optimization approaches have been proposed to address task-resource co-allocation challenges under real-time constraints. Theoretical studies show that determining worst-case response times when memory bandwidth allocations vary over time can be formulated as maximization problems solvable via efficient algorithms \[[1809.05921](http://arxiv.org/abs/1809.05921)\]. These optimization problems often require balancing conflicting objectives such as minimizing resource usage while guaranteeing schedulability under preemptive Earliest Deadline First (EDF) scheduling policies.

The multiframe task model, which accounts for variations in worst-case execution times across job instances, has been extended to consider memory bandwidth regulation effects. By adapting stall analyses to this model, schedulability analysis becomes less pessimistic and more accurate, enabling higher platform utilization without sacrificing safety \[[https://www.semanticscholar.org/paper/e8d15aa827be70bebf15e217ac9295276ddebda7](https://www.semanticscholar.org/paper/e8d15aa827be70bebf15e217ac9295276ddebda7)\]. This refinement is crucial for practical deployment of real-time systems with dynamic workloads and shared memory resources.

Bounding worst-case memory interference in commercial off-the-shelf (COTS) multi-core systems is also a significant research focus. Techniques have been developed to model the timing characteristics of DRAM banks, buses, and controllers, providing tight upper bounds on interference delays. These analyses facilitate memory bank partitioning strategies to further reduce interference and improve predictability \[[https://www.semanticscholar.org/paper/afca4afaaaa543a1da02b266e9b2ac46eb94793b](https://www.semanticscholar.org/paper/afca4afaaaa543a1da02b266e9b2ac46eb94793b)\]. Similarly, DRAM bank-aware memory allocators like PALLOC allocate memory pages to reduce contention, improving performance isolation \[[https://www.semanticscholar.org/paper/6e925ae85e385ac0e8810441d84be97c079f6b22](https://www.semanticscholar.org/paper/6e925ae85e385ac0e8810441d84be97c079f6b22)\].

In summary, these diverse lines of research collectively emphasize the necessity of coordinated memory bandwidth regulation, cache partitioning, and scheduling strategies to achieve predictable timing in real-time multi-core systems. Optimization frameworks combining these elements, especially those employing multi-objective heuristics and layered search strategies, are essential for efficient task-resource co-allocation that meets real-time constraints \[[1809.05921](http://arxiv.org/abs/1809.05921)\]\[[1903.00999](http://arxiv.org/abs/1903.00999)\]\[[https://www.semanticscholar.org/paper/e8d15aa827be70bebf15e217ac9295276ddebda7](https://www.semanticscholar.org/paper/e8d15aa827be70bebf15e217ac9295276ddebda7)\].
