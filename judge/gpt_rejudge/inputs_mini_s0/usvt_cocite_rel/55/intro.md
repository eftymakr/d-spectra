## Related Works

Conversational recommender systems (CRSs) extend traditional recommendation models by engaging users in multi-turn dialogues to dynamically elicit preferences and provide personalized recommendations. This interaction-driven paradigm addresses inherent limitations of static recommendation methods, which struggle to accurately capture complex and multifaceted user preferences due to their reliance on historical behavior alone \[[2002.09102](http://arxiv.org/abs/2002.09102)\]\[[2101.09459](http://arxiv.org/abs/2101.09459)\]\[[1806.03277](http://arxiv.org/abs/1806.03277)\]\[[2004.00646](http://arxiv.org/abs/2004.00646)\].

A fundamental challenge in CRSs is deciding what to ask users about items or attributes, when to recommend items, and how to adapt recommendations based on user feedback in an online manner. The EAR framework exemplifies this approach by structuring CRS interactions into Estimation, Action, and Reflection stages, enabling the system to estimate user preferences, decide between asking attribute-related questions or making recommendations, and update the model upon receiving user rejections \[[2002.09102](http://arxiv.org/abs/2002.09102)\]. However, EAR and similar methods often treat attribute feedback implicitly and separately from item-level feedback, limiting the fine-grained understanding of user preferences.

Graph-based reasoning methods have been proposed to explicitly leverage user feedback over item attributes, improving candidate pruning and increasing recommendation accuracy. Conversational Path Reasoning (CPR) models the CRS task as interactive path traversal on a knowledge graph of attributes, explicitly utilizing user responses to refine recommendations \[[2007.00194](http://arxiv.org/abs/2007.00194)\]. Further, reinforcement learning (RL) approaches unify decision-making about querying attributes or recommending items into a single policy learning task, improving scalability and stability of CRS decision processes \[[2105.09710](http://arxiv.org/abs/2105.09710)\]. RL techniques also address the exploration-exploitation trade-off inherent in multi-turn interactions, optimizing when to ask questions versus make recommendations \[[2005.12979](http://arxiv.org/abs/2005.12979)\].

In addition to decision policies, preference modeling has seen advances through integrating attribute-level and item-level feedback. Models like the Feedback-guided Preference Adaptation Network (FPAN) and Conversational Recommender with Implicit Feedback (CRIF) leverage relations between attribute and item feedback to revise user embeddings dynamically, leading to more accurate preference estimation and improved recommendations in multi-round CRS scenarios \[[https://www.semanticscholar.org/paper/33e0fe2d4cf01b16da89ab0c180cdcbf37b3be17](https://www.semanticscholar.org/paper/33e0fe2d4cf01b16da89ab0c180cdcbf37b3be17)\]\[[https://www.semanticscholar.org/paper/0056038b89647afcee84226adf19feb1023a54c0](https://www.semanticscholar.org/paper/0056038b89647afcee84226adf19feb1023a54c0)\]. These methods highlight the importance of explicitly modeling interactions between different feedback granularities.

To overcome the challenge of requiring extensive user involvement—which can degrade user experience—simulated users have been introduced as a means to automate interaction and evaluation. User simulators generate realistic user responses based on modeled preferences, enabling large-scale testing and training of CRS policies without the cost of human participants \[[2006.08732](http://arxiv.org/abs/2006.08732)\]. Simulated users can help identify conversational breakdowns and improve system robustness \[[2105.09710](http://arxiv.org/abs/2105.09710)\].

Recent works also focus on enhancing the semantic understanding of user input and bridging the gap between natural language and item-level preferences. Knowledge graph-based semantic fusion integrates word- and entity-level representations to improve both recommendation accuracy and dialog quality \[[2007.04032](http://arxiv.org/abs/2007.04032)\]. Topic-guided conversational datasets and architectures further facilitate natural, semantically coherent multi-turn dialogues that guide recommendation scenarios \[[2010.04125](http://arxiv.org/abs/2010.04125)\].

In terms of interaction design, systems have explored various question formats to elicit user preferences more efficiently. Multiple-choice questions capturing multiple interests per attribute type have been proposed to better reflect real-world user uncertainty and preference diversity \[[2112.11775](http://arxiv.org/abs/2112.11775)\]. Other research investigates instruction-based or natural language explanation frameworks to improve transparency and user trust while reducing user burden \[[https://www.semanticscholar.org/paper/3ae5bef6b0c8317603a2deab2527383580904fd8](https://www.semanticscholar.org/paper/3ae5bef6b0c8317603a2deab2527383580904fd8)\]\[[2101.09459](http://arxiv.org/abs/2101.09459)\].

Reinforcement learning and bandit-based methods have been employed to unify attribute and item recommendation actions seamlessly, automatically balancing exploration and exploitation without relying on hand-crafted heuristics \[[2005.12979](http://arxiv.org/abs/2005.12979)\]. Thompson Sampling frameworks that treat both attributes and items as arms have demonstrated improved success rates and conversation efficiency compared to earlier models \[[2005.12979](http://arxiv.org/abs/2005.12979)\].

Finally, recent advances leverage neural architectures and large-scale user data to bootstrap conversational policies and recommendation models. RNN-based systems generate topic suggestions and incorporate user feedback to refine recommendations adaptively \[[https://www.semanticscholar.org/paper/2610b45131f31a7c58b0cd6a8fce21c02ba014be](https://www.semanticscholar.org/paper/2610b45131f31a7c58b0cd6a8fce21c02ba014be)\]. These approaches illustrate the potential of combining deep learning with interactive feedback to improve personalized recommendations.

In summary, the literature reveals a trend towards unified frameworks that integrate attribute and item modeling, explicit use of multi-level feedback, reinforcement learning for policy optimization, and the use of simulated users for scalable training and evaluation. The proposed generative reward model based simulated user (GRSU) aligns with this trajectory by providing both coarse-grained item scoring and fine-grained attribute critiques in a unified instruction-based format, enabling efficient automatic multi-turn interaction and improved preference elicitation in CRSs.
