## Related Works

Natural language-driven table retrieval has garnered significant attention due to the growing importance of extracting structured knowledge from large table repositories. Traditional retrieval systems for tables often rely on dense vector search pipelines that separately handle representation, indexing, and search phases, typically using pretrained embedding models followed by an approximate nearest neighbor search. While these methods achieve strong accuracy, they suffer from cumulative errors introduced at each stage, which negatively impact overall retrieval effectiveness. Moreover, the conventional pipeline limits direct semantic interaction between queries and tables, hindering the model’s ability to fully align query intent with table semantics \[[https://www.semanticscholar.org/paper/d69c0ed04ecc852e8c921900d3e7967f74f81263](https://www.semanticscholar.org/paper/d69c0ed04ecc852e8c921900d3e7967f74f81263)\]\[[2105.06365](http://arxiv.org/abs/2105.06365)\]\[[1906.00041](http://arxiv.org/abs/1906.00041)\].

Recent advances in dense retrieval have demonstrated the superior performance of neural models over classical sparse methods such as BM25. Dense retrievers based on dual-encoder architectures learn query and passage embeddings that improve recall and ranking effectiveness in open-domain question answering and passage retrieval tasks \[[2004.04906](http://arxiv.org/abs/2004.04906)\]. However, these approaches still follow a representation-index-search paradigm, which does not fully resolve error accumulation or enable deep query-document interaction during retrieval. To address efficiency and interaction challenges, models like ColBERT introduced contextualized late interaction, encoding queries and documents independently with BERT and then performing fine-grained similarity matching to enhance semantic alignment without excessive computational overhead \[[2004.12832](http://arxiv.org/abs/2004.12832)\]. Multi-stage ranking architectures leveraging BERT further improve ranking quality by refining candidate passages with pointwise or pairwise classification, balancing latency and accuracy \[[1910.14424](http://arxiv.org/abs/1910.14424)\].

An emerging paradigm, Differentiable Search Index (DSI), challenges the traditional separation of indexing and retrieval by unifying both into a single encoder-decoder transformer model that directly maps queries to document identifiers stored implicitly in model parameters. This approach eliminates the need for an explicit index and reduces error accumulation by tightly coupling indexing and retrieval processes. DSI models have shown competitive performance, even outperforming strong baselines in zero-shot setups, and demonstrate promising generalization capabilities \[[2202.06991](http://arxiv.org/abs/2202.06991)\]. Subsequent work enhanced DSI by generating synthetic queries during indexing to better bridge the distribution mismatch between indexing long documents and retrieving short queries, significantly boosting retrieval accuracy in mono- and cross-lingual settings \[[2206.10128](http://arxiv.org/abs/2206.10128)\]. Furthermore, continual learning extensions such as DSI++ address dynamic corpus updates by incrementally indexing new documents while mitigating catastrophic forgetting through training optimizations and generative memory, thereby improving retrieval stability and reducing retraining costs \[[2212.09744](http://arxiv.org/abs/2212.09744)\].

End-to-end neural corpus indexers have also been proposed, generating document identifiers conditioned on queries using sequence-to-sequence models, and employing prefix-aware decoders and query generation techniques to maximize recall performance. These methods demonstrate substantial gains over traditional retrieval baselines on large-scale benchmarks \[[2206.02743](http://arxiv.org/abs/2206.02743)\]. Similarly, autoregressive search engines generate n-gram based document identifiers autoregressively, enabling effective passage retrieval while maintaining a lightweight memory footprint compared to other autoregressive and dense retrieval systems \[[2204.10628](http://arxiv.org/abs/2204.10628)\].

Specific to table retrieval, semantic matching approaches combine multiple representations—both sparse discrete and dense continuous embeddings—of queries and tables to capture rich semantic information. These methods utilize various similarity measures and supervised learning frameworks to effectively rank tables relevant to keyword or natural language queries, yielding significant improvements over baseline methods \[[1802.06159](http://arxiv.org/abs/1802.06159)\]\[[2105.06365](http://arxiv.org/abs/2105.06365)\]. Deep contextualized language models like BERT have also been applied to ad hoc table retrieval, adapting input encodings to table structure and jointly training with features from prior work to surpass earlier state-of-the-art results \[[2005.09207](http://arxiv.org/abs/2005.09207)\]. Multimodal neural ranking models employ gated units to integrate different table modalities (e.g., captions, headers, cell content) along with co-learning strategies that leverage query-independent and query-dependent signals, further enhancing retrieval performance \[[https://www.semanticscholar.org/paper/373588873bef360e3ecad2e091ac17895eb863af](https://www.semanticscholar.org/paper/373588873bef360e3ecad2e091ac17895eb863af)\]. Neural embeddings tailored for table elements have been shown to improve tasks such as table population and retrieval by incorporating semantic similarities between words, entities, and table components \[[1906.00041](http://arxiv.org/abs/1906.00041)\].

The Birdie framework builds upon these lines of research by employing a differentiable search index that encodes both synthetic query-table mappings and prefix-aware identifiers directly into a unified encoder-decoder language model. This enables deep query-table interaction and eliminates error accumulation inherent in traditional pipelines. Birdie also addresses dynamic indexing challenges via parameter isolation techniques to mitigate forgetting, combining the advantages of DSI models with query generation and continual learning strategies to achieve substantial accuracy and robustness gains over existing dense retrieval methods.
