## Related Works

Table discovery is an essential problem in data management, aiming to retrieve relevant tables from large repositories based on user queries. Traditional methods predominantly rely on keyword queries or query tables, which often result in large, imprecise result sets requiring extensive manual filtering. This limitation motivates the exploration of more refined retrieval paradigms that incorporate natural language (NL) conditions to better express user intent, as proposed in the NL-conditional table discovery (nlcTD) task \[[1802.06159](http://arxiv.org/abs/1802.06159)\].

Early research in table retrieval introduced semantic matching techniques to bridge the gap between queries and tables. For example, the work on ad hoc table retrieval emphasized representing both queries and tables in multiple semantic spaces—combining discrete sparse and continuous dense vector representations—and applying various similarity measures to improve ranking quality \[[1802.06159](http://arxiv.org/abs/1802.06159)\]. This approach showed significant improvements over baseline models, demonstrating the value of semantic representation and matching in table retrieval.

Advancing beyond pure retrieval, pretrained language models have been adapted to jointly understand textual and tabular data, addressing the complex reasoning required for semantic parsing over structured tables. TaBERT, a pretrained model trained on millions of tables and their textual contexts, learns unified representations of NL sentences and table content. It has achieved state-of-the-art results in tasks such as weakly supervised semantic parsing on WikiTableQuestions and competitive performance on text-to-SQL benchmarks like Spider \[[2005.08314](http://arxiv.org/abs/2005.08314)\]. This line of work showcases how integrating NL and tabular data representations can enhance downstream table understanding and retrieval tasks.

Benchmarking efforts in table structure recognition and semantic parsing have also contributed valuable resources for developing and evaluating table-based systems. For instance, datasets focusing on table detection and structure recognition emphasize the diversity of table layouts and the need for robust annotation and evaluation frameworks \[[https://www.semanticscholar.org/paper/bff7592f28354b3be632f4bf678b622f765a2b8d](https://www.semanticscholar.org/paper/bff7592f28354b3be632f4bf678b622f765a2b8d)\]. Although not directly addressing table retrieval, these datasets provide foundational insights into handling heterogeneous table formats, an important consideration when retrieving tables that match complex NL queries.

While related tasks such as table-to-text generation and table-based question answering have seen progress through the use of richly annotated datasets, they differ from nlcTD in their end goals. Table-to-text generation focuses on producing natural language descriptions from tables, whereas table-based QA centers on answering questions using a single table. NL-conditional table discovery uniquely combines structured query tables with NL constraints to refine retrieval, requiring datasets that capture diverse query conditions including unions, joins, and fuzzy matches.

Existing datasets for table retrieval or semantic parsing often lack the scale or complexity needed to fully evaluate NL-conditional discovery scenarios. The nlcTables dataset addresses this gap by providing a large benchmark with over 600 diverse NL-conditional queries, more than 22,000 candidate tables, and detailed relevance annotations. This enables rigorous assessment of current state-of-the-art methods, revealing substantial performance gaps and underscoring the challenges in NL-conditional table discovery.

In summary, prior work has laid the groundwork through semantic matching techniques for table retrieval \[[1802.06159](http://arxiv.org/abs/1802.06159)\], pretrained models for joint text-table understanding \[[2005.08314](http://arxiv.org/abs/2005.08314)\], and datasets for table recognition and semantic parsing \[[https://www.semanticscholar.org/paper/bff7592f28354b3be632f4bf678b622f765a2b8d](https://www.semanticscholar.org/paper/bff7592f28354b3be632f4bf678b622f765a2b8d)\]. However, few efforts have tackled the combination of NL constraints with query tables as in nlcTD, motivating the development of comprehensive benchmarks and novel methods to address this emerging research area.
