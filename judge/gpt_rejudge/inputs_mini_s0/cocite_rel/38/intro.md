## Related Works

Memory bandwidth regulation and cache partitioning are critical techniques for enhancing predictability in real-time multi-core systems, primarily by mitigating interference arising from shared hardware resources such as caches and DRAM controllers \[[1903.00999](http://arxiv.org/abs/1903.00999)\]. These techniques are often combined with partitioned scheduling to allocate tasks and resources to cores in a way that ensures bounded execution times, as task performance heavily depends on the quality and quantity of allocated resources \[[1903.00999](http://arxiv.org/abs/1903.00999)\]. The challenge lies in co-allocating tasks and hardware resources effectively to meet real-time guarantees while optimizing resource utilization.

Several studies have addressed resource partitioning and task scheduling for real-time systems. Cache partitioning approaches, such as cache coloring and set partitioning, have been shown to reduce cache interference among tasks, improving timing predictability \[[https://www.semanticscholar.org/paper/dbd4eb5033815003e7f6519fd66e43e5fc297075](https://www.semanticscholar.org/paper/dbd4eb5033815003e7f6519fd66e43e5fc297075)\]\[[https://www.semanticscholar.org/paper/43cc4d0a998b9aa361264e5fc786c738a62382f1](https://www.semanticscholar.org/paper/43cc4d0a998b9aa361264e5fc786c738a62382f1)\]. However, cache coloring alone faces limitations due to memory fragmentation and under-utilization, which recent work has begun to tackle by introducing novel hardware-software solutions like Programmable Logic In-the-Middle (PLIM) that enable fine-grained control of memory transactions, facilitating advanced cache management strategies such as Cache Bleaching \[[https://www.semanticscholar.org/paper/dbd4eb5033815003e7f6519fd66e43e5fc297075](https://www.semanticscholar.org/paper/dbd4eb5033815003e7f6519fd66e43e5fc297075)\].

Memory bandwidth regulation frameworks like MemGuard provide efficient isolation by dynamically throttling memory access per core, ensuring that tasks do not exceed their allocated bandwidth budgets \[[https://www.semanticscholar.org/paper/bbebaeb1b00fdcde2aeb192543835d3ec1518f8d](https://www.semanticscholar.org/paper/bbebaeb1b00fdcde2aeb192543835d3ec1518f8d)\]\[[1903.00999](http://arxiv.org/abs/1903.00999)\]. This approach has been integrated into real-time scheduling frameworks to enforce strict access limits, reducing worst-case memory interference and enhancing schedulability guarantees. Techniques combining memory bandwidth regulation with task scheduling have demonstrated improvements in system predictability, especially when coupled with gang scheduling policies that serialize task executions to avoid contention \[[1903.00999](http://arxiv.org/abs/1903.00999)\].

Bounding worst-case memory interference has been another focus area, particularly in Commercial Off-The-Shelf (COTS) multi-core systems where unpredictable DRAM controller behavior and bank conflicts can cause substantial delays \[[https://www.semanticscholar.org/paper/afca4afaaaa543a1da02b266e9b2ac46eb94793b](https://www.semanticscholar.org/paper/afca4afaaaa543a1da02b266e9b2ac46eb94793b)\]. Modeling DRAM resources such as banks, buses, and controllers enables tighter upper bounds on interference delays, which can be further reduced through DRAM bank partitioning strategies \[[https://www.semanticscholar.org/paper/afca4afaaaa543a1da02b266e9b2ac46eb94793b](https://www.semanticscholar.org/paper/afca4afaaaa543a1da02b266e9b2ac46eb94793b)\]\[[https://www.semanticscholar.org/paper/6e925ae85e385ac0e8810441d84be97c079f6b22](https://www.semanticscholar.org/paper/6e925ae85e385ac0e8810441d84be97c079f6b22)\]. PALLOC, a DRAM bank-aware memory allocator, exemplifies such efforts by allocating memory considering bank-level conflicts to improve performance isolation \[[https://www.semanticscholar.org/paper/6e925ae85e385ac0e8810441d84be97c079f6b22](https://www.semanticscholar.org/paper/6e925ae85e385ac0e8810441d84be97c079f6b22)\].

Optimization-based co-allocation of tasks and resources has been explored via mixed-integer linear programming (MILP) and heuristic algorithms. Prior work has proposed 0-1 integer linear programming formulations for task-resource allocation problems, enabling exact but computationally expensive solutions \[[https://www.semanticscholar.org/paper/abbd6f8840092bd8e4e3684d3297e1b707abdc5d](https://www.semanticscholar.org/paper/abbd6f8840092bd8e4e3684d3297e1b707abdc5d)\]\[[https://www.semanticscholar.org/paper/d5336fd2234f431f554fc5d878503a04a27e366e](https://www.semanticscholar.org/paper/d5336fd2234f431f554fc5d878503a04a27e366e)\]. To address scalability, multi-objective heuristics employing Pareto-pruned searches and knapsack problem solvers have been introduced, balancing resource usage and schedulability under preemptive EDF scheduling policies \[[https://www.semanticscholar.org/paper/d5336fd2234f431f554fc5d878503a04a27e366e](https://www.semanticscholar.org/paper/d5336fd2234f431f554fc5d878503a04a27e366e)\]. Such multi-layer frameworks allow exploring a wide solution space efficiently while guaranteeing real-time constraints.

Real-time gang scheduling frameworks enforce exclusive execution of parallel real-time tasks ("gangs") to minimize interference and simplify worst-case execution time (WCET) analysis \[[1903.00999](http://arxiv.org/abs/1903.00999)\]. Integrating memory bandwidth throttling with gang scheduling permits safe co-execution of best-effort tasks on idle cores without violating real-time guarantees, enhancing system utilization without sacrificing predictability \[[1903.00999](http://arxiv.org/abs/1903.00999)\].

Profiling-based approaches like E-WarP enable workload-aware memory bandwidth management by predicting application memory demands and saturation points, forming the basis for dynamic and safe consolidation of workloads on multi-core platforms \[[https://www.semanticscholar.org/paper/f71c848137ac1398f84e6ab7d896641f801ca192](https://www.semanticscholar.org/paper/f71c848137ac1398f84e6ab7d896641f801ca192)\]. This predictive approach complements static resource allocation techniques by adapting to runtime behavior and maintaining performance isolation.

In sum, the existing body of work highlights the necessity of combining cache partitioning, memory bandwidth regulation, and task scheduling with optimization and hardware-aware techniques to ensure predictable real-time performance on multi-core systems. Recent advances demonstrate that integrating fine-grained resource control, model-based interference bounding, and multi-objective optimization heuristics leads to improved schedulability and resource efficiency in complex embedded platforms \[[https://www.semanticscholar.org/paper/bbebaeb1b00fdcde2aeb192543835d3ec1518f8d](https://www.semanticscholar.org/paper/bbebaeb1b00fdcde2aeb192543835d3ec1518f8d)\]\[[https://www.semanticscholar.org/paper/dbd4eb5033815003e7f6519fd66e43e5fc297075](https://www.semanticscholar.org/paper/dbd4eb5033815003e7f6519fd66e43e5fc297075)\]\[[https://www.semanticscholar.org/paper/d5336fd2234f431f554fc5d878503a04a27e366e](https://www.semanticscholar.org/paper/d5336fd2234f431f554fc5d878503a04a27e366e)\]\[[https://www.semanticscholar.org/paper/6e925ae85e385ac0e8810441d84be97c079f6b22](https://www.semanticscholar.org/paper/6e925ae85e385ac0e8810441d84be97c079f6b22)\]\[[https://www.semanticscholar.org/paper/afca4afaaaa543a1da02b266e9b2ac46eb94793b](https://www.semanticscholar.org/paper/afca4afaaaa543a1da02b266e9b2ac46eb94793b)\]\[[https://www.semanticscholar.org/paper/f71c848137ac1398f84e6ab7d896641f801ca192](https://www.semanticscholar.org/paper/f71c848137ac1398f84e6ab7d896641f801ca192)\]\[[1903.00999](http://arxiv.org/abs/1903.00999)\].
