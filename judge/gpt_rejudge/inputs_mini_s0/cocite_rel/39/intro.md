## Related Works

De novo genome assembly reconstructs genomes from sequencing reads without a reference, a process challenged by data scale, complexity, and error rates \[[https://www.semanticscholar.org/paper/7279acd9c61a8de019ea2d55d23124dfbb6b5269](https://www.semanticscholar.org/paper/7279acd9c61a8de019ea2d55d23124dfbb6b5269)\]. Early assemblers predominantly used string-based methods such as overlap-layout-consensus (OLC) for longer reads or de Bruijn graphs for short reads, with each approach optimized for specific read lengths and genome sizes \[[https://www.semanticscholar.org/paper/7279acd9c61a8de019ea2d55d23124dfbb6b5269](https://www.semanticscholar.org/paper/7279acd9c61a8de019ea2d55d23124dfbb6b5269)\]. For example, string-based and OLC assemblers excel with very short or longer reads for small genomes, while de Bruijn graph-based assemblers better handle large datasets exceeding hundreds of millions of short reads \[[https://www.semanticscholar.org/paper/7279acd9c61a8de019ea2d55d23124dfbb6b5269](https://www.semanticscholar.org/paper/7279acd9c61a8de019ea2d55d23124dfbb6b5269)\]. However, these methods often demand substantial memory and computational resources, particularly when scaling to large eukaryotic genomes \[[https://www.semanticscholar.org/paper/7bf2f1c55f90e11a4d1df4dd608ac621a08f8b33](https://www.semanticscholar.org/paper/7bf2f1c55f90e11a4d1df4dd608ac621a08f8b33)\]\[[1008.2555](http://arxiv.org/abs/1008.2555)\].

Distributed-memory parallelism has been extensively explored to address scalability and memory constraints in large genome assembly. Assemblers like PASHA employ hybrid parallelism combining multi-threading and distributed computing to assemble large genomes efficiently with modest hardware, demonstrating competitive quality and reduced runtime compared to predecessors like ABySS and SOAPdenovo \[[https://www.semanticscholar.org/paper/7bf2f1c55f90e11a4d1df4dd608ac621a08f8b33](https://www.semanticscholar.org/paper/7bf2f1c55f90e11a4d1df4dd608ac621a08f8b33)\]. Similarly, SWAP-Assembler implements a Small World Asynchronous Parallel (SWAP) model that scales efficiently to thousands of cores, producing high-quality contigs with improved N50 sizes and low error rates on large datasets \[[https://www.semanticscholar.org/paper/fe8d86bc5520b5049104ff58ee7e980982816ebf](https://www.semanticscholar.org/paper/fe8d86bc5520b5049104ff58ee7e980982816ebf)\]. HipMER further exemplifies extreme-scale de novo assembly through distributed-memory parallelism, enabling processing of massive sequencing data \[[https://www.semanticscholar.org/paper/eff7a7b6916b7584b2184b3aa30601d158648be8](https://www.semanticscholar.org/paper/eff7a7b6916b7584b2184b3aa30601d158648be8)\]. These distributed approaches improve throughput and memory usage but still face limitations due to irregular data dependencies and high memory footprints inherent in genome assembly graphs \[[2010.10055](http://arxiv.org/abs/2010.10055)\].

Long-read sequencing technologies such as PacBio and Oxford Nanopore have revolutionized assembly by providing reads exceeding 10 kb in length, simplifying assembly graph complexity and improving contiguity \[[https://www.semanticscholar.org/paper/2b59fd18ada769ef76fb7fcc7382f063791abfab](https://www.semanticscholar.org/paper/2b59fd18ada769ef76fb7fcc7382f063791abfab)\]\[[https://www.semanticscholar.org/paper/618d82a202bb0408e388eba250c66c8a90700c81](https://www.semanticscholar.org/paper/618d82a202bb0408e388eba250c66c8a90700c81)\]. However, their high error rates (5–40%) require sophisticated error correction and overlap detection algorithms. Hybrid error correction methods combine high-accuracy short reads with long reads to produce highly contiguous and accurate assemblies, as demonstrated by Nanocorr for Oxford Nanopore data \[[https://www.semanticscholar.org/paper/e18b489f02530ff144db28cb44537173e4296616](https://www.semanticscholar.org/paper/e18b489f02530ff144db28cb44537173e4296616)\]. Canu, a successor of Celera Assembler, incorporates adaptive k-mer weighting and repeat separation to achieve near-complete microbial and eukaryotic assemblies with improved continuity and reduced runtime \[[https://www.semanticscholar.org/paper/2b59fd18ada769ef76fb7fcc7382f063791abfab](https://www.semanticscholar.org/paper/2b59fd18ada769ef76fb7fcc7382f063791abfab)\]. Minimap and miniasm offer extremely fast mapping and assembly of noisy long reads without error correction, providing rapid but less accurate assemblies \[[1512.01801](http://arxiv.org/abs/1512.01801)\]. Minimap2 extends these capabilities with efficient pairwise alignment for ultra-long reads and large reference sequences \[[1708.01492](http://arxiv.org/abs/1708.01492)\]. BELLA advances overlap detection by using probabilistic models and sparse matrix multiplication to efficiently identify reliable k-mers, improving overlap precision and recall for noisy long reads \[[https://www.semanticscholar.org/paper/f27decfab0389e2003e7ca66260b34eb3c1b8827](https://www.semanticscholar.org/paper/f27decfab0389e2003e7ca66260b34eb3c1b8827)\].

Graph representation and memory efficiency have also been critical research directions. Succinct data structures compress de Bruijn graphs to reduce memory use while maintaining scalability and accuracy, enabling assembly on commodity servers despite sequencing errors \[[1008.2555](http://arxiv.org/abs/1008.2555)\]. Bloom filter–based k-mer counting techniques reduce memory overhead by probabilistically tracking k-mer occurrences, which is essential for error correction and graph construction in large datasets \[[https://www.semanticscholar.org/paper/41cdc268d9ec5595f40ebf2e457f3f7f87a503de](https://www.semanticscholar.org/paper/41cdc268d9ec5595f40ebf2e457f3f7f87a503de)\]. Additionally, MHAP uses locality-sensitive hashing for efficient overlap detection of noisy long reads, enabling reference-grade assemblies of large genomes with high accuracy \[[https://www.semanticscholar.org/paper/618d82a202bb0408e388eba250c66c8a90700c81](https://www.semanticscholar.org/paper/618d82a202bb0408e388eba250c66c8a90700c81)\].

Recent developments focus on communication-efficient parallel algorithms to further address memory-bound and irregular data access challenges. diBELLA 2D introduces distributed-memory sparse matrix operations for overlap detection and layout simplification, achieving near-linear scaling and significant speedups on human and C. elegans genomes \[[2010.10055](http://arxiv.org/abs/2010.10055)\]. Similarly, distributed algorithms for genome similarity computations leverage sparse matrices to scale to massive datasets with reduced communication overhead, exemplified by tools like GenomeAtScale and PASTIS for genomic and protein sequence analysis \[[1911.04200](http://arxiv.org/abs/1911.04200)\]\[[2009.14467](http://arxiv.org/abs/2009.14467)\].

Hardware acceleration efforts remain relatively nascent but promising. While some custom hardware solutions have targeted genomic data processing, existing approaches often address specific tasks rather than the full complexity of de novo assembly \[[https://www.semanticscholar.org/paper/eff7a7b6916b7584b2184b3aa30601d158648be8](https://www.semanticscholar.org/paper/eff7a7b6916b7584b2184b3aa30601d158648be8)\]. The high irregularity and dynamic nature of genome assembly data structures pose challenges for conventional hardware accelerators, motivating designs like near-memory processing architectures to alleviate memory bottlenecks and improve parallelism.

In summary, state-of-the-art de novo assemblers leverage sophisticated algorithms and distributed-memory parallelism to handle large and complex datasets, with long-read technologies further enhancing assembly contiguity and accuracy \[[https://www.semanticscholar.org/paper/7279acd9c61a8de019ea2d55d23124dfbb6b5269](https://www.semanticscholar.org/paper/7279acd9c61a8de019ea2d55d23124dfbb6b5269)\]\[[https://www.semanticscholar.org/paper/2b59fd18ada769ef76fb7fcc7382f063791abfab](https://www.semanticscholar.org/paper/2b59fd18ada769ef76fb7fcc7382f063791abfab)\]\[[https://www.semanticscholar.org/paper/7bf2f1c55f90e11a4d1df4dd608ac621a08f8b33](https://www.semanticscholar.org/paper/7bf2f1c55f90e11a4d1df4dd608ac621a08f8b33)\]\[[https://www.semanticscholar.org/paper/618d82a202bb0408e388eba250c66c8a90700c81](https://www.semanticscholar.org/paper/618d82a202bb0408e388eba250c66c8a90700c81)\]\[[2010.10055](http://arxiv.org/abs/2010.10055)\]. Memory-efficient data structures and communication-optimized distributed algorithms contribute to scalability and performance \[[2010.10055](http://arxiv.org/abs/2010.10055)\]\[[1008.2555](http://arxiv.org/abs/1008.2555)\]\[[https://www.semanticscholar.org/paper/41cdc268d9ec5595f40ebf2e457f3f7f87a503de](https://www.semanticscholar.org/paper/41cdc268d9ec5595f40ebf2e457f3f7f87a503de)\]. Despite these advances, challenges remain in reducing the memory footprint, managing irregular data patterns, and fully exploiting hardware capabilities, motivating novel hardware-software co-design approaches such as near-memory processing to accelerate scalable de novo assembly.
