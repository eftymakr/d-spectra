## Related Works

Personalized outfit generation and recommendation have garnered significant attention due to the increasing demand for intelligent fashion systems that provide users with compatible and personalized outfit suggestions. Early works focused primarily on modeling compatibility among fashion items, often relying on visual features or co-purchase data to learn cross-category relationships. For instance, learning latent compatibility embeddings via Siamese networks using heterogeneous dyadic co-occurrence data demonstrated the importance of capturing cross-category visual compatibility beyond simple similarity \[[1509.07473](http://arxiv.org/abs/1509.07473)\]. Similarly, neural network approaches integrating domain knowledge through attentive knowledge distillation have advanced complementary clothing matching by leveraging fuzzy fashion rules \[[1805.00313](http://arxiv.org/abs/1805.00313)\].

Deep learning architectures have been widely adopted for outfit compatibility and personalized recommendation. FashionNet proposed a two-stage approach combining feature extraction by convolutional networks and compatibility modeling with fully connected layers, using fine-tuning to embed personal preferences effectively \[[1810.02443](http://arxiv.org/abs/1810.02443)\]. OutfitNet further introduced a multiple-instance learning framework with attention mechanisms to capture user-specific preferences and item relevancy within an outfit \[[https://www.semanticscholar.org/paper/762ec45448e915142f355848265d10dd55ab470f](https://www.semanticscholar.org/paper/762ec45448e915142f355848265d10dd55ab470f)\]. Graph-based models, such as the Node-wise Graph Neural Network (NGNN), represent outfits as graphs of category nodes and model item interactions for enhanced compatibility prediction and fill-in-the-blank tasks \[[1902.08009](http://arxiv.org/abs/1902.08009)\]. More recently, Hierarchical Fashion Graph Networks (HFGN) jointly model user, outfit, and item relationships to improve personalized outfit recommendation through embedding propagation on hierarchical graphs \[[2005.12566](http://arxiv.org/abs/2005.12566)\].

Generative approaches have also been explored extensively to create novel fashion items or outfits. Methods combining compatibility learning with generative adversarial networks (GANs) have enabled personalized fashion design by synthesizing items conditioned on user preferences and compatibility constraints \[[https://www.semanticscholar.org/paper/ca3ad34ff2652cd922c3476514a758674bc7e76b](https://www.semanticscholar.org/paper/ca3ad34ff2652cd922c3476514a758674bc7e76b)\]\[[1711.02231](http://arxiv.org/abs/1711.02231)\]. Bidirectional LSTM models have been employed to learn sequential compatibility within outfits, incorporating visual-semantic embeddings to regularize the generation process \[[1707.05691](http://arxiv.org/abs/1707.05691)\]. Outfit generation frameworks have integrated style extraction modules using autoencoders or topic models to capture global outfit style features, allowing controllable style-coherent outfit synthesis \[[1807.03133](http://arxiv.org/abs/1807.03133)\]\[[1707.03376](http://arxiv.org/abs/1707.03376)\]\[[1906.07273](http://arxiv.org/abs/1906.07273)\].

The challenge of personalization, especially with limited user data, has driven innovations in user modeling. Personalized Outfit Generation (POG) connects user preferences on individual items and outfits using Transformer architectures and large-scale user behavior data, enabling industrial-scale personalized outfit recommendations \[[1905.01866](http://arxiv.org/abs/1905.01866)\]. To address sparse user interactions, methods such as learnable anchors represent user preferences as latent vectors in the outfit embedding space, facilitating new user profiling with limited historical data \[[https://www.semanticscholar.org/paper/44cfb82fb3703f7ef2949f1cd38733643ce93328](https://www.semanticscholar.org/paper/44cfb82fb3703f7ef2949f1cd38733643ce93328)\]. Attentive Attribute-Aware Fashion Knowledge Graphs ($A^3$-FKG) employ two-level attention mechanisms to capture fine-grained user preferences on outfit- and item-level attributes, enhancing outfit preference prediction \[[https://www.semanticscholar.org/paper/b5f488dd55024f0db2cabb73b055002b5d995be9](https://www.semanticscholar.org/paper/b5f488dd55024f0db2cabb73b055002b5d995be9)\].

Multi-expert feedback and multi-perspective evaluation have been proposed to improve the quality, compatibility, and personalization of generated outfits. Such frameworks leverage diverse evaluation criteria to generate more comprehensive and objective feedback signals for model fine-tuning, mitigating reliance on manually designed reward functions \[[1712.02662](http://arxiv.org/abs/1712.02662)\]\[[https://www.semanticscholar.org/paper/396b400370ec78275b239ded03c1eba9d073f5eb](https://www.semanticscholar.org/paper/396b400370ec78275b239ded03c1eba9d073f5eb)\]. The integration of multimodal data, including images and textual descriptions, has enhanced outfit generation models by aligning item representations with thematic or user-specific queries, thereby improving coherence and personalization \[[1906.07273](http://arxiv.org/abs/1906.07273)\]\[[2106.04128](http://arxiv.org/abs/2106.04128)\].

Complementing these developments, compatibility family learning introduces multiple compatible prototypes per item to capture diverse compatibility notions and asymmetry, supporting both recommendation and generation tasks. This approach employs a Projected Compatibility Distance function and GAN-based prototype visualization to improve diversity and interpretability in compatibility modeling \[[1712.01262](http://arxiv.org/abs/1712.01262)\]. Style2Vec and similar embedding methods learn latent style features from co-occurrence in style sets, enabling better style classification and analogy reasoning in fashion items \[[1708.04014](http://arxiv.org/abs/1708.04014)\].

Lastly, capsule wardrobe creation focuses on assembling minimal, versatile, and compatible garment sets tailored to user profiles. Optimization-based methods incorporate both garment compatibility and user modeling, including body shape and consumption habits, to personalize capsule wardrobes effectively \[[1712.02662](http://arxiv.org/abs/1712.02662)\]\[[https://www.semanticscholar.org/paper/396b400370ec78275b239ded03c1eba9d073f5eb](https://www.semanticscholar.org/paper/396b400370ec78275b239ded03c1eba9d073f5eb)\].

In summary, personalized outfit generation research has evolved from compatibility modeling based on visual and behavioral data to sophisticated generative frameworks that incorporate user preference modeling, multi-expert feedback, and multimodal input. These advances collectively address challenges such as diversity, cold-start personalization, and comprehensive evaluation, laying a robust foundation for methods like FashionDPO that employ direct preference optimization to refine pre-trained fashion generative models without task-specific reward design.
