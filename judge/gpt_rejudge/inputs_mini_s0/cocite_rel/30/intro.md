## Related Works

The complexity and correctness of testing database transaction isolation have been core concerns in distributed systems research. It is well-established that testing strong isolation levels, notably serializability, is NP-complete, which poses significant challenges for scalable verification \[[1908.04509](http://arxiv.org/abs/1908.04509)\]\[[1806.08416](http://arxiv.org/abs/1806.08416)\]. This computational hardness has driven interest in weaker isolation levels, such as Read Committed (RC), Read Atomic (RA), and Causal Consistency (CC), which offer favorable trade-offs between performance, availability, and isolation guarantees \[[1302.0309](http://arxiv.org/abs/1302.0309)\]\[[1908.04509](http://arxiv.org/abs/1908.04509)\]. These weaker models are common in modern, highly available distributed databases that prioritize low latency and partition tolerance over strict serializability \[[1302.0309](http://arxiv.org/abs/1302.0309)\].

Early approaches to testing weak isolation focused on characterizing transaction histories using dependency graphs and abstract executions. Tools like Elle and Viper leverage dependency graph representations to detect anomalies under various isolation levels, including snapshot isolation (SI) and its variants, while aiming for soundness and completeness \[[2003.10554](http://arxiv.org/abs/2003.10554)\]\[[https://www.semanticscholar.org/paper/9f96a48d2bc0e77004b32960495685be6c301c63](https://www.semanticscholar.org/paper/9f96a48d2bc0e77004b32960495685be6c301c63)\]. However, despite optimizations such as heuristic pruning and novel graph structures (e.g., BC-polygraphs), these techniques still entail polynomial-time complexity with substantial overheads, limiting their applicability to moderate workload sizes \[[https://www.semanticscholar.org/paper/9f96a48d2bc0e77004b32960495685be6c301c63](https://www.semanticscholar.org/paper/9f96a48d2bc0e77004b32960495685be6c301c63)\]\[[2301.07313](http://arxiv.org/abs/2301.07313)\].

Recent work has emphasized black-box testing frameworks that do not require internal database details, improving practical applicability. PolySI exemplifies this approach by encoding snapshot isolation verification into SMT constraints, enabling efficient and sound anomaly detection across large transaction histories and real-world cloud databases \[[2301.07313](http://arxiv.org/abs/2301.07313)\]. Similarly, IsoVista provides a comprehensive black-box isolation checker covering a range of weak isolation guarantees, combining sound characterizations with visualization tools to aid debugging \[[https://www.semanticscholar.org/paper/4f3081dbb68287f0d9d7bec3e7173e6c8ff035b9](https://www.semanticscholar.org/paper/4f3081dbb68287f0d9d7bec3e7173e6c8ff035b9)\]. These frameworks demonstrate the feasibility of black-box testing but still face challenges scaling to very large workloads due to polynomial complexity and constraint solving costs.

The theoretical foundations of weak isolation testing have been further clarified by complexity analyses. It was shown that certain weak isolation levels—such as RC, RA, and CC—are polynomial-time checkable, while others like SI and serializability remain NP-complete \[[1908.04509](http://arxiv.org/abs/1908.04509)\]. Moreover, fixed-parameter algorithms have been proposed that achieve polynomial runtimes when parameters like the number of client sessions are bounded \[[1908.04509](http://arxiv.org/abs/1908.04509)\]. Such insights have guided the design of more efficient testing algorithms tuned to practical workload characteristics.

Complementing these theoretical advances, tools like MonkeyDB and IsoDiff focus on robustness testing and anomaly debugging under weak isolations. MonkeyDB simulates weak isolation behaviors to systematically test application robustness against subtle concurrency anomalies \[[https://www.semanticscholar.org/paper/615ff2896b52bee2cbfd64ced324106a29b73397](https://www.semanticscholar.org/paper/615ff2896b52bee2cbfd64ced324106a29b73397)\]. IsoDiff aids developers by identifying representative anomaly subsets and reducing false positives through correlation and timing analyses, thereby improving the usability of weak isolation testing in real applications \[[https://www.semanticscholar.org/paper/405ae0ebf74cfbf5f2edec62e2966827dcdc9bef](https://www.semanticscholar.org/paper/405ae0ebf74cfbf5f2edec62e2966827dcdc9bef)\].

Despite these advances, existing testers often suffer from high polynomial complexity—commonly cubic or worse—and substantial runtime on large histories, which restricts their deployment in large-scale production environments \[[https://www.semanticscholar.org/paper/cbe191bda20907994d45bc835d20446968370add](https://www.semanticscholar.org/paper/cbe191bda20907994d45bc835d20446968370add)\]\[[2003.10554](http://arxiv.org/abs/2003.10554)\]. Additionally, some state-of-the-art checkers struggle with complex operations such as predicate queries or require white-box access to internal database states, limiting their generality \[[https://www.semanticscholar.org/paper/04178561c9d8cd42904ed0a836e08e55b84703cf](https://www.semanticscholar.org/paper/04178561c9d8cd42904ed0a836e08e55b84703cf)\].

In summary, the field has seen significant progress from foundational complexity results and dependency graph characterizations to practical black-box tools capable of detecting isolation violations under weak consistency models \[[1302.0309](http://arxiv.org/abs/1302.0309)\]\[[2003.10554](http://arxiv.org/abs/2003.10554)\]\[[1908.04509](http://arxiv.org/abs/1908.04509)\]\[[https://www.semanticscholar.org/paper/9f96a48d2bc0e77004b32960495685be6c301c63](https://www.semanticscholar.org/paper/9f96a48d2bc0e77004b32960495685be6c301c63)\]\[[2301.07313](http://arxiv.org/abs/2301.07313)\]\[[https://www.semanticscholar.org/paper/4f3081dbb68287f0d9d7bec3e7173e6c8ff035b9](https://www.semanticscholar.org/paper/4f3081dbb68287f0d9d7bec3e7173e6c8ff035b9)\]. However, the challenge of achieving both scalability and completeness for large workloads remains open, motivating new approaches that improve asymptotic efficiency and reduce practical runtime without sacrificing soundness or generality.
