## Related Works

The management and recommendation of open-source machine learning (ML) resources have garnered increasing attention with the expansion of platforms like Hugging Face. However, these platforms often lack structured representations that can support advanced information retrieval (IR) tasks such as tracing the evolution of models or recommending relevant datasets. To address these limitations, recent research has explored the construction of knowledge graphs and benchmarking frameworks tailored for ML resources.

One notable direction involves cross-platform recommendation systems that link academic papers with relevant code repositories. The paper2repo system exemplifies this by recommending GitHub repositories related to academic papers using a novel approach that integrates text encoding with constrained graph convolutional networks (GCNs). It leverages distant supervision generated from user interactions on GitHub to automatically learn embeddings for papers and repositories in a shared space, enabling effective matching without manual labeling. This approach outperforms traditional recommendation methods, demonstrating the potential of graph-based techniques in bridging heterogeneous platforms \[[2004.06059](http://arxiv.org/abs/2004.06059)\].

Graph-based methods have also been applied to enrich metadata and improve resource discoverability on GitHub itself. GRETA, for instance, uses graph-based tag assignment to classify repositories, enhancing their organization and searchability within the platform \[[https://doi.org/10.1109/COMPSAC.2016.124](https://doi.org/10.1109/COMPSAC.2016.124)\]. This tagging facilitates better resource recommendation and retrieval by capturing semantic relationships among repositories.

Beyond repository recommendation, knowledge graphs have been developed specifically for machine learning method recommendation. DEKR introduces a description-enhanced knowledge graph that integrates textual descriptions with graph structure to recommend ML methods effectively. Similarly, task-oriented ML and deep learning library recommendations have been addressed through knowledge graphs that model the relationships between tasks, libraries, and methods, enabling more precise and context-aware suggestions \[[https://doi.org/10.1145/3404835.3462900](https://doi.org/10.1145/3404835.3462900)\]\[[https://doi.org/10.1109/TSE.2023.3285280](https://doi.org/10.1109/TSE.2023.3285280)\].

The construction of large-scale knowledge graphs capturing domain-specific relations and attributes is critical for advancing ML resource management. HuggingKG represents a pioneering effort in this direction, building a knowledge graph from the Hugging Face community with millions of nodes and edges to encode rich semantic relationships among models, datasets, and other resources. This structured representation supports various IR tasks, including resource recommendation, classification, and tracing model evolution, which traditional platforms lack \[[2004.06059](http://arxiv.org/abs/2004.06059)\].

In parallel, benchmarking frameworks such as HuggingBench provide multi-task test collections to evaluate IR methods on these knowledge graphs, facilitating rigorous assessment and fostering advancements in resource sharing and management. The integration of knowledge graphs and benchmarking aligns with broader trends in ML research emphasizing structured data, interpretability, and reproducibility.

Collectively, these works underscore the importance of graph-based representations and cross-platform integration for managing the growing complexity of open-source ML resources. They highlight methodologies ranging from distant supervision for embedding learning, graph-based tag assignment, to enhanced knowledge graphs for method and library recommendation. These foundations inform the development of systems like HuggingKG and HuggingBench, which address existing gaps by providing structured, scalable, and evaluable resource management solutions \[[2004.06059](http://arxiv.org/abs/2004.06059)\]\[[https://doi.org/10.1145/3404835.3462900](https://doi.org/10.1145/3404835.3462900)\]\[[https://doi.org/10.1109/TSE.2023.3285280](https://doi.org/10.1109/TSE.2023.3285280)\]\[[https://doi.org/10.1109/COMPSAC.2016.124](https://doi.org/10.1109/COMPSAC.2016.124)\].
