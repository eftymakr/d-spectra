## Related Works

Conversational recommendation systems (CRSs) have emerged as a promising paradigm to engage users in multi-turn dialogues that elicit preferences and provide personalized recommendations. A central challenge in CRSs is accurately capturing complex, multifaceted user preferences through interactions, while minimizing user burden to maintain a positive experience \[[2007.00194](http://arxiv.org/abs/2007.00194)\]. Traditional recommendation systems typically rely on static user-item interaction histories, which limit their ability to dynamically adapt to evolving user preferences. Conversational approaches address this by explicitly querying users about preferred item attributes, enhancing personalization \[[2007.00194](http://arxiv.org/abs/2007.00194)\].

Early CRS methods often utilized latent user representations updated implicitly by attribute feedback, but recent advances emphasize explicit modeling of user preferences through graph-based reasoning. For example, Conversational Path Reasoning (CPR) frameworks model recommendation as an interactive path traversal on a graph of attributes and items, using user feedback to prune irrelevant candidates and improve recommendation accuracy \[[2007.00194](http://arxiv.org/abs/2007.00194)\]. Such graph-structured approaches have demonstrated significant improvements over prior state-of-the-art methods on multi-turn recommendation tasks, particularly as the number of attributes increases.

Addressing the cold-start problem, in which user preference data is scarce, recent work has proposed unifying attributes and items within a single action space to better balance exploration and exploitation. The Conversational Thompson Sampling (ConTS) model integrates item attribute queries and item recommendations as interchangeable actions, optimizing the choice of interaction via Thompson Sampling. This approach outperforms bandit-based baselines that treat attributes and items separately and rely on hand-crafted decision functions \[[2005.12979](http://arxiv.org/abs/2005.12979)\]. Holistic modeling of attributes and items enables more natural and efficient preference elicitation, particularly for new users.

The long-tail distribution of items poses another significant challenge in CRS research. Many datasets exhibit a heavy skew toward popular items, resulting in recommendation systems biased toward frequent items and reduced diversity. To combat this, frameworks such as LOT-CRS simulate balanced conversational datasets that evenly cover long-tail items. They utilize pre-training tasks focused on understanding simulated conversations involving rare items and adopt retrieval-augmented fine-tuning with label smoothing to enhance long-tail recommendation performance \[[2307.1165](http://arxiv.org/abs/2307.11650)\]. These advances improve diversity and user satisfaction by encouraging the system to recommend less frequent, but potentially relevant, items.

Simulated users have been explored as a means to automate and evaluate CRS interactions, reducing reliance on costly human participants. Prior works have employed user simulators to diagnose conversational breakdowns and to test system robustness across multi-turn dialogues \[[2307.1165](http://arxiv.org/abs/2307.11650)\]. However, many simulators rely on hand-crafted rules or implicit feedback signals, limiting their ability to capture complex user preferences or provide fine-grained critiques.

Inspired by advances in reward modeling and verification in language reasoning tasks, recent research has incorporated generative reward models to improve interaction quality. Generative verifiers trained via next-token prediction objectives have demonstrated superior performance over discriminative classifiers in selecting correct solutions in multi-step reasoning tasks, leveraging chain-of-thought reasoning and benefiting from seamless integration with pretrained language models \[[2408.1524](http://arxiv.org/abs/2408.15240)\]. Similarly, hybrid approaches combining reinforcement learning from human feedback (RLHF) and reinforcement learning from AI feedback (RLAIF) use generative reward models to produce synthetic preference labels aligned closely with human judgments, enhancing model robustness and generalization \[[2410.12832](http://arxiv.org/abs/2410.12832)\]. These methods suggest promising directions for simulating nuanced user feedback in CRSs.

Overall, the integration of graph-based explicit attribute reasoning \[[2007.00194](http://arxiv.org/abs/2007.00194)\], unified exploration-exploitation frameworks for attributes and items \[[2005.12979](http://arxiv.org/abs/2005.12979)\], long-tail item handling through balanced data simulation \[[2307.1165](http://arxiv.org/abs/2307.11650)\], and generative reward modeling for nuanced feedback \[[2410.12832](http://arxiv.org/abs/2410.12832)\]\[[2408.1524](http://arxiv.org/abs/2408.15240)\] collectively inform the design of advanced simulated user models for conversational recommendation. Such simulated users can provide both coarse-grained item scoring and fine-grained attribute critiques in a unified instruction-based format, enabling automatic multi-turn interaction that balances effectiveness and user experience. This approach draws on prior successes in reward-guided search and verification in complex reasoning tasks to improve candidate ranking and recommendation quality efficiently.
