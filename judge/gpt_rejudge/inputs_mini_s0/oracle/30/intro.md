## Related Works

The complexity of testing transactional consistency in databases has been a central topic in database theory and practice. Early foundational results established that verifying strong isolation levels such as serializability is NP-complete, highlighting the computational challenges involved in ensuring strong correctness guarantees \[[1908.04509](http://arxiv.org/abs/1908.04509)\]. This hardness has motivated research into weaker isolation levels, which offer a more favorable trade-off between performance and consistency and can often be checked more efficiently.

Recent work has shown that several weak isolation levels, including Read Committed (RC), Read Atomic (RA), and Causal Consistency (CC), admit polynomial-time verification algorithms \[[1908.04509](http://arxiv.org/abs/1908.04509)\]. These findings are significant because they enable the development of scalable testers for weak isolation, which are crucial for identifying isolation bugs in large-scale production databases. However, despite these polynomial-time results, existing testers typically have high-degree polynomial complexity, often limiting their practical scalability to moderate-sized workloads \[[1908.04509](http://arxiv.org/abs/1908.04509)\]\[[2301.07313](http://arxiv.org/abs/2301.07313)\]\[[1611.00580](http://arxiv.org/abs/1611.00580)\].

Snapshot Isolation (SI), a widely used weak isolation level, has received particular attention due to its balance between performance and anomaly prevention. However, SI anomalies have been detected in production cloud databases that claim to provide SI, revealing subtle bugs that compromise data integrity \[[2301.07313](http://arxiv.org/abs/2301.07313)\]. PolySI, a black-box checker for SI, utilizes a novel characterization of SI based on generalized polygraphs combined with SMT solvers to efficiently detect violations and generate counterexamples. This approach outperforms prior black-box checkers and scales to large workloads, demonstrating the feasibility and importance of efficient black-box testing for weak isolation \[[2301.07313](http://arxiv.org/abs/2301.07313)\].

Causal consistency, which ensures operations are observed respecting their causal dependencies, is particularly relevant in distributed systems. Testing a single execution for causal consistency is NP-complete, while verifying causal consistency over all executions of an implementation is undecidable in general \[[1611.00580](http://arxiv.org/abs/1611.00580)\]. Nonetheless, under the realistic assumption of data independence, these negative results can be circumvented, enabling practical verification methods for causal consistency in key-value stores and similar systems \[[1611.00580](http://arxiv.org/abs/1611.00580)\]\[[2311.04302](http://arxiv.org/abs/2311.04302)\].

Beyond database transactions, consistency checking under various weak-memory models, such as those used in programming languages and hardware architectures, shares similar complexity challenges. Recent research has revealed that consistency testing under many popular weak-memory models remains NP-complete even when the number of threads, memory locations, and values is bounded, indicating intrinsic hardness that resists parameterized algorithms \[[2311.04302](http://arxiv.org/abs/2311.04302)\]. However, some memory models like Sequential Consistency (SC), x86-TSO, and PSO admit polynomial-time bounded consistency testing, delineating a complexity landscape relevant to concurrency testing and model checking \[[2311.04302](http://arxiv.org/abs/2311.04302)\]\[[2304.03714](http://arxiv.org/abs/2304.03714)\].

For C11-style memory models, which capture nuanced concurrency semantics in C and C++, consistency checking has been extensively studied with a focus on the reads-from relation. This problem is central to applications such as specification testing and dynamic analysis. Recent advances provide nearly linear-time algorithms for certain C11 memory model variants while establishing NP-hardness for others, thereby offering a fine-grained understanding of the complexity landscape. Implementations of these algorithms in tools like TruSt and C11Tester have demonstrated significant practical improvements in efficiency \[[2304.03714](http://arxiv.org/abs/2304.03714)\].

Overall, these works collectively advance the theoretical and practical understanding of isolation and consistency testing. They reveal that while strong isolation testing is computationally intractable, many weak isolation levels are amenable to efficient verification, albeit often with substantial polynomial overheads. Recent breakthroughs in algorithm design and black-box testing frameworks, such as PolySI, have improved scalability and usability, yet challenges remain in further reducing complexity to handle very large workloads typical of modern distributed and cloud databases \[[1908.04509](http://arxiv.org/abs/1908.04509)\]\[[2301.07313](http://arxiv.org/abs/2301.07313)\]\[[1611.00580](http://arxiv.org/abs/1611.00580)\]\[[2311.04302](http://arxiv.org/abs/2311.04302)\]\[[2304.03714](http://arxiv.org/abs/2304.03714)\].
