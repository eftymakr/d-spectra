## Related Works

Natural language-driven table discovery is a critical task that involves retrieving relevant tables from vast repositories in response to user queries expressed in natural language. Traditional methods predominantly adopt a dense vector search pipeline, decomposed into separate stages of table representation, indexing, and search. While effective to some extent, these multi-stage pipelines suffer from accumulated errors during table representation and indexing, which negatively impact downstream retrieval accuracy. Moreover, the decoupled nature of indexing and retrieval limits deep semantic interaction between queries and tables, constraining further improvements in accuracy \[[2212.07588](http://arxiv.org/abs/2212.07588)\]\[[2005.09207](http://arxiv.org/abs/2005.09207)\].

Recent advances have leveraged deep contextualized language models such as BERT to encode tables more effectively for retrieval tasks. For example, approaches that carefully encode table content while respecting structural constraints have shown improved ad hoc table retrieval performance by jointly training semantic features with pretrained models \[[2005.09207](http://arxiv.org/abs/2005.09207)\]\[[2103.12011](http://arxiv.org/abs/2103.12011)\]. Similarly, frameworks like TAPAS extend BERT to handle weakly supervised question answering over tables by incorporating table structure directly into the encoder, enabling better alignment of natural language questions and tabular data \[[2004.02349](http://arxiv.org/abs/2004.02349)\].

To address the challenge of semantic alignment and richer query-table interaction, embedding-based methods have been enhanced with contrastive learning and sophisticated column or graph representations. Starmie, for instance, employs contrastive pretraining of column encoders with pre-trained language models and uses efficient approximate nearest neighbor search (HNSW indexing) to scale dataset discovery from data lakes, outperforming prior union search methods both in accuracy and speed \[[2210.01922](http://arxiv.org/abs/2210.01922)\]. Additionally, graph-based models such as GTR transform tables into multi-granular graphs (cells, rows, columns) and utilize graph transformers to capture complex table layouts and dependencies, further improving retrieval generalization and robustness \[[2105.01736](http://arxiv.org/abs/2105.01736)\].

Beyond representation learning, recent works have explored unifying indexing and retrieval in a single differentiable model. Differentiable Search Index (DSI) approaches encode mappings from queries to document or table identifiers directly within a transformer’s parameters, thereby eliminating separate index structures and reducing cumulative errors \[[2202.06991](http://arxiv.org/abs/2202.06991)\]\[[2206.10128](http://arxiv.org/abs/2206.10128)\]. Notably, DSI models benefit from synthetic query generation to bridge the distribution gap between indexing and retrieval phases, enhancing retrieval effectiveness \[[2206.10128](http://arxiv.org/abs/2206.10128)\]. This paradigm has inspired generative retrieval models that directly predict document identifiers, achieving strong zero-shot and supervised retrieval performance \[[2202.06991](http://arxiv.org/abs/2202.06991)\]\[[2206.02743](http://arxiv.org/abs/2206.02743)\].

Handling dynamic and evolving corpora presents additional challenges. Continual learning methods for generative retrieval, such as CLEVER, integrate incremental quantization techniques and memory-augmented learning to efficiently add new documents while mitigating catastrophic forgetting, ensuring up-to-date retrieval capabilities in the presence of growing datasets \[[2308.14968](http://arxiv.org/abs/2308.14968)\]. This is crucial for table repositories that continuously evolve.

In the domain of table discovery specifically, semantic similarity-based retrieval methods have demonstrated that representing queries and tables in multiple semantic spaces (sparse and dense) and combining various similarity measures within supervised models yields significant improvements over traditional keyword-based search \[[1802.06159](http://arxiv.org/abs/1802.06159)\]. Furthermore, approaches like Solo leverage self-supervised strategies to generate training data and learn table discovery models without human annotation, addressing data scarcity challenges in learned discovery systems \[[2301.0356](http://arxiv.org/abs/2301.03560)\].

Finally, large unified language models designed for knowledge-intensive tasks, such as CorpusLM, integrate generative retrieval and retrieval-augmented generation in a single model. They improve retrieval quality by learning to generate ranked lists of document identifiers and leveraging unsupervised DocID understanding, which could be adapted to table retrieval scenarios to deepen query-table semantic alignment \[[2402.01176](http://arxiv.org/abs/2402.01176)\].

In summary, existing work on natural language-driven table discovery spans advances in table representation, indexing, retrieval, and continual learning. While dense vector pipelines have been dominant, emerging trends favor unified models that combine indexing and retrieval to minimize error accumulation and enhance semantic interactions. Synthetic query generation and continual learning mechanisms further address challenges posed by query distribution shifts and dynamic corpora. These developments provide a solid foundation for frameworks like Birdie, which unify indexing and retrieval via a prefix-aware differentiable search index and integrate continual indexing strategies to improve accuracy and robustness in table discovery.
