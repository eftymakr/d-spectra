## Related Works

The efficient serving of large language models (LLMs) has been a focal point of recent research, with a particular emphasis on optimizing memory usage and inference speed through key-value (KV) cache management. Prior work has explored various techniques for KV cache compression, eviction, and reuse, each with distinct objectives and trade-offs. For instance, **KVLink**  introduced strategies to improve KV cache reuse by precomputing and concatenating caches for documents, reducing time-to-first-token (TTFT) by up to 96%. Similarly, **EFIM** \[[Yuan Feng' 2025-02-06](http://arxiv.org/abs/2502.03805v2)\] addressed infilling tasks by transforming prompt formats to enable better KV cache reuse, achieving a 52% latency reduction and 98% throughput improvement. These approaches highlight the importance of context-aware cache management in enhancing LLM performance.

**Mell** \[[Yuxuan Yue' 2024-02-19](http://arxiv.org/abs/2402.12065v2)\] further advanced the field by proposing a multi-GPU KV cache management system that reduces the number of GPUs required by 31% while increasing GPU utilization by 43%. This work demonstrated that load balancing across GPUs can significantly improve scalability in LLM serving. Additionally, **CacheGen** \[[Yilong Chen' 2024-08-07](http://arxiv.org/abs/2408.03675v2)\] introduced a method for compressing and streaming KV caches, reducing cache size by 3.5–4.3x and total delay by 3.2–3.7x with negligible impact on response quality. These findings underscore the potential of KV cache compression and efficient memory management in improving LLM serving performance.

The importance of workload-aware cache eviction policies has also been emphasized. **NACL**  proposed a general framework for long-context KV cache eviction, achieving up to 50% reduction in cache size with over 95% performance maintenance. This work highlighted the need for adaptive eviction strategies that account for varying request patterns and memory constraints. Similarly, **SAGE-KV**  leveraged self-attention to guide KV cache eviction, achieving 4x higher memory efficiency with improved accuracy over static selection methods. These studies demonstrate that attention-based eviction strategies can significantly enhance efficiency without compromising accuracy.

Furthermore, **InfiniGen** \[[Damiano Brigo' 2008-12-22](http://arxiv.org/abs/0812.4210v1)\] introduced a dynamic KV cache management framework tailored for long-text generation, improving performance by up to 3x compared to prior methods. This work emphasized the importance of speculative computation and efficient cache prefetching in reducing fetch overhead. **VL-Cache** \[[Mayuresh Kunjir' 2015-04-25](http://arxiv.org/abs/1504.06736v2)\] extended these ideas to vision-language models (VLMs), proposing a sparsity-aware compression method that reduced memory footprint by 90% while maintaining accuracy. These advancements illustrate the growing interest in domain-specific optimizations for KV cache management.

In addition, **Ada-KV** \[[Yuan Feng' 2024-07-16](http://arxiv.org/abs/2407.11550v5)\] introduced an adaptive budget allocation strategy for KV cache eviction, improving quality over existing methods by leveraging head-wise budget allocation. **CAKE** \[[Ziran Qin' 2025-03-16](http://arxiv.org/abs/2503.12491v2)\] proposed a cascading and adaptive eviction method that considers layer preferences and temporal dynamics, achieving over 10x speedup in decoding latency. **CriticalKV** \[[Yuan Feng' 2025-02-06](http://arxiv.org/abs/2502.03805v2)\] introduced a formal perturbation-based method for identifying critical KV cache entries, reducing compression loss by more than half. These works highlight the diverse approaches to optimizing KV cache management, from formal analysis to adaptive strategies.

In summary, the body of work on KV cache management for LLMs has evolved from basic compression and reuse strategies to more sophisticated, workload-aware policies that balance performance, memory, and computational efficiency. These studies provide a foundation for the proposed workload-aware cache eviction policy, which aims to improve serving performance under real-world conditions.
