## Related Works

Active learning (AL) has been widely studied for reducing human annotation costs by selecting the most informative unlabeled data for annotation \[[Christopher Briggs' 2020-04-24](http://arxiv.org/abs/2004.11794v2)\]. However, performing AL in isolation can be limited by restricted data diversity and annotation budgets \[[Christopher Briggs' 2020-04-24](http://arxiv.org/abs/2004.11794v2)\]. Federated Active Learning (FAL) extends AL to distributed settings, enabling collaborative data selection and model training while preserving data privacy \[[Sannara Ek' 2022-07-17](http://arxiv.org/abs/2207.08187v1)\]. Despite these advances, existing FAL methods often overlook the heterogeneity of data distribution across clients and the associated fluctuations in global and local model parameters, which can negatively impact model accuracy \[[Sannara Ek' 2022-07-17](http://arxiv.org/abs/2207.08187v1)\]. 

Several works have explored federated learning (FL) with a focus on data heterogeneity and model performance. For instance, FedDiverse addresses data heterogeneity by proposing a client selection algorithm that promotes collaboration between clients with complementary data distributions \[[Andreas Lutz' 2024-11-02](http://arxiv.org/abs/2411.01240v3)\]. Similarly, FedFN introduces feature normalization to alleviate data heterogeneity issues by reducing the gap between feature norms of observed and unobserved classes \[[Hossein Zakerinia' 2022-06-20](http://arxiv.org/abs/2206.10032v4)\]. These methods highlight the importance of addressing data heterogeneity in FL settings. 

In the context of model personalization, FedCor proposes a correlation-based client selection strategy to improve convergence rates in heterogeneous FL \[[Gergely D. Németh' 2025-04-15](http://arxiv.org/abs/2504.11216v2)\]. WAFFLE, on the other hand, introduces a weighted averaging approach to personalize federated learning models based on the Euclidean distance between clients' updates \[[Tianyi Chen' 2020-07-12](http://arxiv.org/abs/2007.06081v1)\]. These methods demonstrate the potential of personalized approaches in FL to enhance model performance. 

The challenge of data heterogeneity also extends to the problem of non-IID data, which has been extensively studied. For example, FedMD leverages model distillation to enable heterogeneous FL by allowing each client to maintain a unique model while aligning with a global model \[[Wenlin Chen' 2020-10-26](http://arxiv.org/abs/2010.13723v3)\]. Similarly, FedCompass addresses client imbalance and data heterogeneity by introducing a computing power-aware scheduler to adaptively assign training tasks \[[Hussain Ahmad Madni' 2023-07-31](http://arxiv.org/abs/2308.00155v1)\]. These approaches highlight the need for adaptive strategies to handle heterogeneous data in FL. 

In addition to data heterogeneity, the issue of model drift and forgetting in non-IID settings has been addressed in several works. For example, Overcoming Forgetting in Federated Learning on Non-IID Data introduces a penalty term to the loss function to ensure convergence to a shared optimum \[[Seongyoon Kim' 2023-11-22](http://arxiv.org/abs/2311.13267v1)\]. This approach helps mitigate the adverse effects of non-IID data on model performance. 

The integration of self-supervised learning in FL has also been explored. Heterogeneous Self-supervised Federated Learning (Hetero-SSFL) enables collaborative representation learning across clients without requiring labeled data \[[Krishna Pillutla' 2021-12-17](http://arxiv.org/abs/2112.09429v2)\]. This work demonstrates the potential of self-supervised learning in FL to handle heterogeneous data. 

These studies collectively underscore the challenges and opportunities in federated active learning, particularly in addressing data heterogeneity, model drift, and the need for personalized and adaptive strategies. The proposed CHASe method builds upon these insights to improve the effectiveness and efficiency of FAL in heterogeneous settings.
