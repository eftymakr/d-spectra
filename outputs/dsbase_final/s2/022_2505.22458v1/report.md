## Related Works

Unsupervised domain adaptation (UDA) for semantic segmentation aims to transfer knowledge from labeled source data to unlabeled target data \[[Binhui Xie' 2021-11-24](http://arxiv.org/abs/2111.12358v2)\]. Traditional UDA methods typically assume that the category settings between source and target domains are known, which is often not the case in real-world applications \[[Yiheng Zhang' 2018-04-23](http://arxiv.org/abs/1804.08286v1)\]. This assumption can lead to significant performance degradation when private classes exist in the target domain \[[Bo Yuan' 2022-04-05](http://arxiv.org/abs/2204.02111v1)\].

To address this limitation, several works have explored methods that do not require prior knowledge of category settings. For example, \[[Zhiming Wang' 2021-03-29](http://arxiv.org/abs/2103.15467v2)\] introduced a curriculum-style learning approach to minimize the domain gap in urban scenery semantic segmentation by first learning global label distributions and local distributions over landmark superpixels. This method is effective in scenarios where the target domain has idiosyncratic characteristics \[[Gabriela Csurka' 2023-02-13](http://arxiv.org/abs/2302.06378v1)\]. Similarly, \[[Seun-An Choe' 2024-05-30](http://arxiv.org/abs/2405.19899v1)\] proposed Fully Convolutional Adaptation Networks (FCAN) that combine appearance and representation-level domain adaptation to improve performance on real-world datasets. These methods focus on aligning the visual appearance and representation between domains \[[Qiming Zhang' 2019-10-29](http://arxiv.org/abs/1910.13049v2)\].

Another line of research has focused on self-training and pseudo-labeling strategies to improve adaptation performance. For instance, \[[Kekai Sheng' 2021-03-25](http://arxiv.org/abs/2103.13561v1)\] proposed an unsupervised cross-modality domain adaptation approach based on pixel alignment and self-training, which helps reduce domain shift in the training segmentation model. This approach leverages self-training to adapt the decision boundary of the segmentation network to fit the distribution of target data \[[Haoyu Ma' 2021-03-24](http://arxiv.org/abs/2103.13041v1)\]. Similarly, \[[Daehan Kim' 2022-11-26](http://arxiv.org/abs/2211.14596v1)\] introduced a framework that uses self-training to iteratively improve the quality of pseudo-labels, leading to better performance on medical image segmentation tasks \[[Zhengeng Yang' 2022-08-12](http://arxiv.org/abs/2208.06087v1)\].

Recent works have also explored the use of normalization techniques to improve domain adaptation. For example, \[[Minsu Kim' 2020-12-15](http://arxiv.org/abs/2012.08226v2)\] introduced Reciprocal Normalization (RN) to address the misalignment between features of corresponding channels across domains. This method improves the transferability of models by adaptively aggregating features with their cross-domain compensatory components \[[Yongchun Zhu' 2022-01-04](http://arxiv.org/abs/2201.01002v1)\]. Additionally, \[[Hexin Dong' 2021-09-29](http://arxiv.org/abs/2109.14219v1)\] proposed a method that uses domain disentanglement and adversarial learning to improve performance on cross-modality medical image segmentation tasks \[[Gabriela Csurka' 2017-02-17](http://arxiv.org/abs/1702.05374v2)\].

In the context of domain adaptation for semantic segmentation, \[[Eleni Chiou' 2021-09-19](http://arxiv.org/abs/2109.09736v1)\] introduced a framework that uses adversarial learning and self-training to adapt models to new domains. This approach is particularly useful when the target domain has a large domain gap compared to the source domain \[[Yuang Liu' 2021-03-30](http://arxiv.org/abs/2103.16372v1)\]. Similarly, \[[Yifan Xu' 2021-04-21](http://arxiv.org/abs/2104.10376v1)\] proposed a method that uses semantic consistency and pseudo-labeling to improve performance on MRI prostate lesion segmentation tasks \[[Yang Zhang' 2017-07-29](http://arxiv.org/abs/1707.09465v5)\].

Overall, these works highlight the challenges and opportunities in domain adaptation for semantic segmentation. While many methods have been proposed, there remains a need for approaches that can handle scenarios with unknown category settings and large domain gaps \[[Dongqiangzi Ye' 2022-06-23](http://arxiv.org/abs/2206.11428v2)\]. The proposed UniMAP framework addresses these challenges by introducing novel components such as Domain-Specific Prototype-based Distinction (DSPD) and Target-based Image Matching (TIM), which enable robust adaptation even without prior knowledge of category settings \[[Ozan Ciga' 2019-09-05](http://arxiv.org/abs/1909.02620v1)\].
