## Related Works

Personalized outfit generation has garnered significant attention in recent years, driven by the increasing demand for tailored fashion recommendations. This task involves generating a set of compatible and personalized fashion items that form a coherent outfit, often based on user preferences or partial input \[[Dongliang Zhou' 2025-02-03](http://arxiv.org/abs/2502.00992v1)\]. Early approaches primarily relied on rule-based systems and collaborative filtering, which lacked the flexibility to capture nuanced user preferences \[[Najmeh Forouzandehmehr' 2024-09-18](http://arxiv.org/abs/2409.12150v1)\]. With the advent of deep learning, particularly in the realm of generative models, researchers have explored more sophisticated methods to enhance the diversity and personalization of generated outfits \[[Yuxi Bi' 2025-04-14](http://arxiv.org/abs/2504.09915v1)\].

Several studies have focused on improving the compatibility of generated outfits by leveraging graph-based models and attention mechanisms. For example, \[[Samaksh Gulati' 2024-04-28](http://arxiv.org/abs/2404.18040v1)\] introduced a graph neural network to model the compatibility between fashion items, while \[[Kedan Li' 2019-06-17](http://arxiv.org/abs/1906.07273v2)\] proposed a hierarchical structure to better capture the relationships between users, items, and outfits. These methods, however, often require extensive manual annotations or domain-specific knowledge, limiting their scalability and adaptability to diverse user preferences \[[Debopriyo Banerjee' 2022-05-02](http://arxiv.org/abs/2205.00663v1)\].

To address these limitations, recent work has turned to reinforcement learning from human feedback (RLHF) and direct preference optimization (DPO) to align models with user preferences without the need for explicit reward functions \[[Siyan Zhao' 2023-10-17](http://arxiv.org/abs/2310.11523v2)\]. Specifically, \[[Hoang Anh Just' 2024-07-19](http://arxiv.org/abs/2407.14477v4)\] proposed a framework that fine-tunes generative models using DPO, which leverages pairwise preference comparisons to guide the optimization process. This approach has shown promise in improving the alignment of generated outfits with user preferences while maintaining compatibility constraints \[[Zeyu Cui' 2019-02-21](http://arxiv.org/abs/1902.08009v1)\]. However, these methods often rely on predefined reward functions or require extensive user feedback, which can be costly and time-consuming \[[Xin Wang' 2019-07-26](http://arxiv.org/abs/1907.11496v2)\].

In the context of fashion, \[[Heming Zhang' 2020-07-05](http://arxiv.org/abs/2007.02388v1)\] introduced a multi-turn direct preference learning framework tailored for mathematical reasoning tasks, demonstrating the potential of preference-based alignment in complex domains. Similarly, \[[Takuma Nakamura' 2018-06-29](http://arxiv.org/abs/1807.03133v3)\] proposed a directional preference alignment (DPA) framework that allows for intuitive control over trade-offs between different user preferences, such as helpfulness and verbosity. These approaches highlight the importance of incorporating user feedback directly into the training process to enhance the personalization and relevance of generated outfits \[[Seongjae Kim' 2021-10-13](http://arxiv.org/abs/2110.06483v1)\].

To further improve the quality and diversity of generated outfits, \[[Debopriyo Banerjee' 2022-03-30](http://arxiv.org/abs/2203.16161v1)\] introduced a framework that integrates both visual and textual information, enabling the model to better understand the context and style of the generated items. This is crucial for ensuring that the generated outfits are not only compatible but also aligned with the user's aesthetic preferences \[[Yuncheng Li' 2016-08-10](http://arxiv.org/abs/1608.03016v2)\].

In addition, \[[Federico Becattini' 2023-04-17](http://arxiv.org/abs/2304.08098v1)\] proposed a method that uses text and image embeddings to represent fashion items, learning a multimodal embedding where the image representation for an item is close to its text representation, and uses this embedding to measure item-query coherence. This approach allows for the generation of outfits that match a specified theme while maintaining compatibility between items \[[Zisen Zhou' 2021-07-27](http://arxiv.org/abs/2107.12533v1)\]. Furthermore, \[[Bowei Li' 2021-07-27](http://arxiv.org/abs/2107.12524v1)\] introduced a framework that leverages the expressive power of large language models (LLMs) for outfit recommendation, mitigating their "black box" and static nature through fine-tuning and direct feedback integration \[[Emily Halina' 2021-07-26](http://arxiv.org/abs/2107.12506v1)\].

In summary, while existing methods have made significant strides in improving the compatibility and personalization of generated outfits, there remains a need for more flexible and scalable approaches that can effectively incorporate user preferences without relying on extensive manual annotations or predefined reward functions \[[Paul Feliot' 2018-09-14](http://arxiv.org/abs/1809.05450v1)\].
