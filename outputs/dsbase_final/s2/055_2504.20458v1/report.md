## Related Works

Conversational recommendation systems (CRSs) have garnered significant attention in recent years due to their ability to engage users in multi-turn interactions to capture nuanced preferences and deliver personalized recommendations \[[Zhendong Chu' 2023-10-31](http://arxiv.org/abs/2310.20109v1)\]. However, effectively understanding user preferences remains a fundamental challenge, as user preferences can be multifaceted and complex, even with access to abundant external knowledge \[[Zhendong Chu' 2023-10-31](http://arxiv.org/abs/2310.20109v1)\]. While user interaction can clarify true preferences, frequent involvement can degrade the user experience \[[Zhendong Chu' 2023-10-31](http://arxiv.org/abs/2310.20109v1)\].

Several approaches have been proposed to address these challenges. One line of work focuses on improving the quality of user feedback through structured elicitation techniques. For instance, \[[Millennium Bismay' 2024-10-30](http://arxiv.org/abs/2410.23180v1)\] presents a Bayesian approach to conversational recommendation systems, where a probability mass function over items is updated after each interaction, using information-theoretic criteria to shape the interaction and determine when to terminate the conversation. This method leverages prior knowledge and historical data to improve recommendation accuracy \[[Millennium Bismay' 2024-10-30](http://arxiv.org/abs/2410.23180v1)\]. Similarly, \[[Francesca Mangili' 2020-02-12](http://arxiv.org/abs/2002.05063v1)\] introduces a Bayesian approach to conversational recommendation systems, where a probability mass function over the items is updated after any interaction with the user, with information-theoretic criteria optimally shaping the interaction and deciding when the conversation should be terminated and the most probable item consequently recommended \[[Francesca Mangili' 2020-02-12](http://arxiv.org/abs/2002.05063v1)\].

Another approach involves the use of simulated users to automate the interaction process. \[[Chen Zhang' 2024-09-20](http://arxiv.org/abs/2409.13948v3)\] introduces a methodology to systematically test conversational recommender systems for conversational breakdowns by using user simulations to generate conversations and identify potential issues. This approach is cost-effective and enables the evaluation of system robustness \[[Chen Zhang' 2024-09-20](http://arxiv.org/abs/2409.13948v3)\]. Similarly, \[[Zhangchi Qiu' 2023-12-18](http://arxiv.org/abs/2312.10967v3)\] explores the use of user simulations to evaluate conversational recommendation systems, demonstrating that such simulations can help identify and mitigate breakdowns in the interaction process \[[Zhangchi Qiu' 2023-12-18](http://arxiv.org/abs/2312.10967v3)\]. \[[Nikolaos Kondylidis' 2021-03-15](http://arxiv.org/abs/2103.08733v1)\] introduces a framework for conversational recommendation systems that uses a simulated user to provide feedback to the system, enabling it to better capture user preferences through multi-turn interaction. This approach reduces the need for frequent user involvement while maintaining recommendation quality \[[Nikolaos Kondylidis' 2021-03-15](http://arxiv.org/abs/2103.08733v1)\].

To enhance the quality of recommendations, some studies have focused on incorporating explainable AI techniques. \[[Wenlin Wang' 2019-10-21](http://arxiv.org/abs/1910.12735v2)\] proposes a category-aware explainable conversational recommendation approach that provides concise explanations without requiring prior user knowledge. This method uses a BERT-based neural architecture to model user preferences and a Feed Forward Network to translate these preferences into item recommendations \[[Wenlin Wang' 2019-10-21](http://arxiv.org/abs/1910.12735v2)\]. \[[Shihao Cai' 2024-10-26](http://arxiv.org/abs/2410.20027v2)\] further extends this idea by introducing a framework that generates natural language explanations for recommendations, improving transparency and user trust \[[Shihao Cai' 2024-10-26](http://arxiv.org/abs/2410.20027v2)\].

Additionally, the integration of large language models (LLMs) into conversational recommendation systems has shown promise. \[[Mateo Gutierrez Granada' 2023-09-07](http://arxiv.org/abs/2309.03645v1)\] introduces a framework called P4R, which leverages LLMs to generate personalized item profiles and align them with semantic representations using BERT and Graph Convolution Networks (GCNs) \[[Mateo Gutierrez Granada' 2023-09-07](http://arxiv.org/abs/2309.03645v1)\]. This approach improves the accuracy of recommendations by capturing richer user and item representations \[[Mateo Gutierrez Granada' 2023-09-07](http://arxiv.org/abs/2309.03645v1)\]. \[[Heriberto Cuayáhuitl' 2018-12-02](http://arxiv.org/abs/1812.00350v1)\] presents a study on dialogue reward prediction for open-ended conversational agents, investigating the amount of dialogue history required for reliably predicting dialogue rewards. The task of dialogue reward prediction is chosen for investigating the effects of varying amounts of dialogue history and their impact on system performance \[[Heriberto Cuayáhuitl' 2018-12-02](http://arxiv.org/abs/1812.00350v1)\].

In summary, existing work on conversational recommendation systems has explored various strategies to improve recommendation accuracy, user experience, and system robustness. These include Bayesian approaches, simulated user interactions, explainable AI, and the integration of LLMs. Our work builds on these contributions by proposing a generative reward model-based simulated user, GRSU, which enables automatic and efficient interaction with CRSs while maintaining high recommendation quality \[[Zhendong Chu' 2023-10-31](http://arxiv.org/abs/2310.20109v1)\].
