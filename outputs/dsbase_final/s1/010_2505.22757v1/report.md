## Related Works

Multi-token prediction (MTP) has emerged as a promising pre-training objective for language models, offering potential improvements in downstream performance, inference speed, and training efficiency \[[Daniel Campos' 2021-08-04](http://arxiv.org/abs/2108.02170v1)\]. Unlike traditional next-token prediction (NTP), which predicts one token at a time, MTP extends this by predicting the next $k$ tokens simultaneously using multiple prediction heads \[[Daniel Campos' 2021-08-04](http://arxiv.org/abs/2108.02170v1)\]. This approach has been shown to enhance the model's ability to capture long-range dependencies and improve generation quality, particularly for large models \[[Daniel Campos' 2021-08-04](http://arxiv.org/abs/2108.02170v1)\]. However, smaller language models (SLMs) face challenges in effectively leveraging the MTP objective, as evidenced by prior studies \[[Daniel Campos' 2021-08-04](http://arxiv.org/abs/2108.02170v1)\]. To address this limitation, this work proposes a curriculum learning strategy tailored for MTP training, exploring two variants: a forward curriculum that gradually increases complexity from NTP to MTP, and a reverse curriculum that does the opposite \[[Daniel Campos' 2021-08-04](http://arxiv.org/abs/2108.02170v1)\].

Curriculum learning has been widely studied in the context of improving model training and performance across various domains, including computer vision and machine translation \[[Gregor Bachmann' 2024-03-11](http://arxiv.org/abs/2403.06963v3)\]. The idea is to structure the learning process by presenting tasks in an order that aligns with the model's capacity, thereby enhancing learning efficiency and generalization \[[Gregor Bachmann' 2024-03-11](http://arxiv.org/abs/2403.06963v3)\]. In the context of language models, curriculum learning has been explored for tasks such as code generation and language modeling \[[Sanmit Narvekar' 2020-03-10](http://arxiv.org/abs/2003.04960v2)\]. For instance, one study demonstrated that a well-designed curriculum significantly improves the accuracy of small decoder-only code language models on code execution tasks \[[Sanmit Narvekar' 2020-03-10](http://arxiv.org/abs/2003.04960v2)\]. Similarly, another work proposed a novel curriculum learning schedule that enhances the performance of small decoder-only language models in code execution tasks \[[Sanmit Narvekar' 2020-03-10](http://arxiv.org/abs/2003.04960v2)\].

The proposed curriculum learning strategy for MTP builds on these insights, aiming to address the specific challenges faced by SLMs in adopting the MTP objective \[[Daniel Campos' 2021-08-04](http://arxiv.org/abs/2108.02170v1)\]. The forward curriculum gradually increases the complexity of the pre-training objective, starting with NTP and transitioning to MTP, enabling SLMs to better leverage the MTP objective during pre-training \[[Daniel Campos' 2021-08-04](http://arxiv.org/abs/2108.02170v1)\]. This approach has been shown to improve downstream NTP performance and generative output quality while retaining the benefits of self-speculative decoding \[[Daniel Campos' 2021-08-04](http://arxiv.org/abs/2108.02170v1)\]. In contrast, the reverse curriculum, which starts with MTP and transitions to NTP, achieves stronger NTP performance and output quality but fails to provide any self-speculative decoding benefits \[[Daniel Campos' 2021-08-04](http://arxiv.org/abs/2108.02170v1)\].

These findings align with broader research on curriculum learning in reinforcement learning and other domains, where structured training regimes have been shown to improve model performance and efficiency \[[Suchir Salhan' 2024-10-30](http://arxiv.org/abs/2410.22886v2)\]. For example, one study proposed a general optimization framework for task sequencing in curriculum learning, demonstrating that curriculum learning can improve initial performance, reduce suboptimal actions during exploration, and discover better policies \[[Suchir Salhan' 2024-10-30](http://arxiv.org/abs/2410.22886v2)\]. Similarly, another work introduced a framework for curriculum learning in reinforcement learning inspired by the pedagogical concept of Zone of Proximal Development (ZPD), showing that learning progress is maximized when tasks are neither too hard nor too easy for the learner .

Further, research has shown that multi-token prediction can be implemented through various methods, such as joint multi-token prediction (JTP), which enriches hidden state representations by jointly predicting multiple future tokens \[[Kwangjun Ahn' 2025-03-24](http://arxiv.org/abs/2503.21801v1)\]. This approach has demonstrated effectiveness in tasks like synthetic star graph navigation \[[Kwangjun Ahn' 2025-03-24](http://arxiv.org/abs/2503.21801v1)\]. Additionally, the use of learnable register tokens in the input sequence, as proposed in MuToR, allows for efficient and scalable multi-token prediction without requiring architectural changes \[[Anastasios Gerontopoulos' 2025-05-15](http://arxiv.org/abs/2505.10518v1)\]. These methods highlight the diversity of approaches to MTP and the potential for curriculum learning to further enhance their effectiveness.
