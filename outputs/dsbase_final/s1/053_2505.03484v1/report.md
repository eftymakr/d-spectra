## Related Works

Recent advances in sequential recommendation have focused on modeling user behavior through attention mechanisms and state-space models, aiming to capture both temporal dynamics and diverse interaction patterns. Early works, such as \[[Uzma Mushtaque' 2025-01-02](http://arxiv.org/abs/2501.01242v1)\], emphasized the importance of modeling user sequential behaviors, but often assumed coherent preferences within sequences, overlooking the volatility of user preferences. Later, \[[Jinzhao Su' 2024-07-18](http://arxiv.org/abs/2407.13135v1)\] introduced a contextualized temporal attention mechanism to weigh historical actions based on their temporal and contextual relevance, improving the modeling of user preferences over time. However, these methods typically ignored the multi-faceted nature of items and user preferences, which is crucial for accurate recommendations.

To address this, \[[Haohao Qu' 2024-09-02](http://arxiv.org/abs/2409.01192v2)\] proposed the Facet-Aware Multi-Head Mixture-of-Experts (FAME) model, which captures the multi-faceted nature of items by leveraging sub-embeddings from each head in the last multi-head attention layer. This approach allows for more nuanced modeling of user preferences across different facets, such as genres or actors in movies. Additionally, \[[Xinyu Du' 2023-04-18](http://arxiv.org/abs/2304.09184v3)\] introduced a Mixture-of-Experts (MoE) network within each attention head to disentangle user preferences within each facet, enhancing the model's ability to handle complex preferences. These methods laid the groundwork for more sophisticated modeling of user preferences in sequential recommendation.

Another key challenge in sequential recommendation is handling variable-length sequences efficiently. \[[Jiyuan Yang' 2024-03-25](http://arxiv.org/abs/2403.16371v1)\] proposed a linear time-periodic dynamical system (LTP) model to reduce computational complexity, while \[[Chengkai Liu' 2024-03-06](http://arxiv.org/abs/2403.03900v2)\] introduced a state-space model (SSM) to process variable-length sequences with linear complexity. The SSM approach has been further refined in \[[Yuda Wang' 2024-06-04](http://arxiv.org/abs/2406.02638v2)\], where it was combined with attention mechanisms to capture both similar and diverse item relationships. This combination of SSM and attention mechanisms has been shown to effectively model temporal dynamics while preserving the flexibility of attention-based models.

The integration of MoE into sequential recommendation has also gained traction. \[[Wei Xiao' 2025-02-12](http://arxiv.org/abs/2502.08132v3)\] introduced a Mixture-of-Experts framework to handle diverse user behaviors by routing different behavioral patterns to specialized experts. This approach allows for adaptive modeling of both focused category-specific browsing and diverse category exploration. \[[Shirley Wu' 2023-12-07](http://arxiv.org/abs/2312.04693v3)\] further extended this idea by proposing a hierarchical time-aware MoE model for multi-modal sequential recommendation, which captures both user interest and temporal dynamics. These methods highlight the potential of MoE in handling complex and diverse user behaviors.

In addition to modeling user preferences and sequences, recent works have also focused on incorporating negative feedback and contextual information. \[[Yong Zheng' 2017-07-27](http://arxiv.org/abs/1707.08913v1)\] proposed a sequence-aware contrastive learning approach that structures item embeddings based on user feedback, improving the ranking of true next items. \[[Linsey Pang' 2024-09-08](http://arxiv.org/abs/2409.05022v1)\] introduced a model that leverages both text and ID features through a sequence-level semantic fusion approach, enhancing the representation of items in sequential recommendation. These methods demonstrate the importance of incorporating diverse contextual information to improve recommendation accuracy.

In summary, recent works have made significant strides in modeling user behavior through attention mechanisms, state-space models, and MoE frameworks. These approaches have addressed key challenges in sequential recommendation, including handling sequence length variations, capturing diverse interaction patterns, and incorporating contextual information. The proposed STAR-Rec model builds upon these advancements by synergistically combining preference-aware attention and state-space modeling through a sequence-level MoE framework.

Recent advances in sequential recommenders have convincingly demonstrated high capability in extracting effective user representations from the given behavior sequences. In this paper, we propose to learn accurate and robust user representations, which are required to be less sensitive to (attack on) noisy behaviors and trust more on the indispensable ones, by modeling counterfactual data distribution. With user representations obtained from the synthesized user sequences, CauseRec performs contrastive user representation learning by contrasting the counterfactual with the observational.
