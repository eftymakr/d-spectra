## Related Works

Natural language (NL)-driven table discovery has gained significant attention in recent years due to the increasing availability of tabular data and the need for efficient retrieval mechanisms. Early approaches relied on traditional dense vector search pipelines, which involve representation, indexing, and search stages \[[Yi Tay' 2022-02-14](http://arxiv.org/abs/2202.06991v3)\]. These methods have achieved notable accuracy but suffer from two primary limitations: error accumulation during representation and indexing, which degrades search accuracy, and insufficient query-table interaction, which hinders semantic alignment \[[Xiaoyang Chen' 2023-05-03](http://arxiv.org/abs/2305.02073v2)\]. 

To address these limitations, several works have explored alternative indexing and search strategies. For instance, \[[Lingxi Cui' 2025-04-22](http://arxiv.org/abs/2504.15849v1)\] introduced a framework for natural language interfaces for temporal databases, emphasizing the importance of temporal linguistic mechanisms and semantic alignment. These approaches highlight the need for better semantic understanding in cross-modal tasks. Similarly, \[[Abhijeet Phatak' 2025-02-05](http://arxiv.org/abs/2502.02788v1)\] proposed a system that uses a large language model (LLM) to generate synthetic queries for each table, enabling deeper semantic alignment. This approach is similar to the query generation component in Birdie, where synthetic queries are used to improve the interaction between queries and tables \[[Zhao Yan' 2017-06-08](http://arxiv.org/abs/1706.02427v1)\].

In the realm of table discovery, \[[Petru Neague' 2024-04-18](http://arxiv.org/abs/2404.12237v2)\] introduced a dataset called nlcTables, which aims to bridge the gap between natural language conditions and table discovery. This dataset includes diverse queries and candidate tables, enabling more robust evaluation of table discovery methods. However, existing methods still struggle with effective semantic alignment between queries and tables \[[Rossen Nenov' 2024-09-30](http://arxiv.org/abs/2410.00169v1)\]. 

To enhance query-table interaction, \[[Gowri Shankar Ramaswamy' 2012-08-20](http://arxiv.org/abs/1208.4016v1)\] explored the use of LLMs for query recommendation, demonstrating the potential of LLMs in understanding user intent and generating relevant queries. This is closely related to the query generation module in Birdie, which leverages an LLM to create synthetic queries for each table \[[Aman Sinha' 2024-04-15](http://arxiv.org/abs/2404.09473v1)\]. 

Another relevant work is \[[Dayu Yang' 2024-11-04](http://arxiv.org/abs/2411.03356v1)\], which introduced a differentiable search index (DSI) that unifies indexing and retrieval into a single transformer model. This approach reduces error accumulation by eliminating the separate indexing and retrieval stages. However, DSI faces challenges with data distribution mismatches between indexing and retrieval processes \[[Amin Abolghasemi' 2022-02-01](http://arxiv.org/abs/2202.00373v2)\]. Birdie builds upon this idea by incorporating a query generation module to address these mismatches \[[Jens Dittrich' 2020-09-22](http://arxiv.org/abs/2009.10669v2)\].

Furthermore, \[[Naoya Sogi' 2024-07-17](http://arxiv.org/abs/2407.12346v2)\] proposed a framework for generating synthetic data for training models, which is relevant to the data generation component of Birdie. The use of synthetic data to improve model performance has also been explored in \[[Xiao Wang' 2020-07-15](http://arxiv.org/abs/2007.07987v1)\], where a differentiable feature aggregation search method was introduced to enhance knowledge distillation. These methods highlight the importance of synthetic data in improving model robustness and performance \[[Hieu Tran' 2022-03-21](http://arxiv.org/abs/2203.10791v2)\].

In summary, the related works demonstrate the ongoing efforts to improve natural language-driven table discovery by addressing limitations in representation, indexing, and query-table interaction. These studies provide a foundation for the proposed framework, Birdie, which aims to unify indexing and search into a single model while improving semantic alignment and reducing error accumulation.

Differentiable Search Index (DSI) frameworks have emerged as a novel paradigm in information retrieval, aiming to simplify the retrieval process by encoding all necessary information about the corpus directly into the model's parameters \[[Yi Tay' 2022-02-14](http://arxiv.org/abs/2202.06991v3)\]. These frameworks typically employ transformer-based neural networks to map queries directly to relevant document identifiers, eliminating the need for traditional indexing structures \[[Abhijeet Phatak' 2025-02-05](http://arxiv.org/abs/2502.02788v1)\]. However, early DSI models faced challenges in distinguishing relevant documents from random ones, which impacted retrieval effectiveness \[[Xiaoyang Chen' 2023-05-03](http://arxiv.org/abs/2305.02073v2)\]. To address this, researchers proposed multi-task distillation approaches to enhance retrieval quality without altering the model structure \[[Xiaoyang Chen' 2023-05-03](http://arxiv.org/abs/2305.02073v2)\]. Additionally, some studies have explored balancing relevance and diversity in DSI training, inspired by Maximal Marginal Relevance (MMR), to achieve both high relevance and diverse recall sets \[[Lingxi Cui' 2025-04-22](http://arxiv.org/abs/2504.15849v1)\]. Furthermore, efforts have been made to integrate large language models (LLMs) with decentralized architectures, enabling efficient query-docid pair processing without direct document access \[[Petru Neague' 2024-04-18](http://arxiv.org/abs/2404.12237v2)\]. These advancements highlight the evolving capabilities of DSI frameworks, addressing issues such as numerical stability \[[Zhao Yan' 2017-06-08](http://arxiv.org/abs/1706.02427v1)\], query-by-document retrieval \[[Petru Neague' 2024-04-18](http://arxiv.org/abs/2404.12237v2)\], and the generalizability of indexing structures \[[Rossen Nenov' 2024-09-30](http://arxiv.org/abs/2410.00169v1)\]. The integration of differentiable search indexing with continual learning strategies has also been explored to mitigate catastrophic forgetting during dynamic indexing \[[Yi Tay' 2022-02-14](http://arxiv.org/abs/2202.06991v3)\]. Overall, DSI frameworks represent a significant shift in information retrieval, offering promising solutions to traditional limitations through end-to-end neural architectures \[[Yi Tay' 2022-02-14](http://arxiv.org/abs/2202.06991v3)\].
