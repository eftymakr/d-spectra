## Related Works

Conversational recommendation systems (CRSs) have gained significant attention due to their ability to capture user preferences through natural language interactions \[[Paul Owoicho' 2023-04-26](http://arxiv.org/abs/2304.13874v3)\]. However, effectively understanding user preferences remains a fundamental challenge, especially given the multifaceted and complex nature of user preferences \[[Paul Owoicho' 2023-04-26](http://arxiv.org/abs/2304.13874v3)\]. Prior work has explored various approaches to enhance user preference elicitation and recommendation accuracy. User simulation has been widely used to evaluate CRSs, offering a cost-effective alternative to human evaluation \[[Sharon Oviatt' 2020-01-09](http://arxiv.org/abs/2001.02912v1)\]. User simulators generate responses that mimic human behavior, allowing for automated evaluation of CRSs \[[Sharon Oviatt' 2020-01-09](http://arxiv.org/abs/2001.02912v1)\]. The work in \[[Sharon Oviatt' 2020-01-09](http://arxiv.org/abs/2001.02912v1)\] emphasizes the importance of preference modeling and task-specific interaction models to achieve high correlation between automatic evaluation measures and manual human assessments. This aligns with our approach of using a simulated user to provide feedback during multi-turn interactions.

Several studies have focused on improving the accuracy of recommendation systems by incorporating user feedback \[[Paul Owoicho' 2023-04-26](http://arxiv.org/abs/2304.13874v3)\]. For instance, \[[Paul Owoicho' 2023-04-26](http://arxiv.org/abs/2304.13874v3)\] introduces a method to model negative user preferences, which helps in recommending more positive items at the top of recommendation lists. This is particularly useful in scenarios where the cost of negative items is high for users. Similarly, \[[Yandi Li' 2023-10-17](http://arxiv.org/abs/2310.11188v2)\] explores the use of negative user preferences to improve recommendation quality, demonstrating that incorporating such information can enhance recommendation accuracy and reduce the number of negative items at the top of recommendation lists.

In the context of conversational recommendation, \[[Chen Zhang' 2024-09-20](http://arxiv.org/abs/2409.13948v3)\] presents a real-time category-based approach that provides concise explanations without requiring prior user knowledge. This method uses a BERT-based neural architecture to model user preferences and recommends items based on category vectors. The work in \[[Chen Zhang' 2024-09-20](http://arxiv.org/abs/2409.13948v3)\] highlights the importance of explainability in conversational recommendation systems, which is a key aspect of our proposed generative reward model.

The use of large language models (LLMs) in conversational recommendation has also been explored. \[[Ziming Li' 2021-03-01](http://arxiv.org/abs/2103.01287v2)\] introduces VideolandGPT, a recommender system that leverages ChatGPT to select content based on user interactions. The study compares personalized and non-personalized versions of the system, showing that the personalized version outperforms the non-personalized one in terms of accuracy and user satisfaction. This underscores the potential of LLMs in enhancing conversational recommendation systems.

Additionally, \[[Igor Shalyminov' 2018-11-02](http://arxiv.org/abs/1811.00967v1)\] evaluates the ability of large language models to simulate human behavior in conversational recommendation. The study introduces a protocol to measure the degree to which language models can accurately emulate human behavior, highlighting the importance of simulating diverse user behaviors for effective evaluation of CRSs.

Furthermore, \[[Kevin Jasberg' 2018-02-16](http://arxiv.org/abs/1802.05895v1)\] explores the impact of scaling unit tests to enhance reward signal quality in code generation tasks. The work demonstrates that increasing the number of unit tests improves the reliability of reward signals, which is relevant to our approach of using a simulated user to provide feedback. This aligns with our use of a simulated user to generate diverse and reliable feedback during multi-turn interactions.

In summary, existing works have explored various methods to enhance user preference elicitation and recommendation accuracy in conversational recommendation systems. Our proposed approach, GRSU, builds on these contributions by introducing a generative reward model based simulated user that provides both coarse-grained and fine-grained feedback to improve recommendation accuracy through multi-turn interaction.
