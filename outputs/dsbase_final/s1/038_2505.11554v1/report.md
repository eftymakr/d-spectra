## Related Works

Memory bandwidth regulation and cache partitioning are widely used techniques for achieving predictable timing in real-time computing systems \[[Binqi Sun' 2023-10-04](http://arxiv.org/abs/2310.02959v1)\]. These techniques are often combined with partitioned scheduling to manage resource allocation and task execution times effectively \[[Vinson Young' 2019-07-04](http://arxiv.org/abs/1907.02184v1)\]. However, the co-allocation of tasks and resources to cores remains a complex challenge, as task execution times strongly depend on the available allocated resources \[[Nadja Ramhöj Holtryd' 2021-02-23](http://arxiv.org/abs/2102.11528v1)\]. This challenge has led to the development of various optimization frameworks and heuristic approaches aimed at improving schedulability and resource efficiency \[[Monowar Hasan' 2017-04-29](http://arxiv.org/abs/1705.00138v3)\].

Several studies have explored the use of mixed-integer programming (MIP) for task-resource co-allocation in real-time systems \[[Tosiron Adegbija' 2016-02-14](http://arxiv.org/abs/1602.04415v1)\]. For example, \[[Afonso Oliveira' 2025-02-04](http://arxiv.org/abs/2502.02437v1)\] presents a MIP formulation for scheduling tasks on multi-core platforms, considering both task and resource constraints. However, MIP approaches are often computationally intensive and may not scale well to large problem instances \[[Asaf Cidon' 2016-10-26](http://arxiv.org/abs/1610.08129v1)\]. In contrast, \[[Gerth Stølting Brodal' 2011-12-22](http://arxiv.org/abs/1112.5472v3)\] introduces a heuristic-based approach that leverages dynamic programming to optimize task allocation, showing improved performance in terms of computational efficiency and solution quality.

The integration of cache set partitioning and memory bandwidth regulation has also been explored in the context of real-time systems. \[[Sparsh Mittal' 2013-09-26](http://arxiv.org/abs/1309.7082v1)\] proposes a method for managing memory bandwidth using a combination of cache set partitioning and a memory guard mechanism, which helps in reducing interference between tasks. This approach is particularly useful in embedded systems where predictable timing is critical \[[Christoph Blumschein' 2022-04-19](http://arxiv.org/abs/2204.08846v1)\]. Similarly, \[[Sparsh Mittal' 2013-09-22](http://arxiv.org/abs/1309.5647v1)\] investigates the use of cache partitioning to improve the schedulability of mixed-criticality systems, demonstrating that careful resource allocation can significantly enhance system performance.

Recent work has also focused on the use of heuristic algorithms for multi-objective optimization in real-time scheduling. \[[Oliver Horst' 2020-09-01](http://arxiv.org/abs/2009.00466v1)\] presents a multi-layer framework that combines Pareto-pruned search with dynamic programming to optimize task allocation, showing promising results in terms of schedulability and resource usage. This setup allows for a more accurate assessment of the proposed methods in practical scenarios \[[Thomas Eiter' 2015-07-06](http://arxiv.org/abs/1507.01451v2)\]. The results from such evaluations are crucial for validating the effectiveness of new scheduling strategies in real-time environments \[[Tosiron Adegbija' 2016-02-14](http://arxiv.org/abs/1602.04414v1)\].
