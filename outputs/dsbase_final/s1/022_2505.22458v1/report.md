## Related Works

Unsupervised domain adaptation (UDA) for semantic segmentation has become a critical area of research due to the high cost of acquiring pixel-level annotations in real-world scenarios. Traditional UDA methods typically assume that the category settings between the source and target domains are known, which is often not the case in practical applications \[[Robert A. Marsden' 2022-08-12](http://arxiv.org/abs/2208.06507v1)\]. This assumption leads to performance degradation when private classes—classes present in the target domain but not in the source—exist \[[Minsu Kim' 2020-12-15](http://arxiv.org/abs/2012.08226v2)\]. To address this limitation, several approaches have been proposed to handle domain shifts without prior knowledge of category settings.

One early approach, curriculum domain adaptation, focuses on minimizing the domain gap by first learning global label distributions and then training a segmentation network while regularizing its predictions to follow these inferred properties \[[Shiqi Yang' 2022-06-07](http://arxiv.org/abs/2206.03600v2)\]. This method is effective for urban scene segmentation but does not address the issue of private classes.

Another notable work, Fully Convolutional Adaptation Networks (FCAN), combines appearance adaptation and representation adaptation to reduce domain shift. FCAN uses adversarial learning to maximize the confusion of a domain discriminator, leading to improved performance on tasks like semantic segmentation from GTA5 to Cityscapes \[[Chaoxiang Ma' 2021-08-13](http://arxiv.org/abs/2108.06383v1)\]. However, FCAN still assumes known category settings and does not explicitly handle private classes.

The paper "Unsupervised Domain Adaptation in Semantic Segmentation Based on Pixel Alignment and Self-Training" introduces a method that reduces domain shift by aligning pixel-level features and using self-training to adapt the decision boundary of the segmentation network \[[Bo Yuan' 2022-04-05](http://arxiv.org/abs/2204.02111v1)\]. This approach improves performance but does not explicitly address the presence of private classes.

In the context of medical image segmentation, DRL-STNet leverages generative adversarial networks (GANs) and disentangled representation learning to translate images between modalities and fine-tune the model using pseudo-labels \[[Seun-An Choe' 2024-05-30](http://arxiv.org/abs/2405.19899v1)\]. This method is effective for cross-modality segmentation but does not directly address the issue of private classes.

The work on "Multi-source Adversarial Domain Aggregation Network for Domain Adaptation" (MADAN) addresses the challenge of aligning multiple source domains with the target domain. MADAN uses adversarial learning and cycle consistency to improve adaptation across domains \[[Yue Wang' 2019-11-27](http://arxiv.org/abs/1911.11981v2)\]. However, it does not explicitly handle private classes.

Recent work on "Domain Private Transformers for Multi-Domain Dialog Systems" explores domain privacy in conversational systems but is not directly applicable to semantic segmentation \[[Gabriela Csurka' 2023-02-13](http://arxiv.org/abs/2302.06378v1)\]. Similarly, "Multi-Representation Adaptation Network for Cross-domain Image Classification" focuses on aligning multiple representations for image classification rather than semantic segmentation \[[Jiaming Zhang' 2021-10-21](http://arxiv.org/abs/2110.11062v1)\].

In summary, while many approaches have been proposed to address domain adaptation in semantic segmentation, few explicitly handle the presence of private classes. The proposed UniMAP framework addresses this gap by introducing a novel approach that enables robust adaptation even without prior knowledge of category settings \[[Yingwei Pan' 2019-10-08](http://arxiv.org/abs/1910.03548v2)\].
