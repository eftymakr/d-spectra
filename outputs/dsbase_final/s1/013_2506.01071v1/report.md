## Related Works

Long-tailed recognition has emerged as a critical research area due to its prevalence in real-world datasets, where a few dominant classes (head classes) occupy most of the data, while the majority of classes (tail classes) contain only a limited number of samples \[[Tianhong Li' 2021-11-27](http://arxiv.org/abs/2111.13998v2)\]. This imbalance leads to biased learning and poor generalization for tail classes \[[Min-Kook Suh' 2023-05-02](http://arxiv.org/abs/2305.01160v3)\]. Various approaches have been proposed to address this issue, primarily focusing on data augmentation, re-balancing strategies, and contrastive learning \[[Chengkai Hou' 2023-06-28](http://arxiv.org/abs/2306.15925v2)\].

Contrastive learning has emerged as a powerful framework for self-supervised representation learning, where the goal is to learn embeddings that capture meaningful semantic relationships between data points \[[Jianggang Zhu' 2022-07-19](http://arxiv.org/abs/2207.09052v3)\]. In the context of long-tailed recognition, several studies have explored how contrastive learning can be adapted to handle class imbalance \[[Weide Liu' 2022-06-02](http://arxiv.org/abs/2206.01010v3)\]. For example, \[[Shiyu Xuan' 2024-03-10](http://arxiv.org/abs/2403.06151v1)\] introduced a method called Balanced Contrastive Learning (BCL) that addresses the issue of imbalanced data by balancing the gradient contribution of negative classes and ensuring that all classes appear in every mini-batch. This helps in forming a regular simplex, which is crucial for effective representation learning \[[Shiyu Xuan' 2024-03-10](http://arxiv.org/abs/2403.06151v1)\].

Similarly, \[[Qiong Chen' 2023-09-28](http://arxiv.org/abs/2309.16135v1)\] proposed a method called Targeted Supervised Contrastive Learning (TSC), which improves the uniformity of the feature distribution on the hypersphere by generating targets uniformly distributed on a hypersphere and making the features of different classes converge to these targets \[[Qiong Chen' 2023-09-28](http://arxiv.org/abs/2309.16135v1)\]. This approach ensures that all classes, including minority classes, maintain a uniform distribution in the feature space, thereby improving class boundaries and generalization \[[Qiong Chen' 2023-09-28](http://arxiv.org/abs/2309.16135v1)\].

Another approach, \[[Minki Jeong' 2022-11-22](http://arxiv.org/abs/2211.11938v1)\], introduced Supervised Contrastive Learning on Mixed Classes (SMC), which creates positives based on the class labels of the original images and uses a class-mixture-based loss to explore a more diverse data space, enhancing the generalization capability of the model \[[Minki Jeong' 2022-11-22](http://arxiv.org/abs/2211.11938v1)\]. This method has shown effectiveness on long-tailed benchmark datasets \[[Minki Jeong' 2022-11-22](http://arxiv.org/abs/2211.11938v1)\].

In addition to contrastive learning, \[[Haolin Pan' 2024-07-06](http://arxiv.org/abs/2407.04911v1)\] proposed a method called Class-Balanced Experts, which combines the strength of diverse classifiers to address the problem of long-tailed recognition. This approach has achieved results close to state-of-the-art and even set new benchmarks on two long-tailed recognition benchmarks \[[Haolin Pan' 2024-07-06](http://arxiv.org/abs/2407.04911v1)\].

Furthermore, \[[Zi-Hao Zhou' 2024-10-08](http://arxiv.org/abs/2410.06109v1)\] introduced a method called Latent Categories based long-tail Recognition (LCReg), which leverages shared latent features between head and tail classes to improve feature representation. This approach has shown significant improvements over baselines on multiple long-tailed image recognition datasets \[[Zi-Hao Zhou' 2024-10-08](http://arxiv.org/abs/2410.06109v1)\].

These works highlight the importance of addressing class imbalance through various techniques, including contrastive learning, data augmentation, and re-balancing strategies. Our proposed Aligned Contrastive Learning (ACL) algorithm builds upon these ideas and introduces novel mechanisms to eliminate gradient conflicts and imbalanced attraction and repulsion gradients between positive and negative pairs \[[Tianhong Li' 2021-11-27](http://arxiv.org/abs/2111.13998v2)\].

The long-tailed recognition problem, where a few classes dominate the dataset while others are underrepresented, has been extensively studied, with recent efforts focusing on improving contrastive learning methods to address class imbalance \[[Tianhong Li' 2021-11-27](http://arxiv.org/abs/2111.13998v2)\]. Traditional contrastive learning approaches, such as Supervised Contrastive Loss (SCL), struggle with long-tailed data due to imbalanced attraction and repulsion gradients between positive and negative pairs, leading to poor generalization for minority classes \[[Weide Liu' 2022-06-02](http://arxiv.org/abs/2206.01010v3)\]. To mitigate this, researchers have proposed various strategies, including targeted supervised contrastive learning (TSC), which enforces uniform distribution of features on a hypersphere to improve separability of minority classes \[[Tianhong Li' 2021-11-27](http://arxiv.org/abs/2111.13998v2)\]. Additionally, methods like Latent Categories based long-tail Recognition (LCReg) leverage shared latent features between head and tail classes to enhance feature diversity and representation \[[Jianggang Zhu' 2022-07-19](http://arxiv.org/abs/2207.09052v3)\]. Another approach, Dual-Branch Long-Tailed Recognition (DB-LTR), combines imbalanced learning with contrastive learning to improve adaptability to tail classes \[[Shiyu Xuan' 2024-03-10](http://arxiv.org/abs/2403.06151v1)\].
