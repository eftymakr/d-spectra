## Related Works

De novo genome assembly remains a computationally intensive task, requiring efficient algorithms and scalable infrastructure to handle the vast amounts of data generated by modern sequencing technologies. Early approaches, such as those based on de Bruijn graphs, have been widely used but suffer from high memory consumption and limited performance \[[Chengxi Ye' 2011-06-14](http://arxiv.org/abs/1106.2603v1)\]. More recent methods have attempted to address these issues through distributed computing frameworks and parallel processing \[[Giulia Guidi' 2020-10-20](http://arxiv.org/abs/2010.10055v1)\]. For example, SparseAssembler introduces a sparse de Bruijn graph structure that significantly reduces memory requirements while maintaining comparable assembly quality \[[Evangelos Georganas' 2017-05-31](http://arxiv.org/abs/1705.11147v1)\]. Similarly, HipMER has been developed for extreme-scale genome assembly, emphasizing efficient parallelization and handling of complex genomic data \[[Yinlong Xie' 2013-05-29](http://arxiv.org/abs/1305.6760v2)\].

The computational complexity of de novo assembly is further exacerbated by the need to manage large datasets and handle irregular data patterns \[[Keith R. Bradnam' 2013-01-23](http://arxiv.org/abs/1301.5406v3)\]. To mitigate these challenges, several studies have explored hardware acceleration. For instance, the work by Zhang et al. introduces a microcoded hardware accelerator for homomorphic encryption, which could be relevant for secure genome analysis \[[Giulia Guidi' 2022-07-10](http://arxiv.org/abs/2207.04350v1)\]. Additionally, the development of GPU schedulers for de novo assembly, such as those in ELBA, has aimed to improve performance by optimizing the use of multiple GPUs \[[Kleber Padovani' 2021-02-02](http://arxiv.org/abs/2102.02649v4)\]. These efforts highlight the growing interest in leveraging specialized hardware to enhance the efficiency of genome assembly.

Recent advances in long-read sequencing have also influenced the development of new assembly algorithms. Tools like Minimap and miniasm have been designed to efficiently map and assemble long reads without requiring error correction \[[Ljiljana Brankovic' 2015-05-15](http://arxiv.org/abs/1505.04019v6)\]. These tools demonstrate the potential of using advanced algorithms to improve assembly accuracy and speed. Similarly, the introduction of quantum-inspired approaches for genome assembly, such as the method described in \[[Massimo Cairo' 2020-02-24](http://arxiv.org/abs/2002.10498v3)\], suggests that novel computational paradigms may offer promising solutions for complex assembly tasks.

Despite these advancements, there remains a need for more efficient and scalable solutions. The proposed NMP-PaK architecture addresses these limitations by introducing a hardware-software co-design approach that leverages near-memory processing to reduce memory bottlenecks and improve computational efficiency \[[Geir K. Sandve' 2011-01-25](http://arxiv.org/abs/1101.4898v1)\]. This work builds on prior efforts to optimize genome assembly through hardware acceleration, such as the development of custom accelerators for sequence-to-graph mapping \[[Sean McWilliam' 2016-07-13](http://arxiv.org/abs/1607.03955v1)\]. The integration of these hardware innovations with software optimizations, such as batch processing and hybrid CPU-NMP execution, further enhances the performance of de novo assembly pipelines.

In summary, while existing methods have made significant strides in improving the efficiency of de novo assembly, there is still room for improvement in terms of memory usage, computational speed, and scalability. The proposed NMP-PaK architecture represents a step forward in addressing these challenges through a novel hardware-software co-design approach.
