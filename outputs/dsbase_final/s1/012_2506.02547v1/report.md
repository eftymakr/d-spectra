## Related Works

Event cameras, also known as neuromorphic sensors, have been widely studied for their ability to capture asynchronous scene changes at the pixel level, offering high temporal resolution \[[Topi Paananen' 2019-06-20](http://arxiv.org/abs/1906.08850v2)\]. However, the high bandwidth and computational demands of event streams have motivated research into event downsampling techniques. Prior work has primarily relied on fixed heuristics or threshold-based strategies to reduce the event rate \[[Hang Su' 2024-12-01](http://arxiv.org/abs/2412.00816v1)\]. These methods, while computationally efficient, often lack adaptability to varying scene dynamics and application-specific requirements. For instance, threshold-based approaches may fail to preserve critical event patterns in complex scenes \[[Eric Mjolsness' 2012-12-03](http://arxiv.org/abs/1212.0582v1)\].

Recent efforts have explored more adaptive methods, such as learning-based event sampling. For example, \[[Shrutarv Awasthi' 2025-05-16](http://arxiv.org/abs/2505.11282v2)\] introduced a feedback control system to regulate event rate and noise, using threshold and refractory period settings. This work demonstrated the feasibility of dynamic adjustment but was limited to specific sensor configurations. Similarly, \[[Lingdong Kong' 2025-03-25](http://arxiv.org/abs/2503.19916v1)\] proposed a differentiable event stream simulator for non-rigid 3D tracking, which enabled the use of event data in real-time applications. However, these methods typically require extensive training or domain-specific adaptations, limiting their generalizability.

The concept of zero-shot event downsampling, where downsampled events remain usable for models trained on the original event stream without task-specific adaptation, has not been extensively explored. This is in contrast to traditional approaches that assume a fixed relationship between original and downsampled events \[[Botao He' 2024-05-28](http://arxiv.org/abs/2405.17769v1)\]. Our work introduces a probabilistic framework, POLED, which models event importance through an event-importance probability density function (ePDF). This approach enables scene-specific adaptation and operates in an online setting, estimating event importance from raw event streams \[[Varun Ravi Kumar' 2019-10-07](http://arxiv.org/abs/1910.04076v4)\].

Several studies have investigated the use of event cameras for vision tasks, such as object detection and image interpolation. For example, \[[Marco Cannici' 2018-07-25](http://arxiv.org/abs/1807.09480v2)\] evaluated event-based face and eye tracking, demonstrating the potential of event data for real-time applications. However, these works typically rely on pre-defined event representations and do not address the challenge of maintaining performance under event-budget constraints. In contrast, our method introduces a contour-preserving ePDF that prioritizes structurally important events, ensuring that key visual features are preserved during downsampling \[[Tobi Delbruck' 2021-05-02](http://arxiv.org/abs/2105.00409v1)\].

Additionally, the use of event cameras in conjunction with deep learning models has been explored in various contexts. For instance, \[[Andreas Ziegler' 2025-04-25](http://arxiv.org/abs/2504.18235v2)\] introduced a framework for robust cross-platform adaptation in event camera perception, addressing the challenge of deploying event cameras across diverse settings. While these approaches focus on improving performance across different platforms, they do not directly address the issue of intelligent sampling for zero-shot event downsampling. Our work fills this gap by proposing a generalizable framework that can be applied across a wide range of vision tasks and applications.

These methods typically focus on controlling event production at the pixel level through adjustable parameters such as threshold, bandwidth, and refractory period \[[Tobi Delbruck' 2021-05-02](http://arxiv.org/abs/2105.00409v1)\]. The goal is to maintain an acceptable event rate while minimizing noise and computational overhead. Existing approaches often rely on fixed heuristics or threshold-based strategies, which can limit adaptability in varying environments \[[Tobi Delbruck' 2021-05-02](http://arxiv.org/abs/2105.00409v1)\]. Recent work has explored feedback control mechanisms that use real-time measurements of event rate and noise to regulate these parameters automatically. For instance, fixed-step feedback controllers have been proposed to adjust threshold and refractory period settings to keep event rates within an acceptable range, while bandwidth control is used to manage noise levels \[[Tobi Delbruck' 2021-05-02](http://arxiv.org/abs/2105.00409v1)\]. These techniques represent a step toward more intelligent and adaptive event sampling, enabling systems to respond to changing conditions without manual intervention.
