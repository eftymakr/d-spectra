## Related Works

Conversational recommendation systems (CRSs) have gained significant attention for their ability to engage users in multi-turn interactions to elicit preferences and provide personalized recommendations \[[Srijata Maji' 2024-05-28](http://arxiv.org/abs/2405.17740v1)\]. However, accurately capturing user preferences remains a fundamental challenge due to the multifaceted and complex nature of user intent \[[Srijata Maji' 2024-05-28](http://arxiv.org/abs/2405.17740v1)\]. Prior work has explored various approaches to enhance the understanding of user preferences in CRSs, including the use of Bayesian methods \[[Shuyang Li' 2021-12-09](http://arxiv.org/abs/2112.05197v1)\], reinforcement learning \[[Victor S. Bursztyn' 2021-09-15](http://arxiv.org/abs/2109.07576v1)\], and neural architectures \[[Ziming Li' 2017-08-15](http://arxiv.org/abs/1708.04378v1)\]. These methods aim to improve the accuracy of recommendations by leveraging user interactions, but they often require extensive user involvement, which can degrade the user experience \[[Srijata Maji' 2024-05-28](http://arxiv.org/abs/2405.17740v1)\].

To address the challenge of balancing effectiveness and efficiency in CRSs, researchers have proposed methods that reduce the need for frequent user input. For instance, \[[Shuyang Li' 2021-12-09](http://arxiv.org/abs/2112.05197v1)\] introduced a Bayesian approach that updates the probability mass function over items based on user interactions, optimizing the interaction process to terminate conversations when the most probable item is recommended. This method relies on prior information and historical data to improve recommendation quality. Similarly, \[[Victor S. Bursztyn' 2021-09-15](http://arxiv.org/abs/2109.07576v1)\] proposed a multi-objective intrinsic reward learning approach that learns intrinsic rewards from user interactions, enabling the system to adapt to user preferences without explicit feedback. These methods demonstrate the potential of using internal reward signals to guide the recommendation process, although they often require extensive training and may not be easily transferable to new domains \[[Victor S. Bursztyn' 2021-09-15](http://arxiv.org/abs/2109.07576v1)\].

Another line of research focuses on the use of simulated users to automate the interaction process. \[[Bowen Yang' 2021-12-15](http://arxiv.org/abs/2112.08140v1)\] introduced a methodology to systematically test conversational recommender systems by simulating user interactions and identifying conversational breakdowns. This approach allows for the evaluation of CRSs without requiring real user participation, thereby improving efficiency. Additionally, \[[Nolwenn Bernard' 2024-05-23](http://arxiv.org/abs/2405.14249v1)\] explored the use of large language models (LLMs) to enhance conversational recommendation systems by generating personalized recommendations based on user interactions. This work demonstrated the effectiveness of LLMs in capturing user preferences and improving recommendation accuracy, although it did not address the issue of user involvement \[[Nolwenn Bernard' 2024-05-23](http://arxiv.org/abs/2405.14249v1)\].

To further reduce the need for user input, \[[Mateo Gutierrez Granada' 2023-09-07](http://arxiv.org/abs/2309.03645v1)\] proposed a framework for generating natural language explanations for recommendations, enabling users to understand the rationale behind recommendations. This approach enhances transparency and trust in CRSs. However, generating high-quality explanations remains a challenge, particularly in complex domains. Similarly, \[[Ziming Li' 2017-08-15](http://arxiv.org/abs/1708.04378v1)\] introduced a category-based conversational recommendation approach that provides concise explanations without requiring prior user knowledge. This method uses a BERT-based neural architecture to model user preferences and recommends items based on category vectors, demonstrating the potential of explainable recommendation systems \[[Ziming Li' 2017-08-15](http://arxiv.org/abs/1708.04378v1)\].

In summary, while existing work has made significant strides in improving the accuracy and efficiency of CRSs, there remains a need for methods that reduce the reliance on frequent user input while maintaining high recommendation quality. The proposed GRSU framework addresses this challenge by using a simulated user to provide feedback, enabling automatic multi-turn interaction with CRSs \[[Srijata Maji' 2024-05-28](http://arxiv.org/abs/2405.17740v1)\]. This approach draws inspiration from prior work on reward models and beam search \[[Victor S. Bursztyn' 2021-09-15](http://arxiv.org/abs/2109.07576v1)\], while also incorporating insights from user simulation \[[Bowen Yang' 2021-12-15](http://arxiv.org/abs/2112.08140v1)\] to ensure seamless integration and efficient interaction.
