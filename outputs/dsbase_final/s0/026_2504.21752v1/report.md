## Related Works

Differential privacy (DP) has become the de facto standard for ensuring data privacy in statistical databases and machine learning applications \[[Fumiyuki Kato' 2021-04-14](http://arxiv.org/abs/2104.06569v2)\]. However, its implementation is vulnerable to malicious behaviors by servers, especially in distributed settings, where incorrect noise sampling or correlated noise generation can undermine privacy guarantees \[[Zhizhi Peng' 2025-02-25](http://arxiv.org/abs/2502.18535v2)\]. Prior work has addressed these challenges by introducing verifiable differential privacy (VDP) mechanisms that allow for the verification of DP compliance \[[Ari Biswas' 2022-08-18](http://arxiv.org/abs/2208.09011v2)\]. These mechanisms often rely on zero-knowledge proofs (ZKPs) to ensure that the server adheres to the prescribed protocol \[[Wenqiang Ruan' 2022-08-18](http://arxiv.org/abs/2208.08662v1)\]. While ZKPs are sufficient for achieving DP under verifiability requirements, they are not necessary, as demonstrated by alternative approaches that use cryptographic techniques to enforce protocol compliance \[[Mengde Han' 2022-09-28](http://arxiv.org/abs/2209.14086v2)\].

Several studies have explored the integration of ZKPs with DP to enhance trust and security in distributed systems. For instance, \[[Shiva Prasad Kasiviswanathan' 2008-03-27](http://arxiv.org/abs/0803.3946v4)\] introduced a framework for verifiable DP that leverages ZKPs to ensure that the output of a differentially private algorithm is both private and verifiable. This work laid the foundation for subsequent research on verifiable DP mechanisms, including the development of efficient verification protocols that reduce computational overhead \[[Kousha Kalantari' 2016-01-24](http://arxiv.org/abs/1601.06426v3)\]. Additionally, \[[Josep Domingo-Ferrer' 2018-03-06](http://arxiv.org/abs/1803.02139v1)\] proposed a system that combines ZKPs with DP to enable secure and privacy-preserving data aggregation in a distributed setting, demonstrating that ZKPs can be used to verify the correctness of DP mechanisms without revealing sensitive information.

The concept of verifiable DP has also been extended to the local model, where data is privatized at the client side before being sent to a central server. In this context, \[[Ashish Dandekar' 2020-03-02](http://arxiv.org/abs/2003.00973v2)\] introduced a verifiable randomized response (VRR) mechanism that allows clients to verify that their data has been processed according to the DP protocol. This work demonstrated that VRR can be used to achieve local DP while maintaining the ability to verify the correctness of the output. Subsequent research has further refined this approach, introducing more efficient verification protocols that reduce communication costs and computational overhead \[[Jonathan Hehir' 2021-05-26](http://arxiv.org/abs/2105.12615v3)\].

In addition to ZKPs, other cryptographic techniques have been explored for verifiable DP. For example, \[[Nikita P. Kalinin' 2024-02-07](http://arxiv.org/abs/2402.04840v3)\] proposed a system that uses homomorphic encryption to enable secure and privacy-preserving data aggregation, while \[[Yucheng Fu' 2024-09-16](http://arxiv.org/abs/2409.10667v2)\] introduced a framework for verifiable DP that leverages secure multi-party computation (MPC) to ensure that the output of a DP algorithm is both private and verifiable. These approaches highlight the growing interest in combining cryptographic techniques with DP to enhance trust and security in distributed systems.

The work presented in this paper builds on these prior contributions by introducing a novel definition called Verifiable Distributed Differential Privacy (VDDP), which incorporates additional verification mechanisms to address the challenges of malicious server behavior in distributed settings. The proposed mechanisms, including the Verifiable Distributed Discrete Laplacian Mechanism (VDDLM) and an improved solution to Verifiable Randomized Response (VRR), demonstrate significant improvements in efficiency and performance compared to existing verifiable DP mechanisms \[[Quan Geng' 2012-12-05](http://arxiv.org/abs/1212.1186v3)\].
